# 動態DNS

> 章節：[Community Plugins](<000 目錄.md#c-36>) › [DNS](<000 目錄.md#c-46>)

為了在防火牆的IP位址變更時更新DNS記錄，請使用動態DNS服務供應商。

我們的 os-ddclient 外掛程式支援使用 [ddclient](https://ddclient.net/)軟體或我們的原生後端來運行各種動態DNS服務。

## 先決條件

在安裝和使用此外掛程式之前，請確保在受支援的DNS提供者之一註冊一個帳戶。

## 安裝

安裝此外掛程式非常簡單，請前往“系統”‣“韌體”‣“插件”，搜尋**os-ddclient**，然後使用\[+\]按鈕進行安裝。

接下來，前往“服務”‣“動態” DNS “設定”，設定一個或多個“動態” DNS服務。

## 常規設定

常規設定標籤可讓您自訂服務設置，這將影響所有動態DNS帳戶。

| 選項 | 說明 |
| --- | --- |
| 啟用 | 啟用或停用服務 |
| 詳細 | 啟用或停用服務的詳細日誌訊息 |
| 允許 IPv6 | 啟用或停用 IPv6 位址的檢索與更新 |
| 間隔 | 服務檢查設備IP位址是否已更改的頻率（以秒為單位） |
| 後端 | 選擇要使用的後端系統，可以是「ddclient」或「native」（見下文） |

注意事項

隨著 `ddclient` 的開發逐漸衰落\[[\*](https://github.com/ddclient/ddclient/issues/528)\]，我們決定提供一個用 Python 編寫的替代方案。選擇本機後端替換所使用的實作。如果您的服務受支持，我們建議嘗試新的本機後端，它還提供對自訂 HTTP 請求的支援。

## 帳戶

帳戶標籤可讓您配置一個或多個動態DNS供應商，該服務將使用API呼叫透過HTTP (S) 更新這些提供者。

| 選項 | 說明 |
| --- | --- |
| 已啟用 | 啟用或停用帳戶（允許關閉條目而不刪除它們） |
| 描述 | 帳戶的描述性名稱 |
| 服務 | 您的動態DNS服務的供應商 |
| resourceId | 指向要更新的服務的指針，目前僅適用於 Azure |
| 使用者名稱 | 用於身份驗證的登入名稱或使用者名，使用基於令牌的身份驗證時留空 |
| 密碼 | 用於驗證的密碼、 API金鑰或安全令牌 |
| 區域 | 通常指要更新的二級網域。例如：*example.com* |
| 主機名稱 | 若要透過所選服務更新的完全限定網域列表，請以逗號分隔。例如：*subdomain.example.com* |
| 檢查 IP 位址方法 | 透過IP檢查服務取得設備的目前IP位址 |
| 要監控的接口 | 用於連接到IP檢查服務的接口，或者如果“檢查 IP 方法”設置為“接口”，則用於從中收集地址的接口 |
| 動態 IPv6 主機 | （可選）使用給定值覆蓋 IPv6 位址的介面識別碼。例如：*::aabb:33ff:fe44:ccdd* |
| 檢查 IP 逾時 | 等待IP檢查服務回傳IP位址的逾時時間（以秒為單位） |
| 強制SSL | 啟用連接到IP檢查和更新服務（透過HTTPS ，儘管大多數服務僅支援HTTPS |

注意事項

要更新完全限定域名 `A` (IPv4) 記錄和 `AAAA` 若要新增 IPv6 記錄，您必須：* 新增一個 IPv4 帳戶，並將「檢查 IP 方法」設定為 IPv4 服務；* 新增一個 IPv6 帳戶，並將「檢查 IP 方法」設定為 IPv6 服務；* 在「常規設定」標籤中，啟用「允許 IPv6」。

## 提供者特定配置

### Cloudflare

對於以 Cloudflare 為提供者的帳戶，還有一個額外的選項 **Zone**，應該將其設定為包含要更新的主機的區域的名稱，而不是其區域ID 。

Cloudflare 接受使用全域令牌授權的選項

|選項|價值|
| --- | --- |
| 使用者名稱 | Cloudflare 帳戶的電子郵件地址。 |
| 密碼 | 全域API金鑰。 |

出於安全考慮，建議使用API令牌，並結合`Permissions`區域 ‣ DNS ‣ 編輯和`Zone Resources`包含 ‣ 特定區域 ‣ 區域（與主機和帳戶選項一起使用）

|選項|價值|
| --- | --- |
| 使用者名稱 | 令牌 |
| 密碼 | API令牌。 |

### Netcup DNS

Netcup是德國主機供應商，提供API用於DNS操作：

-   週：[https://www.netcup-wiki.de/wiki/DNS\_API](https://www.netcup-wiki.de/wiki/DNS_API)
    
-   技術文件：[https://ccp.netcup.net/run/webservice/servers/endpoint.php](https://ccp.netcup.net/run/webservice/servers/endpoint.php)
    

|選項|價值|
| --- | --- |
| 使用者名稱 | 客戶編號 |
| 密碼 | API密碼\| API金鑰，這兩個欄位需要用垂直線 ( `\|` ) 符號連接起來作為分隔符號。 |

-   技術文件：[https://www.mythic-beasts.com/support/API/DNSv2](https://www.mythic-beasts.com/support/API/DNSv2)
    

|選項|價值|
| --- | --- |
