> 章節：[Releases](<000 目錄.md#c-1>) › [Business Edition](<000 目錄.md#c-3>)

已知問題和限制：

-   此版本包含新的主要作業系統版本，應謹慎執行。儘管擴展了測試覆蓋範圍，FreeBSD 所做的更改仍可能在我們不知情的情況下影響操作。除了 ZFS 啟動環境外，主要作業系統版本之間的回溯非常脆弱，在最壞的情況下應該嘗試重新安裝舊版本。有關更多信息，請參閱 FreeBSD 13.0 發行說明 [\[43\]](https://www.freebsd.org/releases/13.0R/relnotes/) 。
    
-   FreeBSD 13 中刪除 IPsec 雜湊和密碼可能會影響現有設置，因為上游已刪除了不安全的加密選項。如果您在第 2 階段使用 MD5、Blowfish、DES、3DES 或 CAST128，請在升級前移至更安全的設定。請注意，第一階段設定不受影響，但仍應避免不安全的設定。有關更多信息，請參閱問題中的 FreeBSD 提交 [\[44\]](https://github.com/opnsense/src/commit/16aabb761c0a) 。
    
-   Realtek 供應商驅動程式不再與更新的 FreeBSD 核心捆綁在一起。如果不確定 FreeBSD 13 是否支援您的 Realtek NIC，請在升級之前安裝 os-realtek-re 插件，以保持 NIC 的可操作性。
    
-   MAC 欺騙現在僅適用於已配置的接口，而不適用於 VLAN 兄弟接口或父接口。由於程式碼中先前的副作用，這可能會引入不必要的配置。確保為所有需要欺騙 MAC 的介面指派並設定欺騙 MAC，或只是欺騙父級上的 MAC，並將 VLAN 同級設定留空，讓它們自動遵循父級 MAC。如果有疑問，現在可以將父介面設定為混雜模式，以允許跨 VLAN 使用混合 MAC 位址。
    
-   非父介面不再顯示媒體和硬體卸載設置，需要在父介面上單獨設定才能生效。由於程式碼中先前的副作用，這可能會引入不必要的配置。如果先前未指派父接口，請指派它以重新應用所需的設定。
    
-   NTPD 預設值變更為預設排除「iburst」選項。 “limited”設定與“kod”選項分離。在這兩種情況下，如果需要，配置調整都可以實現先前的行為。
    
-   由於這兩個插件均已棄用，因此透過 os-dyndns 或 os-rfc2136 進行重新綁定檢查將不再有效。請在升級之前手動新增重新綁定主機或停用重新綁定保護。
    
-   GRE link1 支援已被刪除，現在需要靜態路由才能運行。
    
-   循環日誌記錄支援已被刪除。不需要使用者互動。
