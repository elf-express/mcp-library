# 透過控制台恢復配置

> 章節：[Troubleshooting](<000 目錄.md#c-50>) › [Topics](<000 目錄.md#c-51>)

有時您可能會意外引入破壞性更改，導致網路存取中斷、使用者無法登入或使SSH和 WebGUI 無法存取。如果可以透過串列埠和控制台訪問，則可以在不重新安裝的情況下回滾。

若要透過串列埠存取控制台，請參考本指南：[串列埠控制台連接](<67 串行控制台連接.md>)

當運行具有VGA功能的虛擬機器或硬體時，也可以直接存取控制台。

本指南將逐步介紹如何透過控制台恢復先前的配置。

注意

這需要保留自動備份。如果您在「系統」‣「配置」‣「備份」中變更了備份計數設置，則歷史記錄可能太短，無法從本機備份快取中恢復可用的配置。可能需要掛載包含先前配置的USB快閃磁碟機。

提示

使用 [快照](<99 快照.md>)和ZFS檔案系統可以簡化回溯操作。

## 1. 關閉設備電源

由於需要影響啟動過程來重置配置，因此應該先關閉（虛擬）設備的電源。

注意

如果您執行的是HA系統，請確保關閉所有同步配置的定時任務。否則，它們可能會覆蓋您恢復的配置。

## 2. 存取控制台

確保能夠存取（虛擬）控制台；如果是實體機，您可能需要連接顯示器和鍵盤；如果是具有序列存取功能的設備，請確保使用 PuTTY 等應用程式連接到串行/USB 連接埠。

提示

使用 OPNsense 商店的設備（[https://shop.opnsense.com](https://shop.opnsense.com/) ）時，包裝盒內通常會附帶一條 mini-USB 轉串口線，[串口控制台連接](<67 串行控制台連接.md>)指南將幫助您進行設定。

## 3. 開機啟動

開啟電源，等待 OPNsense 啟動畫面出現。請勿與啟動畫面進行任何操作，等待系統正式啟動。

當文字快速捲動時，按住 **CTRL** 按鈕並快速按下 **C** 鍵，即可退出啟動程序並進入 shell。此操作無需任何身份驗證。

## 4. 替換配置

現在你已經進入了 shell，可以對檔案系統進行修改了。在本例中，我們將恢復先前的 config.xml 版本。

首先，我們將評估應該恢復哪個版本的 config.xml 檔案：

```bash
cd /conf/backup
ls -la
```

查看備份配置的時間戳，複製更改發生之前的那個備份檔案的檔案名稱。我們將備份目前的 config.xml 文件，然後用先前的版本覆寫它。

注意

以下範例必須進行調整，以表示您的 config.xml 時間戳記。

```
cp /conf/config.xml /conf/config.xml.backup
cp /conf/backup/config-YOURTIMESTAMP.xml /conf/config.xml
```

重啟後，替換後的配置將被載入。

```
reboot
```

重新啟動後，確認您可以登錄，並且重大變更已回滾。如果仍然無法登錄，請重複上述步驟，並使用備份設定時間戳記回滾到更早的版本。

如果這無法解決問題，請使用最新的可用映像重新安裝您的裝置(https://docs.opnsense.org/manual/install.html) ，並恢復您已妥善保存的已知良好配置。
