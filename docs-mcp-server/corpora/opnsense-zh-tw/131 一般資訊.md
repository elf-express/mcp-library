# 一般資訊

> 章節：[Firewall](<000 目錄.md#c-26>)

本章解釋了防火牆系統不同模組中使用的一些概念，因此不屬於本主題的特定部分。

## 地址類型

當選擇來源和/或目標位址時，使用者可以根據上下文選擇多個選項。為了解釋不同選項的含義，我們將其總結如下：

---

|   |   |
| --- | --- |
|別名 |靈活的網路類型或位址定義，以便於重複使用，如[別名](<132 別名.md>) | 中所述
|單主機或網路|標準主機或網路 [CIDR 表示法](https://en.wikipedia.org/wiki/Classless_Inter-Domain_Routing) |
|任何|所有 IPv4 和/或 IPv6 位址（全球）|
|此防火牆 |指派給此防火牆的所有 IPv4 和/或 IPv6 位址 |
| \[介面\]網路|指派給裝置的所有網絡，這也包括指派的虛擬位址的網路（\[介面\]在[介面](<106 介面配置.md>)主題中進行了解釋）。通常用於允許來自或流向連接到特定介面的客戶端的流量。 |
| \[介面\]位址|在介面上設定的所有位址，這也包括所有虛擬（別名）位址。 |
|虛擬IP |明確選擇[虛擬 IP](<111 虛擬IP.md>) 中定義的位址 |
