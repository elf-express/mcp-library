# 自由半徑

> 章節：[Community Plugins](<000 目錄.md#c-36>) › [Other](<000 目錄.md#c-38>)

## 安裝

首先，您必須從外掛程式視圖安裝 FreeRADIUS 外掛程式 (os-freeradius)。

![../../_images/menu_plugins.png](<../images/a11a0992-menu_plugins.png>)

頁面重新載入後，您將在 FreeRADIUS 服務下看到一個新的選單項目。選擇後，將彈出一個子選單，其中包含 **General、User**和**Client** 條目：

## 常規設定

![../../_images/freeradius_general.png](<../images/3d9c96a1-freeradius_general.png>)

啟用

若要啟用該服務，您必須選取此方塊。

啟用VLAN分配

如果勾選此框，RADIUS 封包將具有一些未加密的標記，供網路裝置允許動態 VLAN 分配。在這種情況下，身份驗證仍然是加密的，但某些元資料將是可讀的。如果您想在交換器連接埠上設定VLAN，則需要啟用此複選框，這取決於經過驗證的使用者。

## 使用者

![../../_images/freeradius_users.png](<../images/aaacbb31-freeradius_users.png>)

使用者是一個實體，旨在針對 RADIUS 伺服器（電腦或人類）進行身份驗證。

若要建立用戶，請按一下 + 按鈕。

![../../_images/freeradius_edit_user.png](<../images/14792103-freeradius_edit_user.png>)

已啟用

該用戶將被寫入磁碟並可使用。您可以切換此值以暫時停用使用者。

使用者名稱

使用者將用於進行身份驗證的名稱。

密碼

用戶將用於進行身份驗證的密碼。

描述

供您用來尋找使用者的內部資訊。此設定可用於添加一些信息，例如部門。

IP 位址與子網路遮罩

如果您想使用 FreeRADIUS 進行點對點鏈接，您可以在此處新增一個 IP 位址，該位址將指派給客戶端。這對於子網路遮罩同樣有效。

VLAN ID

像交換器這樣支援802.1X認證的二層設備可以使用該欄位根據認證結果動態為交換器連接埠分配VLAN號碼。如果您有行動用戶（例如，如果員工可以將其電腦連接到辦公桌上的擴充塢，交換機會將員工的VLAN ID分配給交換器連接埠），這尤其有用。請注意，第 2 層設備必須能夠讀取此信息，這意味著**您必須在常規中啟用相應選項**

## 客戶

![../../_images/freeradius_clients.png](<../images/bfe6fb7d-freeradius_clients.png>)

RADIUS中的客戶端是中間設備/網路設備，如VPN網關、交換器或存取點。

若要建立新客戶端，請按一下 + 按鈕：

![../../_images/freeradius_edit_client.png](<../images/b3aaa087-freeradius_edit_client.png>)

已啟用

該客戶端將被寫入磁碟並可使用。您可以切換此值以暫時停用客戶端。

名稱

用於客戶端的名稱。

秘密

此金鑰用於在客戶端和 FreeRADIUS 伺服器之間提供信任關係。該密碼應該很強大，因為您只需輸入兩次（一次在 FreeRADIUS 配置中，一次在客戶端配置中），甚至複製它。如果密碼不匹配，FreeRADIUS 將拒絕所有驗證嘗試。

IP CIDR 的位址或網絡

這是客戶端（不是身份驗證設備）的IP 位址。例如，這可能是交換器的 IP 位址。
