# 診斷

> 章節：[System](<000 目錄.md#c-11>)

## 活動

活動模組顯示當前活動進程及其詳細信息，您可以在活動列表中進行搜索，使用網格底部的 info 按鈕獲取一般信息（如負載平均值、進程數等）。

---

|   |   |
| --- | --- |
| PID | 此進程的進程 ID |
| USERNAME | 執行此進程的使用者名稱 |
| PRI | 目前流程優先級 |
| NICE | NICE是 [nice](https://en.wikipedia.org/wiki/Nice_\(Unix\) ) 數量（範圍為 -20 到 20） |
| SIZE | 進程總大小（文字、資料與堆疊） |
| RES | 目前駐留內存量， RAM當前進程正在使用 |
| C | 是進程正在執行的處理器編號（僅在SMP系統上可見） |
| TIME | 進程已使用的系統與使用者 CPU 秒數 |
| WCPU | 加權 CPU 使用率 |
| COMMAND | 指令字串 |

## 服務

服務頁面顯示已設定的服務及其狀態，您可以在這裡停止/啟動/重新啟動所有服務。
