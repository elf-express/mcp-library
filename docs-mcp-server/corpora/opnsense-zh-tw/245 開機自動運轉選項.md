# 開機自動運轉選項

> 章節：[Development Manual](<000 目錄.md#c-52>) › [Backend](<000 目錄.md#c-54>)

## 啟動/自動運行選項

## 系統鉤子

OPNsense 提供了在啟動階段和各種系統事件期間插入自訂腳本的簡單方法。

Syshook 腳本應安裝在：

```
/usr/local/etc/rc.syshook.d/<subdir>/
```

它們可以包含以下子目錄中的任何執行檔（例如 shell 腳本）：

-   備份
    
    -   用於定期備份和復原的腳本
        
    
-   鯉魚
    
    -   用於CARP MASTER / BACKUP事件的腳本
        
    
-   配置
    
    -   配置發生變更（`config.xml` 變更）時使用的腳本。
        
    

注意事項

此事件對於每個更改的修訂版都是原子的，它使用 configd `system event config_changed` 觸發，並透過標準 `Config->save()` 方法中的 `syslog-ng` 處理程序鬆散耦合。 syshook 事件包含指向相關備份檔案的指標（例如 `/conf/backup/config-1601651332.5394.xml`），因此使用者（腳本）知道要處理哪個版本。

提示

嘗試使自訂配置處理程序盡可能小且高效，因為觸發事件的數量可能會快速增長。

-   早
    
    -   系統網路啟動前啟動腳本
        
    
-   進口
    
    -   儘早運行以允許透過預先提供 /conf/config.xml 或事後修改預設導入來覆寫 opnsense-import 功能
        
    
-   監視器
    
    -   腳本在監視由狀態轉換觸發的警報期間運行。第一個參數是受影響網關的名稱的逗號分隔清單。
        
    
-   開始
    
    -   系統網路啟動後啟動腳本
        
    
-   停止
    
    -   在系統正常關閉之前停止腳本
        
    
-   更新
    
    -   核心包更新後更新腳本（更新後）
        
    
-   升級
    
    -   重大升級（升級前）的升級腳本遷移工具
        
    

檔案名稱可以使用數字前綴“XX-”來保留特定的順序。 「20-」通常用於核心腳本，而「50-」用於插件。

範例（vmware guestd 啟動，檔案名稱 /usr/local/etc/rc.syshook.d/early/50-vmware）

```bash
#!/bin/sh

export vmware_guest_vmblock_enable="YES"
export vmware_guest_vmhgfs_enable="YES"
export vmware_guest_vmmemctl_enable="YES"
export vmware_guest_vmxnet_enable="YES"

/usr/local/etc/rc.d/vmware-kmod start
```

不要忘記設定 syshook 檔案的可執行權限。

## 遙控(8)

OPNsense 啟動過程的一部分是探測 */etc/rc.conf.d/* 中可用的 rc(8) 配置文件，當啟用守護程序時，系統將呼叫常規 rc(8) 啟動命令。

如果守護程序需要一些額外的準備，可以提供額外的「啟動」腳本，該腳本將在執行正常的「啟動」之前運行。

範例（使用 */etc/rc.conf.d/squid* 設定的魷魚代理伺服器）：

```
squid_setup="/usr/local/opnsense/scripts/proxy/setup.sh"
squid_enable="YES"
```

configd 模板系統可用於產生必要的設定檔。
