# UI引導網格

> 章節：[Development Manual](<000 目錄.md#c-52>) › [Frontend](<000 目錄.md#c-55>)

UIBootgrid 系統是 [Tabulator](https://tabulator.info/) 的包裝器，並提供一個通用表格系統，可在所有需要資料清單和操作的頁面上重複使用。

## 設定

要開始使用，請參閱[使用網格模組和插件](<367 使用網格模組和插件.md>)。此範例將向您展示如何開始使用最小的網格設定以及該前端程式碼如何與控制器層連結。

## 基本佈局

由於控制器層定義了標準化輸出並期望標準化輸入，因此可以透過簡單地定義一組端點來建構和提供網格，如設定中所述：

```
$("#{{formGridAddress['table_id']}}").UIBootgrid(
    {
        search:'/api/gridexample/settings/search_item/',
        get:'/api/gridexample/settings/get_item/',
        set:'/api/gridexample/settings/set_item/',
        add:'/api/gridexample/settings/add_item/',
        del:'/api/gridexample/settings/del_item/',
        toggle:'/api/gridexample/settings/toggle_item/',
        info:'/api/gridexample/settings/info'
    }
);
```

您可以使用瀏覽器開發人員工具檢查每個操作的請求/回應結構。例如，`search`端點如下所示：

**要求：**

```json
{
    "current": 1,
    "rowCount": 50,
    "sort": {}
}
```

**回應：**

```
{
    "rows": [
        {
            "uuid": "3b4e949d-443b-4127-a709-1e41589db462",
            ...
        },
        ...
    ],
    "rowCount": 1,
    "total": 1,
    "current": 1
}
```

注意事項

`info`端點不常使用（並且可以安全地省略），它們主要用作顯示訊息對話框的簡單觸發器。

## 色譜柱設置

列和關聯的屬性可以透過兩種方式定義：

-   透過表單，支援建立、刪除、更新、新增。
    
-   透過`<table>`結構，僅當`search`端點是唯一需要的（靜態資料）
    

## `form`

在表單中，列屬性在`<grid_view>`標籤中定義，如[定義對話方塊項目](<367 使用網格模組和插件.md#define-dialog-items>)中所述

## `table`

使用表格時，列屬性設定為`data-`屬性。例如：

```xml
<table id="livelog-table" class="table table-condensed table-hover table-striped table-responsive">
    <thead>
        <tr>
            <th data-column-id="interface" data-formatter="interface" data-sortable="false" data-width="80">{{ lang._('Interface') }}</th>
            <th data-column-id="dir" data-type="string" data-formatter="direction" data-sortable="false" data-width="30"></th>
            ...
        <tr>
    </thead>
</table>
```

如果使用 `table` 進行構建，則最低設定需要設定 `data-column-id` 以便將行資料對應到適當的儲存格。此外，列標題文字 (`label`) 在元素本身上設定。

注意事項

在內部，表單被轉換為表格結構。

## `options.formatters`

格式化程式是針對其列指定了格式化程式的每個儲存格執行的函數，並確定在儲存格中呈現給使用者的值。格式化程式可讓您將從控制器取得的資料處理為使用者更容易理解的格式。

`formatters`選項是一個包含`key` - `function`對的對象，其中每個鍵對應於網格形式中的`formatter`值，如[定義對話框項](<367 使用網格模組和插件.md#define-dialog-items>)中所述。

例如：

```
formatters: {
    myformatter: function (column, row, onRendered) {
        return row[column.id];
    }
}
```

上面的範例只是傳回行的值而不進行修改。

`column` 參數是一個對象，包含列的 `id` 和 `visibility` 狀態。

`row`參數是一個包含該行資料的物件。

`onRendered`參數是一個回呼函數，可讓您在渲染單元格時執行函數。例如：

```
formatters: {
    myformatter: function (column, row, onRendered) {
        onRendered((cell) => {
            console.log(`grid cell has been rendered. cell data: ${cell.getData()}`);
        })
        return row[column.id];
    }
}
```

如果您想將事件處理程序綁定到渲染的 DOM 元素，或者單元格包含更複雜的物件（例如非同步初始化的圖形），這非常有用。

回呼函數需要一個參數`cell`，您可以存取該參數來取得[單元格物件](https://tabulator.info/docs/6.4/components#component-cell)

## `options.headerFormatters`

功能上等同於 [options.formatters](#formatters)，但應用於列標題值。預設情況下，不需要在表單的 `grid_view` 標籤中指定 `headerFormatter` 標籤，因為鍵與行鍵相符。例如：

```
headerFormatters: {
    enabled: function(column) {
        return '<i class="fa-solid fa-fw fa-check-square" data-toggle="tooltip" title="{{ lang._('Enabled') }}"></i>';
    }
}
```

上面的範例將匹配 `enabled` 行鍵，並傳回一個帶有工具提示的圖標，顯示列標題的翻譯值。

函數只需要一個參數`column`，它是一個包含`id`, `visible`, `title`的物件。

## `commands`

`Commands` 列是一個特殊的列，它凍結在網格的右側，無論滾動位置如何，都可以輕鬆存取。此列包含連結到可在此配置部分中定義/擴充的操作的按鈕。

除了命令列中定義的命令之外，網格下方還放置了一些命令按鈕，這些命令按鈕連結到與某一網格行無關的操作，例如`add`或`delete-selected`。這些按鈕也可以在命令結構中定義，但將 `footer` 屬性設為 `true`。

以下命令是預設內建的，並根據各自的 CRUD 端點要求自動呈現：

-   `add`。需要`get`, `set`。
    
-   `edit`。需要`get`, `set`。
    
-   `delete`。需要`del`。
    
-   `copy`。需要`get`, `sets`。
    
-   `info`。需要`info`，
    
-   `toggle`。需要`toggle`。
    
-   `enable-selected`。需要`toggle`（請參閱`batchToggle`選項）。
    
-   `disable-selected`。需要`toggle`（請參閱`batchToggle`選項）。
    
-   `delete-selected`。需要`del`（請參閱`batchDelete`選項）。
    

您可以覆寫上述內建指令的特定屬性，因為 `commands` 物件已深度合併，例如：

```
edit: {
    sequence: 200
}
```

將保留所有`edit`命令選項，但將順序從預設的`100`更改為`200`。

額外的命令可以在頂級`commands`物件中定義。命令的結構以唯一鍵開頭，並包含具有以下架構的物件：

|物業 |類型 |必填|說明 |
| --- | --- | --- | --- |
| `method` | `function` |沒有 |點選指令時執行的功能。函數簽名是`(event, cell)`。只有當 `footer` 為 `false` 時，才會傳入[單元格物件](https://tabulator.info/docs/6.4/components#component-cell)。 |
| `title` | `string \| function` |沒有 |翻譯後的標題將顯示為工具提示。如果標題取決於狀態，則此屬性也可以是函數。如果它是一個函數，則 Cell 物件作為參數傳遞。 |
| `requires` | `array` |沒有 |可選的字串數組，定義此指令是否依賴於一個或多個CRUD操作。例如，預設的`add`指令依賴`get`和`set`，否則與此操作相關的表單邏輯將無法取得建置表單所需的結構，也無法在按一下「儲存」後呼叫正確的端點。如果缺少任何必要的端點，則不會呈現該按鈕。 |
| `sequence` | `number` |沒有 |用於控制按鈕在其他按鈕中的排序方式的數字。 |
| `footer` | `boolean` |沒有 |此指令是否應呈現在頁腳或作為行的一部分。 |
| `primary` | `boolean` |沒有 |此指令是否應呈現為主按鈕容器的一部份。僅當 `footer` 為 `true` 時相關。 |
| `classname` | `string` |是的 |圖示類別加入到按鈕元素內的`<span>`。 |
| `filter` | `function` |沒有 |一個函數，如果已定義，則必須傳回 true 或 false 並確定是否應呈現此命令。僅當 `footer` 為 `false` 時才會傳入 Cell 物件。 |
| `onRendered` | `function` |沒有 |在呈現包含事件綁定的元素之後運行的函數。這允許呼叫者覆蓋命令的行為。該元素綁定到該函數，可以透過 `$(this)` 訪問，但完整的 Cell 物件也會作為參數傳入，但前提是 `footer` 是 `false`。此函數優先於`method`.<br>。此函數可用於將渲染指令DOM元素綁定到其他系統元件，例如[$.SimpleFileUploadDlg](<261 看構造（和工具）.md#simplefileuploaddlg>)。 |

UIBootgrid 框架內建了預設命令，它們與預設控制器操作協同工作，以促進基本的 CRUD 行為。

對於進階用例，您也可以直接呼叫內建的`command`方法。範例請參考[Unbound overrides template](https://github.com/opnsense/core/blob/master/src/opnsense/mvc/app/views/OPNsense/Unbound/overrides.volt)

## `tabulatorOptions`

此處設定的任何選項都將直接傳遞到製表器。請參閱他們的[文件](https://tabulator.info/docs/)。

## 方法

UIBootgrid 上的方法可以透過 JQuery bootgrid API 呼叫：

```
$('#<grid-id>').bootgrid('<method>', ...params);
```

### `append(rows)`

將 `rows` 附加到網格。這比 [replace(rows)](#replace) 慢很多。由於大多數排序/過濾邏輯都是遠端發生的，因此`replace`應該是在網格中操作資料的首選方法。

### `replace(rows)`

將網格中的所有資料替換為`rows`。如果`ajax: false`要在網格中設定數據，請使用此功能。

### `getTable()`

取得綁定到此`UIBootgrid`的製表符網格實例。

### `clear()`

清除網格中的所有資料。

### `reload()`

重新載入網格。觸發新的AJAX請求。

### `getRowCount()`

取得目前選定的行數

### `getSelectedRows()`

取得目前選取行的`datakey`值

### `getCurrentRows()`

取得表中所有行的所有`datakey`值

### `getCurrentPage()`

取得目前分頁頁面。

### `destroy()`

摧毀網格

### `setColumns(columns)`

啟用列的可見性。 `columns` 參數需要一個列 ID 陣列。

### `unsetColumns(columns)`

禁用列的可見性。 `columns` 參數需要一個列 ID 陣列。

### `search(value, event)`

在網格中搜尋`value`（如果`ajax: true`則觸發AJAX請求）。

### `select(ids)`

以程式設計方式選擇行。需要一個 `datakey` 字串陣列。

### `getSearchPhrase()`

取得目前搜尋短語。

### `setPersistence(value)`

啟用或停用網格持久性（本機儲存中的列設定）。需要一個布林值。

## 其他組件

如果透過 [$.SimpleActionButton](<261 看構造（和工具）.md#simpleactionbutton>), :`UIBootgrid` 在頁面上呈現 `apply` 按鈕，則會自動向該元素發出訊號，提示使用者在網格中的某些內容發生變更時進行應用，例如當一行已編輯時。在內部，它透過簡單地呼叫`$(document).trigger("settings-changed");`來實現這一點。
