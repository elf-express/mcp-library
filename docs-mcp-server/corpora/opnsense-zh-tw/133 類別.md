# 類別

> 章節：[Firewall](<000 目錄.md#c-26>)

為了簡化大型規則集的維護，OPNsense 包含防火牆類別。每條規則可以包含一個或多個類別，這些類別可以在每個防火牆規則頁面的頂部進行過濾。

可以從規則內建立新類別，也可以使用防火牆 -> 類別中的類別編輯器來管理它們。

類別上沒有很多可用的屬性，您可以選擇設定顏色，並且當從防火牆規則建立時，該項目可以有一個「自動」複選框，在這種情況下，它將在不使用時自動刪除。
