# 15.1「信天翁升天」系列

> 章節：[Releases](<000 目錄.md#c-1>) › [Community Edition](<000 目錄.md#c-2>)

OPNsense 核心團隊很自豪地宣布，它已經發布了開源 OPNsense 防火牆軟體的15.1版本，綽號「Ascending Albatross」。

這是 OPNsense 專案的第一個版本。下載[\[1\]](http://opnsense.org/download/)並立即嘗試！請務必造訪專案網站[\[2\]](http://www.opnsense.org/)並了解有關我們和專案的更多資訊。該專案希望成為用戶、開發者和合作夥伴友好的地方。

我們認為，開源專案應該讓所有人都可以使用其原始碼和建置工具。 OPNsense 使用簡單的 2 條款 BSD 授權。

使用者受益於精美的安裝程式、豐富的功能集和現代化的使用者介面。邀請開發人員查看我們易於使用的建置工具。商業支援有助於保持網路快速和安全。此計畫歡迎合作夥伴共同取得成功。

OPNsense(r) 是基於 FreeBSD 10，是 pfSense(r) 的一個分支，而 pfSense(r) 又是 m0n0wall(r) 的一個分支。

下一個主要版本是15.7，將於 2015 年 7 月 1 日發布。錯誤修復和安全補丁將在可用時發布。

我們期待您加入 OPNsense 社群。

因為開放才有意義！

OPNsense 核心團隊

## 15.1.12（2015 年 6 月 17 日）

這很悲傷，但卻是事實：15.1.12很可能是同類中的最後一個。 6 個月即將結束，15.7 即將到來，其中有許多變化，例如我們如何處理版本號、發布工程分支和即將推出的版本，例如16.1。由於沒有什麼是一成不變的，我們邀請您參與論壇上的討論：

[https://forum.opnsense.org/index.php?topic=705.0](https://forum.opnsense.org/index.php?topic=705.0)

最近 OpenSSL 版本的後果終於解決了，所以現在我們將發布 FreeBSD 的安全建議以及最新版本的 OpenSSL 1.0.2c 和 LibreSSL 2.2.0。升級PHP 5.6.10似乎是另一件明智的事情。

韌體更新方面又收到了另一批小幅更改，現在我們對此感到滿意。如果您發現任何奇怪或異常的情況，請告訴我們。

## 15.1.11.4（2015 年 6 月 12 日）

巧合的是，我們預訂了今天的 15.1.11.4，結果發現自己正在進行 OpenSSL/LibreSSL 更新。 FreeBSD 的速度非常快，並為它們提供了連接埠更新。不過，今天不會發布 OpenSSL 基礎更新。這還不錯，因為我們預設會針對新版本建立所有連接埠。基礎更新將於下週進行。

除了 \*SSL 之外，還發生了很多事情，請參閱註釋和各個更新的連結。韌體GUI的另一輪穩定將使未來的升級更加一致。而且，諷刺的是，如果您在GUI中遇到更新凍結，只需刷新頁面並查找新的更新即可。

以下是全部變更內容：

-   opnsense-update：也獲得了進行軟體包更新的能力
    
-   核心：刪除了未使用的 ssh\_tunnel\_shell 和 3gstats 實用程序，將 sudo 新增至預設實用程式
    
-   captiveportal/traffic shaper：更好地修復本地主機跳過問題
    
-   流量整形器：將 ICMP, IGMP, ESP, AH 和 GRE 協定新增至可選協定中
    
-   核心：修正了導致我們的 API 無法與 Phalcon 2.0.1 及以上版本正常工作的錯誤
    
-   後端：新增了 configctl 命令實用程式啟動器並改進了其日誌記錄功能
    
-   後端：解決了 FreeBSD 上 Python 2.7 的效能下降錯誤
    
-   網關：對於所有建立的新網關，現在預設關閉透過`apinger`進行的監控（出於隱私原因，選擇退出翻轉為選擇加入）
    
-   韌體：重構韌體程式碼以使用 opnsense-update 的新功能
    
-   韌體：修復邊緣情況下要升級的軟體包的解析
    
-   韌體：修復可用軟體包升級的過度緩存
    
-   使用者：具有群組管理員的使用者現在擁有與其關聯的`wheel`群組，允許他們使用`su`或`sudo`（如果已配置）
    
-   使用者：建立新使用者主目錄時不要複製 root 的隱藏文件
    
-   埠： PCRE 8.37\_1 [\[1\]](https://github.com/freebsd/freebsd-ports/commit/030adcf1d)
    
-   埠：phalcon 2.0.2 [\[2\]](https://github.com/phalcon/cphalcon/releases/tag/phalcon-v2.0.2)
    
-   端口：strongswan 5.3.2 [\[3\]](https://wiki.strongswan.org/projects/strongswan/wiki/Changelog53)
    
-   連接埠：sqlite 3.8.10.2 [\[4\]](https://sqlite.org/releaselog/3_8_10_2.html)
    
-   埠：openvpn 2.3.7 [\[5\]](https://github.com/OpenVPN/openvpn/blob/v2.3.7/ChangeLog)

## 15.1.11（2015 年 5 月 22 日）

隨著七月份15.7版本即將完成，本週我們在荷蘭的一張桌子上坐下來回顧過去5個月裡我們所做的更改，我們發現只有一個路線圖[\[1\]](https://opnsense.org/about/road-map/)項目仍然開放：經常請求的IDS包！自最初的 15.1 以來，我們已經取得了長足的進步，並且看到穩定性的提高、功能的擴展以及幾乎每週持續的及時更新。當然，我們希望在前進的同時保持成就。

由於框架更新，15.1.11 的初始版本自周二以來已被推遲，我們必須排除並完善新的 GUI 韌體功能，以最終恢復基本系統更新。如果您從 GUI 更新到此版本，您仍然需要運行控制台韌體（選項 12）升級以保持您的基本系統最新（FreeBSD 10.1-RELEASE-p10）。這是最後一次，我們保證。必須重新啟動。

我們在 FreeBSD 之前發布了 PHP 5.6.9，刪除了許多未使用的軟體包和另外兩個自訂內核補丁，使我們從之前的 40 多個自訂補丁減少到 5 個。我們還計劃進一步修剪，打個比方來說，當 FreeBSD 10.2 上架時，可能會在沒有自訂補丁的情況下運行。

我們沒有忘記最近的 Logjam Attack [\[2\]](https://weakdh.org/) ，但不想進一步推遲目前的發布。話雖如此，15.1.11.1 將於明天發布，其中包括與 Logjam 相關的謹慎調整。

以下是15.1.11的完整更改清單：

-   核心：刪除了未使用的軟體包相依性 b42-fwcutter、bwi-firmware-kmod、dmidecode、ifstated、pecl-ssh2
    
-   核心：由於各種請求，從bind-tools切換回最新的完整綁定9.10包
    
-   src: 與 ALTQ [\[3\]](https://bugs.freebsd.org/bugzilla/show_bug.cgi?id=200222) 一起修復 pf(4) 中的恐慌
    
-   src: 更新到 FreeBSD 10.0-RELEASE-p10 [\[4\]](https://www.freebsd.org/security/advisories/FreeBSD-EN-15:04.freebsd-update.asc) [\[5\]](https://www.freebsd.org/security/advisories/FreeBSD-EN-15:05.ufs.asc)
    
-   src：恢復了另外兩個自訂補丁以與 FreeBSD 保持一致
    
-   連接埠：已更新至 ca\_root\_nss 3.19、sqlite 3.8.10.1、php 5.6.9 [\[6\]]( https://www.php.net/ChangeLog-5.php#5.6.9 ) 、openssh 6.8p1\_7 [\[7\]]( http://www.openwall.com/lists/oss-security/2015/05/16/3 )
    
-   opnsense-update：從升級中排除 /etc/tty
    
-   bsdinstaller：重新設計內部結構以符合現代連接埠標準
    
-   強制門戶：將規則產生切換到新的模板引擎
    
-   韌體：使用MVC程式碼重新實作GUI韌體更新
    
-   選單：消除折疊/展開不一致的情況
    
-   儀表板：修正已停用的小工具對話框
    
-   nat：修復了多個項目的刪除
    
-   nat：修復禁用規則的顯示

[https://sourceforge.net/projects/opnsense/files/15.1.7/](https://sourceforge.net/projects/opnsense/files/15.1.7/)

如何升級：

始終備份您的配置。不要嘗試從 LibreSSL 快照轉到 OpenSSL。並行 LibreSSL 快照將於明天發布。

使用所需的安裝媒體執行全新安裝。如果您已經安裝了舊版本，則始終可以從安裝程式匯入舊配置。

或者，透過實驗，使用韌體更新進行升級，然後轉到 root shell 並發出以下命令。

```
# # opnsense-update && reboot
```

此時，使用這兩種方法中的任何一種，您都應該使用 OPNsense 15.1.7-78bdb9aef FreeBSD 10.1-RELEASE-p6。

這是官方的變更日誌：

-   修正IGMP協定[\[1\]](https://www.freebsd.org/security/advisories/FreeBSD-SA-15:04.igmp.asc)中的整數溢出
    
-   修正 vt(4) 因 ioctl 參數不正確而崩潰的問題 [\[2\]](https://www.freebsd.org/security/advisories/FreeBSD-EN-15:01.vt.asc)
    
-   將基礎系統 OpenSSL 更新為1.0.1l [\[3\]](https://www.freebsd.org/security/advisories/FreeBSD-EN-15:02.openssl.asc)
    
-   修正 freebsd-update 函式庫更新排序問題 [\[4\]](https://www.freebsd.org/security/advisories/FreeBSD-EN-15:03.freebsd-update.asc)
    
-   停用 OpenSSH 的高效能SSH/SCP 和無密碼擴充以跟進一些與安全相關的討論。
    
-   從重型 Bind 安裝切換為輕量 Bind 安裝，以減少攻擊面。
    
-   刪除並用基於 Python 的重寫取代了舊的 `check_reload_status` 守護程式。
    
-   修正了15.1.6.1中引入的自動登入控制台鎖定回歸。
    
-   修正了與 OpenVPN 無法從檔案讀取密碼相關的問題。
    
-   值得注意的連接埠升級：bind-tools 9.10.2、strongswan 5.2.2\_1、curl 7.41 以及針對 mpd/libpdel 的 LibreSSL 修復。
    
-   從 IPv6 和 OpenVPN 腳本中刪除了 PHP-FPM 殘餘物。
    
-   修復了多個 OpenSSL 呼叫以使用最新連接埠版本而不是基本版本。
    
-   改進了儀表板上的記憶體/磁碟/交換使用情況。
    
-   正確設定 DNS 解析器進階預設值。
    
-   修復了自訂未綁定腳本的附加。
    
-   修改了根選單 shell，以便在給予參數時傳遞到真實 shell。
    
-   消除了使用者定義別名中的虛假“Array”前綴。
    
-   將 bogons 檔案取得位置移至本機鏡像。
    
-   core.git 開發引導掛鉤已改進，可以正確包含 /usr/local/etc/rc 變更。
    
-   我們所有的軟體包現在都被註釋為來自我們的鏡像以及額外的保護措施，可能允許您在 OPNsense 之上使用額外的 FreeBSD 軟體包。
