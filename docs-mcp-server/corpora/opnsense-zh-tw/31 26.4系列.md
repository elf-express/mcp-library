# 26.4系列

## 26.4.2（2026 年 8 月 14 日）

此商業版本基於 OPNsense 26.1.11 社群版本，並進行了額外的可靠性改進。

請注意，此版本提供源NAT作為出站NAT的暫定替代。 26.10 系列的功能奇偶校驗正在進行中。目前，請注意來源NAT繼續像以前一樣工作，但GUI將不允許您編輯來源NAT規則，除非您在設定中選擇混合或手動模式。這與出站 NAT 頁面的工作方式一致。從26.10開始，將需要混合或手動模式將來源NAT規則渲染到防火牆中。

遷移說明、已知問題與限制：

-   ISC-DHCP已移至插件。升級時將自動安裝。新安裝時不會安裝，因為它未使用，但您仍然可以安裝並繼續使用它。
    
-   為了適應從ISC-DCHP預設值「追蹤介面」IPv6 模式的改變，現在有一個名為「身分關聯」的同級模式，其功能相同，只是不會自動啟動ISC -DHCPv6 和 Radvd 路由器通告，從而更好地與 Kea 和 Dnsmasq 設定互通。
    
-   Dnsmasq 現在是 DHCPv4、DHCPv6 和RA的預設 DHCP 服務。但上游軟體無法支援前綴委派，因此預設不再提供此功能。在這種情況下，請使用其他 DHCPv6 伺服器。
    
-   出於命令列執行安全性的考慮，已移除歷史函數 mwexec\_bg() 和 mwexec()。請確保您的自訂程式碼未使用它們，並改用 mwexecf()、mwexecfb() 和 mwexecfm()。
    
-   sessionClose() 函數已從MVC程式碼移除，不再需要。請確保從您的自訂程式碼中也移除它。
    
-   入侵偵測功能已移除對 custom.yaml 的支援。請遷移到更新的 /usr/local/etc/suricata/conf.d 覆蓋目錄。
    
-   新的主機發現服務“hostwatch”預設為啟用。您可以隨時在“介面”>“鄰居”>“自動發現”中將其關閉。
    
-   您無需立即造訪防火牆遷移頁面。請先熟悉新規則GUI ，並查閱文件以了解是否存在不相容性。來自浮動介面的單一介面在優先權方面將不再被視為“浮動”。
    
-   防火牆： NAT ：連接埠轉送現在稱為「目標NAT 」。不再支援防火牆規則關聯，但舊的關聯防火牆規則及其最後已知的配置仍然保留，現在可以進行編輯以滿足未來的需求。
    
-   防火牆： NAT ：來源NAT來自以前稱為自動化的頁面集，但出站NAT仍然是這些類型規則的主要頁面。
    
-   企業版和社群版之間的非綁定黑名單現在保持一致。這意味著需要手動重新套用黑名單才能使用新的共享格式。
