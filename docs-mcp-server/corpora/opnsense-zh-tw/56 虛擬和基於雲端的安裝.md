# 虛擬和基於雲端的安裝

> 章節：[Installation and setup](<000 目錄.md#c-5>)

## 本地/伺服器

可使用 DVD ISO 映像在虛擬機器上安裝 OPNsense。完整說明可在[初始安裝和設定](<55 初始安裝和配置.md>)一章中找到。

### 一般提示

為了獲得最佳效能和相容性，請考慮以下準則：

-   最少需要 RAM 為 3 GB
    
-   建議的最小虛擬磁碟大小為 8 GB
    
-   在 Interfaces ‣ Settings 中停用所有硬體卸載設定
    

![../_images/disableoffloading.png](<../images/566c4c4b-disableoffloading.png>)

### VMware ESXi

VMware 提供了安裝 FreeBSD 的完整說明，可以在[此處](https://partnerweb.vmware.com/GOSIG/FreeBSD_14x.html) 找到。

若要安裝 VMware Tools，請前往 System ‣ Firmware ‣ Plugins，然後按一下旁邊的 **+**符號來安裝**os-vmware**。

![../_images/os-vmware.png](<../images/4cb52ee1-os-vmware.png>)

注意事項

雖然其他網路設定可能運作正常，但建議根據 VMware 相容性指南使用VMXNET3。

### Xen

若要安裝 Xen 工具，請前往 System ‣ Firmware ‣ Plugins（勾選 **顯示（第 3 層）社群外掛程式**）並透過點擊旁邊的**+**符號來安裝**os-xen**。

![../_images/os-xen.png](<../images/0915b8f6-os-xen.png>)

### 超V

Hyper-V 第 1 代和第 2 代虛擬機均受開箱即用支持，無需額外的驅動程式或工具。

注意事項

必須在 VM 的硬體 > 安全性部分停用安全啟動。

### KVM

若要安裝 QEMU Guest Agent，請前往系統 ‣ 韌體 ‣ 外掛程式（勾選 **顯示（第 3 層）社群外掛程式**）並透過點擊旁邊的**+**符號來安裝**os-qemu-guest-agent**。

**KVM 晶片組** OPNsense（基於 FreeBSD）支援在舊版 i440FX 機器類型和較新的 Q35 晶片組下運作。

### 其他

OPNsense 可以安裝在所有支援 FreeBSD 的虛擬機器管理程式（例如 Bhyve 或 VirtualBox）上。

注意：要安裝 VirtualBox Guest Additions，請前往 System ‣ Firmware ‣ Plugins（勾選 **顯示（第 3 層）社群外掛程式**）並透過點擊旁邊的**+**符號來安裝**os-virtualbox**。

### 主辦

對於無法使用 DVD ISO 安裝的託管安裝，可以使用 **opnsense-bootstrap** 形式的替代方法。

### opsense-引導程序

opnsense-bootstrap(8) 是一個工具，可以完全重新安裝正在運行的系統，以實現徹底的出廠重置或恢復所有 OPNsense 檔案的一致性。它還可以擦除配置目錄​​，但預設不會這樣做。

它將自動選擇最新的可用版本，並使用當前包指紋 -> CA 根證書 -> HTTPS -> OPNsense 包指紋構建信任鏈。

它還將要做的是將受支援的 FreeBSD 庫存版本轉換為 OPNsense 安裝。支援UFS和ZFS安裝。

opnsense-bootstrap 可在我們的 [GitHub 來源儲存庫](https://github.com/opnsense/update) 取得

## 常見問題

針對不同的虛擬環境報告了一些常見問題。您可以在下面找到這些問題的已知解決方案。

如果您的問題未列出，請務必先嘗試本文中提到的一般提示。

### 安裝期間檔案複製失敗

此問題很可能是由記憶體設定較低引起的。確保您的虛擬 OPNsense 安裝至少有 3 個 GB 或 RAM。

### VMware 上的磁碟錯誤

此問題可能是由有缺陷的驅動器引起的。根據報告，將磁碟機模式變更為 IDE 對某些 ESXi 版本有幫助。

### NAT / XenServer 上的效能問題/XCP-NG

據報道，此問題可透過在 Vifs 上停用 TX 校驗和卸載來解決（僅在 Vifs 上，不在 OPNsense DomU 中） - 有關詳細信息，請參閱此 [文件](https://docs.xcp-ng.org/guides/pfsense/#3-disable-tx-checksum-offload)。

### 流量整形器不適用於 VMware

如果您使用的是 VMXNET3 驅動程序，請嘗試切換到 E1000。
