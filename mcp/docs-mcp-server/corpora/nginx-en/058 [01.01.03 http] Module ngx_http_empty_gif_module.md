# Module ngx_http_empty_gif_module


## Module ngx\_http\_empty\_gif\_module

|   |
| --- |
| [Example Configuration](#example)<br>[Directives](#directives)<br>     [empty\_gif](#empty_gif) |

The `ngx_http_empty_gif_module` module emits single-pixel transparent GIF.

## Example Configuration

> ```
> location = /_.gif {
>     empty_gif;
> }
> ```
