# Module ngx_http_auth_require_module


## Module ngx\_http\_auth\_require\_module

|   |
| --- |
| [Example Configuration](#example)<br>[Directives](#directives)<br>     [auth\_require](#auth_require) |

The `ngx_http_auth_require_module` module (1.29.0) implements variable-based client authorization. It can also use variables provided by other access modules such as [ngx\_http\_auth\_request\_module](<051 [01.01.03 http] Module ngx_http_auth_request_module.md>) or [ngx\_http\_auth\_oidc\_module](<051 [01.01.03 http] Module ngx_http_auth_request_module.md>).

> This module is available as part of our [commercial subscription](https://www.f5.com/products/nginx).

## Example Configuration

> ```
> http {
>     oidc_provider my_idp {
>         ...
>     }
> 
>     map $oidc_claim_role $admin_role {
>         "admin" 1;
>     }
> 
>     server {
>         auth_oidc my_idp;
> 
>         location /admin {
>             auth_require $admin_role;
>         }
>     }
> }
> ```

## Directives

### auth_require

<table>
<tr><th>Syntax:</th><td><code><strong>auth_require</strong> <code><i>$value</i></code> ... [<code>error</code>=<code>4xx</code> | <code>5xx</code>] ;</code></td></tr>
<tr><th>Default:</th><td>auth_require off;</td></tr>
<tr><th>Context:</th><td><code>http</code>, <code>server</code>, <code>location</code>, <code>limit_except</code></td></tr>
</table>

Enables authorization based on the specified variables. The access is allowed only if all the variables are not empty and are not equal to “0”. Otherwise, the module returns `403` code, which can be overridden by the `error` parameter. Several `auth_require` directives can be used to return different error codes.
