## Module ngx\_stream\_return\_module｜模組 ngx_stream_return_module

|   |
| --- |
| [Example Configuration](#example)<br>[Directives](#directives)<br>     [return](#return)<br>[範例設定](#example)<br> [指令](#directives)<br> [返回](#return) |

The `ngx_stream_return_module` module (1.11.2) allows sending a specified value to the client and then closing the connection.

`ngx_stream_return_module`模組（ 1.11.2 ）允許向客戶端發送指定的值，然後關閉連接。

#### Example Configuration｜範例配置

> ```
> server {
>
> 伺服器 {
>     listen 12345;
>
>     聽 12345；
>     return $time_iso8601;
>
>     返回 $time_iso8601；
> }
> ```

#### Directives｜指令

|   |   |
| --- | --- |
| Syntax:<br>文法： | ``**return** `*value*`;``<br>` `**return** ` *值* `;` ` |
| Default:<br>預設值： | — |
| Context:<br>背景： | `server` |

Specifies a `*value*` to send to the client. The value can contain text, variables, and their combination.

指定要傳送給客戶端的`*value*` 。該值可以包含文字、變數及其組合。
