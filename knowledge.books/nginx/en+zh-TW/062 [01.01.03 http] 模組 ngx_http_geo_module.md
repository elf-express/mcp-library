# Module ngx_http_geo_module｜模組 ngx_http_geo_module

> 章節：[en｜在](<000 目錄.md#c-1>) › [docs｜文件](<000 目錄.md#c-2>) › [http](<000 目錄.md#c-5>)

## Module ngx\_http\_geo\_module｜模組 ngx\_http\_geo\_module

|   |
| --- |
| [Example Configuration](#example)<br>[Directives](#directives)<br>     [geo](#geo)<br>[範例設定](#example)<br> [指令](#directives)<br> [地理](#geo) |

The `ngx_http_geo_module` module creates variables with values depending on the client IP address.

`ngx_http_geo_module`模組建立變量，其值取決於客戶端IP位址。

#### Example Configuration｜範例配置

> ```
> geo $geo {
>
> 地理 $geo {
>     default        0;
>
>     預設值為 0；
> 
>     127.0.0.1      2;
>     192.168.1.0/24 1;
>     10.1.0.0/16    1;
> 
>     ::1            2;
>     2001:0db8::/32 1;
> }
> ```

#### Directives｜指令

|   |   |
| --- | --- |
| Syntax:<br>文法： | ``**geo** [`*$address*`] `*$variable*` { ... }``<br>` `**geo** [` *$address* `] ` *$variable* ` { ... }` ` |
| Default:<br>預設值： | — |
| Context:<br>背景： | `http` |

Describes the dependency of values of the specified variable on the client IP address. By default, the address is taken from the `$remote_addr` variable, but it can also be taken from another variable (0.7.27), for example:

描述指定變數的值對客戶端IP位址的依賴關係。預設情況下，位址取自`$remote_addr`變量，但也可以從另一個變數（ 0.7.27 ）中取得，例如：

> ```
> geo $arg_remote_addr $geo {
>     ...;
> }
> ```

> Since variables are evaluated only when used, the mere existence of even a large number of declared “`geo`” variables does not cause any extra costs for request processing.
>
> 由於變數僅在使用時才進行評估，因此即使存在大量已聲明的「 `geo` 」變數也不會為請求處理帶來任何額外的成本。

If the value of a variable does not represent a valid IP address then the “`255.255.255.255`” address is used.

如果變數的值不代表有效的IP位址，則使用「 `255.255.255.255` 」位址。

Addresses are specified either as prefixes in CIDR notation (including individual addresses) or as ranges (0.7.23).

位址可以指定為CIDR表示法中的前綴（包括單一位址）或範圍（ 0.7.23 ）。

> IPv6 prefixes are supported starting from versions 1.3.10 and 1.2.7.
>
> 從版本1.3.10和1.2.7開始支援IPv6前綴。

The following special parameters are also supported:

此外，也支援以下特殊參數：

`delete`

deletes the specified network (0.7.23).

刪除指定的網路（ 0.7.23 ）。

`default`

a value set to the variable if the client address does not match any of the specified addresses. When addresses are specified in CIDR notation, “`0.0.0.0/0`” and “`::/0`” can be used instead of `default`. When `default` is not specified, the default value will be an empty string.

如果用戶端位址與任何指定的位址都不匹配，則將一個值賦給該變數。當地址以CIDR表示法指定時，可以使用“ `0.0.0.0/0` ”和“ `::/0` ”代替`default` 。如果未指定`default` ，則預設值為空字串。

`include`

includes a file with addresses and values. There can be several inclusions.

包含一個帶有地址和值的檔案。可以包含多個文件。

`proxy`

defines trusted addresses (0.8.7, 0.7.63). When a request comes from a trusted address, an address from the “X-Forwarded-For”（X-轉發） request header field will be used instead. In contrast to the regular addresses, trusted addresses are checked sequentially.

定義受信任位址（ 0.8.7, 0.7.63 ）。當請求來自受信任位址時，將使用“X-Forwarded-For”（X-轉發）請求頭字段中的位址。與常規地址不同，受信任地址是按順序檢查的。

> Trusted IPv6 addresses are supported starting from versions 1.3.0 and 1.2.1.
>
> 從版本1.3.0和1.2.1開始支援受信任的IPv6位址。

`proxy_recursive`

enables recursive address search (1.3.0, 1.2.1). If recursive search is disabled then instead of the original client address that matches one of the trusted addresses, the last address sent in “X-Forwarded-For”（X-轉發） will be used. If recursive search is enabled then instead of the original client address that matches one of the trusted addresses, the last non-trusted address sent in “X-Forwarded-For”（X-轉發） will be used.

啟用遞歸位址搜尋（ 1.3.0, 1.2.1 ）。如果遞歸搜尋被停用，則不會使用與受信任位址相符的原始用戶端位址，而是使用“X-Forwarded-For”（X-轉發）中發送的最後一個位址。如果遞歸搜尋被啟用，則不會使用與受信任位址相符的原始用戶端位址，而是使用“X-Forwarded-For”（X-轉發）中發送的最後一個非受信任位址。

`ranges`

indicates that addresses are specified as ranges (0.7.23). This parameter should be the first. To speed up loading of a geo base, addresses should be put in ascending order.

表示地址以範圍形式指定（ 0.7.23 ）。此參數應為第一個參數。為加快地理資料庫的載入速度，位址應依升序排列。

`volatile`

indicates that the variable is not cacheable (1.29.3).

表示該變數不可緩存（ 1.29.3 ）。

Example:

例子：

> ```
> geo $country {
>
> 地理 $country {
>     default        ZZ;
>
>     預設ZZ ;
>     include        conf/geo.conf;
>
>     包含 conf/geo.conf；
>     delete         127.0.0.0/16;
>
>     刪除127.0.0.0/16 ;
>     proxy          192.168.100.0/24;
>
>     代理192.168.100.0/24 ;
>     proxy          2001:0db8::/32;
>
>     代理2001:0db8::/32 ;
> 
>     127.0.0.0/24   US;
>     127.0.0.1/32   RU;
>     10.1.0.0/16    RU;
>     192.168.1.0/24 UK;
> }
> ```

The `conf/geo.conf` file could contain the following lines:

`conf/geo.conf`文件可能包含以下幾行：

> ```
> 10.2.0.0/16    RU;
> 192.168.2.0/24 RU;
> ```

A value of the most specific match is used. For example, for the 127.0.0.1 address the value “`RU`” will be chosen, not “`US`”.

使用最精確匹配的值。例如，對於位址127.0.0.1 ，將選擇值“ `RU` ”，而不是“ `US` ”。

Example with ranges:

使用範圍的範例：

> ```
> geo $country {
>
> 地理 $country {
>     ranges;
>
>     範圍；
>     default                   ZZ;
>
>     預設ZZ ;
>     127.0.0.0-127.0.0.0       US;
>     127.0.0.1-127.0.0.1       RU;
>     127.0.0.1-127.0.0.255     US;
>     10.1.0.0-10.1.255.255     RU;
>     192.168.1.0-192.168.1.255 UK;
> }
> ```
