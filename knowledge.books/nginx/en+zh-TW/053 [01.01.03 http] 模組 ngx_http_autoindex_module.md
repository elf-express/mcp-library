## Module ngx\_http\_autoindex\_module｜模組 ngx\_http\_autoindex\_module

The `ngx_http_autoindex_module` module processes requests ending with the slash character (‘`/`’) and produces a directory listing. Usually a request is passed to the `ngx_http_autoindex_module` module when the [ngx\_http\_index\_module](<071 [01.01.03 http] 模組 ngx_http_index_module.md>) module cannot find an index file.

`ngx_http_autoindex_module`模組處理以斜槓字元（' `/` '）結尾的請求，並產生目錄清單。通常，當 [ngx\_http\_index\_module](<071 [01.01.03 http] 模組 ngx_http_index_module.md>)模組找不到索引檔案時，請求會傳遞給`ngx_http_autoindex_module`模組。

#### Example Configuration｜範例配置

> ```
> location / {
>
> 地點/{
>     autoindex on;
>
>     自動索引已開啟；
> }
> ```

For the HTML [format](#autoindex_format), specifies whether exact file sizes should be output in the directory listing, or rather rounded to kilobytes, megabytes, and gigabytes.

對於HTML [格式](#autoindex_format) ，指定是否應在目錄清單中輸出確切的檔案大小，或是四捨五入到千位元組、兆位元組和千兆位元組。

This directive appeared in version 1.7.9.

該指令出現在版本1.7.9 。

Sets the format of a directory listing.

設定目錄清單的格式。

When the JSONP format is used, the name of a callback function is set with the `callback` request argument. If the argument is missing or has an empty value, then the JSON format is used.

當使用JSONP格式時，回呼函數的名稱會透過`callback`請求參數設定。如果該參數缺失或值為空，則使用JSON格式。

The XML output can be transformed using the [ngx\_http\_xslt\_module](<110 [01.01.03 http] 模組 ngx_http_xslt_module.md>) module.

XML輸出可以使用 [ngx\_http\_xslt\_module](<110 [01.01.03 http] 模組 ngx_http_xslt_module.md>)模組進行轉換。

For the HTML [format](#autoindex_format), specifies whether times in the directory listing should be output in the local time zone or UTC.

對於HTML [格式](#autoindex_format) ，指定目錄清單中的時間是否應以本地時區或UTC輸出。
