Модуль `ngx_http_geoip_module` (0.8.6+) создаёт переменные, значения которых зависят от IP-адреса клиента, используя готовые базы данных [MaxMind](http://www.maxmind.com/).

`ngx_http_geoip_module` ( 0.8.6 +) 模組建立變量，其值取決於客戶端的IP位址，使用現成的 [MaxMind](http://www.maxmind.com/)資料庫。

При использовании баз данных с поддержкой IPv6 (1.3.12, 1.2.7) IPv4-адреса ищутся отображёнными на IPv6.

使用支援 IPv6 的資料庫（ 1.3.12, 1.2.7 ）時，會搜尋 IPv4 位址，並將其對應為 IPv6 位址。

По умолчанию этот модуль не собирается, его сборку необходимо разрешить с помощью конфигурационного параметра `--with-http_geoip_module`.

此模組預設未構建，必須使用`--with-http_geoip_module`配置參數啟用。

> Для сборки и работы этого модуля нужна библиотека [MaxMind GeoIP](http://www.maxmind.com/app/c).
>
> 要建置和運行此模組，您需要 [MaxMind GeoIP](http://www.maxmind.com/app/c)庫。

#### Пример конфигурации｜配置範例

> ```
> http {
>     geoip_country         GeoIP.dat;
>
>     geoip_country GeoIP.dat；
>     geoip_city            GeoLiteCity.dat;
>
>     geoip_city GeoLiteCity.dat;
>     geoip_proxy           192.168.100.0/24;
>
>     geoip_proxy 192.168.100.0/24 ;
>     geoip_proxy           2001:0db8::/32;
>
>     geoip_proxy 2001:0db8::/32 ;
>     geoip_proxy_recursive on;
>
>     geoip_proxy_recursive 已啟用；
>     ...
> ```

Задаёт базу данных для определения страны в зависимости от значения IP-адреса клиента. При использовании этой базы данных доступны следующие переменные:

指定用於根據客戶端的IP位址確定國家/地區的資料庫。使用此資料庫時，可以使用以下變數：

`$geoip_country_code`

двухбуквенный код страны, например, “`RU`”, “`US`”.

название страны, например, “`Russian Federation`”, “`United States`”.

Задаёт базу данных для определения страны, региона и города в зависимости от значения IP-адреса клиента. При использовании этой базы данных доступны следующие переменные:

指定一個資料庫，用於根據客戶的IP地址確定國家/地區、區域和城市。使用此資料庫時，可以使用以下變數：

`$geoip_area_code`

телефонный код области (только для США).

區號（僅限美國）。

> Данная переменная может содержать неактуальную информацию, т.к. соответствующее поле базы данных объявлено устаревшим.
>
> 由於相應的資料庫欄位已被棄用，因此該變數可能包含過時的資訊。

`$geoip_city_continent_code`

двухбуквенный код континента, например, “`EU`”, “`NA`”.

兩位字母的大洲代碼，例如“ `EU` ”、“ `NA` ”。

`$geoip_city_country_code`

двухбуквенный код страны, например, “`RU`”, “`US`”.

兩位字母的國家代碼，例如“ `RU` ”、“ `US` ”。

`$geoip_city_country_code3`

трёхбуквенный код страны, например, “`RUS`”, “`USA`”.

三個字母的國家代碼，例如「 `RUS` 」、「 `USA` 」。

`$geoip_city_country_name`

название страны, например, “`Russian Federation`”, “`United States`”.

國家名稱，例如「 `Russian Federation` 」、「 `United States` 」。

`$geoip_dma_code`

DMA-код региона в США (также известный как “код агломерации”), согласно [геотаргетингу](https://developers.google.com/adwords/api/docs/appendix/cities-DMAregions) Google AdWords API.

DMA是美國的一個地區代碼（也稱為「大都會區代碼」），根據 Google AdWords (https://developers.google.com/adwords/api/docs/appendix/cities-DMAregions) [地理定位]API 。

`$geoip_latitude`

широта.

緯度。

`$geoip_longitude`

долгота.

經度。

`$geoip_region`

двухсимвольный код региона страны (область, край, штат, провинция, федеральная земля и тому подобное), например, “`48`”, “`DC`”.

一個國家的兩個字元代碼（州、邊疆區、州、省、聯邦領土等），例如「 `48` 」、「 `DC` 」。

`$geoip_region_name`

название региона страны (область, край, штат, провинция, федеральная земля и тому подобное), например, “`Moscow City`”, “`District of Columbia`”.

國家名稱（州、邊疆區、州、省、聯邦領土等），例如「 `Moscow City` 」、「 `District of Columbia` 」。

`$geoip_city`

название города, например, “`Moscow`”, “`Washington`”.

城市名稱，例如「 `Moscow` 」、「 `Washington` 」。

`$geoip_postal_code`

почтовый индекс.

郵遞區號.

При выключенном рекурсивном поиске вместо исходного адреса клиента, совпадающего с одним из доверенных адресов, будет использоваться последний адрес, переданный в “X-Forwarded-For”（X-轉發）. При включённом рекурсивном поиске вместо исходного адреса клиента, совпадающего с одним из доверенных адресов, будет использоваться последний не доверенный адрес, переданный в “X-Forwarded-For”（X-轉發）.

當遞歸搜尋被停用時，將使用“X-Forwarded-For”（X-轉發）中傳入的最後一個位址，而不是客戶端的原始位址與某個受信任位址相符的位址。當遞歸搜尋啟用時，將使用“X-Forwarded-For”（X-轉發）中傳入的最後一個不受信任的位址，而不是客戶端的原始位址與某個受信任位址相符的位址。
