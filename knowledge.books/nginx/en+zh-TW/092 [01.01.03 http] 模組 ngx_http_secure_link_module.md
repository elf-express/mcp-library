# Module ngx_http_secure_link_module｜模組 ngx_http_secure_link_module

## Module ngx\_http\_secure\_link\_module｜模組 ngx\_http\_secure\_link\_module

|   |
| --- |
| [Directives](#directives)<br>     [secure\_link](#secure_link)<br>     [secure\_link\_md5](#secure_link_md5)<br>     [secure\_link\_secret](#secure_link_secret)<br>[Embedded Variables](#variables)<br>[指令](#directives)<br> [secure\_link](#secure_link)<br> [secure\_link\_md5](#secure_link_md5)<br> [secure\_link\_secret](#secure_link_secret)<br> [嵌入式變數](#variables) |

The `ngx_http_secure_link_module` module (0.7.18) is used to check authenticity of requested links, protect resources from unauthorized access, and limit link lifetime.

`ngx_http_secure_link_module`模組 ( 0.7.18 ) 用於檢查所請求連結的真實性，保護資源免受未經授權的訪問，並限制連結的生命週期。

The authenticity of a requested link is verified by comparing the checksum value passed in a request with the value computed for the request. If a link has a limited lifetime and the time has expired, the link is considered outdated. The status of these checks is made available in the `$secure_link` variable.

透過將請求中傳遞的校驗和值與為該請求計算出的校驗和值進行比較，來驗證所請求連結的真實性。如果連結的有效期有限且已過期，則該連結被視為已失效。這些檢查的狀態儲存在變數`$secure_link`中。

The module provides two alternative operation modes. The first mode is enabled by the [secure\_link\_secret](#secure_link_secret) directive and is used to check authenticity of requested links as well as protect resources from unauthorized access. The second mode (0.8.50) is enabled by the [secure\_link](#secure_link) and [secure\_link\_md5](#secure_link_md5) directives and is also used to limit lifetime of links.

此模組提供兩種可選的操作模式。第一種模式由 [secure\_link\_secret](#secure_link_secret)指令啟用，用於驗證請求連結的真實性並保護資源免受未經授權的存取。第二種模式 ( 0.8.50 ) 由 [secure\_link](#secure_link)和 [secure\_link\_md5](#secure_link_md5)指令啟用，也用於限制連結的生命週期。

This module is not built by default, it should be enabled with the `--with-http_secure_link_module` configuration parameter.

此模組預設未構建，應使用`--with-http_secure_link_module`配置參數啟用。

#### Directives｜指令

|   |   |
| --- | --- |
| Syntax:<br>語法： | ``**secure_link** `*expression*`;``<br>` `**secure_link** ` *表達式* `;` ` |
| Default:<br>預設值： | — |
| Context:<br>背景： | `http`, `server`, `location` |

Defines a string with variables from which the checksum value and lifetime of a link will be extracted.

定義一個包含變數的字串，從中提取連結的校驗和值和生命週期。

Variables used in an `*expression*` are usually associated with a request; see [example](#secure_link_md5) below.

`*expression*`中使用的變數通常與請求相關聯；請參閱下面的 [範例](#secure_link_md5) 。

The checksum value extracted from the string is compared with the MD5 hash value of the expression defined by the [secure\_link\_md5](#secure_link_md5) directive. If the checksums are different, the `$secure_link` variable is set to an empty string. If the checksums are the same, the link lifetime is checked. If the link has a limited lifetime and the time has expired, the `$secure_link` variable is set to “`0`”. Otherwise, it is set to “`1`”. The MD5 hash value passed in a request is encoded in [base64url](https://datatracker.ietf.org/doc/html/rfc4648#section-5).

從字串中提取的校驗和值與 [secure\_link\_md5](#secure_link_md5)指令定義的表達式的MD5雜湊值進行比較。如果校驗和不同，則將`$secure_link`變數設為空字串。如果校驗和相同，則檢查連結的有效期限。如果連結的有效期有限且已過期，則將`$secure_link`變數設為「 `0` 」。否則，將其設為“ `1` ”。請求中傳遞的MD5哈希值以 [base64url](https://datatracker.ietf.org/doc/html/rfc4648#section-5)格式編碼。

If a link has a limited lifetime, the expiration time is set in seconds since Epoch (Thu, 01 Jan 1970 00:00:00 GMT). The value is specified in the expression after the MD5 hash, and is separated by a comma. The expiration time passed in a request is available through the `$secure_link_expires` variable for a use in the [secure\_link\_md5](#secure_link_md5) directive. If the expiration time is not specified, a link has the unlimited lifetime.

如果連結的有效期限有限，則過期時間以自 Unix 紀元（1970 年 1 月 1 日，星期四， 00:00:00 GMT ）以來的秒數表示。該值在MD5哈希值後的表達式中指定，並以逗號分隔。請求中傳遞的過期時間可透過`$secure_link_expires`變數取得，以便在 [secure\_link\_md5](#secure_link_md5)指令中使用。如果未指定過期時間，則連結的有效期為無限期。

| Syntax:<br>語法： | ``**secure_link_md5** `*expression*`;``<br>` `**secure_link_md5** ` *表達式* `;` ` |

| Context:<br>背景： | `http`, `server`, `location` |

Defines an expression for which the MD5 hash value will be computed and compared with the value passed in a request.

定義一個表達式，用於計算MD5雜湊值，並將其與請求中傳遞的值進行比較。

The expression should contain the secured part of a link (resource) and a secret ingredient. If the link has a limited lifetime, the expression should also contain `$secure_link_expires`.

此表達式應包含連結（資源）的安全部分和秘密成分。如果連結具有有限的生命週期，則該表達式也應包含`$secure_link_expires` 。

To prevent unauthorized access, the expression may contain some information about the client, such as its address and browser version.

為防止未經授權的訪問，表達式可能包含有關客戶端的一些信息，例如其地址和瀏覽器版本。

Example:

例子：

> ```
> location /s/ {
>
> 位置 /s/ {
>     secure_link $arg_md5,$arg_expires;
>     secure_link_md5 "$secure_link_expires$uri$remote_addr secret";
> 
>     if ($secure_link = "") {
>
>     如果（$secure_link =“”）{
>         return 403;
>
>         返回403；
>     }
> 
>     if ($secure_link = "0") {
>
>     如果（$secure_link =“0”）{
>         return 410;
>
>         返回410；
>     }
> 
>     ...
> }
> ```

The “`/s/link?md5=_e4Nc3iduzkWRm01TBBNYw&expires=2147483647`” link restricts access to “`/s/link`” for the client with the IP address 127.0.0.1. The link also has the limited lifetime until January 19, 2038 (GMT).

「 `/s/link?md5=_e4Nc3iduzkWRm01TBBNYw&expires=2147483647` 」連結限制了地址為IP 127.0.0.1端對「 `/s/link` 」的存取。此連結的有效期限也有限，到2038年1月19日為止（ GMT ）。

On UNIX, the `*md5*` request argument value can be obtained as:

在UNIX上， `*md5*`請求參數值可以如下取得：

> ```
> echo -n '2147483647/s/link127.0.0.1 secret' | \
>
> echo -n '2147483647/s/link127. 0.0.1 secret' | \
>     openssl md5 -binary | openssl base64 | tr +/ -_ | tr -d =
> ```

|   |   |
| --- | --- |
| Syntax:<br>文法： | ``**secure_link_secret** `*word*`;``<br>` `**secure_link_secret** ` *字* `;` ` |
| Default:<br>預設值： | — |
| Context:<br>上下文： | `location` |

Defines a secret `*word*` used to check authenticity of requested links.

定義用於檢查所請求連結真實性的金鑰`*word*` 。

The full URI of a requested link looks as follows:

所請求連結的完整URI如下所示：

> ```
> /prefix/hash/link
>
> /前綴/哈希/鏈接
> ```

where `*hash*` is a hexadecimal representation of the MD5 hash computed for the concatenation of the link and secret word, and `*prefix*` is an arbitrary string without slashes.

其中`*hash*`是連結和秘密詞連接計算出的MD5哈希的十六進位表示， `*prefix*`是不帶斜槓的任意字串。

If the requested link passes the authenticity check, the `$secure_link` variable is set to the link extracted from the request URI. Otherwise, the `$secure_link` variable is set to an empty string.

如果請求的連結通過了真實性檢查，則將`$secure_link`變數設定為從請求URI中提取的連結。否則，將`$secure_link`變數設為空字串。

Example:

例子：

> ```
> location /p/ {
>
> 位置 /p/ {
>     secure_link_secret secret;
>
>     secure_link_secret 金鑰；
> 
>     if ($secure_link = "") {
>
>     如果（$secure_link =“”）{
>         return 403;
>
>         返回403；
>     }
> 
>     rewrite ^ /secure/$secure_link;
>
>     重寫 ^ /secure/$secure_link;
> }
> 
> location /secure/ {
>
> 位置 /secure/ {
>     internal;
>
>     內部的;
> }
> ```

A request of “`/p/5e814704a28d9bc1914ff19fa0c4a00a/link`” will be internally redirected to “`/secure/link`”.

對「 `/p/5e814704a28d9bc1914ff19fa0c4a00a/link` 」的請求將在內部重定向到「 `/secure/link` 」。

On UNIX, the hash value for this example can be obtained as:

在UNIX上，此範例的雜湊值可以如下取得：

> ```
> echo -n 'linksecret' | openssl md5 -hex
> ```

#### Embedded Variables｜嵌入變數

`$secure_link`

The status of a link check. The specific value depends on the selected operation mode.

鏈路檢查狀態。具體數值取決於所選的操作模式。

`$secure_link_expires`

The lifetime of a link passed in a request; intended to be used only in the [secure\_link\_md5](#secure_link_md5) directive.

請求中傳遞的連結的生命週期；僅用於 [secure\_link\_md5](#secure_link_md5)指令。
