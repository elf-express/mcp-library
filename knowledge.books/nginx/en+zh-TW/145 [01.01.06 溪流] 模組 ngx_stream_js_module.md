The `ngx_stream_js_module` module is used to implement session and variable handlers in JavaScript with [njs](<133 [01.01.05 紐澤西州] nginx JavaScript 模組.md>).

`ngx_stream_js_module`模組用於在 JavaScript 中實作會話和變數處理程序，[njs](<133 [01.01.05 紐澤西州] nginx JavaScript 模組.md>) 。

Download and install instructions are available [here](<134 [01.01.05 紐澤西州] 下載並安裝.md>).

下載和安裝說明可在此處取得(https://nginx.org/en/docs/njs/install.html) 。

Sets an njs function which will be called at the [access](<165 [01.01.06 溪流] nginx 如何處理TCPUDP會話.md#access_phase>) phase. Since [0.4.0](<129 [01.01.05 紐澤西州] 變化.md#njs0.4.0>), a module function can be referenced.

設定一個 njs 函數，該函數將在 [access](<165 [01.01.06 溪流] nginx 如何處理TCPUDP會話.md#access_phase>)階段呼叫。自 [0.4.0](<129 [01.01.05 紐澤西州] 變化.md#njs0.4.0>)起，可引用模組函數。

The function is called once at the moment when the stream session reaches the [access](<165 [01.01.06 溪流] nginx 如何處理TCPUDP會話.md#access_phase>) phase for the first time. The function is called with the following arguments:

此函數在串流會話首次到達 [access](<165 [01.01.06 溪流] nginx 如何處理TCPUDP會話.md#access_phase>)階段時呼叫一次。呼叫函數時會傳遞以下參數：

`s`

the [Stream Session](<137 [01.01.05 紐澤西州] 參考.md#stream>) object

[串流會話](<137 [01.01.05 紐澤西州] 參考.md#stream>)對象

At this phase, it is possible to perform initialization or register a callback with the [`s.on()`](<137 [01.01.05 紐澤西州] 參考.md#s_on>) method for each incoming data chunk until one of the following methods are called: [`s.allow()`](<137 [01.01.05 紐澤西州] 參考.md#s_allow>), [`s.decline()`](<137 [01.01.05 紐澤西州] 參考.md#s_decline>), [`s.done()`](<137 [01.01.05 紐澤西州] 參考.md#s_done>). As soon as one of these methods is called, the stream session processing switches to the [next phase](<165 [01.01.06 溪流] nginx 如何處理TCPUDP會話.md>) and all current [`s.on()`](<137 [01.01.05 紐澤西州] 參考.md#s_on>) callbacks are dropped.

在此階段，可以使用 [`s.on()`](<137 [01.01.05 紐澤西州] 參考.md#s_on>)方法對每個傳入的資料塊執行初始化或註冊回調，直到呼叫以下方法之一：[`s.allow()`](<137 [01.01.05 紐澤西州] 參考.md#s_allow>) 、[`s.decline()`](<137 [01.01.05 紐澤西州] 參考.md#s_decline>) `s.done()` (https://nginx.org/en/docs/njs/reference.html#s_done) 。一旦呼叫這些方法之一，流會話處理就會切換到 [下一階段](<165 [01.01.06 溪流] nginx 如何處理TCPUDP會話.md>) ，並且所有當前的 [`s.on()`](<137 [01.01.05 紐澤西州] 參考.md#s_on>)回調都將被丟棄。

The function is called once at the moment when the stream session reaches the [preread](<165 [01.01.06 溪流] nginx 如何處理TCPUDP會話.md#preread_phase>) phase for the first time. The function is called with the following arguments:

`s`

the [Stream Session](<137 [01.01.05 紐澤西州] 參考.md#stream>) object

At this phase, it is possible to perform initialization or register a callback with the [`s.on()`](<137 [01.01.05 紐澤西州] 參考.md#s_on>) method for each incoming data chunk until one of the following methods are called: [`s.allow()`](<137 [01.01.05 紐澤西州] 參考.md#s_allow>), [`s.decline()`](<137 [01.01.05 紐澤西州] 參考.md#s_decline>), [`s.done()`](<137 [01.01.05 紐澤西州] 參考.md#s_done>). When one of these methods is called, the stream session switches to the [next phase](<165 [01.01.06 溪流] nginx 如何處理TCPUDP會話.md>) and all current [`s.on()`](<137 [01.01.05 紐澤西州] 參考.md#s_on>) callbacks are dropped.

在此階段，可以執行初始化或註冊回呼函數[`s.on()`](<137 [01.01.05 紐澤西州] 參考.md#s_on>) 對每個傳入的資料塊執行對應的方法，直到呼叫以下方法之一：[`s.allow()`](<137 [01.01.05 紐澤西州] 參考.md#s_allow>), [`s.decline()`](<137 [01.01.05 紐澤西州] 參考.md#s_decline>), [`s.done()`](<137 [01.01.05 紐澤西州] 參考.md#s_done>)當呼叫這些方法之一時，串流會話將切換到[下一階段]。(https://nginx.org/en/docs/stream/stream_processing.html) 以及所有當前的[`s.on()`](<137 [01.01.05 紐澤西州] 參考.md#s_on>) 回調函數被丟棄。

Nevertheless, asynchronous operations are supported in [`s.on()`](<137 [01.01.05 紐澤西州] 參考.md#s_on>) callbacks in the [preread](<165 [01.01.06 溪流] nginx 如何處理TCPUDP會話.md#preread_phase>) phase. See [this example](https://github.com/nginx/njs-examples#authorizing-connections-using-ngx-fetch-as-auth-request-stream-auth-request) for more information.
>
> 由於`js_preread`處理程序會立即傳回結果，因此它僅支援同步回呼。因此，不支援非同步回調，例如 [`ngx.fetch()`](<137 [01.01.05 紐澤西州] 參考.md#ngx_fetch>)或 [`setTimeout()`](<137 [01.01.05 紐澤西州] 參考.md#settimeout>) 。但是，在 [preread](<165 [01.01.06 溪流] nginx 如何處理TCPUDP會話.md#preread_phase>)階段的 [`s.on()`](<137 [01.01.05 紐澤西州] 參考.md#s_on>)回調中支援非同步操作。有關更多信息，請參閱 [此範例](https://github.com/nginx/njs-examples#authorizing-connections-using-ngx-fetch-as-auth-request-stream-auth-request) 。
