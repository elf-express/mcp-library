The `ngx_http_ssi_module` module is a filter that processes SSI (Server Side Includes) commands in responses passing through it. Currently, the list of supported SSI commands is incomplete.

`ngx_http_ssi_module`模組是一個過濾器，用於處理通過它的回應中的SSI （伺服器端包含）命令。目前，支援的SSI指令清單尚不完整。

#### Example Configuration｜範例配置

> ```
> location / {
>
> 地點 / {
>     ssi on;
>
>     ssi是；
>     ...
> }
> ```

該指令出現在版本1.5.1 。

Allows preserving the “Last-Modified”（最後修改日期） header field from the original response during SSI processing to facilitate response caching.

允許在處理SSI時保留原始回應中的“Last-Modified”（最後修改日期）標頭字段，以方便回應快取。

By default, the header field is removed as contents of the response are modified during processing and may contain dynamically generated elements or parts that are changed independently of the original response.

預設情況下，標頭欄位會被刪除，因為回應的內容在處理過程中會被修改，並且可能包含動態產生的元素或部分，這些元素或部分會獨立於原始回應而發生變更。

Enables processing of SSI commands in responses with the specified MIME types in addition to “`text/html`”. The special value “`*`” matches any MIME type (0.8.29).

除了「 `text/html` 」之外，還允許處理具有指定MIME類型的回應中的SSI命令。特殊值“ `*` ”匹配任何MIME類型（ 0.8.29 ）。

設定SSI指令中參數值的最大長度。

#### SSI Commands｜SSI命令

SSI commands have the following generic format:

SSI指令具有以下通用格式：

> ```xml
> <!--# command parameter1=value1 parameter2=value2 ... -->
> ```

The following commands are supported:

支援以下命令：

`block`

Defines a block that can be used as a stub in the `include` command. The block can contain other SSI commands. The command has the following parameter:

定義一個可用作`include`指令存根的程式碼區塊。此程式碼區塊可以包含其他SSI指令。此命令具有以下參數：

`name`

block name.

區塊名稱。

Example:

例子：

> ```xml
> <!--# block name="one" -->
> stub
>
> 存根
> <!--# endblock -->
> ```

`config`

Sets some parameters used during SSI processing, namely:

設定SSI處理過程中所使用的一些參數，具體如下：

`errmsg`

a string that is output if an error occurs during SSI processing. By default, the following string is output:

如果在SSI處理過程中發生錯誤，則會輸出此字串。預設情況下，輸出以下字串：

> ```
> [an error occurred while processing the directive]
>
> [處理指令時發生錯誤]
> ```

`timefmt`

a format string passed to the `strftime()` function used to output date and time. By default, the following format is used:

傳遞給`strftime()`函數的格式字串，用於輸出日期和時間。預設情況下，使用以下格式：

> ```
> "%A, %d-%b-%Y %H:%M:%S %Z"
> ```

The “`%s`” format is suitable to output time in seconds.

「 `%s` 」格式適合以秒為單位輸出時間。

`echo`

Outputs the value of a variable. The command has the following parameters:

輸出變數的值。此指令有以下參數：

`var`

the variable name.

變數名。

`encoding`

the encoding method. Possible values include `none`, `url`, and `entity`. By default, `entity` is used.

編碼方法。可選值包括`none`, `url`和`entity` 。預設使用`entity` 。

`default`

a non-standard parameter that sets a string to be output if a variable is undefined. By default, “`(none)`” is output. The command

一個非標準參數，用於設定變數未定義時要輸出的字串。預設情況下，輸出“ `(none)` ”。該命令

> ```xml
> <!--# echo var="name" default="no" -->
> ```

replaces the following sequence of commands:

替換以下命令序列：

> ```xml
> <!--# if expr="$name" --><!--# echo var="name" --><!--#
>        else -->no<!--# endif -->
>
> <!--# if expr="$name" --><!--# echo var="name" --><!--#
>        else -->否<!--# endif -->
> ```

`if`

Performs a conditional inclusion. The following commands are supported:

執行條件包含操作。支援以下命令：

> ```xml
> <!--# if expr="..." -->
> ...
> <!--# elif expr="..." -->
> ...
> <!--# else -->
> ...
> <!--# endif -->
> ```

Only one level of nesting is currently supported. The command has the following parameter:

目前僅支援一層嵌套。此命令具有以下參數：

`expr`

expression. An expression can be:

表達式。表達式可以是：

-   variable existence check:  
    變數存在性檢查：
    
    > ```xml
    > <!--# if expr="$name" -->
    > ```
    
-   comparison of a variable with a text:  
    將變數與文字進行比較：
    
    > ```xml
    > <!--# if expr="$name = text" -->
    > <!--# if expr="$name != text" -->
    > ```
    
-   comparison of a variable with a regular expression:  
    將變數與正規表示式進行比較：
    
    > ```xml
    > <!--# if expr="$name = /text/" -->
    > <!--# if expr="$name != /text/" -->
    > ```
    

If a `*text*` contains variables, their values are substituted. A regular expression can contain positional and named captures that can later be used through variables, for example:

如果`*text*`包含變量，則會替換其值。正規表示式可以包含位置捕獲和命名捕獲，這些捕獲隨後可以透過變數使用，例如：

> ```xml
> <!--# if expr="$name = /(.+)@(?P<domain>.+)/" -->
>     <!--# echo var="1" -->
>     <!--# echo var="domain" -->
> <!--# endif -->
> ```

`include`

Includes the result of another request into a response. The command has the following parameters:

將另一個請求的結果包含在回應中。此命令具有以下參數：

`file`

specifies an included file, for example:

指定包含的文件，例如：

> ```xml
> <!--# include file="footer.html" -->
> ```

`virtual`

specifies an included request, for example:

指定包含的請求，例如：

> ```xml
> <!--# include virtual="/remote/body.php?argument=value" -->
> ```

Several requests specified on one page and processed by proxied or FastCGI/uwsgi/SCGI/gRPC servers run in parallel. If sequential processing is desired, the `wait` parameter should be used.

在同一頁面上指定的多個請求由代理伺服器或 FastCGI/uwsgi/ SCGI /gRPC 伺服器並行處理。如果需要順序處理，則應使用`wait`參數。

`stub`

a non-standard parameter that names the block whose content will be output if the included request results in an empty body or if an error occurs during the request processing, for example:

一個非標準參數，用於指定當包含的請求返回空正文或在請求處理過程中發生錯誤時，將輸出該內容的區塊，例如：

> ```xml
> <!--# block name="one" -->&nbsp;<!--# endblock -->
>
> <!--# block name="one" --> &nbsp; <!--# endblock -->
> <!--# include virtual="/remote/body.php?argument=value" stub="one" -->
> ```

The replacement block content is processed in the included request context.

替換區塊的內容在包含的請求上下文中進行處理。

`wait`

a non-standard parameter that instructs to wait for a request to fully complete before continuing with SSI processing, for example:

一個非標準參數，指示在繼續進行SSI處理之前，等待請求完全完成，例如：

> ```xml
> <!--# include virtual="/remote/body.php?argument=value" wait="yes" -->
> ```

`set`

a non-standard parameter that instructs to write a successful result of request processing to the specified variable, for example:

一個非標準參數，用於指示將請求處理成功的結果寫入指定的變量，例如：

> ```xml
> <!--# include virtual="/remote/body.php?argument=value" set="one" -->
> ```

The maximum size of the response is set by the [subrequest\_output\_buffer\_size](<056 [01.01.03 http] 模組 ngx_http_core_module.md#subrequest_output_buffer_size>) directive (1.13.10):

回應的最大大小由 [subrequest\_output\_buffer\_size](<056 [01.01.03 http] 模組 ngx_http_core_module.md#subrequest_output_buffer_size>)指令 ( 1.13.10 ) 設定：

> ```
> location /remote/ {
>
> 位置 /remote/ {
>     subrequest_output_buffer_size 64k;
>
>     子請求輸出緩衝區大小 64k；
>     ...
> }
> ```

Prior to version 1.13.10, only the results of responses obtained using the [ngx\_http\_proxy\_module](<085 [01.01.03 http] 模組 ngx_http_proxy_module.md>), [ngx\_http\_memcached\_module](<079 [01.01.03 http] 模組 ngx_http_memcached_module.md>), [ngx\_http\_fastcgi\_module](<060 [01.01.03 http] 模組 ngx_http_fastcgi_module.md>) (1.5.6), [ngx\_http\_uwsgi\_module](<107 [01.01.03 http] 模組 ngx_http_uwsgi_module.md>) (1.5.6), and [ngx\_http\_scgi\_module](<091 [01.01.03 http] 模組 ngx_http_scgi_module.md>) (1.5.6) modules could be written into variables. The maximum size of the response was set with the [proxy\_buffer\_size](<085 [01.01.03 http] 模組 ngx_http_proxy_module.md#proxy_buffer_size>), [memcached\_buffer\_size](<079 [01.01.03 http] 模組 ngx_http_memcached_module.md#memcached_buffer_size>), [fastcgi\_buffer\_size](<060 [01.01.03 http] 模組 ngx_http_fastcgi_module.md#fastcgi_buffer_size>), [uwsgi\_buffer\_size](<107 [01.01.03 http] 模組 ngx_http_uwsgi_module.md#uwsgi_buffer_size>), and [scgi\_buffer\_size](<091 [01.01.03 http] 模組 ngx_http_scgi_module.md#scgi_buffer_size>) directives.

版本之前 1.13.10僅使用 [ngx\_http\_proxy\_module 所得的反應結果](<085 [01.01.03 http] 模組 ngx_http_proxy_module.md>), [ngx\_http\_memcached\_module](<079 [01.01.03 http] 模組 ngx_http_memcached_module.md>), [ngx\_http\_fastcgi\_module](<060 [01.01.03 http] 模組 ngx_http_fastcgi_module.md>) (1.5.6), [ngx\_http\_uwsgi\_module](<107 [01.01.03 http] 模組 ngx_http_uwsgi_module.md>) (1.5.6），以及 [ngx\_http\_scgi\_module](<091 [01.01.03 http] 模組 ngx_http_scgi_module.md>) (1.5.6) 模組可以寫入變數。回應的最大大小由 [proxy\_buffer\_size] 設定。(https://nginx.org/en/docs/http/ngx_http_proxy_module.html#proxy_buffer_size)，[memcached_buffer_size](<079 [01.01.03 http] 模組 ngx_http_memcached_module.md#memcached_buffer_size>)，[fastcgi_buffer_size](<060 [01.01.03 http] 模組 ngx_http_fastcgi_module.md#fastcgi_buffer_size>), [uwsgi\_buffer\_size](<107 [01.01.03 http] 模組 ngx_http_uwsgi_module.md#uwsgi_buffer_size>)和 [scgi\_buffer\_size](<091 [01.01.03 http] 模組 ngx_http_scgi_module.md#scgi_buffer_size>) 指令。

`set`

Sets a value of a variable. The command has the following parameters:

設定變數的值。此命令具有以下參數：

`var`

the variable name.

變數名。

`value`

the variable value. If an assigned value contains variables, their values are substituted.

變數值。如果賦​​值包含變量，則會取代這些變數的值。

#### Embedded Variables｜嵌入變數

The `ngx_http_ssi_module` module supports two embedded variables:

`ngx_http_ssi_module`模組支援兩個嵌入式變數：

`$date_local`

current time in the local time zone. The format is set by the `config` command with the `timefmt` parameter.

當前時間，以當地時區為準。格式由`config`指令和`timefmt`參數設定。

`$date_gmt`

current time in GMT. The format is set by the `config` command with the `timefmt` parameter.

目前時間位於GMT中。格式由`config`指令和`timefmt`參數設定。
