# Module ngx_http_gzip_static_module｜模組 ngx_http_gzip_static_module

> 章節：[en｜在](<000 目錄.md#c-1>) › [docs｜文件](<000 目錄.md#c-2>) › [http](<000 目錄.md#c-5>)

## Module ngx\_http\_gzip\_static\_module｜模組 ngx\_http\_gzip\_static\_module

|   |
| --- |
| [Example Configuration](#example)<br>[Directives](#directives)<br>     [gzip\_static](#gzip_static)<br>[範例設定](#example)<br>[指令](#directives)<br>     [gzip\_static](#gzip_static) |

The `ngx_http_gzip_static_module` module allows sending precompressed files with the “`.gz`” filename extension instead of regular files.

`ngx_http_gzip_static_module` 模組允許發送帶有“`.gz`”文件副檔名的預壓縮文件，而不是常規文件。

This module is not built by default, it should be enabled with the `--with-http_gzip_static_module` configuration parameter.

此模組預設未構建，應使用`--with-http_gzip_static_module`配置參數啟用。

#### Example Configuration｜範例配置

> ```
> gzip_static  on;
>
> gzip_static 開啟；
> gzip_proxied expired no-cache no-store private auth;
>
> gzip_proxied 過期無快取無儲存私有身分驗證；
> ```

<tr><th>Default:<br>預設：</th><td>gzip_static off;<br>gzip_static 關閉；</td></tr>

Enables (“`on`”) or disables (“`off`”) checking the existence of precompressed files. The following directives are also taken into account: [gzip\_http\_version](<066 [01.01.03 http] 模組 ngx_http_gzip_module.md#gzip_http_version>), [gzip\_proxied](<066 [01.01.03 http] 模組 ngx_http_gzip_module.md#gzip_proxied>), [gzip\_disable](<066 [01.01.03 http] 模組 ngx_http_gzip_module.md#gzip_disable>), and [gzip\_vary](<066 [01.01.03 http] 模組 ngx_http_gzip_module.md#gzip_vary>).

啟用（“`on`”）或停用（“`off`”）檢查預壓縮檔案是否存在。也考慮以下指令：[gzip\_http\_version](<066 [01.01.03 http] 模組 ngx_http_gzip_module.md#gzip_http_version>)、[gzip\_proxied](<066 [01.01.03 http] 模組 ngx_http_gzip_module.md#gzip_proxied>)、[gzip\_disable](<066 [01.01.03 http] 模組 ngx_http_gzip_module.md#gzip_disable>) 和 [gzip\_vary](<066 [01.01.03 http] 模組 ngx_http_gzip_module.md#gzip_vary>)。

With the “`always`” value (1.3.6), gzipped file is used in all cases, without checking if the client supports it. It is useful if there are no uncompressed files on the disk anyway or the [ngx\_http\_gunzip\_module](<065 [01.01.03 http] 模組 ngx_http_gunzip_module.md>) is used.

使用“`always`”值（1.3.6），在所有情況下都使用gzip壓縮文件，而不檢查客戶端是否支援它。如果磁碟上沒有未壓縮的檔案或使用了 [ngx\_http\_gunzip\_module](<065 [01.01.03 http] 模組 ngx_http_gunzip_module.md>)，那麼它就很有用。

The files can be compressed using the `gzip` command, or any other compatible one. It is recommended that the modification date and time of original and compressed files be the same.

可以使用 `gzip` 指令或任何其他相容指令來壓縮檔案。建議原始檔案和壓縮檔案的修改日期和時間相同。
