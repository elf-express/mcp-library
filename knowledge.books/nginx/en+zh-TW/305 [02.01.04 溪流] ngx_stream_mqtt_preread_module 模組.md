## Модуль ngx\_stream\_mqtt\_preread\_module｜ngx_stream_mqtt_preread_module 模組

|   |

Модуль `ngx_stream_mqtt_preread_module` (1.23.4) позволяет извлекать информацию из сообщения CONNECT протокола Message Queuing Telemetry Transport (MQTT) версий [3.1.1](https://docs.oasis-open.org/mqtt/mqtt/v3.1.1/mqtt-v3.1.1.html) и [5.0](https://docs.oasis-open.org/mqtt/mqtt/v5.0/mqtt-v5.0.html), например имя пользователя или ID клиента.

`ngx_stream_mqtt_preread_module`模組 (1.23.4) 允許從訊息佇列遙測傳輸 (MQTT) 協定版本 [3.1.1](https://docs.oasis-open.org/mqtt/mqtt/v3.1.1/mqtt-v3.1.1.html)和 [5.0](https://docs.oasis-open.org/mqtt/mqtt/v5.0/mqtt-v5.0.html)的 CONNECT 訊息中提取資訊，例如使用者名稱或客戶端 ID。

> Модуль доступен как часть [коммерческой подписки](https://www.f5.com/products/nginx).
>
> 此模組包含在[商業訂閱](https://www.f5.com/products/nginx)中。

#### Пример конфигурации｜配置範例

> ```
> mqtt_preread on;
>
> mqtt_preread 已開啟；
> return       $mqtt_preread_clientid;
>
> 返回 $mqtt_preread_clientid；
> ```

Разрешает извлечение информации из сообщения СONNECT во время фазы [предварительного чтения](<317 [02.01.04 溪流] Nginx 如何處理TCPUDP會話.md#preread_phase>).

允許在 [預讀 階段從 CONNECT 訊息中提取資訊](<317 [02.01.04 溪流] Nginx 如何處理TCPUDP會話.md#preread_phase>) 。

#### Встроенные переменные｜內建變數

`$mqtt_preread_clientid`

значение `clientid` из СONNECT-сообщения

來自 CONNECT 訊息的`clientid`值

`$mqtt_preread_username`

значение `username` из СONNECT-сообщения

CONNECT 訊息中的`username`值
