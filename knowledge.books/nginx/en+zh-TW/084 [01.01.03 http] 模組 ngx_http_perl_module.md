The `ngx_http_perl_module` module is used to implement location and variable handlers in Perl and insert Perl calls into SSI.

`ngx_http_perl_module`模組用於在 Perl 中實現位置和變數處理程序，並將 Perl 呼叫插入到SSI中。

This module is not built by default, it should be enabled with the `--with-http_perl_module` configuration parameter.

此模組預設未構建，應使用`--with-http_perl_module`配置參數啟用。

> This module requires [Perl](https://www.perl.org/get.html) version 5.6.1 or higher. The C compiler should be compatible with the one used to build Perl.
>
> 本模組需要 Perl 版本(https://www.perl.org/get.html)或更高版本5.6.1編譯器應與用於建置 Perl 的編譯器相容。

#### Known Issues｜已知問題

The module is experimental, caveat emptor applies.

此模組為實驗性模組，請自行承擔風險。

In order for Perl to recompile the modified modules during reconfiguration, it should be built with the `-Dusemultiplicity=yes` or `-Dusethreads=yes` parameters. Also, to make Perl leak less memory at run time, it should be built with the `-Dusemymalloc=no` parameter. To check the values of these parameters in an already built Perl (preferred values are specified in the example), run:

為了使 Perl 在重新配置期間重新編譯修改後的模組，應該使用`-Dusemultiplicity=yes`或`-Dusethreads=yes`參數進行建置。此外，為了減少 Perl 在運行時的記憶體洩漏，應該使用`-Dusemymalloc=no`參數進行建置。若要檢查已建置的 Perl 中這些參數的值（範例中指定了建議值），請執行：

> ```bash
>
> 『`bash
> $ perl -V:usemultiplicity -V:usemymalloc
> usemultiplicity='define';
> usemymalloc='n';
> ```

Note that after rebuilding Perl with the new `-Dusemultiplicity=yes` or `-Dusethreads=yes` parameters, all binary Perl modules will have to be rebuilt as well — they will just stop working with the new Perl.

請注意，在使用新的`-Dusemultiplicity=yes`或`-Dusethreads=yes`參數重新建構 Perl 後，所有二進位 Perl 模組也必須重新建置——它們將不再與新的 Perl 一起使用。

There is a possibility that the main process and then worker processes will grow in size after every reconfiguration. If the main process grows to an unacceptable size, the [live upgrade](<026 [01.01 文件] 控制 Nginx.md#upgrade>) procedure can be applied without changing the executable file.

每次重新配置後，主進程及其後續工作進程的大小都有可能成長。如果主進程成長到無法接受的大小，可以在不更改執行檔的情況下套用 [線上升級](<026 [01.01 文件] 控制 Nginx.md#upgrade>)程式。

While the Perl module is performing a long-running operation, such as resolving a domain name, connecting to another server, or querying a database, other requests assigned to the current worker process will not be processed. It is thus recommended to perform only such operations that have predictable and short execution time, such as accessing the local file system.

當 Perl 模組執行耗時較長的操作（例如解析網域名稱、連接到其他伺服器或查詢資料庫）時，指派給目前工作進程的其他請求將不會被處理。因此，建議僅執行執行時間可預測且較短的操作，例如存取本機檔案系統。

#### Example Configuration｜範例配置

> ```
> http {
> 
>     perl_modules perl/lib;
>     perl_require hello.pm;
> 
>     perl_set $msie6 '
> 
>         sub {
>
>         子 {
>             my $r = shift;
>
>             我的 $r = shift;
>             my $ua = $r->header_in("User-Agent"（使用者代理）);
>
>             my $ua = $r->header_in( "User-Agent"（使用者代理） );
> 
>             return "" if $ua =~ /Opera/;
>
>             如果 $ua =~ /Opera/，則回傳「」；
>             return "1" if $ua =~ / MSIE [6-9]\.\d+/;
>
>             如果 $ua =~ / MSIE [6-9]\.\d+/，則回傳「1」；
>             return "";
>
>             返回 ””;
>         }
> 
>     ';
> 
>     server {
>
>     伺服器 {
>         location / {
>
>         地點 / {
>             perl hello::handler;
>         }
>     }
> ```

The `perl/lib/hello.pm` module:

`perl/lib/hello.pm`模組：

> ```
> package hello;
>
> 打包 hello;
> 
> use nginx;
>
> 使用 nginx；
> 
> sub handler {
>
> 子處理程序{
>     my $r = shift;
>
>     我的 $r = shift;
> 
>     $r->send_http_header("text/html");
>     return OK if $r->header_only;
>
>     如果 $r->header_only，則回傳OK ；
> 
>     $r->print("hello!\n<br/>");
>
>     $r->print("你好！\n <br/> ");
> 
>     if (-f $r->filename or -d _) {
>
>     如果 (-f $r->filename 或 -d _) {
>         $r->print($r->uri, " exists!\n");
>
>         $r->print($r->uri, " 存在！\n");
>     }
> 
>     return OK;
>
>     返回OK ；
> }
> 
> 1;
> __END__
> ```

#### The $r Request Object Methods｜$r 請求物件方法

`$r->args`

returns request arguments.

返回請求參數。

`$r->filename`

returns a filename corresponding to the request URI.

傳回與請求URI對應的檔名。

``$r->has_request_body(`*handler*`)``

` `$r->has_request_body(` *處理程序* `)` `

returns 0 if there is no body in a request. If there is a body, the specified handler is set for the request and 1 is returned. After reading the request body, nginx will call the specified handler. Note that the handler function should be passed by reference. Example:

如果請求體為空，則傳回 0。如果請求體存在，則會為該請求設定指定的處理程序，並傳回 1。 nginx 讀取請求體後，將呼叫指定的處理程序。請注意，處理程序函數應按引用傳遞。例如：

> ```
> package hello;
>
> 打包 hello;
> 
> use nginx;
>
> 使用 nginx；
> 
> sub handler {
>
> 子處理程序{
>     my $r = shift;
>
>     我的 $r = shift;
> 
>     if ($r->request_method ne "POST"（郵政）) {
>
>     如果 ($r->request_method 不等於"POST"（郵政） ) {
>         return DECLINED;
>
>         返回DECLINED ；
>     }
> 
>     if ($r->has_request_body(\&post)) {
>         return OK;
>
>         返回OK ；
>     }
> 
>     return HTTP_BAD_REQUEST;
>
>     返回 HTTP_BAD_REQUEST；
> }
> 
> sub post {
>
> 子帖子{
>     my $r = shift;
>
>     我的 $r = shift;
> 
>     $r->send_http_header;
> 
>     $r->print("request_body: \"", $r->request_body, "\"<br/>");
>
>     $r->print("request_body: \"", $r->request_body, "\" <br/> ");
>     $r->print("request_body_file: \"", $r->request_body_file, "\"<br/>\n");
>
>     $r->print("request_body_file: \"", $r->request_body_file, "\" <br/> \n");
> 
>     return OK;
>
>     返回OK ；
> }
> 
> 1;
> 
> __END__
> ```

`$r->allow_ranges`

enables the use of byte ranges when sending responses.

允許在發送回應時使用位元組範圍。

`$r->discard_request_body`

instructs nginx to discard the request body.

指示 nginx 丟棄請求體。

``$r->header_in(`*field*`)``

` `$r->header_in(` *字段* `)` `

returns the value of the specified client request header field.

傳回指定客戶端請求頭字段的值。

`$r->header_only`

determines whether the whole response or only its header should be sent to the client.

決定是將整個回應還是僅將回應頭髮送給客戶端。

``$r->header_out(`*field*`, `*value*`)``

` `$r->header_out(` *字段* `, ` *值* `)` `

sets a value for the specified response header field.

設定指定響應頭欄位的值。

``$r->internal_redirect(`*uri*`)``

` `$r->internal_redirect(` *嘆氣* `)` `

does an internal redirect to the specified `*uri*`. An actual redirect happens after the Perl handler execution is completed.

執行內部重定向到指定的`*uri*` 。實際重定向發生在 Perl 處理程序執行完成後。

> Since version 1.17.2, the method accepts escaped URIs and supports redirections to named locations.
>
> 自版本1.17.2起，該方法接受轉義的URI，並支援重定向到命名位置。

``$r->log_error(`*errno*`, `*message*`)``

` `$r->log_error(` *errno* `, ` *message* `)` `

writes the specified `*message*` into the [error\_log](<125 [01.01 文件] 核心功能.md#error_log>). If `*errno*` is non-zero, an error code and its description will be appended to the message.

將指定的`*message*`寫入 [error\_log](<125 [01.01 文件] 核心功能.md#error_log>) 。如果`*errno*`非零，則會將錯誤代碼及其描述附加到訊息中。

``$r->print(`*text*`, ...)``

` `$r->print(` *文本* `, ...)` `

passes data to a client.

將資料傳遞給客戶端。

`$r->request_body`

returns the client request body if it has not been written to a temporary file. To ensure that the client request body is in memory, its size should be limited by [client\_max\_body\_size](<056 [01.01.03 http] 模組 ngx_http_core_module.md#client_max_body_size>), and a sufficient buffer size should be set using [client\_body\_buffer\_size](<056 [01.01.03 http] 模組 ngx_http_core_module.md#client_body_buffer_size>).

如果用戶端請求體尚未寫入臨時文件，則傳回客戶端請求體。為確保客戶端請求體位於記憶體中，其大小應受 [client\_max\_body\_size](<056 [01.01.03 http] 模組 ngx_http_core_module.md#client_max_body_size>)的限制，並且應使用 [client\_body\_buffer\_size](<056 [01.01.03 http] 模組 ngx_http_core_module.md#client_body_buffer_size>)設定足夠的緩衝區大小。

`$r->request_body_file`

returns the name of the file with the client request body. After the processing, the file should be removed. To always write a request body to a file, [client\_body\_in\_file\_only](<056 [01.01.03 http] 模組 ngx_http_core_module.md#client_body_in_file_only>) should be enabled.

傳回包含客戶端請求正文的檔案名稱。處理完成後，該文件應被刪除。若要始終將請求正文寫入文件，應啟用 [client\_body\_in\_file\_only](<056 [01.01.03 http] 模組 ngx_http_core_module.md#client_body_in_file_only>) 。

`$r->request_method`

returns the client request HTTP method.

返回客戶端請求HTTP方法。

`$r->remote_addr`

returns the client IP address.

返回客戶端IP位址。

`$r->flush`

immediately sends data to the client.

立即將資料傳送給客戶端。

``$r->sendfile(`*name*`[, `*offset*`[, `*length*`]])``

` `$r->sendfile(` *名稱* `[, ` *偏移量* `[, ` *長度* `]])` `

sends the specified file content to the client. Optional parameters specify the initial offset and length of the data to be transmitted. The actual data transmission happens after the Perl handler has completed.

將指定的文件內容傳送給客戶端。可選參數指定要傳輸的資料的初始偏移量和長度。實際的資料傳輸在 Perl 處理程序完成後進行。

``$r->send_http_header([`*type*`])``

` `$r->send_http_header([` *類型* `])` `

sends the response header to the client. The optional `*type*` parameter sets the value of the “Content-Type”（內容類型） response header field. If the value is an empty string, the “Content-Type”（內容類型） header field will not be sent.

向客戶端發送回應頭。可選參數`*type*`用於設定“Content-Type”（內容類型）響應頭字段的值。如果該值為空字串，則不會傳送“Content-Type”（內容類型）回應頭欄位。

``$r->status(`*code*`)``

` `$r->status(` *代碼* `)` `

sets a response code.

設定響應代碼。

``$r->sleep(`*milliseconds*`, `*handler*`)``

` `$r->sleep(` *毫秒* `, ` *處理程序* `)` `

sets the specified handler and stops request processing for the specified time. In the meantime, nginx continues to process other requests. After the specified time has elapsed, nginx will call the installed handler. Note that the handler function should be passed by reference. In order to pass data between handlers, `$r->variable()` should be used. Example:

設定指定的處理程序，並停止請求處理一段時間。在此期間，nginx 會繼續處理其他要求。指定時間過後，nginx 將呼叫已安裝的處理程序。請注意，處理程序函數應按引用傳遞。要在處理程序之間傳遞數據，應使用`$r->variable()` 。範例：

> ```
> package hello;
>
> 打包 hello;
> 
> use nginx;
>
> 使用 nginx；
> 
> sub handler {
>
> 子處理程序{
>     my $r = shift;
>
>     我的 $r = shift;
> 
>     $r->discard_request_body;
>     $r->variable("var", "OK"（好的）);
>
>     $r->variable("var", "OK"（好的） );
>     $r->sleep(1000, \&next);
> 
>     return OK;
>
>     返回OK ；
> }
> 
> sub next {
>
> 子程序下一個{
>     my $r = shift;
>
>     我的 $r = shift;
> 
>     $r->send_http_header;
>     $r->print($r->variable("var"));
> 
>     return OK;
>
>     返回OK ；
> }
> 
> 1;
> 
> __END__
> ```

``$r->unescape(`*text*`)``

` `$r->unescape(` *文本* `)` `

decodes a text encoded in the “%XX” form.

解碼以「% XX 」形式編碼的文字。

`$r->uri`

returns a request URI.

返回請求URI 。

``$r->variable(`*name*`[, `*value*`])``

` `$r->variable(` *名稱* `[, ` *值* `])` `

returns or sets the value of the specified variable. Variables are local to each request.

傳回或設定指定變數的值。變數在每個請求中都是局部的。
