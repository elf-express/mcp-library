## Модуль ngx\_stream\_pass\_module｜ngx_stream_pass_module 模組

|   |
| --- |
| [Пример конфигурации](#example)<br>[Директивы](#directives)<br>     [pass](#pass)<br>[設定範例](#example)<br> [指令](#directives)<br> [密碼](#pass) |

Модуль `ngx_stream_pass_module` (1.25.5) позволяет передавать принятое соединение напрямую в любой настроенный слушающий сокет в `http`, `stream`, `mail` и других подобных модулях.

`ngx_stream_pass_module` ( 1.25.5 ) 模組可讓您將接收到的連接直接轉送到`http`, `stream`, `mail`和其他類似模組中配置的任何監聽套接字。

#### Пример конфигурации｜配置範例

> ```
> http {
>
> http{
>     server {
>
>     伺服器{
>         listen 8000;
>
>         聽 8000；
> 
>         location / {
>
>         地點/{
>             root html;
>
>             根 html；
>         }
>     }
> }
> 
> stream {
>
> 流{
>     server {
>
>     伺服器{
>         listen 12345 ssl;
>
>         監聽 12345 ssl;
> 
>         ssl_certificate     domain.crt;
>
>         ssl_certificate domain.crt;
>         ssl_certificate_key domain.key;
> 
>         pass 127.0.0.1:8000;
>
>         通過127.0.0.1:8000 ；
>     }
> }
> ```

В примере после терминирования SSL в модуле `stream` соединение передаётся в модуль `http`.

在範例中，在模組`stream`中終止SSL後，連接將轉移到模組`http`。

#### Директивы｜指令

|   |   |
| --- | --- |
| Синтаксис:<br>語法： | ``**pass** `*адрес*`;``<br>` `**pass** ` *地址* `;` ` |
| Умолчание:<br>預設值： | — |
| Контекст:<br>上下文： | `stream`, `server` |

Задаёт адрес сервера с передаваемым соединением. Адрес может быть указан в виде IP-адреса и порта:

指定用於傳輸連線的伺服器位址。位址可以指定為IP位址和連接埠：

> ```
> pass 127.0.0.1:12345;
>
> 通過127.0.0.1:12345 ；
> ```

или в виде пути UNIX-сокета:

或作為UNIX套接字路徑：

> ```
> pass unix:/tmp/stream.socket;
>
> 傳遞 unix:/tmp/stream.socket；
> ```

В адресе также можно использовать переменные:

您也可以在地址中使用變數：

> ```
> pass $upstream;
>
> 傳遞上游；
> ```
