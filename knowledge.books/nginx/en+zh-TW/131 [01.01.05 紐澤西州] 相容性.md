## Compatibility｜相容性

This page describes the JavaScript surface provided by njs:

本頁面介紹了 njs 提供的 JavaScript 介面：

-   the njs and nginx objects, built-in modules, and the `Buffer` object, available with both the [QuickJS](<132 [01.01.05 紐澤西州] JavaScript 引擎.md#quickjs_engine>) and [njs](<132 [01.01.05 紐澤西州] JavaScript 引擎.md#njs_engine>) engines;  
    njs 和 nginx 物件、內建模組以及`Buffer`對象，均可與 [QuickJS](<132 [01.01.05 紐澤西州] JavaScript 引擎.md#quickjs_engine>)和 [njs](<132 [01.01.05 紐澤西州] JavaScript 引擎.md#njs_engine>)引擎一起使用；
-   the ECMAScript language features implemented by the [njs](<132 [01.01.05 紐澤西州] JavaScript 引擎.md#njs_engine>) engine.  
    [njs](<132 [01.01.05 紐澤西州] JavaScript 引擎.md#njs_engine>)引擎實現的 ECMAScript 語言特性。

Definitions of njs specific properties and methods not compliant with ECMAScript can be found in [Reference](<137 [01.01.05 紐澤西州] 參考.md>). Definitions of standard ECMAScript objects and methods can be found in the [ECMAScript specification](http://www.ecma-international.org/ecma-262/).

njs 特有的、不符合 ECMAScript 規範的屬性和方法的定義可以在 [參考](<137 [01.01.05 紐澤西州] 參考.md>)中找到。標準 ECMAScript 物件和方法的定義可以在 [ECMAScript 規範](http://www.ecma-international.org/ecma-262/)中找到。

> The ECMAScript language features listed below describe the [njs](<132 [01.01.05 紐澤西州] JavaScript 引擎.md#njs_engine>) engine, which is deprecated since [1.0.0](<129 [01.01.05 紐澤西州] 變化.md#njs1.0.0>).
