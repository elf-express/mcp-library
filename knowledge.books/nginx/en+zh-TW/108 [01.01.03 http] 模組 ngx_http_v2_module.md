The `ngx_http_v2_module` module (1.9.5) provides support for [HTTP/2](https://datatracker.ietf.org/doc/html/rfc7540).

`ngx_http_v2_module`模組 ( 1.9.5 ) 為 [HTTP /2](https://datatracker.ietf.org/doc/html/rfc7540)提供支援。

This module is not built by default, it should be enabled with the `--with-http_v2_module` configuration parameter.

此模組預設未構建，應使用`--with-http_v2_module`配置參數啟用。

#### Known Issues｜已知問題

Before version 1.9.14, buffering of a client request body could not be disabled regardless of [proxy\_request\_buffering](<085 [01.01.03 http] 模組 ngx_http_proxy_module.md#proxy_request_buffering>), [fastcgi\_request\_buffering](<060 [01.01.03 http] 模組 ngx_http_fastcgi_module.md#fastcgi_request_buffering>), [uwsgi\_request\_buffering](<107 [01.01.03 http] 模組 ngx_http_uwsgi_module.md#uwsgi_request_buffering>), and [scgi\_request\_buffering](<091 [01.01.03 http] 模組 ngx_http_scgi_module.md#scgi_request_buffering>) directive values.

之前的版本 1.9.14無論 [proxy\_request\_buffering] 設定如何，都無法停用客戶端請求體的緩衝。(https://nginx.org/en/docs/http/ngx_http_proxy_module.html#proxy_request_buffering)[fastcgi_request_buffering](<060 [01.01.03 http] 模組 ngx_http_fastcgi_module.md#fastcgi_request_buffering>), [uwsgi\_request\_buffering](<107 [01.01.03 http] 模組 ngx_http_uwsgi_module.md#uwsgi_request_buffering>)以及 [scgi\_request\_buffering](<091 [01.01.03 http] 模組 ngx_http_scgi_module.md#scgi_request_buffering>) 指令值。

Before version 1.19.1, the [lingering\_close](<056 [01.01.03 http] 模組 ngx_http_core_module.md#lingering_close>) mechanism was not used to control closing HTTP/2 connections.

在版本1.19.1之前，[lingering\_close](<056 [01.01.03 http] 模組 ngx_http_core_module.md#lingering_close>)機制未用於控制關閉HTTP /2 連接。

#### Example Configuration｜範例配置

> ```
> server {
>
> 伺服器 {
>     listen 443 ssl;
>
>     監聽 443 ssl；
> 
>     http2 on;
>
>     http2 已開啟；
> 
>     ssl_certificate server.crt;
>     ssl_certificate_key server.key;
> }
> ```

Note that accepting HTTP/2 connections over TLS requires the “Application-Layer Protocol Negotiation”（應用層協定協商） (ALPN) TLS extension support, which is available since [OpenSSL](http://www.openssl.org/) version 1.0.2.

請注意，接受透過TLS HTTP /2 連接需要“Application-Layer Protocol Negotiation”（應用層協定協商） ( ALPN (http://www.openssl.org/) TLS 1.0.2起可用。

Also note that if the [ssl\_prefer\_server\_ciphers](<098 [01.01.03 http] 模組 ngx_http_ssl_module.md#ssl_prefer_server_ciphers>) directive is set to the value “`on`”, the [ciphers](<098 [01.01.03 http] 模組 ngx_http_ssl_module.md#ssl_ciphers>) should be configured to comply with [RFC 9113, Appendix A](https://datatracker.ietf.org/doc/html/rfc9113#appendix-A) black list and supported by clients.

另請注意，如果 [ssl\_prefer\_server\_ciphers](<098 [01.01.03 http] 模組 ngx_http_ssl_module.md#ssl_prefer_server_ciphers>)指令設定為值“ `on` ”，則 [ciphers](<098 [01.01.03 http] 模組 ngx_http_ssl_module.md#ssl_ciphers>)應配置為符合 [ RFC 9113，附錄 A (https://datatracker.ietf.org/doc/html/rfc9113#appendix-A)

Sets the maximum number of requests (including [push](#http2_push) requests) that can be served through one HTTP/2 connection, after which the next client request will lead to connection closing and the need of establishing a new connection.

設定一個HTTP /2 連線可以處理的最大請求數（包括 [push](#http2_push)請求），之後下一個客戶端請求將導致連線關閉，需要建立新的連線。

Closing connections periodically is necessary to free per-connection memory allocations. Therefore, using too high maximum number of requests could result in excessive memory usage and not recommended.

定期關閉連線對於釋放每個連線佔用的記憶體至關重要。因此，設定過高的最大請求數可能會導致記憶體使用過量，不建議這樣做。

Pre-emptively sends ([pushes](https://datatracker.ietf.org/doc/html/rfc9113#section-8.4)) a request to the specified `*uri*` along with the response to the original request. Only relative URIs with absolute path will be processed, for example:

預先向指定的`*uri*`發送請求（[推送](https://datatracker.ietf.org/doc/html/rfc9113#section-8.4) ），同時發送對原始請求的回應。僅處理具有絕對路徑的相對 URI，例如：

> ```
> http2_push /static/css/main.css;
> ```

The `*uri*` value can contain variables.

`*uri*`值可以包含變數。

Several `http2_push` directives can be specified on the same configuration level. The `off` parameter cancels the effect of the `http2_push` directives inherited from the previous configuration level.

`ngx_http_v2_module`模組支援以下嵌入式變數：

`$http2`

negotiated protocol identifier: “`h2`” for HTTP/2 over TLS, “`h2c`” for HTTP/2 over cleartext TCP, or an empty string otherwise.

協商協議標識符：「 `h2` 」表示透過HTTP進行TLS /2傳輸，「 `h2c` 」表示透過明文HTTP進行TCP /2，否則為空。
