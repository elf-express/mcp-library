## Модуль ngx\_http\_gunzip\_module｜模組 ngx\_http\_gunzip\_模組

Модуль `ngx_http_gunzip_module` — это фильтр, распаковывающий ответы с “`Content-Encoding: gzip`” для тех клиентов, которые не поддерживают метод сжатия “gzip”. Модуль будет полезен, когда данные желательно хранить сжатыми для экономии места и сокращения затрат на ввод-вывод.

`ngx_http_gunzip_module`模組是一個過濾器，用於對不支援「gzip」壓縮方法的客戶端的回應進行「 `Content-Encoding: gzip` 」解壓縮。當需要壓縮資料以節省空間並降低 I/O 成本時，此模組非常有用。

По умолчанию этот модуль не собирается, его сборку необходимо разрешить с помощью конфигурационного параметра `--with-http_gunzip_module`.

此模組預設未構建，必須使用`--with-http_gunzip_module`配置參數啟用。

#### Пример конфигурации｜配置範例

> ```
> location /storage/ {
>     gunzip on;
>
>     槍拉鍊開啟；
>     ...
> }
> ```

#### Директивы｜指令

<table>
<tr><th>Синтаксис:<br>語法：</th><td><code><strong>gunzip</strong> <code>on<br>開啟</code> | <code>off<br>關閉</code>;</code></td></tr>
<tr><th>Умолчание:<br>預設：</th><td>gunzip off;<br>關閉槍套；</td></tr>
<tr><th>Контекст:<br>上下文：</th><td><code>http</code>, <code>server<br>伺服器</code>, <code>location<br>位置</code></td></tr>

Разрешает или запрещает распаковку ответов, сжатых методом gzip, для тех клиентов, которые его не поддерживают. Если разрешено, то для определения, поддерживает ли клиент gzip, также учитываются следующие директивы: [gzip\_http\_version](<231 [02.01.01 http] 模組 ngx_http_gzip_module.md#gzip_http_version>), [gzip\_proxied](<231 [02.01.01 http] 模組 ngx_http_gzip_module.md#gzip_proxied>) и [gzip\_disable](<231 [02.01.01 http] 模組 ngx_http_gzip_module.md#gzip_disable>). См. также директиву [gzip\_vary](<231 [02.01.01 http] 模組 ngx_http_gzip_module.md#gzip_vary>).

為不支援 gzip 壓縮回應的用戶端啟用或停用解壓縮。如果啟用，也會考慮以下指令來確定客戶端是否支援 gzip：[gzip\_http\_version](<231 [02.01.01 http] 模組 ngx_http_gzip_module.md#gzip_http_version>)、[gzip\_proxied](<231 [02.01.01 http] 模組 ngx_http_gzip_module.md#gzip_proxied>) 和 [gzip\_disable](<231 [02.01.01 http] 模組 ngx_http_gzip_module.md#gzip_disable>)。另請參閱 [gzip\_vary](<231 [02.01.01 http] 模組 ngx_http_gzip_module.md#gzip_vary>) 指令。

<table>
<tr><th>Синтаксис:<br>文法：</th><td><code><strong>gunzip_buffers</strong> <code><i>число<br>數字</i></code> <code><i>размер<br>大小</i></code>;</code></td></tr>
<tr><th>Умолчание:<br>預設值：</th><td>gunzip_buffers 32 4k|16 8k;<br>gunzip_buffers 32 4k|16 8k；</td></tr>
<tr><th>Контекст:<br>上下文：</th><td><code>http</code>, <code>server<br>伺服器</code>, <code>location<br>位置</code></td></tr>
</table>

Задаёт `*число*` и `*размер*` буферов, в которые будет разжиматься ответ. По умолчанию размер одного буфера равен размеру страницы. В зависимости от платформы это или 4K, или 8K.

指定用於解壓縮響應的`*число*`和`*размер*`緩衝區。預設情況下，單一緩衝區的大小等於頁面大小。根據平台的不同，頁面大小可以是 4K 或 8K。
