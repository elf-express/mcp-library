## Модуль ngx\_stream\_realip\_module｜ngx_stream_realip_module 模組

|   |

Модуль `ngx_stream_realip_module` позволяет менять адрес и порт клиента на переданные в заголовке протокола PROXY (1.11.4). Протокол PROXY должен быть предварительно включён при помощи установки параметра [proxy\_protocol](<297 [02.01.04 溪流] ngx_stream_core_module 模組.md#proxy_protocol>) в директиве `listen`.

`ngx_stream_realip_module`模組可讓您將客戶端的位址和連接埠變更為PROXY ( 1.11.4 ) 協定頭中指定的位址和連接埠。必須透過在`listen`指令中設定 [proxy\_protocol](<297 [02.01.04 溪流] ngx_stream_core_module 模組.md#proxy_protocol>)參數來啟用PROXY協定。

По умолчанию этот модуль не собирается, его сборку необходимо разрешить с помощью конфигурационного параметра `--with-stream_realip_module`.

此模組預設未構建，必須使用`--with-stream_realip_module`配置參數啟用。

#### Пример конфигурации｜配置範例

> ```
> listen 12345 proxy_protocol;
>
> 監聽 12345 代理協議；
> 
> set_real_ip_from  192.168.1.0/24;
>
> set_real_ip_from 192.168.1.0/24 ;
> set_real_ip_from  192.168.2.1;
>
> set_real_ip_from 192.168.2.1 ;
> set_real_ip_from  2001:0db8::/32;
>
> set_real_ip_from 2001:0db8::/32 ;
> ```

#### Директивы｜指令

|   |   |
| --- | --- |
| Синтаксис:<br>語法： | ``**set_real_ip_from** `*адрес*` \| `*CIDR*` \| `unix:`;``<br>` `**set_real_ip_from** ` *地址* ` \| ` * CIDR * ` \| ` unix: `;` ` |
| Умолчание:<br>預設值： | — |
| Контекст:<br>背景： | `stream`, `server` |

Задаёт доверенные адреса, которые передают верный адрес для замены. Если указано специальное значение `unix:`, доверенными будут считаться все UNIX-сокеты.

指定能夠傳遞正確替換地址的受信任位址。如果指定特殊值`unix:` ，則所有UNIX套接字都將被信任。

#### Встроенные переменные｜內建變數

`$realip_remote_addr`

хранит исходный адрес клиента

儲存客戶端的原始位址

`$realip_remote_port`

хранит исходный порт клиента

儲存客戶端的來源端口
