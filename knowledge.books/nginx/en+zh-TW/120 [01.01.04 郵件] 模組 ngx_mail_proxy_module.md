Sets the size of the buffer used for proxying. By default, the buffer size is equal to one memory page. Depending on a platform, it is either 4K or 8K.

設定代理所用緩衝區的大小。預設情況下，緩衝區大小等於一個記憶體頁。依平台不同，緩衝區大小可能為 4K 或 8K。

Indicates whether to pass the error message obtained during the authentication on the backend to the client.

指示是否將後端身份驗證期間獲得的錯誤訊息傳遞給客戶端。

Usually, if the authentication in nginx is a success, the backend cannot return an error. If it nevertheless returns an error, it means some internal error has occurred. In such case the backend message can contain information that should not be shown to the client. However, responding with an error for the correct password is a normal behavior for some POP3 servers. For example, CommuniGatePro informs a user about [mailbox overflow](http://www.stalker.com/CommuniGatePro/Alerts.html#Quota) or other events by periodically outputting the [authentication error](http://www.stalker.com/CommuniGatePro/POP.html#Alerts). The directive should be enabled in this case.

通常情況下，如果 nginx 中的身份驗證成功，後端不會回傳錯誤。但如果後端仍然回傳錯誤，則表示發生了某些內部錯誤。在這種情況下，後端訊息可能包含不應向客戶端顯示的資訊。然而，對於某些POP3來說，即使密碼正確也回傳錯誤是正常行為。例如，CommuniGatePro 會定期輸出「驗證錯誤」來通知使用者郵箱(http://www.stalker.com/CommuniGatePro/Alerts.html#Quota)或其他事件。在這種情況下，應該啟用相應(http://www.stalker.com/CommuniGatePro/POP.html#Alerts)指令。

該指令出現在版本1.19.8 。

Enables the [PROXY protocol](http://www.haproxy.org/download/1.8/doc/proxy-protocol.txt) for connections to a backend. The `on` parameter enables version 1 of the PROXY protocol (text format). The `v2` parameter (1.31.4) enables version 2 of the PROXY protocol (binary format).

啟用 [PROXY 協定](http://www.haproxy.org/download/1.8/doc/proxy-protocol.txt) 以連接到後端。 `on` 參數啟用PROXY 協定的版本 1（文字格式）。 `v2` 參數 (1.31.4) 啟用PROXY 協定的版本 2（二進位格式）。

Enables or disables user authentication on the SMTP backend using the `AUTH` command.

使用`AUTH`指令啟用或停用SMTP後端的使用者驗證。

If [XCLIENT](#xclient) is also enabled, then the `XCLIENT` command will not send the `LOGIN` parameter.

如果 [XCLIENT](#xclient)也已啟用，則`XCLIENT`指令不會傳送`LOGIN`參數。

Sets the `*timeout*` between two successive read or write operations on client or proxied server connections. If no data is transmitted within this time, the connection is closed.

設定客戶端或代理伺服器連線上兩次連續讀取或寫入操作之間的`*timeout*` 。如果在該時間內沒有資料傳輸，則連線關閉。

Enables or disables the passing of the [XCLIENT](http://www.postfix.org/XCLIENT_README.html) command with client parameters when connecting to the SMTP backend.

啟用或停用在連接到SMTP後端時傳遞帶有客戶端參數的 [XCLIENT](http://www.postfix.org/XCLIENT_README.html)指令。

With `XCLIENT`, the MTA is able to write client information to the log and apply various limitations based on this data.

借助`XCLIENT` ， MTA能夠將客戶端資訊寫入日誌，並根據這些資料應用各種限制。

If `XCLIENT` is enabled then nginx passes the following commands when connecting to the backend:

如果啟用了`XCLIENT` ，則nginx在連接到後端時會傳遞以下命令：

-   `EHLO` with the [server name](<117 [01.01.04 郵件] 模組 ngx_mail_core_module.md#server_name>)  
    `EHLO`與 [伺服器名稱](<117 [01.01.04 郵件] 模組 ngx_mail_core_module.md#server_name>)
-   `XCLIENT`
-   `EHLO` or `HELO`, as passed by the client  
    `EHLO`或`HELO` ，由客戶端傳遞

If the name [found](<117 [01.01.04 郵件] 模組 ngx_mail_core_module.md#resolver>) by the client IP address points to the same address, it is passed in the `NAME` parameter of the `XCLIENT` command. If the name could not be found, points to a different address, or [resolver](<117 [01.01.04 郵件] 模組 ngx_mail_core_module.md#resolver>) is not specified, the `[UNAVAILABLE]` is passed in the `NAME` parameter. If an error has occurred in the process of resolving, the `[TEMPUNAVAIL]` value is used.

如果客戶端位址 [found](<117 [01.01.04 郵件] 模組 ngx_mail_core_module.md#resolver>)指向相同位址，則將其傳遞給IP指令的`NAME`參數。如果找不到名稱、名稱指向不同的位址，或未指定 [resolver](<117 [01.01.04 郵件] 模組 ngx_mail_core_module.md#resolver>) ，則將`[UNAVAILABLE]`傳遞給`NAME`參數。如果在解析過程中發生錯誤， `[TEMPUNAVAIL]` `XCLIENT` 。

If `XCLIENT` is disabled then nginx passes the `EHLO` command with the [server name](<117 [01.01.04 郵件] 模組 ngx_mail_core_module.md#server_name>) when connecting to the backend if the client has passed `EHLO`, or `HELO` with the server name, otherwise.

如果`XCLIENT`被停用，則當客戶端連接到後端時，nginx 會傳遞`EHLO`命令，其中包含 [伺服器名稱](<117 [01.01.04 郵件] 模組 ngx_mail_core_module.md#server_name>) （如果客戶端已傳遞`EHLO` ，否則會傳遞伺服器`HELO`命令P20⧟命令，其中包含伺服器名稱。
