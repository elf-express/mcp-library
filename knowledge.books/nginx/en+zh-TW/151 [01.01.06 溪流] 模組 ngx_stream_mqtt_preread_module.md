## Module ngx\_stream\_mqtt\_preread\_module｜模組 ngx\_stream\_mqtt\_preread\_module

|   |

The `ngx_stream_mqtt_preread_module` module (1.23.4) allows extracting information from the CONNECT message of the Message Queuing Telemetry Transport protocol (MQTT) versions [3.1.1](https://docs.oasis-open.org/mqtt/mqtt/v3.1.1/mqtt-v3.1.1.html) and [5.0](https://docs.oasis-open.org/mqtt/mqtt/v5.0/mqtt-v5.0.html), for example, a username or a client ID.

`ngx_stream_mqtt_preread_module`模塊 ( 1.23.4 ) 允許從消息CONNECT遙測傳輸協議 ( MQTT ) 版本 [3.1.1](https://docs.oasis-open.org/mqtt/mqtt/v3.1.1/mqtt-v3.1.1.html)和 [5.0](https://docs.oasis-open.org/mqtt/mqtt/v5.0/mqtt-v5.0.html)訊息中提取訊息，例如使用者名稱或客戶端ID 。

> This module is available as part of our [commercial subscription](https://www.f5.com/products/nginx).
>
> 本模組作為我們[商業訂閱](https://www.f5.com/products/nginx)的一部分提供。

#### Example Configuration｜範例配置

> ```
> mqtt_preread on;
>
> mqtt_preread 已開啟；
> return       $mqtt_preread_clientid;
>
> 返回 $mqtt_preread_clientid；
> ```

Enables extracting information from the MQTT CONNECT message at the [preread](<165 [01.01.06 溪流] nginx 如何處理TCPUDP會話.md#preread_phase>) phase.

能夠在 [預讀](<165 [01.01.06 溪流] nginx 如何處理TCPUDP會話.md#preread_phase>)階段從MQTT CONNECT訊息中擷取訊息。

#### Embedded Variables｜嵌入變數

`$mqtt_preread_clientid`

the `clientid` value from the CONNECT message

來自CONNECT訊息的`clientid`值

`$mqtt_preread_username`

the `username` value from the CONNECT message

來自CONNECT訊息的`username`值
