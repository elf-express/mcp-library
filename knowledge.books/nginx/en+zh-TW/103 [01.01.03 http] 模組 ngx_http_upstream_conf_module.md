# Module ngx_http_upstream_conf_module｜模組 ngx_http_upstream_conf_module

> 章節：[en｜在](<000 目錄.md#c-1>) › [docs｜文件](<000 目錄.md#c-2>) › [http](<000 目錄.md#c-5>)

## Module ngx\_http\_upstream\_conf\_module｜模組 ngx\_http\_upstream\_conf\_module

|   |
| --- |
| [Example Configuration](#example)<br>[Directives](#directives)<br>     [upstream\_conf](#upstream_conf)<br>[範例設定](#example)<br> [指令](#directives)<br> [上游設定](#upstream_conf) |

The `ngx_http_upstream_conf_module` module allows configuring upstream server groups on-the-fly via a simple HTTP interface without the need of restarting nginx. The [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#zone>) or [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#zone>) server group must reside in the shared memory.

`ngx_http_upstream_conf_module`模組允許透過簡單的HTTP介面動態配置上游伺服器群組，而無需重新啟動 nginx。 [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#zone>)或 [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#zone>)伺服器群組必須駐留在共享記憶體中。

> This module was available as part of our [commercial subscription](https://www.f5.com/products/nginx) until 1.13.10. It was superseded by the [ngx\_http\_api\_module](<048 [01.01.03 http] 模組 ngx_http_api_module.md>) module in 1.13.3.
>
> 本模組作為我們[商業訂閱](https://www.f5.com/products/nginx)的一部分提供，直至1.13.10 。它在1.13.3中被[ngx\_http\_api\_module](<048 [01.01.03 http] 模組 ngx_http_api_module.md>)模組取代。

#### Example Configuration｜範例配置

> ```
> upstream backend {
>
> 上游後端 {
>     zone upstream_backend 64k;
>
>     區域 upstream_backend 64k；
> 
>     ...
> }
> 
> server {
>
> 伺服器 {
>     location /upstream_conf {
>         upstream_conf;
>
>         上游配置；
>         allow 127.0.0.1;
>
>         允許127.0.0.1 ；
>         deny all;
>
>         全部否認；
>     }
> }
> ```

#### Directives｜指令

|   |   |
| --- | --- |
| Syntax:<br>文法： | `**upstream_conf**;` |
| Default:<br>預設值： | — |
| Context:<br>背景： | `location` |

Turns on the HTTP interface of upstream configuration in the surrounding location. Access to this location should be [limited](<056 [01.01.03 http] 模組 ngx_http_core_module.md#satisfy>).

啟用周圍位置上游配置的HTTP介面。對該位置的存取應[受限](<056 [01.01.03 http] 模組 ngx_http_core_module.md#satisfy>) 。

Configuration commands can be used to:

配置命令可用於：

-   view the group configuration;  
    查看組配置；
-   view, modify, or remove a server;  
    查看、修改或刪除伺服器；
-   add a new server.  
    新增伺服器。

> Since addresses in a group are not required to be unique, specific servers in a group are referenced by their IDs. IDs are assigned automatically and shown when adding a new server or viewing the group configuration.
>
> 由於群組內位址無需唯一，因此群組內的特定伺服器透過其 ID 進行引用。 ID 會自動分配，並在新增伺服器或查看群組配置時顯示。

A configuration command consists of parameters passed as request arguments, for example:

配置命令由作為請求參數傳遞的參數組成，例如：

> ```
> http://127.0.0.1/upstream_conf?upstream=backend
> ```

The following parameters are supported:

支援以下參數：

`stream=`

Selects a [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md>) upstream server group. Without this parameter, selects an [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md>) upstream server group.

選擇 [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md>)上游伺服器群組。如果沒有此參數，則選擇 [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md>)上游伺服器組。

`upstream=``*name*`

Selects a group to work with. This parameter is mandatory.

選擇要合作的群組。此參數為必填項。

`id=``*number*`

Selects a server for viewing, modifying, or removing.

選擇伺服器進行查看、修改或刪除。

`remove=`

Removes a server from the group.

從群組中移除伺服器。

`add=`

Adds a new server to the group.

在群組中新增一台新伺服器。

`backup=`

Required to add a backup server.

需要新增備份伺服器。

> Before version 1.7.2, `backup=` was also required to view, modify, or remove existing backup servers.
>
> 在版本1.7.2, `backup=`之前，還需要先查看、修改或刪除現有的備份伺服器。

`server=``*address*`

Same as the “`address`” parameter of the [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#server>) or [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#server>) upstream server.

與 [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#server>)或 [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#server>)上游伺服器的「 `address` 」參數相同。

When adding a server, it is possible to specify it as a domain name. In this case, changes of the IP addresses that correspond to a domain name will be monitored and automatically applied to the upstream configuration without the need of restarting nginx (1.7.2). This requires the “`resolver`” directive in the [http](<056 [01.01.03 http] 模組 ngx_http_core_module.md#resolver>) or [stream](<142 [01.01.06 溪流] 模組 ngx_stream_core_module.md#resolver>) block. See also the “`resolve`” parameter of the [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#resolve>) or [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#resolve>) upstream server.

新增伺服器時，可以指定為網域名稱。在這種情況下，與網域對應的位址（ IP ）的變更將被監控，並自動套用到上游配置，無需重新啟動 nginx（ 1.7.2 ）。這需要在 [http]（ (https://nginx.org/en/docs/http/ngx_http_core_module.html#resolver) ）或 [stream](<142 [01.01.06 溪流] 模組 ngx_stream_core_module.md#resolver>) ）程式碼區塊中使用「 `resolver` 」指令。另請參閱 [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#resolve>)或 [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#resolve>)上游伺服器的「 `resolve` 」參數。

`service=``*name*`

Same as the “`service`” parameter of the [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#service>) or [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#service>) upstream server (1.9.13).

與 [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#service>)或 [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#service>)上游伺服器 ( 1.9.13 ) 的「 `service` 」參數相同。

`weight=``*number*`

Same as the “`weight`” parameter of the [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#weight>) or [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#weight>) upstream server.

與 [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#weight>)或 [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#weight>)上游伺服器的「 `weight` 」參數相同。

`max_conns=``*number*`

Same as the “`max_conns`” parameter of the [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#max_conns>) or [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#max_conns>) upstream server.

與 [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#max_conns>)或 [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#max_conns>)上游伺服器的「 `max_conns` 」參數相同。

`max_fails=``*number*`

Same as the “`max_fails`” parameter of the [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#max_fails>) or [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#max_fails>) upstream server.

與 [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#max_fails>)或 [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#max_fails>)上游伺服器的「 `max_fails` 」參數相同。

`fail_timeout=``*time*`

Same as the “`fail_timeout`” parameter of the [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#fail_timeout>) or [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#fail_timeout>) upstream server.

與 [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#fail_timeout>)或 [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#fail_timeout>)上游伺服器的「 `fail_timeout` 」參數相同。

`slow_start=``*time*`

Same as the “`slow_start`” parameter of the [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#slow_start>) or [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#slow_start>) upstream server.

與上游伺服器的 [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#slow_start>)或 [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#slow_start>)的「 `slow_start` 」參數相同。

`down=`

Same as the “`down`” parameter of the [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#down>) or [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#down>) upstream server.

與 [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#down>)或 [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#down>)上游伺服器的「 `down` 」參數相同。

`drain=`

Puts the [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md>) upstream server into the “draining” mode (1.7.5). In this mode, only requests [bound](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#sticky>) to the server will be proxied to it.

將(https://nginx.org/en/docs/http/ngx_http_upstream_module.html)伺服器置於「排空」模式（ 1.7.5 ）。在此模式下，只有發送到該伺服器(https://nginx.org/en/docs/http/ngx_http_upstream_module.html#sticky)請求才會被代理到該伺服器。

`up=`

The opposite of the “`down`” parameter of the [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#down>) or [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#down>) upstream server.

與 [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#down>)或 [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#down>)上游伺服器的「 `down` 」參數相反。

`route=``*string*`

Same as the “`route`” parameter of the [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#route>) upstream server.

與 [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#route>)上游伺服器的「 `route` 」參數相同。

The first three parameters select an object. This can be either the whole http or stream upstream server group, or a specific server. Without other parameters, the configuration of the selected group or server is shown.

前三個參數用於選擇一個物件。這可以是整個 HTTP 或串流上游伺服器群組，也可以是特定的伺服器。如果沒有其他參數，則會顯示所選群組或伺服器的配置。

For example, to view the configuration of the whole group, send:

例如，要查看整個群組的配置，請傳送：

> ```
> http://127.0.0.1/upstream_conf?upstream=backend
> ```

To view the configuration of a specific server, also specify its ID:

若要查看特定伺服器的配置，請同時指定其ID ：

> ```
> http://127.0.0.1/upstream_conf?upstream=backend&id=42
> ```

To add a new server, specify its address in the “`server=`” parameter. Without other parameters specified, a server will be added with other parameters set to their default values (see the [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#server>) or [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#server>) “`server`” directive).

若要新增伺服器，請在「 `server=` 」參數中指定其位址。如果沒有指定其他參數，則新增伺服器時，其他參數將設定為其預設值（請參閱[http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#server>)或[stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#server>) “ `server` ”指令）。

For example, to add a new primary server, send:

例如，要新增的主伺服器，請傳送：

> ```
> http://127.0.0.1/upstream_conf?add=&upstream=backend&server=127.0.0.1:8080
> ```

To add a new backup server, send:

若要新增新的備份伺服器，請傳送：

> ```
> http://127.0.0.1/upstream_conf?add=&upstream=backend&backup=&server=127.0.0.1:8080
> ```

To add a new primary server, set its parameters to non-default values and mark it as “`down`”, send:

若要新增的主伺服器，請將其參數設為非預設值並將其標記為“ `down` ”，然後傳送：

> ```
> http://127.0.0.1/upstream_conf?add=&upstream=backend&server=127.0.0.1:8080&weight=2&down=
> ```

To remove a server, specify its ID:

若要刪除伺服器，請指定其ID :

> ```
> http://127.0.0.1/upstream_conf?remove=&upstream=backend&id=42
> ```

To mark an existing server as “`down`”, send:

若要將現有伺服器標記為“ `down` ”，請傳送：

> ```
> http://127.0.0.1/upstream_conf?upstream=backend&id=42&down=
> ```

To modify the address of an existing server, send:

若要修改現有伺服器的位址，請傳送：

> ```
> http://127.0.0.1/upstream_conf?upstream=backend&id=42&server=192.0.2.3:8123
> ```

To modify other parameters of an existing server, send:

若要修改現有伺服器的其他參數，請傳送：

> ```
> http://127.0.0.1/upstream_conf?upstream=backend&id=42&max_fails=3&weight=4
> ```

The above examples are for an [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md>) upstream server group. Similar examples for a [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md>) upstream server group require the “`stream=`” parameter.

以上範例適用於 [http](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md>)上游伺服器群組。類似的 [stream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md>)上游伺服器群組範例需要「 `stream=` 」參數。
