Модуль `ngx_http_autoindex_module` обслуживает запросы, оканчивающиеся слэшом (‘`/`’), и выдаёт листинг каталога. Обычно запрос попадает к модулю `ngx_http_autoindex_module`, когда модуль [ngx\_http\_index\_module](<236 [02.01.01 http] 模組 ngx_http_index_module.md>) не нашёл индексный файл.

`ngx_http_autoindex_module`模組處理以斜線 (' `/` ') 結尾的請求，並產生目錄清單。當 [ngx\_http\_index\_module](<236 [02.01.01 http] 模組 ngx_http_index_module.md>)模組找不到索引檔時，請求通常會傳送到`ngx_http_autoindex_module`模組。

#### Пример конфигурации｜配置範例

> ```
> location / {
>
> 地點 / {
>     autoindex on;
>
>     自動索引已開啟；
> }
> ```

對於 [格式](#autoindex_format) HTML ，確定目錄清單中的檔案大小是精確顯示還是四捨五入到千位元組、兆位元組和千兆位元組。

Эта директива появилась в версии 1.7.9.

該指令是在版本1.7.9中引入的。

Задаёт формат вывода листинга каталога.

指定目錄列表輸出的格式。

При использовании формата JSONP имя callback-функции задаётся в аргументе запроса `callback`. Если аргумент отсутствует или имеет пустое значение, то используется формат JSON.

使用JSONP格式時，回呼函數名稱在`callback`請求參數中指定。如果該參數缺失或為空，則使用JSON格式。

Вывод в формате XML может быть преобразован при помощи модуля [ngx\_http\_xslt\_module](<271 [02.01.01 http] 模組 ngx_http_xslt_module.md>).

XML格式的輸出可以使用 [ngx\_http\_xslt\_module](<271 [02.01.01 http] 模組 ngx_http_xslt_module.md>)模組進行轉換。
