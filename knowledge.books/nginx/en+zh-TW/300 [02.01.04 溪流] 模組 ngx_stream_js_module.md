Модуль `ngx_stream_js_module` позволяет задавать обработчики сессий и переменных на JavaScript с помощью [njs](<290 [02.01.03 紐澤西州] 模組 nginx JavaScript.md>).

`ngx_stream_js_module`模組可讓您使用 [njs](<290 [02.01.03 紐澤西州] 模組 nginx JavaScript.md>)在 JavaScript 中定義會話和變數處理程序。

Инструкция по сборке и установке доступны [здесь](<291 [02.01.03 紐澤西州] 下載和安裝.md>).

組裝和安裝說明可在此處取得(https://nginx.org/ru/docs/njs/install.html) 。

В этой фазе может происходить инициализация, также при помощи метода [`s.on()`](https://nginx.org/ru/docs/njs/reference.html#s_on) может регистрироваться вызов для каждого входящего блока данных пока не будет вызван один из методов: [`s.done()`](https://nginx.org/ru/docs/njs/reference.html#s_done) [`s.decline()`](https://nginx.org/ru/docs/njs/reference.html#s_decline), [`s.allow()`](https://nginx.org/ru/docs/njs/reference.html#s_allow). При вызове любого из этих методов обработка сессии переходит на [следующую фазу](<317 [02.01.04 溪流] Nginx 如何處理TCPUDP會話.md>) и все текущие вызовы [`s.on()`](https://nginx.org/ru/docs/njs/reference.html#s_on) сбрасываются.

在此階段可能會進行初始化，並且可以使用 [`s.on()`](https://nginx.org/ru/docs/njs/reference.html#s_on)方法為`s.allow()`傳入的資料塊註冊一個調用，直到調用以下方法之一：[ `s.done()` (https://nginx.org/ru/docs/njs/reference.html#s_decline) (https://nginx.org/ru/docs/njs/reference.html#s_done) [ `s.decline()` (https://nginx.org/ru/docs/njs/reference.html#s_allow) 。當呼叫這些方法中的任何一個時，會話處理將進入 [下一階段](<317 [02.01.04 溪流] Nginx 如何處理TCPUDP會話.md>) ，並且所有目前呼叫 [`s.on()`](https://nginx.org/ru/docs/njs/reference.html#s_on)將被重設。

在此階段可能會進行初始化，並且可以使用 [`s.on()`](https://nginx.org/ru/docs/njs/reference.html#s_on)方法為`s.allow()`傳入的資料塊註冊一個調用，直到調用以下方法之一：[`s.done()`](https://nginx.org/ru/docs/njs/reference.html#s_done) 、[ `s.decline()` (https://nginx.org/ru/docs/njs/reference.html#s_decline) (https://nginx.org/ru/docs/njs/reference.html#s_allow) 。當呼叫這些方法中的任何一個時，會話處理將進入 [下一階段](<317 [02.01.04 溪流] Nginx 如何處理TCPUDP會話.md>) ，並且所有目前呼叫 [`s.on()`](https://nginx.org/ru/docs/njs/reference.html#s_on)將被重設。

每個 njs 流程處理程序接收一個參數，即 [物件](https://nginx.org/ru/docs/njs/reference.html#stream)流會話。
