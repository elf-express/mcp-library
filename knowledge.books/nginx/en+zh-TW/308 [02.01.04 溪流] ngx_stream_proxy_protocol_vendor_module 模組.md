# Модуль ngx_stream_proxy_protocol_vendor_module｜ngx_stream_proxy_protocol_vendor_module 模組

## Модуль ngx\_stream\_proxy\_protocol\_vendor\_module｜ngx_stream_proxy_protocol_vendor_module 模組

|   |
| --- |
| [Пример конфигурации](#example)<br>[Встроенные переменные](#variables)<br>[設定範例](#example)<br> [內建變數](#variables) |

Модуль `ngx_stream_proxy_protocol_vendor_module` (1.23.3) позволяет получать дополнительную информацию о соединении из облачных платформ при помощи TLV, полученных из заголовка [протокола PROXY](http://www.haproxy.org/download/1.8/doc/proxy-protocol.txt).

`ngx_stream_proxy_protocol_vendor_module` (1.23.3) 模組可讓您使用從[協定PROXY](http://www.haproxy.org/download/1.8/doc/proxy-protocol.txt)標頭所取得的TLV從雲端平台取得額外的連線資訊。

Поддерживаемые облачные платформы:

支援的雲端平台：

-   Amazon Web Services  
    亞馬遜網路服務
-   Google Cloud Platform
-   Microsoft Azure

Протокол PROXY должен быть предварительно включён при помощи установки параметра `proxy_protocol` в директиве [listen](<297 [02.01.04 溪流] ngx_stream_core_module 模組.md#listen>).

必須先在 [listen](<297 [02.01.04 溪流] ngx_stream_core_module 模組.md#listen>)指令中設定`proxy_protocol`參數來啟用PROXY協定。

> Модуль доступен как часть [коммерческой подписки](https://www.f5.com/products/nginx)
>
> 此模組包含在[商業訂閱](https://www.f5.com/products/nginx)中

#### Пример конфигурации｜配置範例

> ```
> server {
>
> 伺服器{
>     listen 12345 proxy_protocol;
>
>     監聽 12345 代理協議；
>     return $proxy_protocol_tlv_gcp_conn_id;
>
>     返回 $proxy_protocol_tlv_gcp_conn_id;
> }
> ```

#### Встроенные переменные｜內建變數

`$proxy_protocol_tlv_aws_vpce_id`

значение TLV, полученное из заголовка протокола PROXY, содержащее [ID конечной точки VPC AWS](https://docs.aws.amazon.com/elasticloadbalancing/latest/network/load-balancer-target-groups.html#proxy-protocol)

從協議頭PROXY取得的值TLV包含 [ID端點VPC AWS](https://docs.aws.amazon.com/elasticloadbalancing/latest/network/load-balancer-target-groups.html#proxy-protocol)

`$proxy_protocol_tlv_azure_pel_id`

значение TLV, полученное из заголовка протокола PROXY, содержащее [LinkID частной конечной точки Azure](https://learn.microsoft.com/en-us/azure/private-link/private-link-service-overview#getting-connection-information-using-tcp-proxy-v2)

TLV值源自PROXY協定頭，其中包含 [Azure 專用終端點的 LinkID](https://learn.microsoft.com/en-us/azure/private-link/private-link-service-overview#getting-connection-information-using-tcp-proxy-v2)

`$proxy_protocol_tlv_gcp_conn_id`

значение TLV, полученное из заголовка протокола PROXY, содержащее [ID соединения Google Cloud PSC](https://cloud.google.com/vpc/docs/configure-private-service-connect-producer#proxy-protocol)

從協議頭PROXY取得的值TLV包含 [ID Google Cloud 連接PSC](https://cloud.google.com/vpc/docs/configure-private-service-connect-producer#proxy-protocol)
