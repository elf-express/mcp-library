The `ngx_http_fastcgi_module` module allows passing requests to a FastCGI server.

`ngx_http_fastcgi_module`模組允許向 FastCGI 伺服器傳遞請求。

#### Example Configuration｜範例配置

> ```
> location / {
>
> 地點/{
>     fastcgi_pass  localhost:9000;
>
>     fastcgi_pass 本機：9000；
>     fastcgi_index index.php;
> 
>     fastcgi_param SCRIPT_FILENAME /home/www/scripts/php$fastcgi_script_name;
>     fastcgi_param QUERY_STRING    $query_string;
>
>     fastcgi_param QUERY_STRING $query_string;
>     fastcgi_param REQUEST_METHOD  $request_method;
>
>     fastcgi_param REQUEST_METHOD $request_method;
>     fastcgi_param CONTENT_TYPE    $content_type;
>
>     fastcgi_param CONTENT_TYPE $content_type;
>     fastcgi_param CONTENT_LENGTH  $content_length;
>
>     fastcgi_param CONTENT_LENGTH $content_length;
> }
> ```

Defines conditions under which access to a FastCGI server is allowed or [denied](#denied). If all string parameters are not empty and not equal to “0” then the access is allowed. The conditions are evaluated each time before a connection to a FastCGI server is established. Parameter values can contain variables:

定義允許或拒絕存取 FastCGI 伺服器的條件(https://nginx.org/en/docs/http/ngx_http_fastcgi_module.html#denied) 。如果所有字串參數均不為空且不等於“0”，則允許存取。每次建立與 FastCGI 伺服器的連線之前都會評估這些條件。參數值可以包含變數：

> ```
> geo $upstream_last_addr $allow {
>     volatile;
>
>     易揮發的;
>     10.10.0.0/24        1;
> }
> 
> server {
>
> 伺服器{
>     listen 127.0.0.1:8080;
>
>     聽127.0.0.1:8080 ;
> 
>     location / {
>
>     地點/{
>         fastcgi_pass           localhost:9000;
>
>         fastcgi_pass localhost:9000;
>         fastcgi_allow_upstream $allow;
>         ...
>     }
> }
> ```

Makes outgoing connections to a FastCGI server originate from the specified local IP address with an optional port (1.11.2). Parameter value can contain variables (1.3.12). The special value `off` (1.3.12) cancels the effect of the `fastcgi_bind` directive inherited from the previous configuration level, which allows the system to auto-assign the local IP address and port.

使發送至 FastCGI 伺服器的出站連線源自指定的本機位址IP ，並可選擇指定連接埠 ( 1.11.2 )。參數值可以包含變數 ( 1.3.12 )。特殊值`off` ( 1.3.12 ) 會取消從上一配置等級繼承的`fastcgi_bind`指令的效果，該指令允許系統自動分配本地位址和連接埠IP )。

The `transparent` parameter (1.11.0) allows outgoing connections to a FastCGI server originate from a non-local IP address, for example, from a real IP address of a client:

`transparent`參數 ( 1.11.0 ) 允許從非本地IP位址（例如，用戶端的真實IP位址）發出到 FastCGI 伺服器的出站連接：

> ```
> fastcgi_bind $remote_addr transparent;
> ```

In order for this parameter to work, it is usually necessary to run nginx worker processes with the [superuser](<125 [01.01 文件] 核心功能.md#user>) privileges. On Linux it is not required (1.13.8) as if the `transparent` parameter is specified, worker processes inherit the `CAP_NET_RAW` capability from the master process. It is also necessary to configure kernel routing table to intercept network traffic from the FastCGI server.

為了使此參數生效，通常需要以 [superuser](<125 [01.01 文件] 核心功能.md#user>)權限執行 nginx 工作進程。在 Linux 系統上則無需此權限 ( 1.13.8 )，因為如果指定了`transparent`參數，工作進程會從主進程繼承`CAP_NET_RAW`權限。此外，還需要配置內核路由表以攔截來自 FastCGI 伺服器的網路流量。

Sets the `*size*` of the buffer used for reading the first part of the response received from the FastCGI server. This part usually contains a small response header; if it exceeds the buffer size, the response is considered [invalid](#invalid_header). By default, the buffer size is equal to one memory page. This is either 4K or 8K, depending on a platform. It can be made smaller, however.

設定用於讀取從 FastCGI 伺服器收到的回應第一部分的緩衝區大小`*size*` 。這部分通常包含一個較小的響應頭；如果響應頭大小超過緩衝區大小，則該響應被視為無效（ (https://nginx.org/en/docs/http/ngx_http_fastcgi_module.html#invalid_header) ）。預設情況下，緩衝區大小等於一個記憶體頁。根據平台的不同，該大小為 4K 或 8K。不過，緩衝區大小可以減少。

This directive appeared in version 1.5.6.

該指令出現在版本1.5.6 。

Enables or disables buffering of responses from the FastCGI server.

啟用或停用 FastCGI 伺服器回應的緩衝。

When buffering is enabled, nginx receives a response from the FastCGI server as soon as possible, saving it into the buffers set by the [fastcgi\_buffer\_size](#fastcgi_buffer_size) and [fastcgi\_buffers](#fastcgi_buffers) directives. If the whole response does not fit into memory, a part of it can be saved to a [temporary file](#fastcgi_temp_path) on the disk. Writing to temporary files is controlled by the [fastcgi\_max\_temp\_file\_size](#fastcgi_max_temp_file_size) and [fastcgi\_temp\_file\_write\_size](#fastcgi_temp_file_write_size) directives.

啟用緩衝後，nginx 會盡快從 FastCGI 伺服器接收回應，並將其儲存至由 `[fastcgi\_buffer\_size](#fastcgi_buffer_size)和 `[fastcgi\_buffers](#fastcgi_buffers)指令設定的緩衝區中。如果整個回應無法放入內存，則可以將其一部分儲存到磁碟上的暫存檔案 `[temporary file](#fastcgi_temp_path)中。寫入暫存檔案的動作由 `[fastcgi\_max\_temp\_file\_size](#fastcgi_max_temp_file_size)和 `[fastcgi\_temp\_file\_write\_size](#fastcgi_temp_file_write_size)指令控制。

When buffering is disabled, the response is passed to a client synchronously, immediately as it is received. nginx will not try to read the whole response from the FastCGI server. The maximum size of the data that nginx can receive from the server at a time is set by the [fastcgi\_buffer\_size](#fastcgi_buffer_size) directive.

停用緩衝後，回應會同步地立即傳遞給客戶端。 nginx 不會嘗試從 FastCGI 伺服器讀取整個回應。 nginx 一次可以從伺服器接收的最大資料大小由 [fastcgi\_buffer\_size](#fastcgi_buffer_size)指令設定。

Buffering can also be enabled or disabled by passing “`yes`” or “`no`” in the “X-Accel-Buffering” response header field. This capability can be disabled using the [fastcgi\_ignore\_headers](#fastcgi_ignore_headers) directive.

也可以透過在“X-Accel-Buffering”響應頭字段中傳遞「 `yes` 」或「 `no` 」來啟用或停用緩衝。可使用 [fastcgi\_ignore\_headers](#fastcgi_ignore_headers)指令停用此功能。

Sets the `*number*` and `*size*` of the buffers used for reading a response from the FastCGI server, for a single connection. By default, the buffer size is equal to one memory page. This is either 4K or 8K, depending on a platform.

設定用於從 FastCGI 伺服器讀取回應的緩衝區`*number*`和`*size*` ，適用於單一連線。預設情況下，緩衝區大小等於一個記憶體頁。根據平台不同，該值可以是 4K 或 8K。

When [buffering](#fastcgi_buffering) of responses from the FastCGI server is enabled, limits the total `*size*` of buffers that can be busy sending a response to the client while the response is not yet fully read. In the meantime, the rest of the buffers can be used for reading the response and, if needed, buffering part of the response to a temporary file. By default, `*size*` is limited by the size of two buffers set by the [fastcgi\_buffer\_size](#fastcgi_buffer_size) and [fastcgi\_buffers](#fastcgi_buffers) directives.

啟用 FastCGI 伺服器回應的 [buffering](#fastcgi_buffering)功能後，會限制用於向客戶端發送回應的緩衝區總數`*size*` ，直到回應完全讀取完畢。在此期間，其餘緩衝區可用於讀取回應，並在需要時將部分回應緩衝到暫存檔案。預設情況下， `*size*`受限於 [fastcgi\_buffer\_size](#fastcgi_buffer_size)和 [fastcgi\_buffers](#fastcgi_buffers)指令設定的兩個緩衝區的大小。

When enabled, only one request at a time will be allowed to populate a new cache element identified according to the [fastcgi\_cache\_key](#fastcgi_cache_key) directive by passing a request to a FastCGI server. Other requests of the same cache element will either wait for a response to appear in the cache or the cache lock for this element to be released, up to the time set by the [fastcgi\_cache\_lock\_timeout](#fastcgi_cache_lock_timeout) directive.

啟用此功能後，每次只允許一個請求透過向 FastCGI 伺服器傳送請求來填入根據 [fastcgi\_cache\_key](#fastcgi_cache_key)指令標識的新快取元素。對相同快取元素的其他請求將等待快取中出現回應或該元素的快取鎖定被釋放，直到 [fastcgi\_cache\_lock\_timeout](#fastcgi_cache_lock_timeout)指令設定的時間結束。

#### Parameters Passed to a FastCGI Server｜傳遞給 FastCGI 伺服器的參數

HTTP request header fields are passed to a FastCGI server as parameters. In applications and scripts running as FastCGI servers, these parameters are usually made available as environment variables. For example, the “User-Agent”（使用者代理） header field is passed as the `HTTP_USER_AGENT` parameter. In addition to HTTP request header fields, it is possible to pass arbitrary parameters using the [fastcgi\_param](#fastcgi_param) directive.

HTTP請求頭字段作為參數傳遞給 FastCGI 伺服器。在作為 FastCGI 伺服器運行的應用程式和腳本中，這些參數通常以環境變數的形式提供。例如， “User-Agent”（使用者代理）請求頭字段作為`HTTP_USER_AGENT`參數傳遞。除了HTTP請求頭字段之外，還可以使用 [fastcgi\_param](#fastcgi_param)指令傳遞任意參數。

#### Embedded Variables｜嵌入變數

The `ngx_http_fastcgi_module` module supports embedded variables that can be used to set parameters using the [fastcgi\_param](#fastcgi_param) directive:

`ngx_http_fastcgi_module`模組支援嵌入式變量，可以使用 [fastcgi\_param](#fastcgi_param)指令設定參數：

`$fastcgi_script_name`

request URI or, if a URI ends with a slash, request URI with an index file name configured by the [fastcgi\_index](#fastcgi_index) directive appended to it. This variable can be used to set the `SCRIPT_FILENAME` and `PATH_TRANSLATED` parameters that determine the script name in PHP. For example, for the “`/info/`” request with the following directives

請求URI ，或者，如果URI以斜槓結尾，則請求URI ，並在其後附加由 [fastcgi\_index](#fastcgi_index)指令配置的索引檔名。此變數可用於設定`SCRIPT_FILENAME`和`PATH_TRANSLATED`參數，這些參數決定了PHP中的腳本名稱。例如，對於具有以下指令的「 `/info/` 」請求：

> ```
> fastcgi_index index.php;
> fastcgi_param SCRIPT_FILENAME /home/www/scripts/php$fastcgi_script_name;
> ```

the `SCRIPT_FILENAME` parameter will be equal to “`/home/www/scripts/php/info/index.php`”.

`SCRIPT_FILENAME`參數將等於「 `/home/www/scripts/php/info/index.php` 」。

When using the [fastcgi\_split\_path\_info](#fastcgi_split_path_info) directive, the `$fastcgi_script_name` variable equals the value of the first capture set by the directive.
