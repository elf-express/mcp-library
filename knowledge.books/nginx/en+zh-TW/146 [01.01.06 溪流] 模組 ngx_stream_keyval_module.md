## Module ngx\_stream\_keyval\_module｜模組 ngx\_stream\_keyval\_module

|   |

The `ngx_stream_keyval_module` module (1.13.7) creates variables with values taken from key-value pairs managed by the [API](<048 [01.01.03 http] 模組 ngx_http_api_module.md#stream_keyvals_>) or a variable that can also be set with [njs](https://github.com/nginx/njs-examples/).

`ngx_stream_keyval_module`模組 ( 1.13.7 ) 建立變數，其值取自 [API](<048 [01.01.03 http] 模組 ngx_http_api_module.md#stream_keyvals_>)管理的鍵值對，或也可使用 [njs](https://github.com/nginx/njs-examples/)設定的變數。

> This module is available as part of our [commercial subscription](https://www.f5.com/products/nginx).
>
> 本模組作為我們[商業訂閱](https://www.f5.com/products/nginx)的一部分提供。

#### Directives｜指令

|   |   |
| --- | --- |
| Syntax:<br>語法： | ``**keyval** `*key*` `*$variable*` `zone`=`*name*`;``<br>` `**keyval** ` *鍵* ` ` *$變數* ` `區域`=` *名稱* `;` ` |
| Default:<br>預設值： | — |
| Context:<br>背景： | `stream` |

Creates a new `*$variable*` whose value is looked up by the `*key*` in the key-value database. Matching rules are defined by the [`type`](#keyval_type) parameter of the [`keyval_zone`](#keyval_zone) directive. The database is stored in a shared memory zone specified by the `zone` parameter.

建立一個新的`*$variable*`其值由`*key*`在鍵值資料庫中尋找。匹配規則由 [`type`](#keyval_type)指令的 [`keyval_zone`](#keyval_zone)參數定義。資料庫儲存在由`zone`參數指定的共享記憶體區域。

|   |   |
| --- | --- |
| Syntax:<br>語法： | ``**keyval_zone** `zone`=`*name*`:`*size*` [`state`=`*file*`] [`timeout`=`*time*`] [`type`=`string`\|`ip`\|`prefix`] [`sync`];``<br>` `**keyval_zone** `區域`=` *名稱* `:` *大小* ` [`狀態`=` *檔案* `] [`超時`=` *時間 * `] [`類型`=`字串`\|` IP 位址`\|`前綴`] [`同步`];` ` |
| Default:<br>預設值： | — |
| Context:<br>背景： | `stream` |

Sets the `*name*` and `*size*` of the shared memory zone that keeps the key-value database. Key-value pairs are managed by the [API](<048 [01.01.03 http] 模組 ngx_http_api_module.md#stream_keyvals_>).

設定用於保存鍵值資料庫的共享記憶體區域的`*name*`和`*size*` 。鍵值對由 [API](<048 [01.01.03 http] 模組 ngx_http_api_module.md#stream_keyvals_>)管理。

The optional `state` parameter specifies a `*file*` that keeps the current state of the key-value database in the JSON format and makes it persistent across nginx restarts. Changing the file content directly should be avoided.

可選參數`state`指定一個`*file*` ，該參數以JSON格式儲存鍵值資料庫的目前狀態，並使其在 nginx 重新啟動後仍然有效。應避免直接更改文件內容。

Examples:

例如：

> ```
> keyval_zone zone=one:32k state=/var/lib/nginx/state/one.keyval; # path for Linux
>
> keyval_zone zone=one:32k state=/var/lib/nginx/state/one.keyval; # Linux 路徑
> keyval_zone zone=one:32k state=/var/db/nginx/state/one.keyval;  # path for FreeBSD
>
> keyval_zone zone=one:32k state=/var/db/nginx/state/one.keyval; # FreeBSD 的路徑
> ```

The optional `timeout` parameter (1.15.0) sets the time after which key-value pairs are removed from the zone.

可選參數`timeout` ( 1.15.0 ) 設定鍵值對從區域移除的時間。

The optional `type` parameter (1.17.1) activates an extra index optimized for matching the key of a certain type and defines matching rules when evaluating a [keyval](#keyval) `$variable`.

可選的`type`參數 ( 1.17.1 ) 啟動一個額外的索引，該索引針對匹配特定類型的鍵進行了最佳化，並在評估 [keyval](#keyval) `$variable`時定義了匹配規則。

> The index is stored in the same shared memory zone and thus requires additional storage.
>
> 索引儲存在同一個共享記憶體區域中，因此需要額外的儲存空間。

`type=string`

default, no index is enabled; variable lookup is performed using exact match of the record key and a search key

預設情況下，未啟用索引；變數尋找使用記錄鍵和搜尋鍵的精確匹配。

`type=ip`

the search key is the textual representation of IPv4 or IPv6 address or CIDR range; to match a record key, the search key must belong to a subnet specified by a record key or exactly match an IP address

搜尋鍵是 IPv4 或 IPv6 位址或CIDR位址範圍的文字表示；若要符合記錄鍵，搜尋鍵必須屬於記錄鍵指定的子網，或與IP位址完全相符。

`type=prefix`

variable lookup is performed using prefix match of a record key and a search key (1.17.5); to match a record key, the record key must be a prefix of the search key

變數尋找使用記錄鍵和搜尋鍵的前綴匹配（ 1.17.5 ）；要匹配記錄鍵，記錄鍵必須是搜尋鍵的前綴。

The optional `sync` parameter (1.15.0) enables [synchronization](<164 [01.01.06 溪流] 模組 ngx_stream_zone_sync_module.md#zone_sync>) of the shared memory zone. The synchronization requires the `timeout` parameter to be set.

可選參數`sync` （ 1.15.0 ）啟用共享記憶體區域的[同步](<164 [01.01.06 溪流] 模組 ngx_stream_zone_sync_module.md#zone_sync>) 。同步需要設定參數`timeout` 。

> If the synchronization is enabled, removal of key-value pairs (no matter [one](<048 [01.01.03 http] 模組 ngx_http_api_module.md#patchStreamKeyvalZoneKeyValue>) or [all](<048 [01.01.03 http] 模組 ngx_http_api_module.md#deleteStreamKeyvalZoneData>)) will be performed only on a target cluster node. The same key-value pairs on other cluster nodes will be removed upon `timeout`.
>
> 如果啟用同步，則鍵值對的刪除（無論是[一個](<048 [01.01.03 http] 模組 ngx_http_api_module.md#patchStreamKeyvalZoneKeyValue>)或[所有](<048 [01.01.03 http] 模組 ngx_http_api_module.md#deleteStreamKeyvalZoneData>) ）僅在目標叢集節點上執行。其他叢集節點上的相同鍵值對將在`timeout`時刪除。
