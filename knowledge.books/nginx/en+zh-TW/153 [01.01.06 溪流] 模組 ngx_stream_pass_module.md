# Module ngx_stream_pass_module｜模組 ngx_stream_pass_module

> 章節：[en｜在](<000 目錄.md#c-1>) › [docs｜文件](<000 目錄.md#c-2>) › [stream｜溪流](<000 目錄.md#c-8>)

## Module ngx\_stream\_pass\_module｜模組 ngx_stream_pass_module

|   |
| --- |
| [Example Configuration](#example)<br>[Directives](#directives)<br>     [pass](#pass)<br>[範例設定](#example)<br> [指令](#directives)<br> [通行](#pass) |

The `ngx_stream_pass_module` module (1.25.5) allows passing the accepted connection directly to any configured listening socket in `http`, `stream`, `mail`, and other similar modules.

`ngx_stream_pass_module`模組（ 1.25.5 ）允許將已接受的連接直接傳遞給`http`, `stream`, `mail`中任何已配置的監聽套接字，以及其他類似的模組。

#### Example Configuration｜範例配置

> ```
> http {
>     server {
>
>     伺服器 {
>         listen 8000;
>
>         聽 8000；
> 
>         location / {
>
>         地點 / {
>             root html;
>
>             根 html；
>         }
>     }
> }
> 
> stream {
>
> 溪流 {
>     server {
>
>     伺服器 {
>         listen 12345 ssl;
>
>         監聽 12345 ssl;
> 
>         ssl_certificate     domain.crt;
>
>         ssl_certificate domain.crt;
>         ssl_certificate_key domain.key;
> 
>         pass 127.0.0.1:8000;
>
>         通過127.0.0.1:8000 ；
>     }
> }
> ```

In the example, after terminating SSL/TLS in the `stream` module the connection is passed to the `http` module.

在該範例中，在`stream`模組中終止SSL/TLS後，連接將傳遞給`http`模組。

#### Directives｜指令

|   |   |
| --- | --- |
| Syntax:<br>語法： | ``**pass** `*address*`;``<br>` `**pass** ` *地址* `;` ` |
| Default:<br>預設值： | — |
| Context:<br>背景： | `server` |

Sets server address to pass client connection to. The address can be specified as an IP address and a port:

設定客戶端連線要轉送到的伺服器位址。該位址可以指定為IP位址和連接埠：

> ```
> pass 127.0.0.1:12345;
>
> 通過127.0.0.1:12345 ；
> ```

or as a UNIX-domain socket path:

或作為UNIX域套接字路徑：

> ```
> pass unix:/tmp/stream.socket;
>
> 傳遞 unix:/tmp/stream.socket；
> ```

The address can also be specified using variables:

也可以使用變數指定位址：

> ```
> pass $upstream;
>
> 傳遞上游；
> ```
