# Модуль ngx_http_mirror_module｜ngx_http_mirror_module 模組

## Модуль ngx\_http\_mirror\_module｜ngx_http_mirror_module 模組

|   |
| --- |
| [Пример конфигурации](#example)<br>[Директивы](#directives)<br>     [mirror](#mirror)<br>     [mirror\_request\_body](#mirror_request_body)<br>[設定範例](#example)<br> [指令](#directives)<br> [鏡像](#mirror)<br> [鏡像請求正文](#mirror_request_body) |

Модуль `ngx_http_mirror_module` (1.13.4) позволяет зеркалировать исходный запрос при помощи создания фоновых зеркалирующих подзапросов. Ответы на зеркалирующие подзапросы игнорируются.

`ngx_http_mirror_module` ( 1.13.4 ) 模組可讓您透過建立後台鏡像子查詢來鏡像原始查詢。鏡像子查詢的回應將被忽略。

#### Пример конфигурации｜配置範例

> ```
> location / {
>
> 地點 / {
>     mirror /mirror;
>
>     鏡子/鏡子；
>     proxy_pass http://backend;
> }
> 
> location = /mirror {
>     internal;
>
>     內部的;
>     proxy_pass http://test_backend$request_uri;
> }
> ```

#### Директивы｜指令

<table>
<tr><th>Синтаксис:<br>文法：</th><td><code><strong>mirror<br>鏡像</strong> <code><i>uri<br>URI</i></code> | <code>off<br>關閉</code>;</code></td></tr>
<tr><th>Умолчание:<br>預設：</th><td>mirror off;<br>關閉鏡像；</td></tr>
<tr><th>Контекст:<br>上下文：</th><td><code>http</code>, <code>server<br>伺服器</code>, <code>location<br>位置</code></td></tr>
</table>

Задаёт URI, на который будет зеркалироваться исходный запрос. На одном уровне конфигурации может быть задано несколько зеркал.

指定要將原始請求鏡像到的URI 。可以在單一配置層級指定多個鏡像。

<table>
<tr><th>Синтаксис:<br>語法：</th><td><code><strong>mirror_request_body</strong> <code>on</code> | <code>off</code>;</code></td></tr>
<tr><th>Умолчание:<br>預設值：</th><td>mirror_request_body on;<br>啟用 mirror_request_body;</td></tr>
<tr><th>Контекст:<br>上下文：</th><td><code>http</code>, <code>server<br>伺服器</code>, <code>location<br>位置</code></td></tr>
</table>

Определяет, зеркалировать ли тело запроса клиента. Если включено, то тело запроса клиента будет прочитано перед созданием зеркалирующих подзапросов. В этом случае небуферизованное проксирование тела запроса клиента, задаваемое директивами [proxy\_request\_buffering](<248 [02.01.01 http] ngx_http_proxy_module 模組.md#proxy_request_buffering>), [fastcgi\_request\_buffering](<225 [02.01.01 http] ngx_http_fastcgi_module 模組.md#fastcgi_request_buffering>), [scgi\_request\_buffering](<254 [02.01.01 http] 模組 ngx_http_scgi_module.md#scgi_request_buffering>) и [uwsgi\_request\_buffering](<268 [02.01.01 http] 模組 ngx_http_uwsgi_module.md#uwsgi_request_buffering>), будет отключено.

決定是否鏡像客戶端請求體。如果啟用，則會在建立鏡像子請求之前讀取用戶端請求體。在這種情況下，由 [proxy\_request\_buffering](<248 [02.01.01 http] ngx_http_proxy_module 模組.md#proxy_request_buffering>) 、[fastcgi\_request\_buffering](<225 [02.01.01 http] ngx_http_fastcgi_module 模組.md#fastcgi_request_buffering>) 、[scgi\_request\_buffering](<254 [02.01.01 http] 模組 ngx_http_scgi_module.md#scgi_request_buffering>)和(https://nginx.org/ru/docs/http/ngx_http_uwsgi_module.html#uwsgi_request_buffering)被禁用。

> ```
> location / {
>
> 地點 / {
>     mirror /mirror;
>
>     鏡子/鏡子；
>     mirror_request_body off;
>
>     鏡像請求體關閉；
>     proxy_pass http://backend;
> }
> 
> location = /mirror {
>     internal;
>
>     內部的;
>     proxy_pass http://log_backend;
>     proxy_pass_request_body off;
>
>     proxy_pass_request_body 關閉；
>     proxy_set_header Content-Length "";
>     proxy_set_header X-Original-URI $request_uri;
>
>     proxy_set_header X-Original- URI $request_uri;
> }
> ```
