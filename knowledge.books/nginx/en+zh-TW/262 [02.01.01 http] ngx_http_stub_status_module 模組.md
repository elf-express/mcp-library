## Модуль ngx\_http\_stub\_status\_module｜模組 ngx\_http\_stub\_status\_module

Модуль `ngx_http_stub_status_module` предоставляет доступ к базовой информации о состоянии сервера.

`ngx_http_stub_status_module`模組提供對伺服器狀態基本資訊的存取。

По умолчанию этот модуль не собирается, его сборку необходимо разрешить с помощью конфигурационного параметра `--with-http_stub_status_module`.

此模組預設未構建，必須使用`--with-http_stub_status_module`配置參數啟用。

#### Пример конфигурации｜配置範例

> ```
> location = /basic_status {
>     stub_status;
>
>     存根狀態；
> }
> ```

В данной конфигурации создаётся простая веб-страница с основной информацией о состоянии, которая может выглядеть следующим образом:

此配置會建立一個簡單的網頁，其中包含基本狀態訊息，可能如下所示：

> ```yaml
> Active connections: 291
>
> 活躍連線數：291
> server accepts handled requests
>
> 伺服器接受已處理的請求
>  16630948 16630948 31070465
> Reading: 6 Writing: 179 Waiting: 106
>
> 閱讀：6 寫作：179 等待：106
> ```

#### Директивы｜指令

|   |   |
| --- | --- |
| Синтаксис:<br>文法： | `**stub_status**;` |
| Умолчание:<br>預設值： | — |
| Контекст:<br>背景： | `server`, `location` |

Информация о состоянии будет доступна из данного location.

狀態資訊可在此處取得。

> До версии 1.7.5 синтаксис директивы требовал наличия произвольного аргумента, например “`stub_status on`”.
>
> 在1.7.5指令語法需要一個任意參數，例如「 `stub_status on` 」。

#### Данные｜數據

Доступна следующая информация:

以下資訊可供查閱：

`Active connections`

Текущее число активных клиентских соединений, включая `Waiting`\-соединения.

目前活躍客戶端連線數，包括`Waiting`連線。

`accepts`

Суммарное число принятых клиентских соединений.

接受的客戶端連線總數。

`handled`

Суммарное число обработанных соединений. Как правило, значение этого параметра такое же, как `accepts`, если не достигнуто какое-нибудь системное ограничение (например, лимит [worker\_connections](<285 [02.01 文件] 基本功能.md#worker_connections>)).

已處理的連接總數。通常情況下，此參數的值與`accepts`相同，除非達到某些系統限制（例如，[worker\_connections 限制](<285 [02.01 文件] 基本功能.md#worker_connections>) ）。

`requests`

Суммарное число клиентских запросов.

客戶端請求總數。

`Reading`

Текущее число соединений, в которых nginx в настоящий момент читает заголовок запроса.

nginx 目前正在讀取請求頭的連線數。

`Writing`

Текущее число соединений, в которых nginx в настоящий момент отвечает клиенту.

nginx 目前正在回應客戶端的連線數。

`Waiting`

Текущее число бездействующих клиентских соединений в ожидании запроса.

當前空閒客戶端連線數，正在等待請求。

#### Встроенные переменные｜內建變數

Модуль `ngx_http_stub_status_module` поддерживает следующие встроенные переменные (1.3.14):

`ngx_http_stub_status_module`模組支援以下內建變數 ( 1.3.14 )：

`$connections_active`

то же, что и значение `Active connections`;

與`Active connections`的意思相同；

`$connections_reading`

то же, что и значение `Reading`;

與`Reading`的意思相同；

`$connections_writing`

то же, что и значение `Writing`;

與值`Writing`相同；

`$connections_waiting`

то же, что и значение `Waiting`.

與值`Waiting`相同。
