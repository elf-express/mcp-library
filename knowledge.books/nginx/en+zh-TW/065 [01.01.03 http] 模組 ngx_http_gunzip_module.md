# Module ngx_http_gunzip_module｜模組 ngx_http_gunzip_module

## Module ngx\_http\_gunzip\_module｜模組 ngx\_http\_gunzip\_module

The `ngx_http_gunzip_module` module is a filter that decompresses responses with “`Content-Encoding: gzip`” for clients that do not support “gzip” encoding method. The module will be useful when it is desirable to store data compressed to save space and reduce I/O costs.

`ngx_http_gunzip_module`模組是一個過濾器，為不支援「gzip」編碼方法的客戶端使用「`Content-Encoding: gzip`」解壓縮回應。當需要儲存壓縮資料以節省空間並降低 I/O 成本時，此模組將非常有用。

This module is not built by default, it should be enabled with the `--with-http_gunzip_module` configuration parameter.

此模組預設未構建，應使用`--with-http_gunzip_module`配置參數啟用。

Enables or disables decompression of gzipped responses for clients that lack gzip support. If enabled, the following directives are also taken into account when determining if clients support gzip: [gzip\_http\_version](<066 [01.01.03 http] 模組 ngx_http_gzip_module.md#gzip_http_version>), [gzip\_proxied](<066 [01.01.03 http] 模組 ngx_http_gzip_module.md#gzip_proxied>), and [gzip\_disable](<066 [01.01.03 http] 模組 ngx_http_gzip_module.md#gzip_disable>). See also the [gzip\_vary](<066 [01.01.03 http] 模組 ngx_http_gzip_module.md#gzip_vary>) directive.

為缺乏 gzip 支援的用戶端啟用或停用 gzip 回應的解壓縮。若啟用，在決定客戶端是否支援 gzip 時也會考慮以下指令：[gzip\_http\_version](<066 [01.01.03 http] 模組 ngx_http_gzip_module.md#gzip_http_version>)、[gzip\_proxied](<066 [01.01.03 http] 模組 ngx_http_gzip_module.md#gzip_proxied>) 和 [gzip\_disable](<066 [01.01.03 http] 模組 ngx_http_gzip_module.md#gzip_disable>)。另請參閱 [gzip\_vary](<066 [01.01.03 http] 模組 ngx_http_gzip_module.md#gzip_vary>) 指令。

Sets the `*number*` and `*size*` of buffers used to decompress a response. By default, the buffer size is equal to one memory page. This is either 4K or 8K, depending on a platform.

設定用於解壓縮響應的緩衝區的`*number*`和`*size*`。預設情況下，緩衝區大小等於一頁記憶體。這是 4K 或 8K，取決於平台。
