Модуль `ngx_http_map_module` создаёт переменные, значения которых зависят от значений других переменных.

`ngx_http_map_module`模組建立變量，這些變數的值取決於其他變數的值。

#### Пример конфигурации｜配置範例

> ```
> map $http_host $name {
>
> 映射 $http_host $name {
>     hostnames;
>
>     主機名；
> 
>     default       0;
>
>     預設值為 0；
> 
>     example.com   1;
>     *.example.com 1;
>     example.org   2;
>     *.example.org 2;
>     .example.net  3;
>     wap.*         4;
>
>     wap.* 4；
> }
> 
> map $http_user_agent $mobile {
>
> 映射 $http_user_agent $mobile {
>     default       0;
>
>     預設值為 0；
>     "~Opera Mini" 1;
>
>     “~Opera Mini” 1;
> }
> ```

#### Директивы｜指令

Создаёт новую переменную, значение которой зависит от значений одной или более исходных переменных, указанных в первом параметре.

建立一個新變量，其值取決於第一個參數中指定的一個或多個來源變數的值。

> До версии 0.9.0 в качестве первого параметра можно было указать только одну переменную.
>
> 在0.9.0只能指定一個變數作為第一個參數。

> Поскольку переменные вычисляются только в момент использования, само по себе наличие даже большого числа объявлений переменных “`map`” не влечёт за собой никаких дополнительных расходов на обработку запросов.
>
> 由於變數僅在使用時才進行評估，因此即使存在大量的「 `map` 」變數宣告也不會產生任何額外的查詢處理成本。

Параметры внутри блока `map` задают соответствие между исходными и результирующими значениями.

`map`區塊內的參數定義了原始值和結果值之間的對應關係。

Исходные значения задаются строками или регулярными выражениями (0.9.6).

初始值指定為字串或正規表示式（ 0.9.6 ）。

Строки проверяются без учёта регистра.

字串檢查不區分大小寫。

Перед регулярным выражением ставится символ “`~`”, если при сравнении следует учитывать регистр символов, либо символы “`~*`” (1.0.4), если регистр символов учитывать не нужно. Регулярное выражение может содержать именованные и позиционные выделения, которые могут затем использоваться в других директивах совместно с результирующей переменной. Регулярные выражения сопоставляются в момент вычисления результирующей переменной, и успешное сопоставление заменяет позиционные выделения “`$1`”...“`$9`”, установленные ранее сопоставленными регулярными выражениями, см. [Выделения в регулярных выражениях](https://nginx.org/ru/docs/regex_captures.html).

如果比較區分大小寫，則正規表示式前面會加上字元「 `~` 」；如果比較不區分大小寫，則前面會加上字元「 `~*` 」（ 1.0.4 ）。正規表示式可以包含命名捕獲和位置捕獲，這些捕獲可以與結果變數一起用於其他指令中。正則表達式在計算結果變數時進行匹配，匹配成功會替換先前匹配的正則表達式建立的位置捕獲“ `$1` ”...“ `$9` ”，參見[正則表達式中的捕獲](https://nginx.org/ru/docs/regex_captures.html) 。

Если исходное значение совпадает с именем одного из специальных параметров, описанных ниже, перед ним следует поставить символ “`\`”.

如果來源值與下面描述的特殊參數之一的名稱匹配，則應在其前面加上“ `\` ”符號。

В качестве результирующего значения можно указать текст, переменную (0.9.0) и их комбинации (1.11.0).

結果值可以是文字、變數（ 0.9.0 ）或兩者的組合（ 1.11.0 ）。

Также поддерживаются следующие специальные параметры:

此外，也支援以下特殊參數：

`default` `*значение*`

задаёт результирующее значение, если исходное значение не совпадает ни с одним из перечисленных. Если параметр `default` не указан, результирующим значением по умолчанию будет пустая строка.

指定當原始值與任何列出的值都不符時的結果值。如果未指定`default`參數，則結果值預設為空字串。

`hostnames`

указывает, что в качестве исходных значений можно использовать маску для первой или последней части имени хоста, например,

指定主機名稱第一部分或最後一部分的遮罩可以用作初始值，例如：

> ```
> *.example.com 1;
> example.*     1;
>
> 例如* 1；
> ```

Вместо двух записей

而不是兩個條目

> ```
> example.com   1;
> *.example.com 1;
> ```

можно использовать одну:

你可以使用其中一種：

> ```
> .example.com  1;
> ```

Этот параметр следует указывать перед списком значений.

此參數必須在值列表之前指定。

`include` `*файл*`

включает файл со значениями. Включений может быть несколько.

包含一個帶有值的檔案。可能包含多個文件。

`volatile`

указывает, что переменная не кэшируется (1.11.7).

表示該變數未被快取（ 1.11.7 ）。

Поиск производится в следующем порядке приоритета и прекращается на первом подходящем варианте:

搜尋按以下優先順序執行，並在找到第一個合適的選項時終止：

1.  строковое значение без маски  
    不含遮罩的字串值
2.  самое длинное строковое значение с маской в начале, например “`*.example.com`”  
    以遮罩開頭的最長字串值，例如“ `*.example.com` ”
3.  самое длинное строковое значение с маской в конце, например “`mail.*`”  
    最長的字串值，末尾帶有掩碼，例如“ `mail.*` ”
4.  первое подходящее регулярное выражение (в порядке следования в конфигурационном файле)  
    第一個符合的正規表示式（按其在設定檔中出現的順序）
5.  значение по умолчанию (`default`)  
    預設值（ `default` ）
