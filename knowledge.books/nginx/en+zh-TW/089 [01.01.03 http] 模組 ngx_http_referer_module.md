## Module ngx\_http\_referer\_module｜模組 ngx_http_referer_module

The `ngx_http_referer_module` module is used to block access to a site for requests with invalid values in the “Referer”（參考） header field. It should be kept in mind that fabricating a request with an appropriate “Referer”（參考） field value is quite easy, and so the intended purpose of this module is not to block such requests thoroughly but to block the mass flow of requests sent by regular browsers. It should also be taken into consideration that regular browsers may not send the “Referer”（參考） field even for valid requests.

`ngx_http_referer_module`模組用於阻止對站點的訪問，阻止請求的“Referer”（參考）標頭字段值無效。需要注意的是，偽造一個包含有效“Referer”（參考）字段值的請求非常容易，因此該模組的目的並非徹底阻止此類請求，而是阻止普通瀏覽器發送的大量此類請求。此外，還應考慮到，即使是有效的請求，普通瀏覽器也可能不會發送“Referer”（參考）字段。

#### Example Configuration｜範例配置

> ```
> valid_referers none blocked server_names
>
> valid_referers 無 已屏蔽 server_names
>                *.example.com example.* www.example.org/galleries/
>
>                *.example.com 範例。 * www.example.org/galleries/
>                ~\.google\.;
> 
> if ($invalid_referer) {
>
> 如果 ($invalid_referer) {
>     return 403;
>
>     返回403；
> }
> ```

Specifies the “Referer”（參考） request header field values that will cause the embedded `$invalid_referer` variable to be set to an empty string. Otherwise, the variable will be set to “`1`”. Search for a match is case-insensitive.

指定哪些“Referer”（參考）請求頭字段值會導致嵌入的`$invalid_referer`變數被設定為空字串。否則，該變數將被設定為“ `1` ”。搜尋匹配項不區分大小寫。

Parameters can be as follows:

參數可以如下圖所示：

`none`

the “Referer”（參考） field is missing in the request header;

請求頭中缺少“Referer”（參考）字段；

`blocked`

the “Referer”（參考） field is present in the request header, but its value has been deleted by a firewall or proxy server; such values are strings that do not start with “`http://`” or “`https://`”;

請求標頭中存在“Referer”（參考）字段，但其值已被防火牆或代理伺服器刪除；此類值是不以「 `http://` 」或「 `https://` 」開頭的字串；

`server_names`

the “Referer”（參考） request header field contains one of the server names;

“Referer”（參考）請求頭字段包含伺服器名稱之一；

arbitrary string

任意字串

defines a server name and an optional URI prefix. A server name can have an “`*`” at the beginning or end. During the checking, the server’s port in the “Referer”（參考） field is ignored;

定義伺服器名稱和一個可選的URI前綴。伺服器名稱的開頭或結尾可以有「 `*` 」。在檢查期間， “Referer”（參考）欄位中的伺服器連接埠將被忽略；

regular expression

正規表示式

the first symbol should be a “`~`”. It should be noted that an expression will be matched against the text starting after the “`http://`” or “`https://`”.

第一個符號應該是「 `~` 」。需要注意的是，表達式將與「 `http://` 」或「 `https://` 」之後的文字進行比對。

#### Embedded Variables｜嵌入變數

`$invalid_referer`

Empty string, if the “Referer”（參考） request header field value is considered [valid](#valid_referers), otherwise “`1`”.

如果“Referer”（參考）請求頭字段值被認為是 [有效的](#valid_referers) ，則為空字串，否則為「 `1` 」。
