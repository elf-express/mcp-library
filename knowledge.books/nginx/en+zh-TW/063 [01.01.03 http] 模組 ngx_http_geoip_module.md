The `ngx_http_geoip_module` module (0.8.6+) creates variables with values depending on the client IP address, using the precompiled [MaxMind](http://www.maxmind.com/) databases.

`ngx_http_geoip_module`模組 ( 0.8.6 +) 根據客戶端IP位址建立變數值，使用預先編譯的 [MaxMind](http://www.maxmind.com/)資料庫。

When using the databases with IPv6 support (1.3.12, 1.2.7), IPv4 addresses are looked up as IPv4-mapped IPv6 addresses.

當使用支援 IPv6 的資料庫 ( 1.3.12, 1.2.7 ) 時，IPv4 位址會作為 IPv4 對應的 IPv6 位址進行尋找。

This module is not built by default, it should be enabled with the `--with-http_geoip_module` configuration parameter.

此模組預設未構建，應使用`--with-http_geoip_module`配置參數啟用。

> This module requires the [MaxMind GeoIP](http://www.maxmind.com/app/c) library.
>
> 本模組需要 [MaxMind GeoIP](http://www.maxmind.com/app/c)函式庫。

#### Example Configuration｜範例配置

> ```
> http {
>     geoip_country         GeoIP.dat;
>
>     geoip_country GeoIP.dat；
>     geoip_city            GeoLiteCity.dat;
>
>     geoip_city GeoLiteCity.dat;
>     geoip_proxy           192.168.100.0/24;
>
>     geoip_proxy 192.168.100.0/24 ;
>     geoip_proxy           2001:0db8::/32;
>
>     geoip_proxy 2001:0db8::/32 ;
>     geoip_proxy_recursive on;
>
>     geoip_proxy_recursive 已啟用；
>     ...
> ```

Specifies a database used to determine the country depending on the client IP address. The following variables are available when using this database:

指定用於根據客戶端IP位址確定國家/地區的資料庫。使用此資料庫時，可以使用以下變數：

`$geoip_country_code`

two-letter country code, for example, “`RU`”, “`US`”.

兩位字母的國家代碼，例如「 `RU` 」、「 `US` 」。

`$geoip_country_code3`

three-letter country code, for example, “`RUS`”, “`USA`”.

三個字母的國家代碼，例如「 `RUS` 」、「 `USA` 」。

`$geoip_country_name`

country name, for example, “`Russian Federation`”, “`United States`”.

國家名稱，例如「 `Russian Federation` 」、「 `United States` 」。

Specifies a database used to determine the country, region, and city depending on the client IP address. The following variables are available when using this database:

指定一個資料庫，用於根據客戶端IP地址確定國家/地區、區域和城市。使用此資料庫時，可以使用以下變數：

`$geoip_area_code`

telephone area code (US only).

電話區號（僅限US ）。

> This variable may contain outdated information since the corresponding database field is deprecated.
>
> 由於相應的資料庫欄位已棄用，因此該變數可能包含過時的資訊。

`$geoip_city_continent_code`

two-letter continent code, for example, “`EU`”, “`NA`”.

兩位字母的大洲代碼，例如“ `EU` ”、“ `NA` ”。

`$geoip_city_country_code`

two-letter country code, for example, “`RU`”, “`US`”.

兩位字母的國家代碼，例如“ `RU` ”、“ `US` ”。

`$geoip_city_country_code3`

three-letter country code, for example, “`RUS`”, “`USA`”.

三個字母的國家代碼，例如「 `RUS` 」、「 `USA` 」。

`$geoip_city_country_name`

country name, for example, “`Russian Federation`”, “`United States`”.

國家名稱，例如「 `Russian Federation` 」、「 `United States` 」。

`$geoip_dma_code`

DMA region code in US (also known as “metro code”), according to the [geotargeting](https://developers.google.com/adwords/api/docs/appendix/cities-DMAregions) in Google AdWords API.

DMA區域代碼位於US （也稱為「都會代碼」），根據 Google AdWords API中的 [地理定位](https://developers.google.com/adwords/api/docs/appendix/cities-DMAregions) 。

`$geoip_latitude`

latitude.

緯度。

`$geoip_longitude`

longitude.

經度。

`$geoip_region`

two-symbol country region code (region, territory, state, province, federal land and the like), for example, “`48`”, “`DC`”.

雙符號國家區域代碼（地區、領土、州、省、聯邦領土等），例如「 `48` 」、「 `DC` 」。

`$geoip_region_name`

country region name (region, territory, state, province, federal land and the like), for example, “`Moscow City`”, “`District of Columbia`”.

國家名稱（地區、領土、州、省、聯邦土地等），例如「 `Moscow City` 」、「 `District of Columbia` 」。

`$geoip_city`

city name, for example, “`Moscow`”, “`Washington`”.

城市名稱，例如「 `Moscow` 」、「 `Washington` 」。

`$geoip_postal_code`

postal code.

郵遞區號.

This directive appeared in versions 1.3.0 and 1.2.1.

該指令出現在版本1.3.0和1.2.1 。

If recursive search is disabled then instead of the original client address that matches one of the trusted addresses, the last address sent in “X-Forwarded-For”（X-轉發） will be used. If recursive search is enabled then instead of the original client address that matches one of the trusted addresses, the last non-trusted address sent in “X-Forwarded-For”（X-轉發） will be used.

如果遞歸搜尋被停用，則不會使用與受信任位址相符的原始用戶端位址，而是使用“X-Forwarded-For”（X-轉發）中發送的最後一個位址。如果遞歸搜尋被啟用，則不會使用與受信任位址相符的原始用戶端位址，而是使用“X-Forwarded-For”（X-轉發）中發送的最後一個不受信任的位址。
