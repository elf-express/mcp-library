## nginx security advisories｜nginx 安全公告

All nginx security issues should be reported via one of the methods listed [here](https://github.com/nginx/nginx/blob/master/SECURITY.md).

所有 nginx 安全性問題都應該透過 [此處](https://github.com/nginx/nginx/blob/master/SECURITY.md)列出的方法之一進行報告。

Patches are signed using one of the [PGP public keys](<178 [01 在] PGP公鑰.md>).

補丁使用 [PGP公鑰](<178 [01 在] PGP公鑰.md>)之一進行簽署。
