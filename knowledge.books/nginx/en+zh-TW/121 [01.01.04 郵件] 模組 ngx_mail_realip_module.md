# Module ngx_mail_realip_module｜模組 ngx_mail_realip_module

> 章節：[en｜在](<000 目錄.md#c-1>) › [docs｜文件](<000 目錄.md#c-2>) › [mail｜郵件](<000 目錄.md#c-6>)

## Module ngx\_mail\_realip\_module｜模組 ngx\_mail\_realip\_module

|   |
| --- |
| [Example Configuration](#example)<br>[Directives](#directives)<br>     [set\_real\_ip\_from](#set_real_ip_from)<br>[範例設定](#example)<br> [指令](#directives)<br> [set\_real\_ip\_from](#set_real_ip_from) |

The `ngx_mail_realip_module` module is used to change the client address and port to the ones sent in the PROXY protocol header (1.19.8). The PROXY protocol must be previously enabled by setting the [proxy\_protocol](<117 [01.01.04 郵件] 模組 ngx_mail_core_module.md#proxy_protocol>) parameter in the `listen` directive.

`ngx_mail_realip_module`模組用於將客戶端位址和連接埠變更為PROXY協定頭（ 1.19.8 ）中傳送的位址和連接埠。必須事先透過在`listen`指令中設定 [proxy\_protocol](<117 [01.01.04 郵件] 模組 ngx_mail_core_module.md#proxy_protocol>)參數來啟用PROXY協定。

#### Example Configuration｜範例配置

> ```
> listen 110 proxy_protocol;
>
> 監聽 110 代理協議；
> 
> set_real_ip_from  192.168.1.0/24;
>
> set_real_ip_from 192.168.1.0/24 ;
> set_real_ip_from  192.168.2.1;
>
> set_real_ip_from 192.168.2.1 ;
> set_real_ip_from  2001:0db8::/32;
>
> set_real_ip_from 2001:0db8::/32 ;
> ```

#### Directives｜指令

| Syntax:<br>語法： | ``**set_real_ip_from** `*address*` \| `*CIDR*` \| `unix:`;``<br>` `**set_real_ip_from** ` *地址* ` \| ` * CIDR * ` \| ` unix: `;` ` |
| Default:<br>預設值： | — |
| Context:<br>上下文： | `mail`, `server` |

Defines trusted addresses that are known to send correct replacement addresses. If the special value `unix:` is specified, all UNIX-domain sockets will be trusted.

定義已知會傳送正確替換位址的可信任位址。如果指定特殊值`unix:` ，則所有UNIX域套接字都將被信任。
