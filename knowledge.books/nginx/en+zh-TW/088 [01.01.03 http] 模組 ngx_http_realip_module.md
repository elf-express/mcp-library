The `ngx_http_realip_module` module is used to change the client address and optional port to those sent in the specified header field.

`ngx_http_realip_module`模組用於將客戶端位址和選用連接埠變更為在指定的標頭欄位中傳送的位址和連接埠。

This module is not built by default, it should be enabled with the `--with-http_realip_module` configuration parameter.

此模組預設未構建，應使用`--with-http_realip_module`配置參數啟用。

#### Example Configuration｜範例配置

> ```
> set_real_ip_from  192.168.1.0/24;
>
> set_real_ip_from 192.168.1.0/24 ;
> set_real_ip_from  192.168.2.1;
>
> set_real_ip_from 192.168.2.1 ;
> set_real_ip_from  2001:0db8::/32;
>
> set_real_ip_from 2001:0db8::/32 ;
> real_ip_header    X-Forwarded-For;
>
> real_ip_header X-Forwarded-For;
> real_ip_recursive on;
>
> real_ip_recursive 已開啟；
> ```

Defines trusted addresses that are known to send correct replacement addresses. If the special value `unix:` is specified, all UNIX-domain sockets will be trusted. Trusted addresses may also be specified using a hostname (1.13.1).

定義已知會傳送正確替換位址的受信任位址。如果指定特殊值`unix:` ，則所有UNIX域套接字都會被信任。也可以使用主機名稱（ 1.13.1 ）指定受信任位址。

> IPv6 addresses are supported starting from versions 1.3.0 and 1.2.1.
>
> 從版本1.3.0和1.2.1開始支援IPv6位址。

Defines the request header field whose value will be used to replace the client address.

定義請求頭字段，其值將用於替換客戶端地址。

The request header field value that contains an optional port is also used to replace the client port (1.11.0). The address and port should be specified according to [RFC 3986](https://datatracker.ietf.org/doc/html/rfc3986).

包含可選連接埠的請求頭字段值也用於替換客戶端連接埠（ 1.11.0 ）。位址和連接埠應依照 [RFC 3986](https://datatracker.ietf.org/doc/html/rfc3986)指定。

The `proxy_protocol` parameter (1.5.12) changes the client address to the one from the PROXY protocol header. The PROXY protocol must be previously enabled by setting the `proxy_protocol` parameter in the [listen](<056 [01.01.03 http] 模組 ngx_http_core_module.md#listen>) directive.

`proxy_protocol`參數（1.5.12）將客戶端位址改為PROXY協定頭中的位址。必須預先透過在 [listen](<056 [01.01.03 http] 模組 ngx_http_core_module.md#listen>) 指令中設定 `proxy_protocol` 參數來啟用 PROXY 協定。

This directive appeared in versions 1.3.0 and 1.2.1.

該指令出現在版本1.3.0和1.2.1中。

If recursive search is disabled, the original client address that matches one of the trusted addresses is replaced by the last address sent in the request header field defined by the [real\_ip\_header](#real_ip_header) directive. If recursive search is enabled, the original client address that matches one of the trusted addresses is replaced by the last non-trusted address sent in the request header field.

如果遞歸搜尋被停用，則與某個受信任位址相符的原始用戶端位址將被替換為請求頭字段中由 [real\_ip\_header](#real_ip_header)指令定義的最後一個發送的位址。如果遞歸搜尋被啟用，則與某個受信任位址相符的原始用戶端位址將被替換為請求頭欄位中最後一個發送的非受信任位址。

#### Embedded Variables｜嵌入變數

保留原始客戶端位址（ 1.9.7 ）

保留原始客戶端連接埠（ 1.11.0 ）
