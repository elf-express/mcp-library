## Module ngx\_http\_proxy\_protocol\_vendor\_module｜模組 ngx\_http\_proxy\_protocol\_vendor\_module

|   |
| --- |
| [Example Configuration](#example)<br>[Embedded Variables](#variables)<br>[範例配置](#example)<br> [嵌入式變數](#variables) |

The `ngx_http_proxy_protocol_vendor_module` module (1.23.3) allows obtaining additional information about a connection in cloud platforms from application-specific TLVs of the [PROXY protocol](http://www.haproxy.org/download/1.8/doc/proxy-protocol.txt) header.

`ngx_http_proxy_protocol_vendor_module`模組 ( 1.23.3 ) 允許從 [PROXY協定](http://www.haproxy.org/download/1.8/doc/proxy-protocol.txt)標頭的應用程式特定 TLV 取得有關雲端平台連接的其他資訊。

Supported cloud platforms:

支援的雲端平台：

-   Amazon Web Services  
    亞馬遜網路服務
-   Google Cloud Platform
-   Microsoft Azure

The PROXY protocol must be previously enabled by setting the `proxy_protocol` parameter in the [listen](<056 [01.01.03 http] 模組 ngx_http_core_module.md#listen>) directive.

必須先在 [listen](<056 [01.01.03 http] 模組 ngx_http_core_module.md#listen>)指令中設定`proxy_protocol`參數來啟用PROXY協定。

> This module is available as part of our [commercial subscription](https://www.f5.com/products/nginx).
>
> 本模組作為我們[商業訂閱](https://www.f5.com/products/nginx)的一部分提供。

#### Example Configuration｜範例配置

> ```
> proxy_set_header X-Conn-ID $proxy_protocol_tlv_gcp_conn_id;
>
> proxy_set_header X-Conn- ID $proxy_protocol_tlv_gcp_conn_id;
> 
> server {
>
> 伺服器 {
>     listen 80   proxy_protocol;
>
>     監聽 80 代理協議；
>     listen 443  ssl proxy_protocol;
>
>     監聽 443 ssl 代理協定；
>     ...
> }
> ```

#### Embedded Variables｜嵌入變數

`$proxy_protocol_tlv_aws_vpce_id`

TLV value from the PROXY Protocol header representing the [ID of AWS VPC endpoint](https://docs.aws.amazon.com/elasticloadbalancing/latest/network/load-balancer-target-groups.html#proxy-protocol)

TLV值來自PROXY協議頭，表示 [ID的AWS VPC端點](https://docs.aws.amazon.com/elasticloadbalancing/latest/network/load-balancer-target-groups.html#proxy-protocol)

`$proxy_protocol_tlv_azure_pel_id`

TLV value from the PROXY Protocol header representing the [LinkID of Azure private endpoint](https://learn.microsoft.com/en-us/azure/private-link/private-link-service-overview#getting-connection-information-using-tcp-proxy-v2)

TLV值來自PROXY協定標頭，表示 [Azure 專用終端點的 LinkID](https://learn.microsoft.com/en-us/azure/private-link/private-link-service-overview#getting-connection-information-using-tcp-proxy-v2)

`$proxy_protocol_tlv_gcp_conn_id`

TLV value from the PROXY Protocol header representing [Google Cloud PSC connection ID](https://cloud.google.com/vpc/docs/configure-private-service-connect-producer#proxy-protocol)

來自TLV協定頭的值PROXY表示 [Google Cloud PSC連接ID](https://cloud.google.com/vpc/docs/configure-private-service-connect-producer#proxy-protocol)
