## Модуль ngx\_http\_headers\_module｜模組 ngx_http_headers_module

|   |
| --- |
| [Пример конфигурации](#example)<br>[Директивы](#directives)<br>     [add\_header](#add_header)<br>     [add\_header\_inherit](#add_header_inherit)<br>     [add\_trailer](#add_trailer)<br>     [add\_trailer\_inherit](#add_trailer_inherit)<br>     [expires](#expires)<br>(https://nginx.org/ru/docs/http/ngx_http_headers_module.html#expires) |

Модуль `ngx_http_headers_module` позволяет выдавать поля заголовка “Expires”（過期） и “Cache-Control”（快取控制）, а также добавлять произвольные поля в заголовок ответа.

`ngx_http_headers_module`模組允許您輸出“Expires”（過期）和“Cache-Control”（快取控制）標頭字段，以及向響應標頭添加自訂字段。

#### Пример конфигурации｜配置範例

> ```
> expires    24h;
>
> 有效期限24小時；
> expires    modified +24h;
>
> 有效期限修改後+24小時；
> expires    @24h;
>
> 有效期限至24小時後；
> expires    0;
>
> 過期時間為 0；
> expires    -1;
>
> 過期時間-1；
> expires    epoch;
>
> 過期時間（epoch）；
> expires    $expires;
>
> 過期時間 $expires；
> add_header Cache-Control private;
>
> 添加頭部 Cache-Control private;
> ```

Добавляет указанное поле в заголовок ответа при условии, что код ответа равен 200, 201 (1.3.10), 204, 206, 301, 302, 303, 304, 307 (1.1.16, 1.0.13) или 308 (1.13.0). В значении параметра можно использовать переменные.

將指定欄位加入回應標頭，前提是回應碼為 200、201 (1.3.10)、204、206、301、302、303、304、307 (1.1.16, 1.0.13) 或 308 (1.13.0)。您可以在參數值中使用變數。

Директив `add_header` может быть несколько. Директивы наследуются с предыдущего уровня конфигурации при условии, что на данном уровне не описаны свои директивы `add_header`. Правила наследования могут быть переопределены при помощи директивы [add\_header\_inherit](#add_header_inherit) (1.29.3).

可能存在多個`add_header`指令。指令會從上一個配置層級繼承，前提是當前層級沒有定義自己的`add_header`指令。可以使用 [add\_header\_inherit](#add_header_inherit) ( 1.29.3 ) 指令覆寫繼承規則。

Если указан параметр `always` (1.7.5), то поле заголовка будет добавлено независимо от кода ответа.

如果指定了`always` ( 1.7.5 ) 參數，則無論回應代碼為何，都會新增標頭欄位。

Позволяет изменять правила наследования значений, указанных в директивах [add\_header](#add_header). По умолчанию используется [стандартная](#add_header_default_inherit) модель наследования.

允許您變更 [add\_header](#add_header)指令中指定的值的繼承規則。預設情況下，使用 [standard](#add_header_default_inherit)繼承模型。

Параметр `merge` включает добавление значений с предыдущего уровня к значениям, указанным на текущем уровне.

參數`merge`允許將上一層的值加到目前層級的指定值中。

Параметр `off` отменяет наследование значений с предыдущего уровня конфигурации.

參數`off`取消從上一配置等級繼承值。

Сами правила наследования также наследуются стандартным образом. Например `add_header_inherit merge;`, определённый на верхнем уровне, будет рекурсивно наследоваться во всех вложенных уровнях до тех пор, пока не будет переопределён.

繼承規則本身也以標準方式繼承。例如，在頂層定義的`add_header_inherit merge;`將在所有嵌套層級遞歸繼承，直到被重新定義為止。

Разрешает или запрещает добавлять или менять поля “Expires”（過期） и “Cache-Control”（快取控制） в заголовке ответа при условии, что код ответа равен 200, 201 (1.3.10), 204, 206, 301, 302, 303, 304, 307 (1.1.16, 1.0.13) или 308 (1.13.0). В качестве параметра можно задать положительное или отрицательное [время](<319 [02.01 文件] 設定檔中的計量單位.md>).

啟用或停用在回應碼為 200、201（ 1.3.10 ）、204、206、301、302、303、304、307（ 1.1.16, 1.0.13 ）或 308（ 1.13.0 ）時，在響應頭中新增或更改“Expires”（過期）和“Cache-Control”（快取控制）字段。 [時間](<319 [02.01 文件] 設定檔中的計量單位.md>)可以指定為正值或負值。

Время в поле “Expires”（過期） получается как сумма текущего времени и времени, заданного в директиве. Если используется параметр `modified` (0.7.0, 0.6.32), то время получается как сумма времени модификации файла и времени, заданного в директиве.

“Expires”（過期）字段中的時間計算方法為當前時間與指令中指定時間總和。若使用`modified` ( 0.7.0, 0.6.32 ) 參數，則時間計算方法為檔案修改時間與指令中指定時間總和。

Кроме того, с помощью префикса “`@`” можно задать время суток (0.7.9, 0.6.34):

此外，使用前綴「 `@` 」可以設定一天中的時間（ 0.7.9, 0.6.34 ）：

> ```
> expires @15h30m;
>
> 到期時間為15:30；
> ```

Содержимое поля “Cache-Control”（快取控制） зависит от знака заданного времени:

字段“Cache-Control”（快取控制）的內容取決於指定時間的符號：

-   отрицательное время — “Cache-Control: no-cache”.  
    負時間——「Cache-Control: no-cache」。
-   положительное или равное нулю время — “Cache-Control: max-age=`*t*`”, где `*t*` это время в секундах, заданное в директиве.  
    正數或零時間 — “Cache-Control: max-age= `*t*` ”，其中`*t*`是指令中指定的秒數。

Параметр `epoch` задаёт время “`Thu, 01 Jan 1970 00:00:01 GMT`” (1 января 1970 00:00:01 GMT) для поля “Expires”（過期） и “`no-cache`” для поля “Cache-Control”（快取控制）.

參數`epoch`設定欄位“Expires”（過期）的時間「 `Thu, 01 Jan 1970 00:00:01 GMT` 」(1970 年 1 月 1 日00:00:01 GMT )，設定欄位“Cache-Control”（快取控制）的時間「 `no-cache` 」。

Параметр `max` задаёт время “`Thu, 31 Dec 2037 23:55:55 GMT`” (31 декабря 2037 23:55:55 GMT) для поля “Expires”（過期） и 10 лет для поля “Cache-Control”（快取控制）.

`max`參數為“Expires”（過期）字段設定時間「`Thu, 31 Dec 2037 23:55:55 GMT`」（2037年12月31日23:55:55 GMT），為“Cache-Control”（快取控制）字段設定10年。

Параметр `off` запрещает добавлять или менять поля “Expires”（過期） и “Cache-Control”（快取控制） в заголовке ответа.

`off`參數阻止在回應標頭中新增或變更“Expires”（過期）和“Cache-Control”（快取控制）欄位。

В значении последнего параметра можно использовать переменные (1.7.9):

最後一個參數的值可以使用變數（ 1.7.9 ）：

> ```
> map $sent_http_content_type $expires {
>
> 映射 $sent_http_content_type $expires {
>     default         off;
>
>     預設關閉；
>     application/pdf 42d;
>     ~image/         max;
>
>     ~image/max；
> }
> 
> expires $expires;
>
> 過期時間 $expires；
> ```
