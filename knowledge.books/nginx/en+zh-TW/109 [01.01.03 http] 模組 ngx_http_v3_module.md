The `ngx_http_v3_module` module (1.25.0) provides experimental support for [HTTP/3](https://datatracker.ietf.org/doc/html/rfc9114).

`ngx_http_v3_module`模組 ( 1.25.0 ) 為 [HTTP /3](https://datatracker.ietf.org/doc/html/rfc9114)提供實驗支援。

This module is not built by default, it should be enabled with the `--with-http_v3_module` configuration parameter.

此模組預設未構建，應使用`--with-http_v3_module`配置參數啟用。

> This module requires the [OpenSSL](http://www.openssl.org/) library version 1.1.1 or higher.
>
> 本模組需要 [OpenSSL](http://www.openssl.org/)函式庫版本1.1.1或更高版本。

> 0-RTT support requires the [OpenSSL](http://www.openssl.org/) library version 3.5.1 or higher. Alternatively, [BoringSSL](https://boringssl.googlesource.com/boringssl), [LibreSSL](https://www.libressl.org/), or [QuicTLS](https://github.com/quictls/openssl) libraries can be used to build and run this module.
>
> 0- RTT支援需要 [OpenSSL](http://www.openssl.org/)函式庫版本3.5.1或更高版本。或者，可以使用 [BoringSSL](https://boringssl.googlesource.com/boringssl) 、[LibreSSL](https://www.libressl.org/)或 [QuicTLS](https://github.com/quictls/openssl)函式庫來建置和運行此模組。

#### Known Issues｜已知問題

The module is experimental, caveat emptor applies.

此模組為實驗性模組，請自行承擔風險。

Before version 1.29.1, 0-RTT support could not be enabled with OpenSSL regardless of the [ssl\_early\_data](<098 [01.01.03 http] 模組 ngx_http_ssl_module.md#ssl_early_data>) directive value.

在版本1.29.1之前，無論 [ssl\_early\_data](<098 [01.01.03 http] 模組 ngx_http_ssl_module.md#ssl_early_data>)指令值為何，都無法使用 OpenSSL 啟用 0- RTT支援。

The module cannot be built on the Win32 platform.

該模組無法在 Win32 平台上建置。

#### Example Configuration｜範例配置

> ```
> http {
>     log_format quic '$remote_addr - $remote_user [$time_local] '
>                     '"$request" $status $body_bytes_sent '
>                     '"$http_referer" "$http_user_agent" "$http3"';
> 
>     access_log logs/access.log quic;
> 
>     server {
>
>     伺服器 {
>         # for better compatibility it's recommended｜為了獲得更好的兼容性，建議這樣做。
>         # to use the same port for http/3 and https｜HTTP/3 和 HTTPS 使用相同的連接埠
>         listen 8443 quic reuseport;
>
>         監聽 8443 快速重複使用連接埠；
>         listen 8443 ssl;
>
>         監聽 8443 ssl；
> 
>         ssl_certificate     certs/example.com.crt;
>
>         ssl_certificate certs/example.com.crt;
>         ssl_certificate_key certs/example.com.key;
> 
>         location / {
>
>         地點 / {
>             # used to advertise the availability of HTTP/3｜用於宣傳HTTP /3 的供應情況
>             add_header Alt-Svc 'h3=":8443"; ma=86400';
>
>             add_header Alt-Svc 'h3=":8443";馬=86400'；
>         }
>     }
> }
> ```

Enables sending in optimized batch mode using segmentation offloading.

啟用分段卸載功能，以最佳化的批次模式發送資料。

> Optimized sending is supported only on Linux featuring `UDP_SEGMENT`.

> 優化發送僅在配備`UDP_SEGMENT`的 Linux 系統上支援。

Sets a `*file*` with the secret key used to encrypt stateless reset and address validation tokens. By default, a random key is generated on each reload. Tokens generated with old keys are not accepted.

設定一個`*file*`其中包含用於加密無狀態重設令牌和地址驗證令牌的金鑰。預設情況下，每次重新載入時都會產生一個隨機金鑰。使用舊密鑰產生的令牌將不被接受。

Enables the [QUIC Address Validation](https://datatracker.ietf.org/doc/html/rfc9000#name-address-validation) feature. This includes sending a new token in a `Retry` packet or a `NEW_TOKEN` frame and validating a token received in the `Initial` packet.

啟用 [QUIC位址驗證](https://datatracker.ietf.org/doc/html/rfc9000#name-address-validation)功能。這包括在`Retry`封包或`NEW_TOKEN`幀中發送新令牌，並驗證在`Initial`封包中收到的令牌。

#### Embedded Variables｜嵌入變數

The `ngx_http_v3_module` module supports the following embedded variables:

`ngx_http_v3_module`模組支援以下嵌入式變數：

`$http3`

negotiated protocol identifier: “`h3`” for HTTP/3 connections, “`hq`” for hq connections, or an empty string otherwise.

協商的協議標識符：「 `h3` 」用於HTTP /3 連接，「 `hq` 」用於總部連接，否則為空字串。
