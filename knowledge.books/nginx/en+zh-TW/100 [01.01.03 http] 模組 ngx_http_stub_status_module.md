The `ngx_http_stub_status_module` module provides access to basic status information.

`ngx_http_stub_status_module`模組提供對基本狀態資訊的存取。

This module is not built by default, it should be enabled with the `--with-http_stub_status_module` configuration parameter.

此模組預設未構建，應使用`--with-http_stub_status_module`配置參數啟用。

#### Example Configuration｜範例配置

> ```
> location = /basic_status {
>     stub_status;
>
>     存根狀態；
> }
> ```

This configuration creates a simple web page with basic status data which may look like as follows:

此配置會建立一個簡單的網頁，其中包含基本狀態數據，其內容可能如下所示：

> ```yaml
> Active connections: 291
>
> 活躍連線數：291
> server accepts handled requests
>
> 伺服器接受已處理的請求
>  16630948 16630948 31070465
> Reading: 6 Writing: 179 Waiting: 106
>
> 閱讀：6 寫作：179 等待：106
> ```

#### Directives｜指令

|   |   |
| --- | --- |
| Syntax:<br>文法： | `**stub_status**;` |
| Default:<br>預設值： | — |
| Context:<br>背景： | `server`, `location` |

The basic status information will be accessible from the surrounding location.

基本狀態資訊可從周圍位置取得。

> In versions prior to 1.7.5, the directive syntax required an arbitrary argument, for example, “`stub_status on`”.
>
> 在1.7.5之前的版本中，指令語法需要一個任意參數，例如「 `stub_status on` 」。

#### Data｜數據

The following status information is provided:

提供以下狀態資訊：

`Active connections`

The current number of active client connections including `Waiting` connections.

目前活躍客戶端連線數，包括`Waiting`連線。

`accepts`

The total number of accepted client connections.

已接受的客戶端連線總數。

`handled`

The total number of handled connections. Generally, the parameter value is the same as `accepts` unless some resource limits have been reached (for example, the [worker\_connections](<125 [01.01 文件] 核心功能.md#worker_connections>) limit).

已處理的連接總數。通常，此參數值與`accepts`相同，除非達到某些資源限制（例如，[worker\_connections](<125 [01.01 文件] 核心功能.md#worker_connections>)限制）。

`requests`

The total number of client requests.

客戶請求總數。

`Reading`

The current number of connections where nginx is reading the request header.

nginx 正在讀取請求頭的目前連線數。

`Writing`

The current number of connections where nginx is writing the response back to the client.

nginx 目前正在向客戶端寫入回應的連線數。

`Waiting`

The current number of idle client connections waiting for a request.

當前空閒客戶端連線數，正在等待請求。

#### Embedded Variables｜嵌入變數

The `ngx_http_stub_status_module` module supports the following embedded variables (1.3.14):

`ngx_http_stub_status_module`模組支援以下嵌入式變數 ( 1.3.14 )：

`$connections_active`

same as the `Active connections` value;

與`Active connections`值相同；

`$connections_reading`

same as the `Reading` value;

與`Reading`值相同；

`$connections_writing`

same as the `Writing` value;

與`Writing`值相同；

`$connections_waiting`

same as the `Waiting` value.

與`Waiting`值相同。
