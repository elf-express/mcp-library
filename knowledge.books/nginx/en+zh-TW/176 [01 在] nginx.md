nginx ("*engine x*") is an HTTP web server, reverse proxy, content cache, load balancer, TCP/UDP proxy server, and mail proxy server. Originally written by [Igor Sysoev](http://sysoev.ru/en/) and distributed under the [2-clause BSD License](<354 頁.md>).

nginx（「*engine x*」）是一個HTTP Web 伺服器、反向代理、內容快取、負載平衡器、 TCP/UDP代理伺服器和郵件代理伺服器。最初由 [Igor Sysoev](http://sysoev.ru/en/)編寫，並根據 [2-clause BSD License](<354 頁.md>)分發。

Known for flexibility and high performance with low resource utilization, nginx is:

nginx 以其靈活性、高效能和低資源佔用率而聞名：

-   the world's most popular web server \[[Netcraft](https://news.netcraft.com/archives/category/web-server-survey/)\];  
    世界上最受歡迎的網頁伺服器 \[[Netcraft](https://news.netcraft.com/archives/category/web-server-survey/) \];
-   consistently one of the most popular [Docker images](https://hub.docker.com/search?q=nginx) \[[DataDog](https://www.datadoghq.com/docker-adoption/#six)\];  
    總是最受歡迎的 [Docker 映像](https://hub.docker.com/search?q=nginx) \[[DataDog](https://www.datadoghq.com/docker-adoption/#six) \];
-   powering multiple [Ingress Controllers for Kubernetes](https://kubernetes.io/docs/concepts/services-networking/ingress-controllers/), including [our own](https://github.com/nginxinc/kubernetes-ingress).  
    為多個 [Kubernetes Ingress Controllers](https://kubernetes.io/docs/concepts/services-networking/ingress-controllers/)提供支持，包括 [我們自己的](https://github.com/nginxinc/kubernetes-ingress) 。

Enterprise distributions, commercial support and training are [available from F5, Inc.](<175 [01 在] nginx 企業版.md>)

企業版發行、商業支援與培訓由 F5 公司提供(https://nginx.org/en/enterprise.html)

#### Architecture and scalability｜架構和可擴展性

-   One master and several worker processes; worker processes run under an unprivileged user;  
    一個主行程和若干個工作流程；工作行程以非特權使用者身分執行；
-   [Flexible configuration](<031 [01.01 文件] nginx 設定範例.md>);  
    [靈活配置](<031 [01.01 文件] nginx 設定範例.md>) ;
-   [Reconfiguration](<026 [01.01 文件] 控制 Nginx.md#reconfiguration>) and [upgrade of an executable](<026 [01.01 文件] 控制 Nginx.md#upgrade>) without interruption of the client servicing;  
    [重新配置](<026 [01.01 文件] 控制 Nginx.md#reconfiguration>)和 [可執行檔的升級](<026 [01.01 文件] 控制 Nginx.md#upgrade>)不會中斷客戶端服務；
-   [Support](<030 [01.01 文件] 連接處理方式.md>) for kqueue (FreeBSD 4.1+), epoll (Linux 2.6+), /dev/poll (Solaris 7 11/99+), event ports (Solaris 10), select, and poll;  
    [支援](<030 [01.01 文件] 連接處理方式.md>)用於 kqueue（FreeBSD 4.1 +）、epoll（Linux 2.6 +）、/dev/poll（Solaris 7 11/99+）、事件連接埠（Solaris 10）、select 和 poll；
-   The support of the various kqueue features including EV\_CLEAR, EV\_DISABLE (to temporarily disable events), NOTE\_LOWAT, EV\_EOF, number of available data, error codes;  
    支援各種 kqueue 功能，包括EV \_CLEAR、 EV \_DISABLE（暫時停用事件）、 NOTE \_LOWAT、 EV \_EOF、可用資料數量、錯誤代碼；
-   The support of various epoll features including EPOLLRDHUP (Linux 2.6.17+, glibc 2.8+) and EPOLLEXCLUSIVE (Linux 4.5+, glibc 2.24+);  
    支援各種 epoll 功能，包括 EPOLLRDHUP（Linux 2.6.17 +，glibc 2.8 +）和 EPOLLEXCLUSIVE（Linux 4.5 +，glibc 2.24 +）；
-   sendfile (FreeBSD 3.1+, Linux 2.2+, macOS 10.5+), sendfile64 (Linux 2.4.21+), and sendfilev (Solaris 8 7/01+) support;  
    支援 sendfile（FreeBSD 3.1 +、Linux 2.2 +、macOS 10.5 +）、sendfile64（Linux 2.4.21 +）和 sendfilev（Solaris+ 8 7/011+）；
-   [File AIO](<056 [01.01.03 http] 模組 ngx_http_core_module.md#aio>) (FreeBSD 4.3+, Linux 2.6.22+);  
    [文件AIO](<056 [01.01.03 http] 模組 ngx_http_core_module.md#aio>) (FreeBSD 4.3 +, Linux 2.6.22 +);
-   [DIRECTIO](<056 [01.01.03 http] 模組 ngx_http_core_module.md#directio>) (FreeBSD 4.4+, Linux 2.4+, Solaris 2.6+, macOS);  
    [DIRECTIO](<056 [01.01.03 http] 模組 ngx_http_core_module.md#directio>) (FreeBSD 4.4 +, Linux 2.4 +, Solaris 2.6 +, macOS);
-   Accept-filters (FreeBSD 4.1+, NetBSD 5.0+) and TCP\_DEFER\_ACCEPT (Linux 2.4+) [support](<056 [01.01.03 http] 模組 ngx_http_core_module.md#listen>);  
    Accept-filters (FreeBSD 4.1 +, NetBSD 5.0 +) 和TCP \_DEFER\_ACCEPT (Linux 2.4 +) [支援](<056 [01.01.03 http] 模組 ngx_http_core_module.md#listen>) ;
-   10,000 inactive HTTP keep-alive connections take about 2.5M memory;  
    10,000 個不活躍的HTTP保持連線大約佔用 2.5M 記憶體；
-   Data copy operations are kept to a minimum.  
    資料複製操作被控制在最低限度。
