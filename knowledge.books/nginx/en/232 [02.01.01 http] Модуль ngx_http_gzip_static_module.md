# Модуль ngx_http_gzip_static_module

> 章節：[ru](<000 目錄.md#c-9>) › [docs](<000 目錄.md#c-10>) › [http](<000 目錄.md#c-11>)

## Модуль ngx\_http\_gzip\_static\_module

|   |
| --- |
| [Пример конфигурации](#example)<br>[Директивы](#directives)<br>     [gzip\_static](#gzip_static) |

Модуль `ngx_http_gzip_static_module` позволяет отдавать вместо обычного файла предварительно сжатый файл с таким же именем и с расширением “`.gz`”.

По умолчанию этот модуль не собирается, его сборку необходимо разрешить с помощью конфигурационного параметра `--with-http_gzip_static_module`.

#### Пример конфигурации

> ```
> gzip_static  on;
> gzip_proxied expired no-cache no-store private auth;
> ```

#### Директивы

<table>
<tr><th>Синтаксис:</th><td><code><strong>gzip_static</strong> <code>on</code> | <code>off</code> | <code>always</code>;</code></td></tr>
<tr><th>Умолчание:</th><td>gzip_static off;</td></tr>
<tr><th>Контекст:</th><td><code>http</code>, <code>server</code>, <code>location</code></td></tr>
</table>

Разрешает (“`on`”) или запрещает (“`off`”) проверку готового сжатого файла. При использовании также учитываются директивы [gzip\_http\_version](<231 [02.01.01 http] Модуль ngx_http_gzip_module.md#gzip_http_version>), [gzip\_proxied](<231 [02.01.01 http] Модуль ngx_http_gzip_module.md#gzip_proxied>), [gzip\_disable](<231 [02.01.01 http] Модуль ngx_http_gzip_module.md#gzip_disable>) и [gzip\_vary](<231 [02.01.01 http] Модуль ngx_http_gzip_module.md#gzip_vary>).

Со значением “`always`” (1.3.6) во всех случаях будет использоваться сжатый файл, без проверки поддержки на стороне клиента. Это полезно, если на диске всё равно нет несжатых файлов, или используется модуль [ngx\_http\_gunzip\_module](<230 [02.01.01 http] Модуль ngx_http_gunzip_module.md>).

Сжимать файлы можно с помощью программы `gzip` или совместимой с ней. Желательно, чтобы дата и время модификации исходного и сжатого файлов совпадали.
