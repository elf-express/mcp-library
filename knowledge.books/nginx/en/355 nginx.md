# nginx

## nginx

nginx ("*engine x*") is an HTTP web server, reverse proxy, content cache, load balancer, TCP/UDP proxy server, and mail proxy server. Originally written by [Igor Sysoev](http://sysoev.ru/en/) and distributed under the [2-clause BSD License](<354 page.md>). Enterprise distributions, commercial support and training are [available from F5, Inc.](<175 [01 en] nginx enterprise.md>)
