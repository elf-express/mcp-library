# Модуль ngx_http_autoindex_module

> 章節：[ru](<000 目錄.md#c-9>) › [docs](<000 目錄.md#c-10>) › [http](<000 目錄.md#c-11>)

## Модуль ngx\_http\_autoindex\_module

|   |
| --- |
| [Пример конфигурации](#example)<br>[Директивы](#directives)<br>     [autoindex](#autoindex)<br>     [autoindex\_exact\_size](#autoindex_exact_size)<br>     [autoindex\_format](#autoindex_format)<br>     [autoindex\_localtime](#autoindex_localtime) |

Модуль `ngx_http_autoindex_module` обслуживает запросы, оканчивающиеся слэшом (‘`/`’), и выдаёт листинг каталога. Обычно запрос попадает к модулю `ngx_http_autoindex_module`, когда модуль [ngx\_http\_index\_module](<236 [02.01.01 http] Модуль ngx_http_index_module.md>) не нашёл индексный файл.

#### Пример конфигурации

> ```
> location / {
>     autoindex on;
> }
> ```

#### Директивы

<table>
<tr><th>Синтаксис:</th><td><code><strong>autoindex</strong> <code>on</code> | <code>off</code>;</code></td></tr>
<tr><th>Умолчание:</th><td>autoindex off;</td></tr>
<tr><th>Контекст:</th><td><code>http</code>, <code>server</code>, <code>location</code></td></tr>
</table>

Разрешает или запрещает вывод листинга каталога.

<table>
<tr><th>Синтаксис:</th><td><code><strong>autoindex_exact_size</strong> <code>on</code> | <code>off</code>;</code></td></tr>
<tr><th>Умолчание:</th><td>autoindex_exact_size on;</td></tr>
<tr><th>Контекст:</th><td><code>http</code>, <code>server</code>, <code>location</code></td></tr>
</table>

Для [формата](#autoindex_format) HTML определяет, как выводить размеры файлов в листинге каталога: точно или округляя до килобайт, мегабайт и гигабайт.

<table>
<tr><th>Синтаксис:</th><td><code><strong>autoindex_format</strong> <code>html</code> | <code>xml</code> | <code>json</code> | <code>jsonp</code>;</code></td></tr>
<tr><th>Умолчание:</th><td>autoindex_format html;</td></tr>
<tr><th>Контекст:</th><td><code>http</code>, <code>server</code>, <code>location</code></td></tr>
</table>

Эта директива появилась в версии 1.7.9.

Задаёт формат вывода листинга каталога.

При использовании формата JSONP имя callback-функции задаётся в аргументе запроса `callback`. Если аргумент отсутствует или имеет пустое значение, то используется формат JSON.

Вывод в формате XML может быть преобразован при помощи модуля [ngx\_http\_xslt\_module](<271 [02.01.01 http] Модуль ngx_http_xslt_module.md>).

<table>
<tr><th>Синтаксис:</th><td><code><strong>autoindex_localtime</strong> <code>on</code> | <code>off</code>;</code></td></tr>
<tr><th>Умолчание:</th><td>autoindex_localtime off;</td></tr>
<tr><th>Контекст:</th><td><code>http</code>, <code>server</code>, <code>location</code></td></tr>
</table>

Для [формата](#autoindex_format) HTML определяет, в какой временной зоне выводить время в листинге каталога: в локальной или в UTC.
