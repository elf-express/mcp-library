# Module ngx_stream_mqtt_preread_module

> 章節：[en](<000 目錄.md#c-1>) › [docs](<000 目錄.md#c-2>) › [stream](<000 目錄.md#c-8>)

## Module ngx\_stream\_mqtt\_preread\_module

|   |
| --- |
| [Example Configuration](#example)<br>[Directives](#directives)<br>     [mqtt\_preread](#mqtt_preread)<br>[Embedded Variables](#variables) |

The `ngx_stream_mqtt_preread_module` module (1.23.4) allows extracting information from the CONNECT message of the Message Queuing Telemetry Transport protocol (MQTT) versions [3.1.1](https://docs.oasis-open.org/mqtt/mqtt/v3.1.1/mqtt-v3.1.1.html) and [5.0](https://docs.oasis-open.org/mqtt/mqtt/v5.0/mqtt-v5.0.html), for example, a username or a client ID.

> This module is available as part of our [commercial subscription](https://www.f5.com/products/nginx).

#### Example Configuration

> ```
> mqtt_preread on;
> return       $mqtt_preread_clientid;
> ```

#### Directives

<table>
<tr><th>Syntax:</th><td><code><strong>mqtt_preread</strong> <code>on</code> | <code>off</code>;</code></td></tr>
<tr><th>Default:</th><td>mqtt_preread off;</td></tr>
<tr><th>Context:</th><td><code>stream</code>, <code>server</code></td></tr>
</table>

Enables extracting information from the MQTT CONNECT message at the [preread](<165 [01.01.06 stream] How nginx processes a TCPUDP session.md#preread_phase>) phase.

#### Embedded Variables

`$mqtt_preread_clientid`

the `clientid` value from the CONNECT message

`$mqtt_preread_username`

the `username` value from the CONNECT message
