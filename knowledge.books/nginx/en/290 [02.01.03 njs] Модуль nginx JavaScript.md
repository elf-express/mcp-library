## Модуль nginx JavaScript

njs - это модуль nginx, который расширяет возможности сервера nginx с помощью сценариев JavaScript, позволяя создавать пользовательскую логику на стороне сервера и выполнять [другие задачи](#usecases).

nginx вызывает JavaScript-обработчики в фиксированном наборе [точек интеграции](https://nginx.org/ru/docs/njs/integration.html): в фазах обработки HTTP-запроса и ответа, фазах stream-сессии, при вычислении переменных и по таймеру. njs не является самостоятельной средой выполнения приложений: стартовый сценарий и собственный цикл событий отсутствуют, код JavaScript выполняется исключительно в рамках настроенного обработчика, вызванного nginx, по завершении которого управление возвращается nginx.

> Встроенный JavaScript-движок [njs](<289 [02.01.03 njs] Движок JavaScript.md#njs_engine>) объявлен устаревшим начиная с [1.0.0](https://nginx.org/ru/docs/njs/changes.html#njs1.0.0); в новых конфигурациях следует использовать движок [QuickJS](<289 [02.01.03 njs] Движок JavaScript.md#quickjs_engine>).

#### Сценарии использования

-   Комплексное управление доступом и проверка защиты при помощи njs до получения запроса сервером группы
-   Управление заголовками ответа

Подробнее о сценариях использования см. в [примерах](https://github.com/nginx/njs-examples/).

#### Базовый пример HTTP

Чтобы использовать njs в nginx, необходимо:

-   [установить](<291 [02.01.03 njs] Загрузка и установка.md>) njs
    
-   создать файл сценария njs, например `http.js`. Описание свойств и методов njs см. в [справочнике](https://nginx.org/ru/docs/njs/reference.html).
    
    > ```js
    > function hello(r) {
    >     r.return(200, "Hello world!");
    > }
    > 
    > export default {hello};
    > ```
    
-   в файле `nginx.conf` включить модуль [ngx\_http\_js\_module](<238 [02.01.01 http] Модуль ngx_http_js_module.md>) и указать директиву [js\_import](<238 [02.01.01 http] Модуль ngx_http_js_module.md#js_import>) с файлом сценария `http.js`:
    
    > ```
    > load_module modules/ngx_http_js_module.so;
    > 
    > events {}
    > 
    > http {
    >     # начиная с 0.9.1
    >     js_engine qjs;
    > 
    >     js_import http.js;
    > 
    >     server {
    >         listen 8000;
    > 
    >         location / {
    >             js_content http.hello;
    >         }
    >     }
    > }
    > ```
    

Также доступна отдельная утилита [командной строки](<287 [02.01.03 njs] Интерфейс командной строки.md>), которая может использоваться независимо от nginx для разработки и отладки njs.
