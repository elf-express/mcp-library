> 章節：[en](<000 目錄.md#c-1>) › [docs](<000 目錄.md#c-2>) › [njs](<000 目錄.md#c-7>)

## nginx JavaScript module

njs is an nginx module that extends the server's functionality through JavaScript scripting, enabling the creation of custom server-side logic and [more](#usecases).

nginx calls JavaScript handlers at a fixed set of [integration points](https://nginx.org/en/docs/njs/integration.html): HTTP request and response processing phases, stream session phases, variable evaluation, and periodic timers. njs is not a standalone application runtime: it has no start-up script and no event loop of its own, JavaScript code runs only when nginx invokes a configured handler, and control returns to nginx once the handler completes.

> The built-in [njs](<132 [01.01.05 njs] JavaScript Engine.md#njs_engine>) JavaScript engine is deprecated since [1.0.0](<129 [01.01.05 njs] Changes.md#njs1.0.0>); new configurations should use the [QuickJS](<132 [01.01.05 njs] JavaScript Engine.md#quickjs_engine>) engine.

#### Basic HTTP Example

To use njs in nginx:

-   [install](<134 [01.01.05 njs] Download and install.md>) njs
    
-   create an njs script file, for example, `http.js`. See [Reference](<137 [01.01.05 njs] Reference.md>) for the list of njs properties and methods.
    
    > ```js
    > function hello(r) {
    >     r.return(200, "Hello world!");
    > }
    > 
    > export default {hello};
    > ```
    
-   in the `nginx.conf` file, enable [ngx\_http\_js\_module](<073 [01.01.03 http] Module ngx_http_js_module.md>) module and specify the [js\_import](<073 [01.01.03 http] Module ngx_http_js_module.md#js_import>) directive with the `http.js` script file:
    
    > ```
    > load_module modules/ngx_http_js_module.so;
    > 
    > events {}
    > 
    > http {
    >     # since 0.9.1
    >     js_engine qjs;
    > 
    >     js_import http.js;
    > 
    >     server {
    >         listen 8000;
    > 
    >         location / {
    >             js_content http.hello;
    >         }
    >     }
    > }
    > ```
    

There is also a standalone [command line](<130 [01.01.05 njs] Command-line interface.md>) utility that can be used independently of nginx for njs development and debugging.
