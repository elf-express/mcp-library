# Сообщение “ ‘sys_errlist’ is deprecated; use ‘strerror’ or ‘strerror_r’ instead ”

> 章節：[ru](<000 目錄.md#c-9>) › [docs](<000 目錄.md#c-10>)

## Сообщение “ ‘sys\_errlist’ is deprecated; use ‘strerror’ or ‘strerror\_r’ instead ”

При сборке nginx версий 0.7.66, 0.8.35 и выше на Linux выводится предупреждение:

> ```
> warning: `sys_errlist' is deprecated;
>     use `strerror' or `strerror_r' instead
> warning: `sys_nerr' is deprecated;
>     use `strerror' or `strerror_r' instead
> ```

Это нормально: nginx вынужден использовать устаревшие sys\_errlist\[\] и sys\_nerr в обработчиках сигналов, потому что функции strerror() и strerror\_r() не являются Async-Signal-Safe, и их нельзя использовать в обработчиках сигналов.
