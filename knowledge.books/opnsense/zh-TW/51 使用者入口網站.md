## [準備](#id1)

為了有效地使用此模組，請確保允許使用者在本地網路上使用使用者名稱和密碼登入 OPNsense。

## [一般](#id2)

[![../../_images/user_portal.png](<../images/4669beee-user_portal.png>)](https://docs.opnsense.org/_images/user_portal.png)

此入口網站取代了簡單的使用者密碼選單（可在大廳 ‣ 密碼中找到），並提供自助服務支援的附加功能。

根據配置，使用者可以在此處更改密碼和語言、下載並重新產生一次性密碼令牌以及存取他們有權存取的實例的 OpenVPN 設定檔。

注意事項

可見選項卡取決於管理部分中配置的存取權限。

## [管理](#id3)

在 System ‣ Settings ‣ Portal Admin 下，您將找到入口網站的管理部分，其中包括通用帳戶設定和 OpenVPN 執行個體存取。

### [設定](#id4)

在這裡您可以找到門戶的基本設置

|選項|說明 |
| --- | --- |
|允許創建OTP代幣 |選擇用戶應屬於哪個群組來管理自己的令牌 |
|使用者入口網站歡迎資訊 |歡迎訊息（第一個選項卡內容），可能包括 html 格式的文字。 |

### [OpenVPN](#id5)

OpenVPN 標籤顯示一個網格，您可以在其中新增使用者應有權存取的實例，它包含標準 OpenVPN 匯出模組中也提供的大部分設定。

|選項|說明 |
| --- | --- |
|會員|選擇使用者應屬於哪個群組來下載設定檔 |
|伺服器實例|我們授予存取權限的實例 |
|憑證有效期限（天）|憑證的有效期限，過期後使用者將無法再登入 |
|憑證金鑰類型 |要包含在設定檔中的憑證類型 |
|證書摘要演算法 |用於產生證書的摘要演算法|
|匯出範本 |使用者將下載的文件類型 |
|主機名稱 |用於聯絡此防火牆的主機名稱或 IP 位址 |
|啟用靜態挑戰（OTP）|單獨向使用者詢問其一次性密碼令牌（而非作為密碼的一部分）。 |
|自訂配置 |自訂配置，將在輸出檔案中傳回而不進行修改。 |
|描述 |向使用者顯示此實例下載的描述 |

提示

如果應允許使用者為相同服務下載多種檔案格式，您可以複製該條目。只需對每個條目使用不同的描述即可。

## [設定範例](#id6)

以下配置概述了一個非常常見的業務案例，具有以下要求：

用戶應該得到：

> -   帶有使用者憑證的 OpenVPN 設定文件
>     
> -   使用TOTP進行雙重認證
>     
> -   存取自助服務入口網站來管理其密碼、OTP 令牌和 OpenVPN 設定文件
>     

### [1\.配置預設群組](#id7)

我們將建立三個群組來控制對使用者入口網站、OTP 令牌和 OpenVPN 設定檔的存取。

前往 System ‣ Access ‣ Groups 並新增以下群組：

**使用者\_default\_priv**

| **選項**|**描述** |
| --- | --- |
| **群組名稱** | `user_default_priv` |
| **特權** | `Lobby: Password` |

-   按**儲存**並新增下一個
    

注意事項

這允許成員訪問用戶門戶並管理他們的密碼。

**使用者\_otp\_priv**

| **選項**|**描述** |
| --- | --- |
| **群組名稱** | `user_otp_priv` |

-   按**儲存**並新增下一個
    

注意事項

該群組不需要任何權限，我們將在後面的步驟中將其用於使用者入口網站配置，以允許成員存取OTP令牌。

**使用者\_ovpn\_priv**

| **選項**|**描述** |
| --- | --- |
| **群組名稱** | `user_ovpn_priv` |

-   按**儲存**並新增下一個
    

注意事項

該群組不需要任何權限，我們將在後面的步驟中將其用於使用者入口網站配置，以允許成員存取 OpenVPN 實例。

提示

您可以在此處建立多個群組，例如`user_ovpn_priv_sales`, `user_ovpn_priv_admin`，以便您可以控制對多個 OpenVPN 執行個體的存取。

### [2\.配置用戶（入職）](#id8)

現在我們需要一個將成為我們創建的群組的成員的使用者。

前往 System ‣ Access ‣ User 並新增以下使用者：

| **選項**|**描述** |
| --- | --- |
| **使用者名稱** | `john` |
| **密碼** |設定密碼 |
| **團體會員** | `user_default_priv, user_otp_priv, user_ovpn_priv` |

-   按**儲存**
    

注意事項

不需要建立使用者證書，使用者入口網站將在使用者下載 OpenVPN 設定時自動為使用者建立證書。使用者可以自己建立的OTP令牌也是如此。

提示

使用LDAP認證伺服器時，不需要手動建立使用者。前往 System ‣ Access ‣ Servers 並啟用自動使用者建立。對於預設組，選擇 `user_default_priv`。將群組`user_otp_priv`和`user_ovpn_priv`加入到LDAP伺服器上的使用者。請注意，所有群組必須手動創建，並在系統 ‣ 存取 ‣ 群組和 LDAP 伺服器之間共用相同的名稱。

### [3\.設定驗證伺服器](#id9)

我們需要兩種伺服器類型：

> -   預設伺服器`Local Database`將允許使用者透過使用者入口網站進行身份驗證。
>     
> -   額外的伺服器`Local Database + TOTP`將用於OpenVPN。
>     

前往 System ‣ Access ‣ Servers 並新增以下附加伺服器：

| **選項**|**描述** |
| --- | --- |
| **描述性名稱** | `Local Database + TOTP` |
| **類型** | `Local + Timebased One Time Password` |

-   按**儲存**
    

注意

如果您在系統 ‣ 設定 ‣ 管理 中將驗證伺服器設定為 `Local Database + TOTP` 選項，則在沒有管理員事先協助的情況下，使用者無法在使用者入口網站中管理自己的 OTP 令牌；因為他們需要一個 OTP 令牌進行驗證，但可能還沒有。特別是如果您選擇 LDAP 變體並擁有龐大的用戶群，如果一切都應該完全自動化，請考慮這一點。這就是為什麼我們建議使用兩種身份驗證伺服器類型，以便使用者能夠在不使用TOTP的情況下向使用者入口網站進行身份驗證。

### [4\.設定OpenVPN實例](#id10)

前往 VPN ‣ OpenVPN ‣ 實例並新增實例。

您可以使用以下部分作為指導：[設定SSL VPN Road Warrior](https://docs.opnsense.org/manual/how-tos/sslvpn_instance_roadwarrior.html)

以下是遵循該指南時要在實例配置中進行的調整：

| **選項**|**描述** |
| --- | --- |
| **描述** | `user_ovpn_priv` |
| **驗證** | `Local Database + TOTP` |

注意事項

將實例的描述設定為先前建立的群組名稱可以使使用者入口網站中的管理更加簡單。

### [5\.設定使用者入口網站](#id11)

進入 System ‣ Settings ‣ Portal Admin 並設定以下選項：

**設定**

| **選項**|**描述** |
| --- | --- |
| **允許創建OTP代幣** | `user_otp_priv` |

-   按 **應用** 並轉到下一個選項卡
    

注意事項

這允許`user_otp_priv`群組中的任何使用者存取使用者入口網站中的OTP自助服務。

**開放VPN**

| **選項**|**描述** |
| --- | --- |
| **成員** | `user_ovpn_priv` |
| **伺服器實例** | `[Server] user_ovpn_priv` |
| **匯出模板** | `Archive` |
| **靜態挑戰** | `X` |
| **主機名稱** |您的防火牆的FQDN公開有A記錄DNS |
| **描述** | `user_ovpn_priv_archive` |

如果您想提供例如黏度作為替代下載選項，請按**儲存**並新增另一個選擇

| **選項**|**描述** |
| --- | --- |
| **成員** | `user_ovpn_priv` |
| **伺服器實例** | `[Server] user_ovpn_priv` |
| **匯出模板** | `Viscosity (visc)` |
| **靜態挑戰** | `X` |
| **主機名稱** |您的防火牆的FQDN公開有A記錄DNS |
| **描述** | `user_ovpn_priv_viscosity` |

-   按**儲存**並**應用**
    

提示

啟用靜態挑戰將建立一個彈出窗口，要求提供 OTP 令牌，以便使用者不必手動將其與使用者密碼合併。

注意事項

您可以建立多個實例並選擇哪個群組可以下載哪個配置。

注意

請牢記證書的有效期限。使用者無法更新自己的證書，管理員必須為他們執行此操作。或者，在此處選擇非常高的壽命，該壽命在您之前創建的 CA 範圍內。例如，如果CA的有效期為10年，則可以將證書有效期設定為5年。如果您按照本指南所述使用一次性密碼部署額外的使用者身份驗證，那麼較長的生命週期應該沒問題。

### [6\.測試使用者入口](#id12)

現在初始配置已完成，測試使用者入口網站。

檢查系統 ‣ 設定 ‣ 管理 `Listen Interfaces` 是否位於任何一個上，或包含您的使用者將用於存取使用者入口網站的介面。不要忘記建立允許從此網路存取 WebGUI 的防火牆規則。

注意

不建議無限制地允許從公共網路存取WebGUI。

如果您已正確登入 WebGUI 管理員，請開啟其他瀏覽器或隱身標籤。開啟您用於以管理員身分登入的同一個URL，但使用您先前建立的使用者 (john) 登入。

現在您將看到使用者入口網站作為登入頁面。在這裡，您在前面的步驟中建立的配置將顯示其結果。

使用者將能夠更改密碼，產生自己的OTP令牌，並下載OpenVPN設定檔；它也會自動產生他們的使用者憑證。

提示

可以透過重複入職步驟來建立其他使用者。

### [7\.刪除存取權限（Offboarding）](#id13)

前面的步驟概述了大部分入職流程。但是，如果必須刪除使用者存取權限該怎麼辦？

進入系統‣訪問‣用戶並刪除所有`Group memberships`和`Privileges`，重新產生`OTP seed`並設定`Disabled`標誌。儲存後，使用者權限將被取消，即使重新啟用，使用者也無法提升權限，因為他們無法登入使用者門戶，也無法使用OTP令牌建立OpenVPN連線。

注意

如果您使用 LDAP 驗證伺服器，則必須在該伺服器上停用使用者。請記住群組成員身份，以及您可能設定的目前預設群組。

進一步，使用戶證書失效。

前往 System ‣ Trust ‣ Replication 並編輯您為 OpenVPN 實例建立的 CA。如果還沒有 CRL，請透過設定描述並按 **套用** 來建立一個。

然後，再編輯CA，選擇一個`Revocation per type`，例如`Unspecified`，在這裡選擇建立的使用者憑證。申請後，該證書將不再有效。

注意

從GUI刪除憑證不會使其失效。您必須使用吊銷元件將撤銷發佈到 OpenVPN 執行個體。
