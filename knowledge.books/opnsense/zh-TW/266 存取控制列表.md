# 存取控制列表

存取控制列表

![../../_images/acl-finger-print.jpg](<../images/8ef22736-acl-finger-print.jpg>)

## 概述

ACL系統的目標是為遺留程式碼提供向後相容性，並能夠擴展它以添加新功能，而無需重新實現整個系統。

以下步驟決定使用者是否可以存取頁面：

1.  儲存在 system/user 的 config.xml 檔案中的使用者可以設定對該顯式條目有效的“有效權限”，儲存在 <priv/> 部分中
    
2.  該使用者的一個或多個群組，儲存在系統/群組中，其中也包含 priv 部分。
    
3.  將邏輯 acl 鍵連結到 uri 模式的 XML 檔案 (`ACL.xml`)
    

大多數舊元件的存取控制儲存在 models/OPNsense/Core/ACL/ACL.xml 中，大多數新元件在屬於該元件的模型中加入自己的 ACL。所有儲存的`ACL.xml`檔案組合起來決定了使用者/群組管理器中可用的全套選項。沒有明確要求哪個型號服務哪個ACL。

注意事項

當需要單一 ACL 來匹配一組顯式元件（頁面/api 端點）時，可以輕鬆地為模組添加 ACL 文件，而無需進一步的邏輯。

## ACL格式

每個 ACL 檔案都儲存在模型位置 (/usr/local/opnsense/mvc/app/models/)，其中 `ACL.xml` 檔案儲存在位置 \[VENDOR\]/\[MODULE\]/ACL/ACL.xml 中。文件格式如下：

```xml
<acl>
  <my-unique-acl-key>             <!-- as stored for the user/group -->
     <name>My ACL name</name>     <!-- name visible in the user manager -->
     <patterns>
        <pattern>path/to/my/module</pattern>      <!-- list of uri's this ACL should unlock. -->
     </patterns>
  </my-unique-acl-key>
</acL>
```

## PHP的用法

使用PHP的系統相當簡單：

```
$acl = new OPNsense\Core\ACL();
if ( $acl->isPageAccessible("user", "/firewall_rules.php") ) {
  print ( "/firewall_rules.php is accessible" ) ;
}
```

## 在 Volt 模板中的用法

ACL方案綁定到預設的UI控制器，可以透過acl關鍵字來使用：

```
{% if acl.isPageAccessible(session.get('Username'),subMenuItem.Url)  %}
  this page is accessible
{% endif %}
```
