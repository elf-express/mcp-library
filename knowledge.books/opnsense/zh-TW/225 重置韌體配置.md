# 重置韌體配置

> 章節：[Troubleshooting](<000 目錄.md#c-50>) › [Topics](<000 目錄.md#c-51>)

如果`config.xml`檔案中的韌體配置損壞，我們可以使用以下命令重設該部分配置（在控制台上或透過SSH執行）：

```
pluginctl -f system.firmware
```

此處顯示目前儲存的資料並詢問是否要刪除，選擇`Y`刪除該部分，然後返回「系統」‣「韌體」部分重新儲存配置。

注意事項

如果我們的工廠留下了一個快取文件，該文件始終保持「factory-」插件可見，您可以使用以下命令安全地刪除該引用：

`rm /usr/local/opnsense/version/factory-*`
