# 使用網格模組和插件

> 章節：[Development Manual](<000 目錄.md#c-52>) › [Examples](<000 目錄.md#c-62>)

建立網格表單

[![../../_images/grid-sample.png](<../images/e6b9bb05-grid-sample.png>)](https://docs.opnsense.org/_images/grid-sample.png)

## 目標

本範例的目的是展示如何使用我們框架中的各種元件在 OPNsense 中建立資料網格。

如果您還沒有閱讀過 HelloWorld 範例，我們建議您先閱讀它。本範例假設您已經掌握了基礎知識。

本模組我們選擇的主題是電子郵件地址的基本列表，您應該能夠新增、刪除和變更其中的項目。

有關網格系統的詳細文件可在 [UIBootgrid](<262 UI引導網格.md>)中找到。

## 模型

我們的範例從一個模型開始，該模型是透過建立一個繼承自`BaseModel` php 類別和一個包含實際模型定義的XML檔案來建構的。

/usr/local/opnsense/mvc/app/models/OPNsense/GridExample/GridExample.php

```php
<?php
namespace OPNsense\GridExample;

use OPNsense\Base\BaseModel;

class GridExample extends BaseModel
{
}
```

/usr/local/opnsense/mvc/app/models/OPNsense/GridExample/GridExample.xml

```xml
<model>
    <mount>//OPNsense/GridExample</mount>
    <description>
        the OPNsense "GridExample" application
    </description>
    <items>
        <addresses>
            <address type="ArrayField">
                <enabled type="BooleanField">
                    <default>1</default>
                    <Required>Y</Required>
                </enabled>
                <email type="EmailField">
                    <Required>Y</Required>
                </email>
                <schedule type="OptionField">
                    <Default>wly</Default>
                    <Required>Y</Required>
                    <OptionValues>
                        <dly>Daily</dly>
                        <wly>Weekly</wly>
                        <mly>Monthly</mly>
                    </OptionValues>
                </schedule>
                <description type="DescriptionField"/>
            </address>
        </addresses>
    </items>
</model>
```

請注意XML中的`ArrayField`類型，這是一個特殊的嵌套項目欄位類型，它會自動包含一個內部 UUID，以便在寫入磁碟時輕鬆引用。其他兩種欄位類型也在先前的 HelloWorld 範例中使用。所有預先安裝的類型都可以在 [GitHub](https://github.com/opnsense/core/tree/master/src/opnsense/mvc/app/models/OPNsense/Base/FieldTypes)的欄位類型目錄中找到。

## API控制器

`ApiMutableModelControllerBase`類別支援大多數模型操作，所有`*Base`方法都體現了對新模型項或現有模型項進行操作的共享功能。

下面的範例使用基本方法連接我們需要的所有操作，並將它們連接到以`Item`結尾的端點：

-   searchItemAction 會查詢您配置中的項目。
    
-   getItemAction，取得現有記錄（或傳回包含所有預設值的空白記錄）
    
-   addItemAction，新增記錄
    
-   setItemAction，更新記錄
    
-   delItemAction，刪除記錄
    
-   toggleItemAction，切換 [0|1] 「啟用」屬性（請參閱模型中的啟用`BooleanField` ）
    

/usr/local/opnsense/mvc/app/controllers/OPNsense/GridExample/Api/SettingsController.php

```php
namespace OPNsense\GridExample\Api;

use \OPNsense\Base\ApiMutableModelControllerBase;

class SettingsController extends ApiMutableModelControllerBase
{
    protected static $internalModelName = 'gridexample';
    protected static $internalModelClass = 'OPNsense\GridExample\GridExample';

    public function searchItemAction()
    {
        return $this->searchBase("addresses.address", null, "email");
    }

    public function setItemAction($uuid)
    {
        return $this->setBase("address", "addresses.address", $uuid);
    }

    public function addItemAction()
    {
        return $this->addBase("address", "addresses.address");
    }

    public function getItemAction($uuid = null)
    {
        return $this->getBase("address", "addresses.address", $uuid);
    }

    public function delItemAction($uuid)
    {
        return $this->delBase("addresses.address", $uuid);
    }

    public function toggleItemAction($uuid, $enabled = null)
    {
        return $this->toggleBase("addresses.address", $uuid, $enabled);
    }
}
```

所有方法的參數至少包含要操作的`ArrayField`類型的根，並且在操作涉及表單資料的情況下，還包含用作容器中傳輸資料的根屬性的名稱。

例如，getItem (/api/gridexample/settings/getItem/my-uuid-id) 會傳回類似這樣的回應（已高亮顯示容器部分）：

```
{
  "address": {
    "enabled": "1",
    "email": "test@example.com"
    "description": "Test Address"
  }
}
```

## 定義對話框項目

要編輯數據，我們需要定義哪些欄位應該呈現給使用者以及它們的格式。在一個簡單的佈局中，id 欄位引用要對應的實際資料點（例如`address.enabled` ），這與 API 端點傳回的內容完全一致。

建立網格時，同一個表單會為每個欄位 ID 建立列。網格列的格式可以透過`grid_view`標籤來控制。在這個標籤內，我們可以定義`width`, `type`, `formatter`, `sequence`, `visible`, `ignore`和其他標籤。

/usr/local/opnsense/mvc/app/controllers/OPNsense/GridExample/forms/dialogAddress.xml

```xml
<form>
    <field>
        <id>address.enabled</id>
        <label>Enabled</label>
        <type>checkbox</type>
        <help>Enable this address.</help>
        <grid_view>
            <width>6em</width>
            <type>boolean</type>
            <formatter>rowtoggle</formatter>
        </grid_view>
    </field>
    <field>
        <id>address.email</id>
        <label>Email</label>
        <type>text</type>
        <help>Enter the email address.</help>
    </field>
    <field>
        <id>address.schedule</id>
        <label>Schedule</label>
        <type>dropdown</type>
        <help>Select your preferred schedule.</help>
    </field>
    <field>
        <id>address.description</id>
        <label>Description</label>
        <type>text</type>
        <help>Enter an optional description.</help>
        <grid_view>
            <visible>false</visible>
        </grid_view>
    </field>
</form>
```

## UI控制器

使用者介面控制器設定要使用的範本（視圖），並從先前定義的 xml 檔案中收集對話方塊表單和網格屬性。

/usr/local/opnsense/mvc/app/controllers/OPNsense/GridExample/IndexController.php

```php
namespace OPNsense\GridExample;

class IndexController extends \OPNsense\Base\IndexController
{
    public function indexAction()
    {
        $this->view->pick('OPNsense/GridExample/index');
        $this->view->formDialogAddress = $this->getForm("dialogAddress");
        $this->view->formGridAddress = $this->getFormGrid("dialogAddress");
    }
}
```

## 建構伏特模板

我們提供了一個通用的網格系統，如 [UIBootgrid](<262 UI引導網格.md>)中所述。要在我們的模板（視圖）中使用它，我們定義了三個不同的區塊。

首先，我們使用`UIBootgrid()`綁定一個 id 為`{{formGridAddress['table_id']}}`的表格。然後，我們定義該表格，它將轉換為動態可搜尋的網格，並連結我們的對話方塊內容。網格（base\_bootgrid\_table）和對話框（base\_dialog）都使用 volt `partial()` 。

基本的「UIBootgrid」綁定連接了我們先前在API控制器中定義的所有操作，還有更多選項可用，但對於此用例來說不需要這些選項。

我們的編輯對話方塊是預先編寫的，以便 JavaScript 程式碼可以在需要時開啟靜態定義的表單，最後一個高亮顯示的程式碼區塊負責處理這一點。此局部視圖使用三個參數：透過控制器連接的包含所有表單條目的變數、表單名稱（id） `'id':formGridAddress['edit_dialog_id']` （在表格`{{formGridAddress['table_id']}}`中引用）以及對話方塊的標題。

若要套用更改，可以使用 (base\_apply\_button) volt `partial()` ，它會呼叫 reconfigure API端點。事件監聽器附加到 SimpleActionButton()，這是一個用於大多數重新配置用例的共用 JavaScript 函數。

每當網格進行變更時，（base\_apply\_button）將自動顯示資料變更對話方塊。

/usr/local/opnsense/mvc/app/views/OPNsense/GridExample/index.volt

```html
<script>
    $(document).ready(function() {
        $("#{{formGridAddress['table_id']}}").UIBootgrid(
            {   search:'/api/gridexample/settings/search_item/',
                get:'/api/gridexample/settings/get_item/',
                set:'/api/gridexample/settings/set_item/',
                add:'/api/gridexample/settings/add_item/',
                del:'/api/gridexample/settings/del_item/',
                toggle:'/api/gridexample/settings/toggle_item/'
            }
        );

        $("#reconfigureAct").SimpleActionButton();
    });

</script>

<div class="content-box">
    {{ partial('layout_partials/base_bootgrid_table', formGridAddress) }}
</div>
{{ partial('layout_partials/base_apply_button', {'data_endpoint': '/api/gridexample/service/reconfigure'}) }}
{{ partial("layout_partials/base_dialog",['fields':formDialogAddress,'id':formGridAddress['edit_dialog_id'],'label':lang._('Edit address')])}}
```

## 服務控制器

本範例中的服務控制器是一個存根，當透過 SimpleActionButton() 呼叫`/api/gridexample/service/reconfigure`時，它會產生一個通用的狀態回應。

/usr/local/opnsense/mvc/app/controllers/OPNsense/GridExample/Api/ServiceController.php

```php
namespace OPNsense\GridExample\Api;

use OPNsense\Base\ApiControllerBase;

class ServiceController extends ApiControllerBase
{
    public function reconfigureAction()
    {
        sleep(1);
        return ["status" => "ok"];
    }
}
```
