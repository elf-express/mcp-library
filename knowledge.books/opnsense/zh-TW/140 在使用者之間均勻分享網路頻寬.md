# 在使用者之間均勻分享網路頻寬

> 章節：[Firewall](<000 目錄.md#c-26>) › [Traffic Shaping](<000 目錄.md#c-29>) › [Configuration / How-tos](<000 目錄.md#c-30>)

對於此範例，我們假設網路連線為 10 Mbps 下載和 1 Mbps 上傳，我們希望在所有使用者之間均勻共用。

[![](<../images/5edbe2b6-nwdiag-3a3b295df95f5f47b05bd5247ff3374f6.png>)](https://docs.opnsense.org/_images/nwdiag-3a3b295df95f5f47b05bd5247ff3374f6471bbc9.png)

均勻取樣頻寬整形

首先前往 Firewall ‣ Shaper ‣ Pipes。

## 步驟 1 - 建立上傳和下載管道

在 **管道**標籤上，按一下右下角的**+**按鈕。將彈出一個空的**編輯管道**螢幕。

建立上傳管道

|   |   |   |
| --- | --- | --- |
| **啟用** |已檢查 | *檢查以啟用管道* |
| **頻寬** | 1 | *所需頻寬的數值* |
| **頻寬指標** |兆位元/秒 | *與數值一起使用的量測* |
| **面具** |空 | *選擇共用頻寬的目的地* |
| **描述** | PipeUp-1Mbps | *自由字段，輸入描述性內容* |

建立下載管道

|   |   |   |
| --- | --- | --- |
| **啟用** |已檢查 | *檢查以啟用管道* |
| **頻寬** | 10 | 10 *所需頻寬的數值* |
| **頻寬指標** |兆位元/秒 | *與數值一起使用的量測* |
| **面具** |空 | *選擇共用頻寬的目的地* |
| **描述** | PipeDown-10Mbps | *自由字段，輸入描述性內容* |

## 第 2 步 - 建立隊列

在 **佇列**標籤上，按一下右下角的**+**按鈕。將彈出一個空的**編輯隊列**螢幕。

建立上傳隊列

|   |   |   |
| --- | --- | --- |
| **啟用** |已檢查 | *檢查以啟用管道* |
| **管道** | PipeUp-1Mbps | *選擇我們的管道* |
| **重量** | 100 | 100 *與數值一起使用的權重* |
| **面具** |來源 | *每個來源都會創建一個匹配* |
| **描述** | QueueUp-1Mbps | *自由字段，輸入描述性內容* |

建立下載隊列

|   |   |   |
| --- | --- | --- |
| **啟用** |已檢查 | *檢查以啟用管道* |
| **管道** | PipeDown-10Mbps | *選擇我們的管道* |
| **重量** | 100 | 100 *與數值一起使用的權重* |
| **面具** |目的地 | *每個來源都會創建一個匹配* |
| **描述** |佇列下降-10Mbps | *自由字段，輸入描述性內容* |

## 第 3 步 - 建立規則

在 **規則**標籤上，按一下右下角的**+**按鈕。將彈出一個空的**編輯規則**螢幕。

為定向到互聯網（上傳）的流量建立規則。

|   |   |   |
| --- | --- | --- |
| **序列** | 11 | 11 *自動產生編號，僅在需要時覆寫* |
| **介面** | WAN | *選擇連接到網際網路的介面* |
| **原型** | ip | *選擇協議，在我們的範例中為IP* |
| **來源** | 192.168.1.0/24 | *要整形的源IP，選擇LAN網絡* |
| **來源端口** |任何| *要塑造的來源端口，保留任何* |
| **目的地** |任何| *目的地要塑造，留下任意*|
| **目標連接埠** |任何| *如果是靜態的，則使用任何目標連接埠* |
| **目標** | QueueUp-1Mbps | *選擇上傳1Mbps佇列* |
| **描述** |形狀上傳 | *輸入描述性名稱* |

為來自 Internet 的流量建立規則（下載）。

|   |   |   |
| --- | --- | --- |
| **序列** | 21 | 21 *自動產生編號，僅在需要時覆寫* |
| **介面** | WAN | *選擇連接到網際網路的介面* |
| **原型** | ip | *選擇協議，在我們的範例中為IP* |
| **來源** |任何| *來源位址，任意留*|
| **來源端口** |任何| *要塑造的來源端口，保留任何* |
| **目的地** | 192.168.1.0/24 | *要塑造的目的地IP，選擇LAN網絡* |
| **目標端口** |任何| *目的港自行塑造，任意留任*|
| **目標** |佇列下降-10Mbps | *選擇下載 10 Mbps 佇列* |
| **描述** |形狀下載 | *輸入描述性名稱* |

現在按![apply](<../images/ca819e9a-applybtn.png>)啟動流量整形規則。
