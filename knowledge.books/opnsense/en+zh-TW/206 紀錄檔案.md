# Log Files｜紀錄檔案

> 章節：[Services](<000 目錄.md#c-40>)

When troubleshooting problems with your firewall, it is very likely you have to check the logs available on your system. In the UI of OPNsense, the log files are generally grouped with the settings of the component they belong to. The log files can be found here:

在排查防火牆問題時，您很可能需要檢查系統上的日誌。在 OPNsense 的UI目錄下，日誌檔案通常會根據其所屬組件的設定進行分組。日誌檔案位於以下位置：

|   |   |   |
| --- | --- | --- |
| **Captive Portal**<br>**強制入口網站** | Services ‣ Captive Portal ‣ Log File<br>服務 ‣ 強制入口網站 ‣ 記錄檔 | *Events from Captive Portal go here*<br>*來自強制入口網站的事件記錄在此* |
| **DHCPv4** | Services ‣ DHCPv4 ‣ Log File<br>服務 ‣ DHCPv4 ‣ 日誌檔案 | *DHCP events get logged here*<br>* DHCP事件記錄在此* |
| **Dnsmasq DNS** | Services ‣ Dnsmasq DNS ‣ Log File<br>服務 ‣ Dnsmasq DNS ‣ 日誌檔案 | *The DNSmasq Forwarder logs*<br>*DNSmasq 轉發器日誌* |
| **HAProxy** | Services ‣ HAProxy ‣ Log File<br>服務 ‣ HAProxy ‣ 日誌檔案 | *The logs of the Reverse Proxy*<br>*反向代理的日誌* |
| **Intrusion Detection**<br>**入侵偵測** | Services ‣ Intrusion Detection ‣ Log File<br>服務 ‣ 入侵偵測 ‣ 日誌檔案 | *Suricata Logs are here*<br>*Suricata 日誌在此* |
| **Network Time**<br>**網路時間** | Services ‣ Network Time ‣ Log File<br>服務 ‣ 網路時間 ‣ 日誌檔案 | *NTP daemon logs*<br>* NTP守護程式日誌* |
| **Unbound DNS** | Services ‣ Unbound DNS ‣ Log File<br>服務 ‣ Unbound DNS ‣ 日誌檔案 | *Unbound resolver logs can be found here*<br>*Unbound 解析器日誌可在此處找到* |
| **Web Proxy**<br>**Web代理** | Services ‣ Web Proxy ‣ Log File<br>服務 ‣ Web代理 ‣ 日誌檔 | *Squid access.log, store.log and cache.log*<br>*Squid access.log、store.log 與 cache.log* |
