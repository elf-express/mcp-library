# 25.10 Series｜25.10系列

> 章節：[Releases](<000 目錄.md#c-1>) › [Business Edition](<000 目錄.md#c-3>)

The OPNsense business edition transitions to this 25.10 release including revamped frontend grid UI, experimental privilege separation for the GUI, a new and improved firewall automation GUI, performance enhancements especially for numerous aliases being used at once, OpenID Connect integration, captive portal backend rewrite, Greek as a new language, FreeBSD 14.3 plus much more.

OPNsense 商業版過渡到此25.10版本，包括改進的前端網格UI、GUI的實驗性權限分離、新的和改進的防火牆自動化GUI、性能增強（特別是針對同時使用的多個人名14.3 還有更多。

Please make sure to read the migration notes before upgrading.

升級前請務必閱讀遷移說明。

Download link is as follows. An installation guide [\[1\]](<55 初始安裝和配置.md>) and the checksums for the images can be found below as well.

下載連結如下。安裝指南 [\[1\]]( https://docs.opnsense.org/manual/install.html ) 和映像校驗和也如下所示。

[https://downloads.opnsense.com/](https://downloads.opnsense.com/)

Migration notes, known issues and limitations:

遷移說明、已知問題與限制：

-   The captive portal implementation moves from IPFW to PF. Check the technical details first, especially regarding the new ruleset behaviours. [\[45\]](<200 強制入口網站和 GuestNET.md>)  
    強制門戶的實作從IPFW遷移到PF 。請先查看技術細節，特別是關於新規則集行為的部分。 [\[45\]]( https://docs.opnsense.org/manual/captiveportal.html )
    
-   Deprecated Google Drive backups due to upstream policy changes and moved to plugins for existing users.  
    由於上游政策變更，Google 雲端硬碟備份功能已棄用，現有用戶已將其遷移至插件。
    
-   API URLs registered in the default ACLs have been switched from “camelCase” to “snake\_case”.  
    API預設 ACL 中註冊的 URL 已從「駝峰式」切換為「蛇形式」。
    
-   API grid return values now offer “%field” for a value description when available. “field” will now always be the literal value from the configuration. The API previously returned a display value for some field types, but not all.  
    API 網格傳回值現在提供「%field」作為值描述（如果可用）。 「field」現在將始終是配置中的文字值。 API 之前傳回了某些欄位類型的顯示值，但不是全部。
    
-   Reverted tunables “hw.ibrs\_disable” and “vm.pmap.pti” to FreeBSD defaults when no explicit values have been set in tunables.  
    當未在可調參數中設定任何明確值時，將可調參數「hw.ibrs\_disable」和「vm.pmap.pti」還原為 FreeBSD 預設值。
    
-   Moved OpenVPN legacy to plugins as a first step to deprecation.  
    將 OpenVPN 的舊版本遷移到插件中，這是棄用的第一步。
    
-   Moved IPsec legacy to plugins as a first step to deprecation.  
    將 IPsec 傳統功能遷移到外掛程式中，作為棄用的第一步。
