# Normalization｜正常化

> 章節：[Firewall](<000 目錄.md#c-26>)

Traffic normalization protects internal machines against inconsistencies in Internet protocols and implementations. OPNsense has some generic options to normalize some packets on a per interface basis, in some cases more detailed changes are needed, for which custom rules can be configured.

流量規範化可以保護內部機器免受網際網路協定和實現不一致的影響。 OPNsense 提供了一些通用選項，可以按介面對部分資料包進行規範化；在某些情況下，需要更精細的規範化，這時可以配置自訂規則。

By default (when **Disable interface scrub** is not set), all interfaces are scrubbed for all traffic, with `fragment reassemble` enabled and `max-mss` set when specified in **MSS** on the interface.

預設情況下（當未設定 **停用介面清理**時），所有介面都會清理所有流量，啟用`fragment reassemble` ，並在介面上的** MSS ** 中指定時設定`max-mss` 。

Note

注意事項

Some protocols, such as NFS, require specific fragment handling options, which my require specific options set like **IP Do-Not-Fragment\***

某些協議，例如NFS ，需要特定的片段處理選項，這些選項可能需要設定特定的選項，例如**IP Do-Not-Fragment\***

## Settings｜設定

Normalization rules use the same kind of matching as normal firewall rules, which we are not going to detail here. When matched, some different options can be set.

規範化規則使用與普通防火牆規則相同的匹配方式，這裡我們不再贅述。匹配成功後，可以設定一些不同的選項。

Note

注意事項

When rules overlap, the first matching rule wins, hence per interface options are sorted after user configurable ones.

當規則重疊時，第一個符合的規則生效，因此每個介面的選項排在使用者可設定選項之後。

---

|   |   |
| --- | --- |
| Max mss<br>最大 mss | Enforces a maximum MSS for matching TCP packets. Can also be configured on the interface as general rule.<br>強制規定匹配TCP封包的最大MSS延遲。也可以在介面上配置為通用規則。 |
| TOS / DSCP | Enforces a TOS/DCP for matching IP packets.<br>對匹配的IP封包強制執行TOS/DCP 。 |
| Minimum TTL<br>最小TTL | Enforces a minimum TTL for matching IP packets.<br>強制要求匹配IP封包的最小TTL值。 |
| Do not fragment<br>不進行分片 | Clears the `dont-fragment` bit for a matching IP packet, which disables [IP fragmentation](https://en.wikipedia.org/wiki/IP_fragmentation) when set.<br>清除符合的IP封包的`dont-fragment`位，從而在設定時停用 [IP分片](https://en.wikipedia.org/wiki/IP_fragmentation) 。 |
| Random ID<br>隨機ID | Replaces the IP identification field with random values to compensate for predictable values generated by many hosts. This option only applies to packets that are not fragmented after the optional fragment reassembly.<br>將IP標識欄位替換為隨機值，以補償許多主機產生的可預測值。此選項僅適用於在可選的分片重組後未分片的包。 |
