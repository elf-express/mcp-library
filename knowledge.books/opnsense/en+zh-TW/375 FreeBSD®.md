## About FreeBSD｜關於 FreeBSD

FreeBSD is an operating system for a variety of platforms which focuses on features, speed, and stability. It is derived from BSD, the version of UNIX® developed at the University of California, Berkeley. It is developed and maintained by a large community.

FreeBSD 是一個適用於多種平台的作業系統，著重功能、速度和穩定性。它源自於BSD，即加州大學柏克萊分校開發的UNIX®版本。它由一個大型社區開發和維護。

## Relations with OPNsense｜與 OPNsense 的關係

OPNsense is built on top of FreeBSD. The aim of the OPNsense team is to stay as close to the original source as possible. OPNsense can be installed on a standard FreeBSD installation, this way a hosted system can be converted easily to run OPNsense. A bootstrap script is available to make the installation process a joyful experience.

OPNsense 建構在 FreeBSD 之上。 OPNsense 團隊的目標是盡可能接近原始來源。 OPNsense 可以安裝在標準 FreeBSD 安裝上，這樣託管系統就可以輕鬆轉換為運行 OPNsense。引導腳本可以使安裝過程成為一種愉快的體驗。

See also

另請參閱

To convert your FreeBSD hosted installation to OPNsense, see the OPNsense bootstrap script on [OPNsense’s update tools @ github](https://github.com/opnsense/update/)

若要將 FreeBSD 託管安裝轉換為 OPNsense，請參閱 [OPNsense 的更新工具 @ github](https://github.com/opnsense/update/) 上的 OPNsense 開機腳本
