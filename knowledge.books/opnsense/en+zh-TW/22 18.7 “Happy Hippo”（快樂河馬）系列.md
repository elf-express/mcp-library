# 18.7 “Happy Hippo”（快樂河馬） Series｜18.7 “Happy Hippo”（快樂河馬）系列

> 章節：[Releases](<000 目錄.md#c-1>) › [Community Edition](<000 目錄.md#c-2>)

For 3 and a half years now, OPNsense is driving innovation through modularising and hardening the open source firewall, with simple and reliable firmware upgrades, multi-language support, HardenedBSD security, fast adoption of upstream software updates as well as clear and stable 2-Clause BSD licensing.

三年半以來，OPNsense 透過模組化和強化開源防火牆，推動創新，提供簡單可靠的韌體升級、多語言支援、強化的 BSD 安全性、快速採用上游軟體更新以及清晰穩定的 2 條款BSD許可。

Another 6 months passed by ever so quickly! The main goal for 18.7, nicknamed “Happy Hippo”（快樂河馬）, is stability so we have not yet begun to adopt FreeBSD 11.2, but there are several of its Intel NIC driver updates included to bridge the gap until 19.1 comes out. The upgrade also includes a tremendous amount of IPv6 improvements including 6RD support as well as authentication and backup framework consolidation. Please also take note that QinQ is no longer included in this release.

又過了六個月，時間過得很快！ 18.7 （暱稱“Happy Hippo”（快樂河馬） ）的主要目標是穩定性，因此我們尚未開始採用FreeBSD 11.2 ，但其中包含了一些Intel NIC驅動程式更新，以彌補19.1 。此次升級還包含大量IPv6改進，包括6RD支援以及身份驗證和備份框架的整合。另請注意，此版本不再包含QinQ。

These are the most prominent changes since version 18.1:

以下是自18.1版本以來最顯著的變化：

-   improved WAN DHCPv6 and SLAAC connectivity and tracking  
    改進了WAN DHCPv6 和SLAAC連接性和追蹤功能
    
-   functional IPv6 Rapid Deployment (6RD) support  
    功能性 IPv6 快速部署 (6RD) 支持
    
-   improved default route handling and gateway switching  
    改進的預設路由處理和網關交換
    
-   OpenVPN default setup improvements for IPv6 and RADIUS attribute support  
    OpenVPN 預設設定改進，支援 IPv6 和RADIUS屬性
    
-   Dpinger gateway monitoring integration  
    Dpinger網關監控集成
    
-   password policies for local authentication and coupled TOTP  
    用於本地身份驗證和耦合TOTP的密碼策略
    
-   Monit core integration to eventually replace the legacy notifications  
    監控核心整合最終將取代舊式通知
    
-   OpenSSH access via group and shell selection instead of privilege  
    透過群組和 shell 選擇而非權限存取 OpenSSH
    
-   pluggable backup framework with new Nextcloud option  
    帶有全新 Nextcloud 選項的可插拔備份框架
    
-   system tunables are now also used as loader tunables  
    系統可調參數現在也用作載入器可調參數。
    
-   unrestricted VLAN usage for e.g. Xen  
    不受限制的VLAN用途，例如 Xen
    
-   QinQ interface removal  
    QinQ介面移除
    
-   firmware GUI speedup, improved error parsing and console reboot hint  
    韌體GUI速度提升、改進的錯誤解析和控制台重啟提示
    
-   ZFS on root boot support (installer support is pending, but opnsense-bootstrap works)  
    ZFS關於根啟動支援（安裝程式支援正在等待中，但 opnsense-bootstrap 可以正常運作）
    
-   ZFS and MSDOS config import support  
    ZFS和MSDOS配置導入支持
    
-   ISC DHCP version moves from 4.3 to 4.4

-   RRDtool version moves from 1.2 to 1.7  
    RRDtool 版本從1.2升等到1.7
    
-   rework rc.syshook facility to use drop-in directories instead of suffixes  
    重構 rc.syshook 功能，使其使用直接插入的目錄而不是後綴。
    
-   backports of FreeBSD 11.2 Intel NIC drivers  
    FreeBSD 11.2 Intel NIC驅動程式的向後移植
    
-   stand-alone frontend UI development tools  
    獨立前端UI開發工具
    
-   language updates for Czech, French, German, Portuguese (Brazil)  
    捷克語、法語、德語、葡萄牙語（巴西）的語言更新
    
-   UI header security and SSL cipher hardening  
    UI報頭安全性和SSL密碼強化

    大量UI清理和菜單整合

    SSH存取權限現在綁定到「wheel」群組，該群組會自動新增至「admins」群組，「root」是該群組的成員。 「root」是唯一擁有預設 shell 的用戶，即 opnsense-shell，它是 root 控制台選單。
