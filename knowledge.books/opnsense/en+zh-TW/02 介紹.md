# Introduction｜介紹

Welcome to the OPNsense documentation & wiki project! The documentation is a work in progress and is updated frequently. If you would like to contribute in any way, please take a look at our guide on how to [Contribute](<380 貢獻.md>).

歡迎來到 OPNsense 文件和 wiki 專案！文件仍在不斷改進中，我們會經常更新。如果您想以任何方式做出貢獻，請參閱我們的[貢獻指南](<380 貢獻.md>) 。

[![_images/opnsense_logo_horizontaal.png](<../images/2f7274d9-opnsense_logo_horizontaal.png>)](https://docs.opnsense.org/_images/opnsense_logo_horizontaal.png)

## Welcome to OPNsense’s documentation!｜歡迎閱讀 OPNsense 的文檔！

[OPNsense®](https://opnsense.org/) is an open source, easy-to-use and easy-to-build FreeBSD based firewall and routing platform.

[OPNsense®](https://opnsense.org/)是一個開源、易於使用且易於建構的基於 FreeBSD 的防火牆和路由平台。

**OPNsense** includes most of the features available in expensive commercial firewalls, and more in many cases. It brings the rich feature set of commercial offerings with the benefits of open and verifiable sources.

**OPNsense** 包含了大多數昂貴商業防火牆的功能，在許多情況下甚至更多。它不僅擁有商業產品的豐富功能，還具備開放且可驗證原始碼的優勢。

## Mission Statement｜使命宣言

> Give users, developers and businesses a friendly, stable and transparent environment. Make OPNsense the most widely used open source security platform. The project’s name is derived from open and sense and stands for: “Open (source) makes sense.”
>
> 為使用者、開發者和企業提供友善、穩定、透明的環境。使 OPNsense 成為應用最廣泛的開源安全平台。此專案名稱源自 open 和 sense，意為：「開源即有意義」。

## Reading guide｜閱讀指南

While reading the documentation, it is good to know how the various topics are structured, what their purpose is and how to find what you are looking for. Maybe even more important is what this documentation does not offer.

閱讀文件時，了解各個主題的結構、用途以及如何找到所需內容非常重要。但或許更重要的是，要了解這份文件沒有提供哪些資訊。

If you are looking for deeper insights about networking and best practices in designing them, this might not be the best place to look. Most of our documents and how-to’s focus on how to use functionality included in our software and/or one of its plugins. Quite a lot of books are written about networking, there are (online) courses available and Wikipedia contains a lot of relevant articles as well. Some interesting reads include the fundamentals about the [OSI model](https://en.wikipedia.org/wiki/OSI_model), [IP addressing](https://en.wikipedia.org/wiki/IP_address), [routing](https://en.wikipedia.org/wiki/IP_routing) and [network address translation](https://en.wikipedia.org/wiki/Network_address_translation). These resources are likely more suitable for learning about general network concepts. Although we do try to include some context in our documents, there are often assumptions made about the readers knowledge on (basic) networking.

如果您想深入了解網路及其設計的最佳實踐，這裡可能並非最佳選擇。我們的大部分文件和操作指南都專注於如何使用我們軟體及其插件中包含的功能。關於網路的書籍汗牛充棟，還有許多（線上）課程可供選擇，維基百科也包含大量相關文章。一些值得一讀的資料包括[OSI模型](https://en.wikipedia.org/wiki/OSI_model) 、[IP尋址](https://en.wikipedia.org/wiki/IP_address) 、[路由](https://en.wikipedia.org/wiki/IP_routing)和[網路位址轉換](https://en.wikipedia.org/wiki/Network_address_translation)的基礎知識。這些資源可能更適合學習通用的網路概念。儘管我們努力在文件中提供一些背景信息，但通常會假設讀者俱備（基礎）網路知識。

Like many products and projects, ours grows over time, functionality extends and changes, which sometimes makes it difficult to find what you need for the version you are using. Although we try to keep our documentation up to date, sometimes its contents do not reflect reality anymore. If that is the case and you think you found an omission, do not hesitate to open a report using one of our templates on [GitHub](https://github.com/opnsense/docs/issues/new/choose) or a pull request if you are able to.

與許多產品和項目一樣，我們的產品也會隨著時間的推移而不斷發展，功能不斷擴展和變化，這有時會導致您難以找到當前版本所需的資訊。儘管我們努力保持文件的更新，但有時其內容可能已不再反映實際情況。如果您發現任何遺漏，請隨時使用我們在 [GitHub](https://github.com/opnsense/docs/issues/new/choose)上的範本提交報告，或者如果您有能力，也可以提交 pull request。

Always assume the text is intended for the latest version of our product, in time we might add a version selector in the documentation, but given OPNsense is a security product, we advise to keep it up to date anyway to protect yourself against the latest threats.

請務必假設文字適用於我們產品的最新版本，我們可能會在文件中添加版本選擇器，但鑑於 OPNsense 是一款安全產品，我們建議您無論如何都要保持其更新，以保護自己免受最新威脅的侵害。

The releases section contains the changelogs for all versions we published over the years, if there are remarks for an upgrade, this is a useful resource to collect the details.

發布部分包含我們多年來發布的所有版本的變更日誌，如果有升級方面的說明，這是一個收集詳細資訊的有用資源。

Installation and setup is all about getting you started using one of the target options available.

安裝和設定的全部意義就在於幫助您開始使用可用的目標選項之一。

The next sections should be quite familiar when working with OPNsense, as they reflect the options in the product’s menu. If you are not yet used to OPNsense, you can always use the search input in the top-left corner of the screen to find your topic.

接下來的章節內容對於使用 OPNsense 的使用者來說應該相當熟悉，因為它們與產品選單中的選項相對應。如果您還不熟悉 OPNsense，可以隨時使用螢幕左上角的搜尋框尋找所需主題。

Both community and third-party plugins have their own area available, although they eventually register into the same menu structure, it is good to know about possible differences between add-ons and standard functionality. The level of support may differ between core functionality, as also explained in the “Support options” section, feature requests and bugs may be treated different as well (a lot of questions for a plugin which is being developed by a single person, maybe less active than a group of people improving a plugin together for example).

社群外掛程式和第三方外掛都有各自的專屬區域，雖然它們最終都會出現在同一個選單結構中，但了解外掛程式和標準功能之間的差異仍然很有幫助。核心功能的支援等級可能有所不同，正如「支援選項」部分所述，功能請求和錯誤報告的處理方式也可能不同（例如，由個人開發的插件可能會收到很多問題，因此其支援力度可能不如團隊合作開發的插件）。

When it comes to building software on top of OPNsense or extending existing functionality, the development chapter is the one to read. It explains all about our architecture, coding style, how to hook into available facilities and much more.

如果要在 OPNsense 之上建立軟體或擴展現有功能，開發章節是必讀之作。它詳細解釋了我們的架構、編碼風格、如何連接可用功能等等。

Some pointers when it comes to troubleshooting can be found in the section with the same name, it explains a bit about our issue workflow and some tips we collected over the years.

有關故障排除的一些提示可以在同名章節中找到，它簡要介紹了我們的問題處理流程以及我們多年來收集的一些技巧。

Last but not least our documentation includes some pages around project relations, legal guidelines and ways to contribute to the project.

最後，我們的文件還包括一些關於專案關係、法律準則以及如何為專案做出貢獻的頁面。

## Feature set｜功能集

The feature set of OPNsense includes high-end features such as forward caching proxy, traffic shaping, intrusion detection and easy OpenVPN client setup. The latest release is based on a recent FreeBSD for long-term support and uses a newly developed MVC-framework based on Phalcon. OPNsense’s focus on security brings unique features such as easy to use one time password authentication for various components.

OPNsense 的功能集包含許多高階功能，例如前向快取代理、流量整形、入侵偵測以及簡易的 OpenVPN 用戶端設定。最新版本基於最新的 FreeBSD 系統，以確保長期支持，並採用基於 Phalcon 開發的全新MVC框架。 OPNsense 著重於安全性，並為此提供了許多獨特功能，例如針對各種元件的便利一次性密碼驗證。

The robust and reliable update mechanism gives OPNsense the ability to provide important security updates in a timely fashion.

強大且可靠的更新機制使 OPNsense 能夠及時提供重要的安全性更新。
