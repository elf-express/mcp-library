# Local Users & Groups｜本地用戶和群組

> 章節：[System](<000 目錄.md#c-11>) › [Access / User Management](<000 目錄.md#c-12>) › [Configuration](<000 目錄.md#c-13>)

[![../../_images/usermanager_groups.png](<../images/70c9b409-usermanager_groups.png>)](https://docs.opnsense.org/_images/usermanager_groups.png)

With the local user manager in OPNsense one can add users and groups and define the privileges for granting access to certain parts of the GUI (Web Configurator).

透過 OPNsense 中的本機使用者管理員，可以新增使用者和群組，並定義授予對GUI （Web 設定器）某些部分的存取權限的權限。

## Adding Users｜新增用戶

To add a new user go to System ‣ Access ‣ Users and click on the **+** sign at the bottom right corner of the form.

若要新增用戶，請前往“系統”‣“訪問”‣“用戶”，然後按一下表單右下角的**+**符號。

Tip

提示

Although there is no direct relation between users and certificates, one can search the trust store directly for certificates using the same common name as the user name. The button can be used in that case.

雖然使用者和憑證之間沒有直接關聯，但可以使用與使用者名稱相同的通用名稱直接在信任庫中搜尋憑證。在這種情況下，可以使用該按鈕。

Tip

提示

To support migrations, it is possible to bulk-export and import users into the local database. Use the button to receive a formatted csv file, which can be imported using the button. Some sensitive fields (like passwords) are not included in this procedure.

為了支援資料遷移，可以批次匯出用戶資料並將其匯入本地資料庫。點擊按鈕即可取得格式化的 CSV 文件，然後使用另一個按鈕匯入該文件。請注意，此過程不會包含某些敏感欄位（例如密碼）。

### Creating and maintaining API keys｜建立與維護API金鑰

Each user can have api keys for machine to machine communication, to create these use the button in the grid, which downloads a new key/secret file.

每個使用者都可以擁有用於機器間通訊的 API 金鑰，要建立這些金鑰，請使用網格中的按鈕，該按鈕會下載一個新的金鑰/金鑰檔案。

The assigned keys can be found in the “ApiKeys”（API金鑰） tab, where you can remove keys that are no longer used.

已指派的按鍵可以在“ApiKeys”（API金鑰）選項卡中找到，您可以在那裡刪除不再使用的按鍵。

Note

注意事項

Private parts (secret) are only generated once, when lost you will have to generate a new keypair.

私鑰（密鑰）只產生一次，遺失後需要產生新的密鑰對。

## Creating Groups｜建立群組

Go to System ‣ Access ‣ Groups and click on the **+** sign in the lower right corner of the form.

前往“系統”‣“訪問”‣“群組”，然後按一下表單右下角的**+**符號。

Enter a **Group name** and a **Description** and add users to the group.

輸入**群組名稱**和**描述**，並將使用者新增至該群組。

When users should access resources on this firewall via a group, connect the relevant ones via **Assigned Privileges**.

當使用者需要透過群組存取此防火牆上的資源時，請透過**已指派權限**連線相關使用者。

## Validate and change privileges｜驗證並更改權限

The System ‣ Access ‣ Privileges privileges page offers quick insights into the roles available and their purpose.

系統 ‣ 存取 ‣ 權限頁面可快速了解可用角色及其用途。

Each component in the same “lives” on it’s own path (endpoint), these are collected into privileges for easy access.

同一系統中的每個元件都有自己的「生命週期」（端點），這些端點被收集到權限中以便於存取。

---

|   |   |
| --- | --- |
| **ID** | *Internal identifier stored in the database*<br>*儲存在資料庫中的內部識別碼* |
| **Name**<br>**名稱** | *The name of this privilege*<br>*此權限的名稱* |
| **Match**<br>**符合** | *The different paths this privilege matches on*<br>*此權限符合的不同路徑* |
| **Users**<br>**使用者** | *The number of users linked directly into this privilege*<br>*直接關聯到此權限的使用者數量* |
| **Groups**<br>**群組** | *The number of groups linked directly into this privilege*<br>*直接關聯到此權限的群組數量* |
