# Control Plane Shaping｜控制平面整形

> 章節：[Firewall](<000 目錄.md#c-26>) › [Traffic Shaping](<000 目錄.md#c-29>) › [Configuration / How-tos](<000 目錄.md#c-30>)

Planes of Operation is a concept to describe and divide the functionality of a network device.

操作平面是描述和劃分網路設備功能的概念。

In essence, the concept creates logical layers in which packets are categorized per their use and type.

本質上，這個概念創建了邏輯層，其中資料包根據其用途和類型進行分類。

There are 3 Planes:

有 3 個平面：

1.  **The control plane**  
    **控制平面**
    
    Affects the operability of the network.

    影響網路的可操作性。
    
    The control plane is the brain of the router. It consists of dynamic IP routing protocols (that is OSPF, IS-IS, BGP, and so on), the RIB, routing updates, in addition to other protocols such as PIM, IGMP, ICMP, ARP, BFD, LACP, and so on. In short, the control plane is responsible for maintaining the network topology and exchanging protocol information with other routers or network devices.

    控制平面是路由器的大腦。它由動態IP路由協定（即OSPF, IS-IS, BGP等）、RIB、路由更新以及其他協定如PIM, IGMP, ICMP, ARP, BFD, LACP等組成。簡而言之，控制平面負責維護網路拓撲並與其他路由器或網路設備交換協定資訊。
    
2.  **The management plane**  
    **管理平面**
    
    Affects the manageability of the network.

    影響網路的可管理性。
    
    The management plane is used to manage a device through its connection to the network. Examples of protocols processed in the management plane include Simple Network Management Protocol (SNMP), Telnet, File Transfer Protocol (FTP), Secure FTP, and Secure Shell (SSH). These management protocols are used for monitoring and for command-line interface (CLI) access.

    管理平面用於透過設備與網路的連接來管理設備。在管理平面中處理的協定範例包括簡單網路管理協定（SNMP）、Telnet、檔案傳輸協定（FTP）、安全性FTP和安全Shell（SSH）。這些管理協定用於監控和命令列介面 (CLI) 存取。
    
3.  **The data plane**  
    **數據平面**
    
    Affects the applications of the user.

    影響用戶的應用程式。
    
    The data plane is the forwarding plane, which is responsible for the switching of packets through the router.

    資料平面是轉送平面，負責透過路由器進行封包的交換。
    

## Necessity of Control Plane Shaping｜控制平面整形的必要性

The control plane is a necessary component for proper network operation. A congested state of the network, if the control plane is not properly managed, will result in network disruptions. In order to guarantee operation and avoid disruption in such events, we can take advantage of Traffic Shaping.

控制平面是網路正常運作的必要組件。如果控制平面管理不當，網路擁塞狀態將導致網路中斷。為了確保運作並避免此類事件造成中斷，我們可以利用流量整形。

**With Shaping, we can reserve dedicated bandwidth for the control plane**

**透過Shaping，我們可以為控制平面預留專用頻寬**

Attention

注意

The control plane should not share a class (Pipe or Queue) with any other traffic type.

控制平面不應與任何其他流量類型共用類別（管道或佇列）。

## Configuring Control plane for OPNsense｜為 OPNsense 配置控制平面

The configuration will take into account the existence of an already configured shaper as per [Fighting Bufferbloat with FQ\_CoDel](<144 使用 FQ_CoDel 對抗緩衝區膨脹.md>)

此配置將考慮已配置的整形器的存在，依照 [Fighting Bufferbloat with FQ\_CoDel](<144 使用 FQ_CoDel 對抗緩衝區膨脹.md>)

In the configuration steps below, assume these tuned speeds:

在下面的配置步驟中，假設這些調整速度：

|  | Download<br>下載 | Upload<br>上傳 |
| --- | --- | --- |
| Mbit/s<br>兆位元/秒 | 495 | 30<br>495 30 |

Bandwidth allocation requirements for Control plane:

控制平面的頻寬分配要求：

| 1% of BW<br>BW 的 1% | Download<br>下載 | Upload<br>上傳 |
| --- | --- | --- |
| Mbit/s<br>兆位元/秒 | 5 | 1 |

The 1% is the default lowest value, at minimum the BW should be set to 1Mbit/s. Its subjected to be increased if needed.

1% 是預設的最低值，BW 至少應設定為 1Mbit/s。如果需要的話可以增加。

Attention

注意

BW given to a different Pipe needs to be subtracted from already existing ones.

給予不同管道的BW需要從現有的管道中減去。

Schedulers available for Control plane shaping:

可用來控制平面整形的調度程序：

| Schedulers<br>調度程序 | Usable<br>可用 | Note<br>注意 |
| --- | --- | --- |
| FIFO | NO | No weight merit<br>沒有體重優勢 |
| WFQ | YES | weight merit<br>體重優點 |
| DRR | NO | causing latency<br>導致延遲 |
| QFQ | YES | weight merit<br>體重優點 |
| FQ\_CoDel | NO | AQM back-pressure<br>AQM 背壓 |
| FQ\_PIE | NO | AQM back-pressure<br>AQM 背壓 |

In this example we will create a Shaper for the IPv6 Control plane.

在此範例中，我們將為 IPv6 控制平面建立一個 Shaper。

To begin, go to Firewall ‣ Shaper ‣ Pipes. Select the *advanced mode*

首先，前往 Firewall ‣ Shaper ‣ Pipes。選擇*進階模式*

### Step 1a - Create Download Pipe｜步驟 1a - 建立下載管道

On the **Pipes** tab click the **+** button in the lower right corner. An empty **Edit Pipe** screen pops up.

在 **管道**標籤上，按一下右下角的**+**按鈕。彈出一個空的**編輯管道**螢幕。

#### Create Control-plane-Pipe For Download｜建立控制平面管道以供下載

| Setting<br>設定 | Default<br>預設 | Description<br>描述 |
| --- | --- | --- |
| **enabled**<br>**啟用** | Checked<br>已檢查 | *Check to enable the pipe*<br>*檢查以啟用管道* |
| **bandwidth**<br>**頻寬** | 5 | *Set initially to 1% of tuned BW, increase if needed*<br>*初始設定為調諧BW的 1%，若需要則增加* |
| **bandwidth Metric**<br>**頻寬指標** | Mbit/s<br>兆位元/秒 | *Metric associated with the bandwidth*<br>*與頻寬相關的指標* |
| **queue**<br>**佇列** | (empty)<br>（空） | *Leave empty: queues are configured separately*<br>*留空：佇列單獨配置* |
| **mask**<br>**面具** | (none)<br>（無） | *Leave empty*<br>*留空* |
| **scheduler type**<br>**調度程序類型** | WFQ | *Default or QFQ, allows to use weights per queues*<br>*預設或QFQ，允許使用每個佇列的權重* |
| **Enable CoDel**<br>**啟用 CoDel** | (empty)<br>（空白） | *Leave empty*<br>*留空* |
| **(FQ-)CoDel target**<br>**(FQ-)CoDel 目標** | (empty)<br>（空） | *Leave empty*<br>*留空* |
| **(FQ-)CoDel interval**<br>**(FQ-)CoDel 間隔** | (empty)<br>（空） | *Leave empty*<br>*留空* |
| **(FQ-)CoDel ECN** | (empty)<br>（空） | *Leave empty*<br>*留空* |
| **FQ-CoDel quantum**<br>**FQ-CoDel 量子** | (empty)<br>（空） | *Leave empty*<br>*留空* |
| **FQ-CoDel limit**<br>**FQ-CoDel 限制** | (empty)<br>（空） | *Leave empty*<br>*留空* |
| **FQ-CoDel flows**<br>**FQ-CoDel 流程** | (empty)<br>（空） | *Leave empty*<br>*留空* |
| **description**<br>**描述** | Control-plane-Pipe-Download<br>控制平面管道下載 | *Free field, enter something descriptive*<br>*自由字段，輸入描述性內容* |

### Step 1b - Create Upload Pipe｜步驟 1b - 建立上傳管道

On the **Pipes** tab click the **+** button in the lower right corner. An empty **Edit Pipe** screen pops up.

在 **管道**標籤上，按一下右下角的**+**按鈕。彈出一個空的**編輯管道**螢幕。

Follow the same process as for the Download pipe, entering the 1% of tuned bandwidth value, and entering “Control-plane-Pipe-Upload”（控制平面管道上傳） for the **description**.

依照下載管道相同的流程，輸入 1% 的調整頻寬值，並輸入 “Control-plane-Pipe-Upload”（控制平面管道上傳） 作為 **說明**。

### Step 2a - Create Download Queue｜步驟 2a - 建立下載佇列

On the **Queues** tab click the **+** button in the lower right corner. An empty **Edit queue** screen pops up.

在 **佇列**標籤上，按一下右下角的**+**按鈕。彈出一個空的**編輯佇列**螢幕。

#### Create Control-plane-IPv6-Queue For Download｜建立控制平面 IPv6 佇列以供下載

|   |   |   |
| --- | --- | --- |
| **enabled**<br>**啟用** | Checked<br>已檢查 | *Check to enable the queue*<br>*檢查以啟用佇列* |
| **pipe**<br>**管道** | Control-plane-Pipe-Download<br>控制平面管道下載 | *Select our Pipe*<br>*選擇我們的管道* |
| **weight**<br>**重量** | 100 | *The higher weight the higher the ratio of BW a queue gets*<br>100 *權重越高，隊列獲得BW的比例就越高* |
| **mask**<br>**面具** | (none)<br>（無） | *Leave empty for a queue*<br>*為佇列留空* |
| **Enable CoDel**<br>**啟用 CoDel** | (empty)<br>（空） | *Leave empty for a queue*<br>*為佇列留空* |
| **(FQ-)CoDel target**<br>**(FQ-)CoDel 目標** | (empty)<br>（空） | *Leave empty for a queue*<br>*為佇列留空* |
| **(FQ-)CoDel interval**<br>**(FQ-)CoDel 間隔** | (empty)<br>（空） | *Leave empty for a queue*<br>*為佇列留空* |
| **(FQ-)CoDel ECN** | (empty)<br>（空） | *Leave empty for a queue*<br>*為佇列留空* |
| **description**<br>**描述** | Control-plane-IPv6-Queue-Download<br>控制平面 IPv6 佇列下載 | *Free field, enter something descriptive*<br>*自由字段，輸入描述性內容* |

Note

注意事項

Using WFQ or QFQ and weights, we can tell how much BW each protocol control plane will get.

使用WFQ或QFQ和權重，我們可以知道每個協議控制平面將獲得多少BW。

### Step 2b - Create Upload Queue｜步驟 2b - 建立上傳佇列

On the **Queues** tab click the **+** button in the lower right corner. An empty **Edit queue** screen pops up.

在 **佇列**標籤上，按一下右下角的**+**按鈕。彈出一個空的**編輯佇列**螢幕。

Follow the same process as for the Download queue, selecting the **“Control-plane-Pipe-Upload”（控制平面管道上傳）**, and entering “Control-plane-IPv6-Queue-Upload”（控制平面 IPv6 佇列上傳） for the **description**.

依照與下載佇列相同的過程，選擇 **“Control-plane-Pipe-Upload”（控制平面管道上傳）**，並輸入 “Control-plane-IPv6-Queue-Upload”（控制平面 IPv6 佇列上傳） 作為**描述**。

### Step 3a - Create Download Rule｜步驟 3a - 建立下載規則

On the **Rules** tab click the **+** button in the lower right corner. An empty **Edit rule** screen pops up.

在 **規則**標籤上，按一下右下角的**+**按鈕。彈出一個空的**編輯規則**畫面。

#### Create a Control-plane-IPv6-Rule For Download｜建立用於下載的控制平面 IPv6 規則

|   |   |   |
| --- | --- | --- |
| **enabled**<br>**啟用** | Checked<br>已檢查 | *Check to enable the rule*<br>*檢查以啟用規則* |
| **sequence**<br>**序列** | 1 | *Auto generated number, overwrite only when needed*<br>*自動產生編號，僅在需要時覆蓋* |
| **interface**<br>**介面** | WAN | *Select the interface connected to the internet*<br>*選擇連接到網際網路的介面* |
| **proto**<br>**原型** | ipv6-icmp<br>ipv6 icmp | *Select the protocol, ipv6-icmp in our example*<br>*在我們的範例中選擇協定 ipv6-icmp* |
| **source**<br>**來源** | any<br>任何 | *The source address to shape, leave on any*<br>*要整形的來源位址，保留任意* |
| **src-port**<br>**來源端口** | any<br>任何 | *The source port to shape, leave on any*<br>*要塑造的來源端口，保留任何* |
| **destination**<br>**目的地** | any<br>任何 | *The destination IP to shape, leave on any*<br>*目的地IP塑造，留下任意* |
| **dst-port**<br>**目標端口** | any<br>任何 | *The destination port to shape, leave on any*<br>*目的港自行塑造，任意留任* |
| **direction**<br>**方向** | in<br>在 | *Matches incoming or outgoing packets or both (default). We want to shape Download e.g ingress on WAN*<br>*符合傳入或傳出資料包或兩者（預設）。我們想要塑造下載，例如 WAN* 上的入口 |

| **description**<br>**描述** | Control-plane-IPv6-Rule-Download<br>控制平面 IPv6 規則下載 | *Enter a descriptive name*<br>*輸入描述性名稱* |

### Step 3b - Create Upload Rule｜步驟 3b - 建立上傳規則

On the **Rules** tab click the **+** button in the lower right corner. An empty **Edit rule** screen pops up.

在 **規則**標籤上，按一下右下角的**+**按鈕。彈出一個空的**編輯規則**畫面。

Follow the same process as for the Download rule, using the same values except:

按照與下載規則相同的過程，使用相同的值，但以下情況除外：

-   **sequence** (set to 2);  
    **序列**（設定為2）；
    
-   **direction** (set to “out”)  
    **方向**（設定為“出”）
    
-   **target** (set to “Control-plane-IPv6-Queue-Upload”（控制平面 IPv6 佇列上傳）);  
    **目標**（設定為“Control-plane-IPv6-Queue-Upload”（控制平面 IPv6 佇列上傳））；
    
-   **description** (set to “Control-plane-IPv6-Rule-Upload”（控制平面 IPv6 規則上傳）)  
    **描述**（設定為“Control-plane-IPv6-Rule-Upload”（控制平面 IPv6 規則上傳））
    

Attention

注意

The sequences needs to be at least 1 less than the default any rules or rules that would catch this traffic type and you may need to adjust the other rule sequence values accordingly.

這些序列需要比預設的任何規則或捕獲此流量類型的規則至少少 1，並且您可能需要相應地調整其他規則序列值。

### Step 4 - Finalizing the configuration｜第 4 步 - 完成配置

Now press **Apply** to activate the traffic shaping rules.

現在按 **應用** 啟動流量整形規則。

## Additional Control plane per protocol｜每個協定的附加控制平面

In case we need to create control plane of additional protocols such as BGP, PIM, etc. We can use the already created “Control-plane-Pipe”（控制平面管道）. Simple add Queues with proper weights and Rules into this specific Pipe matching the traffic.

如果我們需要建立額外協定的控制平面，例如BGP, PIM等，我們可以使用已經建立的“Control-plane-Pipe”（控制平面管道）。簡單地將具有適當權重和規則的佇列新增至與流量相符的特定管道中。
