# Generic info｜一般資訊

> 章節：[Firewall](<000 目錄.md#c-26>)

This chapter explains some of the concepts that are used in different modules of our firewall system and therefore don’t belong to a specific section of this topic.

本章解釋了防火牆系統不同模組中使用的一些概念，因此不屬於本主題的特定部分。

## Address types｜地址類型

When choosing source and/or destination addresses, the user can choose several options depending on the context. To explain what the different options mean when being presented, we will summarize them below:

當選擇來源和/或目標位址時，使用者可以根據上下文選擇多個選項。為了解釋不同選項的含義，我們將其總結如下：

---

|   |   |
| --- | --- |
| Alias<br>別名 | Flexible type of network or address definition for easy reuse, explained in [aliases](<132 別名.md>)<br>靈活的網路類型或位址定義，以便於重複使用，如[別名](<132 別名.md>) |
| Single host or network<br>單主機或網路 | Standard host or network in [CIDR notation](https://en.wikipedia.org/wiki/Classless_Inter-Domain_Routing)<br>標準主機或網路 [CIDR 表示法](https://en.wikipedia.org/wiki/Classless_Inter-Domain_Routing) |
| any<br>任何 | All IPv4 and/or IPv6 addresses (in the world)<br>所有 IPv4 和/或 IPv6 位址（全球） |
| This Firewall<br>此防火牆 | All IPv4 and/or IPv6 addresses assigned to this firewall<br>指派給此防火牆的所有 IPv4 和/或 IPv6 位址 |
| \[Interface\] Network<br>\[介面\]網路 | All networks assigned to the device, this will also include networks of assigned virtual addresses (\[Interface\] is explained in the [interfaces](<106 介面配置.md>) topic). Normally used to allow traffic from or to clients connected to a specific interface.<br>指派給裝置的所有網絡，這也包括指派的虛擬位址的網路（\[介面\]在[介面](<106 介面配置.md>)主題中進行了解釋）。通常用於允許來自或流向連接到特定介面的客戶端的流量。 |
| \[Interface\] Address<br>\[介面\]位址 | All addresses configured on an interface, this includes all virtual (alias) addresses as well.<br>在介面上設定的所有位址，這也包括所有虛擬（別名）位址。 |
| Virtual IPs<br>虛擬IP | Explicit selection for addresses defined in [Virtual IPs](<111 虛擬IP.md>)<br>明確選擇[虛擬 IP](<111 虛擬IP.md>) 中定義的位址 |
