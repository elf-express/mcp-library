> 章節：[Releases](<000 目錄.md#c-1>) › [Community Edition](<000 目錄.md#c-2>)

For an entire decade now, OPNsense is driving innovation through modularising and hardening the open source firewall, with simple and reliable firmware upgrades, multi-language support, fast adoption of upstream software updates as well as clear and stable 2-Clause BSD licensing.

十年來，OPNsense 透過模組化和強化開源防火牆，推動創新，提供簡單可靠的韌體升級、多語言支援、快速採用上游軟體更新以及清晰穩定的 2 條款BSD許可。

25.1, nicknamed “Ultimate Unicorn”（終極獨角獸）, features numerous MVC/API conversions, improved security zones support and documentation, ZFS snapshot support, a new UI look with a light and dark theme, PHP 8.3, FreeBSD 14.2 plus much more.

25.1，暱稱“Ultimate Unicorn”（終極獨角獸），具有大量 MVC/API 轉換、改進的安全區域支援和文件、ZFS 快照支援、帶有淺色和深色主題的新 UI 外觀、PHP 8.3、FreeBSD 14.2 等等。

## 25.1.12 (July 22, 2025)｜25.1.12 （2025年7月22日）

This EoL release after an EoL release is unexpected, but certainly not unnecessary. A bug in the shared library naming in Sqlite was briefly introduced in FreeBSD ports going into 25.1.11 which is also a likely cause for reported update issues with missing packages after reboot. This was only uncovered yesterday during upgrade testing for 25.7.

在上一個版本發布終止支援 (EoL) 後又發布一個 EoL 版本，這雖然出乎意料，但並非毫無必要。 Sqlite 共享庫命名中的一個 bug 在 FreeBSD ports 中短暫出現，並被引入到25.1.11版本中，這很可能是導致重啟後出現軟體包缺失更新問題的原因之一。這個問題直到昨天在25.7的升級測試中才被發現。

To ensure proper upgrades it was decided to roll a full stable release with added benefits like security fixes for Unbound, LibXML and a “modern browser” fix for the firewall rules page which could not be saved under particular circumstances.

為了確保正確升級，決定推出完整的穩定版本，並添加一些額外功能，例如修復 Unbound 和 LibXML 的安全問題，以及修復防火牆規則頁面在特定情況下無法保存的「現代瀏覽器」問題。

25.7 itself is still scheduled for tomorrow pending green light during testing its rebuild. The firmware components have already been wired to detect the upgrade once it becomes visible on the mirror. There will likely be no further hotfix this time to pick up the release. Just check again for updates some hours after the 25.7 release announcement to allow for mirrors to synchronize.

25.7本身仍計劃於明日發布，但需通過重建測試。韌體組件已完成連接，以便在鏡像伺服器上顯示升級資訊後立即檢測到。此次可能不會再發布其他熱補丁來同步版本。請在25.7發佈公告發佈數小時後再次檢查更新，以便鏡像伺服器同步。

## 25.1.11 (July 16, 2025)｜25.1.11 （2025年7月16日）

此次維護版本也將是25.1系列的最終版本。它包含了最新的FreeBSD SA/EN補丁以及其他第三方安全更新和一些小的修復。

We did see issues with the “e2fsprogs-libuuid” dependency lately obsoleted by FreeBSD ports and while packages such as “netdata” may refuse updating in the first update it should eventually reinstall correctly using the new “libuuid” package. If you see related issues make sure you are not using multi-repo setups that still provide the obsoleted dependency.

我們最近發現 FreeBSD ports 已棄用“e2fsprogs-libuuid”依賴項，雖然像“netdata”這樣的軟體包在首次更新時可能拒絕更新，但最終應該會使用新的“libuuid”軟體包正確重新安裝。如果您遇到相關問題，請確保您沒有使用仍提供已棄用依賴項的多倉庫設定。

That being said, 25.7-RC1 is already out, but RC2 likely follows tomorrow. We are still set for a final release date of July 23. See you on the other side!

Migration notes, known issues and limitations:

遷移說明、已知問題與限制：

-   The access management was rewritten in MVC and contains behavioural changes including not rendering UNIX accounts for non-shell users. The integrated authentication via PAM has been the default for a long time so the option to disable it has been removed. The manual LDAP importer is no longer available since LDAP/RADIUS authenticators support on-demand creation and default group setup option. The “page-system-groupmanager-addprivs” privilege was removed since the page does not exist anymore. A multi-purpose privilege editor has been added under the existing “page-system-usermanager-addprivs” instead.  
    存取管理功能已在MVC中重寫，並包含一些行為變更，例如不再為非 shell 使用者渲染UNIX帳戶。透過PAM集成的身份驗證長期以來一直是預設設置，因此已移除禁用選項。由於LDAP/RADIUS身份驗證器支援按需建立和預設群組設定選項，因此不再提供手動LDAP導入器。 「page-system-groupmanager-addprivs」權限已移除，因為該頁面已不存在。取而代之的是，在現有的「page-system-usermanager-addprivs」下新增了一個多用途權限編輯器。
    
-   PPP devices can no longer be configured on the interface settings page. To edit the device settings use the native PPP device edit page instead.  
    PPP設備無法再透過介面設定頁面進行設定。若要編輯設備設置，請改用原生PPP設備編輯頁面。
    
-   FreeBSD 14.2 comes with the stock pf(4) behaviour regarding ICMPv6 neighbour discovery state tracking which was avoided so far in 24.7.x.  
    FreeBSD 14.2帶有關於 ICMPv6 鄰居發現狀態追蹤的 pf(4) 標準行為，而24.7 .x 中一直避免這種情況。

    Let's Encrypt 將於30.01.2025版本停止支援OCSP Must Staple 擴充。如果在此日期之後仍啟用此選項，則發行請求將失敗。

Migration notes, known issues and limitations:

遷移說明、已知問題與限制：

-   The access management was rewritten in MVC and contains behavioural changes including not rendering UNIX accounts for non-shell users. The integrated authentication via PAM has been the default for a long time so the option to disable it has been removed. The manual LDAP importer is no longer available since LDAP/RADIUS authenticators support on-demand creation and default group setup option. The “page-system-groupmanager-addprivs” privilege was removed since the page does not exist anymore. A multi-purpose privilege editor has been added under the existing “page-system-usermanager-addprivs” instead.  
    存取管理功能已在MVC中重寫，並包含一些行為變更，例如不再為非shell使用者渲染UNIX帳戶。透過PAM集成的身份驗證長期以來一直是預設設置，因此已移除禁用選項。由於LDAP/RADIUS身份驗證器支援按需建立和預設群組設定選項，因此手動LDAP導入器不再可用。 「page-system-groupmanager-addprivs」權限已移除，因為該頁面已不存在。取而代之的是，在現有的「page-system-usermanager-addprivs」下新增了一個多用途權限編輯器。
    
-   PPP devices can no longer be configured on the interface settings page. To edit the device settings use the native PPP device edit page instead.  
    PPP設備無法再透過介面設定頁面進行設定。若要編輯設備設置，請改用原生PPP設備編輯頁面。
    
-   FreeBSD 14.2 comes with the stock pf(4) behaviour regarding ICMPv6 neighbour discovery state tracking which was avoided so far in 24.7.x.  
    FreeBSD 14.2帶有關於 ICMPv6 鄰居發現狀態追蹤的 pf(4) 標準行為，而24.7 .x 版本則避免了這種情況。
    
-   Let’s Encrypt ends support for the OCSP Must Staple extension on 30.01.2025. Issuance requests will fail if this option is still enabled past this date.  
    Let's Encrypt 將於30.01.2025版本停止支援OCSP Must Staple 擴充。如果在此日期之後仍啟用此選項，則發行請求將失敗。
