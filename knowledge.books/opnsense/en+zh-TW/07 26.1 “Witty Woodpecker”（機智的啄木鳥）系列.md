# 26.1 “Witty Woodpecker”（機智的啄木鳥） Series｜26.1 “Witty Woodpecker”（機智的啄木鳥）系列

> 章節：[Releases](<000 目錄.md#c-1>) › [Community Edition](<000 目錄.md#c-2>)

For over 11 years now, OPNsense is driving innovation through modularising and hardening the open source firewall, with simple and reliable firmware upgrades, multi-language support, fast adoption of upstream software updates, modern IPv6 support, as well as clear and stable 2-Clause BSD licensing.

11 年來，OPNsense 透過模組化和強化開源防火牆、簡單可靠的韌體升級、多語言支援、上游軟體更新的快速採用、現代 IPv6 支援以及清晰穩定的 2 條款BSD 許可來推動創新。

26.1, nicknamed “Witty Woodpecker”（機智的啄木鳥）, features almost a full firewall MVC/API experience as automation rules have been promoted to the new rules GUI, Suricata version 8 with inline inspection mode using “divert”, assorted IPv6 reliability and feature improvements, router advertisements MVC/API, full code shell command escaping revamp, default IPv6 mode now using Dnsmsaq for client connectivity, Unbound blocklist source selection, an automatic host discovery service, plus much more.

26.1，暱稱“Witty Woodpecker”（機智的啄木鳥） ，具有幾乎完整的防火牆 MVC/API 體驗，自動化規則已升級到新的規則 GUI，Suricata 版本 8，使用「divert」的內聯檢查模式，各種 IPv6 可靠性和功能改進，路由器通告 MVC/API，完整的代碼 shell IPv 客戶轉義改進，Unfid-li阻止清單來源​​選擇，自動主機發現服務，以及更多功能。

The upgrade path for 25.7 will likely be unlocked on January 29, which is probably tomorrow if anyone is asking why it is not there yet. We want to ensure the upgrade goes as smoothly as possible so please be patient! :)

25.7的升級路徑可能會在1月29日解鎖，如果有人問為什麼還沒有的話，那可能就是明天了。我們希望確保升級盡可能順利，請耐心等待！ :)

## 26.1.11 (July 01, 2026)｜26.1.11（2026 年 7 月 1 日）

Back already with a bag of security advisories also for FreeBSD which came out just yesterday. We highly appreciate the increased amount of reports we are getting for the core code and we are working through them, but need to improve our process and guidelines somewhat in order to make more sense of the result for all of you. This will probably take additional effort after 26.7 is out.

回來時已經帶著一包昨天剛發布的針對 FreeBSD 的安全建議。我們非常感謝我們收到的核心程式碼報告數量的增加，我們正在解決這些報告，但需要稍微改進我們的流程和指南，以便讓大家更了解結果。 26.7 推出後，這可能需要額外的努力。

Note that this update brings the outbound to source NAT migration page, but it is only a formality as outbound NAT will stay in 26.7 although the legacy firewall rules page will move to a plugin during the major upgrade. It is the same process that was employed with ISC-DHCP. Due to this addition, however, the source NAT rules entered in the system will no longer work unless the mode is set to either “manual” or “hybrid”.

請注意，此更新將出站到來源NAT遷移頁面，但這只是一種形式，因為出站NAT將保留在26.7中，儘管舊防火牆規則頁面將在主要升級期間移動到插件。這與 ISC-DHCP 所採用的過程相同。然而，由於此添加，除非模式設定為“手動”或“混合”，否則輸入到系統中的來源NAT規則將不再起作用。

And thanks everyone for early 26.7-BETA testing! We are content to ship 26.7-RC1 early next week as a follow-up. The final release of 26.7 is planned for July 15.

感謝大家早期的26.7-BETA測試！我們很樂意在下週初發貨26.7-RC1作為後續。 26.7 預定於 7 月 15 日發售。

## 26.1.8 (May 12, 2026)｜26.1.8（2026 年 5 月 12 日）

This updated fixes two recently reported vulnerabilities in the core code pertaining to WAN DHCPv4 configuration and user management. It also includes third party updates to Dnsmasq, OpenSSH and Unbound amongst others.
