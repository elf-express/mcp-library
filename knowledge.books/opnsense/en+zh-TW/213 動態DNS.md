# Dynamic DNS｜動態DNS

> 章節：[Community Plugins](<000 目錄.md#c-36>) › [DNS](<000 目錄.md#c-46>)

In order to update DNS records when the firewall’s IP address changes, use a dynamic DNS service provider.

為了在防火牆的IP位址變更時更新DNS記錄，請使用動態DNS服務供應商。

Our os-ddclient plugin offers support for various dynamic DNS services using either the [ddclient](https://ddclient.net/) software or our native backend.

我們的 os-ddclient 外掛程式支援使用 [ddclient](https://ddclient.net/)軟體或我們的原生後端來運行各種動態DNS服務。

## Prerequisites｜先決條件

Before installing and using this plugin, make sure to register an account with one of the supported DNS providers.

在安裝和使用此外掛程式之前，請確保在受支援的DNS提供者之一註冊一個帳戶。

## Installation｜安裝

Installation of this plugin is rather easy, go to System ‣ Firmware ‣ Plugins and search for **os-ddclient**, use the \[+\] button to install it.

安裝此外掛程式非常簡單，請前往“系統”‣“韌體”‣“插件”，搜尋**os-ddclient**，然後使用\[+\]按鈕進行安裝。

Next go to Services ‣ Dynamic DNS ‣ Settings to configure one or more Dynamic DNS services.

接下來，前往“服務”‣“動態” DNS “設定”，設定一個或多個“動態” DNS服務。

## General settings｜常規設定

The general settings tab allows you to customize the services settings which will affect all dynamic DNS accounts.

常規設定標籤可讓您自訂服務設置，這將影響所有動態DNS帳戶。

| Option<br>選項 | Description<br>說明 |
| --- | --- |
| Enable<br>啟用 | Enable or disable the service<br>啟用或停用服務 |
| Verbose<br>詳細 | Enable or disable detailed log messages for the service<br>啟用或停用服務的詳細日誌訊息 |
| Allow IPv6<br>允許 IPv6 | Enable or disable retrieving and updating IPv6 addresses<br>啟用或停用 IPv6 位址的檢索與更新 |
| Interval<br>間隔 | How often (in seconds) the service checks if the appliance’s IP addresses have changed<br>服務檢查設備IP位址是否已更改的頻率（以秒為單位） |
| Backend<br>後端 | The system the Select the backend to use, either “ddclient” or “native” (see below)<br>選擇要使用的後端系統，可以是「ddclient」或「native」（見下文） |

Note

筆記

With `ddclient` developments sunsetting \[[\*](https://github.com/ddclient/ddclient/issues/528)\] we decided to offer an alternative written in Python. Selecting the native backend replaces the employed implementation. If your service is supported, we do advise to try out the new native backend which also offers support for custom HTTP requests.

隨著 `ddclient` 的開發逐漸衰落\[[\*](https://github.com/ddclient/ddclient/issues/528)\]，我們決定提供一個用 Python 編寫的替代方案。選擇本機後端替換所使用的實作。如果您的服務受支持，我們建議嘗試新的本機後端，它還提供對自訂 HTTP 請求的支援。

## Accounts｜帳戶

The accounts tab allows you to configure one or more dynamic DNS providers which the service will update using an API call over HTTP(S).

帳戶標籤可讓您配置一個或多個動態DNS提供程序，該服務將使用透過API (S) 的HTTP呼叫來更新這些提供者。

| Option<br>選項 | Description<br>說明 |
| --- | --- |
| Enabled<br>已啟用 | Enable or disable the account (allows turning entries off without removing them)<br>啟用或停用帳戶（允許關閉條目而不刪除它們） |
| Description<br>描述 | A descriptive name for the account<br>帳戶的描述性名稱 |
| Service<br>服務 | The provider of your Dynamic DNS Service<br>您的動態DNS服務的供應商 |
| resourceId | A pointer to the service to be updated, currently only relevant for Azure<br>指向要更新的服務的指針，目前僅適用於 Azure |
| Username<br>使用者名稱 | Login or user name to authenticate with, left empty when using token-based authentication<br>用於身份驗證的登入名稱或使用者名，使用基於令牌的身份驗證時留空 |
| Password<br>密碼 | Password, API key or security token to authenticate with<br>用於驗證的密碼、 API金鑰或安全令牌 |
| Zone<br>區域 | Typically the second-level domain name to update. For example: *example.com*<br>通常指要更新的二級網域。例如：*example.com* |
| Hostname(s)<br>主機名稱 | A list of fully-qualified domain names to update via the selected service, separated by commas. For example: *subdomain.example.com*<br>若要透過所選服務更新的完全限定網域列表，請以逗號分隔。例如：*subdomain.example.com* |
| Check ip method<br>檢查 IP 位址方法 | The IP checking service to get the appliance’s current IP address from<br>透過IP檢查服務取得設備的目前IP位址 |
| Interface to monitor<br>要監控的接口 | The interface to connect to the IP checking service from, or if the “Check ip method” is set to “Interface”（介面） the interface to collect an address from<br>用於連接到IP檢查服務的接口，或者，如果“檢查 IP 方法”設置為“Interface”（介面）則用於從中收集地址的接口 |
| Dynamic ipv6 host<br>動態 IPv6 主機 | Optionally overwrite the interface identifier of the ipv6 address with the given value. For example: *::aabb:33ff:fe44:ccdd*<br>可選擇使用給定值覆寫 IPv6 位址的介面識別碼。例如：*::aabb:33ff:fe44:ccdd* |
| Check ip timeout<br>檢查 IP 逾時 | How long to wait in seconds for the IP checking service to respond with an IP address<br>等待IP檢查服務回傳IP位址的逾時時間（以秒為單位） |
| Force SSL<br>強制SSL | Enable connecting to IP checking and updating services over HTTPS, though majority only support HTTPS anyway<br>啟用連接到IP以檢查和更新透過HTTPS提供的服務，儘管大多數服務僅支援HTTPS |

Note

筆記

To update a fully-qualified domain name’s `A` (IPv4) record and `AAAA` (IPv6) record, you must: \* Add one account for IPv4 with the “Check ip method” set to an IPv4 service \* Add one account for IPv6 with the “Check ip method” set to an IPv6 service \* On the *General Settings* tab, enable “Allow IPv6”（允許 IPv6）

要更新完全限定域名 `A` (IPv4) 記錄和 `AAAA` 若要新增 IPv6 記錄，您必須：* 新增一個 IPv4 帳戶，並將「檢查 IP 方法」設定為 IPv4 服務；* 新增一個 IPv6 帳戶，並將「檢查 IP 方法」設定為 IPv6 服務；* 在「常規設定」標籤中啟用 “Allow IPv6”（允許 IPv6）

## Provider-specific configuration｜提供者特定配置

### Cloudflare

For accounts with Cloudflare as provider, there is an additional option **Zone**, which should be set as the name of the zone containing the host to be updated, not its zone ID.

對於以 Cloudflare 為提供者的帳戶，還有一個額外的選項 **Zone**，應該將其設定為包含要更新的主機的區域的名稱，而不是其區域ID的名稱。

Cloudflare accepts authorization with the global token with the options

Cloudflare 接受使用全域令牌授權的選項

| Option<br>選擇權 | Value<br>價值 |
| --- | --- |
| Username<br>使用者名稱 | The email of the Cloudflare account.<br>Cloudflare 帳戶的電子郵件地址。 |
| Password<br>密碼 | Global API Key.<br>全球API金鑰。 |

Using an API token is recommended for security reasons, with `Permissions` Zone ‣ DNS ‣ Edit and `Zone Resources` Include ‣ Specific zone ‣ zone with the host, and the account options

出於安全考慮，建議使用API令牌，並結合`Permissions`區域 ‣ DNS ‣ 編輯和`Zone Resources`包含 ‣ 特定區域 ‣ 區域（與主機和帳戶選項一起使用）

| Option<br>選擇權 | Value<br>價值 |
| --- | --- |
| Username<br>使用者名稱 | token<br>令牌 |
| Password<br>密碼 | API token.<br>API令牌。 |
