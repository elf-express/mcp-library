# Routes｜路線

> 章節：[System](<000 目錄.md#c-11>)

Routing is one of the core features of your firewall, which is responsible for forwarding packets over the network based on (predefined) paths.

路由是防火牆的核心功能之一，它負責根據（預先定義的）路徑在網路上轉送封包。

Within the routing section of your firewall you can keep track of configured routes and define static routes yourself to teach your firewall which path it should take when forwarding packets to a specific network.

在防火牆的路由部分，您可以追蹤已設定的路由，並自行定義靜態路由，以告訴防火牆在將封包轉送到特定網路時應該走哪條路徑。

![](<../images/8dcb45dc-blockdiag-9a911defa1c48c439fade06078ae34.png>)

When a client sends a packet to the firewall for a network not directly attached to it, the firewall would normally check its routing table to determine to which gateway (see [Gateways](<93 閘道.md>)) it should be send.

當客戶端向防火牆發送封包，目標網路並非直接連接到該防火牆時，防火牆通常會檢查其路由表，以確定應該將封包傳送至哪個網關（請參閱[網關](<93 閘道.md>) ）。

Tip

提示

Use traceroute (Interfaces ‣ Diagnostics ‣ Trace Route) to verify which path traffic would follow to reach its destination.

使用 traceroute（介面 ‣ 診斷 ‣ 路由追蹤）來驗證流量到達目的地所遵循的路徑。

## Configuration｜配置

This is where you can setup static routes, looking at the diagram in the previous chapter, here you would define how `[1]` would access `[2]` using router `[3]`.

在這裡你可以設定靜態路由，參考上一章的圖表，在這裡你可以定義`[1]`如何使用路由器`[3]`訪問`[2]` 。

The number of settings are obviously limited, we need to know the gateway and the target network.

設定項的數量顯然是有限的，我們需要知道網關和目標網路。

---

|   |   |
| --- | --- |
| Disabled<br>已停用 | (temporary) disable this item<br>（暫時）停用此項目 |
| Network Address<br>網路位址 | Destination network to reach<br>要到達的目標網路 |
| Gateway<br>網關 | The gateway to use.<br>要使用的網關。 |
| Description<br>描述 | Optional description for this item<br>此物品的可選描述 |

Note

注意事項

Some services are known to update the routing table themselves, in which case you shouldn’t add static routes manually (OpenVPN manages its own routes for example).

已知有些服務會自行更新路由表，在這種情況下，您不應該手動新增靜態路由（例如，OpenVPN 會管理自己的路由）。

## Logs｜紀錄

路由相關的日誌記錄，例如 IPv6 的`radvd`和`rtsold`會將訊息寫入此日誌部分，這些訊息可用於偵錯目的。
