# Tor Configuration｜Tor 配置

> 章節：[Community Plugins](<000 目錄.md#c-36>) › [Other](<000 目錄.md#c-38>)

Note

筆記

Saving changes in modal dialogs does not apply the settings. To apply them, you have to click the “Reload Service”（儲值服務） button.

在模態對話方塊中儲存變更並不會套用這些設定。要套用這些設置，您必須點擊“Reload Service”（儲值服務）按鈕。

## Installation｜安裝

First of all, install the tor plugin (os-tor) from the plugins view.

首先，從插件視圖安裝 tor 插件（os-tor）。

![../../_images/menu_plugins.png](<../images/a11a0992-menu_plugins.png>)

After a page reload you will get a new menu entry under services for Tor. Open the menu and choose “Configuration”（配置） to configure the plugin.

頁面刷新後，您將在 Tor 服務下看到一個新的選單項目。開啟該選單，然後選擇“Configuration”（配置）來配置插件。

## General Settings｜常規設定

This section controls how Tor behaves in general as well as forward proxying.

本節控制 Tor 的整體行為以及前向代理。

### Global Settings｜全域設定

![../../_images/tor_general.png](<../images/3ca9c0da-tor_general.png>)

#### Tor Service Settings｜Tor 服務設定

Enable

使能夠

Controls if the service should be running. If it is enabled, it will also be enabled at boot time.

控制該服務是否應該運作。如果啟用，則該服務也會在啟動時自動啟用。

Control Port

控制埠

The control port is used for control communication with the Tor daemon. This Port requires a password, which will not be disclosed to the GUI but can be queried via the API. This setting is available for you to handle Port conflicts, so you can change this port.

控制埠用於與 Tor 守護程序進行控制通訊。此連接埠需要密碼，密碼不會透露給GUI ，但可以透過API查詢。此設定可用於處理連接埠衝突，因此您可以變更此連接埠。

Create a logfile, Send log messages to syslog

建立日誌文件，並將日誌訊息傳送到系統日誌

Enable this checkbox if you want some logging. Please note that a detailed log may lead to privacy issues.

如果您需要記錄日誌，請選取此核取方塊。請注意，詳細的日誌記錄可能會導致隱私問題。

Logfile, Syslog level

日誌文件，系統日誌等級

If the corresponding checkbox is enabled, this will be the minimum severity for sending or writing log messages.

如果啟用相應的複選框，這將是發送或寫入日誌訊息的最低嚴重程度。

Fascist Mode

法西斯模式

If internet access is filtered, you can try this option. Please note that this is not compatible with other features like “Hidden Services”（隱藏服務）.

如果您的網路存取受到過濾，您可以嘗試此選項。請注意，此選項與其他功能（例如“Hidden Services”（隱藏服務）不相容。

Fascist Firewall Ports

法西斯防火牆端口

These are the unfiltered ports of the firewall. The defaults of 80 and 443 are chosen, because they are commonly open.

這些是防火牆未過濾的連接埠。預設連接埠為 80 和 443，因為它們通常是開放的。

#### Forward Proxy｜前向代理

Note

筆記

The SOCKS proxy is only usable from localhost (127.0.0.1 and ::1) unless an ACL is added in the “SOCKS Proxy ACL”（SOCKS 代理 ACL） section.

SOCKS代理只能從本地主機（ 127.0.0.1和 ::1）使用，除非在“SOCKS Proxy ACL”（SOCKS 代理 ACL）部分加入ACL 。

Listen Interfaces

監聽介面

Add one or multiple interfaces, on which Tor should listen additionally to the loopback interface. This is required if you want to use Tor from other computers than the appliance itself. Tor will bind on the statically configured IP address from your interface configuration. If the interface has no static IP configured, it will be ignored.

增加一個或多個接口，Tor 需要監聽這些接口上的環回接口。如果您想從設備以外的其他電腦使用 Tor，則必須這樣做。 Tor 將綁定到介面配置中靜態配置的IP位址。如果介面未配置靜態IP位址，則會被忽略。

SOCKS Port Number

SOCKS埠號

The port which should be used for the SOCKS server.

SOCKS伺服器應使用的連接埠。

#### Transparent Forward Proxy｜透明前向代理

Transparent Port

透明連接埠

This port is the target for your NAT rule. Please create a rule for this port in the “Destination NAT (Port Forward)” section of the firewall.

此連接埠是您NAT規則的目標連接埠。請在防火牆的「目標NAT （連接埠轉送）」部分為此連接埠建立規則。

Transparent DNS Port

透明DNS端口

If you are using Tor transparently, you can resolve .onion addresses to IPs of the given pool for example. This also allows to keep DNS secret.

如果您以透明方式使用 Tor，例如，您可以將 .onion 位址解析為給定位址池的 IP 位址。這也有助於對DNS保密。

Transparent IP Pool

透明IP泳池

This is used to provide an IP pool to Tor, which can be used for host mapping. This needs to be a /16 network at minimum.

這用於向 Tor 提供一個IP位址池，該位址池可用於主機對映。這至少需要一個 /16 的網路。

Map Host To IP Pool

地圖主機到IP泳池

This option will assign IP addresses to resolved .onion domains by the Tor DNS service. Checking this box is recommend but a transparent IP pool is required

此選項會將IP位址指派給 Tor DNS服務解析的 .onion 網域。建議勾選此框，但必須使用透明的IP位址池。

### SOCKS ACL

Warning

警告

If untrusted devices have access to the SOCKS proxy, private information may be leaked. Please be careful with the networks you allow here.

如果不受信任的裝置能夠存取SOCKS代理伺服器，則可能會洩漏私人資訊。請謹慎選擇允許存取的網路。

![../../_images/tor_socks_acl.png](<../images/97e2cef8-tor_socks_acl.png>)

In this example, you can see that all Hosts of the 192.168.0.0/16 network have access to the Tor Proxy. By default, connections are forbidden.

在這個例子中，你可以看到192.168.0.0/16網路中的所有主機都可以存取Tor代理程式。預設情況下，連線是被禁止的。

Creating a new entry is quite easy. Just click the + and fill out the form:

建立新條目非常簡單。只需點擊“+”並填寫表格即可：

![../../_images/tor_socks_acl_edit.png](<../images/ac8e97bb-tor_socks_acl_edit.png>)

Enable

使能夠

The entry will be added to the configuration file. If this checkbox is unchecked, the entry is ignored.

該條目將被新增至設定檔。如果取消選取此複選框，則該條目將被忽略。

Protocol

協定

Select the protocol in use for this ACL. You can choose between IPv4 and IPv6. By default, IPv6 is selected.

請選擇此ACL使用的協定。您可以選擇 IPv4 或 IPv6。預設情況下，選擇 IPv6。

Network

網路

In this field, you have to add the network, on which this ACL should be applied in CIDR notation.

在此欄位中，您必須新增網絡，該網絡應以ACL表示法應用CIDR 。

Action

行動

Select if the traffic should be accepted or rejected.

選擇是否接受或拒絕流量。

## Hidden Services｜隱藏服務

A hidden service is an open TCP port, which is hosted in the Tor network and therefore the origin of the service is hard to trace. For example, you can host a website in Tor by running a webserver in your network and forwarding a hidden service port to this webserver.

隱藏服務是指開放的TCP端口，它託管在Tor網路中，因此很難追蹤服務的來源。例如，您可以透過在自己的網路中執行Web伺服器，並將隱藏服務連接埠轉送到該Web伺服器，從而在Tor網路中託管網站。

Warning

警告

This does not work with every protocol as there are protocols which open arbitrary ports. An example for that is FTP. You may work around this issue by limiting the usable ports of such services (for example 10 ports) and forward those to the server.

這種方法並非適用於所有協議，因為有些協定會開放任意連接埠。例如FTP 。您可以透過限制此類服務的可用連接埠（例如10個連接埠）並將這些連接埠轉送到伺服器來解決此問題。

If you want to host a hidden service, you need to open the hidden service tab and click the + button.

如果要託管隱藏服務，則需要開啟隱藏服務選項卡，然後按一下「+」按鈕。

![../../_images/tor_hidden_services.png](<../images/0696aee7-tor_hidden_services.png>)

The following dialog will open and you can enter a name.

接下來會開啟一個對話框，您可以在其中輸入名稱。

![../../_images/tor_hidden_services_edit.png](<../images/bc4065c6-tor_hidden_services_edit.png>)

You are allowed to add any alphanumeric name here. For example, you can call your service sampleservice.

您可以在此處新增任何字母數字名稱。例如，您可以將您的服務命名為 sampleservice。

Click “Save changes” and your service is saved to the configuration file but not saved to the Tor configuration file.

點擊“儲存變更”，您的服務將儲存到設定檔中，但不會儲存到 Tor 設定檔中。

Switch to the “Hidden Service Routing”（隱藏服務路由） tab:

切換到“Hidden Service Routing”（隱藏服務路由）選項卡：

![../../_images/tor_hidden_services_routing.png](<../images/dcacbc8a-tor_hidden_services_routing.png>)

For any port you want to forward, you have to click + and fill out the form:

要轉發任何端口，您必須點擊“+”並填寫表格：

![../../_images/tor_hidden_services_route_edit.png](<../images/6206de8c-tor_hidden_services_route_edit.png>)

Hidden Service

隱藏服務

The service on which the Destination NAT (Port Forward) applies. The entries in this list are the services created in the previous step.

目標連接埠轉送 ( NAT ) 所應用的服務。此清單中的條目是在上一個步驟中建立的服務。

Port

港口

The virtual Port in the Tor network.

Tor 網路中的虛擬連接埠。

Target Host

目標主機

The host, on which the real service is running.

運行實際服務的主機。

Target Port

目標連接埠

The real port of the service. Please note that this does not need to match the Port field but some services may act strange on mismatch.

服務的實際連接埠。請注意，此連接埠無需與「連接埠」欄位匹配，但某些服務在連接埠不匹配時可能會出現異常行為。

The sample in the screenshot would forward traffic from the virtual host in the Tor network it gets on port 80 to 127.0.0.1:8080

截圖中的範例會將 Tor 網路中虛擬主機透過 80 連接埠接收到的流量轉送到127.0.0.1:8080

Warning

警告

When using local connections like 127.0.0.1 or ::1, your application may think this connection is trusted (localhost is not from the internet). Be careful when forwarding traffic to localhost.

使用本機連線（例如127.0.0.1或 ::1）時，您的應用程式可能會認為此連線是可信任的（localhost 並非來自網路）。將流量轉送到 localhost 時請務必謹慎。

In addition to regular onion services, the services can be protected even more by requiring the client to know a secret cookie.

除了常規的洋蔥服務外，還可以透過要求客戶端知道一個秘密 cookie 來進一步保護這些服務。

This setting needs to be configured on both ends. On the server hosting the onion service, you need to configure it on the configuration tab for the onion service.

此設定需要在兩端都進行配置。在託管洋蔥服務的伺服器上，您需要在洋蔥服務的配置標籤中進行設定。

For example, if you want to have a stealth service (undetectable without knowing the key), you can configure it like the following:

例如，如果您想要一個隱蔽服務（在不知道金鑰的情況下無法偵測到），您可以如下設定：

![../../_images/tor_hidden_services_edit_very_hidden.png](<../images/473a5e30-tor_hidden_services_edit_very_hidden.png>)

Authorization Type

授權類型

Can be Stealth or Basic. Basic means that multiple clients can use the entry point and it is still visible but unauthorized hosts can not connect.

可以是隱蔽模式或基本模式。基本模式意味著多個用戶端可以使用該入口點，入口點仍然可見，但未經授權的主機無法連線。

Authorized Clients

授權客戶

You can choose some names for your clients. Each client gets a authorization cookie assigned so they can connect to it. If you set this value, this onion service will not be available to the public anymore.

您可以為客戶端選擇名稱。每個用戶端都會被指派一個授權 cookie，以便連線到該服務。如果您設定了此值，則此洋蔥服務將不再對公眾開放。

Now as this service will need to be configured to the client side as well, you will need to add the secret to the configuration page. To configure a authorization cookie for a service, you can open the Onion Service Authentication tab and fill out the form like on the screenshot:

由於此服務也需要在客戶端進行配置，因此您需要將金鑰新增至配置頁面。若要為服務設定授權 cookie，您可以開啟「洋蔥服務驗證」選項卡，並依照螢幕截圖所示填寫表單：

![../../_images/tor_hidden_servicesvery_hidden_credentials.png](<../images/89004997-tor_hidden_servicesvery_hidden_credentia.png>)

You need to configure the hostname and the authorization cookie you will get.

您需要設定主機名稱和您將獲得的授權 cookie。

Host Name

主機名稱

Enter the .onion address of the onion service.

輸入洋蔥服務的 .onion 地址。

Authentication Cookie

身份驗證 Cookie

This is the authentication code you will get from the maintainer of the onion service. Enter it into this field.

這是您將從洋蔥服務維護者獲得的驗證碼。請將其輸入到此欄位中。

When you are done, save the settings and reload the service. After that, you should be able to reach the service.

完成後，儲存設定並重新載入服務。之後，您應該可以存取該服務了。

## Relays｜接力賽

A Tor relay is a host which forwards traffic for other Tor nodes. A relay that allows traffic to pass outside of the Tor network is called an “Exit Node”（出口節點）. If the relay is configured only for you (not for public access), it is called a bridge. Bridges are used to circumvent filtering of public entry nodes based on IP/Port basis as the existence of bridges is usually unknown.

Tor 中繼是為其他 Tor 節點轉送流量的主機。允許流量通過 Tor 網路外部的中繼稱為“Exit Node”（出口節點） 。如果中繼僅供您個人使用（不對外公開），則稱為橋接器。橋接器用於繞過基於IP /連接埠的公共入口節點過濾，因為橋接器的存在通常是未知的。

### Relays And Bridges｜中繼和橋樑

![../../_images/tor_relay.png](<../images/08f7c6b3-tor_relay.png>)

Note

筆記

To be a relay, your host must have a public available port. With relaying, you will increase the anonymity of Tor and it is less risky than an exit node.

要成為 Tor 中繼，您的主機必須擁有一個公開可用的連接埠。透過中繼，您可以提高 Tor 的匿名性，而且風險比出口節點更低。

Enable

使能夠

Enable this checkbox if you want to relay traffic (forward foreign traffic).

如果要轉送流量（轉送國外流量），請選取此核取方塊。

Host

主持人

This is the host to bind the relay port to. This can be the public IP address. This setting is optional and may be omitted.

這是要綁定中繼埠的主機。可以是公網IP地址。此設定是可選的，可以省略。

Port

港口

This is the public port used. Do not forget to add a firewall rule to pass traffic to this port. Otherwise it will not work.

這是使用的公共連接埠。請務必新增防火牆規則，允許流量流向此連接埠。否則將無法正常工作。

Address

地址

You can enter the FQDN or the WAN IP of this Firewall.

您可以進入此防火牆的FQDN或WAN IP 。

Nickname

暱稱

A nickname can be used to identify your network but it must only consist of alphanumeric characters.

您可以使用暱稱來識別您的網絡，但暱稱必須僅由字母數字字元組成。

Bandwidth Rate

頻寬速率

You can limit the bandwidth Tor will use. By default, Tor will use the maximum amount of bandwidth available. The value must be at least 72 kilobits per second.

您可以限制 Tor 使用的頻寬。預設情況下，Tor 將使用最大可用頻寬。該值必須至少為 72 千位元/秒。

Bandwidth Burst

頻寬突發

See Bandwidth Rate.

請參閱頻寬速率。

Directory Port

目錄連接埠

If you have a lot of bandwidth, you can also configure a directory port. You should not enable this port if your bandwidth is small.

如果您的頻寬充足，也可以配置目錄連接埠。如果頻寬較小，則不應啟用此連接埠。

Reject Private IPs

拒絕私有IP

**IMPORTANT** DO NOT DISABLE UNLESS YOU KNOW WHAT YOU ARE DOING. This option blocks access to RFC1918 addresses regardless of the configured policy. If you disable this option, somebody can invade your network.

**重要提示** DO NOT DISABLE UNLESS YOU KNOW WHAT YOU ARE DOING 。此選項會阻止對RFC1918位址的訪問，無論配置的策略為何。如果停用此選項，其他人可以入侵您的網路。

Bridge

橋

Enable this setting, if you want to be a bridge.

如果您想成為橋樑，請啟用此設定。

Publish Server Descriptor

發布伺服器描述符

If this is disabled, Tor will not publish descriptors. If you don’t want to be in a directory (for example for testing reasons), uncheck this option.

如果停用此選項，Tor 將不會發布描述符。如果您不想進入某個目錄（例如測試目的），請取消選取此選項。

### Exit Nodes｜出口節點

Warning

警告

Providing an exit node can lead to legal issues. It may be a good idea to consult a lawyer before setting up one as you might be made responsible for traffic, which originates from a malicious Tor user.

提供出口節點可能會導致法律問題。在設定出口節點之前諮詢律師或許是個好主意，因為您可能需要對來自惡意 Tor 用戶的流量負責。

If you have relaying enabled, you can also become an exit node. To allow outgoing connections, you have to open to the “Exit Node ACL”（出口節點 ACL） tab.

如果啟用了中繼功能，您也可以成為出口節點。要允許出站連接，您必須打開“Exit Node ACL”（出口節點 ACL）選項卡。

![../../_images/tor_exit.png](<../images/e6f65270-tor_exit.png>)

Click on + to add a new ACL.

點選 + 新增的ACL 。

![../../_images/tor_exit_acl_entry.png](<../images/c25a8304-tor_exit_acl_entry.png>)

Enable

使能夠

If it is checked, the ACL will be used by Tor, otherwise the line is ignored.

如果選中，Tor 將使用ACL ，否則該行將被忽略。

Protocol

協定

Select the protocol, on which this ACL applies. You can select IPv4 and IPv6 here. IPv6 is the default.

請選擇本ACL適用的協議。您可以在此處選擇IPv4和IPv6。 IPv6為預設值。

Network

網路

You can enter a target network in CIDR notation or an IP address here. If no IP is given, any IP will match.

您可以在此輸入目標網路的CIDR表示法或IP位址。如果沒有指定IP ，則任何IP都將匹配。

Start Port, End Port

起始端口，結束端口

This match is the target port of a connection. You can provide only a start port if you want to match a single port. If you provide both, a port range will be used.

此匹配項是連接的目標連接埠。如果您只想匹配單個端口，則只需提供起始端口即可。如果您同時提供起始端口和目標端口，則將使用端口範圍。

Action

行動

If you select “Reject”（拒絕）, no exit node traffic will be sent to this host and it will not be forwarded. If you choose “Accept”（接受）, your host may be chosen as an exit node in a circuit.

如果選擇“Reject”（拒絕） ，則不會向此主機發送任何出口節點流量，也不會轉送該流量。如果選擇“Accept”（接受） ，則您的主機可能被選為電路中的出口節點。
