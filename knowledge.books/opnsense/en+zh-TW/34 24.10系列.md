# 24.10 Series｜24.10系列

> 章節：[Releases](<000 目錄.md#c-1>) › [Business Edition](<000 目錄.md#c-3>)

The OPNsense business edition transitions to this 24.10 release including ZFS snapshot support via GUI/API, rewritten dashboard, system trust MVC/API support, GRE and GIF MVC/API support, NAT 1-to-1 MVC/API support, WireGuard QR code generator, dynamic IPsec VTI tunnel support, experimental OpenVPN DCO support, FreeBSD 14.1, Python 3.11 plus much more.

OPNsense 商業版過渡到此版本。 24.10 發布包括 ZFS 透過快照支持 GUI/API重寫的儀表板，系統信任 MVC/API 支持， GRE 和 GIF MVC/API 支持， NAT 一對一 MVC/API 支援 WireGuard QR 代碼產生器，動態 IPsec VTI 支援隧道，實驗性 OpenVPN DCO 支援 FreeBSD 14.1， Python 3.11 還有更多。

Please make sure to read the migration notes before upgrading.

升級前請務必閱讀遷移說明。

Download link is as follows. An installation guide [\[1\]](<55 初始安裝和配置.md>) and the checksums for the images can be found below as well.

下載連結如下。安裝指南 [\[1\]]( https://docs.opnsense.org/manual/install.html ) 和映像校驗和也如下所示。

[https://downloads.opnsense.com/](https://downloads.opnsense.com/)
