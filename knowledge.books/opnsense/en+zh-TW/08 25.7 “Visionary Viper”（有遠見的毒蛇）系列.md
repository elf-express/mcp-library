# 25.7 “Visionary Viper”（有遠見的毒蛇） Series｜25.7 “Visionary Viper”（有遠見的毒蛇）系列

> 章節：[Releases](<000 目錄.md#c-1>) › [Community Edition](<000 目錄.md#c-2>)

For over a decade now, OPNsense is driving innovation through modularising and hardening the open source firewall, with simple and reliable firmware upgrades, multi-language support, fast adoption of upstream software updates as well as clear and stable 2-Clause BSD licensing.

十多年來，OPNsense 透過模組化和強化開源防火牆、簡單可靠的韌體升級、多語言支援、上游軟體更新的快速採用以及清晰穩定的 2 條款BSD 許可來推動創新。

25.7, nicknamed “Visionary Viper”（有遠見的毒蛇）, features reusable and thoroughly revamped frontend code, an SFTP backup plugin, experimental privilege separation for the GUI, JSON container support for aliases, a new and improved firewall automation GUI, performance enhancements especially for numerous aliases being used at once, Dnsmasq DHCP support, Kea DHCPv6 support, Greek as a new language, FreeBSD 14.3 plus much more.

25.7，綽號 “Visionary Viper”（有遠見的毒蛇）具有可重複使用且徹底改進的前端程式碼，以及 SFTP 備份插件，實驗性權限分離 GUI, JSON 容器別名支持，以及全新改良的防火牆自動化功能 GUI效能提升，尤其是同時使用多個別名時，Dnsmasq DHCP 支援、Kea DHCPv6 支援、希臘語作為新語言、FreeBSD 14.3 還有更多。

## 25.7.11 (January 15, 2026)｜25.7.11（2026 年 1 月 15 日）

25.7.11 comes at a strange point in time but we will try to offer a bit of familiarity and common sense as we probably all need more of this. <3

25.7.11 出現在一個奇怪的時間點，但我們會盡力提供一些熟悉和常識，因為我們可能都需要更多這些。 <3

This release brings the new host discovery service which resolves and remembers MAC addresses for IPv4 and IPv6 hosts in your connected networks and provides this data for the firewall MAC aliases and captive portal clients. It is now enabled by default, but you can choose to opt out by disabling the automatic discovery option.

此版本帶來了新的主機發現服務，可解析並記住連接網路中 IPv4 和 IPv6 主機的 MAC 位址，並為防火牆 MAC 別名和強制入口網站用戶端提供此資料。現在預設啟用它，但您可以透過停用自動發現選項來選擇退出。

Note to people who were already on 25.7.11 and 27.7.11\_1: a modified hostwatch version was published disabling two excessive log messages. Applying the hotfix 25.7.11\_2 will not restart hostwatch. Please do so under Interfaces: Neighbors: Automatic Discovery by either using “apply” or the restart button in the service widget. Other reported issues will be addressed shortly.

已經使用 25.7.11 和 27.7.11\_1 的使用者請注意：已發布修改後的 hostwatch 版本，停用兩個過多的日誌訊息。應用修補程式 25.7.11\_2 將不會重新啟動 Hostwatch。請在「介面：鄰居：自動發現」下使用「應用」或服務小工具中的重新啟動按鈕執行此操作。其他報告的問題將很快解決。

A lot of work went into IPv6 improvements over the holidays as is tradition with the help of users debugging their networks during that time. A number of kernel fixes have been supplied and dhcp6c will also receive a larger update in 26.1 soon.

按照傳統，在假期期間，在用戶調試網路的幫助下，IPv6 的改進進行了大量工作。已經提供了許多核心修復程序，dhcp6c 很快就會在 26.1 中收到更大的更新。

The changes are otherwise clustered around preparation for the major upgrade which brings an number of fundamental changes with the ongoing removal of ISC-DHCP from core. A plugin is already available through the development version and should auto-install. If not make sure you install it before attempting a reboot there. For the stable version everything is as it was.

這些變化主要圍繞著重大升級的準備工作，隨著不斷從核心中刪除ISC-DHCP，帶來了許多根本性的變化。插件已經可以透過開發版本使用並且應該自動安裝。如果沒有，請確保在嘗試重新啟動之前安裝它。對於穩定版本，一切都保持原樣。

That being said, 26.1-RC1 will be out early next week and RC2 likely follows quickly. We are still set for a final release date of January 28. See you on the other side!

話雖如此，26.1-RC1 將於下週初發布，RC2 可能很快就會發布。我們仍將最終發布日期定為 1 月 28 日。我們另一邊見！

## 25.7.10 (December 18, 2025)｜25.7.10（2025 年 12 月 18 日）

This update is released mainly due to the fact that FreeBSD-SA-25:12.rtsold [\[2\]](https://www.freebsd.org/security/advisories/FreeBSD-SA-25:12.rtsold.asc) has impact on WAN-facing DHCPv6 connectivity being used, but also offers a mid-size batch of improvements like CARP VHID awareness for DHCRelay and a thorough cleanup and improvement pass over the Suricata integration we have been discussing during Suricon in November.

此次更新主要是因為 FreeBSD-SA-25:12.rtsold [\[2\]]( https://www.freebsd.org/security/advisories/FreeBSD-SA-25:12.rtsold.asc ) 對正在使用的面向 WAN 的 DHCPv6 連接產生了影響，但也提供了一批中等規模的改進，例如 DHCRelay 的 CARP VHID 連接產生了影響，但也提供了一批中等規模的改進

Of special note is that the captive portal accounting moves back to ipfw(4) from pf(4) because in larger deployments accounting rules are much faster this way and the use case of Ethernet-less captive portals such as on top of WireGuard now work properly again. The hook for pluggable pf(4) “ether” rules remains for now but will be removed in 26.1 as we do not intend to advocate its use.

特別值得注意的是，強制門戶計費從 pf(4) 移回 ipfw(4)，因為在大型部署中，計費規則通過這種方式要快得多，並且無以太網強制門戶的用例（例如在 WireGuard 之上）現在可以再次正常工作。可插入 pf(4)“以太”规则的钩子目前仍然存在，但将在 26.1 中删除，因为我们不打算提倡使用它。

Also, Python has reported security issues of which a DoS in http.client could potentially affect existing installations given that an HTTP server sends a malicious response which “can consume a large amount of memory and CPU time and cause swapping”. Python has not released an update for version 3.11 at this point in time.

此外，Python 還報告了安全性問題，其中 http.client 中的 DoS 可能會影響現有安裝，因為 HTTP 伺服器發送惡意回應，「可能消耗大量記憶體和 CPU 時間並導致交換」。 Python 目前尚未发布版本 3.11 的更新。

## 25.7.r2 (July 17, 2025)｜25.7 .r2（2025年7月17日）

This is the second release candidate for your consideration. A kernel update was included to keep up with FreeBSD stable/14. A few nice things have been added to Dnsmasq as well. This is an online update only.

這是供您參考的第二個候選版本。此次更新包含了核心更新，以與 FreeBSD stable/14 保持同步。此外，Dnsmasq 還添加了一些實用功能。本次更新僅限線上。

Here are the development highlights since version 25.1 came out:

以下是自25.1版本發布以來的主要開發進展：

-   Replace the setup wizard with a modern MVC/API variant  
    將設定精靈替換為現代的MVC/API版本
    
-   Switch to reusable frontend code  
    切換到可重複使用的前端程式碼
    
-   ChartJS 4 update and related functionality migrations  
    ChartJS 4 更新及相關功能遷移
    
-   User manager CSV export and import option  
    用戶管理器CSV匯出和匯入選項
    
-   New plugin for SFTP configuration backups  
    用於SFTP配置備份的新插件
    
-   Move frontend grid from Bootgrid to Tabulator  
    將前端網格從 Bootgrid 遷移到 Tabulator
    
-   Optional privilege separation for the web GUI (running as non-root)  
    可選的 Web 權限分離GUI （以非 root 使用者身分執行）
    
-   User/group manager adds optional source network constraint  
    使用者/群組管理器新增了可選的來源網路約束
    
-   JSON container support for aliases  
    JSON容器別名支持
    
-   Firewall automation GUI revamp  
    防火牆自動化GUI改造
    
-   Performance improvements when using large amounts of aliases  
    使用大量別名時效能有所提升
    
-   Dnsmasq DHCP support for small and medium sized setups  
    Dnsmasq DHCP支援中小型部署
    
-   Support advanced (manual) configurations in Kea  
    支援 Kea 中的高級（手動）配置
    
-   Add IPv6 support (including prefix delegation) to Kea  
    為 Kea 新增 IPv6 支援（包括前綴委派）
    
-   Bridges MVC migration  
    橋樑MVC遷移
    
-   Migrate IPsec mobile page to MVC  
    將 IPsec 行動頁面移轉到MVC
    
-   Greek as a new language  
    希臘語作為一種新語言
    
-   FreeBSD 14.3
    

And these are the full patch notes against 25.7-RC1:

以下是25.7-RC1完整補丁說明：

-   system: fix passing “arguments” as parameters for cron jobs  
    系統：修正將「參數」作為 cron 作業的參數傳遞的問題
    
-   firewall: code cleanup and performance improvements for alias diagnostics page  
    防火牆：別名診斷頁面的程式碼清理和效能改進
    
-   dnsmasq: add CNAME configuration option to host overrides  
    dnsmasq：將CNAME設定選項新增至主機覆蓋
    
-   dnsmasq: add optional subnet mask to “dhcp-range” to satisfy DHCP relay requirements  
    dnsmasq：在「dhcp-range」中加入可選子網路遮罩，以符合DHCP中繼要求
    
-   dnsmasq: fix empty DHCP option value spawning stray comma  
    dnsmasq：修復空DHCP選項值所導致的多餘逗號
    
-   lang: make more strings translate-able (contributed by Tobias Degen)  
    lang：使更多字串可翻譯（由 Tobias Degen 貢獻）
    
-   lang: further updates  
    語言：進一步更新
    
-   isc-dhcp: add static mapping CSV export  
    isc-dhcp：新增靜態映射CSV導出
    
-   backend: trigger boot template reload without using configd  
    後端：無需使用 configd 即可觸發啟動範本重新加載
    
-   mvc: use getNodeContent to gather grid data  
    MVC：使用 getNodeContent 取得網格數據
    
-   ui: adjusted grid command column sizes appropriately where needed  
    使用者介面：根據需要適當調整了網格命令列的大小。
    
-   ui: exclude container fields from search functionality for now  
    使用者介面：暫時將容器欄位從搜尋功能中排除
    
-   src: bnxt: fix BASE-T, 40G AOC, 1G-CX, autoneg and unknown media lists  
    src: bnxt: 修復BASE -T、40G AOC 、1G- CX 、自動協商和未知媒體列表
    
-   src: net80211: in ieee80211\_sta\_join() only do\_ht if HT is avail  
    src: net80211: 在 ieee80211\_sta\_join() 中，僅當HT可用時才執行 do\_ht
    
-   src: linuxkpi: assorted changes from stable/14  
    src: linuxkpi: 來自 stable/14 的各種更改
    
-   src: iwlwifi: compile in ACPI support  
    src: iwlwifi: 編譯為ACPI支持
    
-   src: rtw89: enable ACPI support on FreeBSD  
    src: rtw89: 在 FreeBSD 上啟用ACPI支持
    
-   src: ifconfig: optimise non-listing case with netlink  
    src: ifconfig: 使用 netlink 最佳化非列表情況
    
-   src: pf: fix ICMP ECHO handling of ID conflicts  
    src: pf: 修復ICMP ECHO對ID衝突的處理
    

Migration notes, known issues and limitations:

遷移說明、已知問題與限制：

-   Deprecated Google Drive backups due to upstream policy changes and moved to plugins for existing users.  
    由於上游政策變更，Google 雲端硬碟備份功能已棄用，現有用戶已將其遷移至插件。
    
-   API URLs registered in the default ACLs have been switched from “camelCase” to “snake\_case”.  
    API預設 ACL 中註冊的 URL 已從「駝峰式」切換為「蛇形式」。
    
-   API grid return values now offer “%field” for a value description when available. “field” will now always be the literal value from the configuration. The API previously returned a display value for some field types, but not all.  
    API 網格傳回值現在提供「%field」作為值描述（如果可用）。 「field」現在將始終是配置中的文字值。 API 之前傳回了某些欄位類型的顯示值，但不是全部。
    
-   Reverted tunables “hw.ibrs\_disable” and “vm.pmap.pti” to FreeBSD defaults.  
    將「hw.ibrs\_disable」和「vm.pmap.pti」這兩個可調參數還原為FreeBSD預設值。
    
-   The new wizard still has bugs relating to disabling LAN configuration.  
    新嚮導仍然存在與停用LAN配置相關的錯誤。
    
-   Moved OpenVPN legacy to plugins as a first step to deprecation.  
    將 OpenVPN 的舊版本遷移到插件中，這是棄用的第一步。
    
-   Moved IPsec legacy to plugins as a first step to deprecation.  
    將 IPsec 傳統功能遷移到外掛程式中，作為棄用的第一步。
    

Stay safe, Your OPNsense team

請注意安全，OPNsense團隊敬上
