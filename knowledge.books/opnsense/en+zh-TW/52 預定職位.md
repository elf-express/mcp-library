# Scheduled jobs｜預定職位

> 章節：[Business Edition](<000 目錄.md#c-4>)

Similar to the [cron](<98 設定.md#cron>) service, scheduled jobs can execute certain predefined commands. The difference is cron is used for periodic schedules, jobs handles one time planned events.

與 [cron](<98 設定.md#cron>) 服務類似，計畫作業可以執行某些預先定義的指令。差別在於 cron 用於定期規劃，作業處理一次性規劃事件。

This feature is practical to plan automatic updates during maintenance slots or to shutdown the system if we know electrical engineers are going to cut the power at a specific time.

此功能對於在維護時段計劃自動更新或在我們知道電氣工程師將在特定時間切斷電源時關閉系統非常實用。

A list of example commands can be found at the cron section of the manual.

範例命令清單可以在手冊的 cron 部分找到。

| **Fieldname**<br>**欄位名稱** | **Purpose**<br>**目的** |
| --- | --- |
| Time<br>時間 | Date and time the action should be performed<br>應執行操作的日期和時間 |
| Until (s)<br>直到（s） | When scheduled, counts down to the moment of execution<br>安排好後，倒數至執行時刻 |
| Command<br>指令 | Configd command to execute<br>要執行的 Configd 指令 |
| Parameters<br>參數 | Optional parameters<br>可選參數 |
| Description<br>描述 | Description to use for the job.<br>用於作業的描述。 |
