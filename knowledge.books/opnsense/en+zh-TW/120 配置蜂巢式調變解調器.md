# Configuring Cellular Modems｜配置蜂巢式調變解調器

> 章節：[Interfaces](<000 目錄.md#c-19>) › [Setup Guides](<000 目錄.md#c-21>) › [Wireless and Cellular](<000 目錄.md#c-23>)

OPNsense supports a wide range of USB and miniPCIe cellular modems that can be used as primary internet (WAN) connection or as failover for a fixed/ethernet connection.

OPNsense 支援各種USB和 miniPCIe 蜂窩數據機，可用作主要互聯網 ( WAN ) 連接或用作固定/乙太網路連接的故障轉移。

With this guide we show you how to easily add a new modem and configure it to be used as primary WAN connection.

本指南將向您展示如何輕鬆新增新的數據機並將其配置為主要WAN連接。

## Supported devices｜支援的設備

In general, OPNsense should support all cellular modems that are supported by the respective FreeBSD kernel (see latest <https://cgit.freebsd.org/src/tree/sys/dev/usb/serial/u3g.c#n197>). However, not all devices behave the same way, you might have to tweak your card with specific AT commands, for example in the init string.

一般來說，OPNsense 應該支援所有 FreeBSD 核心支援的蜂巢式調變解調器（請參閱最新的<https://cgit.freebsd.org/src/tree/sys/dev/usb/serial/u3g.c#n197> ）。但是，並非所有裝置的行為都相同，您可能需要使用特定的AT命令來調整您的網卡，例如在初始化字串中進行設定。

The screenshots in this guide are for a Huawei ME909u-521 miniPCIe cellular modem.

本指南中的螢幕截圖適用於華為 ME909u-521 miniPCIe 蜂巢式調變解調器。

## Choosing the right hardware｜選擇合適的硬體

Depending on the country you want to use the modem in, you might need a different cellular modem. mPCIe cards are rather expensive so make sure you get a device that supports the LTE bands of the country and provider you want to work with. Use websites like [FrequencyCheck](https://www.frequencycheck.com/) to find the frequency band(s) used and get a cellular modem that supports these frequencies.

根據您想要使用調變解調器的國家/地區，您可能需要不同的蜂巢式調變解調器。 mPCIe 卡價格較高，因此請確保您選擇的設備支援您要使用的國家/地區和運營商的LTE頻段。您可以使用 [FrequencyCheck](https://www.frequencycheck.com/)等網站來尋找所使用的頻段，並選擇支援這些頻段的蜂巢式調變解調器。

You should also buy an appropriate pigtail antenna cable and LTE antenna. Note that LTE antennas often have different connectors than Wi-Fi antennas, chose your equipment accordingly. Getting the right antenna has a big impact on the quality of your signal. For LTE, MIMO (multiple input, multiple output) antennas should be considered, see for example [this guide](https://www.specialistantennas.co.uk/news/lte-antenna-choices-considerations).

您還應該購買合適的尾纖天線電纜和LTE天線。請注意， LTE天線的介面通常與Wi-Fi天線不同，請據此選擇合適的設備。選擇合適的天線對訊號品質有很大影響。對於LTE, MIMO （多輸入多輸出）天線，應考慮使用其他類型的天線，例如請參閱[本指南](https://www.specialistantennas.co.uk/news/lte-antenna-choices-considerations) 。

Note

注意事項

Make sure to connect the antenna to the cellular modem once you start configuring the modem in OPNsense. There is little chance that you get any signal without antenna.

在 OPNsense 中設定調變解調器時，請務必將天線連接到數據機。如果沒有天線，幾乎不可能接收任何訊號。

## Step 1 - Talking to the cellular modem｜第一步——與蜂窩調製解調器通信

First, we need to figure out what device is accepting AT commands on your modem. For the Huawei modem used in this example the device is `/dev/cuaU0.0`, other modems might provide the AT interface on another device.

首先，我們需要確定您的數據機上哪個裝置正在接收AT指令。在本例中使用的華為數據機，該設備是`/dev/cuaU0.0` ，其他數據機可能透過另一個設備提供AT介面。

On FreeBSD, `/dev/cuauN` devices are call-out ports that are used for modems instead of terminals, see section [26.2.1](https://www.freebsd.org/doc/handbook/serial.html) in the FreeBSD manual.

在 FreeBSD 中， `/dev/cuauN`設備是用於調製解調器而不是終端的呼叫端口，請參閱 FreeBSD 手冊中的 [26.2.1](https://www.freebsd.org/doc/handbook/serial.html)部分。

The best way to locate the correct port is to send AT commands to it. This can be tested using the utility `cu`:

找到正確連接埠的最佳方法是向其發送AT命令。可以使用`cu`工具進行測試：

```
cu -l /dev/cuaU0.2
Connected
AT (<-type that)
OK
```

Once you see `Connected` type `AT`. If you do not get an `OK` back, enter `~.` to quit and try the next device. In this particular example, a Sierra Wireless MC7430 card was used and `/dev/cuaU0.2` is the only device where we get `OK` back.

看到`Connected`後，輸入`AT` 。如果沒有收到`OK`的回复，請輸入`~.`退出並嘗試下一個裝置。在本例中，使用的是 Sierra Wireless MC7430網卡，只有`/dev/cuaU0.2`設備會回傳`OK`回覆。

Now, check if a SIM card is available and can be accessed:

現在，檢查SIM卡是否可用且可以存取：

```
cu -l /dev/cuaU0.2
Connected
AT+CPIN?
+CPIN: READY
```

There are multiple things that can go wrong here, the SIM card might not have been detected or you might have a pin on the SIM.

這裡可能會出現多種問題， SIM卡可能未被偵測到，或者SIM卡可能設定了 PIN 碼。

Once the SIM card is ready, quit `cu` with `~.`.

一旦SIM卡準備就緒，使用`~.`退出`cu` 。

Note

注意事項

To get rid of the pin, first check if it is valid with `AT+CPIN="1234"` where `1234` is the pin of your SIM card. To get rid of the pin, enter `AT+CLCK="SC",0,"1234"`. The pin should now be gone.

若要清除密碼，請先使用`AT+CPIN="1234"`檢查其是否有效，其中`1234`是您SIM卡的密碼。若要清除密碼，請輸入`AT+CLCK="SC",0,"1234"` 。密碼現在應該已清除。

Note

注意事項

If you never get a `READY` after `AT+CPIN?` you might want to play with the different mPCIe slots on your system. In my case on a PC Engines APU board and a Sierra Wireless card I had to switch slots until the SIM card was detected properly. The middle one did the trick for me, if someone understands how or why this is happening, please add your findings to this documentation. Also, APU boards have more than one SIM slot, try both slots in case the first option did not work.

如果在嘗試`AT+CPIN?`之後始終無法獲得`READY`您可以嘗試更換系統上的不同 mPCIe 插槽。就我而言，在PC Engines APU主機板和 Sierra Wireless 網卡上，我必須更換插槽才能正確識別SIM網卡。中間的那個插槽解決了我的問題。如果您知道這是怎麼回事，或知道原因，請將您的發現新增至此文件。此外， APU主機板有多個SIM插槽，如果第一個方法無效，請嘗試兩個插槽。

## Step 2 - Configure Point to Point device｜步驟 2 - 配置點對點設備

Go to Interfaces ‣ Point-to-Point ‣ Devices and click on **Add** in the upper right corner of the form.

轉到“介面”‣“點對點”‣“設備”，然後按一下表單右上角的**新增**。

Fill in the form like this (Example is for Dutch Mobile 4G KPN Subscription):

請如下填寫表格（範例為荷蘭移動4G KPN套餐訂閱）：

|   |   |
| --- | --- |
| **Link Type**<br>**連結類型** | PPP |
| **Link interface(s)**<br>**連結介面** | /dev/cuaU0.0 ( HUAWEI Mobile Connect - Modem)<br>/dev/cuaU0.0 ( HUAWEI行動連線 - 數據機) |
| **Description**<br>**描述** | 4G Cellular Network<br>4G 蜂窩網路 |
| **Service Provider**<br>**服務提供者** | Select Country, Provider & Plan for auto configuration<br>選擇國家/地區、服務提供者和套餐以進行自動設定 |
| **Username**<br>**使用者名稱** | Leave Empty (for NL KPN)<br>留空（用於NL KPN ） |
| **Password**<br>**密碼** | Leave Empty (for NL KPN)<br>留空（用於NL KPN ） |
| **Phone Number**<br>**電話號碼** | \*99# (for NL KPN)<br>*99#（用於NL KPN ） |
| **Access Point Name (APN)**<br>**存取點名稱 ( APN )** | fastinternet (for NL KPN 4G)<br>fastinternet (適用於NL KPN 4G) |

If you need to enter a PIN number, then click on **Advanced Options**

若您需要輸入PIN號碼，請點選**進階選項**

Click **Save** to apply the settings.

點擊**儲存**以套用設定。

[![../../_images/4g_configure_ppp.png](<../images/0d0234ff-4g_configure_ppp.png>)](https://docs.opnsense.org/_images/4g_configure_ppp.png) [![../../_images/ppp_celular_configured.png](<../images/a604b3f0-ppp_celular_configured.png>)](https://docs.opnsense.org/_images/ppp_celular_configured.png)

## Step 3 - Assign the WAN interface｜步驟 3 - 分配WAN接口

To assign the interface go to Interfaces ‣ Assignments in our case we will make this our primary internet connection and change the WAN assignment accordingly.

要分配接口，請轉到“接口”‣“分配”，在本例中，我們將把此接口設為主要互聯網連接，並相應地更改WAN分配。

To do so just change the **Network port** for **WAN** to **ppp0 (/dev/cuaU0.0) - 4G Cellular Network**.

為此，只需將 **WAN**的**網路連接埠**變更為**ppp0 (/dev/cuaU0.0) - 4G 蜂窩網路**。

Now click **Save** below the form.

現在點擊表單下方的**儲存**按鈕。

If everything went fine, then you are all set, and the default gateway will be the one of you cellular connection.

如果一切順利，那麼就一切就緒，預設網關將是您的蜂窩網路連接的網關。

[![../../_images/Interface_assignment_4g.png](<../images/a971b923-Interface_assignment_4g.png>)](https://docs.opnsense.org/_images/Interface_assignment_4g.png)

## Step 4 - Troubleshooting｜第四步 - 故障排除

In case it still does not work, first look at the log of the cellular device’s PPP connection, to do so go to: System ‣ Log Files ‣ General. If you are lucky you can see what went wrong directly in the log. Unfortunately, the PPP log is not very informative so it might not help at all.

如果仍然無效，請先查看手機PPP連接的日誌，具體操作為：系統‣日誌檔案‣常規。運氣好的話，可以直接在日誌中看到出錯的原因。遺憾的是， PPP日誌的資訊量有限，可能根本幫不上忙。

If you can’t figure out what is wrong, then a reboot to reinitialize the device can sometimes help. This seems particularly true on embedded devices, better reboot once too much and if you got lost in the options, a factory reset to start from scratch is a good idea too. In our experience playing with SIM cards from different providers required factory resets (for whatever reason) to get them to work properly.

如果實在找不到問題所在，重啟裝置重新初始化有時會有幫助。這點在嵌入式裝置上尤其適用，重啟次數過多反而會適得其反。如果您在各種設定選項中迷失了方向，恢復原廠設定也是個好辦法。根據我們的經驗，使用不同供應商的SIM卡時，無論出於何種原因，都需要恢復出廠設定才能正常運作。

Note

注意事項

As mentioned above, the SIM card needs to be available. See the hints in the first step of this tutorial to make sure everything is prepared properly.

如上所述，需要準備SIM卡。請參閱本教學第一步驟中的提示，確保一切準備就緒。

Note

注意事項

Some Sierra Wireless modems still seem to need a specific init string to work properly. One that seems to work for multiple users and LTE cards is `&F0E1Q0 +CMEE=2`. In any case you should first try without init string and only give it a try if you could not get any connection without. You can add this in Interfaces ‣ Point-to-Point ‣ Devices ‣ Your particular device ‣ Advanced Options ‣ Init String.

某些 Sierra Wireless 數據機似乎仍然需要特定的初始化字串才能正常運作。一個似乎適用於多個使用者和LTE網卡的初始化字串是`&F0E1Q0 +CMEE=2` 。無論如何，您應該先嘗試不使用初始化字串，只有在不使用初始化字串的情況下無法建立連接時才嘗試使用。您可以在「介面」‣「點對點」‣「裝置」‣「您的特定裝置」‣「進階選項」‣「初始化字串」中新增此字串。

When the device seems to work properly then checkout if the interface was assigned an IP address, go to Interfaces ‣ Overview and click on the WAN interface to see the details.

當設備看起來工作正常時，檢查介面是否分配了IP位址，轉到“介面”‣“概覽”，然後按一下WAN介面查看詳細資訊。

You should see an IP address, Gateway IP and ISP DNS server(s). If all is filled in, then either your firewall is blocking the traffic or the network connection is not working well.

您應該會看到IP位址、 IP網關和ISP DNS伺服器。如果全部填寫完整，則表示您的防火牆阻止了流量，或網路連線有問題。

In case you were not successful, you might have to check manually what is going on. Read the [Troubleshooting PPP Connections](https://www.freebsd.org/doc/handbook/ppp-troubleshoot.html) section in the FreeBSD manual for more information and consult the OPNsense support forum.

如果操作失敗，您可能需要手動檢查問題所在。請閱讀 FreeBSD 手冊中的 [故障排除PPP連接](https://www.freebsd.org/doc/handbook/ppp-troubleshoot.html)部分以獲取更多信息，並諮詢 OPNsense 支援論壇。
