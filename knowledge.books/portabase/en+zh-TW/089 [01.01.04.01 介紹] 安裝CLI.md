# Install the CLI｜安裝CLI

> 章節：[data-radix-scroll-area-viewport{scrollbar-width:none;-ms-o](<000 目錄.md#c-1>) › [portabase/portabase1.8K120](<000 目錄.md#c-2>) › [CLI｜命令列介面](<000 目錄.md#c-29>) › [Introduction｜介紹](<000 目錄.md#c-30>)

CLI


Install, check and upgrade the Portabase CLI.

安裝、檢查和升級 Portabase CLI。

The CLI ships as a single binary for Linux (amd64 / arm64), macOS and Windows.

CLI 作為適用於 Linux (amd64 / arm64)、macOS 和 Windows 的單一二進位提供。

**Requirement:** **Docker** with the **Compose plugin** on the machine where you run the CLI.

**要求：** **Docker**以及運行 CLI 的電腦上的**Compose 插件**。

## [Install](#install)｜[安裝](#install)

```bash
curl -sL https://portabase.io/install | bash
```

## [Check the version](#check-the-version)｜[查看版本](#check-the-version)

```
portabase --version
```

This also tells you if a newer release is available.

這也可以告訴您是否有新版本可用。

## [Upgrade](#upgrade)｜[升級](#upgrade)

```
portabase update
```

See [`update`](<101 [01.01.04.01.02 命令] 配置和更新.md#update>) for channels and details.

頻道及詳情請見[`update`](<101 [01.01.04.01.02 命令] 配置和更新.md#update>)。

Upgrading from 26.08.12 or earlier?

從 26.08.12 或更早版本升級？

Commands were renamed. Read the [migration guide](<103 [01.01.04.01 介紹] 遷移指南.md>) before upgrading.

命令被重命名。升級前請閱讀[遷移指南](<103 [01.01.04.01 介紹] 遷移指南.md>)。

`portabase: command not found` after install? See [Troubleshooting](<102 [01.01.04.01 介紹] 故障排除.md>).

`portabase: command not found`安裝後？請參閱[故障排除](<102 [01.01.04.01 介紹] 故障排除.md>)。
