# 成員與許可權

> 章節：[多重文件](<000 目錄.md#c-1>) › [data-radix-scroll-area-viewport{scrollbar-width:none;-ms-o](<000 目錄.md#c-2>)

邀請成員，並用 owner、admin 和 member 三種角色管理工作區許可權。

加入[工作區](/docs/zh/workspaces)的人都是成員，每位成員有一個角色：`owner`、`admin` 或 `member`。角色只控制工作區設定和團隊管理；建立任務、發表評論等日常協作對所有成員開放。

## 三種角色

| 操作 | owner | admin | member |
| --- | --- | --- | --- |
| 檢視工作區並參與日常協作 | ✓ | ✓ | ✓ |
| 修改工作區設定 | ✓ | ✓ | — |
| 邀請 `admin` 或 `member` | ✓ | ✓ | — |
| 調整或移除 `admin`、`member` | ✓ | ✓ | — |
| 授予、收回或移除 `owner` | ✓ | — | — |
| 刪除工作區 | ✓ | — | — |

工作區必須始終保留至少一名 `owner`：最後一名 `owner` 不能被降級、移除或離開。

角色不決定誰能執行智慧體。每個智慧體有獨立的訪問範圍（Access），`owner` 和 `admin` 也不能繞過它執行未授權的智慧體。詳見[智慧體](/docs/zh/agents#%E6%9D%83%E9%99%90%E4%B8%8E-access)。

## 邀請成員

`owner` 和 `admin` 在設定 → 成員中輸入郵箱、選擇角色後傳送邀請。邀請只能授予 `admin` 或 `member`；`owner` 需要先加入工作區，再由現有 `owner` 提升。

![成员管理：邀请表单与带角色的成员名册](/docs/_next/image?url=%2Fdocs%2F_next%2Fstatic%2Fmedia%2Fmembers-roster.e389ae07.webp&w=3840&q=75)

受邀者用該郵箱登入即可接受，無需提前註冊。邀請有效期 7 天，過期後重新發送。在限制註冊的自部署例項中，待接受且未過期的邀請允許該郵箱建立賬號，無需另外加入白名單，見[登入與註冊](/docs/zh/auth-setup#%E9%82%80%E8%AF%B7%E4%B8%8E%E6%B3%A8%E5%86%8C%E9%99%90%E5%88%B6)。

邀請連結只出現在郵件裡，產品介面中沒有檢視或複製它的入口。郵件傳送失敗時邀請記錄仍然存在，可以撤銷後重新發送。

## 調整角色

`admin` 可以在 `admin` 和 `member` 之間調整角色，也可以移除這兩類成員。涉及 `owner` 的變更——提升、更改或移除——只有 `owner` 能執行。

角色變化立即生效。

## 移除成員

被移除的成員立即失去工作區訪問許可權。該成員建立的任務、評論和其他協作記錄保留在工作區中。

移除成員會同時停用該成員擁有的執行時、歸檔繫結在其上的智慧體，並取消尚未結束的執行。該成員在智慧體訪問範圍（Access）中獲得的授權也會被清除，重新加入後不會自動恢復。
