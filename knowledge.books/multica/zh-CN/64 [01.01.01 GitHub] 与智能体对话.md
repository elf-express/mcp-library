# 与智能体对话

> 章節：[Multica Docs](<000 目錄.md#c-1>) › [data-radix-scroll-area-viewport{scrollbar-width:none;-ms-o](<000 目錄.md#c-2>) › [GitHub](<000 目錄.md#c-3>)

和智能体一对一独立聊天，整段对话完全私人。智能体默认没有任何任务上下文、也不会自动建任务——但你明确要求时，它会以你的工作区权限代你操作。

对话适合还没有形成明确任务的工作：梳理想法、查询工作区情况、讨论方案，或者先让智能体完成一个小任务。

**对话（Chat）是你和 [智能体](<56 [01.01.01 GitHub] 智能体.md>) 的一对一独立沟通**——跳出 [任务](<53 [01.01.01 GitHub] 任务.md>) 看板。智能体默认**没有任何任务上下文**——它不盯着你的看板，也不会自己把对话变成任务——整段对话**完全私人**（[工作区](<51 [01.01.01 GitHub] 工作区.md>) 里其他人、包括 admin 都看不到）。适合和智能体讨论方案、做 brainstorming、问一个不属于任何任务的问题。

对话**不绑定某一条任务**：智能体不会自动收到任务的描述和评论，但仍可以在权限范围内用 Multica CLI 查询工作区、项目、任务和 skill。

对话也可以携带背景。点击输入框左下角的 **+**，选择**项目上下文**，为对话挂上一个[项目](<54 [01.01.01 GitHub] 项目.md>)；智能体执行时会收到该项目的描述和仓库等资源。

![与智能体的对话：提问后得到整理成表格的回答](<../images/9d5fbb2f-image.webp>)

## [开始对话](#%E5%BC%80%E5%A7%8B%E5%AF%B9%E8%AF%9D)

1.  打开侧边栏中的**对话**。
2.  点击新建，选择一个你有权运行的智能体。
3.  输入消息，也可以附加图片或文件。
4.  发送后，Multica 会为这条消息创建一次执行，回复会回到当前对话。

运行时离线时，消息会等待它重新上线。智能体被归档，或者你失去调用权限后，不能继续发送新消息。

第一条消息发送前，对话页会显示所选智能体配置的最多三个建议。选择后会把完整提示词填入输入框而不会发送，方便你先调整。未配置建议的智能体会使用本地化的通用示例。

## [对话与任务的选择](#%E5%AF%B9%E8%AF%9D%E4%B8%8E%E4%BB%BB%E5%8A%A1%E7%9A%84%E9%80%89%E6%8B%A9)

| 需要 | 更适合 |
| --- | --- |
| 快速提问、探索方案或处理私人草稿 | **对话** |
| 明确负责人、状态、优先级和交付结果 | **任务** |
| 让团队成员查看背景并继续讨论 | **任务** |
| 临时查看工作区信息，不需要建立工作记录 | **对话** |

在 Multica 中创建的直接对话只对创建者开放，其他工作区成员和管理员不能读取。需要团队共同查看的结论，应整理到任务、项目说明或 skill 中。

## [多轮上下文](#%E5%A4%9A%E8%BD%AE%E4%B8%8A%E4%B8%8B%E6%96%87)

同一段对话会尽量继续 AI 编程工具中的原会话，因此后续消息不需要重复前面的内容。Multica 会保存会话标识，并把后续执行路由到能够访问该会话的运行时。

如果本地会话已经不存在、上下文无法继续，或者上一次错误不适合复用，运行时会从新会话开始。对话中的历史消息仍然保留。

## [查看和停止执行](#%E6%9F%A5%E7%9C%8B%E5%92%8C%E5%81%9C%E6%AD%A2%E6%89%A7%E8%A1%8C)

智能体运行时，界面会显示当前阶段和工具活动。展开**查看详情**可以检查更完整的执行过程。

需要中断时，点击输入框旁的停止按钮。已经返回到对话中的内容会保留；尚未开始处理的输入会尽量恢复到编辑框中。

## [整理对话列表](#%E6%95%B4%E7%90%86%E5%AF%B9%E8%AF%9D%E5%88%97%E8%A1%A8)

对话支持重命名、置顶、归档和删除：

-   **置顶**把常用对话固定在列表前面；
-   **归档**把对话移到"已归档"并设为只读；
-   **取消归档**后可以继续发送消息；
-   **删除**会永久移除对话及其中的消息。

如果对话绑定了外部渠道（如 Slack），归档时绑定会断开，取消归档不会恢复，需要重新绑定。

删除对话无法撤销，并会停止其中尚未结束的执行。暂时不需要时用归档。
