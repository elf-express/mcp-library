# Module ngx_http_autoindex_module

> 章節：[en](<000 目錄.md#c-1>) › [docs](<000 目錄.md#c-2>) › [http](<000 目錄.md#c-5>)

## Module ngx\_http\_autoindex\_module

|   |
| --- |
| [Example Configuration](#example)<br>[Directives](#directives)<br>     [autoindex](#autoindex)<br>     [autoindex\_exact\_size](#autoindex_exact_size)<br>     [autoindex\_format](#autoindex_format)<br>     [autoindex\_localtime](#autoindex_localtime) |

The `ngx_http_autoindex_module` module processes requests ending with the slash character (‘`/`’) and produces a directory listing. Usually a request is passed to the `ngx_http_autoindex_module` module when the [ngx\_http\_index\_module](<071 [01.01.03 http] Module ngx_http_index_module.md>) module cannot find an index file.

#### Example Configuration

> ```
> location / {
>     autoindex on;
> }
> ```

For the HTML [format](#autoindex_format), specifies whether exact file sizes should be output in the directory listing, or rather rounded to kilobytes, megabytes, and gigabytes.

<table>
<tr><th>Syntax:</th><td><code><strong>autoindex_format</strong> <code>html</code> | <code>xml</code> | <code>json</code> | <code>jsonp</code>;</code></td></tr>
<tr><th>Default:</th><td>autoindex_format html;</td></tr>
<tr><th>Context:</th><td><code>http</code>, <code>server</code>, <code>location</code></td></tr>
</table>

This directive appeared in version 1.7.9.

Sets the format of a directory listing.

When the JSONP format is used, the name of a callback function is set with the `callback` request argument. If the argument is missing or has an empty value, then the JSON format is used.

The XML output can be transformed using the [ngx\_http\_xslt\_module](<110 [01.01.03 http] Module ngx_http_xslt_module.md>) module.

<table>
<tr><th>Syntax:</th><td><code><strong>autoindex_localtime</strong> <code>on</code> | <code>off</code>;</code></td></tr>
<tr><th>Default:</th><td>autoindex_localtime off;</td></tr>
<tr><th>Context:</th><td><code>http</code>, <code>server</code>, <code>location</code></td></tr>
</table>

For the HTML [format](#autoindex_format), specifies whether times in the directory listing should be output in the local time zone or UTC.
