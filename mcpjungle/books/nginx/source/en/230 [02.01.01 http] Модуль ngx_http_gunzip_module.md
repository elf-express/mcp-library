# Модуль ngx_http_gunzip_module

> 章節：[ru](<000 目錄.md#c-9>) › [docs](<000 目錄.md#c-10>) › [http](<000 目錄.md#c-11>)

## Модуль ngx\_http\_gunzip\_module

|   |
| --- |
| [Пример конфигурации](#example)<br>[Директивы](#directives)<br>     [gunzip](#gunzip)<br>     [gunzip\_buffers](#gunzip_buffers) |

Модуль `ngx_http_gunzip_module` — это фильтр, распаковывающий ответы с “`Content-Encoding: gzip`” для тех клиентов, которые не поддерживают метод сжатия “gzip”. Модуль будет полезен, когда данные желательно хранить сжатыми для экономии места и сокращения затрат на ввод-вывод.

По умолчанию этот модуль не собирается, его сборку необходимо разрешить с помощью конфигурационного параметра `--with-http_gunzip_module`.

#### Пример конфигурации

> ```
> location /storage/ {
>     gunzip on;
>     ...
> }
> ```

#### Директивы

<table>
<tr><th>Синтаксис:</th><td><code><strong>gunzip</strong> <code>on</code> | <code>off</code>;</code></td></tr>
<tr><th>Умолчание:</th><td>gunzip off;</td></tr>
<tr><th>Контекст:</th><td><code>http</code>, <code>server</code>, <code>location</code></td></tr>
</table>

Разрешает или запрещает распаковку ответов, сжатых методом gzip, для тех клиентов, которые его не поддерживают. Если разрешено, то для определения, поддерживает ли клиент gzip, также учитываются следующие директивы: [gzip\_http\_version](<231 [02.01.01 http] Модуль ngx_http_gzip_module.md#gzip_http_version>), [gzip\_proxied](<231 [02.01.01 http] Модуль ngx_http_gzip_module.md#gzip_proxied>) и [gzip\_disable](<231 [02.01.01 http] Модуль ngx_http_gzip_module.md#gzip_disable>). См. также директиву [gzip\_vary](<231 [02.01.01 http] Модуль ngx_http_gzip_module.md#gzip_vary>).

<table>
<tr><th>Синтаксис:</th><td><code><strong>gunzip_buffers</strong> <code><i>число</i></code> <code><i>размер</i></code>;</code></td></tr>
<tr><th>Умолчание:</th><td>gunzip_buffers 32 4k|16 8k;</td></tr>
<tr><th>Контекст:</th><td><code>http</code>, <code>server</code>, <code>location</code></td></tr>
</table>

Задаёт `*число*` и `*размер*` буферов, в которые будет разжиматься ответ. По умолчанию размер одного буфера равен размеру страницы. В зависимости от платформы это или 4K, или 8K.
