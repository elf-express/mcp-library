# Модуль ngx_stream_return_module

> 章節：[ru](<000 目錄.md#c-9>) › [docs](<000 目錄.md#c-10>) › [stream](<000 目錄.md#c-14>)

## Модуль ngx\_stream\_return\_module

|   |
| --- |
| [Пример конфигурации](#example)<br>[Директивы](#directives)<br>     [return](#return) |

Модуль `ngx_stream_return_module` (1.11.2) позволяет отправить заданное значение клиенту и после этого закрыть соединение.

#### Пример конфигурации

> ```
> server {
>     listen 12345;
>     return $time_iso8601;
> }
> ```

#### Директивы

|   |   |
| --- | --- |
| Синтаксис: | ``**return** `*значение*`;`` |
| Умолчание: | — |
| Контекст: | `server` |

Задаёт `*значение*`, отправляемое клиенту. В качестве значения можно использовать текст, переменные и их комбинации.
