# Модуль ngx_http_random_index_module

> 章節：[ru](<000 目錄.md#c-9>) › [docs](<000 目錄.md#c-10>) › [http](<000 目錄.md#c-11>)

## Модуль ngx\_http\_random\_index\_module

|   |
| --- |
| [Пример конфигурации](#example)<br>[Директивы](#directives)<br>     [random\_index](#random_index) |

Модуль `ngx_http_random_index_module` обслуживает запросы, оканчивающиеся слэшом (‘`/`’), и выдаёт случайный файл в качестве индексного файла каталога. Модуль выполняется до модуля [ngx\_http\_index\_module](<236 [02.01.01 http] Модуль ngx_http_index_module.md>).

По умолчанию этот модуль не собирается, его сборку необходимо разрешить с помощью конфигурационного параметра `--with-http_random_index_module`.

#### Пример конфигурации

> ```
> location / {
>     random_index on;
> }
> ```

<tr><th>Умолчание:</th><td>random_index off;</td></tr>
