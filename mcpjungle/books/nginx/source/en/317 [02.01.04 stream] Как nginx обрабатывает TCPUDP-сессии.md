# Как nginx обрабатывает TCPUDP-сессии

> 章節：[ru](<000 目錄.md#c-9>) › [docs](<000 目錄.md#c-10>) › [stream](<000 目錄.md#c-14>)

## Как nginx обрабатывает TCP/UDP-сессии

Обработка клиентской TCP/UDP-сессии происходит последовательными **фазами**:

`Post-accept`

Первая фаза после принятия клиентского соединения. В этой фазе выполняется модуль [ngx\_stream\_realip\_module](<309 [02.01.04 stream] Модуль ngx_stream_realip_module.md>).

`Pre-access`

Предварительная проверка доступа. В этой фазе выполняются модули [ngx\_stream\_limit\_conn\_module](<301 [02.01.04 stream] Модуль ngx_stream_limit_conn_module.md>) и [ngx\_stream\_set\_module](<311 [02.01.04 stream] Модуль ngx_stream_set_module.md>).

`Access`

Ограничение доступа для клиента перед обработкой данных. В этой фазе выполняется модуль [ngx\_stream\_access\_module](<296 [02.01.04 stream] Модуль ngx_stream_access_module.md>), при использовании [njs](<290 [02.01.03 njs] Модуль nginx JavaScript.md>) выполняется директива [js\_access](<300 [02.01.04 stream] Модуль ngx_stream_js_module.md#js_access>).

`SSL`

Терминирование TLS/SSL. В этой фазе выполняется модуль [ngx\_stream\_ssl\_module](<313 [02.01.04 stream] Модуль ngx_stream_ssl_module.md>).

`Preread`

Чтение первых байт данных в [буфер предварительного чтения](<297 [02.01.04 stream] Модуль ngx_stream_core_module.md#preread_buffer_size>) для анализа, например модулем [ngx\_stream\_ssl\_preread\_module](<314 [02.01.04 stream] Модуль ngx_stream_ssl_preread_module.md>), перед их обработкой. При использовании [njs](<290 [02.01.03 njs] Модуль nginx JavaScript.md>) в этой фазе выполняется директива [js\_preread](<300 [02.01.04 stream] Модуль ngx_stream_js_module.md#js_preread>).

`Content`

Обязательная фаза, в которой происходит обработка данных, как правило [проксирование](<307 [02.01.04 stream] Модуль ngx_stream_proxy_module.md>) на [группу серверов](<316 [02.01.04 stream] Модуль ngx_stream_upstream_module.md>) или [отправка](<310 [02.01.04 stream] Модуль ngx_stream_return_module.md>) клиенту заданного значения. При использовании [njs](<290 [02.01.03 njs] Модуль nginx JavaScript.md>) в этой фазе выполняется директива [js\_filter](<300 [02.01.04 stream] Модуль ngx_stream_js_module.md#js_filter>).

`Log`

Заключительная фаза, в которой записывается результат обработки клиентской сессии. В этой фазе выполняется модуль [ngx\_stream\_log\_module](<302 [02.01.04 stream] Модуль ngx_stream_log_module.md>).
