# Модуль ngx_http_index_module

> 章節：[ru](<000 目錄.md#c-9>) › [docs](<000 目錄.md#c-10>) › [http](<000 目錄.md#c-11>)

## Модуль ngx\_http\_index\_module

|   |
| --- |
| [Пример конфигурации](#example)<br>[Директивы](#directives)<br>     [index](#index) |

Модуль `ngx_http_index_module` обслуживает запросы, оканчивающиеся слэшом (‘`/`’). Такие запросы также могут обслуживаться модулями [ngx\_http\_autoindex\_module](<218 [02.01.01 http] Модуль ngx_http_autoindex_module.md>) и [ngx\_http\_random\_index\_module](<250 [02.01.01 http] Модуль ngx_http_random_index_module.md>).

#### Пример конфигурации

> ```
> location / {
>     index index.$geo.html index.html;
> }
> ```

#### Директивы

<table>
<tr><th>Синтаксис:</th><td><code><strong>index</strong> <code><i>файл</i></code> ...;</code></td></tr>
<tr><th>Умолчание:</th><td>index index.html;</td></tr>
<tr><th>Контекст:</th><td><code>http</code>, <code>server</code>, <code>location</code></td></tr>
</table>

Определяет файлы, которые будут использоваться в качестве индекса. В имени файла можно использовать переменные. Наличие файлов проверяется в порядке их перечисления. В конце списка может стоять файл с абсолютным путём. Пример:

> ```
> index index.$geo.html index.0.html /index.html;
> ```

Необходимо иметь в виду, что при использовании индексного файла делается внутреннее перенаправление и запрос может быть обработан уже в другом location’е. Например, в такой конфигурации:

> ```
> location = / {
>     index index.html;
> }
> 
> location / {
>     ...
> }
> ```

запрос “`/`” будет фактически обработан во втором location’е как “`/index.html`”.
