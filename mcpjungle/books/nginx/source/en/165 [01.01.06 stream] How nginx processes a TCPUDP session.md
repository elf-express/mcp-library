# How nginx processes a TCPUDP session

> 章節：[en](<000 目錄.md#c-1>) › [docs](<000 目錄.md#c-2>) › [stream](<000 目錄.md#c-8>)

## How nginx processes a TCP/UDP session

A TCP/UDP session from a client is processed in successive steps called **phases**:

`Post-accept`

The first phase after accepting a client connection. The [ngx\_stream\_realip\_module](<156 [01.01.06 stream] Module ngx_stream_realip_module.md>) module is invoked at this phase.

`Pre-access`

Preliminary check for access. The [ngx\_stream\_limit\_conn\_module](<147 [01.01.06 stream] Module ngx_stream_limit_conn_module.md>) and [ngx\_stream\_set\_module](<158 [01.01.06 stream] Module ngx_stream_set_module.md>) modules are invoked at this phase.

`Access`

Client access limitation before actual data processing. At this phase, the [ngx\_stream\_access\_module](<141 [01.01.06 stream] Module ngx_stream_access_module.md>) module is invoked, for [njs](<133 [01.01.05 njs] nginx JavaScript module.md>), the [js\_access](<145 [01.01.06 stream] Module ngx_stream_js_module.md#js_access>) directive is invoked.

`SSL`

TLS/SSL termination. The [ngx\_stream\_ssl\_module](<160 [01.01.06 stream] Module ngx_stream_ssl_module.md>) module is invoked at this phase.

`Preread`

Reading initial bytes of data into the [preread buffer](<142 [01.01.06 stream] Module ngx_stream_core_module.md#preread_buffer_size>) to allow modules such as [ngx\_stream\_ssl\_preread\_module](<161 [01.01.06 stream] Module ngx_stream_ssl_preread_module.md>) analyze the data before its processing. For [njs](<133 [01.01.05 njs] nginx JavaScript module.md>), the [js\_preread](<145 [01.01.06 stream] Module ngx_stream_js_module.md#js_preread>) directive is invoked at this phase.

`Content`

Mandatory phase where data is actually processed, usually [proxied](<154 [01.01.06 stream] Module ngx_stream_proxy_module.md>) to [upstream](<163 [01.01.06 stream] Module ngx_stream_upstream_module.md>) servers, or a specified value is [returned](<157 [01.01.06 stream] Module ngx_stream_return_module.md>) to a client. For [njs](<133 [01.01.05 njs] nginx JavaScript module.md>), the [js\_filter](<145 [01.01.06 stream] Module ngx_stream_js_module.md#js_filter>) directive is invoked at this phase.

`Log`

The final phase where the result of a client session processing is recorded. The [ngx\_stream\_log\_module](<148 [01.01.06 stream] Module ngx_stream_log_module.md>) module is invoked at this phase.
