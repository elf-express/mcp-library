# Модуль ngx_stream_mqtt_preread_module

> 章節：[ru](<000 目錄.md#c-9>) › [docs](<000 目錄.md#c-10>) › [stream](<000 目錄.md#c-14>)

## Модуль ngx\_stream\_mqtt\_preread\_module

|   |
| --- |
| [Пример конфигурации](#example)<br>[Директивы](#directives)<br>     [mqtt\_preread](#mqtt_preread)<br>[Встроенные переменные](#variables) |

Модуль `ngx_stream_mqtt_preread_module` (1.23.4) позволяет извлекать информацию из сообщения CONNECT протокола Message Queuing Telemetry Transport (MQTT) версий [3.1.1](https://docs.oasis-open.org/mqtt/mqtt/v3.1.1/mqtt-v3.1.1.html) и [5.0](https://docs.oasis-open.org/mqtt/mqtt/v5.0/mqtt-v5.0.html), например имя пользователя или ID клиента.

> Модуль доступен как часть [коммерческой подписки](https://www.f5.com/products/nginx).

#### Пример конфигурации

> ```
> mqtt_preread on;
> return       $mqtt_preread_clientid;
> ```

#### Директивы

<table>
<tr><th>Синтаксис:</th><td><code><strong>mqtt_preread</strong> <code>on</code> | <code>off</code>;</code></td></tr>
<tr><th>Умолчание:</th><td>mqtt_preread off;</td></tr>
<tr><th>Контекст:</th><td><code>stream</code>, <code>server</code></td></tr>
</table>

Разрешает извлечение информации из сообщения СONNECT во время фазы [предварительного чтения](<317 [02.01.04 stream] Как nginx обрабатывает TCPUDP-сессии.md#preread_phase>).

#### Встроенные переменные

`$mqtt_preread_clientid`

значение `clientid` из СONNECT-сообщения

`$mqtt_preread_username`

значение `username` из СONNECT-сообщения
