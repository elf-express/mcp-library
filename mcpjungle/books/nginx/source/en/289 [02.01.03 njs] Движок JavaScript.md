# Движок JavaScript

> 章節：[ru](<000 目錄.md#c-9>) › [docs](<000 目錄.md#c-10>) › [njs](<000 目錄.md#c-13>)

## Движок JavaScript

Начиная с версии [0.8.6](https://nginx.org/ru/docs/njs/changes.html#njs0.8.6) поддерживается несколько JS-движков. Для выбора движка используется директива `js_engine` в [http](<238 [02.01.01 http] Модуль ngx_http_js_module.md#js_engine>) и [stream](<300 [02.01.04 stream] Модуль ngx_stream_js_module.md#js_engine>). По умолчанию используется движок njs.

#### Движок njs

> Движок njs объявлен устаревшим начиная с [1.0.0](https://nginx.org/ru/docs/njs/changes.html#njs1.0.0); для нового кода следует использовать движок [QuickJS](#quickjs_engine).

njs  — встроенный движок JavaScript, разработанный как часть модуля njs. Подробнее см. в разделе [Совместимость](<288 [02.01.03 njs] Совместимость.md>).

#### Движок QuickJS

[QuickJS](https://bellard.org/quickjs/)  — компактный встроенный движок JavaScript, который поддерживает спецификацию [ES2023](https://tc39.es/ecma262/2023/), включая модули, асинхронные генераторы, прокси и BigInt.

Начиная с [0.8.6](https://nginx.org/ru/docs/njs/changes.html#njs0.8.6) доступна оперативная замена [njs/nginx objects](https://nginx.org/ru/docs/njs/reference.html) для обеспечения совместимости с движком njs, но с некоторыми исключениями:

-   API njs: [`njs.dump()`](https://nginx.org/ru/docs/njs/reference.html#njs_dump), `console.dump()`.
-   устаревшее API: `require()`, вместо необходимо использовать утверждение `import`.
-   директива `js_preload_object` для [http](<238 [02.01.01 http] Модуль ngx_http_js_module.md#js_preload_object>) и [stream](<300 [02.01.04 stream] Модуль ngx_stream_js_module.md#js_preload_object>).

статус встроенных модулей njs:

-   [`buffer`](https://nginx.org/ru/docs/njs/reference.html#buffer): начиная с [0.8.6](https://nginx.org/ru/docs/njs/changes.html#njs0.8.6).
-   [`crypto`](https://nginx.org/ru/docs/njs/reference.html#crypto): начиная с [0.8.10](https://nginx.org/ru/docs/njs/changes.html#njs0.8.10).
-   [`fs`](https://nginx.org/ru/docs/njs/reference.html#njs_api_fs): начиная с [0.8.9](https://nginx.org/ru/docs/njs/changes.html#njs0.8.9).
-   [`querystring`](https://nginx.org/ru/docs/njs/reference.html#querystring): начиная с [0.8.10](https://nginx.org/ru/docs/njs/changes.html#njs0.8.10).
-   [`WebCrypto`](https://nginx.org/ru/docs/njs/reference.html#builtin_crypto): начиная с [0.8.10](https://nginx.org/ru/docs/njs/changes.html#njs0.8.10).
-   [`xml`](https://nginx.org/ru/docs/njs/reference.html#xml): начиная с [0.8.10](https://nginx.org/ru/docs/njs/changes.html#njs0.8.10).
-   [`zlib`](https://nginx.org/ru/docs/njs/reference.html#zlib): начиная с [0.8.5](https://nginx.org/ru/docs/njs/changes.html#njs0.8.5).

статус встроенных объектов njs:

-   [`process`](https://nginx.org/ru/docs/njs/reference.html#process): начиная с [0.8.8](https://nginx.org/ru/docs/njs/changes.html#njs0.8.8).
-   [`TextDecoder`](https://nginx.org/ru/docs/njs/reference.html#textdecoder): начиная с [0.8.10](https://nginx.org/ru/docs/njs/changes.html#njs0.8.10).
-   [`TextEncoder`](https://nginx.org/ru/docs/njs/reference.html#textencoder): начиная с [0.8.10](https://nginx.org/ru/docs/njs/changes.html#njs0.8.10).

статус встроенных объектов nginx:

-   [`ngx.fetch`](https://nginx.org/ru/docs/njs/reference.html#ngx_fetch): начиная с [0.9.1](https://nginx.org/ru/docs/njs/changes.html#njs0.9.1).
-   [`shared dictionary`](https://nginx.org/ru/docs/njs/reference.html#ngx_shared): начиная с [0.8.8](https://nginx.org/ru/docs/njs/changes.html#njs0.8.8).
