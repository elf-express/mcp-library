# Модуль ngx_http_empty_gif_module

> 章節：[ru](<000 目錄.md#c-9>) › [docs](<000 目錄.md#c-10>) › [http](<000 目錄.md#c-11>)

## Модуль ngx\_http\_empty\_gif\_module

|   |
| --- |
| [Пример конфигурации](#example)<br>[Директивы](#directives)<br>     [empty\_gif](#empty_gif) |

Модуль `ngx_http_empty_gif_module` выдаёт однопиксельный прозрачный GIF.

#### Пример конфигурации

> ```
> location = /_.gif {
>     empty_gif;
> }
> ```

#### Директивы

|   |   |
| --- | --- |
| Синтаксис: | `**empty_gif**;` |
| Умолчание: | — |
| Контекст: | `location` |

Разрешает в содержащем location выдавать однопиксельный прозрачный GIF.
