# JavaScript Engine

> 章節：[en](<000 目錄.md#c-1>) › [docs](<000 目錄.md#c-2>) › [njs](<000 目錄.md#c-7>)

## JavaScript Engine

Starting from version [0.8.6](<129 [01.01.05 njs] Changes.md#njs0.8.6>), multiple JavaScript engines are supported. To specify a particular engine, use the `js_engine` directive available for both the [http](<073 [01.01.03 http] Module ngx_http_js_module.md#js_engine>) and [stream](<145 [01.01.06 stream] Module ngx_stream_js_module.md#js_engine>). By default, the njs engine is used.

#### njs engine

> The njs engine is deprecated since [1.0.0](<129 [01.01.05 njs] Changes.md#njs1.0.0>); new code should use the [QuickJS](#quickjs_engine) engine instead.

njs is an embeddable JavaScript engine developed as a part of the njs module. See the [Compatibility](<131 [01.01.05 njs] Compatibility.md>) section for details.

#### QuickJS engine

[QuickJS](https://bellard.org/quickjs/) is a lightweight, embeddable JavaScript engine that supports the [ES2023](https://tc39.es/ecma262/2023/) specification, including features as modules, asynchronous generators, proxies and BigInt.

Since version [0.8.6](<129 [01.01.05 njs] Changes.md#njs0.8.6>), a drop-in replacement for [njs/nginx objects](<137 [01.01.05 njs] Reference.md>) has been introduced to ensure compatibility with the njs engine, with the following exceptions:

-   njs-specific API: [`njs.dump()`](<137 [01.01.05 njs] Reference.md#njs_dump>), `console.dump()`.
-   deprecated API: `require()`, use the `import` statement instead.
-   `js_preload_object` directive for [http](<073 [01.01.03 http] Module ngx_http_js_module.md#js_preload_object>) and [stream](<145 [01.01.06 stream] Module ngx_stream_js_module.md#js_preload_object>).
