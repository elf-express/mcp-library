# Module ngx_stream_return_module

> 章節：[en](<000 目錄.md#c-1>) › [docs](<000 目錄.md#c-2>) › [stream](<000 目錄.md#c-8>)

## Module ngx\_stream\_return\_module

|   |
| --- |
| [Example Configuration](#example)<br>[Directives](#directives)<br>     [return](#return) |

The `ngx_stream_return_module` module (1.11.2) allows sending a specified value to the client and then closing the connection.

#### Example Configuration

> ```
> server {
>     listen 12345;
>     return $time_iso8601;
> }
> ```

#### Directives

|   |   |
| --- | --- |
| Syntax: | ``**return** `*value*`;`` |
| Default: | — |
| Context: | `server` |

Specifies a `*value*` to send to the client. The value can contain text, variables, and their combination.
