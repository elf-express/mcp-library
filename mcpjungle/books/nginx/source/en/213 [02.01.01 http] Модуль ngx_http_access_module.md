# Модуль ngx_http_access_module

> 章節：[ru](<000 目錄.md#c-9>) › [docs](<000 目錄.md#c-10>) › [http](<000 目錄.md#c-11>)

## Модуль ngx\_http\_access\_module

|   |
| --- |
| [Пример конфигурации](#example)<br>[Директивы](#directives)<br>     [allow](#allow)<br>     [deny](#deny) |

Модуль `ngx_http_access_module` позволяет ограничить доступ для определённых адресов клиентов.

Ограничить доступ можно также по [паролю](<215 [02.01.01 http] Модуль ngx_http_auth_basic_module.md>), по [результату подзапроса](<217 [02.01.01 http] Модуль ngx_http_auth_request_module.md>) или по [JWT](<216 [02.01.01 http] Модуль ngx_http_auth_jwt_module.md>). Одновременное ограничение доступа по адресу и паролю управляется директивой [satisfy](<221 [02.01.01 http] Модуль ngx_http_core_module.md#satisfy>).

#### Пример конфигурации

> ```
> location / {
>     deny  192.168.1.1;
>     allow 192.168.1.0/24;
>     allow 10.1.1.0/16;
>     allow 2001:0db8::/32;
>     deny  all;
> }
> ```

Правила проверяются в порядке их записи до первого соответствия. В данном примере доступ разрешён только для IPv4-сетей `10.1.1.0/16` и `192.168.1.0/24`, кроме адреса `192.168.1.1`, и для IPv6-сети `2001:0db8::/32`. Если правил много, то лучше воспользоваться переменными модуля [ngx\_http\_geo\_module](<227 [02.01.01 http] Модуль ngx_http_geo_module.md>).

#### Директивы

|   |   |
| --- | --- |
| Синтаксис: | ``**allow** `*адрес*` \| `*CIDR*` \| `unix:` \| `all`;`` |
| Умолчание: | — |
| Контекст: | `http`, `server`, `location`, `limit_except` |

Разрешает доступ для указанной сети или адреса. Если указано специальное значение `unix:` (1.5.1), разрешает доступ для всех UNIX-сокетов.

На одном уровне может быть указано несколько директив `allow`. Директивы наследуются с предыдущего уровня конфигурации при условии, что на данном уровне не описаны свои директивы `allow` и `deny`.

|   |   |
| --- | --- |
| Синтаксис: | ``**deny** `*адрес*` \| `*CIDR*` \| `unix:` \| `all`;`` |
| Умолчание: | — |
| Контекст: | `http`, `server`, `location`, `limit_except` |

Запрещает доступ для указанной сети или адреса. Если указано специальное значение `unix:` (1.5.1), запрещает доступ для всех UNIX-сокетов.

На одном уровне может быть указано несколько директив `deny`. Директивы наследуются с предыдущего уровня конфигурации при условии, что на данном уровне не описаны свои директивы `allow` и `deny`.
