Модуль `ngx_stream_set_module` (1.19.3) позволяет устанавливать значение переменной.

`ngx_stream_set_module` ( 1.19.3 ) 模組可讓您設定變數的值。

#### Пример конфигурации｜配置範例

> ```
> server {
>
> 伺服器{
>     listen 12345;
>
>     聽 12345；
>     set    $true 1;
>
>     設定 $true 為 1；
> }
> ```

#### Директивы｜指令

|   |   |
| --- | --- |
| Синтаксис:<br>語法： | ``**set** `*$переменная*` `*значение*`;``<br>` `**set** ` *$變數* ` ` *值* `;` ` |
| Умолчание:<br>預設值： | — |
| Контекст:<br>背景： | `server` |

Устанавливает значение указанной переменной. В качестве значения можно использовать текст, переменные и их комбинации.

設定指定變數的值。該值可以是文字、變數或二者的組合。
