## Модуль ngx\_stream\_return\_module｜ngx_stream_return_module 模組

|   |
| --- |
| [Пример конфигурации](#example)<br>[Директивы](#directives)<br>     [return](#return)<br>[設定範例](#example)<br> [指令](#directives)<br> [返回](#return) |

Модуль `ngx_stream_return_module` (1.11.2) позволяет отправить заданное значение клиенту и после этого закрыть соединение.

`ngx_stream_return_module` ( 1.11.2 ) 模組可讓您向客戶端發送指定的值，然後關閉連線。

#### Пример конфигурации｜配置範例

> ```
> server {
>
> 伺服器{
>     listen 12345;
>
>     聽 12345；
>     return $time_iso8601;
>
>     返回 $time_iso8601；
> }
> ```

#### Директивы｜指令

|   |   |
| --- | --- |
| Синтаксис:<br>文法： | ``**return** `*значение*`;``<br>` `**return** ` *值* `;` ` |
| Умолчание:<br>預設值： | — |
| Контекст:<br>背景： | `server` |

Задаёт `*значение*`, отправляемое клиенту. В качестве значения можно использовать текст, переменные и их комбинации.

指定傳送給客戶端的`*значение*` 。該值可以是文字、變數或二者的組合。
