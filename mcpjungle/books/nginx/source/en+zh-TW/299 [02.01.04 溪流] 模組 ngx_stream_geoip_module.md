## Модуль ngx\_stream\_geoip\_module｜模組 ngx\_stream\_geoip\_module

|   |
| --- |
| [Пример конфигурации](#example)<br>[Директивы](#directives)<br>     [geoip\_country](#geoip_country)<br>     [geoip\_city](#geoip_city)<br>     [geoip\_org](#geoip_org)<br>[設定範例](#example)<br> [指令](#directives)<br> [geoip_country](#geoip_country)<br> [geoip_city](#geoip_city)<br> [geoip_org](#geoip_org) |

Модуль `ngx_stream_geoip_module` (1.11.3) создаёт переменные, значения которых зависят от IP-адреса клиента, используя готовые базы данных [MaxMind](http://www.maxmind.com/).

`ngx_stream_geoip_module` ( 1.11.3 ) 模組建立變量，其值取決於客戶端的IP位址，使用現成的 [MaxMind](http://www.maxmind.com/)資料庫。

При использовании баз данных с поддержкой IPv6 IPv4-адреса ищутся отображёнными на IPv6.

使用支援 IPv6 的資料庫時，會將 IPv4 位址對應為 IPv6 位址進行搜尋。

По умолчанию этот модуль не собирается, его сборку необходимо разрешить с помощью конфигурационного параметра `--with-stream_geoip_module`.

此模組預設未構建，必須使用`--with-stream_geoip_module`配置參數啟用。

> Для сборки и работы этого модуля нужна библиотека [MaxMind GeoIP](http://www.maxmind.com/app/c).
>
> 要建置和運行此模組，您需要 [MaxMind GeoIP](http://www.maxmind.com/app/c)庫。

#### Пример конфигурации｜配置範例

> ```
> stream {
>
> 流{
>     geoip_country         GeoIP.dat;
>
>     geoip_country GeoIP.dat；
>     geoip_city            GeoLiteCity.dat;
>
>     geoip_city GeoLiteCity.dat;
> 
>     map $geoip_city_continent_code $nearest_server {
>
>     映射 $geoip_city_continent_code $nearest_server {
>         default        example.com;
>
>         預設範例.com；
>         EU          eu.example.com;
>         NA          na.example.com;
>         AS          as.example.com;
>     }
>    ...
> }
> ```

Задаёт базу данных для определения страны в зависимости от значения IP-адреса клиента. При использовании этой базы данных доступны следующие переменные:

指定用於根據客戶端IP位址確定國家/地區的資料庫。使用此資料庫時，可以使用以下變數：

`$geoip_country_code`

двухбуквенный код страны, например, “`RU`”, “`US`”.

兩位字母的國家代碼，例如「 `RU` 」、「 `US` 」。

`$geoip_country_code3`

трёхбуквенный код страны, например, “`RUS`”, “`USA`”.

三字母國家代碼，例如「 `RUS` 」、「 `USA` 」。

`$geoip_country_name`

название страны, например, “`Russian Federation`”, “`United States`”.

國家名稱，例如「 `Russian Federation` 」、「 `United States` 」。

|   |   |
| --- | --- |
| Синтаксис:<br>文法： | ``**geoip_city** `*файл*`;``<br>` `**geoip_city** ` *文件* `;` ` |
| Умолчание:<br>預設值： | — |
| Контекст:<br>背景： | `stream` |

Задаёт базу данных для определения страны, региона и города в зависимости от значения IP-адреса клиента. При использовании этой базы данных доступны следующие переменные:

指定一個資料庫，用於根據客戶端的IP地址確定國家/地區、區域和城市。使用此資料庫時，可以使用以下變數：

`$geoip_area_code`

телефонный код области (только для США).

區號（僅限美國）。

> Данная переменная может содержать неактуальную информацию, т.к. соответствующее поле базы данных объявлено устаревшим.
>
> 由於相應的資料庫欄位已被棄用，因此該變數可能包含過時的資訊。

`$geoip_city_continent_code`

двухбуквенный код континента, например, “`EU`”, “`NA`”.

兩位字母的大洲代碼，例如“ `EU` ”、“ `NA` ”。

`$geoip_city_country_code`

двухбуквенный код страны, например, “`RU`”, “`US`”.

兩位字母的國家代碼，例如“ `RU` ”、“ `US` ”。

`$geoip_city_country_code3`

трёхбуквенный код страны, например, “`RUS`”, “`USA`”.

三個字母的國家代碼，例如「 `RUS` 」、「 `USA` 」。

`$geoip_city_country_name`

название страны, например, “`Russian Federation`”, “`United States`”.

國家名稱，例如「 `Russian Federation` 」、「 `United States` 」。

`$geoip_dma_code`

DMA-код региона в США (также известный как “код агломерации”), согласно [геотаргетингу](https://developers.google.com/adwords/api/docs/appendix/cities-DMAregions) Google AdWords API.

DMA是美國的一個地區代碼（也稱為「大都會區代碼」），根據 Google AdWords (https://developers.google.com/adwords/api/docs/appendix/cities-DMAregions) [地理定位]API 。

`$geoip_latitude`

широта.

緯度。

`$geoip_longitude`

долгота.

經度。

`$geoip_region`

двухсимвольный код региона страны (область, край, штат, провинция, федеральная земля и тому подобное), например, “`48`”, “`DC`”.

一個國家的兩個字元代碼（州、邊疆區、州、省、聯邦領土等），例如「 `48` 」、「 `DC` 」。

`$geoip_region_name`

название региона страны (область, край, штат, провинция, федеральная земля и тому подобное), например, “`Moscow City`”, “`District of Columbia`”.

國家名稱（州、邊疆區、州、省、聯邦領土等），例如「 `Moscow City` 」、「 `District of Columbia` 」。

`$geoip_city`

название города, например, “`Moscow`”, “`Washington`”.

城市名稱，例如「 `Moscow` 」、「 `Washington` 」。

`$geoip_postal_code`

почтовый индекс.

郵遞區號.

Задаёт базу данных для определения названия организации в зависимости от значения IP-адреса клиента. При использовании этой базы данных доступна следующая переменная:

指定一個資料庫，用於根據客戶的IP地址確定組織名稱。使用此資料庫時，可以使用以下變數：

`$geoip_org`

название организации, например, “The University of Melbourne”（墨爾本大學）.

組織名稱，例如“The University of Melbourne”（墨爾本大學） 。
