## nginx JavaScript module｜nginx JavaScript 模組

njs is an nginx module that extends the server's functionality through JavaScript scripting, enabling the creation of custom server-side logic and [more](#usecases).

njs 是一個 nginx 模組，它透過 JavaScript 腳本擴展伺服器的功能，從而能夠創建自訂的伺服器端邏輯和 [更多](#usecases) 。

nginx calls JavaScript handlers at a fixed set of [integration points](https://nginx.org/en/docs/njs/integration.html): HTTP request and response processing phases, stream session phases, variable evaluation, and periodic timers. njs is not a standalone application runtime: it has no start-up script and no event loop of its own, JavaScript code runs only when nginx invokes a configured handler, and control returns to nginx once the handler completes.

nginx 會在一組固定的整合點（ (https://nginx.org/en/docs/njs/integration.html): HTTP ）呼叫 JavaScript 處理程序，這些點包含請求和回應處理階段、串流會話階段、變數求值階段以及週期性計時器。 njs 不是一個獨立的應用程式執行時間：它沒有啟動腳本，也沒有自己的事件循環，JavaScript 程式碼僅在 nginx 呼叫已設定的處理程序時執行，處理程序完成後控制權會傳回給 nginx。

> The built-in [njs](<132 [01.01.05 紐澤西州] JavaScript 引擎.md#njs_engine>) JavaScript engine is deprecated since [1.0.0](<129 [01.01.05 紐澤西州] 變化.md#njs1.0.0>); new configurations should use the [QuickJS](<132 [01.01.05 紐澤西州] JavaScript 引擎.md#quickjs_engine>) engine.
>
> 內建的 [njs](<132 [01.01.05 紐澤西州] JavaScript 引擎.md#njs_engine>) JavaScript 引擎自 [1.0.0](<129 [01.01.05 紐澤西州] 變化.md#njs1.0.0>)起已被棄用；新的配置應使用 [QuickJS](<132 [01.01.05 紐澤西州] JavaScript 引擎.md#quickjs_engine>)引擎。

#### Basic HTTP Example｜基本HTTP範例

To use njs in nginx:

在 nginx 中使用 njs：

-   [install](<134 [01.01.05 紐澤西州] 下載並安裝.md>) njs  
    [安裝](<134 [01.01.05 紐澤西州] 下載並安裝.md>) njs
    
-   create an njs script file, for example, `http.js`. See [Reference](<137 [01.01.05 紐澤西州] 參考.md>) for the list of njs properties and methods.  
    建立一個 njs 腳本文件，例如`http.js` 。有關 njs 屬性和方法的列表，請參閱 [參考](<137 [01.01.05 紐澤西州] 參考.md>) 。
    
    > ```js
    > function hello(r) {
    >
    > 函數你好（r）{
    >     r.return(200, "Hello world!");
    >
    >     r.return(200, "你好世界！");
    > }
    > 
    > export default {hello};
    > ```
    
-   in the `nginx.conf` file, enable [ngx\_http\_js\_module](<073 [01.01.03 http] 模組 ngx_http_js_module.md>) module and specify the [js\_import](<073 [01.01.03 http] 模組 ngx_http_js_module.md#js_import>) directive with the `http.js` script file:  
    在`nginx.conf`檔案中，啟用 [ngx\_http\_js\_module](<073 [01.01.03 http] 模組 ngx_http_js_module.md>)模組，並在`http.js`腳本檔案中指定 [js\_import](<073 [01.01.03 http] 模組 ngx_http_js_module.md#js_import>)指令：
    
    > ```
    > load_module modules/ngx_http_js_module.so;
    >
    > 載入模組 modules/ngx_http_js_module.so;
    > 
    > events {}
    >
    > 事件 {}
    > 
    > http {
    >     # since 0.9.1｜自0.9.1
    >     js_engine qjs;
    >
    >     js_engine qjs；
    > 
    >     js_import http.js;
    > 
    >     server {
    >
    >     伺服器 {
    >         listen 8000;
    >
    >         聽 8000；
    > 
    >         location / {
    >
    >         地點 / {
    >             js_content http.hello;
    >
    >             js_content http.hello；
    >         }
    >     }
    > }
    > ```
    

There is also a standalone [command line](<130 [01.01.05 紐澤西州] 命令列介面.md>) utility that can be used independently of nginx for njs development and debugging.

此外，還有一個獨立的 [命令列](<130 [01.01.05 紐澤西州] 命令列介面.md>)實用程序，可以獨立於 nginx 用於 njs 開發和調試。
