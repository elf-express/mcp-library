Модуль `ngx_http_sub_module` — это фильтр, изменяющий в ответе одну заданную строку на другую.

`ngx_http_sub_module`模組是一個過濾器，它將響應從一個給定的字串更改為另一個字串。

По умолчанию этот модуль не собирается, его сборку необходимо разрешить с помощью конфигурационного параметра `--with-http_sub_module`.

此模組預設未構建，必須使用`--with-http_sub_module`配置參數啟用。

#### Пример конфигурации｜配置範例

> ```
> location / {
>
> 地點/{
>     sub_filter '<a href="http://127.0.0.1:8080/'  '<a href="https://$host/';
>
>     子過濾器'<a href=" http://127.0.0.1:8080/' '<a href=" https://$host/';
>     sub_filter '<img src="http://127.0.0.1:8080/' '<img src="https://$host/';
>
>     子過濾器'<img src=" http://127.0.0.1:8080/' '<img src=" https://$host/';
>     sub_filter_once on;
>
>     子過濾器一次開啟；
> }
> ```

#### Директивы｜指令

|   |   |
| --- | --- |
| Синтаксис:<br>語法： | ``**sub_filter** `*строка*` `*замена*`;``<br>` `**sub_filter** ` *字串* ` ` *替換* `;` ` |
| Умолчание:<br>預設值： | — |
| Контекст:<br>背景： | `http`, `server`, `location` |

Задаёт строку, которую нужно заменить, и строку замены. Заменяемая строка проверяется без учёта регистра. В заменяемой строке (1.9.4) и в строке замены можно использовать переменные. На одном уровне конфигурации может быть указано несколько директив `sub_filter` (1.9.4). Директивы наследуются с предыдущего уровня конфигурации при условии, что на данном уровне не описаны свои директивы `sub_filter`.

指定要替換的字串和替換字串。替換字串區分大小寫。替換字串（ 1.9.4 ）和目標字串中均可使用變數。單一配置等級可以指定多個`sub_filter` （ 1.9.4 ）指令。除非當前層級定義了自己的`sub_filter`指令，否則指令將從上一個配置層級繼承。

Эта директива появилась в версии 1.5.1.

該指令是在版本1.5.1中引入的。

Позволяет сохранить поле заголовка “Last-Modified”（最後修改日期） исходного ответа во время замены для лучшего кэширования ответов.

允許您在替換過程中保留原始回應的“Last-Modified”（最後修改日期）標頭字段，以便更好地快取回應。

По умолчанию поле заголовка удаляется, так как содержимое ответа изменяется во время обработки.

預設情況下，標頭欄位會被移除，因為回應內容在處理過程中會被修改。

Определяет, сколько раз нужно искать каждую из заменяемых строк: один раз или многократно.

確定每個替換字串要搜尋多少次：一次或多次。

<tr><th>Синтаксис:<br>語法：</th><td><code><strong>sub_filter_types<br>子過濾器類型</strong> <code><i>mime-тип<br>MIME 類型</i></code> ...;</code></td></tr>
<tr><th>Умолчание:<br>預設值：</th><td>sub_filter_types text/html;<br>篩選類型 text/html；</td></tr>
<tr><th>Контекст:<br>上下文：</th><td><code>http</code>, <code>server<br>伺服器</code>, <code>location<br>位置</code></td></tr>
</table>

Разрешает замену строк в ответах с указанными MIME-типами в дополнение к “`text/html`”. Специальное значение “`*`” соответствует любому MIME-типу (0.8.29).

除了「 `text/html` 」之外，還允許使用指定的MIME類型對回應進行字串替換。特殊值“ `*` ”匹配任何MIME類型（ 0.8.29 ）。
