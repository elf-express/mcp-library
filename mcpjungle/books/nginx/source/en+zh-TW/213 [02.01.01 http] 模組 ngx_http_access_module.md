# Модуль ngx_http_access_module｜模組 ngx_http_access_module

> 章節：[ru](<000 目錄.md#c-9>) › [docs｜文件](<000 目錄.md#c-10>) › [http](<000 目錄.md#c-11>)

## Модуль ngx\_http\_access\_module｜模組 ngx\_http\_access\_module

|   |
| --- |
| [Пример конфигурации](#example)<br>[Директивы](#directives)<br>     [allow](#allow)<br>     [deny](#deny)<br>[設定範例](#example)<br>[指令](#directives)<br>     [允許](#allow)<br>     [拒絕](#deny) |

Модуль `ngx_http_access_module` позволяет ограничить доступ для определённых адресов клиентов.

`ngx_http_access_module` 模組可讓您限制對某些客戶端位址的存取。

Ограничить доступ можно также по [паролю](<215 [02.01.01 http] 模組 ngx_http_auth_basic_module.md>), по [результату подзапроса](<217 [02.01.01 http] ngx_http_auth_request_module 模組.md>) или по [JWT](<216 [02.01.01 http] ngx_http_auth_jwt_module 模組.md>). Одновременное ограничение доступа по адресу и паролю управляется директивой [satisfy](<221 [02.01.01 http] 模組 ngx_http_core_module.md#satisfy>).

您也可以透過[密碼](<215 [02.01.01 http] 模組 ngx_http_auth_basic_module.md>)、[子查詢結果](<217 [02.01.01 http] ngx_http_auth_request_module 模組.md>)或[JWT](<216 [02.01.01 http] ngx_http_auth_jwt_module 模組.md>)來限制存取。透過位址和密碼同時限制存取由 [satisfy](<221 [02.01.01 http] 模組 ngx_http_core_module.md#satisfy>) 指令控制。

#### Пример конфигурации｜配置範例

> ```
> location / {
>
> 地點 / {
>     deny  192.168.1.1;
>
>     否認192.168.1.1；
>     allow 192.168.1.0/24;
>
>     允許192.168.1.0/24；
>     allow 10.1.1.0/16;
>
>     允許10.1.1.0/16；
>     allow 2001:0db8::/32;
>
>     允許2001:0db8::/32；
>     deny  all;
>
>     否認一切；
> }
> ```

Правила проверяются в порядке их записи до первого соответствия. В данном примере доступ разрешён только для IPv4-сетей `10.1.1.0/16` и `192.168.1.0/24`, кроме адреса `192.168.1.1`, и для IPv6-сети `2001:0db8::/32`. Если правил много, то лучше воспользоваться переменными модуля [ngx\_http\_geo\_module](<227 [02.01.01 http] 模組 ngx_http_geo_module.md>).

規則按照編寫的順序進行檢查，直到出現第一個匹配項。在此範例中，僅允許 IPv4 網路 `10.1.1.0/16` 和 `192.168.1.0/24`（位址 `192.168.1.1` 除外）以及 IPv6 網路 `2001:0db8::/32` 存取。如果規則很多，那麼最好使用模組變數[ngx\_http\_geo\_module](<227 [02.01.01 http] 模組 ngx_http_geo_module.md>)。

#### Директивы｜指令

|   |   |
| --- | --- |
| Синтаксис:<br>語法： | ``**allow** `*адрес*` \| `*CIDR*` \| `unix:` \| `all`;``<br>``**allow** `*地址*` \| `*CIDR*` \| `unix:` \| `全部`;`` |
| Умолчание:<br>預設值： | — |
| Контекст:<br>上下文： | `http`, `server`, `location`, `limit_except` |

Разрешает доступ для указанной сети или адреса. Если указано специальное значение `unix:` (1.5.1), разрешает доступ для всех UNIX-сокетов.

允許存取指定的網路或位址。如果指定特殊值`unix:` (1.5.1)，則允許存取所有UNIX套接字。

На одном уровне может быть указано несколько директив `allow`. Директивы наследуются с предыдущего уровня конфигурации при условии, что на данном уровне не описаны свои директивы `allow` и `deny`.

可以在同一層級指定多個`allow`指令。指令繼承自先前的配置級別，前提是該級別沒有描述其自己的指令`allow`和`deny`。

|   |   |
| --- | --- |
| Синтаксис:<br>語法： | ``**deny** `*адрес*` \| `*CIDR*` \| `unix:` \| `all`;``<br>``**deny** `*地址*` \| `*CIDR*` \| `unix:` \| `全部`;`` |
| Умолчание:<br>預設值： | — |
| Контекст:<br>上下文： | `http`, `server`, `location`, `limit_except` |

Запрещает доступ для указанной сети или адреса. Если указано специальное значение `unix:` (1.5.1), запрещает доступ для всех UNIX-сокетов.

拒絕存取指定的網路或位址。如果指定了特殊值 `unix:` (1.5.1)，則拒絕所有 UNIX 套接字的存取。

На одном уровне может быть указано несколько директив `deny`. Директивы наследуются с предыдущего уровня конфигурации при условии, что на данном уровне не описаны свои директивы `allow` и `deny`.

可以在同一層級指定多個`deny`指令。指令繼承自先前的配置級別，前提是該級別沒有描述其自己的指令`allow` 和`deny`。
