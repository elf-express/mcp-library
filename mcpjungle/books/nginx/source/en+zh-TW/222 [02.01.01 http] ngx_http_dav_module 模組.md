Модуль `ngx_http_dav_module` предназначен для автоматизации задач управления файлами на сервере по протоколу WebDAV. Модуль обрабатывает HTTP- и WebDAV-методы PUT, DELETE, MKCOL, COPY и MOVE.

`ngx_http_dav_module`模組旨在利用 WebDAV 協定自動執行伺服器上的檔案管理任務。本模組支援HTTP以及 WebDAV 方法PUT, DELETE, MKCOL, COPY和MOVE 。

По умолчанию этот модуль не собирается, его сборку необходимо разрешить с помощью конфигурационного параметра `--with-http_dav_module`.

此模組預設未構建，必須使用`--with-http_dav_module`配置參數啟用。

> WebDAV-клиенты, которые требуют для работы дополнительных WebDAV-методов, не будут работать с этим модулем.
>
> 需要額外 WebDAV 方法才能正常運作的 WebDAV 用戶端將無法與此模組一起使用。

#### Пример конфигурации｜配置範例

> ```
> location / {
>
> 地點 / {
>     root                  /data/www;
>
>     根目錄 /data/www;
> 
>     client_body_temp_path /data/client_temp;
> 
>     dav_methods PUT DELETE MKCOL COPY MOVE;
>
>     dav_methods PUT DELETE MKCOL COPY MOVE ;
> 
>     create_full_put_path  on;
>
>     啟用 create_full_put_path；
>     dav_access            group:rw  all:r;
>
>     dav_access 群組：讀寫所有：讀寫；
> 
>     limit_except GET {
>         allow 192.168.1.0/32;
>
>         允許192.168.1.0/32 ；
>         deny  all;
>
>         否認一切；
>     }
> }
> ```

По спецификации WebDAV-метод PUT может создавать файл только в уже существующем каталоге. Данная директива разрешает создавать все необходимые промежуточные каталоги.

根據 WebDAV 規範， PUT方法只能在現有目錄中建立檔案。此指令允許建立所有必要的中間目錄。

Разрешает указанные HTTP- и WebDAV-методы. Параметр `off` запрещает все методы, обрабатываемые данным модулем. Поддерживаются следующие методы: `PUT`, `DELETE`, `MKCOL`, `COPY` и `MOVE`.

允許指定的 HTTP 和 WebDAV 方法。 `off`選項禁用該模組處理的所有方法。支援以下方法：`PUT`, `DELETE`, `MKCOL`, `COPY`和`MOVE`。

Файл, загружаемый методом PUT, записывается во временный файл, а потом этот файл переименовывается. Начиная с версии 0.8.9 временный файл и его постоянное место хранения могут располагаться на разных файловых системах. Однако нужно учитывать, что в этом случае вместо дешёвой операции переименовывания в пределах одной файловой системы файл копируется с одной файловой системы на другую. Поэтому лучше, если сохраняемые файлы будут находиться на той же файловой системе, что и каталог с временными файлами, задаваемый директивой [client\_body\_temp\_path](<221 [02.01.01 http] 模組 ngx_http_core_module.md#client_body_temp_path>) для данного location.

使用PUT方法上傳的文件會被寫入一個暫存文件，然後該文件會被重新命名。從0.8.9版本開始，暫存檔案及其永久儲存位置可以位於不同的檔案系統上。但是需要注意的是，在這種情況下，檔案不是在同一個檔案系統內進行簡單的重新命名操作，而是從一個檔案系統複製到另一個檔案系統。因此，對於給定的位置，最好將已儲存的檔案與 [client\_body\_temp\_path](<221 [02.01.01 http] 模組 ngx_http_core_module.md#client_body_temp_path>)指令指定的暫存檔案目錄位於同一檔案系統上。

При создании файла с помощью метода PUT можно задать дату модификации, передав её в поле заголовка “Date”（日期）.

使用PUT方法建立檔案時，可以透過在“Date”（日期）標頭欄位中傳遞來指定修改日期。
