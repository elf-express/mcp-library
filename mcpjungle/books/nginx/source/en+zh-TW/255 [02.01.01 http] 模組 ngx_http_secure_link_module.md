## Модуль ngx\_http\_secure\_link\_module｜模組 ngx\_http\_secure\_link\_module

Модуль `ngx_http_secure_link_module` (0.7.18) позволяет проверять аутентичность запрашиваемых ссылок, защищать ресурсы от несанкционированного доступа, а также ограничивать срок действия ссылок.

模組`ngx_http_secure_link_module`（0.7.18）可讓您檢查請求連結的真實性，保護資源免遭未經授權的訪問，並限制連結的有效期限。

Правильность запрашиваемой ссылки проверяется сравнением переданного в запросе значения контрольной суммы со значением, вычисляемым для запроса. Если ссылка имеет ограниченный срок действия и он истёк, ссылка считается устаревшей. Результат этих проверок делается доступным в переменной `$secure_link`.

透過將請求中發送的校驗和值與為請求計算的值進行比較來驗證所請求連結的正確性。如果連結有有限的過期日期並且已經過期，則該連結被視為過期。這些檢查的結果在變數`$secure_link`中可用。

Модуль реализует два альтернативных режима работы. В первом режиме, который включается директивой [secure\_link\_secret](#secure_link_secret), можно проверить аутентичность запрашиваемых ссылок и защитить их от несанкционированного доступа. Второй режим (0.8.50) включается директивами [secure\_link](#secure_link) и [secure\_link\_md5](#secure_link_md5), и позволяет также ограничить срок действия ссылок.

此模組實現兩種替代操作模式。在第一種模式下，由 [secure\_link\_secret](#secure_link_secret) 指令啟用，您可以檢查所要求連結的真實性並保護它們免受未經授權的存取。第二種模式（0.8.50）由 [secure\_link](#secure_link) 和 [secure\_link\_md5](#secure_link_md5) 指令啟用，並且還允許您限制連結的有效期限。

По умолчанию этот модуль не собирается, его сборку необходимо разрешить с помощью конфигурационного параметра `--with-http_secure_link_module`.

此模組預設未構建，必須使用`--with-http_secure_link_module`配置參數啟用。

#### Директивы｜指令

|   |   |
| --- | --- |
| Синтаксис:<br>語法： | ``**secure_link** `*выражение*`;``<br>``**secure_link** `*表情*`;`` |
| Умолчание:<br>預設值： | — |
| Контекст:<br>背景： | `http`, `server`, `location` |

Задаёт строку с переменными, из которой будет выделено значение контрольной суммы и время действия ссылки.

設定一個包含變數的字串，將從中提取校驗和值和連結有效期。

Используемые в выражении переменные обычно связаны с запросом; см. [пример](#secure_link_md5) ниже.

表達式中使用的變數通常與查詢相關；請參閱下面的[範例](#secure_link_md5)。

Выделенное из строки значение контрольной суммы сравнивается со значением MD5-хэша, вычисляемым для выражения, заданного директивой [secure\_link\_md5](#secure_link_md5). Если контрольные суммы не совпадают, значением переменной `$secure_link` становится пустая строка. Если контрольные суммы совпадают, проверяется время действия ссылки. Если срок действия ссылки задан и истёк, переменная `$secure_link` получает значение “`0`”. В противном случае она получает значение “`1`”. Значение MD5-хэш передаётся в запросе закодированным в [base64url](https://datatracker.ietf.org/doc/html/rfc4648#section-5).

從字串中提取的校驗和值與為 [secure\_link\_md5](#secure_link_md5) 指令指定的表達式計算的 MD5 雜湊值進行比較。如果校驗和不匹配，則變數`$secure_link`的值將變為空字串。如果校驗和匹配，則檢查連結的有效期。如果連結設定為過期並且已經過期，則變數`$secure_link`設定為「`0`」。否則它會得到值“`1`”。 MD5-哈希值在以 [base64url](https://datatracker.ietf.org/doc/html/rfc4648#section-5) 編碼的請求中發送。

Если ссылка имеет ограниченный срок действия, время её действия задаётся в секундах с начала эпохи (1 января 1970 года 00:00:00 GMT). Значение указывается в выражении после MD5-хэша и отделяется от него запятой. Время действия ссылки, переданное в запросе, делается доступным в переменной `$secure_link_expires` для использования в директиве [secure\_link\_md5](#secure_link_md5). Если время действия ссылки не задано, ссылка имеет неограниченный срок действия.

如果連結具有有限的到期日期，則其到期時間以從紀元開始（1970 年 1 月 1 日00:00:00 GMT）開始的秒數為單位指定。該值在 MD5 哈希之後的表達式中指示，並以逗號分隔。請求中傳遞的連結過期時間可在變數 `$secure_link_expires` 中使用，以在 [secure\_link\_md5](#secure_link_md5) 指令中使用。如果不指定連結過期時間，則連結將無限期過期。

| --- | --- |
| Синтаксис:<br>語法： | ``**secure_link_md5** `*выражение*`;``<br>``**secure_link_md5** `*表情*`;`` |
| Умолчание:<br>預設值： | — |
| Контекст:<br>上下文： | `http`, `server`, `location` |

Задаёт выражение, для которого считается значение MD5-хэш, сравниваемое с переданным в запросе.

指定計算 MD5 雜湊值的表達式，與請求中傳遞的雜湊值進行比較。

Выражение должно содержать защищаемую часть ссылки (ресурс) и секретную составляющую. Если ссылка имеет ограниченный срок действия, выражение также должно содержать `$secure_link_expires`.

此表達式必須包含連結（資源）的受保護部分和秘密元件。如果連結的持續時間有限，則表達式也必須包含 `$secure_link_expires`。

Для предотвращения несанкционированного доступа выражение может содержать информацию о клиенте, например, его адрес и версию браузера.

為了防止未經授權的訪問，表達式可以包含有關客戶端的信息，例如其地址和瀏覽器版本。

Пример:

例子：

> ```
> location /s/ {
>
> 位置 /s/ {
>     secure_link $arg_md5,$arg_expires;
>     secure_link_md5 "$secure_link_expires$uri$remote_addr secret";
>
>     secure_link_md5 "$secure_link_expires$uri$remote_addr 秘密";
> 
>     if ($secure_link = "") {
>
>     如果 ($secure_link = "") {
>         return 403;
>
>         返回 403；
>     }
> 
>     if ($secure_link = "0") {
>
>     如果 ($secure_link = "0") {
>         return 410;
>
>         返回 410；
>     }
> 
>     ...
> }
> ```

Ссылка “`/s/link?md5=_e4Nc3iduzkWRm01TBBNYw&expires=2147483647`” ограничивает доступ к “`/s/link`” для клиента с IP-адресом 127.0.0.1. Ссылка также имеет ограниченный срок действия до 19 января 2038 года (GMT).

「`/s/link?md5=_e4Nc3iduzkWRm01TBBNYw&expires=2147483647`」連結限制具有IP位址127.0.0.1的客戶端對「`/s/link`」的存取。此連結的有效期限也有限，截止日期為 2038 年 1 月 19 日 (GMT)。

Значение аргумента запроса `*md5*` на UNIX можно получить так:

查詢參數`*md5*`到UNIX的值可以如下取得：

> ```
> echo -n '2147483647/s/link127.0.0.1 secret' | \
>
> echo -n '2147483647/s/link127.0.0.1 秘密' | \
>     openssl md5 -binary | openssl base64 | tr +/ -_ | tr -d =
>
>     openssl md5 - 二進位 | openssl base64 | OpenSSL Base64 | tr +/ -_ | tr-d =
> ```

|   |   |
| --- | --- |
| Синтаксис:<br>文法： | ``**secure_link_secret** `*слово*`;``<br>``**secure_link_secret** `*字*`;`` |
| Умолчание:<br>預設值： | — |
| Контекст:<br>上下文： | `location` |

Задаёт секретное `*слово*` для проверки аутентичности запрашиваемых ссылок.

設定秘密`*слово*`來檢查所請求連結的真實性。

Полный URI запрашиваемой ссылки выглядит так:

所請求連結的完整URI如下所示：

> ```
> /префикс/хэш/ссылка
>
> /前綴/哈希/鏈接
> ```

где `*хэш*` — MD5-хэш в шестнадцатеричном виде, вычисленный для конкатенации ссылки и секретного слова, а `*префикс*` — произвольная строка без слэшей.

其中 `*хэш*` 是為連結和秘密字的串聯計算的 MD5 十六進位哈希值，`*префикс*` 是不帶斜線的任意字串。

Если запрашиваемая ссылка проходит проверку на аутентичность, значением переменной `$secure_link` становится ссылка, выделенная из URI запроса. В противном случае значением переменной `$secure_link` становится пустая строка.

如果請求的連結通過了驗證檢查，則變數`$secure_link`的值將成為從URI請求中提取的連結。否則，變數`$secure_link`的值將變成空字串。

Пример:

例子：

> ```
> location /p/ {
>
> 位置 /p/ {
>     secure_link_secret secret;
>
>     secure_link_secret 秘密；
> 
>     if ($secure_link = "") {
>
>     如果 ($secure_link = "") {
>         return 403;
>
>         返回 403；
>     }
> 
>     rewrite ^ /secure/$secure_link;
>
>     重寫 ^ /secure/$secure_link;
> }
> 
> location /secure/ {
>
> 位置/安全/ {
>     internal;
>
>     內部的;
> }
> ```

По запросу “`/p/5e814704a28d9bc1914ff19fa0c4a00a/link`” будет выполнено внутреннее перенаправление на “`/secure/link`”.

請求“`/p/5e814704a28d9bc1914ff19fa0c4a00a/link`”將在內部重定向到“`/secure/link`”。

Значение хэша для данного примера на UNIX можно получить так:

本例在UNIX上的哈希值可以這樣取得：

> ```
> echo -n 'linksecret' | openssl md5 -hex
>
> echo -n '連結秘密' | openssl md5 - 十六進位
> ```

#### Встроенные переменные｜內建變數

`$secure_link`

Результат проверки ссылки. Конкретное значение зависит от выбранного режима работы.

檢查連結的結果。具體值取決於所選的工作模式。

`$secure_link_expires`

Время действия ссылки, переданное в запросе. Предназначено исключительно для использования в директиве [secure\_link\_md5](#secure_link_md5).

請求中傳遞的連結的過期時間。專門用於 [secure\_link\_md5](#secure_link_md5) 指令。
