## Модуль ngx\_http\_realip\_module｜ngx_http_realip_module 模組

Модуль `ngx_http_realip_module` позволяет менять адрес и необязательный порт клиента на переданные в указанном поле заголовка.

`ngx_http_realip_module`模組可讓您將用戶端位址和選用連接埠變更為在指定的標頭欄位中傳遞的位址和連接埠。

По умолчанию этот модуль не собирается, его сборку необходимо разрешить с помощью конфигурационного параметра `--with-http_realip_module`.

此模組預設未構建，必須使用`--with-http_realip_module`配置參數啟用。

#### Пример конфигурации｜配置範例

> ```
> set_real_ip_from  192.168.1.0/24;
>
> set_real_ip_from 192.168.1.0/24 ;
> set_real_ip_from  192.168.2.1;
>
> set_real_ip_from 192.168.2.1 ;
> set_real_ip_from  2001:0db8::/32;
>
> set_real_ip_from 2001:0db8::/32 ;
> real_ip_header    X-Forwarded-For;
>
> real_ip_header X-Forwarded-For;
> real_ip_recursive on;
>
> real_ip_recursive 已開啟；
> ```

Задаёт доверенные адреса, которые передают верный адрес для замены. Если указано специальное значение `unix:`, доверенными будут считаться все UNIX-сокеты. Доверенные адреса могут быть также заданы при помощи имени хоста (1.13.1).

指定能夠傳遞正確替換地址的受信任位址。如果指定特殊值`unix:` ，則所有UNIX套接字都將被信任。也可以使用主機名稱（ 1.13.1 ）指定受信任位址。

> IPv6-адреса поддерживаются начиная с версий 1.3.0 и 1.2.1.
>
> 從版本1.3.0和1.2.1開始支援IPv6位址。

Задаёт поле заголовка запроса, значение которого будет использоваться для замены адреса клиента.

指定一個請求頭字段，其值將用於替換客戶端地址。

Значение поля заголовка запроса, содержащее необязательный порт, также используется для замены порта клиента (1.11.0). Адрес и порт должны быть указаны согласно [RFC 3986](https://datatracker.ietf.org/doc/html/rfc3986).

包含可選連接埠的請求頭字段值也用於替換客戶端連接埠（ 1.11.0 ）。位址和連接埠必須依照 [RFC 3986](https://datatracker.ietf.org/doc/html/rfc3986)指定。

Параметр `proxy_protocol` (1.5.12) меняет адрес клиента на указанный в заголовке PROXY-протокола. Протокол PROXY должен быть предварительно включён при помощи установки параметра `proxy_protocol` в директиве [listen](<221 [02.01.01 http] 模組 ngx_http_core_module.md#listen>).

`proxy_protocol` ( 1.5.12 ) 參數將客戶端位址變更為PROXY協定頭中指定的位址。必須先在 [listen](<221 [02.01.01 http] 模組 ngx_http_core_module.md#listen>)指令中設定`proxy_protocol`參數來啟用PROXY協定。

Эта директива появилась в версиях 1.3.0 и 1.2.1.

該指令出現在版本1.3.0和1.2.1中。

При выключенном рекурсивном поиске исходный адрес клиента, совпадающий с одним из доверенных адресов, заменяется на последний адрес, переданный в поле заголовка запроса, заданного директивой [real\_ip\_header](#real_ip_header). При включённом рекурсивном поиске исходный адрес клиента, совпадающий с одним из доверенных адресов, заменяется на последний не доверенный адрес, переданный в заданном поле заголовка запроса.

停用遞歸搜尋時，用戶端與受信任位址相符的原始位址將被替換為請求頭字段中由 [real\_ip\_header](#real_ip_header)指令指定的最後一個位址。啟用遞歸搜尋時，用戶端與受信任位址相符的原始位址將被替換為請求頭字段中指定的最後一個不受信任位址。

#### Встроенные переменные｜內建變數

`$realip_remote_addr`

хранит исходный адрес клиента (1.9.7)

儲存客戶端的來源位址（ 1.9.7 ）

`$realip_remote_port`

хранит исходный порт клиента (1.11.0)

儲存客戶端的來源連接埠（ 1.11.0 ）
