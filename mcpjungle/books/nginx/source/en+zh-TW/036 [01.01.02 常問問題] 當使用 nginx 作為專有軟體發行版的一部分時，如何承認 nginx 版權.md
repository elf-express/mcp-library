## How can nginx copyright be acknowledged when using nginx as part of a proprietary software distribution?｜當使用 nginx 作為專有軟體發行版的一部分時，如何承認 nginx 版權？

**Q:** I’d like to use nginx distribution as part of my proprietary software package. How can nginx copyright be acknowledged when using nginx as part of a proprietary software distribution?

**問：** 我想使用 nginx 發行版作為我的專有軟體包的一部分。當使用 nginx 作為專有軟體發行版的一部分時，如何承認 nginx 版權？

**A:** The text below should be added to your license conditions, followed by the text of the applicable 2-clause BSD license described [here](<354 頁.md>).

**答：** 應將以下文字加入您的授權條件中，後面接著[此處](<354 頁.md>) 所描述的適用 2 條款 BSD 授權的文字。

> ```
> This product contains software provided by Nginx, Inc. and its contributors.
>
> 本產品包含 Nginx, Inc. 及其貢獻者提供的軟體。
> ```

Also, if your build of nginx includes any of the following 3rd party products: zlib, PCRE, OpenSSL — it’s worth including their copyright acknowledgements and disclaimers as well.

另外，如果您的 nginx 版本包含以下任何第 3 方产品：zlib、PCRE、OpenSSL — 也值得包含它们的版权声明和免责声明。
