# Движок JavaScript｜JavaScript 引擎

## Движок JavaScript｜JavaScript 引擎

Начиная с версии [0.8.6](https://nginx.org/ru/docs/njs/changes.html#njs0.8.6) поддерживается несколько JS-движков. Для выбора движка используется директива `js_engine` в [http](<238 [02.01.01 http] 模組 ngx_http_js_module.md#js_engine>) и [stream](<300 [02.01.04 溪流] 模組 ngx_stream_js_module.md#js_engine>). По умолчанию используется движок njs.

從版本 [0.8.6](https://nginx.org/ru/docs/njs/changes.html#njs0.8.6)支援多種JS 。 [http](<238 [02.01.01 http] 模組 ngx_http_js_module.md#js_engine>)和 [stream](<300 [02.01.04 溪流] 模組 ngx_stream_js_module.md#js_engine>)中的`js_engine`指令用於選擇引擎。預設使用 njs 引擎。

#### Движок njs｜NJS引擎

> Движок njs объявлен устаревшим начиная с [1.0.0](https://nginx.org/ru/docs/njs/changes.html#njs1.0.0); для нового кода следует использовать движок [QuickJS](#quickjs_engine).
>
> njs 引擎自 [1.0.0](https://nginx.org/ru/docs/njs/changes.html#njs1.0.0)起已被棄用；新程式碼應使用 [QuickJS](#quickjs_engine)引擎。

njs  — встроенный движок JavaScript, разработанный как часть модуля njs. Подробнее см. в разделе [Совместимость](<288 [02.01.03 紐澤西州] 相容性.md>).

njs 是一個嵌入式 JavaScript 引擎，作為 njs 模組的一部分開發。有關更多信息，請參閱 [相容性 部分](<288 [02.01.03 紐澤西州] 相容性.md>) 。

#### Движок QuickJS｜QuickJS引擎

[QuickJS](https://bellard.org/quickjs/)  — компактный встроенный движок JavaScript, который поддерживает спецификацию [ES2023](https://tc39.es/ecma262/2023/), включая модули, асинхронные генераторы, прокси и BigInt.

[QuickJS](https://bellard.org/quickjs/)是一個緊湊的嵌入式 JavaScript 引擎，支援 [ES2023](https://tc39.es/ecma262/2023/)規範，包括模組、非同步產生器、代理程式和 BigInt。

Начиная с [0.8.6](https://nginx.org/ru/docs/njs/changes.html#njs0.8.6) доступна оперативная замена [njs/nginx objects](https://nginx.org/ru/docs/njs/reference.html) для обеспечения совместимости с движком njs, но с некоторыми исключениями:

從 [0.8.6](https://nginx.org/ru/docs/njs/changes.html#njs0.8.6)開始，可以使用 [njs/nginx 物件](https://nginx.org/ru/docs/njs/reference.html)的熱下拉選單替代方案來確保與 njs 引擎的兼容性，但也有一些例外：

-   API njs: [`njs.dump()`](https://nginx.org/ru/docs/njs/reference.html#njs_dump), `console.dump()`.  
    API njs: [ `njs.dump()` ](https://nginx.org/ru/docs/njs/reference.html#njs_dump), `console.dump()` 。
-   устаревшее API: `require()`, вместо необходимо использовать утверждение `import`.  
    API: `require()`已過時，您應該使用語句`import` 。
-   директива `js_preload_object` для [http](<238 [02.01.01 http] 模組 ngx_http_js_module.md#js_preload_object>) и [stream](<300 [02.01.04 溪流] 模組 ngx_stream_js_module.md#js_preload_object>).  
    `js_preload_object`指令用於 [http](<238 [02.01.01 http] 模組 ngx_http_js_module.md#js_preload_object>)和 [stream](<300 [02.01.04 溪流] 模組 ngx_stream_js_module.md#js_preload_object>) 。
