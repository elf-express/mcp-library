Модуль `ngx_http_gzip_module` — это фильтр, сжимающий ответ методом gzip, что позволяет уменьшить размер передаваемых данных в 2 и более раз.

`ngx_http_gzip_module`模組是一個過濾器，它使用 gzip 方法壓縮響應，從而可以將傳輸資料的大小減少 2 倍或更多。

> При использовании протокола SSL/TLS сжатые ответы могут быть подвержены атакам [BREACH](https://en.wikipedia.org/wiki/BREACH).
>
> 使用SSL/TLS協定時，壓縮響應可能容易受到 [BREACH](https://en.wikipedia.org/wiki/BREACH)攻擊。

#### Пример конфигурации｜配置範例

> ```
> gzip            on;
>
> 啟用 gzip 壓縮；
> gzip_min_length 1000;
> gzip_proxied    expired no-cache no-store private auth;
>
> gzip_proxied 過期 無快取 無儲存 私有身分驗證;
> gzip_types      text/plain application/xml;
>
> gzip_types text/plain application/xml;
> ```

Для записи в лог достигнутого коэффициента сжатия можно использовать переменную `$gzip_ratio`.

要記錄所達到的壓縮比，可以使用`$gzip_ratio`變數。

Задаёт `*число*` и `*размер*` буферов, в которые будет сжиматься ответ. По умолчанию размер одного буфера равен размеру страницы. В зависимости от платформы это или 4K, или 8K.

指定用於壓縮響應的`*число*`和`*размер*`緩衝區。預設情況下，單一緩衝區的大小等於頁面大小。根據平台的不同，頁面大小可以是 4K 或 8K。

> До версии 0.7.28 по умолчанию использовалось 4 буфера размером 4K или 8K.
>
> 在0.7.28預設使用 4 個 4K 或 8K 大小的緩衝區。

Запрещает сжатие ответа методом gzip для запросов с полями заголовка “User-Agent”（使用者代理）, совпадающими с заданными регулярными выражениями.

防止對帶有“User-Agent”（使用者代理）標頭欄位且與給定正規表示式匹配的請求的回應進行 gzip 壓縮。

Специальная маска “`msie6`” (0.7.12) соответствует регулярному выражению “`MSIE [4-6]\.`”, но работает быстрее. Начиная с версии 0.8.11 из этой маски исключается “`MSIE 6.0; ... SV1`”.

特殊遮罩“ `msie6` ”（ 0.7.12 ）匹配正規表示式“ `MSIE [4-6]\.` ”，但速度更快。從版本0.8.11 “ `MSIE 6.0; ... SV1` ”已從該遮罩中排除。

Разрешает или запрещает сжатие ответа методом gzip для проксированных запросов в зависимости от запроса и ответа. То, что запрос проксированный, определяется на основании наличия поля “Via”（透過） в заголовке запроса. В директиве можно указать одновременно несколько параметров:

根據請求和回應，啟用或停用代理請求的 gzip 回應壓縮。代理請求由請求頭中是否存在“Via”（透過）字段來判斷。此指令可以指定多個參數：

`off`

запрещает сжатие для всех проксированных запросов, игнорируя остальные параметры;

禁用所有代理請求的壓縮，忽略其他參數；

`expired`

разрешает сжатие, если в заголовке ответа есть поле “Expires”（過期） со значением, запрещающим кэширование;

如果回應頭包含禁止快取的“Expires”（過期）字段，則允許壓縮；

`no-cache`

разрешает сжатие, если в заголовке ответа есть поле “Cache-Control”（快取控制） с параметром “`no-cache`”;

如果回應標頭包含帶有「 `no-cache` 」參數的“Cache-Control”（快取控制）字段，則啟用壓縮；

`no-store`

разрешает сжатие, если в заголовке ответа есть поле “Cache-Control”（快取控制） с параметром “`no-store`”;

如果回應標頭包含帶有「 `no-store` 」參數的“Cache-Control”（快取控制）字段，則啟用壓縮；

`private`

разрешает сжатие, если в заголовке ответа есть поле “Cache-Control”（快取控制） с параметром “`private`”;

如果回應標頭包含帶有「 `private` 」參數的“Cache-Control”（快取控制）字段，則啟用壓縮；

`no_last_modified`

разрешает сжатие, если в заголовке ответа нет поля “Last-Modified”（最後修改日期）;

如果響應頭中沒有“Last-Modified”（最後修改日期）字段，則允許壓縮；

`no_etag`

разрешает сжатие, если в заголовке ответа нет поля “ETag”（電子標籤）;

如果響應頭中沒有“ETag”（電子標籤）字段，則允許壓縮；

`auth`

разрешает сжатие, если в заголовке запроса есть поле “Authorization”（授權）;

如果請求頭包含“Authorization”（授權）字段，則啟用壓縮；

`any`

разрешает сжатие для всех проксированных запросов.

啟用對所有代理請求的壓縮。

Разрешает сжатие ответа методом gzip для указанных MIME-типов в дополнение к “`text/html`”. Специальное значение “`*`” соответствует любому MIME-типу (0.8.29). Ответы с типом “`text/html`” сжимаются всегда.

啟用對指定MIME類型以及「 `text/html` 」類型的回應進行 gzip 壓縮。特殊值“ `*` ”匹配任何MIME類型（ 0.8.29 ）。類型為「 `text/html` 」的響應始終會被壓縮。

Разрешает или запрещает выдавать в ответе поле заголовка “Vary: Accept-Encoding”, если активны директивы [gzip](#gzip), [gzip\_static](<232 [02.01.01 http] 模組 ngx_http_gzip_static_module.md#gzip_static>) или [gunzip](<230 [02.01.01 http] 模組 ngx_http_gunzip_module.md#gunzip>).

當 [gzip](#gzip) 、[gzip\_static](<232 [02.01.01 http] 模組 ngx_http_gzip_static_module.md#gzip_static>)或 [gunzip](<230 [02.01.01 http] 模組 ngx_http_gunzip_module.md#gunzip>)指令處於活動狀態時，啟用或停用回應中的「Vary: Accept-Encoding」標頭欄位。

#### Встроенные переменные｜內建變數

`$gzip_ratio`

достигнутый коэффициент сжатия — отношение размера исходного ответа к размеру сжатого.

所達到的壓縮比是原始響應的大小與壓縮後響應的大小之比。
