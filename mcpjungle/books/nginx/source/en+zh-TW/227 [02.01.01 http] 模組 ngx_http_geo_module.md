## Модуль ngx\_http\_geo\_module｜模組 ngx\_http\_geo\_module

|   |
| --- |
| [Пример конфигурации](#example)<br>[Директивы](#directives)<br>     [geo](#geo)<br>[設定範例](#example)<br> [指令](#directives)<br> [地理](#geo) |

Модуль `ngx_http_geo_module` создаёт переменные, значения которых зависят от IP-адреса клиента.

`ngx_http_geo_module`模組建立變量，其值取決於客戶端的IP位址。

#### Пример конфигурации｜配置範例

> ```
> geo $geo {
>
> 地理 $geo {
>     default        0;
>
>     預設值為 0；
> 
>     127.0.0.1      2;
>     192.168.1.0/24 1;
>     10.1.0.0/16    1;
> 
>     ::1            2;
>     2001:0db8::/32 1;
> }
> ```

#### Директивы｜指令

|   |   |
| --- | --- |
| Синтаксис:<br>文法： | ``**geo** [`*$адрес*`] `*$переменная*` { ... }``<br>` `**geo** [` *$address* `] ` *$variable* ` { ... }` ` |
| Умолчание:<br>預設值： | — |
| Контекст:<br>背景： | `http` |

Описывает для указанной переменной зависимость значения от IP-адреса клиента. По умолчанию адрес берётся из переменной `$remote_addr`, но его также можно получить из другой переменной (0.7.27), например:

描述指定變數的值如何取決於客戶端的IP位址。預設情況下，位址取自`$remote_addr`變量，但也可以從另一個變數（ 0.7.27 ）取得，例如：

> ```
> geo $arg_remote_addr $geo {
>     ...;
> }
> ```

> Поскольку переменные вычисляются только в момент использования, само по себе наличие даже большого числа объявлений переменных “`geo`” не влечёт за собой никаких дополнительных расходов на обработку запросов.
>
> 由於變數僅在使用時才進行評估，因此即使存在大量的「 `geo` 」變數宣告也不會產生任何額外的查詢處理成本。

Если значение переменной не представляет из себя правильный IP-адрес, то используется адрес “`255.255.255.255`”.

如果變數值不代表有效的IP位址，則使用「 `255.255.255.255` 」位址。

Адреса задаются либо префиксами в формате CIDR (включая одиночные адреса), либо в виде диапазонов (0.7.23).

位址可以指定為前綴（格式為CIDR ，包括單一位址）或範圍（ 0.7.23 ）。

> IPv6-префиксы поддерживаются начиная с версий 1.3.10 и 1.2.7.
>
> 從版本1.3.10和1.2.7開始支援IPv6前綴。

Также поддерживаются следующие специальные параметры:

此外，也支援以下特殊參數：

`delete`

удаляет описанную сеть (0.7.23).

刪除所描述的網路（ 0.7.23 ）。

`default`

значение переменной, если адрес клиента не соответствует ни одному из заданных адресов. При задании адресов в формате CIDR вместо `default` можно использовать “`0.0.0.0/0`” и “`::/0`”. Если параметр `default` не указан, значением по умолчанию будет пустая строка.

如果用戶端位址與任何指定的位址都不匹配，則此變數的值會發生變化。以CIDR格式指定位址時，可以使用「 `0.0.0.0/0` 」和「 `::/0` 」來取代`default` 。如果未指定`default`參數，則預設值為空字串。

`include`

включает файл с адресами и значениями. Включений может быть несколько.

包含一個地址和值的檔案。可能包含多個文件。

`proxy`

задаёт доверенные адреса (0.8.7, 0.7.63), при запросе с которых будет использоваться адрес в переданном поле заголовка запроса “X-Forwarded-For”（X-轉發）. В отличие от обычных адресов, доверенные адреса проверяются последовательно.

指定受信任位址（ 0.8.7, 0.7.63 ），這些位址在發出請求時將使用傳遞的“X-Forwarded-For”（X-轉發）請求頭字段中的位址。與常規地址不同，受信任地址是按順序檢查的。

> Доверенные IPv6-адреса поддерживаются начиная с версий 1.3.0 и 1.2.1.
>
> 從版本1.3.0和1.2.1開始支援受信任的IPv6位址。

`proxy_recursive`

включает рекурсивный поиск адреса (1.3.0, 1.2.1). При выключенном рекурсивном поиске вместо исходного адреса клиента, совпадающего с одним из доверенных адресов, будет использоваться последний адрес, переданный в “X-Forwarded-For”（X-轉發）. При включённом рекурсивном поиске вместо исходного адреса клиента, совпадающего с одним из доверенных адресов, будет использоваться последний не доверенный адрес, переданный в “X-Forwarded-For”（X-轉發）.

啟用遞歸位址搜尋（ 1.3.0, 1.2.1 ）。停用遞歸搜尋時，將使用“X-Forwarded-For”（X-轉發）中傳入的最後一個位址，而不是客戶端的原始位址與某個受信任位址相符的位址。啟用遞歸搜尋時，將使用“X-Forwarded-For”（X-轉發）中傳入的最後一個不受信任的位址，而不是用戶端的原始位址與某個受信任位址相符的位址。

`ranges`

указывает, что адреса задаются в виде диапазонов (0.7.23). Этот параметр должен быть первым. Для ускорения загрузки гео-базы нужно располагать адреса в порядке возрастания.

指定位址以範圍形式指定（ 0.7.23 ）。此參數必須是第一個參數。為了加快地理資料庫載入速度，地址應按升序排列。

`volatile`

указывает, что переменная не кэшируется (1.29.3).

表示該變數未被快取（ 1.29.3 ）。

Пример:

例子：

> ```
> geo $country {
>
> 地理 $country {
>     default        ZZ;
>
>     預設ZZ ;
>     include        conf/geo.conf;
>
>     包含 conf/geo.conf；
>     delete         127.0.0.0/16;
>
>     刪除127.0.0.0/16 ;
>     proxy          192.168.100.0/24;
>
>     代理192.168.100.0/24 ;
>     proxy          2001:0db8::/32;
>
>     代理2001:0db8::/32 ;
> 
>     127.0.0.0/24   US;
>     127.0.0.1/32   RU;
>     10.1.0.0/16    RU;
>     192.168.1.0/24 UK;
> }
> ```

В файле `conf/geo.conf` могут быть такие строки:

`conf/geo.conf`文件可能包含類似這樣的行：

> ```
> 10.2.0.0/16    RU;
> 192.168.2.0/24 RU;
> ```

В качестве значения выбирается максимальное совпадение, например, для адреса 127.0.0.1 будет выбрано значение “`RU`”, а не “`US`”.

所選值是最接近的匹配項，例如，對於位址127.0.0.1將選擇值“ `RU` ”，而不是“ `US` ”。

Пример описания диапазонов:

範圍描述範例：

> ```
> geo $country {
>
> 地理 $country {
>     ranges;
>
>     範圍；
>     default                   ZZ;
>
>     預設ZZ ;
>     127.0.0.0-127.0.0.0       US;
>     127.0.0.1-127.0.0.1       RU;
>     127.0.0.2-127.0.0.255     US;
>     10.1.0.0-10.1.255.255     RU;
>     192.168.1.0-192.168.1.255 UK;
> }
> ```
