## Модуль nginx JavaScript｜模組 nginx JavaScript

njs - это модуль nginx, который расширяет возможности сервера nginx с помощью сценариев JavaScript, позволяя создавать пользовательскую логику на стороне сервера и выполнять [другие задачи](#usecases).

njs 是一個 nginx 模組，它使用 JavaScript 腳本擴展了 nginx 伺服器，讓您可以建立自訂伺服器端邏輯並執行 [其他任務](#usecases) 。

nginx вызывает JavaScript-обработчики в фиксированном наборе [точек интеграции](https://nginx.org/ru/docs/njs/integration.html): в фазах обработки HTTP-запроса и ответа, фазах stream-сессии, при вычислении переменных и по таймеру. njs не является самостоятельной средой выполнения приложений: стартовый сценарий и собственный цикл событий отсутствуют, код JavaScript выполняется исключительно в рамках настроенного обработчика, вызванного nginx, по завершении которого управление возвращается nginx.

nginx 會在一組固定的(https://nginx.org/ru/docs/njs/integration.html)整合點呼叫 JavaScript 處理程序：在HTTP請求和回應處理期間、串流會話階段、變數計算期間以及透過計時器。 njs 不是一個獨立的應用程式執行時間：它沒有啟動腳本和自己的事件循環；JavaScript 程式碼僅在由 nginx 呼叫的已配置處理程序中執行，之後控制權返回給 nginx。

> Встроенный JavaScript-движок [njs](<289 [02.01.03 紐澤西州] JavaScript 引擎.md#njs_engine>) объявлен устаревшим начиная с [1.0.0](https://nginx.org/ru/docs/njs/changes.html#njs1.0.0); в новых конфигурациях следует использовать движок [QuickJS](<289 [02.01.03 紐澤西州] JavaScript 引擎.md#quickjs_engine>).
>
> 內建的 JavaScript 引擎 [njs](<289 [02.01.03 紐澤西州] JavaScript 引擎.md#njs_engine>)自 [1.0.0](https://nginx.org/ru/docs/njs/changes.html#njs1.0.0)起已被棄用；新的配置應使用 [QuickJS](<289 [02.01.03 紐澤西州] JavaScript 引擎.md#quickjs_engine>)引擎。

#### Базовый пример HTTP｜基本範例HTTP

Чтобы использовать njs в nginx, необходимо:

要在nginx中使用njs，您需要：

-   [установить](<291 [02.01.03 紐澤西州] 下載和安裝.md>) njs  
    [安裝](<291 [02.01.03 紐澤西州] 下載和安裝.md>) njs
    
-   создать файл сценария njs, например `http.js`. Описание свойств и методов njs см. в [справочнике](https://nginx.org/ru/docs/njs/reference.html).  
    建立一個 njs 腳本文件，例如`http.js` 。有關 njs 屬性和方法的說明，請參閱 [參考](https://nginx.org/ru/docs/njs/reference.html) 。
    
    > ```js
    > function hello(r) {
    >
    > 函數 hello(r) {
    >     r.return(200, "Hello world!");
    > }
    > 
    > export default {hello};
    > ```
    
-   в файле `nginx.conf` включить модуль [ngx\_http\_js\_module](<238 [02.01.01 http] 模組 ngx_http_js_module.md>) и указать директиву [js\_import](<238 [02.01.01 http] 模組 ngx_http_js_module.md#js_import>) с файлом сценария `http.js`:  
    在`nginx.conf`檔案中，啟用 [ngx\_http\_js\_module](<238 [02.01.01 http] 模組 ngx_http_js_module.md>)模組，並使用`http.js`腳本檔案指定 [js\_import](<238 [02.01.01 http] 模組 ngx_http_js_module.md#js_import>)指令：
    
    > ```
    > load_module modules/ngx_http_js_module.so;
    >
    > 載入模組 modules/ngx_http_js_module.so;
    > 
    > events {}
    >
    > 事件 {}
    > 
    > http {
    >
    > http{
    >     # начиная с 0.9.1｜從0.9.1開始
    >     js_engine qjs;
    >
    >     js_engine qjs；
    > 
    >     js_import http.js;
    > 
    >     server {
    >
    >     伺服器{
    >         listen 8000;
    >
    >         聽 8000；
    > 
    >         location / {
    >
    >         地點/{
    >             js_content http.hello;
    >         }
    >     }
    > }
    > ```
    

Также доступна отдельная утилита [командной строки](<287 [02.01.03 紐澤西州] 命令列介面.md>), которая может использоваться независимо от nginx для разработки и отладки njs.

此外，還有一個獨立的 [命令列 實用程式](<287 [02.01.03 紐澤西州] 命令列介面.md>)可供使用，它可以獨立於 nginx 來開發和調試 njs。
