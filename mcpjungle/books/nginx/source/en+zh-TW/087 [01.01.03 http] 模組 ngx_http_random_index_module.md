# Module ngx_http_random_index_module｜模組 ngx_http_random_index_module

> 章節：[en｜在](<000 目錄.md#c-1>) › [docs｜文件](<000 目錄.md#c-2>) › [http](<000 目錄.md#c-5>)

## Module ngx\_http\_random\_index\_module｜模組 ngx\_http\_random\_index\_module

|   |
| --- |
| [Example Configuration](#example)<br>[Directives](#directives)<br>     [random\_index](#random_index)<br>[範例配置](#example)<br> [指令](#directives)<br> [隨機索引](#random_index) |

The `ngx_http_random_index_module` module processes requests ending with the slash character (‘`/`’) and picks a random file in a directory to serve as an index file. The module is processed before the [ngx\_http\_index\_module](<071 [01.01.03 http] 模組 ngx_http_index_module.md>) module.

`ngx_http_random_index_module`模組處理以斜槓字元（' `/` '）結尾的請求，並從目錄中隨機選擇一個檔案作為索引檔案。此模組在 [ngx\_http\_index\_module](<071 [01.01.03 http] 模組 ngx_http_index_module.md>)模組之前處理。

This module is not built by default, it should be enabled with the `--with-http_random_index_module` configuration parameter.

此模組預設未構建，應使用`--with-http_random_index_module`配置參數啟用。

#### Example Configuration｜範例配置

> ```
> location / {
>
> 地點 / {
>     random_index on;
>
>     隨機索引開啟；
> }
> ```
