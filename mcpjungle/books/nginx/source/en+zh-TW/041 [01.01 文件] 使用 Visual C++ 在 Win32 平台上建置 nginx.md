## Building nginx on the Win32 platform with Visual C｜使用 Visual C++ 在 Win32 平台上建置 nginx

| --- |

#### Prerequisites｜先決條件

To build nginx on the Microsoft Win32® platform you need:

要在 Microsoft Win32® 平台上建置 nginx，您需要：

-   Microsoft Visual C compiler. Microsoft Visual Studio® 8, 10, 17 are known to work.  
    微軟 Visual C 編譯器。已知 Microsoft Visual Studio® 8、10 和 17 均可正常運作。
-   [MSYS](https://sourceforge.net/projects/mingw/files/MSYS/) or [MSYS2](https://www.msys2.org/).  
    [MSYS](https://sourceforge.net/projects/mingw/files/MSYS/)或 [MSYS2](https://www.msys2.org/) 。
-   Perl, if you want to build OpenSSL® and nginx with SSL support. For example [ActivePerl](http://www.activestate.com/activeperl) or [Strawberry Perl](http://strawberryperl.com/).  
    如果您想建造支援SSL的OpenSSL®和nginx，可以使用Perl。例如[ActivePerl](http://www.activestate.com/activeperl)或[Strawberry Perl](http://strawberryperl.com/) 。
-   [Git](https://cli.github.com/) client.  
    [Git](https://cli.github.com/)客戶端。
-   [PCRE](http://www.pcre.org/), [zlib](http://zlib.net/) and [OpenSSL](http://www.openssl.org/) libraries sources.  
    [PCRE](http://www.pcre.org/) , [zlib](http://zlib.net/)和 [OpenSSL](http://www.openssl.org/)庫原始碼。

#### Build steps｜建置步驟

Ensure that paths to Perl, Git and MSYS bin directories are added to PATH environment variable before you start build. To set Visual C environment run vcvarsall.bat script from Visual C directory.

在開始建置之前，請確保將 Perl、Git 和 bin MSYS的路徑新增至環境PATH 。若要設定 Visual C 環境，請從 Visual C 目錄執行 vcvarsall.bat 腳本。

To build nginx:

建構 nginx：

-   Start MSYS bash.  
    啟動MSYS bash。
-   Check out nginx sources from the GitHub repository:  
    從 GitHub 倉庫查看 nginx 原始碼：
    
    > ```bash
    >
    > ````bash
    > git clone https://github.com/nginx/nginx.git
    > ```
    
-   Create a build and lib directories, and unpack zlib, PCRE and OpenSSL libraries sources into lib directory:  
    建立 build 和 lib 目錄，並將 zlib、 PCRE和 OpenSSL 函式庫的源碼解壓縮到 lib 目錄中：
    
    > ```bash
    >
    > ````bash
    > mkdir objs
    > mkdir objs/lib
    > cd objs/lib
    > tar -xzf ../../pcre2-10.39.tar.gz
    >
    > tar -xzf ../../pcre2- 10.39 .tar.gz
    > tar -xzf ../../zlib-1.3.1.tar.gz
    >
    > tar -xzf ../../zlib- 1.3.1 .tar.gz
    > tar -xzf ../../openssl-3.0.14.tar.gz
    >
    > tar -xzf ../../openssl- 3.0.14 .tar.gz
    > ```
    
-   Run configure script:  
    運行配置腳本：
    
    > ```
    > auto/configure \
    >
    > 自動/配置\
    >     --with-cc=cl \
    >     --with-debug \
    >     --prefix= \
    >     --conf-path=conf/nginx.conf \
    >     --pid-path=logs/nginx.pid \
    >     --http-log-path=logs/access.log \
    >     --error-log-path=logs/error.log \
    >     --sbin-path=nginx.exe \
    >     --http-client-body-temp-path=temp/client_body_temp \
    >     --http-proxy-temp-path=temp/proxy_temp \
    >     --http-fastcgi-temp-path=temp/fastcgi_temp \
    >     --http-scgi-temp-path=temp/scgi_temp \
    >     --http-uwsgi-temp-path=temp/uwsgi_temp \
    >     --with-cc-opt=-DFD_SETSIZE=1024 \
    >     --with-pcre=objs/lib/pcre2-10.39 \
    >
    >     --with-pcre=objs/lib/pcre2- 10.39 \
    >     --with-zlib=objs/lib/zlib-1.3.1 \
    >
    >     --with-zlib=objs/lib/zlib- 1.3.1 \
    >     --with-openssl=objs/lib/openssl-3.0.14 \
    >
    >     --with-openssl=objs/lib/openssl- 3.0.14 \
    >     --with-openssl-opt=no-asm \
    >     --with-http_ssl_module
    > ```
    
-   Run make:  
    運行 make：
    
    > ```
    > nmake
    >
    > 奈米製造
    > ```
