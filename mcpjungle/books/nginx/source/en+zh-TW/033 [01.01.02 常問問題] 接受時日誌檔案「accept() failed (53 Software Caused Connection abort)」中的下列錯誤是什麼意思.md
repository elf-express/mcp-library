# What does the following error mean in the log file “accept() failed (53 Software caused connection abort) while acceptin｜接受時日誌檔案「accept() failed (53 Software Caused Connection abort)」中的下列錯誤是什麼意思

## What does the following error mean in the log file: “accept() failed (53: Software caused connection abort) while accepting new connection on 0.0.0.0:80”?｜日誌檔案中的以下錯誤是什麼意思：「在 0.0.0.0:80 上接受新連線時，accept() 失敗（53：軟體導致連線中止）」？

**Q:** What does the following error mean in the log file: "accept() failed (53: Software caused connection abort) while accepting new connection on 0.0.0.0:80"?

**問：** 日誌檔案中的以下錯誤是什麼意思：「在 0.0.0.0:80 上接受新連線時，accept() 失敗（53：軟體導致連線中止）」？

**A:** Such errors stem from the connections that the clients managed to close before nginx was able to process them. For instance, this can happen in a situation when the user didn’t wait for a page heavily populated with images to load fully, and clicked on a different link. In this case user’s browser would close all of the prior connections which aren’t longer necessary. It is a non-critical error.

**答：** 此類錯誤源自於用戶端在 nginx 能夠處理它們之前設法關閉的連線。例如，當使用者沒有等待充滿圖像的頁面完全載入並點擊不同的連結時，就會發生這種情況。在這種情況下，使用者的瀏覽器將關閉所有不再需要的先前連線。這是一個非嚴重錯誤。
