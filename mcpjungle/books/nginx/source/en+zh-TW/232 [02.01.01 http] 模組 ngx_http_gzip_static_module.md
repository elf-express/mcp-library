# Модуль ngx_http_gzip_static_module｜模組 ngx_http_gzip_static_module

> 章節：[ru](<000 目錄.md#c-9>) › [docs｜文件](<000 目錄.md#c-10>) › [http](<000 目錄.md#c-11>)

## Модуль ngx\_http\_gzip\_static\_module｜模組 ngx\_http\_gzip\_static\_module

|   |
| --- |
| [Пример конфигурации](#example)<br>[Директивы](#directives)<br>     [gzip\_static](#gzip_static)<br>[設定範例](#example)<br> [指令](#directives)<br> [gzip\_static](#gzip_static) |

Модуль `ngx_http_gzip_static_module` позволяет отдавать вместо обычного файла предварительно сжатый файл с таким же именем и с расширением “`.gz`”.

`ngx_http_gzip_static_module`模組可讓您傳回一個同名但副檔名為「 `.gz` 」的預壓縮文件，而不是一個普通文件。

По умолчанию этот модуль не собирается, его сборку необходимо разрешить с помощью конфигурационного параметра `--with-http_gzip_static_module`.

此模組預設未構建，必須使用`--with-http_gzip_static_module`配置參數啟用。

#### Пример конфигурации｜配置範例

> ```
> gzip_static  on;
>
> 啟用 gzip_static；
> gzip_proxied expired no-cache no-store private auth;
>
> gzip_proxied 過期 無快取 無儲存 私有身分驗證;
> ```

Разрешает (“`on`”) или запрещает (“`off`”) проверку готового сжатого файла. При использовании также учитываются директивы [gzip\_http\_version](<231 [02.01.01 http] 模組 ngx_http_gzip_module.md#gzip_http_version>), [gzip\_proxied](<231 [02.01.01 http] 模組 ngx_http_gzip_module.md#gzip_proxied>), [gzip\_disable](<231 [02.01.01 http] 模組 ngx_http_gzip_module.md#gzip_disable>) и [gzip\_vary](<231 [02.01.01 http] 模組 ngx_http_gzip_module.md#gzip_vary>).

啟用（“ `on` ”）或停用（“ `off` ”）對已完成壓縮檔案的驗證。使用時，也會考慮 [gzip\_http\_version](<231 [02.01.01 http] 模組 ngx_http_gzip_module.md#gzip_http_version>) 、[gzip\_proxied](<231 [02.01.01 http] 模組 ngx_http_gzip_module.md#gzip_proxied>) 、[gzip\_disable](<231 [02.01.01 http] 模組 ngx_http_gzip_module.md#gzip_disable>)和 [gzip\_vary](<231 [02.01.01 http] 模組 ngx_http_gzip_module.md#gzip_vary>)指令。

Со значением “`always`” (1.3.6) во всех случаях будет использоваться сжатый файл, без проверки поддержки на стороне клиента. Это полезно, если на диске всё равно нет несжатых файлов, или используется модуль [ngx\_http\_gunzip\_module](<230 [02.01.01 http] 模組 ngx_http_gunzip_module.md>).

值「 `always` 」（ 1.3.6 ）將始終使用壓縮文件，而不檢查客戶端是否支援。如果磁碟上沒有未壓縮的文件，或使用了[ngx\_http\_gunzip\_module](<230 [02.01.01 http] 模組 ngx_http_gunzip_module.md>)模組，則此方法非常有用。

Сжимать файлы можно с помощью программы `gzip` или совместимой с ней. Желательно, чтобы дата и время модификации исходного и сжатого файлов совпадали.

您可以使用`gzip`或相容的程式壓縮檔案。最好使原始檔案和壓縮檔案的修改日期和時間一致。
