# Модуль ngx_google_perftools_module｜模組 ngx_google_perftools_module

## Модуль ngx\_google\_perftools\_module｜ngx\_google\_perftools\_module 模組

|   |
| --- |
| [Пример конфигурации](#example)<br>[Директивы](#directives)<br>     [google\_perftools\_profiles](#google_perftools_profiles)<br>[設定範例](#example)<br> [指令](#directives)<br> [google\_perftools\_profiles](#google_perftools_profiles) |

Модуль `ngx_google_perftools_module` (0.6.29) включает поддержку профилирования рабочих процессов nginx при помощи [Google Performance Tools](https://github.com/gperftools/gperftools). Модуль предназначен для разработчиков nginx.

`ngx_google_perftools_module` ( 0.6.29 ) 模組支援使用 [Google Performance Tools](https://github.com/gperftools/gperftools)分析 nginx 工作進程。此模組面向 nginx 開發人員。

По умолчанию этот модуль не собирается, его сборку необходимо разрешить с помощью конфигурационного параметра `--with-google_perftools_module`.

此模組預設未構建，必須使用`--with-google_perftools_module`配置參數啟用。

> Для сборки и работы этого модуля нужна библиотека [gperftools](https://github.com/gperftools/gperftools).
>
> 要建置和運行此模組，您需要 [gperftools](https://github.com/gperftools/gperftools)庫。

#### Пример конфигурации｜配置範例

> ```
> google_perftools_profiles /path/to/profile;
> ```

Профили будут сохраняться как `/path/to/profile.<worker_pid>`.

個人資料將儲存為`/path/to/profile.<worker_pid>` 。

#### Директивы｜指令

|   |   |
| --- | --- |
| Синтаксис:<br>語法： | ``**google_perftools_profiles** `*файл*`;``<br>``**google_perftools_profiles** `*檔*`;`` |
| Умолчание:<br>預設值： | — |
| Контекст:<br>背景： | `main` |

Задаёт имя файла, который хранит информацию о профилировании рабочего процесса nginx. Идентификатор рабочего процесса всегда является частью имени файла и добавляется в конце имени после точки.

指定用於儲存 nginx 工作進程效能分析資訊的檔案名稱。工作進程 ID 始終包含在檔案名稱中，並新增至檔案名稱末尾的句點之後。
