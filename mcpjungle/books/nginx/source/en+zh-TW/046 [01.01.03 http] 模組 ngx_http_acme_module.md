The `ngx_http_acme_module` module implements the automatic certificate management ([ACMEv2](https://datatracker.ietf.org/doc/html/rfc8555)) protocol.

`ngx_http_acme_module`模組實現了自動證書管理（[ACMEv2](https://datatracker.ietf.org/doc/html/rfc8555) ）協定。

The source code of the module is available [here](https://github.com/nginx/nginx-acme). Download and install instructions are available [here](https://github.com/nginx/nginx-acme/blob/main/README.md).

此模組的原始碼可在此處取得：[此處](https://github.com/nginx/nginx-acme) 。下載和安裝說明可在此處取得：[此處](https://github.com/nginx/nginx-acme/blob/main/README.md) 。

The module is also available in a prebuilt `nginx-module-acme` [package](<177 [01 在] nginx Linux 軟體套件.md#dynmodules>) and in `nginx-plus-module-acme` package as part of our [commercial subscription](https://www.f5.com/products/nginx) since 1.29.0.

本模組也以預先建置的`nginx-module-acme` [軟體包](<177 [01 在] nginx Linux 軟體套件.md#dynmodules>)和`nginx-plus-module-acme`軟體包的形式提供，作為我們 [商業訂閱](https://www.f5.com/products/nginx)的一部分，自1.29.0起提供。

#### Example Configuration｜範例配置

> ```
> resolver 127.0.0.1:53;
>
> 解127.0.0.1:53 ；
> 
> acme_issuer example {
>
> acme_issuer 範例 {
>     uri         https://acme.example.com/directory;
>
>     uri https://acme.example.com/directory;
>     contact     admin@example.test;
>
>     請聯絡 admin@example.test；
>     state_path  /var/cache/nginx/acme-example;
>
>     state_path /var/cache/nginx/acme-example;
>     accept_terms_of_service;
>
>     接受服務條款；
> }
> 
> acme_shared_zone zone=ngx_acme_shared:1M;
> 
> server {
>
> 伺服器{
>     listen 443 ssl;
>
>     監聽 443 ssl；
>     server_name  .example.test;
>
>     server_name.example.test;
> 
>     acme_certificate example;
>
>     acme_certificate 範例；
> 
>     ssl_certificate       $acme_certificate;
>
>     ssl_certificate $acme_certificate;
>     ssl_certificate_key   $acme_certificate_key;
>
>     ssl_certificate_key $acme_certificate_key;
> 
>     # do not parse the certificate on each request｜不要在每次請求時都解析證書
>     ssl_certificate_cache max=2;
> }
> 
> server {
>
> 伺服器{
>     # listener on port 80 is required to process ACME HTTP-01 challenges｜需要監聽埠 80 以處理ACME HTTP -01 挑戰
>     listen 80;
>
>     聽 80；
> 
>     location / {
>
>     地點/{
>         return 404;
>
>         返回 404；
>     }
> }
> ```

Defines a directory for storing the module data that can be persisted across restarts. This can improve the load time by skipping some requests on startup, and avoid hitting request rate limits on the ACME server.

定義一個用於儲存模組資料的目錄，該目錄的資料可以在重新啟動後保留。這可以透過跳過啟動時的一些請求來縮短載入時間，並避免達到ACME伺服器的請求速率限制。

The directory contains sensitive content, such as the account key, issued certificates, and private keys.

該目錄包含敏感內容，例如帳戶金鑰、已頒發的憑證和私鑰。

The `off` parameter (0.2.0) disables storing the account information and issued certificates on disk.

`off`參數 ( 0.2.0 ) 停用將帳戶資訊和頒發的憑證儲存在磁碟上。

> Prior to version 0.2.0, the state directory was not created by default.
>
> 在版本0.2.0之前，預設不會建立狀態目錄。

Agrees to the terms of service under which the ACME server will be used. Some servers require accepting the terms of service before account registration. The terms are usually available on the ACME server's website, and the URL will be printed to the error log if necessary.

同意接受使用ACME伺服器的服務條款。部分伺服器要求在註冊帳號前接受服務條款。這些條款通常可在ACME伺服器的網站上找到，如有必要， URL條款也會記錄在錯誤日誌中。

Allows increasing the size of in-memory storage of the module. The shared memory zone will be used to store the issued certificates, keys and challenge data for all the configured certificate issuers.

允許增加模組的記憶體儲存空間。共用記憶體區域將用於儲存所有已設定憑證授權單位的已核發憑證、金鑰和質詢資料。

The default zone size is sufficient to hold approximately 50 ECDSA prime256v1 keys or 35 RSA 2048 keys.

預設區域大小足以容納約 50 個ECDSA prime256v1 鑰匙或 35 個RSA 2048 鑰匙。

Defines a certificate with the list of `identifiers` requested from issuer `issuer`.

定義一個證書，其中包含從頒發者`issuer`請求的`identifiers`列表。

The explicit list of identifiers can be omitted. In this case, the identifiers will be taken from the [server\_name](<056 [01.01.03 http] 模組 ngx_http_core_module.md#server_name>) directive in the same [server](<056 [01.01.03 http] 模組 ngx_http_core_module.md#server>) block. Not all values accepted in the `server_name` are valid certificate identifiers: regular expressions and wildcards are not supported.

可以省略顯式標識符清單。在這種情況下，標識符將從同一 [server](<056 [01.01.03 http] 模組 ngx_http_core_module.md#server>)程式碼區塊中的 [server\_name](<056 [01.01.03 http] 模組 ngx_http_core_module.md#server_name>)指令中取得。並非所有`server_name`中接受的值都是有效的憑證識別碼：不支援正規表示式和通配符。

The key parameter sets the type of a generated private key. Supported key algorithms and sizes: `ecdsa:256` (default), `ecdsa:384`, `ecdsa:521`, `rsa:2048`, `rsa:3072`, `rsa:4096`.

關鍵參數設定產生的私鑰的類型。支援的金鑰演算法和大小： `ecdsa:256` （預設）， `ecdsa:384`, `ecdsa:521`, `rsa:2048`, `rsa:3072`, `rsa:4096` 。

#### Embedded Variables｜嵌入變數

The `ngx_http_acme_module` module supports embedded variables, valid in the [server](<056 [01.01.03 http] 模組 ngx_http_core_module.md#server>) block with the [acme\_certificate](#acme_certificate) directive:

`ngx_http_acme_module`模組支援嵌入式變量，在 [server](<056 [01.01.03 http] 模組 ngx_http_core_module.md#server>)區塊中，使用 [acme\_certificate](#acme_certificate)指令時有效：

`$acme_certificate`

SSL certificate that can be passed to the [ssl\_certificate](<098 [01.01.03 http] 模組 ngx_http_ssl_module.md#ssl_certificate>)

SSL可傳遞給 [ssl\_certificate 的憑證](<098 [01.01.03 http] 模組 ngx_http_ssl_module.md#ssl_certificate>)

`$acme_certificate_key`

SSL certificate private key that can be passed to [ssl\_certificate\_key](<098 [01.01.03 http] 模組 ngx_http_ssl_module.md#ssl_certificate_key>)

SSL可傳遞給 [ssl\_certificate\_key 的憑證私鑰](<098 [01.01.03 http] 模組 ngx_http_ssl_module.md#ssl_certificate_key>)
