Модуль `ngx_http_v3_module` (1.25.0) обеспечивает экспериментальную поддержку [HTTP/3](https://datatracker.ietf.org/doc/html/rfc9114).

`ngx_http_v3_module` ( 1.25.0 ) 模組為 [HTTP /3](https://datatracker.ietf.org/doc/html/rfc9114)提供實驗性支援。

По умолчанию этот модуль не собирается, его сборку необходимо разрешить с помощью конфигурационного параметра `--with-http_v3_module`.

此模組預設未構建，必須使用`--with-http_v3_module`配置參數啟用。

> Для сборки и работы этого модуля нужна библиотека [OpenSSL](http://www.openssl.org/) версии 1.1.1 или выше.
>
> 此模組需要 [OpenSSL](http://www.openssl.org/)庫版本1.1.1或更高版本才能建置和運行。

> Для поддержки 0-RTT нужна библиотека [OpenSSL](http://www.openssl.org/) версии 3.5.1 или выше. Также возможно использование библиотек [BoringSSL](https://boringssl.googlesource.com/boringssl), [LibreSSL](https://www.libressl.org/), [QuicTLS](https://github.com/quictls/openssl).
>
> 要支援 0- RTT您需要 [OpenSSL](http://www.openssl.org/)庫版本3.5.1或更高版本。您也可以使用 [BoringSSL](https://boringssl.googlesource.com/boringssl) 、[LibreSSL](https://www.libressl.org/)和 [QuicTLS](https://github.com/quictls/openssl)函式庫。

#### Известные проблемы｜已知問題

Модуль экспериментальный, поэтому возможно всё.

本模組尚處於實驗階段，因此一切皆有可能。

До версии 1.29.1 поддержка 0-RTT не могла быть разрешена при использовании OpenSSL независимо от значения директивы [ssl\_early\_data](<260 [02.01.01 http] 模組 ngx_http_ssl_module.md#ssl_early_data>).

在1.29.1無論 [ssl\_early\_data](<260 [02.01.01 http] 模組 ngx_http_ssl_module.md#ssl_early_data>)指令的值為何，使用 OpenSSL 時都無法啟用對 0- RTT的支援。

Сборка модуля не поддерживается на платформе Win32.

Win32平台不支援模組組裝。

Задаёт `*файл*` с секретным ключом, применяемым при шифровании stateless reset и address validation токенов. По умолчанию создаётся случайный ключ при каждой перезагрузке. Токены, созданные при помощи старых ключей, не принимаются.

`*файл*`指定用於加密無狀態重設令牌和位址驗證令牌的金鑰。預設情況下，每次重啟時都會產生一個隨機密鑰。使用舊密鑰產生的令牌將不被接受。

#### Встроенные переменные｜內建變數

Модуль `ngx_http_v3_module` поддерживает следующие встроенные переменные:

`ngx_http_v3_module`模組支援以下內建變數：

`$http3`

согласованный идентификатор протокола: “`h3`” для HTTP/3-соединений, “`hq`” для hq-соединений, либо пустая строка.

協商的協議標識符：「 `h3` 」表示HTTP /3連接，「 `hq` 」表示總部連接，或為空字串。
