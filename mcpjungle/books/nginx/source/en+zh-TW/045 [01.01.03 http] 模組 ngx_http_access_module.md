# Module ngx_http_access_module｜模組 ngx_http_access_module

## Module ngx\_http\_access\_module｜模組 ngx_http_access_module

|   |
| --- |
| [Example Configuration](#example)<br>[Directives](#directives)<br>     [allow](#allow)<br>     [deny](#deny)<br>[範例設定](#example)<br> [指令](#directives)<br> [允許](#allow)<br> [拒絕](#deny) |

The `ngx_http_access_module` module allows limiting access to certain client addresses.

`ngx_http_access_module`模組允許限制對某些客戶端位址的存取。

Access can also be limited by [password](<049 [01.01.03 http] 模組 ngx_http_auth_basic_module.md>), by the [result of subrequest](<051 [01.01.03 http] 模組 ngx_http_auth_request_module.md>), or by [JWT](<050 [01.01.03 http] 模組 ngx_http_auth_jwt_module.md>). Simultaneous limitation of access by address and by password is controlled by the [satisfy](<056 [01.01.03 http] 模組 ngx_http_core_module.md#satisfy>) directive.

存取也可以透過 [密碼](<049 [01.01.03 http] 模組 ngx_http_auth_basic_module.md>) 、[子請求結果](<051 [01.01.03 http] 模組 ngx_http_auth_request_module.md>)或 [JWT](<050 [01.01.03 http] 模組 ngx_http_auth_jwt_module.md>)來限制。透過位址和密碼同時限制存取由 [滿足](<056 [01.01.03 http] 模組 ngx_http_core_module.md#satisfy>)指令控制。

#### Example Configuration｜範例配置

> ```
> location / {
>
> 地點/{
>     deny  192.168.1.1;
>
>     否認192.168.1.1 ；
>     allow 192.168.1.0/24;
>
>     允許192.168.1.0/24 ；
>     allow 10.1.1.0/16;
>
>     允許10.1.1.0/16 ；
>     allow 2001:0db8::/32;
>
>     允許2001:0db8::/32 ；
>     deny  all;
>
>     全部否認；
> }
> ```

The rules are checked in sequence until the first match is found. In this example, access is allowed only for IPv4 networks `10.1.1.0/16` and `192.168.1.0/24` excluding the address `192.168.1.1`, and for IPv6 network `2001:0db8::/32`. In case of a lot of rules, the use of the [ngx\_http\_geo\_module](<062 [01.01.03 http] 模組 ngx_http_geo_module.md>) module variables is preferable.

規則會依序檢查，直到找到第一個符合項目。在本例中，僅允許存取 IPv4 網路`10.1.1.0/16`和`192.168.1.0/24` （不包括位址`192.168.1.1` ，以及 IPv6 網路`2001:0db8::/32` 。如果規則很多，建議使用 [ngx\_http\_geo\_module](<062 [01.01.03 http] 模組 ngx_http_geo_module.md>)模組變數。

#### Directives｜指令

|   |   |
| --- | --- |
| Syntax:<br>語法： | ``**allow** `*address*` \| `*CIDR*` \| `unix:` \| `all`;``<br>` `**allow** ` *地址* ` \| ` * CIDR * ` \| ` unix: ` \| `所有`;` ` |
| Default:<br>預設值： | — |
| Context:<br>背景： | `http`, `server`, `location`, `limit_except` |

Allows access for the specified network or address. If the special value `unix:` is specified (1.5.1), allows access for all UNIX-domain sockets.

允許對指定的網路或位址進行存取。如果指定了特殊值`unix:` （ 1.5.1 ），則允許對所有UNIX域套接字進行存取。

Several `allow` directives can be specified on the same level. These directives are inherited from the previous configuration level if and only if there are no `allow` and `deny` directives defined on the current level.

同一層級可以指定多個`allow`指令。當且僅噹噹前等級未定義`allow`和`deny`指令時，這些指令才會從上一個組態等級繼承。

|   |   |
| --- | --- |
| Syntax:<br>語法： | ``**deny** `*address*` \| `*CIDR*` \| `unix:` \| `all`;``<br>` `**deny** ` *地址* ` \| ` * CIDR * ` \| ` unix: ` \| `全部`;` ` |
| Default:<br>預設值： | — |
| Context:<br>背景： | `http`, `server`, `location`, `limit_except` |

Denies access for the specified network or address. If the special value `unix:` is specified (1.5.1), denies access for all UNIX-domain sockets.

拒絕指定網路或位址的存取。如果指定了特殊值`unix:` （ 1.5.1 ），則拒絕所有UNIX域套接字的存取。

Several `deny` directives can be specified on the same level. These directives are inherited from the previous configuration level if and only if there are no `allow` and `deny` directives defined on the current level.

同一層級可以指定多個`deny`指令。當且僅噹噹前等級未定義`allow`和`deny`指令時，這些指令才會從上一個組態等級繼承。
