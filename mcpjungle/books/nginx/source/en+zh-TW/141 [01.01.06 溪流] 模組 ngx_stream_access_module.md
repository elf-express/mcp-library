# Module ngx_stream_access_module｜模組 ngx_stream_access_module

## Module ngx\_stream\_access\_module｜模組 ngx_stream_access_module

|   |
| --- |
| [Example Configuration](#example)<br>[Directives](#directives)<br>     [allow](#allow)<br>     [deny](#deny)<br>[範例設定](#example)<br> [指令](#directives)<br> [允許](#allow)<br> [拒絕](#deny) |

The `ngx_stream_access_module` module (1.9.2) allows limiting access to certain client addresses.

`ngx_stream_access_module`模組（ 1.9.2 ）允許限制對某些客戶端位址的存取。

#### Example Configuration｜範例配置

> ```
> server {
>
> 伺服器 {
>     ...
>     deny  192.168.1.1;
>
>     拒絕192.168.1.1 ;
>     allow 192.168.1.0/24;
>
>     允許192.168.1.0/24 ；
>     allow 10.1.1.0/16;
>
>     允許10.1.1.0/16 ；
>     allow 2001:0db8::/32;
>
>     允許2001:0db8::/32 ；
>     deny  all;
>
>     全部否認；
> }
> ```

The rules are checked in sequence until the first match is found. In this example, access is allowed only for IPv4 networks `10.1.1.0/16` and `192.168.1.0/24` excluding the address `192.168.1.1`, and for IPv6 network `2001:0db8::/32`.

規則按順序檢查，直到找到第一個匹配項。在本例中，僅允許存取 IPv4 網路`10.1.1.0/16`和`192.168.1.0/24` （不包括位址`192.168.1.1` ，以及 IPv6 網路`2001:0db8::/32` 。

Allows access for the specified network or address. If the special value `unix:` is specified, allows access for all UNIX-domain sockets.

允許對指定的網路或位址進行存取。如果指定了特殊值`unix:` ，則允許對所有UNIX域套接字進行存取。

|   |   |
| --- | --- |

| Default:<br>預設值： | — |

Denies access for the specified network or address. If the special value `unix:` is specified, denies access for all UNIX-domain sockets.

拒絕指定網路或位址的存取。如果指定了特殊值`unix:` ，則拒絕所有UNIX域套接字的存取。
