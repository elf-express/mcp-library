Sets permitted methods of [SASL authentication](https://datatracker.ietf.org/doc/html/rfc2554) for SMTP clients. Supported methods are:

設定客戶SMTP允許的[SASL認證](https://datatracker.ietf.org/doc/html/rfc2554)方法。支持的方法有：

`plain`

[AUTH PLAIN](https://datatracker.ietf.org/doc/html/rfc4616)

`login`

[AUTH LOGIN](https://datatracker.ietf.org/doc/html/draft-murchison-sasl-login-00)

`cram-md5`

[AUTH CRAM-MD5](https://datatracker.ietf.org/doc/html/rfc2195). In order for this method to work, the password must be stored unencrypted.

[AUTH CRAM-MD5](https://datatracker.ietf.org/doc/html/rfc2195) 。為了使此方法有效，密碼必須以未加密的形式儲存。

`external`

[AUTH EXTERNAL](https://datatracker.ietf.org/doc/html/rfc4422) (1.11.6).

`none`

Authentication is not required.

無需身份驗證。

Plain text authentication methods (`AUTH PLAIN` and `AUTH LOGIN`) are always enabled, though if the `plain` and `login` methods are not specified, `AUTH PLAIN` and `AUTH LOGIN` will not be automatically included in [smtp\_capabilities](#smtp_capabilities).

純文字驗證方法（ `AUTH PLAIN`和`AUTH LOGIN` ）始終啟用，但如果未指定`plain`和`login`方法，則`AUTH PLAIN`和`AUTH LOGIN`將不會自動包含在 [smtp\_capabilities](#smtp_capabilities)中。

Sets the SMTP protocol extensions list that is passed to the client in response to the `EHLO` command. The authentication methods specified in the [smtp\_auth](#smtp_auth) directive and [STARTTLS](https://datatracker.ietf.org/doc/html/rfc3207) are automatically added to this list depending on the [starttls](<123 [01.01.04 郵件] 模組 ngx_mail_ssl_module.md#starttls>) directive value.

設定回應`EHLO`指令而傳遞給客戶端的SMTP協定擴充清單。根據 [starttls](<123 [01.01.04 郵件] 模組 ngx_mail_ssl_module.md#starttls>)指令的值，[smtp\_auth](#smtp_auth)指令和 [STARTTLS](https://datatracker.ietf.org/doc/html/rfc3207)指令中指定的身份驗證方法會自動新增至此清單。

It makes sense to specify the extensions supported by the MTA to which the clients are proxied (if these extensions are related to commands used after the authentication, when nginx transparently proxies the client connection to the backend).

如果這些擴充與身份驗證後使用的命令相關，那麼指定客戶端代理到的MTA支援的擴充就很有意義（當 nginx 透明地將客戶端連接代理到後端時）。

The current list of standardized extensions is published at [www.iana.org](http://www.iana.org/assignments/mail-parameters).

目前標準化擴充清單發佈在 [www.iana.org](http://www.iana.org/assignments/mail-parameters) 。

Sets the `*size*` of the buffer used for reading SMTP commands. By default, the buffer size is equal to one memory page. This is either 4K or 8K, depending on a platform.

設定用於讀取指令的緩衝區大小SMTP `*size*` 。預設情況下，緩衝區大小等於一個記憶體頁。根據平台不同，該大小為 4K 或 8K。

Allows setting a delay before sending an SMTP greeting in order to reject clients who fail to wait for the greeting before sending SMTP commands.

允許在發送SMTP問候語之前設定延遲，以便拒絕在發送SMTP命令之前未等待問候語的客戶端。
