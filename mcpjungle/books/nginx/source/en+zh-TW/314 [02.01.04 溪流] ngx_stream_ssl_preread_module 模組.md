## Модуль ngx\_stream\_ssl\_preread\_module｜ngx_stream_ssl_preread_module 模組

Модуль `ngx_stream_ssl_preread_module` (1.11.5) позволяет извлекать информацию из сообщения [ClientHello](https://datatracker.ietf.org/doc/html/rfc5246#section-7.4.1.2) без терминирования SSL/TLS, например имя сервера, запрошенное через [SNI](https://datatracker.ietf.org/doc/html/rfc6066#section-3) или протоколы, указанные в [ALPN](https://datatracker.ietf.org/doc/html/rfc7301). По умолчанию этот модуль не собирается, его сборку необходимо разрешить с помощью конфигурационного параметра `--with-stream_ssl_preread_module`.

`ngx_stream_ssl_preread_module`模組 (1.11.5) 允許從 [ClientHello](https://datatracker.ietf.org/doc/html/rfc5246#section-7.4.1.2)訊息中提取訊息，而無需 SSL/TLS 終止，例如透過 [SNI](https://datatracker.ietf.org/doc/html/rfc6066#section-3)請求的伺服器名稱或 [ALPN](https://datatracker.ietf.org/doc/html/rfc7301)中指定的協定。此模組預設未構建，必須透過`--with-stream_ssl_preread_module`配置參數啟用。

#### Пример конфигурации｜配置範例

Выбор сервера по имени:

按名稱選擇伺服器：

> ```
> map $ssl_preread_server_name $name {
>
> 映射 $ssl_preread_server_name $name {
>     backend.example.com      backend;
>
>     backend.example.com 後端；
>     default                  backend2;
>
>     預設後端2；
> }
> 
> upstream backend {
>
> 上游後端{
>     server 192.168.0.1:12345;
>
>     伺服器192.168.0.1:12345 ;
>     server 192.168.0.2:12345;
>
>     伺服器192.168.0.2:12345 ;
> }
> 
> upstream backend2 {
>
> 上游後端2 {
>     server 192.168.0.3:12345;
>
>     伺服器192.168.0.3:12345 ;
>     server 192.168.0.4:12345;
>
>     伺服器192.168.0.4:12345 ;
> }
> 
> server {
>
> 伺服器{
>     listen      12346;
>
>     聽 12346；
>     proxy_pass  $name;
>
>     proxy_pass $name;
>     ssl_preread on;
>
>     ssl_preread 已開啟；
> }
> ```

Выбор сервера по протоколу:

按協定選擇伺服器：

> ```
> map $ssl_preread_alpn_protocols $proxy {
>
> 映射 $ssl_preread_alpn_protocols $proxy {
>     ~\bh2\b           127.0.0.1:8001;
>
>     ~\bh2\b 127.0.0.1:8001 ;
>     ~\bhttp/1.1\b     127.0.0.1:8002;
>
>     ~\bhttp/ 1.1 \b 127.0.0.1:8002 ;
>     ~\bxmpp-client\b  127.0.0.1:8003;
>
>     ~\bxmpp-client\b 127.0.0.1:8003 ;
> }
> 
> server {
>
> 伺服器{
>     listen      9000;
>
>     聽 9000；
>     proxy_pass  $proxy;
>
>     proxy_pass $proxy;
>     ssl_preread on;
>
>     ssl_preread 已開啟；
> }
> ```

Выбор сервера по версии протокола SSL:

根據SSL協定版本選擇伺服器：

> ```
> map $ssl_preread_protocol $upstream {
>
> 映射 $ssl_preread_protocol $upstream {
>     ""        ssh.example.com:22;
>     "TLSv1.2" new.example.com:443;
>     default   tls.example.com:443;
>
>     預設 tls.example.com:443;
> }
> 
> # ssh и https на одном порту｜SSH 和 https 使用相同端口
> server {
>
> 伺服器{
>     listen      192.168.0.1:443;
>
>     聽192.168.0.1:443 ;
>     proxy_pass  $upstream;
>
>     proxy_pass $upstream;
>     ssl_preread on;
>
>     ssl_preread 已開啟；
> }
> ```

Разрешает извлечение информации из сообщения ClientHello во время фазы [предварительного чтения](<317 [02.01.04 溪流] Nginx 如何處理TCPUDP會話.md#preread_phase>).

允許在 [預讀] 階段從 ClientHello 訊息中提取資訊(https://nginx.org/ru/docs/stream/stream_processing.html#preread_phase) 。

#### Встроенные переменные｜內建變數

`$ssl_preread_protocol`

максимальная версия протокола SSL, поддерживаемая клиентом (1.15.2)

客戶端支援的SSL協定的最高版本（ 1.15.2 ）

`$ssl_preread_server_name`

имя сервера, запрошенное через SNI

透過SNI請求伺服器名稱

`$ssl_preread_alpn_protocols`

список протоколов, переданный клиентом через ALPN (1.13.10). Значения разделяются запятыми.

客戶端透過ALPN （ 1.13.10 ）傳輸的協定清單。值之間用逗號分隔。
