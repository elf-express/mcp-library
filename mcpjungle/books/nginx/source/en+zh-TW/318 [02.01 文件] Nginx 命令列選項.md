## Параметры командной строки nginx｜Nginx 命令列選項

nginx поддерживает следующие параметры командной строки:

nginx 支援以下命令列選項：

-   `-?` | `-h` — вывод справки по параметрам командной строки.  
    `-?` | `-h` — 顯示命令列參數的幫助。
-   `` -c `*файл*` `` — использование альтернативного конфигурационного файла `*файл*` вместо файла по умолчанию.  
    使用 ` ` -c ` *file* ` `` — использование альтернативного конфигурационного файла ` *file*` 取代預設檔。
-   `` -e `*файл*` `` — использование альтернативного лог-файла ошибок `*файл*` вместо файла по умолчанию (1.19.5). Специальное значение `stderr` выбирает стандартный файл ошибок.  
    ` ` -e ` *file* ` `` — использование альтернативного лог-файла ошибок ` *file* ` вместо файла по умолчанию (1.19.5). Специальное значение ` stderr` 選擇標準錯誤檔案。
-   `` -g `*директивы*` `` — задание [глобальных директив конфигурации](<285 [02.01 文件] 基本功能.md>), например  
    ` ` -g ` *指令* ` ` ` — 設定 [全域設定指令](<285 [02.01 文件] 基本功能.md>) ，例如
    
    > ```
    > nginx -g "pid /var/run/nginx.pid; worker_processes `sysctl -n hw.ncpu`;"
    >
    > nginx -g "pid /var/run/nginx.pid; worker_processes `sysctl -n hw.ncpu` ;"
    > ```
    
-   `` -l `*unix:socket*` | `*порт*` `` — включение [REST API управления nginx](https://docs.nginx.com/nginx/admin-guide/basic-functionality/runtime-control#control-api) на указанном UNIX-сокете или порту (1.31.5).  
    ` ` -l ` *unix:socket* ` | ` *port* ` ` ` — 啟用 [REST API nginx 管理](https://docs.nginx.com/nginx/admin-guide/basic-functionality/runtime-control#control-api)在指定的UNIX上接字或連接埠1.31.5 。
    
    > Начиная с версии 1.29.8 и до версии 1.31.5 этот параметр был доступен как часть [коммерческой подписки](https://www.f5.com/products/nginx).
    >
    > 從版本1.29.8到版本1.31.5此選項作為[商業訂閱](https://www.f5.com/products/nginx)的一部分提供。
    
-   `` -p `*префикс*` `` — задание префикса пути nginx, т.е. каталога, в котором будут находиться файлы сервера (по умолчанию — каталог `*/usr/local/nginx*`).  
    ` ` -p ` *前綴* ` `` — задание префикса пути nginx, т.е. каталога, в котором будут находиться файлы сервера (по умолчанию — каталог ` */usr/local/nginx*`）。
-   `-q` — вывод только сообщений об ошибках при тестировании конфигурации.  
    `-q` — 測試配置時僅輸出錯誤訊息。
-   `` -s `*сигнал*` `` — отправка *сигнала* главному процессу. Аргументом *сигнал* может быть:  
    ` ` -s ` *signal* ` ` ` — 向主程序發送一個 *signal* 訊號。 *signal* 參數可以是：
    -   `stop` — быстрое завершение  
        `stop` - 快速完成
    -   `quit` — плавное завершение  
        `quit` — 平滑完成
    -   `reload` — перезагрузка конфигурации, старт нового рабочего процесса с новой конфигурацией, плавное завершение старых рабочих процессов.  
        `reload` — 重新載入配置，使用新配置啟動新工作流程，並優雅地終止舊工作流程。
    -   `reopen` — переоткрытие лог-файлов  
        `reopen` — 重新開啟日誌文件
-   `-t` — тестирование конфигурационного файла: nginx проверяет синтаксическую правильность конфигурации, а затем пытается открыть файлы, описанные в конфигурации.  
    `-t` — 設定檔測試：nginx 檢查設定的語法正確性，然後嘗試開啟設定中所述的檔案。
-   `-T` — то же, что и `-t`, а также вывод конфигурационных файлов в стандартный поток вывода (1.9.2).  
    `-T` — 與`-t`相同，並且也將設定檔輸出到標準輸出流 ( 1.9.2 )。
-   `-v` — вывод версии nginx.  
    `-v` — nginx 版本輸出。
-   `-V` — вывод версии nginx, версии компилятора и параметров конфигурации сборки.  
    `-V` — 輸出 nginx 版本、編譯器版本和建置設定參數。
