The `ngx_otel_module` module provides [OpenTelemetry](https://opentelemetry.io/) distributed tracing support. The module supports [W3C](https://w3c.github.io/trace-context) context propagation and OTLP/gRPC export protocol.

`ngx_otel_module`模組提供 [OpenTelemetry](https://opentelemetry.io/)分散式追蹤支援。本模組支援 [W3C](https://w3c.github.io/trace-context)上下文傳播和OTLP /gRPC 導出協定。

The source code of the module is available [here](https://github.com/nginx/nginx-otel). Download and install instructions are available [here](https://github.com/nginx/nginx-otel/blob/main/README.md).

此模組的原始碼可在[此處](https://github.com/nginx/nginx-otel)取得。下載和安裝說明可在[此處](https://github.com/nginx/nginx-otel/blob/main/README.md)取得。

The module is also available in a prebuilt `nginx-module-otel` [package](<177 [01 在] nginx Linux 軟體套件.md#dynmodules>) since 1.25.3 and in `nginx-plus-module-otel` package as part of our [commercial subscription](https://www.f5.com/products/nginx) since 1.23.4.

本模組也以預先建構的`nginx-module-otel` [軟體包](<177 [01 在] nginx Linux 軟體套件.md#dynmodules>)的形式提供，自1.25.3起，並以`nginx-plus-module-otel`軟體包的形式提供，作為我們 [商業訂閱](https://www.f5.com/products/nginx)的一部分，自1.23.4

#### Example Configuration｜範例配置

> ```
> load_module modules/ngx_otel_module.so;
>
> 載入模組 modules/ngx_otel_module.so;
> 
> events {
>
> 事件 {
> }
> 
> http {
> 
>     otel_exporter {
>
>     hotel_exporter {
>         endpoint localhost:4317;
>
>         端點 localhost:4317;
>     }
> 
>     server {
>
>     伺服器 {
>         listen 127.0.0.1:8080;
>
>         聽127.0.0.1:8080 ;
> 
>         location / {
>
>         地點 / {
>             otel_trace         on;
>
>             otel_trace 已開啟；
>             otel_trace_context inject;
>
>             otel_trace_context 注入；
> 
>             proxy_pass http://backend;
>         }
>     }
> }
> ```

Specifies OTel data export parameters:

指定OTel資料導出參數：

`endpoint [(http|https)://]host:port;`

OTLP/gRPC endpoint that will accept telemetry data. TLS is supported since 0.1.2.

OTLP /gRPC 端點0.1.2 TLS受支持。

`trusted_certificate path;`

the CA certificates file in PEM format used to verify TLS endpoint (since 0.1.2). Defaults to OS provided CA bundle.

用於驗證端點（自TLS起） 0.1.2 CA憑證檔案PEM格式）。預設為OS提供的CA捆綁包。

`header name value;`

a custom HTTP header to add to telemetry export request (since 0.1.2).

要新增到遙測導出請求的自訂HTTP標頭（因為0.1.2 ）。

`interval time;`

the maximum interval between two exports, by default is `5` seconds.

兩次導出之間的最大間隔預設為`5`秒。

`batch_size number;`

the maximum number of spans to be sent in one batch per worker, by default is `512`.

每個工作進程一次發送的最大跨度數為`512` 。

`batch_count number;`

the number of pending batches per worker, spans exceeding the limit are dropped, by default is `4`.

每個工作進程的待處理批次數量，超過限制的跨度將被丟棄，預設值為`4` 。

>
>     標頭 X- API -Token“my-token-value”;
> }
> ```

Specifies how to propagate [traceparent/tracestate](https://www.w3.org/TR/trace-context/#design-overview) headers:

指定如何傳播 [traceparent/tracestate](https://www.w3.org/TR/trace-context/#design-overview)標頭：

`extract`

uses an existing trace context from the request, so that the identifiers of a [trace](#var_otel_trace_id) and the [parent span](#var_otel_parent_id) are inherited from the incoming request.

使用請求中已有的追蹤上下文，以便從傳入的請求繼承 [追蹤](#var_otel_trace_id)和 [父級 span](#var_otel_parent_id)的標識符。

`inject`

adds a new context to the request, overwriting existing headers, if any.

在請求中新增新的上下文，覆蓋現有的標頭（如果有）。

`propagate`

updates the existing context (combines [extract](#extract) and [inject](#inject)).

更新現有上下文（合併 [提取](#extract)和 [注入](#inject) ）。

`ignore`

skips context headers processing.

跳過上下文標頭處理。

#### Default span attributes｜預設跨度屬性

The following [span attributes](https://opentelemetry.io/docs/specs/semconv/registry/attributes/http/) are added automatically:

以下 [span 屬性](https://opentelemetry.io/docs/specs/semconv/registry/attributes/http/)會自動新增：

-   `http.method`
-   `http.target`
-   `http.route`
-   `http.scheme`
-   `http.flavor`
-   `http.user_agent`
-   `http.request_content_length`
-   `http.response_content_length`
-   `http.status_code`
-   `net.host.name`
-   `net.host.port`
-   `net.sock.peer.addr`
-   `net.sock.peer.port`

#### Embedded Variables｜嵌入變數

`$otel_trace_id`

the identifier of the trace the current span belongs to, for example, `56552bc4daa3bf39c08362527e1dd6c4`

當前跨距所屬軌跡的標識符，例如`56552bc4daa3bf39c08362527e1dd6c4`

`$otel_span_id`

the identifier of the current span, for example, `4c0b8531ec38ca59`

當前跨度的標識符，例如`4c0b8531ec38ca59`

`$otel_parent_id`

the identifier of the parent span, for example, `dc94d281b0f884ea`

父級 span 的標識符，例如`dc94d281b0f884ea`

`$otel_parent_sampled`

the “`sampled`” flag of the parent span, can be “`1`” or “`0`”

父級 span 的「 `sampled` 」標誌可以是「 `1` 」或「 `0` 」。
