## Сборка nginx из исходных файлов｜從原始檔建構 nginx

Сборка настраивается командой `configure`. Она определяет особенности системы и, в частности, методы, которые nginx может использовать для обработки соединений. В конце концов она создаёт `Makefile`.

建置過程由`configure`指令配置。它定義了系統特性，特別是 nginx 可以用來處理連線的方法。最終，它創建`Makefile` 。

Команда `configure` поддерживает следующие параметры:

`configure`指令支援以下參數：

`--help`

печатает справочное сообщение.

列印幫助資訊。

`` --prefix=`*путь*` ``

` ` --prefix=` *路徑* ` ` `

задаёт каталог, в котором будут находиться файлы сервера. Этот же каталог будет использоваться для всех относительных путей, задаваемых `configure` (кроме путей к исходным текстам библиотек) и в конфигурационном файле `nginx.conf`. По умолчанию — каталог `/usr/local/nginx`.

指定伺服器檔案所在的目錄。此目錄也將用於`configure`中指定的所有相對路徑（庫來源路徑除外）以及`nginx.conf`設定檔中的路徑。預設值為`/usr/local/nginx`目錄。

`` --sbin-path=`*путь*` ``

` ` --sbin-path=` *路徑* ` ` `

задаёт имя исполняемого файла nginx. Это имя используется только на стадии установки. По умолчанию файл называется `` `*префикс*`/sbin/nginx ``.

指定 nginx 可執行檔的名稱。此名稱僅在安裝期間使用。預設情況下，該檔案名稱為 ` ` ` *前綴* `/sbin/nginx ` `。

`` --modules-path=`*путь*` ``

` ` --modules-path=` *路徑* ` ` `

задаёт каталог, в который будут устанавливаться динамические модули. По умолчанию используется каталог `` `*префикс*`/modules ``.

指定動態模組的安裝目錄。預設情況下，使用 ` ` ` *前綴* `/modules `目錄。

`` --conf-path=`*путь*` ``

` ` --conf-path=` *路徑* ` ` `

задаёт имя конфигурационного файла `nginx.conf`. При желании nginx можно всегда запустить с другим конфигурационным файлом, указав его в параметре командной строки `` -c `*файл*` ``. По умолчанию файл называется `` `*префикс*`/conf/nginx.conf ``.

指定`nginx.conf`設定檔的名稱。如果需要，nginx 始終可以透過在命令列參數 ` ` -c ` *file* ` ``. По умолчанию файл называется `` ` *prefix* `/conf/nginx.conf ` ` 中指定不同的設定檔來啟動。

`` --error-log-path=`*путь*` ``

` ` --error-log-path=` *路徑* ` ` `

задаёт имя основного файла ошибок, предупреждений и диагностики. После установки имя файла можно всегда поменять в конфигурационном файле `nginx.conf` с помощью директивы [error\_log](<285 [02.01 文件] 基本功能.md#error_log>). По умолчанию имя файла — `` `*префикс*`/logs/error.log ``.

指定主要錯誤、警告和診斷文件的名稱。安裝後，始終可以使用 [error\_log](<285 [02.01 文件] 基本功能.md#error_log>) 指令在設定檔`nginx.conf`中變更檔案名稱。預設檔名是`` `*前綴*`/logs/error.log ``。

`` --pid-path=`*путь*` ``

` ` --pid-path=` *路徑* ` ` `

задаёт имя файла `nginx.pid`, в котором будет храниться номер главного процесса. После установки имя файла можно всегда поменять в конфигурационном файле `nginx.conf` с помощью директивы [pid](<285 [02.01 文件] 基本功能.md#pid>). По умолчанию имя файла — `` `*префикс*`/logs/nginx.pid ``.

指定用於儲存主進程 ID 的`nginx.pid`檔案的名稱。安裝後，可以隨時在`nginx.conf`設定檔中使用 [pid](<285 [02.01 文件] 基本功能.md#pid>)指令更改檔案名稱。預設檔名是 ` ` ` *前綴* `/logs/nginx.pid ` `。

`` --lock-path=`*путь*` ``

` ` --lock-path=` *路徑* ` ` `

задаёт префикс имён файлов блокировок. После установки значение можно всегда поменять в конфигурационном файле `nginx.conf` с помощью директивы [lock\_file](<285 [02.01 文件] 基本功能.md#lock_file>). По умолчанию используется значение `` `*префикс*`/logs/nginx.lock ``.

指定鎖定檔案名稱的前綴。安裝後，可以隨時在`nginx.conf`設定檔中使用 [lock\_file](<285 [02.01 文件] 基本功能.md#lock_file>)指令變更該值。預設值為 ` ` ` *prefix* `/logs/nginx.lock ` `。

`` --user=`*имя*` ``

` ` --user=` *姓名* ` ` `

задаёт имя непривилегированного пользователя, с правами которого будут выполняться рабочие процессы. После установки это имя можно всегда поменять в конфигурационном файле `nginx.conf` с помощью директивы [user](<285 [02.01 文件] 基本功能.md#user>). По умолчанию имя пользователя nobody.

指定運行工作進程的非特權使用者的名稱。安裝後，可以隨時在`nginx.conf`設定檔中使用 [user](<285 [02.01 文件] 基本功能.md#user>)指令變更此名稱。預設情況下，使用者名為 nobody。

`` --group=`*имя*` ``

` ` --group=` *姓名* ` ` `

задаёт имя группы, с правами которой будут выполняться рабочие процессы. После установки это имя можно всегда поменять в конфигурационном файле `nginx.conf` с помощью директивы [user](<285 [02.01 文件] 基本功能.md#user>). По умолчанию группа совпадает с именем непривилегированного пользователя.

指定工作進程運行所依據的權限群組的名稱。安裝後，可以隨時在`nginx.conf`設定檔中使用 [user](<285 [02.01 文件] 基本功能.md#user>)指令變更此名稱。預設情況下，該群組與非特權使用者的名稱相同。

`` --build=`*имя*` ``

` ` --build=` *姓名* ` ` `

задаёт необязательное имя сборки nginx.

指定一個可選的 nginx 程序集名稱。

`--with-select_module`  
`--without-select_module`

разрешает или запрещает сборку модуля для работы сервера с помощью метода `select()`. Этот модуль собирается автоматически, если на платформе не обнаружено более подходящего метода — kqueue, epoll или /dev/poll.

啟用或停用使用`select()`方法建構伺服器模組。如果在平台上未偵測到更合適的建置方法（例如 kqueue、epoll 或 /dev/poll），則會自動建置此模組。

`--with-poll_module`  
`--without-poll_module`

разрешает или запрещает сборку модуля для работы сервера с помощью метода `poll()`. Этот модуль собирается автоматически, если на платформе не обнаружено более подходящего метода — kqueue, epoll или /dev/poll.

啟用或停用使用`poll()`方法建構伺服器模組。如果在平台上未偵測到更合適的建置方法（例如 kqueue、epoll 或 /dev/poll），則會自動建置此模組。

`--with-control-api`

разрешает использование [REST API управления nginx](https://docs.nginx.com/nginx/admin-guide/basic-functionality/runtime-control#control-api) (1.31.5), см. также параметр командной строки [`-l`](<318 [02.01 文件] Nginx 命令列選項.md#l>).

啟用 [REST API nginx 控制](https://docs.nginx.com/nginx/admin-guide/basic-functionality/runtime-control#control-api) ( 1.31.5 )，另請參閱命令列參數 [`-l`](<318 [02.01 文件] Nginx 命令列選項.md#l>) 。

разрешает использование [пулов потоков](<285 [02.01 文件] 基本功能.md#thread_pool>).

разрешает использование при сборке библиотеки zlib ассемблерных вставок, оптимизированных для одного из следующих процессоров: `pentium`, `pentiumpro`.

啟用建置 zlib 函式庫時使用針對下列處理器之一最佳化的彙編程式碼： `pentium`, `pentiumpro` 。

`--with-libatomic`

разрешает сборку с библиотекой libatomic\_ops.

啟用使用 libatomic\_ops 庫進行建置。

`` --with-libatomic=`*путь*` ``

` ` --with-libatomic=` *路徑* ` ` `

задаёт путь к исходным текстам библиотеки libatomic\_ops.

設定 libatomic\_ops 庫原始碼的路徑。

`` --with-openssl=`*путь*` ``

` ` --with-openssl=` *路徑* ` ` `

задаёт путь к исходным текстам библиотеки OpenSSL.

指定 OpenSSL 庫原始碼的路徑。

`` --with-openssl-opt=`*параметры*` ``

` ` --with-openssl-opt=` *參數* ` ` `

задаёт дополнительные параметры сборки OpenSSL.

指定其他 OpenSSL 建置選項。

`--with-debug`

разрешает [отладочный лог](<205 [02.01 文件] 偵錯日誌.md>).

啟用[調試日誌](<205 [02.01 文件] 偵錯日誌.md>) 。

Пример использования параметров (всё это нужно набрать в одной строке):

使用參數的範例（所有內容都需要寫在一行中）：

> ./configure
>
> ./配置
>     --sbin-path=/usr/local/nginx/nginx
>     --conf-path=/usr/local/nginx/nginx.conf
>     --pid-path=/usr/local/nginx/nginx.pid
>     --with-http_ssl_module

>
>     --with-pcre=../pcre2- 10.39

>
>     --with-zlib=../zlib- 1.3
> ```
