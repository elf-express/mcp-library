Модуль `ngx_http_ssi_module` — это фильтр, обрабатывающий команды SSI (Server Side Includes) в проходящих через него ответах. На данный момент список поддерживаемых команд SSI неполон.

`ngx_http_ssi_module` 模組是一個過濾器，用於處理通過它的回應中的 SSI（伺服器端包含）命令。目前支援的SSI指令清單尚不完整。

#### Пример конфигурации｜配置範例

> ```
> location / {
>
> 地點 / {
>     ssi on;
>
>     SSI 開啟；
>     ...
> }
> ```

Эта директива появилась в версии 1.5.1.

該指令出現在版本1.5.1。

Позволяет сохранить поле заголовка “Last-Modified”（最後修改日期） исходного ответа во время обработки SSI для лучшего кэширования ответов.

允許您在 SSI 處理期間保留原始回應的 “Last-Modified”（最後修改日期） 標頭字段，以便更好地快取回應。

По умолчанию поле заголовка удаляется, так как содержимое ответа изменяется во время обработки и может содержать динамически созданные элементы или части, которые изменились независимо от исходного ответа.

預設情況下，標頭欄位會被刪除，因為回應內容在處理過程中會發生變化，並且可能包含動態產生的元素或已變更的部分，無論原始回應為何。

#### Команды SSI｜命令SSI

Общий формат команд SSI такой:

SSI指令的一般格式為：

> ```xml
> <!--# команда параметр1=значение1 параметр2=значение2 ... -->
> ```

Поддерживаются следующие команды:

支援以下命令：

`block`

Описывает блок, который можно использовать как заглушку в команде `include`. Внутри блока могут быть другие команды SSI. Параметр команды:

描述可用作 `include` 指令中佔位符的區塊。塊內可能還有其他指令SSI。命令參數：

`name`

имя блока.

塊名稱。

Пример:

例子：

> ```xml
> <!--# block name="one" -->
> заглушка
>
> 存根
> <!--# endblock -->
> ```

`config`

Задаёт некоторые параметры, используемые при обработке SSI, а именно:

設定處理SSI時所使用的一些參數，即：

`errmsg`

строка, выводящаяся при ошибке во время обработки SSI. По умолчанию выводится такая строка:

處理過程中出現錯誤時輸出字串SSI。預設情況下輸出以下行：

> ```
> [an error occurred while processing the directive]
>
> [處理指令時發生錯誤]
> ```

`timefmt`

строка формата, передаваемая функции `strftime()` для вывода даты и времени. По умолчанию используется такой формат:

傳遞給 `strftime()` 函數以輸出日期和時間的格式字串。預設格式為：

> ```
> "%A, %d-%b-%Y %H:%M:%S %Z"
>
> “％A，％d-％b-％Y％H：％M：％S％Z”
> ```

Для вывода времени в секундах подходит формат “`%s`”.

“`%s`”格式適合以秒為單位顯示時間。

`echo`

Выводит значение переменной. Параметры команды:

列印變數的值。命令參數：

`var`

имя переменной.

變數名。

`encoding`

способ кодирования. Возможны три значения — `none`, `url` и `entity`. По умолчанию используется `entity`.

編碼方法。有三個可能的值 - `none`, `url` 和 `entity`。預設為`entity`。

`default`

нестандартный параметр, задающий строку, которая выводится, если переменная не определена. По умолчанию выводится строка “`(none)`”. Команда

一個非標準參數，指定在未定義變數時列印的字串。預設顯示字串“`(none)`”。團隊

> ```xml
> <!--# echo var="name" default="нет" -->
> ```

заменяет такую последовательность команд:

替換以下命令序列：

> ```xml
> <!--# if expr="$name" --><!--# echo var="name" --><!--#
>        else -->нет<!--# endif -->
>
> <!--# if expr="$name" --><!--# echo var="name" --><!--#
>        else -->無<!--# endif -->
> ```

`if`

Выполняет условное включение. Поддерживаются следующие команды:

執行條件啟用。支援以下命令：

> ```xml
> <!--# if expr="..." -->
> ...
> <!--# elif expr="..." -->
> ...
> <!--# else -->
> ...
> <!--# endif -->
> ```

На данный момент поддерживается только один уровень вложенности. Параметр команды:

目前，僅支援一層嵌套。命令參數：

`expr`

выражение. В выражении может быть:

表達。表達式可以是：

-   проверка существования переменной:  
    檢查變數是否存在：
    
    > ```xml
    > <!--# if expr="$name" -->
    > ```
    
-   сравнение переменной с текстом:  
    將變數與文字進行比較：
    
    > ```xml
    > <!--# if expr="$name = text" -->
    > <!--# if expr="$name != text" -->
    > ```
    
-   сравнение переменной с регулярным выражением:  
    將變數與正規表示式進行比較：
    
    > ```xml
    > <!--# if expr="$name = /text/" -->
    > <!--# if expr="$name != /text/" -->
    > ```
    

Если в `*text*` встречаются переменные, то производится подстановка их значений. В регулярном выражении можно задать позиционные и именованные выделения, а затем использовать их через переменные, например:

如果在`*text*`中找到變量，則它們的值將被替換。在正規表示式中，您可以指定位置和命名選擇，然後透過變數使用它們，例如：

> ```xml
> <!--# if expr="$name = /(.+)@(?P<domain>.+)/" -->
>     <!--# echo var="1" -->
>     <!--# echo var="domain" -->
> <!--# endif -->
> ```

`include`

Включает в ответ результат другого запроса. Параметры команды:

在回應中包含另一個請求的結果。命令參數：

`file`

задаёт включаемый файл, например:

指定包含的文件，例如：

> ```xml
> <!--# include file="footer.html" -->
> ```

`virtual`

задаёт включаемый запрос, например:

指定要包含的查詢，例如：

> ```xml
> <!--# include virtual="/remote/body.php?argument=value" -->
> ```

Несколько запросов, указанных на одной странице и обрабатываемых проксируемыми или FastCGI/uwsgi/SCGI/gRPC-серверами, работают параллельно. Если нужна последовательная обработка, следует воспользоваться параметром `wait`.

在同一頁面上指定並由代理或 FastCGI/uwsgi/SCGI/gRPC 伺服器處理的多個請求並行運行。如果需要順序處理，則應使用參數`wait`。

`stub`

нестандартный параметр, задающий имя блока, содержимое которого будет выведено, если тело ответа на включаемый запрос пустое или если при исполнении запроса произошла ошибка, например:

一個非標準參數，指定區塊的名稱，如果包含的請求的回應正文為空或在請求執行過程中發生錯誤，則將顯示區塊的內容，例如：

> ```xml
> <!--# block name="one" -->&nbsp;<!--# endblock -->
>
> <!--# block name="one" --><!--# endblock -->
> <!--# include virtual="/remote/body.php?argument=value" stub="one" -->
> ```

Содержимое замещающего блока обрабатывается в контексте включаемого запроса.

替換區塊的內容在所包含的請求的上下文中進行處理。

`wait`

нестандартный параметр, указывающий, нужно ли ждать полного исполнения данного запроса, прежде чем продолжать выполнение SSI, например:

一個非標準參數，指示是否等待給定請求完成執行後再繼續執行SSI，例如：

> ```xml
> <!--# include virtual="/remote/body.php?argument=value" wait="yes" -->
> ```

`set`

нестандартный параметр, указывающий, что удачный результат выполнения запроса нужно записать в заданную переменную, например:

非標準參數，表示請求成功的結果應寫入指定變量，例如：

> ```xml
> <!--# include virtual="/remote/body.php?argument=value" set="one" -->
> ```

Максимальный размер ответа задаётся директивой [subrequest\_output\_buffer\_size](<221 [02.01.01 http] 模組 ngx_http_core_module.md#subrequest_output_buffer_size>) (1.13.10):

最大回應大小由 [subrequest\_output\_buffer\_size](<221 [02.01.01 http] 模組 ngx_http_core_module.md#subrequest_output_buffer_size>) (1.13.10) 指令設定：

> ```
> location /remote/ {
>
> 位置/遠端/ {
>     subrequest_output_buffer_size 64k;
>
>     子請求輸出緩衝區大小 64k；
>     ...
> }
> ```

До версии 1.13.10 в переменные можно было записать только результаты ответов, полученные через модули [ngx\_http\_proxy\_module](<248 [02.01.01 http] ngx_http_proxy_module 模組.md>), [ngx\_http\_memcached\_module](<244 [02.01.01 http] ngx_http_memcached_module 模組.md>), [ngx\_http\_fastcgi\_module](<225 [02.01.01 http] ngx_http_fastcgi_module 模組.md>) (1.5.6), [ngx\_http\_uwsgi\_module](<268 [02.01.01 http] 模組 ngx_http_uwsgi_module.md>) (1.5.6) и [ngx\_http\_scgi\_module](<254 [02.01.01 http] 模組 ngx_http_scgi_module.md>) (1.5.6). Максимальный размер ответа задавался при помощи директив [proxy\_buffer\_size](<248 [02.01.01 http] ngx_http_proxy_module 模組.md#proxy_buffer_size>), [memcached\_buffer\_size](<244 [02.01.01 http] ngx_http_memcached_module 模組.md#memcached_buffer_size>), [fastcgi\_buffer\_size](<225 [02.01.01 http] ngx_http_fastcgi_module 模組.md#fastcgi_buffer_size>), [uwsgi\_buffer\_size](<268 [02.01.01 http] 模組 ngx_http_uwsgi_module.md#uwsgi_buffer_size>) и [scgi\_buffer\_size](<254 [02.01.01 http] 模組 ngx_http_scgi_module.md#scgi_buffer_size>).

之前版本 1.13.10 只有透過模組接收到的回應結果才能寫入變數 [ngx\_http\_proxy\_module](<248 [02.01.01 http] ngx_http_proxy_module 模組.md>), [ngx\_http\_memcached\_module](<244 [02.01.01 http] ngx_http_memcached_module 模組.md>), [ngx\_http\_fastcgi\_module](<225 [02.01.01 http] ngx_http_fastcgi_module 模組.md>) (1.5.6), [ngx\_http\_uwsgi\_module](<268 [02.01.01 http] 模組 ngx_http_uwsgi_module.md>) (1.5.6) 和 [ngx\_http\_scgi\_module](<254 [02.01.01 http] 模組 ngx_http_scgi_module.md>) (1.5.6）。最大回應大小是使用 [proxy\_buffer\_size 指令設定的](<248 [02.01.01 http] ngx_http_proxy_module 模組.md#proxy_buffer_size>), [memcached\_buffer\_size](<244 [02.01.01 http] ngx_http_memcached_module 模組.md#memcached_buffer_size>), [fastcgi\_buffer\_size](<225 [02.01.01 http] ngx_http_fastcgi_module 模組.md#fastcgi_buffer_size>), [uwsgi\_buffer\_size](<268 [02.01.01 http] 模組 ngx_http_uwsgi_module.md#uwsgi_buffer_size>) 和 [scgi\_buffer\_size](<254 [02.01.01 http] 模組 ngx_http_scgi_module.md#scgi_buffer_size>).

`set`

Присваивает значение переменной. Параметры команды:

為變數賦值。命令參數：

`var`

имя переменной.

變數名。

`value`

значение переменной. Если в присваиваемом значении есть переменные, то производится подстановка их значений.

變數值。如果分配的值包含变量，则它们的值将被替换。

#### Встроенные переменные｜內建變數

Модуль `ngx_http_ssi_module` поддерживает две встроенные переменные:

`ngx_http_ssi_module`模組支援兩個內建變數：

`$date_local`

текущее время в локальной временной зоне. Формат задаётся командой `config` с параметром `timefmt`.

當地時區的當前時間。格式由命令`config`和参数`timefmt`设置。

`$date_gmt`

текущее время в GMT. Формат задаётся командой `config` с параметром `timefmt`.

目前時間在GMT。格式由命令`config`和参数`timefmt`设置。
