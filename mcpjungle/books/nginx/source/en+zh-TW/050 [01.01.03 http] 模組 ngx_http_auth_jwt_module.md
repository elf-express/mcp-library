The `ngx_http_auth_jwt_module` module (1.11.3) implements client authorization by validating the provided [JSON Web Token](https://datatracker.ietf.org/doc/html/rfc7519) (JWT) using the specified keys. The module supports [JSON Web Signature](https://datatracker.ietf.org/doc/html/rfc7515) (JWS), [JSON Web Encryption](https://datatracker.ietf.org/doc/html/rfc7516) (JWE) (1.19.7), and Nested JWT (1.21.0). The module can be used for [OpenID Connect](http://openid.net/specs/openid-connect-core-1_0.html) authentication.

`ngx_http_auth_jwt_module`模組 (1.11.3) 透過使用指定的金鑰驗證提供的 [JSON Web Token](https://datatracker.ietf.org/doc/html/rfc7519) (JWT) 來實現客戶端授權。此模組支援 [JSON Web Signature](https://datatracker.ietf.org/doc/html/rfc7515) (JWS)、[JSON Web Encryption](https://datatracker.ietf.org/doc/html/rfc7516) (JWE) (1.19.7) 和嵌套 JWT (1.21.0)。此模組可用於 [OpenID Connect](http://openid.net/specs/openid-connect-core-1_0.html)身份驗證。

The module may be combined with other access modules, such as [ngx\_http\_access\_module](<045 [01.01.03 http] 模組 ngx_http_access_module.md>), [ngx\_http\_auth\_basic\_module](<049 [01.01.03 http] 模組 ngx_http_auth_basic_module.md>), and [ngx\_http\_auth\_request\_module](<051 [01.01.03 http] 模組 ngx_http_auth_request_module.md>), via the [satisfy](<056 [01.01.03 http] 模組 ngx_http_core_module.md#satisfy>) directive.

此模組可透過 [satisfy (https://nginx.org/en/docs/http/ngx_http_access_module.html) 、[ngx\_http\_auth\_basic\_module](<049 [01.01.03 http] 模組 ngx_http_auth_basic_module.md>)與 [ngx\_http73\n\SFquest\ (https://nginx.org/en/docs/http/ngx_http_auth_request_module.html) (https://nginx.org/en/docs/http/ngx_http_core_module.html#satisfy)組合使用。

> This module is available as part of our [commercial subscription](https://www.f5.com/products/nginx).
>
> 本模組包含在我們的[商業訂閱](https://www.f5.com/products/nginx)中。

#### Supported Algorithms｜支援的演算法

The module supports the following JSON Web [Algorithms](https://www.iana.org/assignments/jose/jose.xhtml#web-signature-encryption-algorithms).

此模組支援以下JSON Web [演算法](https://www.iana.org/assignments/jose/jose.xhtml#web-signature-encryption-algorithms) 。

JWS algorithms:

JWS演算法：

-   HS256, HS384, HS512
-   RS256, RS384, RS512
-   ES256, ES384, ES512
-   EdDSA (Ed25519 and Ed448 signatures) (1.15.7)  
    EdDSA（Ed25519 和 Ed448 簽名）（ 1.15.7 ）
-   PS256, PS384, PS512 (1.29.0)

> Prior to version 1.13.7, only HS256, RS256, ES256 algorithms were supported.
>
> 在版本1.13.7之前，僅支援HS256, RS256, ES256演算法。

JWE content encryption algorithms (1.19.7):

JWE內容加密演算法 ( 1.19.7 ):

-   A128CBC-HS256, A192CBC-HS384, A256CBC-HS512
-   A128GCM, A192GCM, A256GCM

JWE key management algorithms (1.19.9):

JWE金鑰管理演算法 ( 1.19.9 ):

-   A128KW, A192KW, A256KW
-   A128GCMKW, A192GCMKW, A256GCMKW
-   dir - direct use of a shared symmetric key as the content encryption key  
    dir - 直接使用共享對稱金鑰作為內容加密金鑰
-   RSA-OAEP, RSA-OAEP-256, RSA-OAEP-384, RSA-OAEP-512 (1.21.0)

Enables validation of JSON Web Token. The specified `*string*` is used as a `realm`. Parameter value can contain variables.

啟用對JSON Web Token 的驗證。指定的`*string*`用作`realm` 。參數值可以包含變數。

The optional `token` parameter specifies a variable that contains JSON Web Token. By default, JWT is passed in the “Authorization”（授權） header as a [Bearer Token](https://datatracker.ietf.org/doc/html/rfc6750). JWT may be also passed as a cookie or a part of a query string:

可選的 `token` 參數指定包含 JSON Web Token 的變數。預設情況下，JWT作為[承載令牌](https://datatracker.ietf.org/doc/html/rfc6750). JWT在“Authorization”（授權）標頭中傳遞，也可以作為cookie或查詢字串的一部分傳遞：

> ```
> auth_jwt "closed site" token=$cookie_auth_token;
> ```

The special value `off` cancels the effect of the `auth_jwt` directive inherited from the previous configuration level.

特殊值`off`取消從上一個設定等級繼承的`auth_jwt`指令的效果。

Specifies additional checks for JWT validation. The value can contain text, variables, and their combination, and must start with a variable (1.21.7). The authentication will succeed only if all the values are not empty and are not equal to “0”.

指定對JWT驗證的附加檢查。該值可以包含文字、變數及其組合，並且必須以變數 ( 1.21.7 ) 開頭。只有當所有值均不為空且不等於“0”時，身份驗證才會成功。

> ```
> map $jwt_claim_iss $valid_jwt_iss {

#### Embedded Variables｜嵌入變數

The `ngx_http_auth_jwt_module` module supports embedded variables:

`ngx_http_auth_jwt_module`模組支援嵌入式變數：

`$jwt_header_``*name*`

returns the value of a specified [JOSE header](https://datatracker.ietf.org/doc/html/rfc7515#section-4)

傳回指定 [JOSE標頭](https://datatracker.ietf.org/doc/html/rfc7515#section-4)的值

`$jwt_claim_``*name*`

returns the value of a specified [JWT claim](https://datatracker.ietf.org/doc/html/rfc7519#section-4)

傳回指定 [JWT宣告](https://datatracker.ietf.org/doc/html/rfc7519#section-4)的值

For nested claims and claims including a dot (“.”), the value of the variable cannot be evaluated; the [auth\_jwt\_claim\_set](#auth_jwt_claim_set) directive should be used instead.

對於巢狀宣告和包含點（「.」）的聲明，無法評估變數的值；應改用 [auth\_jwt\_claim\_set](#auth_jwt_claim_set)指令。

Variable values for tokens encrypted with JWE are available only after decryption which occurs during the [Access](<028 [01.01.01 開發] 開發指南.md#http_phases>) phase.

使用JWE加密的令牌的變數值僅在解密後可用，解密發生在 [Access](<028 [01.01.01 開發] 開發指南.md#http_phases>)階段。

`$jwt_payload`

returns the decrypted top-level payload of `nested` or `encrypted` tokens (1.21.2). For nested tokens returns the enclosed JWS token. For encrypted tokens returns JSON with claims.

傳回`nested`或`encrypted`令牌（ 1.21.2 ）的解密頂層有效載荷。對於嵌套令牌，傳回包含的JWS令牌。對於加密令牌，返回帶有宣告的JSON 。
