# How nginx processes a TCPUDP session｜nginx 如何處理TCPUDP會話

> 章節：[en｜在](<000 目錄.md#c-1>) › [docs｜文件](<000 目錄.md#c-2>) › [stream｜溪流](<000 目錄.md#c-8>)

## How nginx processes a TCP/UDP session｜nginx 如何處理TCP/UDP會話

A TCP/UDP session from a client is processed in successive steps called **phases**:

來自客戶端的TCP/UDP會話按稱為**階段**的連續步驟進行處理：

`Post-accept`

The first phase after accepting a client connection. The [ngx\_stream\_realip\_module](<156 [01.01.06 溪流] 模組 ngx_stream_realip_module.md>) module is invoked at this phase.

接受客戶端連線後的第一階段。 [ngx\_stream\_realip\_module](<156 [01.01.06 溪流] 模組 ngx_stream_realip_module.md>)模組在此階段被呼叫。

`Pre-access`

Preliminary check for access. The [ngx\_stream\_limit\_conn\_module](<147 [01.01.06 溪流] 模組 ngx_stream_limit_conn_module.md>) and [ngx\_stream\_set\_module](<158 [01.01.06 溪流] 模組 ngx_stream_set_module.md>) modules are invoked at this phase.

初步訪問檢查。在此階段呼叫 [ngx\_stream\_limit\_conn\_module](<147 [01.01.06 溪流] 模組 ngx_stream_limit_conn_module.md>)和 [ngx\_stream\_set\_module](<158 [01.01.06 溪流] 模組 ngx_stream_set_module.md>)模組。

`Access`

Client access limitation before actual data processing. At this phase, the [ngx\_stream\_access\_module](<141 [01.01.06 溪流] 模組 ngx_stream_access_module.md>) module is invoked, for [njs](<133 [01.01.05 紐澤西州] nginx JavaScript 模組.md>), the [js\_access](<145 [01.01.06 溪流] 模組 ngx_stream_js_module.md#js_access>) directive is invoked.

在實際資料處理之前限制客戶端存取。在此階段，呼叫 [ngx\_stream\_access\_module](<141 [01.01.06 溪流] 模組 ngx_stream_access_module.md>)模組；對於 [njs](<133 [01.01.05 紐澤西州] nginx JavaScript 模組.md>) ，呼叫 [js\_access](<145 [01.01.06 溪流] 模組 ngx_stream_js_module.md#js_access>)指令。

`SSL`

TLS/SSL termination. The [ngx\_stream\_ssl\_module](<160 [01.01.06 溪流] 模組 ngx_stream_ssl_module.md>) module is invoked at this phase.

TLS/SSL終止。 [ngx\_stream\_ssl\_module](<160 [01.01.06 溪流] 模組 ngx_stream_ssl_module.md>)模組在此階段被呼叫。

`Preread`

Reading initial bytes of data into the [preread buffer](<142 [01.01.06 溪流] 模組 ngx_stream_core_module.md#preread_buffer_size>) to allow modules such as [ngx\_stream\_ssl\_preread\_module](<161 [01.01.06 溪流] 模組 ngx_stream_ssl_preread_module.md>) analyze the data before its processing. For [njs](<133 [01.01.05 紐澤西州] nginx JavaScript 模組.md>), the [js\_preread](<145 [01.01.06 溪流] 模組 ngx_stream_js_module.md#js_preread>) directive is invoked at this phase.

將初始位元組資料讀入 [預讀緩衝區](<142 [01.01.06 溪流] 模組 ngx_stream_core_module.md#preread_buffer_size>) ，以便 [ngx_stream_ssl_preread_module](<161 [01.01.06 溪流] 模組 ngx_stream_ssl_preread_module.md>)等模組在處理資料之前對其進行分析。對於 [njs](<133 [01.01.05 紐澤西州] nginx JavaScript 模組.md>) ，在此階段會呼叫 [js_preread](<145 [01.01.06 溪流] 模組 ngx_stream_js_module.md#js_preread>)指令。

`Content`

Mandatory phase where data is actually processed, usually [proxied](<154 [01.01.06 溪流] 模組 ngx_stream_proxy_module.md>) to [upstream](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md>) servers, or a specified value is [returned](<157 [01.01.06 溪流] 模組 ngx_stream_return_module.md>) to a client. For [njs](<133 [01.01.05 紐澤西州] nginx JavaScript 模組.md>), the [js\_filter](<145 [01.01.06 溪流] 模組 ngx_stream_js_module.md#js_filter>) directive is invoked at this phase.

資料實際處理的必經階段，通常是將資料(https://nginx.org/en/docs/stream/ngx_stream_proxy_module.html)到(https://nginx.org/en/docs/stream/ngx_stream_upstream_module.html)伺服器， (https://nginx.org/en/docs/njs/index.html)將指定值(https://nginx.org/en/docs/stream/ngx_stream_return_module.html)給客戶端。對於 njs，在此階段會呼叫(https://nginx.org/en/docs/stream/ngx_stream_js_module.html#js_filter)指令。

`Log`

The final phase where the result of a client session processing is recorded. The [ngx\_stream\_log\_module](<148 [01.01.06 溪流] 模組 ngx_stream_log_module.md>) module is invoked at this phase.

客戶端會話處理結果記錄的最後階段。 [ngx\_stream\_log\_module](<148 [01.01.06 溪流] 模組 ngx_stream_log_module.md>)模組在此階段被呼叫。
