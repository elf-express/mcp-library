## Module ngx\_http\_browser\_module｜模組 ngx_http_browser_module

|   |
| --- |

The `ngx_http_browser_module` module creates variables whose values depend on the value of the “User-Agent”（使用者代理） request header field:

`ngx_http_browser_module`模組建立變量，這些變數的值取決於“User-Agent”（使用者代理）請求頭字段的值：

`$modern_browser`

equals the value set by the [modern\_browser\_value](#modern_browser_value) directive, if a browser was identified as modern;

如果瀏覽器被辨識為現代瀏覽器，則等於 [modern\_browser\_value](#modern_browser_value)指令設定的值；

`$ancient_browser`

equals the value set by the [ancient\_browser\_value](#ancient_browser_value) directive, if a browser was identified as ancient;

如果瀏覽器被辨識為古老瀏覽器，則等於 [ancient\_browser\_value](#ancient_browser_value)指令設定的值；

`$msie`

equals “1” if a browser was identified as MSIE of any version.

如果瀏覽器被辨識為任何版本的MSIE ，則等於「1」。

#### Example Configuration｜範例配置

Choosing an index file:

選擇索引檔：

> ```
> modern_browser_value "modern.";
> 
> modern_browser msie      5.5;
>
> 現代瀏覽器 msie 5.5 ;
> modern_browser gecko     1.0.0;
>
> modern_browser gecko 1.0.0 ;
> modern_browser opera     9.0;
>
> modern_browser opera 9.0 ;
> modern_browser safari    413;
>
> modern_browser Safari 413;
> modern_browser konqueror 3.0;
>
> modern_browser konqueror 3.0 ;
> 
> index index.${modern_browser}html index.html;
> ```

Redirection for old browsers:

舊版瀏覽器重定向：

> ```
> modern_browser msie      5.0;
>
> 現代_瀏覽器 msie 5.0 ;
> modern_browser gecko     0.9.1;
>
> modern_browser gecko 0.9.1 ;
> modern_browser opera     8.0;
>
> modern_browser opera 8.0 ;
> modern_browser safari    413;
>
> modern_browser Safari 413;
> modern_browser konqueror 3.0;
>
> modern_browser konqueror 3.0 ;
> 
> modern_browser unlisted;
>
> modern_browser 未列出；
> 
> ancient_browser Links Lynx netscape4;
> 
> if ($ancient_browser) {
>
> 如果 ($ancient_browser) {
>     rewrite ^ /ancient.html;
>
>     重寫 ^ /ancient.html;
> }
> ```

If any of the specified substrings is found in the “User-Agent”（使用者代理） request header field, the browser will be considered ancient. The special string “`netscape4`” corresponds to the regular expression “`^Mozilla/[1-4]`”.

如果在“User-Agent”（使用者代理）請求頭字段中找到任何指定的子字串，則該瀏覽器將被視為過時版本。特殊字串「 `netscape4` 」對應於正規表示式「 `^Mozilla/[1-4]` 」。

Sets a value for the `$ancient_browser` variables.

設定`$ancient_browser`變數的值。

|   |   |
| --- | --- |
| Syntax:<br>語法： | ``**modern_browser** `*browser*` `*version*`;``<br>``**modern_browser** `unlisted`;``<br>` `**modern_browser** ` *瀏覽器* ` ` *版本* `;``<br>``**modern_browser** `未列出`;` ` |
| Default:<br>預設值： | — |
| Context:<br>背景： | `http`, `server`, `location` |

Specifies a version starting from which a browser is considered modern. A browser can be any one of the following: `msie`, `gecko` (browsers based on Mozilla), `opera`, `safari`, or `konqueror`.

指定瀏覽器被視為現代瀏覽器的起始版本。瀏覽器可以是以下任何一種： `msie`, `gecko` （基於 Mozilla 的瀏覽器）、 `opera`, `safari`或`konqueror` 。

Versions can be specified in the following formats: X, X.X, X.X.X, or X.X.X.X. The maximum values for each of the format are 4000, 4000.99, 4000.99.99, and 4000.99.99.99, respectively.

版本可以採用以下格式指定：X、XX、XXX 或 XXXX。每種格式的最大值分別為 4000、 4000.99, 4000.99.99和4000.99.99.99 。

The special value `unlisted` specifies to consider a browser as modern if it was not listed by the `modern_browser` and [ancient\_browser](#ancient_browser) directives. Otherwise such a browser is considered ancient. If a request does not provide the “User-Agent”（使用者代理） field in the header, the browser is treated as not being listed.

特殊值`unlisted`指定，如果瀏覽器未在`modern_browser`和 [ancient\_browser](#ancient_browser)指令中列出，則將其視為現代瀏覽器。否則，此類瀏覽器將被視為舊版瀏覽器。如果請求頭中未提供“User-Agent”（使用者代理）字段，則該瀏覽器將被視為未列出。
