## Module ngx\_stream\_realip\_module｜模組 ngx\_stream\_realip\_module

|   |
| --- |
| [Example Configuration](#example)<br>[Directives](#directives)<br>     [set\_real\_ip\_from](#set_real_ip_from)<br>[Embedded Variables](#variables)<br>[範例設定](#example)<br> [指令](#directives)<br> [set\_real\_ip\_from](#set_real_ip_from)<br> [嵌入式變數](#variables) |

The `ngx_stream_realip_module` module is used to change the client address and port to the ones sent in the PROXY protocol header (1.11.4). The PROXY protocol must be previously enabled by setting the [proxy\_protocol](<142 [01.01.06 溪流] 模組 ngx_stream_core_module.md#proxy_protocol>) parameter in the `listen` directive.

`ngx_stream_realip_module`模組用於將客戶端位址和連接埠變更為PROXY協定頭（ 1.11.4 ）中傳送的位址和連接埠PROXY協定必須事先啟用，方法是在`listen`指令中設定 [proxy\_protocol](<142 [01.01.06 溪流] 模組 ngx_stream_core_module.md#proxy_protocol>)參數。

This module is not built by default, it should be enabled with the `--with-stream_realip_module` configuration parameter.

此模組預設未構建，應使用`--with-stream_realip_module`配置參數啟用。

#### Example Configuration｜範例配置

> ```
> listen 12345 proxy_protocol;
>
> 監聽 12345 代理協議；
> 
> set_real_ip_from  192.168.1.0/24;
>
> set_real_ip_from 192.168.1.0/24 ;
> set_real_ip_from  192.168.2.1;
>
> set_real_ip_from 192.168.2.1 ;
> set_real_ip_from  2001:0db8::/32;
>
> set_real_ip_from 2001:0db8::/32 ;
> ```

#### Directives｜指令

|   |   |
| --- | --- |
| Syntax:<br>語法： | ``**set_real_ip_from** `*address*` \| `*CIDR*` \| `unix:`;``<br>` `**set_real_ip_from** ` *地址* ` \| ` * CIDR * ` \| ` unix: `;` ` |
| Default:<br>預設值： | — |
| Context:<br>背景： | `stream`, `server` |

Defines trusted addresses that are known to send correct replacement addresses. If the special value `unix:` is specified, all UNIX-domain sockets will be trusted.

定義已知會傳送正確替換位址的受信任位址。如果指定特殊值`unix:` ，則所有UNIX域套接字都會被信任。

保留原始客戶端位址
