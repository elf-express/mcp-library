# JavaScript Engine｜JavaScript 引擎

> 章節：[en｜在](<000 目錄.md#c-1>) › [docs｜文件](<000 目錄.md#c-2>) › [njs｜紐澤西州](<000 目錄.md#c-7>)

## JavaScript Engine｜JavaScript 引擎

Starting from version [0.8.6](<129 [01.01.05 紐澤西州] 變化.md#njs0.8.6>), multiple JavaScript engines are supported. To specify a particular engine, use the `js_engine` directive available for both the [http](<073 [01.01.03 http] 模組 ngx_http_js_module.md#js_engine>) and [stream](<145 [01.01.06 溪流] 模組 ngx_stream_js_module.md#js_engine>). By default, the njs engine is used.

從版本 [0.8.6](<129 [01.01.05 紐澤西州] 變化.md#njs0.8.6>)開始，支援多種 JavaScript 引擎。要指定特定的引擎，請使用 [http](<073 [01.01.03 http] 模組 ngx_http_js_module.md#js_engine>)和 [stream](<145 [01.01.06 溪流] 模組 ngx_stream_js_module.md#js_engine>)中均可用的`js_engine`指令。預設情況下，使用 njs 引擎。

#### njs engine｜njs引擎

> The njs engine is deprecated since [1.0.0](<129 [01.01.05 紐澤西州] 變化.md#njs1.0.0>); new code should use the [QuickJS](#quickjs_engine) engine instead.
>
> njs 引擎自 [1.0.0](<129 [01.01.05 紐澤西州] 變化.md#njs1.0.0>)起已被棄用；新程式碼應改用 [QuickJS](#quickjs_engine)引擎。

njs is an embeddable JavaScript engine developed as a part of the njs module. See the [Compatibility](<131 [01.01.05 紐澤西州] 相容性.md>) section for details.

njs 是一個可嵌入的 JavaScript 引擎，它是 njs 模組的一部分。詳情請參閱 [相容性](<131 [01.01.05 紐澤西州] 相容性.md>)部分。

#### QuickJS engine｜QuickJS引擎

[QuickJS](https://bellard.org/quickjs/) is a lightweight, embeddable JavaScript engine that supports the [ES2023](https://tc39.es/ecma262/2023/) specification, including features as modules, asynchronous generators, proxies and BigInt.

[QuickJS](https://bellard.org/quickjs/)是一個輕量級的、可嵌入的 JavaScript 引擎，支援 [ES2023](https://tc39.es/ecma262/2023/)規範，包括模組、非同步產生器、代理和 BigInt 等功能。

Since version [0.8.6](<129 [01.01.05 紐澤西州] 變化.md#njs0.8.6>), a drop-in replacement for [njs/nginx objects](<137 [01.01.05 紐澤西州] 參考.md>) has been introduced to ensure compatibility with the njs engine, with the following exceptions:

自版本 [0.8.6](<129 [01.01.05 紐澤西州] 變化.md#njs0.8.6>)起，引入了 [njs/nginx 物件](<137 [01.01.05 紐澤西州] 參考.md>)的直接替換，以確保與 njs 引擎的兼容性，但以下情況除外：

-   njs-specific API: [`njs.dump()`](<137 [01.01.05 紐澤西州] 參考.md#njs_dump>), `console.dump()`.  
    njs 特有的API : [ `njs.dump()` ](<137 [01.01.05 紐澤西州] 參考.md#njs_dump>), `console.dump()` 。
-   deprecated API: `require()`, use the `import` statement instead.  
    已棄用API: `require()` ，請改用`import`語句。
-   `js_preload_object` directive for [http](<073 [01.01.03 http] 模組 ngx_http_js_module.md#js_preload_object>) and [stream](<145 [01.01.06 溪流] 模組 ngx_stream_js_module.md#js_preload_object>).  
    `js_preload_object`指令用於 [http](<073 [01.01.03 http] 模組 ngx_http_js_module.md#js_preload_object>)和 [stream](<145 [01.01.06 溪流] 模組 ngx_stream_js_module.md#js_preload_object>) 。
