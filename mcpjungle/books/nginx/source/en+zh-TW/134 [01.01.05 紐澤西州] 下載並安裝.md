#### Installing as a Linux package｜以 Linux 軟體包形式安裝

For Linux, njs modules [packages](<177 [01 在] nginx Linux 軟體套件.md#dynmodules>) can be used:

對於 Linux 系統，可以使用 njs 模組 [軟體包](<177 [01 在] nginx Linux 軟體套件.md#dynmodules>) ：

-   `nginx-module-njs` — njs [dynamic](<125 [01.01 文件] 核心功能.md#load_module>) modules  
    `nginx-module-njs` — njs [動態](<125 [01.01 文件] 核心功能.md#load_module>)模組
-   `nginx-module-njs-dbg` — debug symbols for the `nginx-module-njs` package  
    `nginx-module-njs-dbg` — `nginx-module-njs`包的調試符號

After package installation, njs dynamic modules need to be loaded with the [`load_module`](<125 [01.01 文件] 核心功能.md#load_module>) directive:

安裝軟體包後，需要使用 [`load_module`](<125 [01.01 文件] 核心功能.md#load_module>)指令載入 njs 動態模組：

> ```
> load_module modules/ngx_http_js_module.so;
>
> 載入模組 modules/ngx_http_js_module.so;
> ```

or

或者

> ```
> load_module modules/ngx_stream_js_module.so;
>
> 載入模組 modules/ngx_stream_js_module.so;
> ```

#### Building from the sources｜從源頭構建

The [repository](https://github.com/nginx/njs) with njs sources can be cloned with the following command (requires [Git](https://git-scm.com/) client):

可以使用以下指令複製包含 njs 原始碼的 [倉庫](https://github.com/nginx/njs) （需要 [Git](https://git-scm.com/)客戶端）：

> ```bash
>
> 『`bash
> git clone https://github.com/nginx/njs
> ```

Then the modules should be compiled from [nginx](<024 [01.01 文件] 從原始碼建構 nginx.md>) root directory using the `--add-module` configuration parameter:

然後應該使用`--add-module`配置參數，從 [nginx](<024 [01.01 文件] 從原始碼建構 nginx.md>)根目錄編譯模組：

> ```
> ./configure --add-module=path-to-njs/nginx
> ```

The modules can also be built as [dynamic](<125 [01.01 文件] 核心功能.md#load_module>):

這些模組也可以建構為 [動態](<125 [01.01 文件] 核心功能.md#load_module>) :

> ```
> ./configure --add-dynamic-module=path-to-njs/nginx
> ```

#### Adding QuickJS engine support｜添加 QuickJS 引擎支持

Make sure you have built the QuickJS library:

請確保您已建置 QuickJS 庫：

> ```bash
>
> 『`bash
> git clone https://github.com/bellard/quickjs
> cd quickjs
> CFLAGS='-fPIC' make libquickjs.a
>
> CFLAGS ='-fPIC' make libquickjs.a
> ```

At the module compilation step, also specify the include (`-I`) and library (`-L`) paths with the `--with-cc-opt=` and `--with-ld-opt=` configuration parameters:

在模組編譯步驟中，也要使用`--with-cc-opt=`和`--with-ld-opt=`配置參數指定包含 ( `-I` ) 和函式庫 ( `-L` ) 路徑：

> ```
> ./configure --add-module=path-to-njs/nginx \
>     --with-cc-opt="-I path-to-quickjs" \
>     --with-ld-opt="-L path-to-quickjs"
>
>     --with-ld-opt="-L 路徑到 quickjs"
> ```

#### Building njs command-line utility｜建立 njs 命令列實用程式

To build only the njs command-line [utility](<130 [01.01.05 紐澤西州] 命令列介面.md>), run `./configure` and `make njs` commands from njs root directory. After building, the utility is available as `./build/njs`.

若要僅建置 njs 命令列 [實用程式](<130 [01.01.05 紐澤西州] 命令列介面.md>) ，請從 njs 根目錄執行`./configure`和`make njs`命令。建置完成後，該實用程式將作為`./build/njs`提供。
