## Модуль ngx\_http\_referer\_module｜ngx_http_referer_module 模組

Модуль `ngx_http_referer_module` позволяет блокировать доступ к сайту для запросов с неверными значениями поля “Referer”（參考） в заголовке. Следует иметь в виду, что подделать запрос с нужным значением поля “Referer”（參考） не составляет большого труда, поэтому цель использования данного модуля заключается не в стопроцентном блокировании подобных запросов, а в блокировании массового потока запросов, сделанных обычными браузерами. Нужно также учитывать, что обычные браузеры могут не передавать поле “Referer”（參考） даже для верных запросов.

`ngx_http_referer_module`模組可讓您封鎖對您的網站存取的包含無效“Referer”（參考）標頭欄位值的請求。需要注意的是，偽造包含有效“Referer”（參考）標頭字段值的請求並不難，因此該模組的目的並非完全阻止此類請求，而是阻止標準瀏覽器發出的大部分請求。此外，即使是有效的請求，標準瀏覽器也可能不會發送“Referer”（參考）標頭欄位。

#### Пример конфигурации｜配置範例

> ```
> valid_referers none blocked server_names
>
> valid_referers 無 已屏蔽 server_names
>                *.example.com example.* www.example.org/galleries/
>
>                *.example.com 範例。 * www.example.org/galleries/
>                ~\.google\.;
> 
> if ($invalid_referer) {
>
> 如果 ($invalid_referer) {
>     return 403;
>
>     返回 403；
> }
> ```

Задаёт значения поля “Referer”（參考） заголовка запроса, при которых встроенная переменная `$invalid_referer` будет иметь пустую строку в качестве значения. В противном случае значение переменной равно “`1`”. Поиск совпадения производится без учёта регистра символов.

指定請求頭字段“Referer”（參考）的值，使內建變數`$invalid_referer`的值為空字串。否則，該變數的值為「 `1` 」。匹配不區分大小寫。

Параметры могут быть следующие:

參數可以是以下幾種：

`none`

поле “Referer”（參考） в заголовке запроса отсутствует;

請求頭中缺少欄位“Referer”（參考） ；

`blocked`

поле “Referer”（參考） в заголовке запроса присутствует, но его значение удалено межсетевым экраном (firewall) или прокси-сервером; к таким значениям относятся строки, не начинающиеся на “`http://`” или “`https://`”;

請求標頭中存在“Referer”（參考）字段，但其值已被防火牆或代理伺服器刪除；此類值包括不以「 `http://` 」或「 `https://` 」開頭的字串；

`server_names`

в поле “Referer”（參考） заголовка запроса указано одно из имён сервера;

其中一個伺服器名稱在“Referer”（參考）請求頭字段中指定；

произвольная строка

任意字串

задаёт имя сервера и необязательное начало URI. В начале или конце имени сервера может быть “`*`”. При проверке порт сервера в поле “Referer”（參考） игнорируется;

指定伺服器名稱和可選前綴URI 。伺服器名稱可以以「 `*` 」開頭或結尾。檢查時將忽略“Referer”（參考）欄位中的伺服器連接埠；

регулярное выражение

正規表示式

в начале должен быть символ “`~`”. Необходимо учитывать, что на совпадение с выражением будет проверяться текст, начинающийся после “`http://`” или “`https://`”.

開頭必須包含符號「 `~` 」。需要注意的是，系統會檢查「 `http://` 」或「 `https://` 」之後的文字是否與表達式相符。

Пример:

例子：

> ```
> valid_referers none blocked server_names
>
> valid_referers 無 已屏蔽 server_names
>                *.example.com example.* www.example.org/galleries/
>
>                *.example.com 範例。 * www.example.org/galleries/
>                ~\.google\.;
> ```

#### Встроенные переменные｜內建變數

`$invalid_referer`

Пустая строка, если значение поля “Referer”（參考） заголовка запроса считается [правильным](#valid_referers), иначе “`1`”.

如果“Referer”（參考）請求頭字段的值被認為是 [正確的](#valid_referers) ，則為空字串，否則為「 `1` 」。
