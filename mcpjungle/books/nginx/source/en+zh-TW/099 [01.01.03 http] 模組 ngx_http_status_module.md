The `ngx_http_status_module` module provides access to various status information.

`ngx_http_status_module`模組提供各種狀態資訊的存取。

> This module was available as part of our [commercial subscription](https://www.f5.com/products/nginx) until 1.13.10. It was superseded by the [ngx\_http\_api\_module](<048 [01.01.03 http] 模組 ngx_http_api_module.md>) module in 1.13.3.
>
> 本模組作為我們[商業訂閱](https://www.f5.com/products/nginx)的一部分提供，直至1.13.10 。它在1.13.3中被[ngx\_http\_api\_module](<048 [01.01.03 http] 模組 ngx_http_api_module.md>)模組取代。

By default, status information is output in the JSON format.

預設情況下，狀態資訊以JSON格式輸出。

Alternatively, data may be output as JSONP. The `*callback*` parameter specifies the name of a callback function. Parameter value can contain variables. If parameter is omitted, or the computed value is an empty string, then “`ngx_status_jsonp_callback`” is used.

或者，數據可以輸出為JSONP `*callback*`指定回呼函數的名稱。參數值可以包含變數。如果省略參數，或計算出的值為空字串，則使用「 `ngx_status_jsonp_callback` 」。

Enables collection of virtual [http](<056 [01.01.03 http] 模組 ngx_http_core_module.md#server>) or [stream](<142 [01.01.06 溪流] 模組 ngx_stream_core_module.md#server>) (1.7.11) server status information in the specified `*zone*`. Several servers may share the same zone.

允許在指定的`*zone*`中收集虛擬 [http](<056 [01.01.03 http] 模組 ngx_http_core_module.md#server>)或 [stream](<142 [01.01.06 溪流] 模組 ngx_stream_core_module.md#server>) ( 1.7.11 ) 伺服器狀態資訊。多個伺服器可以共享同一個區域。

#### Data｜數據

The following status information is provided:

提供以下狀態資訊：

`version`

Version of the provided data set. The current version is 8.

所提供資料集的版本。目前版本為 8。

`nginx_version`

Version of nginx.

nginx 版本。

`nginx_build`

Name of nginx build.

nginx 建置名稱。

`address`

The address of the server that accepted status request.

接受狀態請求的伺服器位址。

`generation`

The total number of configuration [reloads](<026 [01.01 文件] 控制 Nginx.md#reconfiguration>).

配置[重新加載 的總次數](<026 [01.01 文件] 控制 Nginx.md#reconfiguration>) 。

`load_timestamp`

Time of the last reload of configuration, in milliseconds since Epoch.

上次重新載入配置的時間，以自 Unix 紀元以來的毫秒數表示。

`timestamp`

Current time in milliseconds since Epoch.

自 Unix 紀元以來的當前時間（以毫秒為單位）。

`pid`

The ID of the worker process that handled status request.

處理狀態請求的工作進程的ID 。

`ppid`

The ID of the master process that started the [worker process](#pid).

啟動 [工作進程](#pid)的主進程ID 。

`processes`

`respawned`

The total number of abnormally terminated and respawned child processes.

異常終止並重新啟動的子進程總數。

`connections`

`accepted`

The total number of accepted client connections.

已接受的客戶端連線總數。

`dropped`

The total number of dropped client connections.

客戶端連線斷開的總數。

`active`

The current number of active client connections.

當前活躍客戶端連線數。

`idle`

The current number of idle client connections.

當前空閒客戶端連線數。

`ssl`

`handshakes`

The total number of successful SSL handshakes.

成功握手的總次數SSL 。

`handshakes_failed`

The total number of failed SSL handshakes.

SSL握手失敗的總數。

`session_reuses`

The total number of session reuses during SSL handshake.

在SSL握手期間會話重用的總次數。

`requests`

`total`

The total number of client requests.

客戶請求總數。

`current`

The current number of client requests.

當前客戶端請求數量。

`server_zones`

For each [status\_zone](#status_zone):

對於每個 [status\_zone](#status_zone) :

`processing`

The number of client requests that are currently being processed.

目前正在處理的客戶請求數量。

`requests`

The total number of client requests received from clients.

從客戶收到的客戶請求總數。

`responses`

`total`

The total number of responses sent to clients.

發送給客戶的回覆總數。

`1xx`, `2xx`, `3xx`, `4xx`, `5xx`

The number of responses with status codes 1xx, 2xx, 3xx, 4xx, and 5xx.

狀態碼為 1xx、2xx、3xx、4xx 和 5xx 的回應數量。

`discarded`

The total number of requests completed without sending a response.

未發送回應的請求總數。

`received`

The total number of bytes received from clients.

從客戶端接收到的總位元組數。

`sent`

The total number of bytes sent to clients.

發送給客戶端的總位元組數。

`slabs`

For each shared memory zone that uses slab allocator:

對於每個使用 slab 分配器的共享記憶體區域：

`pages`

`used`

The current number of used memory pages.

目前已使用的記憶體頁數。

`free`

The current number of free memory pages.

目前可用記憶體頁數。

`slots`

For each memory slot size (8, 16, 32, 64, 128, etc.) the following data are provided:

對於每種記憶體插槽容量（8、16、32、64、128 等），提供以下資料：

`used`

The current number of used memory slots.

目前已使用的記憶體插槽數量。

`free`

The current number of free memory slots.

目前可用記憶體插槽數量。

`reqs`

The total number of attempts to allocate memory of specified size.

嘗試分配指定大小記憶體的總次數。

`fails`

The number of unsuccessful attempts to allocate memory of specified size.

分配指定大小記憶體的失敗嘗試次數。

`upstreams`

For each [dynamically configurable](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#zone>) [group](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#upstream>), the following data are provided:

對於每個[動態可設定](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#zone>) [群組](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#upstream>) ，提供以下數據：

`peers`

For each [server](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#server>), the following data are provided:

對於每個[伺服器](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#server>) ，提供以下數據：

`id`

The ID of the server.

伺服器的ID 。

`server`

An [address](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#server>) of the server.

伺服器的 [位址](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#server>) 。

`name`

The name of the server specified in the [server](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#server>) directive.

[server](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#server>)指令中指定的伺服器名稱。

`service`

The [service](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#service>) parameter value of the [server](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#server>) directive.

[server](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#server>)指令的 [service](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#service>)參數值。

`backup`

A boolean value indicating whether the server is a [backup](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#backup>) server.

一個布林值，指示伺服器是否為 [備份](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#backup>)伺服器。

`weight`

[Weight](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#weight>) of the server.

[重量](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#weight>)伺服器。

`state`

Current state, which may be one of “`up`”, “`draining`”, “`down`”, “`unavail`”, “`checking`”, or “`unhealthy`”.

目前狀態可能是「 `up` 」、「 `draining` 」、「 `down` 」、「 `unavail` 」、「 `checking` 」或「 `unhealthy` 」之一。

`active`

The current number of active connections.

目前活躍連線數。

`max_conns`

The [max\_conns](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#max_conns>) limit for the server.

伺服器的 [max\_conns](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#max_conns>)限制。

`requests`

The total number of client requests forwarded to this server.

轉送至此伺服器的客戶端請求總數。

`responses`

`total`

The total number of responses obtained from this server.

從該伺服器收到的回應總數。

`1xx`, `2xx`, `3xx`, `4xx`, `5xx`

The number of responses with status codes 1xx, 2xx, 3xx, 4xx, and 5xx.

狀態碼為 1xx、2xx、3xx、4xx 和 5xx 的回應數量。

`sent`

The total number of bytes sent to this server.

傳送到此伺服器的總位元組數。

`received`

The total number of bytes received from this server.

從該伺服器接收到的總位元組數。

`fails`

The total number of unsuccessful attempts to communicate with the server.

與伺服器通訊失敗的總次數。

`unavail`

How many times the server became unavailable for client requests (state “`unavail`”) due to the number of unsuccessful attempts reaching the [max\_fails](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#max_fails>) threshold.

由於失敗嘗試次數達到 [max\_fails](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#max_fails>)閾值，伺服器對客戶端請求不可用（狀態「 `unavail` 」）的次數。

`health_checks`

`checks`

The total number of [health check](<104 [01.01.03 http] 模組 ngx_http_upstream_hc_module.md#health_check>) requests made.

已發出的[健康檢查](<104 [01.01.03 http] 模組 ngx_http_upstream_hc_module.md#health_check>)請求總數。

`fails`

The number of failed health checks.

健康檢查不合格的次數。

`unhealthy`

How many times the server became unhealthy (state “`unhealthy`”).

伺服器出現不健康狀態（狀態「 `unhealthy` 」）的次數。

`last_passed`

Boolean indicating if the last health check request was successful and passed [tests](<104 [01.01.03 http] 模組 ngx_http_upstream_hc_module.md#match>).

布林值，表示上次健康檢查請求是否成功並通過了 [測試](<104 [01.01.03 http] 模組 ngx_http_upstream_hc_module.md#match>) 。

`downtime`

Total time the server was in the “`unavail`”, “`checking`”, and “`unhealthy`” states.

伺服器處於「 `unavail` 」、「 `checking` 」和「 `unhealthy` 」狀態的總時間。

`downstart`

The time (in milliseconds since Epoch) when the server became “`unavail`”, “`checking`”, or “`unhealthy`”.

伺服器變成「 `unavail` 」、「 `checking` 」或「 `unhealthy` 」的時間（自 Epoch 以來的毫秒數）。

`selected`

The time (in milliseconds since Epoch) when the server was last selected to process a request (1.7.5).

伺服器上次被選取處理請求的時間（自 Epoch 以來的毫秒數）（ 1.7.5 ）。

`header_time`

The average time to get the [response header](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#var_upstream_header_time>) from the server (1.7.10). Prior to version 1.11.6, the field was available only when using the [least\_time](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#least_time>) load balancing method.

從伺服器取得 [回應頭](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#var_upstream_header_time>)的平均時間 ( 1.7.10 )。在版本1.11.6之前，此欄位僅在使用 [least\_time](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#least_time>)負載平衡方法時可用。

`response_time`

The average time to get the [full response](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#var_upstream_response_time>) from the server (1.7.10). Prior to version 1.11.6, the field was available only when using the [least\_time](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#least_time>) load balancing method.

從伺服器 ( 1.7.10 ) 取得 [完整回應](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#var_upstream_response_time>)的平均時間。在版本1.11.6之前，此欄位僅在使用 [least\_time](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#least_time>)負載平衡方法時可用。

`keepalive`

The current number of idle [keepalive](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#keepalive>) connections.

目前空閒 [keepalive](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#keepalive>)連接數。

`zombies`

The current number of servers removed from the group but still processing active client requests.

目前已從群組中移除但仍在處理活躍用戶端請求的伺服器數量。

`zone`

The name of the shared memory [zone](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#zone>) that keeps the group’s configuration and run-time state.

保存群組配置和運行時狀態的共享記憶體 [區域](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#zone>)的名稱。

`queue`

For the requests [queue](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#queue>), the following data are provided:

對於請求 [隊列](<105 [01.01.03 http] 模組 ngx_http_upstream_module.md#queue>) ，提供以下資料：

`size`

The current number of requests in the queue.

目前佇列中的請求數量。

`max_size`

The maximum number of requests that can be in the queue at the same time.

佇列中同時可以存在的最大請求數。

`overflows`

The total number of requests rejected due to the queue overflow.

由於佇列溢出而被拒絕的請求總數。

`caches`

For each cache (configured by [proxy\_cache\_path](<085 [01.01.03 http] 模組 ngx_http_proxy_module.md#proxy_cache_path>) and the likes):

對於每個快取（由 [proxy\_cache\_path](<085 [01.01.03 http] 模組 ngx_http_proxy_module.md#proxy_cache_path>)等配置）：

`size`

The current size of the cache.

快取的當前大小。

`max_size`

The limit on the maximum size of the cache specified in the configuration.

配置中指定的快取最大​​大小限制。

`cold`

A boolean value indicating whether the “cache loader” process is still loading data from disk into the cache.

一個布林值，指示「快取載入器」進程是否仍在將資料從磁碟載入到快取中。

`hit`, `stale`, `updating`, `revalidated`

`responses`

The total number of responses read from the cache (hits, or stale responses due to [proxy\_cache\_use\_stale](<085 [01.01.03 http] 模組 ngx_http_proxy_module.md#proxy_cache_use_stale>) and the likes).

`responses`

接收最後一個位元組資料的平均時間。在版本1.11.6之前，此欄位僅在使用 [least\_time](<163 [01.01.06 溪流] 模組 ngx_stream_upstream_module.md#least_time>)負載平衡方法時可用。
