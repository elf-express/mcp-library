## Модуль ngx\_http\_index\_module｜模組 ngx_http_index_module

Модуль `ngx_http_index_module` обслуживает запросы, оканчивающиеся слэшом (‘`/`’). Такие запросы также могут обслуживаться модулями [ngx\_http\_autoindex\_module](<218 [02.01.01 http] ngx_http_autoindex_module 模組.md>) и [ngx\_http\_random\_index\_module](<250 [02.01.01 http] 模組 ngx_http_random_index_module.md>).

`ngx_http_index_module`模組處理以斜線結尾的請求（' `/` '）。此類請求也可以由 [ngx\_http\_autoindex\_module](<218 [02.01.01 http] ngx_http_autoindex_module 模組.md>)和 [ngx\_http\_random\_index\_module](<250 [02.01.01 http] 模組 ngx_http_random_index_module.md>)模組處理。

#### Пример конфигурации｜配置範例

> ```
> location / {
>
> 地點 / {
>     index index.$geo.html index.html;
> }
> ```

Определяет файлы, которые будут использоваться в качестве индекса. В имени файла можно использовать переменные. Наличие файлов проверяется в порядке их перечисления. В конце списка может стоять файл с абсолютным путём. Пример:

指定要用作索引的文件。檔案名稱中可以使用變數。文件將按列表順序檢查是否存在。可以使用絕對路徑的檔案放在清單末端。例如：

> ```
> index index.$geo.html index.0.html /index.html;
> ```

Необходимо иметь в виду, что при использовании индексного файла делается внутреннее перенаправление и запрос может быть обработан уже в другом location’е. Например, в такой конфигурации:

需要注意的是，使用索引檔案時，會執行內部重定向，請求可能會在不同的位置處理。例如，在以下配置中：

> ```
> location = / {
>
> 位置 = / {
>     index index.html;
> }
> 
> location / {
>
> 地點 / {
>     ...
> }
> ```

запрос “`/`” будет фактически обработан во втором location’е как “`/index.html`”.

請求「 `/` 」實際上將在第二個位置作為「 `/index.html` 」進行處理。
