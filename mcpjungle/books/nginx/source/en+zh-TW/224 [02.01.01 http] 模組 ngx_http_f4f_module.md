## Модуль ngx\_http\_f4f\_module｜模組 ngx\_http\_f4f\_模組

|   |
| --- |
| [Пример конфигурации](#example)<br>[Директивы](#directives)<br>     [f4f](#f4f)<br>     [f4f\_buffer\_size](#f4f_buffer_size)<br>[設定範例](#example)<br> [指令](#directives)<br> [f4f](#f4f)<br> [f4f_buffer_size](#f4f_buffer_size) |

Модуль `ngx_http_f4f_module` обеспечивает серверную поддержку протокола Adobe HTTP Dynamic Streaming (HDS).

`ngx_http_f4f_module`模組為 Adob​​e HTTP動態串流 ( HDS ) 協定提供伺服器支援。

Модуль предоставляет возможность обработки запросов HTTP Dynamic Streaming в виде “`/videoSeg1-Frag1`”, т.е. извлечения необходимого фрагмента из `videoSeg1.f4f` при помощи индексного файла `videoSeg1.f4x`. Модуль является альтернативой модулю Adobe f4f (HTTP Origin Module) для Apache.

此模組能夠將HTTP串流請求處理為“ `/videoSeg1-Frag1` ”，即使用`videoSeg1.f4x`檔案從`videoSeg1.f4f`中提取所需片段。此模組是 Adob​​e f4f 模組（ HTTP模組）的替代方案，適用於 Apache 伺服器。

Необходима предварительная обработка данных при помощи Adobe f4fpackager, дополнительную информацию см. в соответствующей документации.

需要使用 Adob​​e f4fpackager 進行資料預處理，請參閱相關文件以了解更多資訊。

> Модуль доступен как часть [коммерческой подписки](https://www.f5.com/products/nginx).
>
> 此模組包含在[商業訂閱](https://www.f5.com/products/nginx)中。
