## Модуль ngx\_stream\_mqtt\_filter\_module｜模組 ngx_stream_mqtt_filter_module

Модуль `ngx_stream_mqtt_filter_module` (1.23.4) обеспечивает поддержку протокола Message Queuing Telemetry Transport (MQTT) версий [3.1.1](https://docs.oasis-open.org/mqtt/mqtt/v3.1.1/mqtt-v3.1.1.html) и [5.0](https://docs.oasis-open.org/mqtt/mqtt/v5.0/mqtt-v5.0.html).

`ngx_stream_mqtt_filter_module` ( 1.23.4 ) 模組為訊息佇列遙測傳輸 ( MQTT ) 協定版本 [3.1.1](https://docs.oasis-open.org/mqtt/mqtt/v3.1.1/mqtt-v3.1.1.html)與 [5.0](https://docs.oasis-open.org/mqtt/mqtt/v5.0/mqtt-v5.0.html) 。

> Модуль доступен как часть [коммерческой подписки](https://www.f5.com/products/nginx).
>
> 此模組包含在[商業訂閱](https://www.f5.com/products/nginx)中。

#### Пример конфигурации｜配置範例

> ```
> listen            127.0.0.1:18883;
>
> 聽127.0.0.1:18883 ;
> proxy_pass        backend;
>
> proxy_pass 後端；
> proxy_buffer_size 16k;
> 
> mqtt             on;
>
> MQTT開啟；
> mqtt_set_connect clientid "$client";
> mqtt_set_connect username "$name";
>
> mqtt_set_connect 使用者名稱 "$name";
> ```

Задаёт `*число*` и `*размер*` буферов, необходимых для обработки MQTT-сообщений, для одного соединения.

指定處理單一連線的MQTT訊息所需的`*число*`和`*размер*`緩衝區。

> Эта директива устарела начиная с версии 1.25.1. Вместо неё следует использовать директиву [mqtt\_buffers](#mqtt_buffers).
>
> 此指令自版本1.25.1起已棄用。應改用[mqtt\_buffers指令](#mqtt_buffers) 。

Задаёт `*размер*` буфера, в который будет записываться модифицированное сообщение. По умолчанию размер одного буфера равен размеру страницы памяти. В зависимости от платформы это или 4K, или 8K, однако его можно сделать меньше.

指定用於寫入修改後訊息的`*размер*`緩衝區。預設情況下，一個緩衝區的大小等於一個記憶體頁的大小。根據平台的不同，該大小為 4K 或 8K，但可以減少。

| Синтаксис:<br>語法： | ``**mqtt_set_connect** `поле` `*значение*`;``<br>` `**mqtt_set_connect** `字段` ` *值* `;` ` |
| Умолчание:<br>預設值： | — |
| Контекст:<br>背景： | `server` |

Устанавливает `поле` в заданное `значение` для сообщения CONNECT. Поддерживаются следующие поля: `clientid`, `username` и `password`. В качестве значения можно использовать текст, переменные и их комбинации.

將訊息CONNECT的`значение` `поле`支援以下欄位： `clientid`, `username`和`password` 。值可以是文字、變數或二者的組合。

На одном уровне может быть указано несколько директив `mqtt_set_connect`:

可以在一個層級上指定多個`mqtt_set_connect`指令：

> ```
> mqtt_set_connect clientid "$client";
> mqtt_set_connect username "$name";
>
> mqtt_set_connect 使用者名稱 "$name";
> ```
