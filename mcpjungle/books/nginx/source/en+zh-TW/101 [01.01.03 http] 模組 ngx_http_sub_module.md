The `ngx_http_sub_module` module is a filter that modifies a response by replacing one specified string by another.

`ngx_http_sub_module`模組是一個過濾器，它透過將一個指定的字串替換為另一個指定的字串來修改回應。

This module is not built by default, it should be enabled with the `--with-http_sub_module` configuration parameter.

此模組預設未構建，應使用`--with-http_sub_module`配置參數啟用。

#### Example Configuration｜範例配置

> ```
> location / {
>
> 地點 / {
>     sub_filter '<a href="http://127.0.0.1:8080/'  '<a href="https://$host/';
>
>     子過濾器'<a href=" http://127.0.0.1:8080/' '<a href=" https://$host/';
>     sub_filter '<img src="http://127.0.0.1:8080/' '<img src="https://$host/';
>
>     子過濾器'<img src=" http://127.0.0.1:8080/' '<img src=" https://$host/';
>     sub_filter_once on;
>
>     子過濾器一次開啟；
> }
> ```

#### Directives｜指令

|   |   |
| --- | --- |
| Syntax:<br>語法： | ``**sub_filter** `*string*` `*replacement*`;``<br>` `**sub_filter** ` *字串* ` ` *替換* `;` ` |
| Default:<br>預設值： | — |
| Context:<br>背景： | `http`, `server`, `location` |

Sets a string to replace and a replacement string. The string to replace is matched ignoring the case. The string to replace (1.9.4) and replacement string can contain variables. Several `sub_filter` directives can be specified on the same configuration level (1.9.4). These directives are inherited from the previous configuration level if and only if there are no `sub_filter` directives defined on the current level.

設定要替換的字串和替換字串。匹配要替換的字串時忽略大小寫。要替換的字串（ 1.9.4 ）和替換字串可以包含變數。可以在同一組態等級（ 1.9.4 ）上指定多個`sub_filter`指令。當且僅噹噹前等級未定義`sub_filter`指令時，這些指令才會從上一個配置等級繼承。

This directive appeared in version 1.5.1.

該指令出現在版本1.5.1 。

Allows preserving the “Last-Modified”（最後修改日期） header field from the original response during replacement to facilitate response caching.

允許在替換過程中保留原始回應中的“Last-Modified”（最後修改日期）標頭字段，以便於回應快取。

By default, the header field is removed as contents of the response are modified during processing.

預設情況下，由於回應內容在處理過程中會被修改，因此會刪除標頭欄位。

Indicates whether to look for each string to replace once or repeatedly.

指示每個要替換的字串是查找一次還是重複查找。

Enables string replacement in responses with the specified MIME types in addition to “`text/html`”. The special value “`*`” matches any MIME type (0.8.29).

除了「 `text/html` 」類型外，還允許對具有指定MIME類型的回應進行字串替換。特殊值“ `*` ”匹配任何MIME類型（ 0.8.29 ）。
