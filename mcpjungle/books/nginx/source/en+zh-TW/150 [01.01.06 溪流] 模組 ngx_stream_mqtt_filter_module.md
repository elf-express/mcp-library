The `ngx_stream_mqtt_filter_module` module (1.23.4) provides support for Message Queuing Telemetry Transport protocol (MQTT) versions [3.1.1](https://docs.oasis-open.org/mqtt/mqtt/v3.1.1/mqtt-v3.1.1.html) and [5.0](https://docs.oasis-open.org/mqtt/mqtt/v5.0/mqtt-v5.0.html).

`ngx_stream_mqtt_filter_module`模組 ( 1.23.4 ) 提供對訊息佇列遙測傳輸協定 ( MQTT ) 版本 [3.1.1](https://docs.oasis-open.org/mqtt/mqtt/v3.1.1/mqtt-v3.1.1.html)與 [5.0](https://docs.oasis-open.org/mqtt/mqtt/v5.0/mqtt-v5.0.html) 。

> This module is available as part of our [commercial subscription](https://www.f5.com/products/nginx).
>
> 本模組作為我們[商業訂閱](https://www.f5.com/products/nginx)的一部分提供。

#### Example Configuration｜範例配置

> ```
> listen            127.0.0.1:18883;
>
> 聽127.0.0.1:18883 ;
> proxy_pass        backend;
>
> proxy_pass 後端；
> proxy_buffer_size 16k;
> 
> mqtt             on;
>
> MQTT開啟；
> mqtt_set_connect clientid "$client";
> mqtt_set_connect username "$name";
>
> mqtt_set_connect 使用者名稱 "$name";
> ```

為給定的虛擬伺服器啟用MQTT協定。

<table>
<tr><th>Syntax:<br>文法：</th><td><code><strong>mqtt_buffers</strong> <code><i>number<br>數字</i></code> <code><i>size<br>大小</i></code>;</code></td></tr>

This directive appeared in version 1.25.1.

該指令出現在版本1.25.1 。

Sets the `*number*` and `*size*` of the buffers used for handling MQTT messages, for a single connection.

設定用於處理MQTT訊息的緩衝區的`*number*`和`*size*` ，適用於單一連接。

<tr><th>Context:<br>上下文：</th><td><code>server<br>伺服器</code></td></tr>

> This directive is obsolete since version 1.25.1. The [mqtt\_buffers](#mqtt_buffers) directive should be used instead.
>
> 此指令自版本1.25.1起已過時。應改用[mqtt\_buffers](#mqtt_buffers)指令。

Sets the `*size*` of the buffer used for writing a modified message. By default, the buffer size is equal to one memory page. This is either 4K or 8K, depending on a platform. It can be made smaller, however.

設定用於寫入修改後訊息的緩衝區的`*size*`值。預設情況下，緩衝區大小等於一個記憶體頁。根據平台不同，該值可以是 4K 或 8K。不過，也可以將其減小。

|   |   |

| Syntax:<br>語法： | ``**mqtt_set_connect** `field` `*value*`;``<br>` `**mqtt_set_connect** `字段` ` *值* `;` ` |

| Context:<br>背景： | `server` |

Sets the message `field` to the given `value` for CONNECT message. The following fields are supported: `clientid`, `username`, and `password`. The value can contain text, variables, and their combination.

將訊息`field`設定為給定的`value` ，對應訊息CONNECT 。支援以下欄位： `clientid`, `username`和`password` 。該值可以包含文字、變數及其組合。

Several `mqtt_set_connect` directives can be specified on the same level:

可以在同一層級指定多個`mqtt_set_connect`指令：

> ```
> mqtt_set_connect clientid "$client";
> mqtt_set_connect username "$name";
>
> mqtt_set_connect 使用者名稱 "$name";
> ```
