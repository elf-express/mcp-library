# Command-line parameters｜命令列參數

> 章節：[en｜在](<000 目錄.md#c-1>) › [docs｜文件](<000 目錄.md#c-2>)

## Command-line parameters｜命令列參數

nginx supports the following command-line parameters:

nginx 支援以下命令列參數：

-   `-?` | `-h` — print help for command-line parameters.  
    `-?` | `-h` — 列印命令列參數的幫助資訊。
-   `` -c `*file*` `` — use an alternative configuration `*file*` instead of a default file.  
    ` ` -c ` *file* ` `` — use an alternative configuration ` *file*` 而非預設檔。
-   `` -e `*file*` `` — use an alternative error log `*file*` to store the log instead of a default file (1.19.5). The special value `stderr` selects the standard error file.  
    ` ` -e ` *file* ` `` — use an alternative error log ` *file* ` to store the log instead of a default file (1.19.5). The special value ` stderr` 選擇標準錯誤檔案。
-   `` -g `*directives*` `` — set [global configuration directives](<125 [01.01 文件] 核心功能.md>), for example,  
    ` ` -g ` *指令* ` ` ` — 設定 [全域設定指令](<125 [01.01 文件] 核心功能.md>) ，例如，
    
    > ```
    > nginx -g "pid /var/run/nginx.pid; worker_processes `sysctl -n hw.ncpu`;"
    >
    > nginx -g "pid /var/run/nginx.pid; worker_processes `sysctl -n hw.ncpu` ;"
    > ```
    
-   `` -l `*unix:socket*` | `*port*` `` — enable [nginx control REST API](https://docs.nginx.com/nginx/admin-guide/basic-functionality/runtime-control#control-api) on a specified UNIX-domain socket or port (1.31.5).  
    ` ` -l ` *unix:socket* ` | ` *port* ` ` ` — 啟用 [nginx 控制REST API](https://docs.nginx.com/nginx/admin-guide/basic-functionality/runtime-control#control-api)在指定的UNIX - 1.31.5字或連接埠上。
    
    > Since version 1.29.8 and prior to version 1.31.5, this parameter was available as part of our [commercial subscription](https://www.f5.com/products/nginx).
    >
    > 從版本1.29.8到版本1.31.5之前，此參數是作為我們[商業訂閱](https://www.f5.com/products/nginx)的一部分提供。
    
-   `` -p `*prefix*` `` — set nginx path prefix, i.e. a directory that will keep server files (default value is `*/usr/local/nginx*`).  
    ` ` -p ` *前綴* ` `` — set nginx path prefix, i.e. a directory that will keep server files (default value is ` */usr/local/nginx*`）。
-   `-q` — suppress non-error messages during configuration testing.  
    `-q` — 在配置測試期間抑制非錯誤訊息。
-   `` -s `*signal*` `` — send a *signal* to the master process. The argument *signal* can be one of:  
    ` ` -s ` *signal* ` ` ` — 向主程序發送一個 *signal* 訊號。參數 *signal* 可以是下列其中一個值：
    -   `stop` — shut down quickly  
        `stop` — 快速關閉
    -   `quit` — shut down gracefully  
        `quit` — 優雅地關閉
    -   `reload` — reload configuration, start the new worker process with a new configuration, gracefully shut down old worker processes.  
        `reload` — 重新載入配置，使用新配置啟動新的工作進程，優雅地關閉舊的工作進程。
    -   `reopen` — reopen log files  
        `reopen` — 重新開啟日誌文件
-   `-t` — test the configuration file: nginx checks the configuration for correct syntax, and then tries to open files referred in the configuration.  
    `-t` — 測試設定檔：nginx 檢查設定的語法是否正確，然後嘗試開啟設定中引用的檔案。
-   `-T` — same as `-t`, but additionally dump configuration files to standard output (1.9.2).  
    `-T` — 與`-t`相同，但也會將設定檔轉儲到標準輸出 ( 1.9.2 )。
-   `-v` — print nginx version.  
    `-v` — 列印 nginx 版本。
-   `-V` — print nginx version, compiler version, and configure parameters.  
    `-V` — 列印 nginx 版本、編譯器版本和設定參數。
