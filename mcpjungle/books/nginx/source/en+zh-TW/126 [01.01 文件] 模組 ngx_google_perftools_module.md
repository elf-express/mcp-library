# Module ngx_google_perftools_module｜模組 ngx_google_perftools_module

## Module ngx\_google\_perftools\_module｜模組 ngx\_google\_perftools\_module

|   |
| --- |
| [Example Configuration](#example)<br>[Directives](#directives)<br>     [google\_perftools\_profiles](#google_perftools_profiles)<br>[範例設定](#example)<br> [指令](#directives)<br> [google\_perftools\_profiles](#google_perftools_profiles) |

The `ngx_google_perftools_module` module (0.6.29) enables profiling of nginx worker processes using [Google Performance Tools](https://github.com/gperftools/gperftools). The module is intended for nginx developers.

`ngx_google_perftools_module`模組（ 0.6.29 ）支援使用 [Google Performance Tools](https://github.com/gperftools/gperftools)對 nginx 工作進程進行效能分析。此模組面向 nginx 開發人員。

This module is not built by default, it should be enabled with the `--with-google_perftools_module` configuration parameter.

此模組預設未構建，應使用`--with-google_perftools_module`配置參數啟用。

> This module requires the [gperftools](https://github.com/gperftools/gperftools) library.
>
> 本模組需要 [gperftools](https://github.com/gperftools/gperftools)函式庫。

#### Example Configuration｜範例配置

> ```
> google_perftools_profiles /path/to/profile;
> ```

Profiles will be stored as `/path/to/profile.<worker_pid>`.

設定檔將儲存為`/path/to/profile.<worker_pid>` 。

#### Directives｜指令

|   |   |
| --- | --- |
| Syntax:<br>文法： | ``**google_perftools_profiles** `*file*`;``<br>` `**google_perftools_profiles** ` *文件* `;` ` |
| Default:<br>預設值： | — |
| Context:<br>背景： | `main` |

Sets a file name that keeps profiling information of nginx worker process. The ID of the worker process is always a part of the file name and is appended to the end of the file name, after a dot.

設定一個檔案名，用於保存 nginx 工作進程的效能分析資訊。工作進程的ID始終是檔案名稱的一部分，並附加在檔案名稱末尾，以點號 (.) 結尾。
