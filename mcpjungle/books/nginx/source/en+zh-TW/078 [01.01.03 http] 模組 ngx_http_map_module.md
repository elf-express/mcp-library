The `ngx_http_map_module` module creates variables whose values depend on values of other variables.

`ngx_http_map_module`模組建立變量，這些變數的值取決於其他變數的值。

#### Example Configuration｜範例配置

> ```
> map $http_host $name {
>
> 映射 $http_host $name {
>     hostnames;
>
>     主機名；
> 
>     default       0;
>
>     預設值為 0；
> 
>     example.com   1;
>     *.example.com 1;
>     example.org   2;
>     *.example.org 2;
>     .example.net  3;
>     wap.*         4;
>
>     wap.* 4；
> }
> 
> map $http_user_agent $mobile {
>
> 映射 $http_user_agent $mobile {
>     default       0;
>
>     預設值為 0；
>     "~Opera Mini" 1;
>
>     “~Opera Mini” 1;
> }
> ```

#### Directives｜指令

|   |   |
| --- | --- |
| Syntax:<br>語法： | ``**map** `*string*` `*$variable*` { ... }``<br>` `**map** ` *字串* ` ` *$變數* ` { ... }` ` |
| Default:<br>預設值： | — |
| Context:<br>背景： | `http` |

Creates a new variable whose value depends on values of one or more of the source variables specified in the first parameter.

建立一個新變量，其值取決於第一個參數中指定的一個或多個來源變數的值。

> Before version 0.9.0 only a single variable could be specified in the first parameter.
>
> 在版本0.9.0之前，第一個參數只能指定一個變數。

> Since variables are evaluated only when they are used, the mere declaration even of a large number of “`map`” variables does not add any extra costs to request processing.
>
> 由於變數僅在使用時才進行評估，因此即使聲明大量的「 `map` 」變數也不會為請求處理增加任何額外的成本。

Parameters inside the `map` block specify a mapping between source and resulting values.

`map`區塊內的參數指定來源值和結果值之間的對應。

Source values are specified as strings or regular expressions (0.9.6).

來源值指定為字串或正規表示式（ 0.9.6 ）。

Strings are matched ignoring the case.

字串匹配時忽略大小寫。

A regular expression should either start from the “`~`” symbol for a case-sensitive matching, or from the “`~*`” symbols (1.0.4) for case-insensitive matching. A regular expression can contain named and positional captures that can later be used in other directives along with the resulting variable. The regular expressions are matched when the resulting variable is evaluated, and a successful match replaces the positional captures “`$1`”...“`$9`” set by previously matched regular expressions, see [Regular expression captures](https://nginx.org/en/docs/regex_captures.html).

正規表示式應以「 `~` 」符號開頭以區分大小寫進行匹配，或以「 `~*` 」符號（ 1.0.4 ）開頭以不區分大小寫進行匹配。正規表示式可以包含命名捕獲和位置捕獲，這些捕獲可以與結果變數一起用於其他指令。正規表示式在計算結果變數時進行匹配，匹配成功會替換先前匹配的正則表達式設定的位置捕獲“ `$1` ”...“ `$9` ”，請參閱[正則表達式捕獲](https://nginx.org/en/docs/regex_captures.html) 。

If a source value matches one of the names of special parameters described below, it should be prefixed with the “`\`” symbol.

如果來源值與下面描述的特殊參數名稱之一匹配，則應在其前面加上「 `\` 」符號。

The resulting value can contain text, variable (0.9.0), and their combination (1.11.0).

結果值可以包含文字、變數（ 0.9.0 ）及其組合（ 1.11.0 ）。

The following special parameters are also supported:

此外，也支援以下特殊參數：

`default` `*value*`

sets the resulting value if the source value matches none of the specified variants. When `default` is not specified, the default resulting value will be an empty string.

如果來源值與任何指定的變體都不匹配，則設定結果值。如果未指定`default` ，則預設結果值為空字串。

`hostnames`

indicates that source values can be hostnames with a prefix or suffix mask:

表示來源值可以是帶有前綴或後綴掩碼的主機名稱：

> ```
> *.example.com 1;
> example.*     1;
>
> 例如* 1；
> ```

The following two records

以下兩筆記錄

> ```
> example.com   1;
> *.example.com 1;
> ```

can be combined:

可以組合使用：

> ```
> .example.com  1;
> ```

This parameter should be specified before the list of values.

此參數應在值列表之前指定。

`include` `*file*`

includes a file with values. There can be several inclusions.

包含一個帶有值的檔案。可以包含多個文件。

`volatile`

indicates that the variable is not cacheable (1.11.7).

表示該變數不可緩存（ 1.11.7 ）。

The search is performed in the following order of priority and terminates on the first matching variant:

搜尋按以下優先順序執行，並在找到第一個符合項目時終止：

1.  the string value without a mask  
    不含遮罩的字串值
2.  the longest string value with a prefix mask, e.g. “`*.example.com`”  
    最長的字串值，帶有前綴掩碼，例如“ `*.example.com` ”
3.  the longest string value with a suffix mask, e.g. “`mail.*`”  
    最長的字串值，帶有後綴掩碼，例如“ `mail.*` ”
4.  the first matching regular expression (in order of appearance in the configuration file)  
    第一個符合的正規表示式（按在設定檔中出現的順序）
5.  the default value  
    預設值
