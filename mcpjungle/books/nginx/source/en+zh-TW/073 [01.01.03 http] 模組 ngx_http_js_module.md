The `ngx_http_js_module` module is used to implement location, variable, and filter handlers in JavaScript with [njs](<133 [01.01.05 紐澤西州] nginx JavaScript 模組.md>).

`ngx_http_js_module` 模組用於透過 [njs](<133 [01.01.05 紐澤西州] nginx JavaScript 模組.md>) 在 JavaScript 中實作位置、變數和過濾器處理程序。

Download and install instructions are available [here](<134 [01.01.05 紐澤西州] 下載並安裝.md>).

下載和安裝說明可在[此處](<134 [01.01.05 紐澤西州] 下載並安裝.md>)取得。

Sets an njs function as a response body filter. The filter function is called for each data chunk of a response body with the following arguments:

將 njs 函數設定為回應正文過濾器。使用以下參數為響應正文的每個資料塊呼叫過濾器函數：

`r`

the [HTTP request](<137 [01.01.05 紐澤西州] 參考.md#http>) object

[HTTP請求](<137 [01.01.05 紐澤西州] 參考.md#http>)對象

`data`

the incoming data chunk, may be a string or Buffer depending on the `buffer_type` value, by default is a string. Since [0.8.5](<129 [01.01.05 紐澤西州] 變化.md#njs0.8.5>), the `data` value is implicitly converted to a valid UTF-8 string by default. For binary data, the `buffer_type` value should be set to `buffer`.

傳入的資料區塊，可能是字串或 Buffer，取決於 `buffer_type` 值，預設為字串。自 [0.8.5](<129 [01.01.05 紐澤西州] 變化.md#njs0.8.5>) 起，`data` 值預設隱式轉換為有效的 UTF-8 字串。對於二進位數據，`buffer_type`值應設定為`buffer`。

`flags`

an object with the following properties:

具有以下屬性的物件：

`last`

a boolean value, true if data is a last buffer.

布林值，如果資料是最後一個緩衝區，則為 true。

The filter function can pass its own modified version of the input data chunk to the next body filter by calling [`r.sendBuffer()`](<137 [01.01.05 紐澤西州] 參考.md#r_sendbuffer>). For example, to transform all the lowercase letters in the response body:

過濾器函數可以透過呼叫[`r.sendBuffer()`](<137 [01.01.05 紐澤西州] 參考.md#r_sendbuffer>)將其自己的輸入資料塊的修改版本傳遞給下一個主體過濾器。例如，要轉換回應正文中的所有小寫字母：

> ```js
> function filter(r, data, flags) {
>
> 函數過濾器（r，數據，標誌）{
>     r.sendBuffer(data.toLowerCase(), flags);
> }
> ```

If the filter function changes the length of the response body, the “Content-Length”（內容長度） response header (if present) should be cleared in [`js_header_filter`](#js_header_filter) to enforce chunked transfer encoding:

如果過濾器函數更改響應正文的長度，則應在 [`js_header_filter`](#js_header_filter) 中清除“Content-Length”（內容長度）響應標頭（如果存在）以強制執行分塊傳輸編碼：

> ```
> example.conf:
>  location /foo {
>
>  位置/foo {
>      # proxy_pass http://localhost:8080;
> 
>     js_header_filter main.clear_content_length;
>     js_body_filter   main.filter;
>
>     js_body_filter main.filter；
>  }
> 
> example.js:
>  function clear_content_length(r) {
>
>  函數clear_content_length(r) {
>      delete r.headersOut['Content-Length'];
>
>      刪除 r.headersOut['Content-Length'];
>  }
> ```

To stop filtering and pass the data chunks to the client without calling `js_body_filter`, [`r.done()`](<137 [01.01.05 紐澤西州] 參考.md#r_done>) can be used. For example, to prepend some data to the response body:

要停止過濾並將資料塊傳遞給客戶端而不呼叫`js_body_filter`，可以使用[`r.done()`](<137 [01.01.05 紐澤西州] 參考.md#r_done>)。例如，要將一些資料加入到回應正文中：

> ```js
> function prepend(r, data, flags) {
>
> 函數前置（r，數據，標誌）{
>     r.sendBuffer("XXX");
>     r.sendBuffer(data, flags);
>
>     r.sendBuffer(數據, 標誌);
>     r.done();
> }
> ```

> As the `js_body_filter` handler returns its result immediately, it supports only synchronous operations. Thus, asynchronous operations such as [r.subrequest()](<137 [01.01.05 紐澤西州] 參考.md#r_subrequest>) or [setTimeout()](<137 [01.01.05 紐澤西州] 參考.md#settimeout>) are not supported.
>
> 由於`js_body_filter`處理程序立即返回其結果，因此它僅支援同步操作。因此，不支援 [r.subrequest()](<137 [01.01.05 紐澤西州] 參考.md#r_subrequest>) 或 [setTimeout()](<137 [01.01.05 紐澤西州] 參考.md#settimeout>) 等非同步操作。

> The directive can be specified inside the [if](<090 [01.01.03 http] 模組 ngx_http_rewrite_module.md#if>) block since [0.7.7](<129 [01.01.05 紐澤西州] 變化.md#njs0.7.7>).
>
> 自 [0.7.7](<129 [01.01.05 紐澤西州] 變化.md#njs0.7.7>) 以來，可以在 [if](<090 [01.01.03 http] 模組 ngx_http_rewrite_module.md#if>) 區塊內指定該指令。

Sets an njs function as a handler in the [access phase](<028 [01.01.01 開發] 開發指南.md#http_phases>). Asynchronous operations such as [r.subrequest()](<137 [01.01.05 紐澤西州] 參考.md#r_subrequest>), [ngx.fetch()](<137 [01.01.05 紐澤西州] 參考.md#ngx_fetch>), and [setTimeout()](<137 [01.01.05 紐澤西州] 參考.md#settimeout>) are supported.

在[訪問階段](<028 [01.01.01 開發] 開發指南.md#http_phases>)設定一個njs函數作為處理程序。支援 [r.subrequest()](<137 [01.01.05 紐澤西州] 參考.md#r_subrequest>)、[ngx.fetch()](<137 [01.01.05 紐澤西州] 參考.md#ngx_fetch>)、[setTimeout()](<137 [01.01.05 紐澤西州] 參考.md#settimeout>) 等非同步操作。

A handler that returns without calling [`r.return()`](<137 [01.01.05 紐澤西州] 參考.md#r_return>) or [`r.decline()`](<137 [01.01.05 紐澤西州] 參考.md#r_decline>) grants access. To deny access or send a custom response (for example, a redirect), the handler may call [`r.return()`](<137 [01.01.05 紐澤西州] 參考.md#r_return>). To make the handler express no opinion, deferring the decision to other access checkers under [`satisfy any`](<056 [01.01.03 http] 模組 ngx_http_core_module.md#satisfy>), the handler may call [`r.decline()`](<137 [01.01.05 紐澤西州] 參考.md#r_decline>).

不呼叫 [`r.return()`](<137 [01.01.05 紐澤西州] 參考.md#r_return>) 或 [`r.decline()`](<137 [01.01.05 紐澤西州] 參考.md#r_decline>) 傳回的處理程序將授予存取權限。若要拒絕存取或傳送自訂回應（例如重新導向），處理程序可以呼叫 [`r.return()`](<137 [01.01.05 紐澤西州] 參考.md#r_return>)。為了使處理程序不表達任何意見，將決定推遲給[`satisfy any`](<056 [01.01.03 http] 模組 ngx_http_core_module.md#satisfy>)下的其他訪問檢查器，處理程序可以呼叫[`r.decline()`](<137 [01.01.05 紐澤西州] 參考.md#r_decline>)。

預設情況下，`js_periodic`處理程序在工作進程0上執行。可選的`worker_affinity`參數允許指定應在其中執行位置內容處理程序的特定工作進程。每個工作進程集由允許的工作進程的位元遮罩表示。 `all` 遮罩允許處理程序在所有工作進程中執行。
