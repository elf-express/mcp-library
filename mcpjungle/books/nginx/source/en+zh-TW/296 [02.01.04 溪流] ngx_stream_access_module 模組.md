## Модуль ngx\_stream\_access\_module｜ngx_stream_access_module 模組

|   |

Модуль `ngx_stream_access_module` (1.9.2) позволяет ограничить доступ для определённых адресов клиентов.

`ngx_stream_access_module` ( 1.9.2 ) 模組可讓您限制對特定客戶端位址的存取。

#### Пример конфигурации｜配置範例

> ```
> server {
>
> 伺服器{
>     ...
>     deny  192.168.1.1;
>
>     拒絕192.168.1.1 ;
>     allow 192.168.1.0/24;
>
>     允許192.168.1.0/24 ；
>     allow 10.1.1.0/16;
>
>     允許10.1.1.0/16 ；
>     allow 2001:0db8::/32;
>
>     允許2001:0db8::/32 ；
>     deny  all;
>
>     全部否認；
> }
> ```

Правила проверяются в порядке их записи до первого соответствия. В данном примере доступ разрешён только для IPv4-сетей `10.1.1.0/16` и `192.168.1.0/24`, кроме адреса `192.168.1.1`, и для IPv6-сети `2001:0db8::/32`.

規則會依照編寫順序進行檢查，直到出現第一個符合項目。在本例中，僅允許存取 IPv4 網路`10.1.1.0/16`和`192.168.1.0/24` ，位址`192.168.1.1`除外，以及 IPv6 網路`2001:0db8::/32` 。

#### Директивы｜指令

|   |   |
| --- | --- |
| Синтаксис:<br>語法： | ``**allow** `*адрес*` \| `*CIDR*` \| `unix:` \| `all`;``<br>` `**allow** ` *地址* ` \| ` * CIDR * ` \| ` unix: ` \| `所有`;` ` |
| Умолчание:<br>預設值： | — |
| Контекст:<br>背景： | `stream`, `server` |

Разрешает доступ для указанной сети или адреса. Если указано специальное значение `unix:`, разрешает доступ для всех UNIX-сокетов.

允許對指定的網路或位址進行存取。如果指定了特殊值`unix:` ，則允許對所有UNIX套接字進行存取。

|   |   |
| --- | --- |
| Синтаксис:<br>語法： | ``**deny** `*адрес*` \| `*CIDR*` \| `unix:` \| `all`;``<br>` `**deny** ` *地址* ` \| ` * CIDR * ` \| ` unix: ` \| `全部`;` ` |
| Умолчание:<br>預設值： | — |
| Контекст:<br>背景： | `stream`, `server` |

Запрещает доступ для указанной сети или адреса. Если указано специальное значение `unix:`, запрещает доступ для всех UNIX-сокетов.

拒絕指定網路或位址的存取。如果指定特殊值`unix:` ，則拒絕所有UNIX套接字的存取。
