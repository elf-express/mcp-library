## Module ngx\_stream\_ssl\_preread\_module｜模組 ngx_stream_ssl_preread_module

|   |
| --- |
| [Example Configuration](#example)<br>[Directives](#directives)<br>     [ssl\_preread](#ssl_preread)<br>[Embedded Variables](#variables)<br>[範例設定](#example)<br> [指令](#directives)<br> [ssl\_preread](#ssl_preread)<br> [嵌入式變數](#variables) |

The `ngx_stream_ssl_preread_module` module (1.11.5) allows extracting information from the [ClientHello](https://datatracker.ietf.org/doc/html/rfc5246#section-7.4.1.2) message without terminating SSL/TLS, for example, the server name requested through [SNI](https://datatracker.ietf.org/doc/html/rfc6066#section-3) or protocols advertised in [ALPN](https://datatracker.ietf.org/doc/html/rfc7301). This module is not built by default, it should be enabled with the `--with-stream_ssl_preread_module` configuration parameter.

`ngx_stream_ssl_preread_module`模組（ 1.11.5 ）允許從 [ClientHello](https://datatracker.ietf.org/doc/html/rfc5246#section-7.4.1.2)訊息中提取信息，而無需終止SSL/TLS ，例如，透過 [SNI](https://datatracker.ietf.org/doc/html/rfc6066#section-3)請求的伺服器名稱或在 [ ALPN (https://datatracker.ietf.org/doc/html/rfc7301)中通告的協議。此模組預設未構建，應使用`--with-stream_ssl_preread_module`配置參數啟用。

#### Example Configuration｜範例配置

Selecting an upstream based on server name:

根據伺服器名稱選擇上游伺服器：

> ```
> map $ssl_preread_server_name $name {
>
> 映射 $ssl_preread_server_name $name {
>     backend.example.com      backend;
>
>     backend.example.com 後端；
>     default                  backend2;
>
>     預設後端2；
> }
> 
> upstream backend {
>
> 上游後端 {
>     server 192.168.0.1:12345;
>
>     伺服器192.168.0.1:12345 ;
>     server 192.168.0.2:12345;
>
>     伺服器192.168.0.2:12345 ;
> }
> 
> upstream backend2 {
>
> 上游後端2 {
>     server 192.168.0.3:12345;
>
>     伺服器192.168.0.3:12345 ;
>     server 192.168.0.4:12345;
>
>     伺服器192.168.0.4:12345 ;
> }
> 
> server {
>
> 伺服器 {
>     listen      12346;
>
>     聽 12346；
>     proxy_pass  $name;
>
>     proxy_pass $name;
>     ssl_preread on;
>
>     ssl_preread 已開啟；
> }
> ```

Selecting an upstream based on protocol:

根據協定選擇上游伺服器：

> ```
> map $ssl_preread_alpn_protocols $proxy {
>
> 映射 $ssl_preread_alpn_protocols $proxy {
>     ~\bh2\b           127.0.0.1:8001;
>
>     ~\bh2\b 127.0.0.1:8001 ;
>     ~\bhttp/1.1\b     127.0.0.1:8002;
>
>     ~\bhttp/ 1.1 \b 127.0.0.1:8002 ;
>     ~\bxmpp-client\b  127.0.0.1:8003;
>
>     ~\bxmpp-client\b 127.0.0.1:8003 ;
> }
> 
> server {
>
> 伺服器 {
>     listen      9000;
>
>     聽 9000；
>     proxy_pass  $proxy;
>
>     proxy_pass $proxy;
>     ssl_preread on;
>
>     ssl_preread 已開啟；
> }
> ```

Selecting an upstream based on SSL protocol version:

根據SSL協定版本選擇上游伺服器：

> ```
> map $ssl_preread_protocol $upstream {
>
> 映射 $ssl_preread_protocol $upstream {
>     ""        ssh.example.com:22;
>     "TLSv1.2" new.example.com:443;
>     default   tls.example.com:443;
>
>     預設 tls.example.com:443;
> }
> 
> # ssh and https on the same port｜SSH 和 HTTPS 使用相同連接埠
> server {
>
> 伺服器 {
>     listen      192.168.0.1:443;
>
>     聽192.168.0.1:443 ;
>     proxy_pass  $upstream;
>
>     proxy_pass $upstream;
>     ssl_preread on;
>
>     ssl_preread 已開啟；
> }
> ```

Enables extracting information from the ClientHello message at the [preread](<165 [01.01.06 溪流] nginx 如何處理TCPUDP會話.md#preread_phase>) phase.

允許在 [preread](<165 [01.01.06 溪流] nginx 如何處理TCPUDP會話.md#preread_phase>)階段從 ClientHello 訊息中提取資訊。

#### Embedded Variables｜嵌入變數

`$ssl_preread_protocol`

the highest SSL protocol version supported by the client (1.15.2)

客戶端支援的最高SSL協定版本（ 1.15.2 ）

`$ssl_preread_server_name`

server name requested through SNI

透過SNI請求伺服器名稱

`$ssl_preread_alpn_protocols`

list of protocols advertised by the client through ALPN (1.13.10). The values are separated by commas.

客戶端透過ALPN ( 1.13.10 ) 通告的協定清單。值之間用逗號分隔。
