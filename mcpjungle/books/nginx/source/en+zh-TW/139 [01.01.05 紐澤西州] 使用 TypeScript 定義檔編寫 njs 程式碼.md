## Writing njs code using TypeScript definition files｜使用 TypeScript 定義檔編寫 njs 程式碼

[TypeScript](https://www.typescriptlang.org/) is a typed superset of JavaScript that compiles to plain JavaScript.

[TypeScript](https://www.typescriptlang.org/)是 JavaScript 的類型化超集，可以編譯成純 JavaScript。

TypeScript supports definition files that contain type information of existing JavaScript libraries. This enables other programs to use the values defined in the files as if they were statically typed TypeScript entities.

TypeScript 支援包含現有 JavaScript 函式庫類型資訊的定義檔。這使得其他程式能夠像使用靜態類型的 TypeScript 實體一樣使用檔案中定義的值。

njs provides TypeScript definition files for its [API](<137 [01.01.05 紐澤西州] 參考.md>) which can be used to:

njs 為其 [API](<137 [01.01.05 紐澤西州] 參考.md>)提供了 TypeScript 定義文件，可用於：

-   Get autocompletion and API check in an editor  
    在編輯器中取得自動補全和API簽到
-   Write njs type-safe code  
    編寫 NJS 類型安全的程式碼

#### Compiling TypeScript definition files｜編譯 TypeScript 定義文件

> ```bash
>
> 『`bash
> $ git clone https://github.com/nginx/njs
> $ cd njs && ./configure && make ts
> $ ls build/ts/
> njs_core.d.ts
> njs_shell.d.ts
> ngx_http_js_module.d.ts
> ngx_stream_js_module.d.ts
> ```

#### API checks and autocompletions｜API檢查和自動完成

Put `*.d.ts` files to a place where you editor can find it.

將`*.d.ts`檔案放到編輯器可以找到的地方。

`test.js`:

> ```js
> /// <reference path="ngx_http_js_module.d.ts" />
> /**
>  * @param {NginxHTTPRequest} r
>  * */
> function content_handler(r) {
>
> 函數 content_handler(r) {
>     r.headersOut['content-type'] = 'text/plain';
>     r.return(200, "Hello"（你好）);
>
>     r.return(200, "Hello"（你好） );
> }
> ```

#### Writing njs type-safe code｜編寫 njs 類型安全的程式碼

`test.ts`:

> ```js
> /// <reference path="ngx_http_js_module.d.ts" />
> function content_handler(r: NginxHTTPRequest) {
>     r.headersOut['content-type'] = 'text/plain';
>     r.return(200, "Hello from TypeScript");
> }
> ```

TypeScript installation:

TypeScript 安裝：

> ```
> # npm install -g typescript
> ```

TypeScript compilation:

TypeScript 編譯：

> ```bash
>
> 『`bash
> $ tsc test.ts
> $ cat test.js
> ```

The resulting `test.js` file can be used directly with njs.

產生的`test.js`檔案可以直接與 njs 一起使用。
