The `ngx_http_gzip_module` module is a filter that compresses responses using the “gzip” method. This often helps to reduce the size of transmitted data by half or even more.

`ngx_http_gzip_module`模組是一個使用「gzip」方法壓縮響應的過濾器。這通常有助於將傳輸資料的大小減少一半甚至更多。

> When using the SSL/TLS protocol, compressed responses may be subject to [BREACH](https://en.wikipedia.org/wiki/BREACH) attacks.
>
> 使用SSL/TLS協定時，壓縮響應可能會受到[BREACH](https://en.wikipedia.org/wiki/BREACH)攻擊。

#### Example Configuration｜範例配置

> ```
> gzip            on;
>
> gzip 開啟；
> gzip_min_length 1000;
>
> gzip_min_length 1000；
> gzip_proxied    expired no-cache no-store private auth;
>
> gzip_proxied 過期無快取無儲存私有身分驗證；
> gzip_types      text/plain application/xml;
>
> gzip_types 文字/普通應用程式/xml；
> ```

The `$gzip_ratio` variable can be used to log the achieved compression ratio.

`$gzip_ratio` 變數可用來記錄所實現的壓縮比。

Sets the `*number*` and `*size*` of buffers used to compress a response. By default, the buffer size is equal to one memory page. This is either 4K or 8K, depending on a platform.

設定用於壓縮響應的緩衝區的`*number*`和`*size*`。預設情況下，緩衝區大小等於一頁記憶體。這是 4K 或 8K，取決於平台。

> Until version 0.7.28, four 4K or 8K buffers were used by default.
>
> 在版本0.7.28之前，預設使用四個4K或8K緩衝區。

Disables gzipping of responses for requests with “User-Agent”（使用者代理） header fields matching any of the specified regular expressions.

Enables or disables gzipping of responses for proxied requests depending on the request and response. The fact that the request is proxied is determined by the presence of the “Via”（透過） request header field. The directive accepts multiple parameters:

根據請求和回應啟用或停用代理請求回應的 gzip 壓縮。請求被代理的事實是由“Via”（透過）請求頭字段的存在來決定的。此指令接受多個參數：

`off`

disables compression for all proxied requests, ignoring other parameters;

禁用所有代理請求的壓縮，忽略其他參數；

`expired`

enables compression if a response header includes the “Expires”（過期） field with a value that disables caching;

如果回應標頭包含 “Expires”（過期） 欄位以及停用快取的值，則啟用壓縮；

`no-cache`

enables compression if a response header includes the “Cache-Control”（快取控制） field with the “`no-cache`” parameter;

如果回應標頭包含帶有「`no-cache`」參數的“Cache-Control”（快取控制）字段，則啟用壓縮；

`no-store`

enables compression if a response header includes the “Cache-Control”（快取控制） field with the “`no-store`” parameter;

如果響應頭包含帶有「`no-store`」參數的“Cache-Control”（快取控制）字段，則啟用壓縮；

`private`

enables compression if a response header includes the “Cache-Control”（快取控制） field with the “`private`” parameter;

如果回應頭包含帶有「`private`」參數的“Cache-Control”（快取控制）字段，則啟用壓縮；

`no_last_modified`

enables compression if a response header does not include the “Last-Modified”（最後修改日期） field;

如果回應標頭不包含 “Last-Modified”（最後修改日期） 字段，則啟用壓縮；

`no_etag`

enables compression if a response header does not include the “ETag”（電子標籤） field;

如果回應標頭不包含 “ETag”（電子標籤） 字段，則啟用壓縮；

`auth`

enables compression if a request header includes the “Authorization”（授權） field;

如果請求標頭包含 “Authorization”（授權） 字段，則啟用壓縮；

`any`

enables compression for all proxied requests.

為所有代理請求啟用壓縮。

Enables gzipping of responses for the specified MIME types in addition to “`text/html`”. The special value “`*`” matches any MIME type (0.8.29). Responses with the “`text/html`” type are always compressed.

除了「`text/html`」之外，還可以對指定的MIME類型的回應啟用gzip壓縮。特殊值“`*`”匹配任何MIME類型（0.8.29）。 “`text/html`”類型的響應始終被壓縮。

<tr><th>Syntax:<br>語法：</th><td><code><strong>gzip_vary</strong> <code>on</code> | <code>off<br>關閉</code>;</code></td></tr>

<tr><th>Context:<br>上下文：</th><td><code>http</code>, <code>server<br>伺服器</code>, <code>location<br>位置</code></td></tr>
</table>

Enables or disables inserting the “Vary: Accept-Encoding” response header field if the directives [gzip](#gzip), [gzip\_static](<067 [01.01.03 http] 模組 ngx_http_gzip_static_module.md#gzip_static>), or [gunzip](<065 [01.01.03 http] 模組 ngx_http_gunzip_module.md#gunzip>) are active.

如果指令 [gzip](#gzip)、[gzip\_static](<067 [01.01.03 http] 模組 ngx_http_gzip_static_module.md#gzip_static>) 或 [gunzip](<065 [01.01.03 http] 模組 ngx_http_gunzip_module.md#gunzip>) 處於活動狀態，則啟用或停用插入「Vary: Accept-Encoding」回應標頭欄位。

#### Embedded Variables｜嵌入變數

`$gzip_ratio`

achieved compression ratio, computed as the ratio between the original and compressed response sizes.

達到的壓縮比，計算為原始響應大小和壓縮響應大小之間的比率。
