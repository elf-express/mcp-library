## Module ngx\_http\_index\_module｜模組 ngx\_http\_index\_module

|   |
| --- |
| [Example Configuration](#example)<br>[Directives](#directives)<br>     [index](#index)<br>[設定範例](#example)<br>[指令](#directives)<br>     [索引](#index) |

The `ngx_http_index_module` module processes requests ending with the slash character (‘`/`’). Such requests can also be processed by the [ngx\_http\_autoindex\_module](<053 [01.01.03 http] 模組 ngx_http_autoindex_module.md>) and [ngx\_http\_random\_index\_module](<087 [01.01.03 http] 模組 ngx_http_random_index_module.md>) modules.

`ngx_http_index_module`模組處理以斜槓字元（‘`/`’）結尾的請求。此類請求也可以由 [ngx\_http\_autoindex\_module](<053 [01.01.03 http] 模組 ngx_http_autoindex_module.md>) 和 [ngx\_http\_random\_index\_module](<087 [01.01.03 http] 模組 ngx_http_random_index_module.md>) 模組處理。

#### Example Configuration｜範例配置

> ```
> location / {
>
> 地點 / {
>     index index.$geo.html index.html;
>
>     索引index.$geo.htmlindex.html;
> }
> ```

Defines files that will be used as an index. The `*file*` name can contain variables. Files are checked in the specified order. The last element of the list can be a file with an absolute path. Example:

定義將用作索引的檔案。 `*file*` 名稱可以包含變數。按照指定的順序檢查文件。列表的最後一個元素可以是具有絕對路徑的檔案。範例：

> ```
> index index.$geo.html index.0.html /index.html;
>
> 索引index.$geo.html index.0.html /index.html;
> ```

It should be noted that using an index file causes an internal redirect, and the request can be processed in a different location. For example, with the following configuration:

需要注意的是，使用索引檔案會導致內部重定向，並且可以在不同的位置處理請求。例如，使用以下配置：

> ```
> location = / {
>
> 位置 = / {
>     index index.html;
>
>     索引index.html；
> }
> 
> location / {
>
> 地點 / {
>     ...
> }
> ```

a “`/`” request will actually be processed in the second location as “`/index.html`”.

「`/`」請求實際上將在第二個位置作為「`/index.html`」進行處理。
