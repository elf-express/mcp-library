## Module ngx\_http\_headers\_module｜模組 ngx\_http\_headers\_module

The `ngx_http_headers_module` module allows adding the “Expires”（過期） and “Cache-Control”（快取控制） header fields, and arbitrary fields, to a response header.

`ngx_http_headers_module` 模組允許將 “Expires”（過期） 和 “Cache-Control”（快取控制） 標頭字段以及任意字段添加到響應標頭。

#### Example Configuration｜範例配置

> ```
> expires    24h;
>
> 24小時後過期；
> expires    modified +24h;
>
> 修改後+24h 到期；
> expires    @24h;
>
> @24 小時到期；
> expires    0;
>
> 過期 0；
> expires    -1;
>
> 過期-1；
> expires    epoch;
>
> 過期紀元；
> expires    $expires;
>
> 過期$過期；
> add_header Cache-Control private;
>
> add_header 快取控制私有；
> ```

#### Directives｜指令

|   |   |

| Syntax:<br>語法： | ``**add_header** `*name*` `*value*` [`always`];``<br>``**add_header** `*名稱*` `*值*` [`始終`];`` |
| Default:<br>預設值： | — |
| Context:<br>上下文： | `http`, `server`, `location`, `if in location` |

Adds the specified field to a response header provided that the response code equals 200, 201 (1.3.10), 204, 206, 301, 302, 303, 304, 307 (1.1.16, 1.0.13), or 308 (1.13.0). Parameter value can contain variables.

將指定欄位加入回應標頭，前提是回應代碼等於 200、201 (1.3.10)、204、206、301、302、303、304、307 (1.1.16, 1.0.13) 或 308 (1.13.0)。參數值可以包含變數。

There could be several `add_header` directives. These directives are inherited from the previous configuration level if and only if there are no `add_header` directives defined on the current level. Inheritance rules can be redefined with the [add\_header\_inherit](#add_header_inherit) directive (1.29.3).

可能有多個 `add_header` 指令。當且僅噹噹前層級上沒有定義 `add_header` 指令時，這些指令才會從先前的設定等級繼承。可以使用 [add\_header\_inherit](#add_header_inherit) 指令 (1.29.3) 重新定義繼承規則。

If the `always` parameter is specified (1.7.5), the header field will be added regardless of the response code.

如果指定了`always`參數（1.7.5），則無論回應代碼為何，都會新增標頭欄位。

This directive appeared in version 1.29.3.

該指令出現在版本1.29.3。

Allows altering inheritance rules for the values specified in the [add\_header](#add_header) directives. By default, the [standard](#add_header_default_inherit) inheritance model is used.

允許變更 [add\_header](#add_header) 指令中指定的值的繼承規則。預設情況下，使用[標準](#add_header_default_inherit)繼承模型。

The `merge` parameter enables appending values from the previous level to the values defined at the current level.

`merge` 參數允許將前一層級的值附加到目前層級定義的值。

The `off` parameter cancels inheritance of the values from the previous configuration level.

`off` 參數取消繼承先前配置等級的值。

The inheritance rules themselves are inherited in a standard way. For example, `add_header_inherit merge;` specified at the top level will be inherited in all nested levels recursively unless redefined later.

繼承規則本身是以標準方式繼承的。例如，在頂層指定的`add_header_inherit merge;`將在所有嵌套層級中遞歸繼承，除非稍後重新定義。

There could be several `add_trailer` directives. These directives are inherited from the previous configuration level if and only if there are no `add_trailer` directives defined on the current level. Inheritance rules can be redefined with the [add\_trailer\_inherit](#add_trailer_inherit) directive (1.29.3).

可能有多個 `add_trailer` 指令。當且僅噹噹前層級上沒有定義 `add_trailer` 指令時，這些指令才會從先前的設定層級繼承。可以使用 [add\_trailer\_inherit](#add_trailer_inherit) 指令 (1.29.3) 重新定義繼承規則。

If the `always` parameter is specified the specified field will be added regardless of the response code.

如果指定了 `always` 參數，則無論回應代碼為何，都會新增指定欄位。

Enables or disables adding or modifying the “Expires”（過期） and “Cache-Control”（快取控制） response header fields provided that the response code equals 200, 201 (1.3.10), 204, 206, 301, 302, 303, 304, 307 (1.1.16, 1.0.13), or 308 (1.13.0). The parameter can be a positive or negative [time](<167 [01.01 文件] 設定檔計量單位.md>).

啟用或停用新增或修改 “Expires”（過期） 和 “Cache-Control”（快取控制） 回應頭字段，前提是回應代碼等於 200, 201 (1.3.10), 204, 206, 301, 302, 303, 304, 307 (1.1.16, 1.0.13），或 308（1.13.0）。參數可以是正數或負數[時間](<167 [01.01 文件] 設定檔計量單位.md>).

The time in the “Expires”（過期） field is computed as a sum of the current time and `*time*` specified in the directive. If the `modified` parameter is used (0.7.0, 0.6.32) then the time is computed as a sum of the file’s modification time and the `*time*` specified in the directive.

“Expires”（過期） 欄位中的時間計算為目前時間與指令中指定的 `*time*` 總和。如果使用`modified`參數（0.7.0, 0.6.32），則時間將計算為檔案的修改時間與指令中指定的`*time*`總和。

In addition, it is possible to specify a time of day using the “`@`” prefix (0.7.9, 0.6.34):

此外，也可以使用「`@`」前綴 (0.7.9, 0.6.34) 指定一天中的某個時間：

> ```
> expires @15h30m;
>
> 截止時間@15h30m；
> ```

The contents of the “Cache-Control”（快取控制） field depends on the sign of the specified time:

“Cache-Control”（快取控制）字段的內容取決於指定時間的符號：

-   time is negative — “Cache-Control: no-cache”.  
    時間為負數－「快取控制：無快取」。
-   time is positive or zero — “Cache-Control: max-age=`*t*`”, where `*t*` is a time specified in the directive, in seconds.  
    time 為正數或零 - “Cache-Control: max-age=`*t*`”，其中 `*t*` 是指令中指定的時間，以秒為單位。

The `epoch` parameter sets “Expires”（過期） to the value “`Thu, 01 Jan 1970 00:00:01 GMT`”, and “Cache-Control”（快取控制） to “`no-cache`”.

`epoch`參數將“Expires”（過期）設定為值“`Thu, 01 Jan 1970 00:00:01 GMT`”，將“Cache-Control”（快取控制）設定為“`no-cache`”。

The `max` parameter sets “Expires”（過期） to the value “`Thu, 31 Dec 2037 23:55:55 GMT`”, and “Cache-Control”（快取控制） to 10 years.

`max`參數將“Expires”（過期）設定為值“`Thu, 31 Dec 2037 23:55:55 GMT`”，將“Cache-Control”（快取控制）設定為10年。

The `off` parameter disables adding or modifying the “Expires”（過期） and “Cache-Control”（快取控制） response header fields.

`off` 參數禁止新增或修改 “Expires”（過期） 和 “Cache-Control”（快取控制） 響應頭字段。

The last parameter value can contain variables (1.7.9):

最後一個參數值可以包含變數（1.7.9）：

> ```
> map $sent_http_content_type $expires {
>
> 映射 $sent_http_content_type $expires {
>     default         off;
>
>     預設關閉；
>     application/pdf 42d;
>
>     應用程式/pdf 42d；
>     ~image/         max;
>
>     〜圖像/最大值；
> }
> 
> expires $expires;
>
> 過期$過期；
> ```
