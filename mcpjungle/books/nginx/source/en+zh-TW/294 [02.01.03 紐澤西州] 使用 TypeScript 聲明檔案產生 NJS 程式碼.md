## Создание кода njs при помощи файлов деклараций TypeScript｜使用 TypeScript 聲明檔案產生 NJS 程式碼

[TypeScript](https://www.typescriptlang.org/) — это типизированное подмножество JavaScript, которое компилируется в обычный JavaScript.

[TypeScript](https://www.typescriptlang.org/)是 JavaScript 的一個類型化子集，可以編譯成常規 JavaScript。

TypeScript поддерживает файлы деклараций, в которых содержится типизированная информация существующих библиотек JavaScript. С их помощью программы могут использовать значения в файлах также, если бы эти значения были статически типизированными сущностями TypeScript.

TypeScript 支援包含來自現有 JavaScript 程式庫的類型資訊的聲明檔案。這些檔案允許程式使用檔案中的值，就好像這些值是靜態類型的 TypeScript 實體一樣。

В njs файлы деклараций TypeScript предоставляются для [API](https://nginx.org/ru/docs/njs/reference.html) и могут использоваться при:

在 njs 中，提供了 TypeScript 聲明文件，適用於 [API](https://nginx.org/ru/docs/njs/reference.html) ，可在以下情況下使用：

-   автозаполнении и проверки API в редакторе  
    編輯器中API的自動填入與驗證
-   создании типобезопасного njs-кода.  
    建立類型安全的 NJS 程式碼。

#### Компиляция файлов деклараций TypeScript｜編譯 TypeScript 聲明文件

> ```bash
>
> 『`bash
> $ git clone https://github.com/nginx/njs
> $ cd njs && ./configure && make ts
> $ ls build/ts/
> njs_core.d.ts
> njs_shell.d.ts
> ngx_http_js_module.d.ts
> ngx_stream_js_module.d.ts
> ```

#### Проверка API и автозаполнение｜API驗證和自動填充

Файлы деклараций `*.d.ts` необходимо поместить в место, доступное редактору:

聲明文件`*.d.ts`必須放置在編輯人員可以存取的位置：

`test.js`:

> ```js
> /// <reference path="ngx_http_js_module.d.ts" />
> /**
>  * @param {NginxHTTPRequest} r
>  * */
> function content_handler(r) {
>
> 函數 content_handler(r) {
>     r.headersOut['content-type'] = 'text/plain';
>     r.return(200, "Hello"（你好）);
>
>     r.return(200, "Hello"（你好） );
> }
> ```

#### Создание типобезопасного njs кода｜建立類型安全的 NJS 程式碼

`test.ts`:

> ```js
> /// <reference path="ngx_http_js_module.d.ts" />
> function content_handler(r: NginxHTTPRequest) {
>     r.headersOut['content-type'] = 'text/plain';
>     r.return(200, "Hello from TypeScript");
> }
> ```

Установка TypeScript:

安裝 TypeScript：

> ```
> # npm install -g typescript
> ```

Компиляция TypeScript:

TypeScript 編譯：

> ```bash
>
> 『`bash
> $ tsc test.ts
> $ cat test.js
> ```

Созданный файл `test.js` может использоваться напрямую в njs.

產生的`test.js`檔案可以直接在njs中使用。
