## Module ngx\_http\_mirror\_module｜模組 ngx\_http\_mirror\_module

The `ngx_http_mirror_module` module (1.13.4) implements mirroring of an original request by creating background mirror subrequests. Responses to mirror subrequests are ignored.

`ngx_http_mirror_module`模組（ 1.13.4 ）透過建立後台鏡像子請求來實現原始請求的鏡像。對鏡像子請求的回應將被忽略。

#### Example Configuration｜範例配置

> ```
> location / {
>
> 地點 / {
>     mirror /mirror;
>
>     鏡子/鏡子；
>     proxy_pass http://backend;
> }
> 
> location = /mirror {
>     internal;
>
>     內部的;
>     proxy_pass http://test_backend$request_uri;
> }
> ```

Sets the URI to which an original request will be mirrored. Several mirrors can be specified on the same configuration level.

設定要將原始請求鏡像到的URI 。可以在相同配置層級指定多個鏡像。

<table>
<tr><th>Syntax:<br>語法：</th><td><code><strong>mirror_request_body</strong> <code>on</code> | <code>off</code>;</code></td></tr>
<tr><th>Default:<br>預設值：</th><td>mirror_request_body on;<br>啟用 mirror_request_body;</td></tr>
<tr><th>Context:<br>上下文：</th><td><code>http</code>, <code>server<br>伺服器</code>, <code>location<br>位置</code></td></tr>
</table>

Indicates whether the client request body is mirrored. When enabled, the client request body will be read prior to creating mirror subrequests. In this case, unbuffered client request body proxying set by the [proxy\_request\_buffering](<085 [01.01.03 http] 模組 ngx_http_proxy_module.md#proxy_request_buffering>), [fastcgi\_request\_buffering](<060 [01.01.03 http] 模組 ngx_http_fastcgi_module.md#fastcgi_request_buffering>), [scgi\_request\_buffering](<091 [01.01.03 http] 模組 ngx_http_scgi_module.md#scgi_request_buffering>), and [uwsgi\_request\_buffering](<107 [01.01.03 http] 模組 ngx_http_uwsgi_module.md#uwsgi_request_buffering>) directives will be disabled.

指示是否鏡像客戶端請求體。啟用後，將在建立鏡像子請求之前讀取客戶端請求體。在這種情況下，由 [proxy\_request\_buffering](<085 [01.01.03 http] 模組 ngx_http_proxy_module.md#proxy_request_buffering>) 、[fastcgi\_request\_buffering](<060 [01.01.03 http] 模組 ngx_http_fastcgi_module.md#fastcgi_request_buffering>) 、[scgi\_request\_buffering](<091 [01.01.03 http] 模組 ngx_http_scgi_module.md#scgi_request_buffering>)和 [uwsgi\_refin\ (https://nginx.org/en/docs/http/ngx_http_uwsgi_module.html#uwsgi_request_buffering) 。

> ```
> location / {
>
> 地點 / {
>     mirror /mirror;
>
>     鏡子/鏡子；
>     mirror_request_body off;
>
>     鏡像請求體關閉；
>     proxy_pass http://backend;
> }
> 
> location = /mirror {
>     internal;
>
>     內部的;
>     proxy_pass http://log_backend;
>     proxy_pass_request_body off;
>
>     proxy_pass_request_body 關閉；
>     proxy_set_header Content-Length "";
>     proxy_set_header X-Original-URI $request_uri;
>
>     proxy_set_header X-Original- URI $request_uri;
> }
> ```
