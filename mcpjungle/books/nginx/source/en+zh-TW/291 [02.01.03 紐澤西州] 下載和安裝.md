#### Установка пакета Linux｜安裝 Linux 軟體包

Для установки модулей njs на Linux могут быть использованы [пакеты](<327 [02 ru] 適用於 Linux 的 nginx 軟體包.md#dynmodules>):

要在 Linux 上安裝 njs 模組，可以使用 [packages](<327 [02 ru] 適用於 Linux 的 nginx 軟體包.md#dynmodules>) ：

-   `nginx-module-njs` — [динамические](<285 [02.01 文件] 基本功能.md#load_module>) модули njs  
    `nginx-module-njs` — [動態](<285 [02.01 文件] 基本功能.md#load_module>) njs 模組
-   `nginx-module-njs-dbg` — debug-символы для пакета `nginx-module-njs`  
    `nginx-module-njs-dbg` — `nginx-module-njs`包的調試符號

После установки пакетов необходимо загрузить динамические модули njs при помощи директивы [`load_module`](<285 [02.01 文件] 基本功能.md#load_module>):

安裝軟體套件後，您需要使用 [`load_module`](<285 [02.01 文件] 基本功能.md#load_module>)指令載入動態 njs 模組：

> ```
> load_module modules/ngx_http_js_module.so;
>
> 載入模組 modules/ngx_http_js_module.so;
> ```

или

或者

> ```
> load_module modules/ngx_stream_js_module.so;
>
> 載入模組 modules/ngx_stream_js_module.so;
> ```

#### Установка из исходных файлов｜從來源檔案安裝

[Репозиторий](https://github.com/nginx/njs) с исходным кодом njs можно клонировать следующей командой (необходим клиент [Git](https://git-scm.com/)):

可以使用以下指令複製包含 njs 原始碼的 [倉庫](https://github.com/nginx/njs) （需要 [Git](https://git-scm.com/)客戶端）：

> ```bash
>
> 『`bash
> git clone https://github.com/nginx/njs
> ```

Затем модули необходимо собрать из корневого каталога [nginx](<202 [02.01 文件] 從原始檔建構 nginx.md>) с помощью конфигурационного параметра `--add-module`:

然後需要使用組態參數`--add-module`從 [nginx 根目錄](<202 [02.01 文件] 從原始檔建構 nginx.md>)建置模組：

> ```
> ./configure --add-module=path-to-njs/nginx
> ```

Модули также можно собрать как [динамические](<285 [02.01 文件] 基本功能.md#load_module>):

模組也可以組裝成 [動態](<285 [02.01 文件] 基本功能.md#load_module>) :

> ```
> ./configure --add-dynamic-module=path-to-njs/nginx
> ```

#### Добавление поддержки QuickJS｜新增 QuickJS 支援

Убедитесь, что присутствует библиотека QuickJS:

請確保已安裝 QuickJS 庫：

> ```bash
>
> 『`bash
> git clone https://github.com/bellard/quickjs
> cd quickjs
> CFLAGS='-fPIC' make libquickjs.a
>
> CFLAGS ='-fPIC' make libquickjs.a
> ```

На этапе компиляции модулей также укажите пути include (`-I`) и library (`-L`) с помощью конфигурационных параметров `--with-cc-opt=` и `--with-ld-opt=`:

在模組編譯期間，也要使用`--with-cc-opt=`和`--with-ld-opt=`配置參數指定包含 ( `-I` ) 和函式庫 ( `-L` ) 路徑：

> ```
> ./configure --add-module=path-to-njs/nginx \
>     --with-cc-opt="-I path-to-quickjs" \
>     --with-ld-opt="-L path-to-quickjs"
>
>     --with-ld-opt="-L 路徑到 quickjs"
> ```

#### Сборка утилиты командной строки njs｜建立 njs 命令列實用程式

Чтобы собрать только [утилиту](<287 [02.01.03 紐澤西州] 命令列介面.md>) командной строки njs, необходимо запустить команды `./configure` и `make njs` из корневого каталога njs. После сборки утилита доступна как `./build/njs`.

若要僅建置 njs 命令列實用程式(https://nginx.org/ru/docs/njs/cli.html) ，請從 njs 根目錄執行命令`./configure`和`make njs` 。建置完成後，該實用程式將作為`./build/njs`提供。
