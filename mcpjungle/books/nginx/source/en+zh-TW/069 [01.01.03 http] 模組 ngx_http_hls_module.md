The `ngx_http_hls_module` module provides HTTP Live Streaming (HLS) server-side support for MP4 and MOV media files. Such files typically have the `.mp4`, `.m4v`, `.m4a`, `.mov`, or `.qt` filename extensions. The module supports H.264 video codec, AAC and MP3 audio codecs.

`ngx_http_hls_module` 模組為 MP4 和 MOV 媒體檔案提供HTTP 直播 (HLS) 伺服器端支援。此類檔案通常具有 `.mp4`, `.m4v`, `.m4a`, `.mov` 或 `.qt` 檔案副檔名。此模組支援 H.264 視訊編解碼器、AAC 和 MP3 音訊編解碼器。

For each media file, two URIs are supported:

對於每個媒體文件，支援兩個 URI：

-   A playlist URI with the “`.m3u8`” filename extension. The URI can accept optional arguments:  
    帶有“`.m3u8`”檔案副檔名的播放清單 URI。 URI 可以接受可選參數：
    -   “`start`” and “`end`” define playlist boundaries in seconds (1.9.0).  
        「`start`」和「`end`」以秒為單位定義播放清單邊界（1.9.0）。
    -   “`offset`” shifts an initial playback position to the time offset in seconds (1.9.0). A positive value sets a time offset from the beginning of the playlist. A negative value sets a time offset from the end of the last fragment in the playlist.  
        「`offset`」將初始播放位置移到以秒為單位的時間偏移（1.9.0）。正值設定距播放清單開頭的時間偏移。負值設定距播放清單中最後一個片段末端的時間偏移。
    -   “`len`” defines the fragment length in seconds.  
        「`len`」定義片段長度（以秒為單位）。
-   A fragment URI with the “`.ts`” filename extension. The URI can accept optional arguments:  
    帶有「`.ts`」檔案副檔名的片段URI。 URI 可以接受可選參數：
    -   “`start`” and “`end`” define fragment boundaries in seconds.  
        「`start`」和「`end`」以秒為單位定義片段邊界。

>
> 本模組作為我們的[商業訂閱](https://www.f5.com/products/nginx)的一部分提供。

#### Example Configuration｜範例配置

> ```
> location / {
>
> 地點 / {
>     hls;
>
>     HLS；
>     hls_fragment            5s;
>
>     hls_fragment 5s；
>     hls_buffers             10 10m;
>
>     hls_buffers 10 10m；
>     hls_mp4_buffer_size     1m;
>
>     hls_mp4_buffer_size 1m；
>     hls_mp4_max_buffer_size 5m;
>
>     hls_mp4_max_buffer_size 5m；
>     root /var/video/;
>
>     根/var/video/；
> }
> ```

With this configuration, the following URIs are supported for the “`/var/video/test.mp4`” file:

透過此配置，「`/var/video/test.mp4`」檔案支援以下 URI：

> ```
> http://hls.example.com/test.mp4.m3u8?offset=1.000&start=1.000&end=2.200
> http://hls.example.com/test.mp4.m3u8?len=8.000
> http://hls.example.com/test.mp4.ts?start=1.000&end=2.200
> ```

This directive appeared in version 1.5.12.

該指令出現在版本1.5.12。

Adds arguments from a playlist request to URIs of fragments. This may be useful for performing client authorization at the moment of requesting a fragment, or when protecting an HLS stream with the [ngx\_http\_secure\_link\_module](<092 [01.01.03 http] 模組 ngx_http_secure_link_module.md>) module.

將播放清單請求中的參數新增至片段的 URI。這對於在請求片段時執行客戶端授權，或使用 [ngx\_http\_secure\_link\_module](<092 [01.01.03 http] 模組 ngx_http_secure_link_module.md>) 模組保護 HLS 串流時可能很有用。

For example, if a client requests a playlist `http://example.com/hls/test.mp4.m3u8?a=1&b=2`, the arguments `a=1` and `b=2` will be added to URIs of fragments after the arguments `start` and `end`:

例如，如果客戶端請求播放清單`http://example.com/hls/test.mp4.m3u8?a=1&b=2`，則參數`a=1`和`b=2`將被加入到參數`start`和`end`之後的片段URI中：

> ```
> #EXTM3U
> #EXT-X-VERSION:3
> #EXT-X-TARGETDURATION:15
> #EXT-X-PLAYLIST-TYPE:VOD
> 
> #EXTINF:9.333,
> test.mp4.ts?start=0.000&end=9.333&a=1&b=2
> #EXTINF:7.167,
> test.mp4.ts?start=9.333&end=16.500&a=1&b=2
> #EXTINF:5.416,
> test.mp4.ts?start=16.500&end=21.916&a=1&b=2
> #EXTINF:5.500,
> test.mp4.ts?start=21.916&end=27.416&a=1&b=2
> #EXTINF:15.167,
> test.mp4.ts?start=27.416&end=42.583&a=1&b=2
> #EXTINF:9.626,
> test.mp4.ts?start=42.583&end=52.209&a=1&b=2
> 
> #EXT-X-ENDLIST
> ```

If an HLS stream is protected with the [ngx\_http\_secure\_link\_module](<092 [01.01.03 http] 模組 ngx_http_secure_link_module.md>) module, `$uri` should not be used in the [secure\_link\_md5](<092 [01.01.03 http] 模組 ngx_http_secure_link_module.md#secure_link_md5>) expression because this will cause errors when requesting the fragments. [Base URI](<078 [01.01.03 http] 模組 ngx_http_map_module.md#map>) should be used instead of `$uri` (`$hls_uri` in the example):

如果 HLS 流受 [ngx\_http\_secure\_link\_module](<092 [01.01.03 http] 模組 ngx_http_secure_link_module.md>) 模組保護，則 `$uri` 不應在 [secure\_link\_md5](<092 [01.01.03 http] 模組 ngx_http_secure_link_module.md#secure_link_md5>) 表達式中使用，因為這會在請求片段時導致錯誤。 [基礎URI應使用](<078 [01.01.03 http] 模組 ngx_http_map_module.md#map>)代替`$uri`（範例中為`$hls_uri`）：

> ```
> http {
>     ...
> 
>     map $uri $hls_uri {
>
>     地圖 $uri $hls_uri {
>         ~^(?<base_uri>.*).m3u8$ $base_uri;
>         ~^(?<base_uri>.*).ts$   $base_uri;
>
>         ~^(?<base_uri>.*).ts$ $base_uri;
>         default                 $uri;
>
>         預設$uri；
>     }
> 
>     server {
>
>     伺服器 {
>         ...
>

>

>             hls;
>
>             HLS；
>             hls_forward_args on;
>
>             hls_forward_args 開啟；
> 
>             alias /var/videos/;
>
>             別名 /var/videos/;
> 
>             secure_link $arg_md5,$arg_expires;
>             secure_link_md5 "$secure_link_expires$hls_uri$remote_addr secret";
