## Module ngx\_stream\_set\_module｜模組 ngx_stream_set_module

|   |
| --- |

The `ngx_stream_set_module` module (1.19.3) allows setting a value for a variable.

`ngx_stream_set_module`模組（ 1.19.3 ）允許設定變數的值。

#### Example Configuration｜範例配置

> ```
> server {
>
> 伺服器 {
>     listen 12345;
>
>     聽 12345；
>     set    $true 1;
>
>     設定 $true 為 1；
> }
> ```

#### Directives｜指令

|   |   |
| --- | --- |
| Syntax:<br>語法： | ``**set** `*$variable*` `*value*`;``<br>` `**set** ` *$變數* ` ` *值* `;` ` |
| Default:<br>預設值： | — |
| Context:<br>背景： | `server` |

Sets a `*value*` for the specified `*variable*`. The `*value*` can contain text, variables, and their combination.

為指定的`*variable*`設定`*value*`可以包含文字、 `*value*`及其組合。
