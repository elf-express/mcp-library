# Модуль ngx_mail_realip_module｜模組 ngx_mail_realip_module

> 章節：[ru](<000 目錄.md#c-9>) › [docs｜文件](<000 目錄.md#c-10>) › [mail｜郵件](<000 目錄.md#c-12>)

## Модуль ngx\_mail\_realip\_module｜模組 ngx\_mail\_realip\_module

|   |
| --- |
| [Пример конфигурации](#example)<br>[Директивы](#directives)<br>     [set\_real\_ip\_from](#set_real_ip_from)<br>[設定範例](#example)<br> [指令](#directives)<br> [set\_real\_ip\_from](#set_real_ip_from) |

Модуль `ngx_mail_realip_module` позволяет менять адрес и порт клиента на переданные в заголовке протокола PROXY (1.19.8). Протокол PROXY должен быть предварительно включён при помощи установки параметра [proxy\_protocol](<278 [02.01.02 郵件] 模組 ngx_mail_core_module.md#proxy_protocol>) в директиве `listen`.

`ngx_mail_realip_module`模組可讓您將客戶端的位址和連接埠變更為PROXY ( 1.19.8 ) 協定頭中指定的位址和連接埠。必須透過在`listen`指令中設定 [proxy\_protocol](<278 [02.01.02 郵件] 模組 ngx_mail_core_module.md#proxy_protocol>)參數來啟用PROXY協定。

#### Пример конфигурации｜配置範例

> ```
> listen 110 proxy_protocol;
>
> 監聽 110 代理協議；
> 
> set_real_ip_from  192.168.1.0/24;
>
> set_real_ip_from 192.168.1.0/24 ;
> set_real_ip_from  192.168.2.1;
>
> set_real_ip_from 192.168.2.1 ;
> set_real_ip_from  2001:0db8::/32;
>
> set_real_ip_from 2001:0db8::/32 ;
> ```

#### Директивы｜指令

|   |   |
| --- | --- |
| Синтаксис:<br>語法： | ``**set_real_ip_from** `*адрес*` \| `*CIDR*` \| `unix:`;``<br>` `**set_real_ip_from** ` *地址* ` \| ` * CIDR * ` \| ` unix: `;` ` |
| Умолчание:<br>預設值： | — |
| Контекст:<br>背景： | `mail`, `server` |

Задаёт доверенные адреса, которые передают верный адрес для замены. Если указано специальное значение `unix:`, доверенными будут считаться все UNIX-сокеты.

指定能夠傳遞正確替換地址的受信任位址。如果指定特殊值`unix:` ，則所有UNIX套接字都將被信任。
