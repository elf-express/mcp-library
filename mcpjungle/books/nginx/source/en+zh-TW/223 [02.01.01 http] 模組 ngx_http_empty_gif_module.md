Модуль `ngx_http_empty_gif_module` выдаёт однопиксельный прозрачный GIF.

`ngx_http_empty_gif_module`模組產生一個單像素透明的GIF 。

#### Пример конфигурации｜配置範例

> ```
> location = /_.gif {
>     empty_gif;
>
>     空的gif；
> }
> ```

#### Директивы｜指令

|   |   |
| --- | --- |
| Синтаксис:<br>文法： | `**empty_gif**;` |
| Умолчание:<br>預設值： | — |
| Контекст:<br>背景： | `location` |

Разрешает в содержащем location выдавать однопиксельный прозрачный GIF.

允許包含位置發出一個像素透明的GIF 。
