Модуль `ngx_http_browser_module` создаёт переменные, значения которых зависят от значения поля “User-Agent”（使用者代理） в заголовке запроса:

`ngx_http_browser_module`模組建立變量，這些變數的值取決於請求標頭中“User-Agent”（使用者代理）欄位的值：

`$modern_browser`

равна значению, заданному директивой [modern\_browser\_value](#modern_browser_value), если браузер опознан как современный;

如果瀏覽器被辨識為現代瀏覽器，則等於 [modern\_browser\_value](#modern_browser_value)指令指定的值；

`$ancient_browser`

равна значению, заданному директивой [ancient\_browser\_value](#ancient_browser_value), если браузер опознан как устаревший;

如果瀏覽器被辨識為過時，則等於 [ancient\_browser\_value](#ancient_browser_value)指令指定的值；

`$msie`

равна “1”, если браузер опознан как MSIE любой версии.

如果瀏覽器被辨識為任何版本的MSIE ，則等於「1」。

#### Пример конфигурации｜配置範例

Выбор индексного файла:

選擇索引檔：

> ```
> modern_browser_value "modern.";
> 
> modern_browser msie      5.5;
>
> 現代瀏覽器 msie 5.5 ;
> modern_browser gecko     1.0.0;
>
> modern_browser gecko 1.0.0 ;
> modern_browser opera     9.0;
>
> modern_browser opera 9.0 ;
> modern_browser safari    413;
>
> modern_browser Safari 413;
> modern_browser konqueror 3.0;
>
> modern_browser konqueror 3.0 ;
> 
> index index.${modern_browser}html index.html;
> ```

Перенаправление для старых браузеров:

針對舊版瀏覽器的重定向：

> ```
> modern_browser msie      5.0;
>
> 現代_瀏覽器 msie 5.0 ;
> modern_browser gecko     0.9.1;
>
> modern_browser gecko 0.9.1 ;
> modern_browser opera     8.0;
>
> modern_browser opera 8.0 ;
> modern_browser safari    413;
>
> modern_browser Safari 413;
> modern_browser konqueror 3.0;
>
> modern_browser konqueror 3.0 ;
> 
> modern_browser unlisted;
>
> modern_browser 未列出；
> 
> ancient_browser Links Lynx netscape4;
> 
> if ($ancient_browser) {
>
> 如果 ($ancient_browser) {
>     rewrite ^ /ancient.html;
>
>     重寫 ^ /ancient.html;
> }
> ```

#### Директивы｜指令

|   |   |
| --- | --- |
| Синтаксис:<br>語法： | ``**ancient_browser** `*строка*` ...;``<br>` `**ancient_browser** ` *字串* ` ...;` ` |
| Умолчание:<br>預設值： | — |
| Контекст:<br>背景： | `http`, `server`, `location` |

Задаёт подстроки, при нахождении которых в поле “User-Agent”（使用者代理） заголовка запроса браузер считается устаревшим. Специальная строка “`netscape4`” соответствует регулярному выражению “`^Mozilla/[1-4]`”.

指定在“User-Agent”（使用者代理）請求頭字段中找到的子字串，會導致瀏覽器認為該請求已過期。特殊字串“ `netscape4` ”匹配正規表示式“ `^Mozilla/[1-4]` ”。

Задаёт значение для переменных `$ancient_browser`.

設定變數`$ancient_browser`的值。

|   |   |
| --- | --- |
| Синтаксис:<br>語法： | ``**modern_browser** `*браузер*` `*версия*`;``<br>``**modern_browser** `unlisted`;``<br>` `**modern_browser** ` *瀏覽器* ` ` *版本* `;``<br>``**modern_browser** `未列出`;` ` |
| Умолчание:<br>預設值： | — |
| Контекст:<br>背景： | `http`, `server`, `location` |

Задаёт версию браузера, начиная с которой он считается современным. В качестве браузера можно задать `msie`, `gecko` (браузеры, созданные на основе Mozilla), `opera`, `safari` или `konqueror`.

指定被視為現代瀏覽器的起始版本。您可以將瀏覽器設定為`msie`, `gecko` （基於 Mozilla 的瀏覽器）、 `opera`, `safari`或`konqueror` 。

Версии можно задать в форматах X, X.X, X.X.X или X.X.X.X. Максимальные значения для каждого из форматов соответственно — 4000, 4000.99, 4000.99.99 и 4000.99.99.99.

版本可以採用 X、XX、XXX 或 XXXX 格式指定。每種格式的最大值分別為 4000、 4000.99, 4000.99.99和4000.99.99.99 。

Специальное значение `unlisted` указывает считать современным браузер, не описанный директивами `modern_browser` и [ancient\_browser](#ancient_browser). В противном случае неперечисленный браузер будет считаться устаревшим. Если в заголовке запроса нет поля “User-Agent”（使用者代理）, то браузер считается неперечисленным.

特殊值`unlisted`表示未被`modern_browser`和[ancient\_browser](#ancient_browser)指令涵蓋的瀏覽器被視為現代瀏覽器。否則，未列出的瀏覽器被視為過時瀏覽器。如果“User-Agent”（使用者代理）請求頭字段缺失，則該瀏覽器被視為未列出。
