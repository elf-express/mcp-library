## Совместимость｜相容性

Эта страница описывает JavaScript-функциональность, предоставляемую njs:

本頁面介紹了 njs 提供的 JavaScript 功能：

-   объекты njs и nginx, встроенные модули и объект `Buffer`, доступные в обоих движках, [QuickJS](<289 [02.01.03 紐澤西州] JavaScript 引擎.md#quickjs_engine>) и [njs](<289 [02.01.03 紐澤西州] JavaScript 引擎.md#njs_engine>);  
    njs 和 nginx 物件、內建模組以及`Buffer`對象，在兩個引擎中均可用，[QuickJS](<289 [02.01.03 紐澤西州] JavaScript 引擎.md#quickjs_engine>)和 [njs](<289 [02.01.03 紐澤西州] JavaScript 引擎.md#njs_engine>) ;
-   возможности языка ECMAScript, реализованные в движке [njs](<289 [02.01.03 紐澤西州] JavaScript 引擎.md#njs_engine>).  
    [njs](<289 [02.01.03 紐澤西州] JavaScript 引擎.md#njs_engine>)引擎中實作了 ECMAScript 語言功能。

Описания методов и свойств, доступных только в njs и не соответствующих стандарту ECMAScript, доступны в [справочнике](https://nginx.org/ru/docs/njs/reference.html). Описания стандартных объектов и методов ECMAScript доступны в [спецификации ECMAScript](http://www.ecma-international.org/ecma-262/).

僅在 njs 中可用且不符合 ECMAScript 標準的方法和屬性的描述可在 [參考](https://nginx.org/ru/docs/njs/reference.html)中找到。標準 ECMAScript 物件和方法的描述可在 [ECMAScript 規範](http://www.ecma-international.org/ecma-262/)中找到。

#### Совместимость с ECMAScript (движок njs)｜ECMAScript 相容性（NJS 引擎）

> Перечисленные ниже возможности языка ECMAScript относятся к движку [njs](<289 [02.01.03 紐澤西州] JavaScript 引擎.md#njs_engine>), объявленному устаревшим начиная с [1.0.0](https://nginx.org/ru/docs/njs/changes.html#njs1.0.0). Движок [QuickJS](<289 [02.01.03 紐澤西州] JavaScript 引擎.md#quickjs_engine>) поддерживает ES2023; для нового кода следует использовать движок QuickJS.
>
> 以下 ECMAScript 語言特性僅適用於 [njs](<289 [02.01.03 紐澤西州] JavaScript 引擎.md#njs_engine>)引擎，該引擎已從 [1.0.0](https://nginx.org/ru/docs/njs/changes.html#njs1.0.0)版本開始棄用。 [QuickJS](<289 [02.01.03 紐澤西州] JavaScript 引擎.md#quickjs_engine>)引擎支援ES2023 ；新程式碼應使用 QuickJS 引擎。

Движок njs реализован в соответствии с [ECMAScript 5.1](http://www.ecma-international.org/ecma-262/5.1/) (строгий режим) c некоторыми расширениями [ECMAScript 6](http://www.ecma-international.org/ecma-262/6.0/) и позже. Совместимость находится в стадии развития.

njs引擎是根據[ECMAScript 5.1](http://www.ecma-international.org/ecma-262/5.1/) （嚴格模式）實現的，並對[ECMAScript 6](http://www.ecma-international.org/ecma-262/6.0/)及更高版本進行了一些擴展。相容性工作仍在進行中。
