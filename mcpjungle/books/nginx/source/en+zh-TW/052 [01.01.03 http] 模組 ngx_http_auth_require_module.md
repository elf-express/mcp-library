## Module ngx\_http\_auth\_require\_module｜模組 ngx_http_auth_require_module

|   |
| --- |
| [Example Configuration](#example)<br>[Directives](#directives)<br>     [auth\_require](#auth_require)<br>[範例設定](#example)<br> [指令](#directives)<br> [auth\_require](#auth_require) |

The `ngx_http_auth_require_module` module (1.29.0) implements variable-based client authorization. It can also use variables provided by other access modules such as [ngx\_http\_auth\_request\_module](<051 [01.01.03 http] 模組 ngx_http_auth_request_module.md>) or [ngx\_http\_auth\_oidc\_module](<051 [01.01.03 http] 模組 ngx_http_auth_request_module.md>).

`ngx_http_auth_require_module`模組 ( 1.29.0 ) 實作了基於變數的客戶端授權。它也可以使用其他存取模組提供的變量，例如 [ngx\_http\_auth\_request\_module](<051 [01.01.03 http] 模組 ngx_http_auth_request_module.md>)或 [ngx\_http\_auth\_oidc\_module](<051 [01.01.03 http] 模組 ngx_http_auth_request_module.md>) 。

#### Example Configuration｜範例配置

> ```
> http {
>
> http{
>     oidc_provider my_idp {
>         ...
>     }
> 
>     map $oidc_claim_role $admin_role {
>
>     映射 $oidc_claim_role $admin_role {
>         "admin" 1;
>
>         “管理員” 1；
>     }
> 
>     server {
>
>     伺服器{
>         auth_oidc my_idp;
> 
>         location /admin {
>             auth_require $admin_role;
>         }
>     }
> }
> ```

Enables authorization based on the specified variables. The access is allowed only if all the variables are not empty and are not equal to “0”. Otherwise, the module returns `403` code, which can be overridden by the `error` parameter. Several `auth_require` directives can be used to return different error codes.

啟用基於指定變數的授權。僅當所有變數均不為空且不等於“0”時，才允許存取。否則，模組將傳回`403`程式碼，該程式碼可透過`error`參數進行覆蓋。可以使用多個`auth_require`指令來傳回不同的錯誤碼。
