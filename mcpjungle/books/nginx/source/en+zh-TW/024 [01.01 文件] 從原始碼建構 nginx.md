## Building nginx from Sources｜從原始碼建構 nginx

The build is configured using the `configure` command. It defines various aspects of the system, including the methods nginx is allowed to use for connection processing. At the end it creates a `Makefile`.

使用 `configure` 指令配置建置。它定義了系統的各個方面，包括允許 nginx 用於連接處理的方法。最後它創建了一個`Makefile`。

The `configure` command supports the following parameters:

`configure`指令支援以下參數：

`--help`

prints a help message.

列印幫助訊息。

`` --prefix=`*path*` ``

`` --prefix=`*路徑*` ``

defines a directory that will keep server files. This same directory will also be used for all relative paths set by `configure` (except for paths to libraries sources) and in the `nginx.conf` configuration file. It is set to the `/usr/local/nginx` directory by default.

定義一個保存伺服器檔案的目錄。該目錄也將用於 `configure` 設定的所有相對路徑（庫來源的路徑除外）和 `nginx.conf` 設定檔中。預設為`/usr/local/nginx`目錄。

`` --sbin-path=`*path*` ``

`` --sbin-path=`*路徑*` ``

sets the name of an nginx executable file. This name is used only during installation. By default the file is named `` `*prefix*`/sbin/nginx ``.

設定 nginx 可執行檔的名稱。此名稱僅在安裝期間使用。預設情況下，檔案名稱為「` `*prefix*`/sbin/nginx `」。

`` --modules-path=`*path*` ``

`` --modules-path=`*路徑*` ``

defines a directory where nginx dynamic modules will be installed. By default the `` `*prefix*`/modules `` directory is used.

定義將安裝 nginx 動態模組的目錄。預設使用 `` `*prefix*`/modules `` 目錄。

`` --conf-path=`*path*` ``

`` --conf-path=`*路徑*` ``

sets the name of an `nginx.conf` configuration file. If needs be, nginx can always be started with a different configuration file, by specifying it in the command-line parameter `` -c `*file*` ``. By default the file is named `` `*prefix*`/conf/nginx.conf ``.

設定`nginx.conf`設定檔的名稱。如果需要，nginx 始終可以透過在命令列參數 `` -c `*file*` ``. By default the file is named `` `*prefix*`/conf/nginx.conf `` 中指定不同的設定檔來啟動。

`` --error-log-path=`*path*` ``

`` --error-log-path=`*路徑*` ``

sets the name of the primary error, warnings, and diagnostic file. After installation, the file name can always be changed in the `nginx.conf` configuration file using the [error\_log](<125 [01.01 文件] 核心功能.md#error_log>) directive. By default the file is named `` `*prefix*`/logs/error.log ``.

設定主要錯誤、警告和診斷文件的名稱。安裝後，始終可以使用 [error\_log](<125 [01.01 文件] 核心功能.md#error_log>) 指令在 `nginx.conf` 設定檔中變更檔案名稱。預設情況下，檔案名稱為「` `*prefix*`/logs/error.log `」。

`` --pid-path=`*path*` ``

`` --pid-path=`*路徑*` ``

sets the name of an `nginx.pid` file that will store the process ID of the main process. After installation, the file name can always be changed in the `nginx.conf` configuration file using the [pid](<125 [01.01 文件] 核心功能.md#pid>) directive. By default the file is named `` `*prefix*`/logs/nginx.pid ``.

設定儲存主進程的進程ID的`nginx.pid`檔案的名稱。安裝後，始終可以使用 [pid](<125 [01.01 文件] 核心功能.md#pid>) 指令在 `nginx.conf` 設定檔中變更檔案名稱。預設情況下，檔案名稱為「` `*prefix*`/logs/nginx.pid `」。

`` --lock-path=`*path*` ``

`` --lock-path=`*路徑*` ``

sets a prefix for the names of lock files. After installation, the value can always be changed in the `nginx.conf` configuration file using the [lock\_file](<125 [01.01 文件] 核心功能.md#lock_file>) directive. By default the value is `` `*prefix*`/logs/nginx.lock ``.

設定鎖定檔案名稱的前綴。安裝後，始終可以使用 [lock\_file](<125 [01.01 文件] 核心功能.md#lock_file>) 指令在 `nginx.conf` 設定檔中變更該值。預設值為`` `*前綴*`/logs/nginx.lock ``。

`` --user=`*name*` ``

`` --user=`*名字*` ``

sets the name of an unprivileged user whose credentials will be used by worker processes. After installation, the name can always be changed in the `nginx.conf` configuration file using the [user](<125 [01.01 文件] 核心功能.md#user>) directive. The default user name is nobody.

設定非特權使用者的名稱，其憑證將由工作進程使用。安裝後，始終可以使用 [user](<125 [01.01 文件] 核心功能.md#user>) 指令在 `nginx.conf` 設定檔中變更名稱。預設使用者名稱是nobody。

`` --group=`*name*` ``

`` --group=`*名字*` ``

sets the name of a group whose credentials will be used by worker processes. After installation, the name can always be changed in the `nginx.conf` configuration file using the [user](<125 [01.01 文件] 核心功能.md#user>) directive. By default, a group name is set to the name of an unprivileged user.

設定工作進程將使用其憑證的群組的名稱。安裝後，始終可以使用 [user](<125 [01.01 文件] 核心功能.md#user>) 指令在 `nginx.conf` 設定檔中變更名稱。預設情況下，群組名稱設定為非特權使用者的名稱。

`` --build=`*name*` ``

`` --build=`*名字*` ``

sets an optional nginx build name.

設定可選的 nginx 建置名稱。

`` --builddir=`*path*` ``

`` --builddir=`*路徑*` ``

sets a build directory.

設定建置目錄。

`--with-select_module`  
`--without-select_module`

enables or disables building a module that allows the server to work with the `select()` method. This module is built automatically if the platform does not appear to support more appropriate methods such as kqueue, epoll, or /dev/poll.

啟用或停用建置允許伺服器使用`select()`方法的模組。如果平台似乎不支援更合適的方法（例如 kqueue、epoll 或 /dev/poll），則會自動建立此模組。

`--with-poll_module`

enables or disables building a module that allows the server to work with the `poll()` method. This module is built automatically if the platform does not appear to support more appropriate methods such as kqueue, epoll, or /dev/poll.

啟用或停用建置允許伺服器使用`poll()`方法的模組。如果平台似乎不支援更合適的方法（例如 kqueue、epoll 或 /dev/poll），則會自動建立此模組。

enables the use of [nginx control REST API](https://docs.nginx.com/nginx/admin-guide/basic-functionality/runtime-control#control-api) (1.31.5), see also the [`-l`](<166 [01.01 文件] 命令列參數.md#l>) command-line parameter.

啟用 [nginx 控制REST API](https://docs.nginx.com/nginx/admin-guide/basic-functionality/runtime-control#control-api) (1.31.5)，另請參閱 [`-l`](<166 [01.01 文件] 命令列參數.md#l>) 命令列參數。

`--with-threads`

enables the use of [thread pools](<125 [01.01 文件] 核心功能.md#thread_pool>).

允許使用[線程池](<125 [01.01 文件] 核心功能.md#thread_pool>)。

`--with-file-aio`

enables the use of [asynchronous file I/O](<056 [01.01.03 http] 模組 ngx_http_core_module.md#aio>) (AIO) on FreeBSD and Linux.

允許在 FreeBSD 和 Linux 上使用 [非同步檔案 I/O](<056 [01.01.03 http] 模組 ngx_http_core_module.md#aio>) (AIO)。

`--with-http_ssl_module`

enables building a module that adds the [HTTPS protocol support](<098 [01.01.03 http] 模組 ngx_http_ssl_module.md>) to an HTTP server. This module is not built by default. The OpenSSL library is required to build and run this module.

允許建構一個模組，將[HTTPS協定支援](<098 [01.01.03 http] 模組 ngx_http_ssl_module.md>)加入到HTTP伺服器。預設情況下不建置此模組。建置和運行此模組需要 OpenSSL 庫。

`--with-http_v2_module`

enables building a module that provides support for [HTTP/2](<108 [01.01.03 http] 模組 ngx_http_v2_module.md>). This module is not built by default.

允許建構支援 [HTTP/2](<108 [01.01.03 http] 模組 ngx_http_v2_module.md>) 的模組。預設情況下不建置此模組。

`--with-http_v3_module`

enables building a module that provides support for [HTTP/3](<109 [01.01.03 http] 模組 ngx_http_v3_module.md>). This module is not built by default. The OpenSSL library that provides HTTP/3 support is required to build and run this module.

允許建構支援 [HTTP/3](<109 [01.01.03 http] 模組 ngx_http_v3_module.md>) 的模組。預設情況下不建置此模組。建置和運行此模組需要提供 HTTP/3 支援的 OpenSSL 庫。

`--with-http_realip_module`

enables building the [ngx\_http\_realip\_module](<088 [01.01.03 http] 模組 ngx_http_realip_module.md>) module that changes the client address to the address sent in the specified header field. This module is not built by default.

允許建置 [ngx\_http\_realip\_module](<088 [01.01.03 http] 模組 ngx_http_realip_module.md>) 模組，將客戶端位址變更為在指定標頭欄位中傳送的位址。預設情況下不建置此模組。

允許建構 [ngx\_http\_addition\_module](<047 [01.01.03 http] 模組 ngx_http_addition_module.md>) 模組，在回應之前和之後加入文字。預設情況下不建置此模組。

`--with-http_xslt_module`

This module is not built by default. The [libxml2](http://xmlsoft.org/) and [libxslt](http://xmlsoft.org/XSLT/) libraries are required to build and run this module.

允許建構 [ngx\_http\_xslt\_module](<110 [01.01.03 http] 模組 ngx_http_xslt_module.md>) 模組，該模組使用一個或多個 XSLT 樣式表轉換 XML 回應。預設情況下不建置此模組。建置和執行此模組需要 [libxml2](http://xmlsoft.org/) 和 [libxslt](http://xmlsoft.org/XSLT/) 函式庫。

允許建構 [ngx\_http\_image\_filter\_module](<070 [01.01.03 http] 模組 ngx_http_image_filter_module.md>) 模組，該模組可將影像轉換為 JPEG, GIF, PNG 和 WebP 格式。預設情況下不建置此模組。

`--with-http_geoip_module`

enables building the [ngx\_http\_geoip\_module](<063 [01.01.03 http] 模組 ngx_http_geoip_module.md>) module that creates variables depending on the client IP address and the precompiled [MaxMind](http://www.maxmind.com/) databases. This module is not built by default.

允許建置 [ngx\_http\_geoip\_module](<063 [01.01.03 http] 模組 ngx_http_geoip_module.md>) 模組，該模組根據客戶端 IP 位址和預先編譯的 [MaxMind](http://www.maxmind.com/) 資料庫建立變數。預設情況下不建置此模組。

允許建構 [ngx\_http\_sub\_module](<101 [01.01.03 http] 模組 ngx_http_sub_module.md>) 模組，該模組透過用另一個指定字串取代一個指定字串來修改回應。預設情況下不建置此模組。

允許建置 [ngx\_http\_dav\_module](<057 [01.01.03 http] 模組 ngx_http_dav_module.md>) 模組，該模組透過 WebDAV 協定提供檔案管理自動化。預設情況下不建置此模組。

允許建置 [ngx\_http\_flv\_module](<061 [01.01.03 http] 模組 ngx_http_flv_module.md>) 模組，為 Flash 視訊 (FLV) 檔案提供偽流伺服器端支援。預設情況下不建置此模組。

`--with-http_mp4_module`

允許建置 [ngx\_google\_perftools\_module](<126 [01.01 文件] 模組 ngx_google_perftools_module.md>) 模組，該模組允許使用 [Google Performance Tools](https://github.com/gperftools/gperftools) 對 nginx 工作流程進行分析。此模組適用於 nginx 開發人員，預設不建置。

`` --with-cc-opt=`*parameters*` ``

`` --with-cc-opt=`*参数*` ``

sets additional parameters that will be added to the CFLAGS variable. When using the system PCRE library under FreeBSD, `--with-cc-opt="-I /usr/local/include"` should be specified. If the number of files supported by `select()` needs to be increased it can also be specified here such as this: `--with-cc-opt="-D FD_SETSIZE=2048"`.

設定將會加入 CFLAGS 變數的附加參數。在FreeBSD下使用系統PCRE函式庫時，需指定`--with-cc-opt="-I /usr/local/include"`。如果需要增加`select()`支援的檔案數量，也可以在這裡指定，例如：`--with-cc-opt="-D FD_SETSIZE=2048"`。

sets additional parameters that will be used during linking. When using the system PCRE library under FreeBSD, `--with-ld-opt="-L /usr/local/lib"` should be specified.

设置链接期间将使用的附加参数。在FreeBSD下使用系統PCRE函式庫時，需指定`--with-ld-opt="-L /usr/local/lib"`。

設定PCRE庫的來源路徑。庫發行版需從 [PCRE](http://www.pcre.org/) 網站下載並解壓縮。剩下的由nginx的`./configure`和`make`完成。 [location](<056 [01.01.03 http] 模組 ngx_http_core_module.md#location>) 指令和 [ngx\_http\_rewrite\_module](<090 [01.01.03 http] 模組 ngx_http_rewrite_module.md>) 模組中的正規表示式支援需要該函式庫。
