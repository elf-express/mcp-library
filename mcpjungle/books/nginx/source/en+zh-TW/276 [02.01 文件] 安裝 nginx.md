# Установка nginx｜安裝 nginx

> 章節：[ru](<000 目錄.md#c-9>) › [docs｜文件](<000 目錄.md#c-10>)

## Установка nginx｜安裝 nginx

nginx устанавливается по-разному в зависимости от операционной системы.

依作業系統不同，nginx 的安裝方式也不同。

#### Установка на Linux｜Linux 系統安裝

Для установки nginx на Linux могут быть использованы [пакеты](<327 [02 ru] 適用於 Linux 的 nginx 軟體包.md>) с nginx.org.

要在 Linux 上安裝 nginx，可以使用來自 nginx.org 的(https://nginx.org/ru/linux_packages.html)軟體包。

#### Установка на FreeBSD｜安裝 FreeBSD

На FreeBSD можно установить nginx либо из [пакетов](https://docs.freebsd.org/en/books/handbook/ports/#pkgng-intro), либо с помощью системы [портов](https://docs.freebsd.org/en/books/handbook/ports/#ports-using). Система портов даёт большую гибкость, позволяя выбирать из широкого набора настроек. Порт скомпилирует nginx с выбранными опциями и установит.

在 FreeBSD 系統中，您可以透過 [packages](https://docs.freebsd.org/en/books/handbook/ports/#pkgng-intro)或使用 [ports 系統](https://docs.freebsd.org/en/books/handbook/ports/#ports-using)安裝 nginx。 ports 系統提供了更大的靈活性，讓您可以選擇各種設定。 ports 會使用您選擇的選項編譯 nginx 並進行安裝。

#### Сборка из исходных файлов｜從來源檔案構建

Если необходима специфическая функциональность, недоступная из пакетов или портов, можно скомпилировать nginx из исходного кода. Будучи наиболее гибким, этот подход может быть сложным для начинающего. [Сборка nginx из исходных файлов](<202 [02.01 文件] 從原始檔建構 nginx.md>) освещает этот вопрос более подробно.

如果您需要某些軟體包或連接埠中沒有的特定功能，您可以從原始程式碼編譯 nginx。雖然這種方法最靈活，但對初學者來說可能具有挑戰性。 [從原始碼建構 nginx](<202 [02.01 文件] 從原始檔建構 nginx.md>)對此主題進行了更詳細的介紹。
