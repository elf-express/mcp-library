## Модуль ngx\_http\_random\_index\_module｜模組 ngx\_http\_random\_index\_module

|   |
| --- |
| [Пример конфигурации](#example)<br>[Директивы](#directives)<br>     [random\_index](#random_index)<br>[設定範例](#example)<br> [指令](#directives)<br> [隨機索引](#random_index) |

Модуль `ngx_http_random_index_module` обслуживает запросы, оканчивающиеся слэшом (‘`/`’), и выдаёт случайный файл в качестве индексного файла каталога. Модуль выполняется до модуля [ngx\_http\_index\_module](<236 [02.01.01 http] 模組 ngx_http_index_module.md>).

`ngx_http_random_index_module`模組處理以斜線 (' `/` ') 結尾的請求，並傳回一個隨機檔案作為目錄索引檔。此模組在 [ngx\_http\_index\_module](<236 [02.01.01 http] 模組 ngx_http_index_module.md>)模組之前執行。

По умолчанию этот модуль не собирается, его сборку необходимо разрешить с помощью конфигурационного параметра `--with-http_random_index_module`.

此模組預設未構建，必須使用`--with-http_random_index_module`配置參數啟用。

#### Пример конфигурации｜配置範例

> ```
> location / {
>
> 地點 / {
>     random_index on;
>
>     隨機索引開啟；
> }
> ```
