# Module ngx_http_num_map_module｜模組 ngx_http_num_map_module

## Module ngx\_http\_num\_map\_module｜模組 ngx\_http\_num\_map\_module

|   |

The `ngx_http_num_map_module` module (1.29.3) creates variables whose values depend on numeric values or numeric value ranges.

`ngx_http_num_map_module`模組 ( 1.29.3 ) 建立變量，其值取決於數值或數值範圍。

> This module is available as part of our [commercial subscription](https://www.f5.com/products/nginx).
>
> 本模組作為我們的[商業訂閱](https://www.f5.com/products/nginx)的一部分提供。

#### Example Configuration｜範例配置

> ```
> num_map $remote_port $port_allow {
>     default    0;
>
>     預設值為 0；
> 
>     80         1;
>     443        1;
>     <=1023     0;
>     8080-8090  1;
> }
> ```

#### Directives｜指令

|   |   |

Describes how the values of the specified variable depend on numeric values or numeric value ranges.

描述指定變數的值如何取決於數值或數值範圍。

> Since variables are evaluated only when used, the mere existence of even a large number of declared “`num_map`” variables does not cause any extra costs for request processing.
>
> 由於變數僅在使用時才進行評估，因此即使存在大量已聲明的「 `num_map` 」變數也不會給請求處理帶來任何額外的成本。

Parameters inside the `num_map` block specify a mapping between source and resulting values.

`num_map`區塊內的參數指定來源值和結果值之間的對應。

Source values are specified as numbers or as numeric ranges.

源值以數字或數值範圍的形式指定。

The following special parameters are also supported:

此外，也支援以下特殊參數：

`default`

sets the resulting value if the source value matches none of the specified variants. When `default` is not specified, the default resulting value will be an empty string.

如果來源值與任何指定的變體都不匹配，則設定結果值。如果未指定`default` ，則預設結果值為空字串。

`include`

includes a file with values. There can be several inclusions.

包含一個帶有值的檔案。可以包含多個文件。

`volatile`

indicates that the variable is not cacheable.

表示該變數不可緩存。
