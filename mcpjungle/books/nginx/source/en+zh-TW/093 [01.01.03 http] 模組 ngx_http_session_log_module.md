## Module ngx\_http\_session\_log\_module｜模組 ngx_http_session_log_module

The `ngx_http_session_log_module` module enables logging sessions (that is, aggregates of multiple HTTP requests) instead of individual HTTP requests.

`ngx_http_session_log_module`模組能夠記錄會話（即多個HTTP請求的聚合），而不是單一HTTP請求。

> This module is available as part of our [commercial subscription](https://www.f5.com/products/nginx).
>
> 本模組作為我們[商業訂閱](https://www.f5.com/products/nginx)的一部分提供。

#### Example Configuration｜範例配置

The following configuration sets up a session log and maps requests to sessions according to the request client address and “User-Agent”（使用者代理） request header field:

以下配置設定會話日誌，並根據請求客戶端位址和“User-Agent”（使用者代理）請求頭字段將請求對應到會話：

> ```
>     session_log_zone /path/to/log format=combined
>                      zone=one:1m timeout=30s
>
>                      區域=1:1分鐘 逾時=30秒
>                      md5=$binary_remote_addr$http_user_agent;
> 
>     location /media/ {
>         session_log one;
>
>         session_log 1；
>     }
> ```

Enables the use of the specified session log. The special value `off` cancels the effect of the `session_log` directives inherited from the previous configuration level.

啟用指定的會話日誌。特殊值`off`會取消從上一設定等級繼承的`session_log`指令的效果。

<table>
<tr><th>Syntax:<br>語法：</th><td><code><strong>session_log_format</strong> <code><i>name<br>名稱</i></code> <code><i>string<br>字串</i></code> ...;</code></td></tr>
<tr><th>Default:<br>預設值：</th><td>session_log_format combined "...";</td></tr>
<tr><th>Context:<br>上下文：</th><td><code>http</code></td></tr>
</table>

Specifies the output format of a log. The value of the `$body_bytes_sent` variable is aggregated across all requests in a session. The values of all other variables available for logging correspond to the first request in a session.

指定日誌的輸出格式。 `$body_bytes_sent` 變數的值是在會話中的所有請求中聚合的。可用於記錄的所有其他變數的值對應於會話中的第一個請求。

| --- | --- |
| Syntax:<br>语法： | ``**session_log_zone** `*path*` `zone`=`*name*`:`*size*` [`format`=`*format*`] [`timeout`=`*time*`] [`id`=`*id*`] [`md5`=`*md5*`] ;``<br>``**session_log_zone** `*路径*` `区域`=`*名称*`:`*大小*` [`格式`=`*格式*`] [`超時`=`*時間*`] [`id`=`*id*`] [`md5`=`*md5*`] ;`` |
| Default:<br>預設值： | — |
| Context:<br>背景： | `http` |

Sets the path to a log file and configures the shared memory zone that is used to store currently active sessions.

設定日誌檔案的路徑，並配置用於儲存目前活動會話的共用記憶體區域。

A session is considered active for as long as the time elapsed since the last request in the session does not exceed the specified `timeout` (by default, 30 seconds). Once a session is no longer active, it is written to the log.

只要自會話中最後一個請求以來經過的時間不超過指定的`timeout` （預設值為30秒），則該會話被視為處於活動狀態。一旦會話不再處於活動狀態，它將被寫入日誌。

The `id` parameter identifies the session to which a request is mapped. The `id` parameter is set to the hexadecimal representation of an MD5 hash (for example, obtained from a cookie using variables). If this parameter is not specified or does not represent the valid MD5 hash, nginx computes the MD5 hash from the value of the `md5` parameter and creates a new session using this hash. Both the `id` and `md5` parameters can contain variables.

`id` 參數標識請求對應到的會話。 `id` 參數設定為 MD5 哈希值的十六進位表示形式（例如，使用變數從 cookie 取得）。如果未指定此參數或不代表有效的 MD5 哈希值，nginx 將根據 `md5` 參數的值計算 MD5 哈希值，並使用此哈希值建立新會話。 `id`和`md5`參數都可以包含變數。

The `format` parameter sets the custom session log format configured by the [session\_log\_format](#session_log_format) directive. If `format` is not specified, the predefined “`combined`” format is used.

`format`參數設定由 [session\_log\_format](#session_log_format)指令配置的自訂會話日誌格式。如果未指定`format` ，則使用預先定義的「 `combined` 」格式。

#### Embedded Variables｜嵌入變數

The `ngx_http_session_log_module` module supports two embedded variables:

`ngx_http_session_log_module`模組支援兩個嵌入式變數：

`$session_log_id`

current session ID;

當前會話ID ；

`$session_log_binary_id`

current session ID in binary form (16 bytes).

當前會話ID以二進位形式表示（16 位元組）。
