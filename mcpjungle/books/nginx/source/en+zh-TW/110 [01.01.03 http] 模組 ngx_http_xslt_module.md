The `ngx_http_xslt_module` (0.7.8+) is a filter that transforms XML responses using one or more XSLT stylesheets.

`ngx_http_xslt_module` ( 0.7.8 +) 是一個過濾器，它使用一個或多個XSLT樣式表轉換XML響應。

This module is not built by default, it should be enabled with the `--with-http_xslt_module` configuration parameter.

此模組預設未構建，應使用`--with-http_xslt_module`配置參數啟用。

> This module requires the [libxml2](http://xmlsoft.org/) and [libxslt](http://xmlsoft.org/XSLT/) libraries.
>
> 本模組需要 [libxml2](http://xmlsoft.org/)和 [libxslt](http://xmlsoft.org/XSLT/)函式庫。

#### Example Configuration｜範例配置

> ```
> location / {
>
> 地點 / {
>     xml_entities    /site/dtd/entities.dtd;
>
>     xml_entities /site/dtd/entities.dtd;
>     xslt_stylesheet /site/xslt/one.xslt param=value;
>     xslt_stylesheet /site/xslt/two.xslt;
> }
> ```

Specifies the DTD file that declares character entities. This file is compiled at the configuration stage. For technical reasons, the module is unable to use the external subset declared in the processed XML, so it is ignored and a specially defined file is used instead. This file should not describe the XML structure. It is enough to declare just the required character entities, for example:

指定聲明字元實體的DTD檔案。此文件在配置階段編譯。由於技術原因，模組無法使用已處理的XML中聲明的外部子集，因此該檔案將被忽略，並改用一個專門定義的檔案。此文件不應描述XML結構。只需聲明所需的字元實體即可，例如：

> ```xml
> <!ENTITY nbsp "&#xa0;">
>
> <! ENTITY nbsp "&#xa0;">
> ```

Enables or disables loading of external entities declared in the internal DTD subset of the processed XML. Only loading of file-based external entities is supported.

啟用或停用載入在已處理的DTD的內部XML子集中聲明的外部實體。僅支援載入基於檔案的外部實體。

> To prevent reading arbitrary local files accessible to the worker process, it is recommended to enable external entities only when the processed XML is trusted.
>
> 為防止讀取工作進程可存取的任意本機文件，建議僅在受信任處理的XML時才啟用外部實體。

Allows preserving the “Last-Modified”（最後修改日期） header field from the original response during XSLT transformations to facilitate response caching.

允許在XSLT轉換期間保留原始回應的“Last-Modified”（最後修改日期）標頭字段，以方便回應快取。

By default, the header field is removed as contents of the response are modified during transformations and may contain dynamically generated elements or parts that are changed independently of the original response.

預設情況下，標頭欄位會被刪除，因為回應的內容在轉換過程中會被修改，並且可能包含動態產生的元素或部分，這些元素或部分會獨立於原始回應而變更。

Defines the parameters for XSLT stylesheets. The `*value*` is treated as an XPath expression. The `*value*` can contain variables. To pass a string value to a stylesheet, the [xslt\_string\_param](#xslt_string_param) directive can be used.

定義XSLT表的參數。 `*value*`將被視為 XPath 表達式。 `*value*`可以包含變數。要將字串值傳遞給樣式表，可以使用(https://nginx.org/en/docs/http/ngx_http_xslt_module.html#xslt_string_param) [xslt\_string\_param]。

There could be several `xslt_param` directives. These directives are inherited from the previous configuration level if and only if there are no `xslt_param` and [xslt\_string\_param](#xslt_string_param) directives defined on the current level.

可能存在多個`xslt_param`指令。當且僅噹噹前等級未定義`xslt_param`和 [xslt\_string\_param](#xslt_string_param)指令時，這些指令才會從上一個設定等級繼承。

可能存在多個`xslt_string_param`指令。當且僅噹噹前等級未定義 [xslt\_param](#xslt_param)和`xslt_string_param`指令時，這些指令才會從上一個組態等級繼承。

Defines the XSLT stylesheet and its optional parameters. A stylesheet is compiled at the configuration stage.

定義XSLT樣式表及其可選參數。樣式表在配置階段編譯。

Parameters can either be specified separately, or grouped in a single line using the “`:`” delimiter. If a parameter includes the “`:`” character, it should be escaped as “`%3A`”. Also, `libxslt` requires to enclose parameters that contain non-alphanumeric characters into single or double quotes, for example:

參數可以單獨指定，也可以使用「 `:` 」分隔符號將它們分組到一行中。如果參數包含「 `:` 」字符，則應將其轉義為「 `%3A` 」。此外， `libxslt`要求將包含非字母數字字元的參數以單引號或雙引號括起來，例如：

> ```
> param1='http%3A//www.example.com':param2=value2
> ```

The parameters description can contain variables, for example, the whole line of parameters can be taken from a single variable:

參數描述可以包含變量，例如，整行參數都可以取自單一變數：

> ```
> location / {
>
> 地點 / {
>     xslt_stylesheet /site/xslt/one.xslt
>                     $arg_xslt_params
>                     param1='$value1':param2=value2
>                     param3=value3;
> }
> ```

It is possible to specify several stylesheets. They will be applied sequentially in the specified order.

可以指定多個樣式表。它們將按照指定的順序依次應用。

Enables transformations in responses with the specified MIME types in addition to “`text/xml`”. The special value “`*`” matches any MIME type (0.8.29). If the transformation result is an HTML response, its MIME type is changed to “`text/html`”.

除了「 `text/xml` 」類型外，還允許對具有指定MIME類型的回應進行轉換。特殊值“ `*` ”匹配任何MIME類型（ 0.8.29 ）。如果轉換結果是HTML響應，則其MIME類型將變更為「 `text/html` 」。
