# Set up an agent｜設立代理

> 章節：[data-radix-scroll-area-viewport{scrollbar-width:none;-ms-o](<000 目錄.md#c-1>) › [portabase/portabase1.8K120](<000 目錄.md#c-2>) › [CLI｜命令列介面](<000 目錄.md#c-29>) › [Introduction｜介紹](<000 目錄.md#c-30>) › [Guides｜指南](<000 目錄.md#c-31>)

CLIGuides

CLI指南


Create an agent, add a database and connect it to your dashboard.

建立代理，新增資料庫並將其連接到您的儀表板。

At the end of this guide, an agent runs next to your database and appears as connected in the dashboard.

在本指南的最後，代理程式將在您的資料庫旁邊運行，並在儀表板中顯示為已連線。

**Prerequisites:** the [CLI installed](<089 [01.01.04.01 介紹] 安裝CLI.md>), Docker running, a [dashboard](<092 [01.01.04.01.01 指南] 設定儀表板.md>) reachable from this server.

**先決條件：** [已安裝CLI](<089 [01.01.04.01 介紹] 安裝CLI.md>)，Docker 正在運行，可從此伺服器存取[儀表板](<092 [01.01.04.01.01 指南] 設定儀表板.md>)。

### [Get an Edge Key](#get-an-edge-key)｜[取得邊緣鑰匙](#get-an-edge-key)

Before starting, go to your **Portabase Dashboard**, create a new Agent and copy its **Edge Key**.

開始之前，請前往 **Portabase 儀表板**，建立一個新代理並複製其**Edge Key**。

### [Create the agent](#create-the-agent)｜[建立代理](#create-the-agent)

```
portabase agent create my-agent
```

Paste the Edge Key when asked. A `my-agent/` folder is created.

當詢問時貼上邊緣鍵。將會建立一個`my-agent/`資料夾。

The wizard then asks **"Add a database?"** — answer yes to add one now, or continue with the next step.

然後精靈會詢問 **「新增資料庫？」** — 回答「是」立即添加，或繼續下一步。

### [Add a database](#add-a-database)｜[新增資料庫](#add-a-database)

```
portabase agent db add my-agent
```

Pick the engine, then `existing` for your own server or `new` for a test container. Engine-specific notes: [Databases](<077 [01.01.03.01.01 資料庫] 支援的資料庫.md>).

選擇引擎，然後為您自己的伺服器選擇`existing`，或為測試容器選擇`new`。引擎特定註解：[資料庫](<077 [01.01.03.01.01 資料庫] 支援的資料庫.md>)。

### [Start the agent](#start-the-agent)｜[啟動代理](#start-the-agent)

```
portabase start my-agent
```

### [Check the connection](#check-the-connection)｜[檢查連接](#check-the-connection)

```
portabase logs my-agent
```

The agent shows up as connected in the dashboard. If the logs show "Ping server failed", see [Troubleshooting](<102 [01.01.04.01 介紹] 故障排除.md>).

代理程式在儀表板中顯示為已連線。如果日誌顯示“Ping 伺服器失敗”，請參閱[故障排除](<102 [01.01.04.01 介紹] 故障排除.md>)。
