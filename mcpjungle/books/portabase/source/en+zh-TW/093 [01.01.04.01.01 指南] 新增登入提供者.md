# Add a login provider｜新增登入提供者

> 章節：[data-radix-scroll-area-viewport{scrollbar-width:none;-ms-o](<000 目錄.md#c-1>) › [portabase/portabase1.8K120](<000 目錄.md#c-2>) › [CLI｜命令列介面](<000 目錄.md#c-29>) › [Introduction｜介紹](<000 目錄.md#c-30>) › [Guides｜指南](<000 目錄.md#c-31>)

CLIGuides

CLI指南


Enable single sign-on (OIDC or OAuth) on a dashboard with the CLI.

使用 CLI 在儀表板上啟用單一登入（OIDC 或 OAuth）。

At the end of this guide, users can log in to your dashboard with your identity provider.

在本指南的最後，使用者可以使用您的身分提供者登入您的儀表板。

**Prerequisites:** a [dashboard](<092 [01.01.04.01.01 指南] 設定儀表板.md>) served on a public URL (not `localhost`), and a client ID / secret from your provider — see [OIDC setup](<015 [01.01.02.01.01.01.01.01.01.01 OIDC 配置] OIDC配置.md>) or [OAuth2 setup](<019 [01.01.02.01.01.01.01.01.02.01 OAuth2 配置] OAuth2 配置.md>).

**先决条件：** 在公共 URL（不是 `localhost`）上提供的 [仪表板](<092 [01.01.04.01.01 指南] 設定儀表板.md>)，以及来自您的提供商的客户端 ID/秘密 — 请参阅 [OIDC 设置](<015 [01.01.02.01.01.01.01.01.01.01 OIDC 配置] OIDC配置.md>) 或 [OAuth2 设置](<019 [01.01.02.01.01.01.01.01.02.01 OAuth2 配置] OAuth2 配置.md>)。

### [Set the public URL](#set-the-public-url)｜[設定公開URL](#set-the-public-url)

```
portabase dashboard set ./my-dashboard url https://backup.example.com
```

### [Add the provider](#add-the-provider)｜[新增提供者](#add-the-provider)

```
printf '%s\n' "$KEYCLOAK_SECRET" | portabase dashboard auth add ./my-dashboard oidc keycloak \
  --issuer https://sso.example.com/realms/main \
  --client portabase --secret-stdin \
  --title "Company SSO" --scopes "openid profile email" --pkce
```

For OAuth (Google, GitHub…), use `oauth <provider>` and drop `--issuer`.

對於 OAuth（Google、GitHub...），請使用 `oauth <provider>` 並刪除 `--issuer`。

### [Register the callback URL](#register-the-callback-url)｜[註冊回呼URL](#register-the-callback-url)

The CLI prints the callback URL. Add it to your provider's allowed redirect URIs.

CLI 列印回呼URL。將其新增至提供者允許的重定向 URI 中。

### [Restart and test](#restart-and-test)｜[重啟測試](#restart-and-test)

```
portabase restart ./my-dashboard
```

The login page now shows a **Company SSO** button.

登入頁面現在顯示**公司SSO**按鈕。
