Installation


Install the Portabase Dashboard and Agent with the Portabase CLI.

The CLI is the recommended way to install Portabase. It generates the configuration and the encryption secret (`PROJECT_SECRET`), and starts the containers for you.

Install the CLI first. If it isn't installed yet, follow the instructions [here](<089 [01.01.04.01 Introduction] Install the CLI.md>).

Breaking changes in recent CLI versions

This guide uses the current syntax: `portabase dashboard create` and `portabase agent create`. With the **CLI 26.08.12 or earlier**, the commands were `portabase dashboard <name>` and `portabase agent <name>` — see the [legacy reference](<104 [01.01.04.01 Introduction] CLI reference (Legacy).md>). Upgrading an existing installation? Read the [migration guide](<103 [01.01.04.01 Introduction] Migration guide.md>) first.

---

## [Quick install](#quick-install)

```
portabase dashboard create my-dashboard --start
portabase agent create my-agent
portabase agent db add my-agent
portabase start my-agent
```

Open `http://localhost:8887` to reach the dashboard. The agent needs an Edge Key created in the dashboard.
