# 快速上手

> 章節：[多重文件](<000 目錄.md#c-1>) › [data-radix-scroll-area-viewport{scrollbar-width:none;-ms-o](<000 目錄.md#c-2>) › [GitHub](<000 目錄.md#c-3>)

連線一臺電腦，建立你的第一個智慧體，並讓它完成第一個任務。

智慧體執行前，執行它的電腦上需要有至少一款已安裝並登入的[支援的 AI 程式設計工具](<69 [01.01.01 GitHub] AI 程式設計工具對照.md>)，例如 Claude Code、Codex 或 Cursor。Multica 不自帶這些工具。

## [1\. 登入，進入工作區](#1-%E7%99%BB%E5%BD%95%E8%BF%9B%E5%85%A5%E5%B7%A5%E4%BD%9C%E5%8C%BA)

用 Web（[multica.ai](<01 [01.01.01 GitHub] 你的下一批員工.md>)）或 [Multica Desktop](https://multica.ai/download) 登入，支援郵箱驗證碼和 Google。

-   **Desktop**：可以自動連線這臺電腦。
-   **Web**：需要在下一步通過命令列連線。

## [2\. 連線一臺電腦](#2-%E8%BF%9E%E6%8E%A5%E4%B8%80%E5%8F%B0%E7%94%B5%E8%84%91)

智慧體在你連線的電腦上執行工作。開啟側邊欄底部的 **配置 → 執行時**：

-   **用 Desktop**：Desktop 會自動把這臺電腦註冊為執行時，並檢測已安裝的 AI 程式設計工具。剛安裝的工具，點"重新整理"重新檢測。
-   **用 Web，或需要新增另一臺電腦**：點右上角的 **新增電腦**，在目標電腦的終端裡執行彈窗給出的兩條命令：

**macOS / Linux**

```bash
curl -fsSL https://raw.githubusercontent.com/multica-ai/multica/main/scripts/install.sh | bash
multica setup
```

**Windows PowerShell**

```
irm https://raw.githubusercontent.com/multica-ai/multica/main/scripts/install.ps1 | iex
multica setup
```

`multica setup` 會開啟瀏覽器完成登入，然後讓守護程序在後臺執行。守護程序上線後，彈窗通常在一分鐘內自動檢測到這臺電腦。

**成功標誌**：執行時列表裡出現一臺線上的電腦。

![Add a computer 弹窗：两条命令与等待检测提示](<../images/afbf19de-image.webp>)

自託管例項的連線命令略有不同，見[自託管快速上手](<50 [01.01.01 GitHub] 自託管快速上手.md>)。

## [3\. 建立一個智慧體](#3-%E5%88%9B%E5%BB%BA%E4%B8%80%E4%B8%AA%E6%99%BA%E8%83%BD%E4%BD%93)

開啟側邊欄的 **工作區 → 智慧體**，點 **新建智慧體**，選擇一條路徑：

-   **從空白開始**：自己填欄位。最少只需要名稱，再確認執行時和 AI 程式設計工具即可建立。
-   **通過 AI 建立**：描述你想要什麼，由 Agent Builder 提問並生成配置。這條路徑需要一個線上執行時。

其餘配置可以之後完善，詳見[建立和配置智慧體](<57 [01.01.01 GitHub] 建立和配置智慧體.md>)。

**成功標誌**：智慧體列表中出現你的智慧體，並顯示為線上。

![创建智能体的起点选择页：Start blank 与 Build with AI](<../images/9f208c98-image.webp>)

## [4\. 把第一個任務交給它](#4-%E6%8A%8A%E7%AC%AC%E4%B8%80%E4%B8%AA%E4%BB%BB%E5%8A%A1%E4%BA%A4%E7%BB%99%E5%AE%83)

點側邊欄頂部的 **新建任務**（或按快捷鍵 `C`）。在預設的智慧體模式下：

1.  在 **建立者** 中選擇剛建立的智慧體；
2.  用一兩句話描述要做的事，例如"介紹一下這個工作區可以怎麼用"；
3.  提交。Multica 會建立任務、把智慧體設為負責人並立即開始執行。

![新建任务弹窗的智能体模式：Created by 已选中 Multica Assistant](<../images/1cc8d77c-image.webp>)

## [5\. 檢視進度和結果](#5-%E6%9F%A5%E7%9C%8B%E8%BF%9B%E5%BA%A6%E5%92%8C%E7%BB%93%E6%9E%9C)

提交後開啟這條任務：執行日誌顯示執行狀態，智慧體的進展和回覆出現在時間線中。

**成功標誌**：執行日誌狀態變為"已完成"，時間線中出現智慧體的回覆。需要檢視完整過程時，點"檢視記錄"。

![任务中智能体的回复与已完成的执行日志](<../images/ae019ffe-image.webp>)

## [常見問題](#%E5%B8%B8%E8%A7%81%E9%97%AE%E9%A2%98)

| 現象 | 先檢查什麼 |
| --- | --- |
| 沒有找到執行時 | 確認 AI 程式設計工具已經安裝並能在終端中執行。Desktop 點"重新整理"；CLI 方式重新執行 `multica setup`。 |
| 執行時顯示離線 | Desktop 保持開啟；CLI 方式執行 `multica daemon status`，未啟動時執行 `multica daemon start`。 |
| 任務一直排隊 | 確認智慧體使用的執行時線上。執行時達到併發上限時，新執行會繼續排隊。 |

更多情況見[故障排查](<83 [01.01.01 GitHub] 故障排查.md>)。
