# Http

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Configures HTTP server settings including rate limiting, CORS, and security headers.

 配置HTTP伺服器設置，包括速率限制、 CORS和安全標頭。

 This object can be configured from the WebUI under Settings › Network › HTTP › General Settings › Network › HTTP › Security

 此物件可透過 WebUI在「設定」&gt;「網路」&gt; HTTP “常規設定”&gt;「網路」&gt; HTTP 「安全」中進行設定。

## Fields｜田野

##### `rateLimitAuthenticated`

> Type: \\\[\\\`Rate\\\`\\\]\\\(#rate\\\)\\\`?\\\` · default: \\\`{"count":1000,"period":60000}\\\`

類型：\[ \`Rate\` \]\(#rate\)\`?\` · 預設值： \`{"count":1000,"period":60000}\`

 Specifies the request rate limit for authenticated users

 指定已認證使用者的請求速率限制

##### `rateLimitAnonymous`

> Type: \\\[\\\`Rate\\\`\\\]\\\(#rate\\\)\\\`?\\\` · default: \\\`{"count":100,"period":60000}\\\`

類型：\[ \`Rate\` \]\(#rate\)\`?\` · 預設值： \`{"count":100,"period":60000}\`

 Specifies the request rate limit for unauthenticated users

 指定未經身份驗證使用者的請求速率限制

##### `allowedEndpoints`

> Type: \\\[\\\`Expression\\\`\\\]\\\(#expression\\\) · default: \\\`{"else":"200"}\\\`

類型：\[\`Expression\`\]\(#expression\) · 預設值： \`{"else":"200"}\`

 An expression that determines whether access to an endpoint is allowed. The expression should an HTTP status code \(200, 403, etc.\)

 用於決定是否允許存取端點的表達式。此表達式應傳回一個HTTP狀態碼（200、403等）。

 Available variables: \[\`HttpVariable\`\]\(&lt;323 \[02.14.02.02 多變的\] HttpVariable.md&gt;\).

 可用變數：\[\`HttpVariable\`\]\(&lt;323 \[02.14.02.02 多變的\] HttpVariable.md&gt;\) 。

##### `enableHsts`

> Type: \\\`Boolean\\\` · default: \\\`false\\\`

類型： \`Boolean\` · 預設值： \`false\`

 Specifies whether to enable HTTP Strict Transport Security for the HTTP server.

 指定是否為HTTP伺服器啟用HTTP嚴格傳輸安全。

##### `usePermissiveCors`

> Type: \\\`Boolean\\\` · default: \\\`false\\\`

類型： \`Boolean\` · 預設值： \`false\`

 Specifies whether to allow all origins in the CORS policy for the HTTP server

 指定是否允許CORS策略中所有來源的訪問，該策略適用於HTTP伺服器

##### `responseHeaders`

> Type: \\\`Map<string, string="">\\\`

類型： \`Map&amp;lt;string, string=""&amp;gt;\`

 Additional headers to include in HTTP responses

 HTTP響應中要包含的其他標頭

##### `useXForwarded`

> Type: \\\`Boolean\\\` · default: \\\`false\\\`

類型： \`Boolean\` · 預設值： \`false\`

 Specifies whether to use the Forwarded or X-Forwarded-For header to determine the client’s IP address

 指定是使用 Forwarded 標頭或 X-Forwarded-For 標頭來決定客戶端的IP位址

##### `redirectRoot`

> Type: \\\`String?\\\` · default: \\\`"/account"\\\`

類型： \`String?\` · 預設值： \`"/account"\`

 The URL to redirect users to when they access the root path of the HTTP server. If not set, the server will return a 404 Not Found response.

 當使用者存取HTTP的根路徑時，要重新導向到的URL 。如果未設置，伺服器將傳回 404 Not Found 回應。

## JMAP API

 The Http singleton is available via the `urn:stalwart:jmap` capability.

 Http 單例可透過`urn:stalwart:jmap`功能取得。

### `x:Http/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是 [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)節5.1中定義。

 For singletons, the `ids` argument should be the literal `singleton` \(or `null` to return the single instance\).

 對於單例， `ids`參數應該是字面值`singleton` （或`null`以傳回單一實例）。

 This method requires the `sysHttpGet` permission.

 此方法需要`sysHttpGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:Http/get",
          {
            "ids": [
              "singleton"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:Http/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節定義。

 For singletons, only the `update` argument with id `singleton` is accepted; `create` and `destroy` arguments are rejected.

 對於單例，僅接受 id 為`singleton` `update`參數；拒絕`create`和`destroy`參數。

 This method requires the `sysHttpUpdate` permission.

 此方法需要`sysHttpUpdate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:Http/set",
          {
            "update": {
              "singleton": {
                "redirectRoot": "updated value"
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get Http
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update Http --field redirectRoot='updated value'
```
