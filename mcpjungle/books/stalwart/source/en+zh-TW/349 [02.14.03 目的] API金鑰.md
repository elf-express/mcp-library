# ApiKey｜API金鑰

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

API key credential for programmatic access.

 API用於程式化存取的關鍵憑證。

 This object can be configured from the WebUI under Account › Credentials › API Keys

 此物件可在 WebUI下的「帳號 › 憑證 › API金鑰」中進行設定。

## JMAP API

 The ApiKey object is available via the `urn:stalwart:jmap` capability.

 ApiKey 物件可透過`urn:stalwart:jmap`功能取得。

### `x:ApiKey/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節定義。

 This method requires the `sysApiKeyGet` permission.

 此方法需要`sysApiKeyGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:ApiKey/get",
          {
            "ids": [
              "id1"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:ApiKey/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節定義。

 Supports create, update, and destroy operations in a single call.

 支援在一次呼叫中執行建立、更新和銷毀操作。

#### Create｜創造

 This operation requires the `sysApiKeyCreate` permission.

 此操作需要`sysApiKeyCreate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:ApiKey/set",
          {
            "create": {
              "new1": {
                "allowedIps": {},
                "description": "Example",
                "permissions": {
                  "@type": "Inherit"
                }
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:ApiKey/query`

 This is a standard [Foo/query](https://www.rfc-editor.org/rfc/rfc8620#section-5.5) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.5), Section 5.5.

 這是 [Foo/query](https://www.rfc-editor.org/rfc/rfc8620#section-5.5)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.5)節5.5中定義。

 This method requires the `sysApiKeyQuery` permission.

 此方法需要`sysApiKeyQuery` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:ApiKey/query",
          {
            "filter": {
              "expiresAt": "2026-01-01T00:00:00Z"
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

The `x:ApiKey/query` `filter` argument accepts the following conditions \(combinable with `AnyOf` / `AllOf` / `Not` per RFC 8620\):

`x:ApiKey/query` `filter`參數接受以下條件（可與`AnyOf` / `AllOf` / `Not`結合使用，請參閱RFC 8620）：

| Condition 條件 | Kind 種類 |
| --- | --- |
| `expiresAt` | date 日期 |

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get ApiKey id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create ApiKey \
  --field description=Example \
  --field 'permissions={"@type":"Inherit"}' \
  --field 'allowedIps={}'
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query ApiKey
stalwart-cli query ApiKey --where expiresAt=2026-01-01T00:00:00Z
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update ApiKey id1 --field description='updated value'
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete ApiKey --ids id1
```

## Nested types｜巢狀類型

### CredentialPermissions｜憑證權限

 Permission assignment mode for a credential.

 憑證的權限分配模式。

- **`Inherit`**: Same permissions as account. No additional fields.
**`Inherit`**：權限與帳戶相同。無其他字段。
- **`Disable`**: Disable some permissions. Carries the fields of [CredentialPermissionsList](#credentialpermissionslist).
**`Disable`**: 停用某些權限。包含 [CredentialPermissionsList](#credentialpermissionslist)的欄位。
- **`Replace`**: Replace all permissions. Carries the fields of [CredentialPermissionsList](#credentialpermissionslist).
**`Replace`**: 替換所有權限。包含 [CredentialPermissionsList](#credentialpermissionslist)的欄位。

 List of permissions to assign to a credential.
