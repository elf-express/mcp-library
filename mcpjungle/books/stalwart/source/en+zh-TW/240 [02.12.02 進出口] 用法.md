# Usage｜用法

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[migration｜遷移\\\]\\\(&lt;000 目錄.md#c-37&gt;\\\) › \\\[import export｜進出口\\\]\\\(&lt;000 目錄.md#c-40&gt;\\\)

[Vandelay](https://github.com/stalwartlabs/vandelay) presents a small command surface built around three subcommands. The `import` command reads a source account into a local archive, the `export` command reconciles an archive onto a target JMAP server, and the `inspect` command displays the contents of an archive without touching the network. Every invocation follows the same shape, with the local archive given as the final positional argument:

[Vandelay](https://github.com/stalwartlabs/vandelay) 呈現了一個圍繞三個子指令建構的小型指令介面。 `import` 指令將來源帳號讀取到本機檔案中，`export` 指令將檔案協調到目標 JMAP 伺服器上，`inspect` 指令在不接觸網路的情況下顯示檔案的內容。每次呼叫都遵循相同的形狀，並將本地存檔作為最終位置參數給出：

```bash title=&amp;quot;Terminal window&amp;quot;
vandelay <import|export|inspect> [options...] <ARCHIVE>
```

The archive is a single SQLite file holding exactly one account. The `import` and `export` commands create it if it does not already exist; `inspect` only reads it.

 該存檔是一個單獨的 SQLite 文件，僅包含一個帳戶。如果尚不存在，則使用 `import` 和 `export` 指令建立它； `inspect` 只讀。

## The two sync modes｜兩種同步模式

 There are exactly two synchronisation modes, `import` and `export`, and there is no separate command for discovery, resume or incremental update. Those are all expressed by re-running an import or an export against the same archive, because both modes are convergent. An interrupted run is completed by repeating it; a later run captures or applies whatever has changed since the previous one. This is the central idea to keep in mind when operating the tool: the safe response to almost any interruption is to run the same command again.

 同步模式只有兩種： `import`和`export` ，沒有單獨的發現、復原或增量更新指令。這些操作都是透過對同一個歸檔檔案重新執行匯入或匯出操作來實現的，因為這兩種模式都是收斂的。中斷的運行會透過重複執行該操作來完成；後續運行會捕獲或套用自上次運行以來發生的所有變更。這是操作該工具時需要牢記的核心思想：對於幾乎所有中斷，最安全的應對方法是再次執行相同的命令。

## Credentials｜證書

 Sources and targets that require authentication accept their secrets in three ways, and the order in which Vandelay looks for them is designed so that secrets need never appear on the command line. A secret may be passed through a flag, but is more safely provided through an environment variable, and when neither is present Vandelay prompts for it interactively on the terminal. The environment variables are `VANDELAY_PASSWORD` for Basic-authentication passwords, `VANDELAY_TOKEN` for bearer tokens, `VANDELAY_EWS_CLIENT_SECRET` for the Exchange EWS application-only flow, and `VANDELAY_GRAPH_TOKEN` for a pre-acquired Microsoft Graph token. Passing a password or token directly as a flag value is supported for scripting but discouraged, because it exposes the secret in the process table and the shell history.

 需要身份驗證的來源和目標可以透過三種方式接收金鑰，Vandelay 查找金鑰的順序經過精心設計，確保金鑰永遠不會出現在命令列中。密鑰可以透過標誌傳遞，但更安全的方法是透過環境變數提供。如果兩者都不存在，Vandelay 會在終端機上以互動方式提示輸入金鑰。環境變數分別為： `VANDELAY_PASSWORD`用於基本驗證密碼， `VANDELAY_TOKEN`用於持有者令牌， `VANDELAY_EWS_CLIENT_SECRET`用於 Exchange EWS僅限應用程式流程，以及`VANDELAY_GRAPH_TOKEN`用於預先取得的 Microsoft Graph 令牌。雖然腳本支援直接將密碼或令牌作為標誌值傳遞，但不建議這樣做，因為這會將金鑰暴露在進程表和 shell 歷史記錄中。

## Global flags｜全球旗幟

 A set of flags is common to every command, controlling concurrency, logging, retry behaviour and TLS handling.

 每個命令都有一組通用的標誌，用於控制並發性、日誌記錄、重試行為和TLS處理。

| Flag 標誌 | Default 預設值 | Meaning 意義 |
| --- | --- | --- |
| `-j, --threads <N>` | logical CPUs 邏輯 CPU | Worker pool size, clamped down to the server’s advertised concurrency limit. 工作執行緒池大小，限制在伺服器公佈的並發限制內。 |
| `--dry-run` | off 關閉 | Compute and report the full plan; perform no writes. 計算並報告完整計劃；不執行任何寫入操作。 |
| `-v, --verbose` | off 關閉 | Increase log verbosity; repeatable up to `-vvv`. Mutually exclusive with `--quiet`. 增加日誌詳細程度；可重複執行至`-vvv` 。與`--quiet`互斥。 |
| `-q, --quiet` | off 關閉 | Restrict output to warnings and errors. 僅輸出警告和錯誤訊息。 |
| `--max-retries <N>` | 5 | Maximum retry attempts per request on transient failures. 每次請求在瞬態故障時的最大重試次數。 |
| `--allow-invalid-certs` | off 關閉 | Accept self-signed or otherwise invalid TLS certificates. 接受自簽名或其他無效的TLS憑證。 |

The worker pool governs how many requests run in parallel, but Vandelay never exceeds the concurrency a server advertises, so the value set here is an upper bound rather than a guarantee. Verbosity climbs from the default of per-type progress lines and a final summary, through per-chunk progress and retry notices at `-v`, to a full record of every protocol call at `-vv` and complete request and response bodies at `-vvv`; the deeper levels are written to standard error so that standard output stays parseable, and secrets are always redacted regardless of level. Accepting invalid certificates should be reserved for test servers.

 工作池控制並行運行的請求數量，但 Vandelay 永遠不會超過伺服器公佈的並發數，因此此處設定的值是上限而不是保證。詳細程度從預設的每種類型進度線和最終摘要，通過`-v`的每個區塊進度和重試通知，到`-vv`的每個協議調用的完整記錄以及`-vvv`的完整請求和響應正文；更深的級別被寫入標準錯誤，以便標準輸出始終被可解析，無論級別保持可解析，無論級別如何，秘密總是被編輯級別。接受無效憑證應保留給測試伺服器。

## Dry runs｜演練

 Every command accepts `--dry-run`, which performs all the reading and reconciliation needed to determine exactly what would change but writes nothing, neither to the archive on import nor to the target on export. The plan it prints, including the counts of objects that would be created, updated or removed, is the recommended way to preview a migration before committing to it, particularly before a destructive export.

 每個命令都接受`--dry-run` ，該參數會執行所有必要的讀取和協調工作，以確定具體哪些內容會發生更改，但不會寫入任何內容，無論是導入時寫入歸檔文件，還是導出時寫入目標文件。它列印的計劃（包括將要建立、更新或刪除的物件數量）是預覽遷移的建議方法，尤其是在執行破壞性導出之前。

## Inspecting an archive｜查閱檔案

 The `inspect` command provides a read-only view of an archive. It never opens a network connection and never modifies the data, which makes it safe to run at any time to verify that an import captured what was expected before proceeding to export.

`inspect`指令提供歸檔文件的唯讀視圖。它從不開啟網路連接，也從不修改數據，因此可以隨時運行，以驗證匯入是否捕獲了預期內容，然後再進行匯出。

```bash title=&amp;quot;Terminal window&amp;quot;
vandelay inspect <ARCHIVE> [TYPE] [--limit <N>] [--offset <N>]
```

Run without a type, `inspect` prints a per-type summary giving the count of every object kind in the archive together with blob-storage statistics. Given an object type, it dumps that type’s contents: the accepted tokens are `mailbox`, `email`, `identity`, `sievescript`, `addressbook`, `contactcard`, `calendar`, `calendarevent`, `participantidentity` and `filenode`. The `mailbox` and `filenode` types are rendered as a tree and ignore the pagination options, while the other types are listed in pages and honour `--limit` and `--offset` for stepping through large collections.

 不指定類型時， `inspect`會列印每個類型的摘要，列出歸檔中每種物件類型的數量以及 blob 儲存統計資料。給定一個物件類型，它會轉儲該類型的內容：可接受的標記是`mailbox`, `email`, `identity`, `sievescript`, `addressbook`, `contactcard`, `calendar`, `calendarevent`, `participantidentity`和`filenode`和`mailbox`類型會以樹狀結構呈現，並忽略分頁選項；而其他類型則以頁的形式列出，並遵循`filenode` `--offset` `--limit`遍歷大型集合。

## Exit codes｜退出代碼

 Vandelay reports the outcome of a run through its exit status, which is useful when driving it from scripts and schedulers.

 Vandelay 透過其退出狀態報告運行結果，這在透過腳本和調度程序驅動它時非常有用。

| Code 代碼 | Meaning 意義 |
| --- | --- |
| 0 | Success. All selected types were reconciled, though warnings may have been printed. 成功。所有選定的類型已核對，但可能列印了警告訊息。 |
| 1 | Usage error, such as a bad flag or a missing required argument. 使用錯誤，例如錯誤的標誌或缺少必要參數。 |
| 2 | Connection, authentication or session-discovery failure. 連線、身份驗證或會話發現失敗。 |
| 3 | Account resolution failure: the account was not found or was ambiguous. 帳戶解析失敗：未找到帳戶或帳戶資訊不明確。 |
| 4 | Source-change protection triggered without `--allow-source-change`. 源變更保護已觸發，但未啟用`--allow-source-change` 。 |
| 5 | Partial failure: some objects or types failed, while the archive was left consistent and resumable. 部分失敗：某些物件或類型失敗，但歸檔檔案仍保持一致且可復原。 |
| 6 | Aborted by the operator at the `--prune` confirmation prompt. 操作員在`--prune`確認提示處中止了操作。 |
| 7 | Local archive or input/output failure: the archive could not be opened, created or read. 本機歸檔或輸入/輸出故障：無法開啟、建立或讀取歸檔檔案。 |

A partial failure, code 5, is always safe to retry, because import converges by recomputing its identifier difference and export converges by re-matching. Code 7 indicates a local problem, such as a bad path, a stale lock or insufficient disk, and never points to anything wrong on the remote side.

 部分失敗（代碼 5）始終可以安全重試，因為導入操作會透過重新計算標識符差異來收斂，而導出操作會透過重新匹配來收斂。代碼 7 表示本機問題，例如路徑錯誤、鎖過期或磁碟空間不足，絕不會指向遠端的任何問題。

 The distinction that matters when reading an exit status is between a failure that belongs to one object or one data type and a failure that belongs to the whole run. Code 5 is reserved for the former: a single message that could not be mapped, a type whose method the server does not implement, an object too large to split. Those are counted, warned about, and the run carries on with the remaining work, leaving an archive that is consistent and that a repeat run will converge. Everything else stops the run at the point of failure and reports its own code, because no further type could have succeeded. A connection refused, a rejected credential, or an HTTP error from the endpoint the session advertised all report code 2 rather than repeating the same warning once per type and then claiming a resumable partial success. An unresolvable account reports code 3, source-change protection code 4, and a failure to read or write the archive itself code 7.

 讀取退出狀態時，關鍵在於區分屬於單一物件或單一資料類型的失敗和屬於整個運行的失敗。代碼 5 保留給前者：無法映射的單一訊息、伺服器未實現的方法的類型、過大而無法拆分的物件。這些失敗會被計數並發出警告，運行會繼續執行剩餘的工作，最終產生一個一致的歸檔文件，以便重複運行能夠收斂。其他所有失敗都會在失敗點停止運行並報告其自身的程式碼，因為沒有其他類型能夠成功處理。連線被拒絕、憑證被拒絕或會話所通告的端點傳回的HTTP錯誤都會報告代碼 2，而不是針對每種類型重複發出相同的警告，然後聲稱部分成功且可恢復。無法解析的帳戶報告代碼 3，原始碼變更保護報告代碼 4，讀取或寫入歸檔文件本身失敗報告代碼 7。
