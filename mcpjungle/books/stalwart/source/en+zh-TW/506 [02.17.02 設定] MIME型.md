# MIME types｜MIME型

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[spamfilter｜垃圾郵件過濾器\\\]\\\(&lt;000 目錄.md#c-69&gt;\\\) › \\\[settings｜設定\\\]\\\(&lt;000 目錄.md#c-71&gt;\\\)

File-extension classification lets the spam filter react to message attachments in an informed way, based on the expected MIME type of each extension and a small set of flags. Each classification is stored as a SpamFileExtension object \(found in the WebUI under Settings › Spam Filter › Lists › File Extensions\).

 檔案副檔名分類使垃圾郵件過濾器能夠根據每個副檔名的預期MIME類型和一組標誌，以更聰明的方式對郵件附件做出反應。每個分類都儲存為 SpamFileExtension物件（可在 WebUI 的「設定」&gt;「垃圾郵件過濾器」&gt;「清單」&gt;「檔案副檔名」下找到）。

## Fields｜田野

 Each SpamFileExtension instance carries:

 每個 SpamFileExtension 實例都包含：

- extension: the file-name extension this entry applies to, without the leading dot.
extension : 此條目適用的檔案副檔名，不含開頭的點。
- contentTypes: the set of MIME types that are expected for this extension. Leaving the set empty means no MIME type is required.
contentTypes : 此擴充所需的MIME型集合。如果集合為空，則表示不需要MIME類型。
- isBad: marks the extension as risky or malicious. Messages carrying an attachment whose extension is flagged as bad receive an increased spam score.
isBad ：將副檔名標記為風險或惡意。帶有被標記為惡意副檔名的附件的郵件，其垃圾郵件評分會升高。
- isArchive: marks the extension as an archive format \(such as `zip` or `rar`\). The filter can then apply archive-specific logic, for example inspecting the archive contents or penalising nested archives.
isArchive : 將副檔名標記為歸檔格式（例如`zip`或`rar` ）。然後，過濾器可以應用特定於歸檔的邏輯，例如檢查歸檔內容或懲罰嵌套歸檔。
- isNz: marks the extension as “not in archive”: a file with this extension should not appear inside another archive. If the filter finds such a file nested inside an archive, the spam score is adjusted accordingly.
isNz ：將此副檔名標記為「不在壓縮包內」：具有此副檔名的檔案不應出現在其他壓縮包內。如果過濾器發現此類檔案嵌套在壓縮包內，則會相應地調整垃圾郵件評分。
The filter uses these flags to apply rule-based scoring. For example, finding an archive \(`isArchive = true`\) inside another archive increases the spam score, since nested archives are a common tactic for hiding malicious content.
 此篩選器使用這些標誌進行基於規則的評分。例如，在一個歸檔檔案（ `isArchive = true` ）中發現另一個歸檔檔案會增加垃圾郵件評分，因為嵌套歸檔檔案是隱藏惡意內容的常用手段。

## Examples｜範例

 PDF files are expected to carry a PDF MIME type and should not appear inside archives:

 PDF文件應帶有PDF MIME類型，且不應出現在歸檔文件中：

```json
{
  "extension": "pdf",
  "contentTypes": {"application/pdf": true, "application/x-pdf": true},
  "isArchive": false,
  "isBad": false,
  "isNz": true
}
```

HTML files carried as attachments are treated as risky:

 HTML作為附件傳輸的文件被視為高風險文件：

```json
{
  "extension": "htm",
  "contentTypes": {"text/html": true},
  "isArchive": false,
  "isBad": true,
  "isNz": false
}
```

Batch files are considered malicious regardless of the declared MIME type:

 無論MIME的類型是什麼，批次檔都被視為惡意檔案：

```json
{
  "extension": "bat",
  "contentTypes": {},
  "isArchive": false,
  "isBad": true,
  "isNz": false
}
```

RAR files are archives:

 RAR文件是存檔文件：

```json
{
  "extension": "rar",
  "contentTypes": {},
  "isArchive": true,
  "isBad": false,
  "isNz": false
}
```
