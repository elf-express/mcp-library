# RocksDB

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[storage｜貯存\\\]\\\(&lt;000 目錄.md#c-72&gt;\\\) › \\\[backends｜後端\\\]\\\(&lt;000 目錄.md#c-73&gt;\\\)

RocksDB is an embeddable, high-performance, persistent key-value store originally developed at Facebook. It is well suited to fast storage devices such as SSDs, and its efficient use of CPU and memory makes it a popular choice for embedded workloads. RocksDB is the recommended backend for single-node installations of Stalwart because of its speed and reliability.

 RocksDB 是一款可嵌入式、高效能的持久化鍵值儲存系統，最初由 Facebook 開發。它非常適合 SSD 等高速儲存設備，並且由於其對CPU和記憶體的高效利用，成為嵌入式工作負載的熱門選擇。鑑於其速度和可靠性，RocksDB 是 Stalwart 單節點部署的建議後端。

## Configuration｜配置

 The RocksDB backend is selected by choosing the `RocksDb` variant on the DataStore object \(found in the WebUI under Settings › Storage › Data Store\). The variant exposes the following fields:

 若要選擇 RocksDB 後端，請在 DataStore物件上選擇`RocksDb`變體（可在 WebUI 的「設定」&gt;「儲存」&gt;「資料儲存」中找到）。該變體公開以下欄位：

- path: filesystem path where the RocksDB data directory is stored \(required\).
path : RocksDB 資料目錄所在的檔案系統路徑（必要）。
- blobSize: minimum size, in bytes, for an object to be stored in the blob store rather than inline in the metadata store. Default: `16834`.
blobSize : 物件儲存在 blob 儲存中而非內聯儲存在元資料儲存中的最小大小（以位元組為單位）。預設值： `16834` 。
- bufferSize: size of the in-memory write buffer, in bytes. A larger buffer improves write throughput at the cost of memory. Default: `134217728` \(128 MB\).
bufferSize : 記憶體中寫入緩衝區的大小，以位元組為單位。更大的緩衝區可以提高寫入吞吐量，但會佔用更多記憶體。預設值： `134217728` \(128 MB \)。
- poolWorkers: number of worker threads dedicated to database operations. Defaults to the number of CPU cores available on the host.
poolWorkers : 專用於資料庫操作的工作執行緒數。預設值為主機上可用的CPU核心數。
RocksDB is also available as a backend for other stores \(blob, search, in-memory\) through the `Default` variant of the BlobStore, SearchStore, and InMemoryStore objects, in which case they reuse the configured data store.
 RocksDB 也可以透過 BlobStore 、SearchStore和 InMemoryStore物件的`Default`變體作為其他儲存（blob、搜尋、記憶體）的後端，在這種情況下，它們會儲存的資料。
