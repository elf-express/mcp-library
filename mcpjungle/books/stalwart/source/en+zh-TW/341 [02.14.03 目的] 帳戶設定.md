# AccountSettings｜帳戶設定

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Configures default account settings for locale and encryption.

 配置區域設定和加密的預設帳戶設定。

 This object can be configured from the WebUI under Account › Settings

 此物件可在 WebUI下的「帳號 › 設定」中進行設定。

## JMAP API

 The AccountSettings singleton is available via the `urn:stalwart:jmap` capability.

 AccountSettings 單例可透過`urn:stalwart:jmap`功能取得。

### `x:AccountSettings/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節定義。

 For singletons, the `ids` argument should be the literal `singleton` \(or `null` to return the single instance\).

 對於單例， `ids`參數應該是字面值`singleton` （或`null`以傳回單一實例）。

 This method requires the `sysAccountSettingsGet` permission.

 此方法需要`sysAccountSettingsGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:AccountSettings/get",
          {
            "ids": [
              "singleton"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:AccountSettings/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是 [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)節5.3中定義。

 For singletons, only the `update` argument with id `singleton` is accepted; `create` and `destroy` arguments are rejected.

 對於單例，僅接受 id 為`singleton` `update`參數；拒絕`create`和`destroy`參數。

 This method requires the `sysAccountSettingsUpdate` permission.

 此方法需要`sysAccountSettingsUpdate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:AccountSettings/set",
          {
            "update": {
              "singleton": {
                "description": "updated value"
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get AccountSettings
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update AccountSettings --field description='updated value'
```

## Nested types｜巢狀類型

### EncryptionAtRest｜靜態加密

 Encryption-at-rest algorithm selection.

 靜態資料加密演算法選擇。

- **`Disabled`**: Disabled. No additional fields.
**`Disabled`**：已停用。無其他字段。
- **`Aes128`**: AES-128. Carries the fields of [EncryptionSettings](#encryptionsettings).
**`Aes128`**: AES -128。攜帶 [EncryptionSettings](#encryptionsettings)的場。
- **`Aes256`**: AES-256. Carries the fields of [EncryptionSettings](#encryptionsettings).
**`Aes256`**: AES -256。攜帶 [EncryptionSettings](#encryptionsettings)的場。
- **`Aes256Gcm`**: AES-256-GCM \(S/MIME only\). Carries the fields of [EncryptionSettings](#encryptionsettings).
**`Aes256Gcm`**: AES -256- GCM \(僅限 S/ MIME \)。攜帶 [EncryptionSettings](#encryptionsettings)的場。
- **`ChaCha20Poly1305`**: ChaCha20-Poly1305 \(S/MIME only\). Carries the fields of [EncryptionSettings](#encryptionsettings).
**`ChaCha20Poly1305`**: ChaCha20-Poly1305 \(僅限 S/ MIME \)。攜帶 [EncryptionSettings](#encryptionsettings)的場。
