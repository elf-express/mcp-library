# SpamFileExtension｜垃圾郵件擴展

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines a file extension classification rule for spam filtering.

 定義垃圾郵件過濾的檔案副檔名分類規則。

 This object can be configured from the WebUI under Settings › Spam Filter › Lists › File Extensions

 可以透過 WebUI下的「設定」›「垃圾郵件過濾器」›「清單」›「檔案副檔名」來設定此物件。

## Fields｜田野

##### `extension`

> Type: \\\`String\\\` · read-only

類型： \`String\` · 只讀

 The file name extension

 檔案副檔名

##### `isArchive`

> Type: \\\`Boolean\\\` · default: \\\`false\\\`

類型： \`Boolean\` · 預設值： \`false\`

 Whether this file extension is considered an archive

 該檔案副檔名是否被視為存檔

##### `isBad`

> Type: \\\`Boolean\\\` · default: \\\`false\\\`

類型： \`Boolean\` · 預設值： \`false\`

 Whether this file extension is considered bad

 這種檔案副檔名是否被認為是不好的

##### `isNz`

> Type: \\\`Boolean\\\` · default: \\\`false\\\`

類型： \`Boolean\` · 預設值： \`false\`

 Whether this file extension is considered a NZ file

 該檔案副檔名是否被視為NZ文件

##### `contentTypes`

> Type: \\\`Set<string>\\\`

類型： \`Set<string>\`

 The MIME types associated with this file extension

 與此檔案副檔名關聯的MIME類型

## JMAP API

 The SpamFileExtension object is available via the `urn:stalwart:jmap` capability.

 SpamFileExtension 物件可透過`urn:stalwart:jmap`功能取得。

### `x:SpamFileExtension/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是 [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)節5.1中定義。

 This method requires the `sysSpamFileExtensionGet` permission.

 此方法需要`sysSpamFileExtensionGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:SpamFileExtension/get",
          {
            "ids": [
              "id1"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

 這是 [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)節5.3中定義。

 Supports create, update, and destroy operations in a single call.

### `x:SpamFileExtension/query`

 This is a standard [Foo/query](https://www.rfc-editor.org/rfc/rfc8620#section-5.5) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.5), Section 5.5.

 這是 [Foo/query](https://www.rfc-editor.org/rfc/rfc8620#section-5.5)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.5)節5.5中定義。

 This method requires the `sysSpamFileExtensionQuery` permission.

 此方法需要`sysSpamFileExtensionQuery` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:SpamFileExtension/query",
          {
            "filter": {
              "extension": "example"
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

| Condition 條件 | Kind 種類 |
| --- | --- |
| `extension` | text 文本 |

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get SpamFileExtension id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create SpamFileExtension \
  --field 'contentTypes={}'
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query SpamFileExtension
stalwart-cli query SpamFileExtension --where extension=example
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update SpamFileExtension id1 --field isArchive=false
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete SpamFileExtension --ids id1
```
