# FileStorage｜文件儲存

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Configures file storage limits.

 設定檔儲存限制。

 This object can be configured from the WebUI under Settings › Files & Sharing › File Storage

 此物件可在 WebUI 「設定」&gt;「檔案與共用」&gt;「檔案儲存」中進行設定。

## Fields｜田野

##### `maxSize`

> Type: \\\`Size\\\` · default: \\\`26214400\\\`

類型： \`Size\` · 預設值： \`26214400\`

 Specifies the maximum size of a file that can be uploaded to the server

 指定可以上傳到伺服器的檔案最大大小

##### `maxFiles`

> Type: \\\`UnsignedInt?\\\` · min: 1

類型： \`UnsignedInt?\` · 最小：1

 The default maximum number of files a user can create

 使用者可建立的預設最大檔案數

##### `maxFolders`

> Type: \\\`UnsignedInt?\\\` · min: 1

類型： \`UnsignedInt?\`最小值：1

 The default maximum number of file folders a user can create

 使用者可以建立的文件資料夾的預設最大數量。

## JMAP API

 The FileStorage singleton is available via the `urn:stalwart:jmap` capability.

 FileStorage 單例可透過`urn:stalwart:jmap`功能取得。

### `x:FileStorage/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節定義。

 For singletons, the `ids` argument should be the literal `singleton` \(or `null` to return the single instance\).

 對於單例， `ids`參數應該是字面值`singleton` （或`null`以傳回單一實例）。

 This method requires the `sysFileStorageGet` permission.

 此方法需要`sysFileStorageGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:FileStorage/get",
          {
            "ids": [
              "singleton"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:FileStorage/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節定義。

 For singletons, only the `update` argument with id `singleton` is accepted; `create` and `destroy` arguments are rejected.

 對於單例，僅接受 id 為`singleton` `update`參數；拒絕`create`和`destroy`參數。

 This method requires the `sysFileStorageUpdate` permission.

 此方法需要`sysFileStorageUpdate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:FileStorage/set",
          {
            "update": {
              "singleton": {
                "maxSize": 26214400
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get FileStorage
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update FileStorage --field maxSize=26214400
```
