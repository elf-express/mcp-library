# Configuration｜配置

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[server｜伺服器\\\]\\\(&lt;000 目錄.md#c-62&gt;\\\) › \\\[tls\\\]\\\(&lt;000 目錄.md#c-65&gt;\\\) › \\\[acme｜巔峰\\\]\\\(&lt;000 目錄.md#c-66&gt;\\\)

ACME providers are registered as AcmeProvider objects \(found in the WebUI under Settings › TLS › ACME Providers\). Each provider describes where to talk to the CA, which challenge to use, and which contacts are notified. The relevant fields are:

 ACME提供者註冊為 AcmeProvider物件（可在 WebUI 的「設定」&gt; TLS &gt; ACME提供者」中找到）。每個提供者都描述如何與CA通訊、使用哪個挑戰以及通知哪些聯絡人。相關欄位如下：

- directory: the directory URL of the ACME provider. Let’s Encrypt’s production directory is `https://acme-v02.api.letsencrypt.org/directory` \(the default\); the staging directory `https://acme-staging-v02.api.letsencrypt.org/directory` is used for test runs that do not consume production rate-limit budget.
directory : URL提供ACME的目錄。 Let's Encrypt 的生產目錄是`https://acme-v02.api.letsencrypt.org/directory` （預設值）；暫存目錄`https://acme-staging-v02.api.letsencrypt.org/directory`用於不佔用生產速率限制預算的測試運行。
- challengeType: the challenge type used to validate control of each domain. One of `TlsAlpn01` \(default\), `Dns01`, `DnsPersist01`, or `Http01`. DNS-PERSIST-01 is a variant of the DNS-01 challenge that keeps the validation TXT record in place after the initial issuance so that subsequent renewals do not have to republish it; use it with DNS providers where propagation is slow or where keeping the record simplifies automation.
challengeType ：用於驗證每個域控制權的挑戰類型 （預設）、 `TlsAlpn01`或`Dns01`, `DnsPersist01` -01 是`Http01`. DNS-PERSIST -01 挑戰的變體，它在初始頒發後保留驗證TXT記錄，以便後續續期無需重新發​​布；在傳播速度較慢或保留記錄DNS以便後續續期無需將DNS
- contact: one or more contact email addresses. Used by the CA for expiry warnings and security notices.
contact : 一個或多個聯絡信箱地址。由CA用於發送到期警告和安全通知。
- renewBefore: how early renewal starts, expressed as a fraction of the remaining lifetime. Default `R23` \(two thirds of the remaining validity period has elapsed\).
renewBefore : 續期開始的提前程度，以剩餘有效期限的百分比表示。預設值為`R23` （剩餘有效期的三分之二已過去）。
- maxRetries: number of attempts before giving up on a failed challenge. Default `10`.
maxRetries : 嘗試失敗挑戰後放棄的次數。預設值為`10` 。
- eabKeyId / eabHmacKey: External Account Binding \(EAB\) credentials when the CA requires them.
eabKeyId / eabHmacKey : 當CA需要時，外部帳戶綁定 \( EAB \) 憑證。
- memberTenantId: tenant scope of the provider \(Enterprise deployments only\).
memberTenantId : 提供者的租用戶範圍（僅限企業部署）。
An AcmeProvider does not list the domains it covers. Instead, each Domain that needs an automatically managed certificate sets its certificateManagement to the `Automatic` variant, which carries an acmeProviderId reference to the AcmeProvider and an optional subjectAlternativeNames set \(leave empty to request a wildcard or the default set of SANs\). A single AcmeProvider can be referenced from any number of Domain records, so one ACME account issues certificates for many domains. ACME account keys and state are stored in the data store and need no filesystem path.
 AcmeProvider 不會列出其覆蓋的網域。相反，每個需要自動管理證書的 Domain都會將其 certificateManagement設置為`Automatic`變體，該變體包含指向 AcmeProvider 的 \[ `acmeProviderId`變體，該變體包含指向 AcmeProvider 的 subjectAlternativeNames \([https://stalw.art/docs/ref/object/domain#certificatemanagementproperties\)集（留空則請求通配符或預設的](https://stalw.art/docs/ref/object/domain#certificatemanagementproperties%2529%2525E9%25259B%252586%2525EF%2525BC%252588%2525E7%252595%252599%2525E7%2525A9%2525BA%2525E5%252589%252587%2525E8%2525AB%25258B%2525E6%2525B1%252582%2525E9%252580%25259A%2525E9%252585%25258D%2525E7%2525AC%2525A6%2525E6%252588%252596%2525E9%2525A0%252590%2525E8%2525A8%2525AD%2525E7%25259A%252584) SAN 集）。一個 AcmeProvider 可以被任意數量的 Domain 記錄引用，因此一個 ACME 帳戶可以為多個網域頒發憑證。 ACME 帳戶金鑰和狀態儲存在資料儲存中，無需檔案系統路徑。

 Default-certificate selection is made on the SystemSettings singleton through defaultCertificateId: whichever Certificate is pointed to there is served to clients that do not send SNI in their ClientHello. The AcmeProvider itself has no “default” flag; a provider becomes the default implicitly by issuing the Certificate selected via defaultCertificateId. This setting is optional, since clients negotiating with SNI pick their certificate from the domain records directly.

 預設憑證的選擇在 SystemSettings單例中透過 defaultCertificateId進行：指向此處的憑證將提供給未在其 ClientHello 中發送SNI的客戶端。 AcmeProvider 本身沒有「預設」標誌；提供者透過頒發通過 defaultCertificateId選擇的憑證而隱式成為預設提供者。此設定是可選的，因為與SNI協商的用戶端會直接從網域記錄中選擇其憑證。

- Regularly check the contact email for messages from the ACME provider.
定期查看聯絡郵箱，以獲取來自ACME提供者的消息。
- Point a new provider at the staging directory first to verify the configuration; switching to production afterwards avoids consuming the production rate-limit budget on failed runs.
首先將新的提供者指向暫存目錄以驗證配置；之後切換到生產環境可以避免在運行失敗時消耗生產環境的速率限制預算。
## DNS configuration｜DNS配置

 When challengeType is set to `Dns01` or `DnsPersist01`, Stalwart publishes the validation record through a configured DNS provider. DNS providers are registered as DnsServer objects; see DNS providers for the supported variants and the credentials each one needs.

 當 challengeType 設定為 `Dns01` 或 `DnsPersist01` 時，Stalwart 透過設定的 DNS 提供者發布驗證記錄。 DNS 提供者註冊為 DnsServer 物件；請參閱 DNS 提供者 以了解受支援的變體以及每個變體所需的憑證。

 The DNS zone used for record updates is set per domain on the Domain object. When dnsManagement is the `Automatic` variant, dnsServerId picks the DnsServer to drive and origin names the zone that carries the records \(for example, `example.com` for a domain `sub.example.com`\). Leaving origin empty uses the domain name itself as the zone. This lets several domains share one DnsServer while each pins its own zone for DNS-01 and DNS-PERSIST-01 validation.

 用於記錄更新的DNS區域是在 Domain物件上按域設定的。當 dnsManagement為`Automatic`變體時，dnsServerId選擇要驅動的 DNS 伺服器，而 \[ `origin` `example.com` \([https://stalw.art/docs/ref/object/domain#dnsmanagementproperties](https://stalw.art/docs/ref/object/domain#dnsmanagementproperties)\) ，區域名稱為`sub.example.com` ）。如果將 origin留空，則使用網域本身作為區域。這樣，多個網域就可以共用一個 DNS 伺服器，同時每個網域都可以固定自己的區域以進行DNS -01 和DNS-PERSIST -01 驗證。

## Example｜例子

 An ACME provider pointing at the Let’s Encrypt production directory and using TLS-ALPN-01:

 指向 Let's Encrypt 生產目錄並使用TLS-ALPN -01 的ACME提供者：

```json
{
  "directory": "https://acme-v02.api.letsencrypt.org/directory",
  "challengeType": "TlsAlpn01",
  "contact": {"[email protected]": true},
  "renewBefore": "R23"
}
```
