# QueuedMessage｜已排隊訊息

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Represents a queued email message pending delivery.

 表示已排隊等待發送的電子郵件。

 This object can be configured from the WebUI under Management › Emails › Queued

 此物件可在 WebUI下的「管理 › 電子郵件 › 已排隊」中進行設定。

#### QueueExpiry｜隊列過期

 Message expiry strategy for a queued recipient.

 針對已排隊接收者的消息過期策略。

**`Ttl`**: 基於TTL的過期時間。包含 [QueueExpiryTtl](#queueexpiryttl)字段。
- **`Attempts`**: Attempt-based expiry. Carries the fields of [QueueExpiryAttempts](#queueexpiryattempts).
**`Attempts`**：基於嘗試次數的過期。包含 [QueueExpiryAttempts](#queueexpiryattempts)字段。

#### RecipientStatus｜收件者狀態

 Delivery status for a queued message recipient.

 已排隊訊息接收者的投遞狀態。

- **`Scheduled`**: Delivery is pending. No additional fields.
**`Scheduled`**：出貨待處理。無需填寫其他欄位。
- **`Completed`**: Message was successfully delivered. Carries the fields of [ServerResponse](#serverresponse).
**`Completed`**: 訊息已成功送達。包含 [ServerResponse](#serverresponse)字段。
- **`TemporaryFailure`**: Delivery failed temporarily, will retry. Carries the fields of [DeliveryError](#deliveryerror).
**`TemporaryFailure`**: 暫時投遞失敗，將重試。包含 [DeliveryError](#deliveryerror)的欄位。
- **`PermanentFailure`**: Delivery failed permanently, will not retry. Carries the fields of [DeliveryError](#deliveryerror).
**`PermanentFailure`**: 投遞永久失敗，不會重試。包含 [DeliveryError](#deliveryerror)字段。

### MessageFlag｜訊息標誌

| Value 值 | Label 標籤 |
| --- | --- |
