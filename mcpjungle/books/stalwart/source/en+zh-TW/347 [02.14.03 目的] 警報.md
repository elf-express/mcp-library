# Alert｜警報

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines an alert rule triggered by metric conditions.

 定義由指標條件觸發的警報規則。

 This object is only available with an Enterprise license.

 此物件僅適用於 企業許可證 。

 This object can be configured from the WebUI under Settings › Telemetry › Alerts

 可透過 WebUI下的「設定 › 遙測 › 警報」設定此物件。

## Fields｜田野

##### `condition`

> Type: \\\[\\\`Expression\\\`\\\]\\\(#expression\\\) · required

類型：\[\`Expression\`\]\(#expression\) · 必填

 The condition that triggers the alert.

 觸發警報的條件。

##### `emailAlert`

> Type: \\\[\\\`AlertEmail\\\`\\\]\\\(#alertemail\\\) · required

類型：\[\`AlertEmail\`\]\(#alertemail\) · 必填

 Email notification settings

 電子郵件通知設定

##### `eventAlert`

> Type: \\\[\\\`AlertEvent\\\`\\\]\\\(#alertevent\\\) · required

類型：\[\`AlertEvent\`\]\(#alertevent\) · 必填

 Event notification settings

 事件通知設定

##### `enable`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Enable or disable the alert

 啟用或停用警報

## JMAP API

 The Alert object is available via the `urn:stalwart:jmap` capability.

 警報對象可透過`urn:stalwart:jmap`功能取得。

### `x:Alert/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是 [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)節5.1中定義。

 This method requires the `sysAlertGet` permission.

 此方法需要`sysAlertGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:Alert/get",
          {
            "ids": [
              "id1"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:Alert/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節定義。

 Supports create, update, and destroy operations in a single call.

 支援在一次呼叫中執行建立、更新和銷毀操作。

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get Alert id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create Alert \
  --field 'condition={"else":"Example"}' \
  --field 'emailAlert={"@type":"Disabled"}' \
  --field 'eventAlert={"@type":"Disabled"}'
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query Alert
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update Alert id1 --field condition='{"else":"Example"}'
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete Alert --ids id1
```

### AlertEmail｜提醒郵件

 Defines email notification settings for alerts.

 設定警報的電子郵件通知選項。

- **`Disabled`**: Disabled. No additional fields.
**`Disabled`**：已停用。無其他字段。
- **`Enabled`**: Enabled. Carries the fields of [AlertEmailProperties](#alertemailproperties).
**`Enabled`**: 已啟用。攜帶 [AlertEmailProperties](#alertemailproperties)的場。
