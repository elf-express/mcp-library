# Reference｜參考

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[sieve｜篩\\\]\\\(&lt;000 目錄.md#c-67&gt;\\\)

Stalwart extends Sieve with a set of built-in functions that can be called from expressions inside `eval`, `let`, and `while` instructions. The functions operate on Sieve values \(strings, integers, floats, arrays\) and on the message being processed: headers, MIME parts, envelope, and environment.

 Stalwart 為 Sieve 擴展了一組內建函數，這些函數可以從 表達式內部調用，也可以在`eval`, `let`和`while`指令中調用。這些函數可以操作 Sieve 值（字串、整數、浮點數、陣列）以及正在處理的訊息：頭部、 MIME部分、信封和環境。

 Some functions are available only to the trusted interpreter, which runs scripts installed by the administrator at an SMTP stage. The untrusted interpreter runs user-created scripts and exposes a smaller subset, excluding functions that touch external systems \(DNS, HTTP, SQL, key-value stores, external programs\) or that inspect parts of the message that are not relevant to per-user filtering. Each entry below notes when a function is restricted to trusted scripts.

 某些功能僅對受信任解釋器可用，該解釋器運行管理員在SMTP階段安裝的腳本。 不受信任解釋器運行使用者建立的腳本，並公開一個較小的子集，其中排除了涉及外部系統（ DNS, HTTP, SQL ，鍵值儲存、外部程式）或檢查與使用者過濾無關的訊息部分的函數。以下每個條目都註明了某個功能何時僅限於受信任腳本。

 The `vnd.stalwart.expressions` extension must be declared in a `require` statement before these functions can be used.

 必須先在`require`語句中宣告`vnd.stalwart.expressions`擴展，才能使用這些函數。

## Text functions｜文字功能

### `trim`

 Removes whitespace from both ends of a string.

 刪除字串兩端的空格。

- **Arguments**: 1 \(String or Array\)
**參數**：1 個（字串或陣列）
- **Example**: `let "name" "trim(header.subject)"` removes leading and trailing whitespace from the subject line.
**範例**： `let "name" "trim(header.subject)"`刪除主旨行開頭和結尾的空格。
### `trim_start`, `trim_end`

 Removes whitespace from the start or the end of a string.

 刪除字串開頭或結尾的空格。

- **Arguments**: 1 \(String or Array\)
**參數**：1 個（字串或陣列）
- **Example**: `let "clean" "trim_end(header.subject)"`.
**範例**： `let "clean" "trim_end(header.subject)"` 。
### `len`

 Returns the length in bytes for strings, or the number of elements for arrays.

 傳回字串的位元組長度，或陣列的元素數量。

- **Arguments**: 1 \(String or Array\)
**參數**：1 個（字串或陣列）
- **Example**: `if eval "len(header.subject) > 200" { ... }` detects unusually long subject lines.
**範例**： `if eval "len(header.subject) > 200" { ... }`偵測異常長的郵件主旨行。
### `to_lowercase`, `to_uppercase`

 Converts a string to lowercase or uppercase.

 將字串轉換為小寫或大寫。

- **Arguments**: 1 \(String or Array\)
**參數**：1 個（字串或陣列）
- **Example**: `let "domain" "to_lowercase(email_part(envelope.from, 'domain'))"`.
**範例**： `let "domain" "to_lowercase(email_part(envelope.from, 'domain'))"` 。
### `is_lowercase`, `is_uppercase`

 Returns `true` when every alphabetic character in the string is lowercase or uppercase. Non-alphabetic characters are ignored.

 當字串中的所有字母字元均為小寫或大寫時，傳回`true` 。非字母字元將被忽略。

- **Arguments**: 1 \(String or Array\)
**參數**：1 個（字串或陣列）
- **Example**: `if eval "is_uppercase(header.subject)" { addflag "$screaming"; }`.
**範例**： `if eval "is_uppercase(header.subject)" { addflag "$screaming"; }` 。
### `is_ascii`

 Returns `true` when the value is a pure-ASCII string, integer, or float. For arrays, returns `true` when every string element is ASCII.

 當值為純ASCII 、整數或浮點數時，傳回`true` 。對於數組，當每個字串元素都是ASCII時，傳回`true` 。

- **Arguments**: 1 \(String, Number, or Array\)
**參數**：1 個（字串、數字或陣列）
- **Example**: `if eval "!is_ascii(header.subject)" { ... }` fires for a subject containing non-ASCII text.
**範例**： `if eval "!is_ascii(header.subject)" { ... }`會針對包含非ASCII文字的主題觸發。
### `has_digits`

 Returns `true` when the string contains at least one ASCII digit.

 當字串包含至少一個數字時，回傳`true` ... ASCII

- **Arguments**: 1 \(String or Array\)
**參數**：1 個（字串或陣列）
- **Example**: `if eval "has_digits(envelope.from)" { ... }`.
**範例**： `if eval "has_digits(envelope.from)" { ... }` 。
### `count_chars`

 Counts the number of Unicode characters in a string.

 計算字串中Unicode字元的數量。

- **Arguments**: 1 \(String\)
**參數**：1（字串）
- **Example**: `count_chars('héllo')` returns `5`.
**範例**： `count_chars('héllo')`回傳`5` 。
### `count_spaces`, `count_uppercase`, `count_lowercase`

 Count whitespace, uppercase alphabetic, or lowercase alphabetic characters.

 統計空格、大寫字母或小寫字母的數量。

- **Arguments**: 1 \(String\)
**參數**：1（字串）
- **Example**: `if eval "count_uppercase(header.subject) > 20" { addflag "$screaming"; }`.
**範例**： `if eval "count_uppercase(header.subject) > 20" { addflag "$screaming"; }` 。
### `contains`

 Returns `true` when the first argument contains the second. For arrays, element equality is used instead of substring search.

 當第一個參數包含第二個參數時，回傳`true` 。對於數組，使用元素相等性而非子字串搜尋。

- **Arguments**: 2 \(String or Array, Substring or Element\)
**參數**：2 個（字串或數組，子字串或元素）
- **Example**: `if eval "contains(header.subject, 'INVOICE')" { ... }`.
**範例**： `if eval "contains(header.subject, 'INVOICE')" { ... }` 。
### `contains_ignore_case`

 Like `contains`, but compares case-insensitively.

 與`contains`類似，但不區分大小寫進行比較。

- **Arguments**: 2 \(String or Array, Substring or Element\)
**參數**：2 個（字串或數組，子字串或元素）
### `eq_ignore_case`

 Compares two strings for equality, ignoring ASCII case.

 比較兩個字串是否相等，忽略ASCII情況。

- **Arguments**: 2 \(String, String\)
**參數**：2（字串，字串）
- **Example**: `if eval "eq_ignore_case(env.helo_domain, 'mail.example.org')" { ... }`.
**範例**： `if eval "eq_ignore_case(env.helo_domain, 'mail.example.org')" { ... }` 。
### `starts_with`, `ends_with`

 Returns `true` when the first string starts or ends with the second.

 當第一個字串以第二個字串開頭或結尾時，回傳`true` 。

- **Arguments**: 2 \(String, Prefix or Suffix\)
**參數**：2 個（字串、前綴或後綴）
- **Example**: `if eval "ends_with(email_part(envelope.from, 'domain'), '.example.org')" { ... }`.
**範例**： `if eval "ends_with(email_part(envelope.from, 'domain'), '.example.org')" { ... }` 。
### `strip_prefix`, `strip_suffix`

 Removes the given prefix or suffix from a string. Returns the empty string when the affix is not present.

 從字串中移除指定的前綴或後綴。如果字串中不存在指定的前綴或後綴，則傳回空字串。

- **Arguments**: 2 \(String, Affix\)
**參數**：2（字串，詞綴）
- **Example**: `let "tenant" "strip_suffix(email_part(envelope.to, 'domain'), '.example.org')"`.
**範例**： `let "tenant" "strip_suffix(email_part(envelope.to, 'domain'), '.example.org')"` 。
### `substring`

 Extracts a substring by character position. The second argument is the zero-based start index; the third is the number of characters to take.

 根據字元位置提取子字串。第二個參數是從零開始的起始索引；第三個參數是要擷取的字元數。

- **Arguments**: 3 \(String, Start, Count\)
**參數**：3 個（字串、起始值、計數）
- **Example**: `let "prefix" "substring(header.subject, 0, 10)"`.
**範例**： `let "prefix" "substring(header.subject, 0, 10)"` 。
### `lines`

 Splits a string into an array on newline boundaries.

 將字串依換行符號分割成陣列。

- **Arguments**: 1 \(String\)
**參數**：1（字串）
### `split`, `rsplit`

 Splits a string on every occurrence of a delimiter. `rsplit` returns the array ordered from right to left.

 在每次出現分隔符號時分割字串。 `rsplit` 傳回從右到左排序的陣列。

- **Arguments**: 2 \(String, Delimiter\)
**參數**：2（字串，分隔符號）
- **Example**: `let "labels" "rsplit(email_part(envelope.to, 'domain'), '.')"` yields `['org', 'example', 'mx1']` for `mx1.example.org`.
**範例**： `let "labels" "rsplit(email_part(envelope.to, 'domain'), '.')"`產生`['org', 'example', 'mx1']` ，其中`mx1.example.org` 。
### `split_once`, `rsplit_once`

 Splits a string at the first or the last occurrence of the delimiter and returns the two parts as a two-element array. Returns the empty string when the delimiter is not found.

 在分隔符號首次或最後一次出現時分割字串，並將分割後的兩部分作為包含兩個元素的陣列傳回。如果未找到分隔符，則傳回空字串。

- **Arguments**: 2 \(String, Delimiter\)
**參數**：2（字串，分隔符號）
### `split_n`

 Splits a string at most `n` times. The final element contains any remaining input, including further occurrences of the delimiter.

 最多將字串分割`n`次。最後一個元素包含所有剩餘的輸入，包括分隔符號的後續出現。

- **Arguments**: 3 \(String, Delimiter, Max Splits\)
**參數**：3 個（字串、分隔符號、最大分割數）
- **Example**: `split_n('a,b,c,d', ',', 2)` returns `['a', 'b', 'c,d']`.
**範例**： `split_n('a,b,c,d', ',', 2)`回傳`['a', 'b', 'c,d']` 。
### `thread_name`

 Returns the thread name of the subject by stripping reply/forward prefixes \(`Re:`, `Fwd:`, language variants\) and normalising whitespace. Used to group related messages.

 返回主題的線程名稱，去除回复/轉發前綴（ `Re:`, `Fwd:` ，語言變體）並規範化空格。用於對相關訊息進行分組。

- **Arguments**: 1 \(String\)
**參數**：1（字串）
- **Example**: `let "subject" "thread_name(header.subject)"`.
**範例**： `let "subject" "thread_name(header.subject)"` 。
### `html_to_text`

 Converts an HTML string to its plain-text equivalent.

 將HTML字串轉換為其純文字等效項。

- **Arguments**: 1 \(String\)
**參數**：1（字串）
- **Example**: `let "body" "html_to_text(body.to_html)"`.
**範例**： `let "body" "html_to_text(body.to_html)"` 。
### `detect_language` *\(trusted only\)*｜`detect_language` *\(僅限受信任使用者\)*

 Returns the two-letter ISO 639-1 language code detected for a string, or `"unknown"` if no language could be determined.

 傳回偵測到的字串的雙字母語言代碼ISO 639-1，如果無法確定語言，則傳回`"unknown"` 。

- **Arguments**: 1 \(String\)
**參數**：1（字串）
- **Example**: `if eval "detect_language(body.to_text) == 'ru'" { fileinto "russian"; }`.
**範例**： `if eval "detect_language(body.to_text) == 'ru'" { fileinto "russian"; }` 。
### `levenshtein_distance` *\(trusted only\)*｜`levenshtein_distance` *\(僅限受信任使用者\)*

 Returns the Levenshtein edit distance between two strings.

 傳回兩個字串之間的萊文斯坦編輯距離。

- **Arguments**: 2 \(String, String\)
**參數**：2（字串，字串）
- **Example**: `if eval "levenshtein_distance(to_lowercase(envelope.to), '[[email protected]](https://stalw.art/cdn-cgi/l/email-protection)') <= 2" { ... }` catches recipient typosquatting.
**範例**： `if eval "levenshtein_distance(to_lowercase(envelope.to), '[[email protected]](https://stalw.art/cdn-cgi/l/email-protection)') <= 2" { ... }`偵測到收件者網域拼字錯誤。
### `cosine_similarity` *\(trusted only\)*｜`cosine_similarity` *\(僅限受信任使用者\)*

 Returns a float in `[0, 1]` representing the cosine similarity of two values. Arrays are compared as bags of elements; strings are compared as bags of characters.

 傳回一個`[0, 1]`類型的浮點數，表示兩個值的餘弦相似度。陣列按元素包進行比較；字串按字元包進行比較。

- **Arguments**: 2 \(Array or String, Array or String\)
**參數**：2 個（陣列或字串，陣列或字串）
### `jaccard_similarity` *\(trusted only\)*｜`jaccard_similarity` *\(僅限受信任使用者\)*

 Returns a float in `[0, 1]` representing the Jaccard similarity \(intersection over union\) of two values. Arrays are compared as sets of elements; strings as sets of characters.

 傳回一個`[0, 1]`浮點數，表示兩個值的 Jaccard 相似度（交集比並集）。數組按元素集合進行比較；字串按字元集合進行比較。

- **Arguments**: 2 \(Array or String, Array or String\)
**參數**：2 個（陣列或字串，陣列或字串）
## Array functions｜數組函數

### `count`

 Returns the number of elements in an array. For non-array values, returns `1` when the value is non-empty and `0` otherwise.

 傳回數組中元素的數量。對於非數組值，當值非空時回傳`1` ，否則回傳`0` 。

- **Arguments**: 1 \(Array\)
**參數**：1（陣列）
- **Example**: `if eval "count(recipients) > 100" { ... }`.
**範例**： `if eval "count(recipients) > 100" { ... }` 。
### `sort`

 Returns a sorted copy of the input array. The second argument is `true` for ascending order and `false` for descending.

 傳回輸入數組的排序副本。第二個參數`true`表示升序排列， `false`表示降序排列。

- **Arguments**: 2 \(Array, Ascending\)
**參數**：2（數組，升序）
- **Example**: `sort(['z', 'a', 'b'], true)` returns `['a', 'b', 'z']`.
**範例**： `sort(['z', 'a', 'b'], true)`回傳`['a', 'b', 'z']` 。
### `dedup`

 Returns a copy of the array with duplicate elements removed, preserving the original order.

 傳回數組的副本，其中刪除了重複元素，並保留了原始順序。

- **Arguments**: 1 \(Array\)
**參數**：1（陣列）
### `winnow`

 Returns a copy of the array with empty elements removed.

 傳回一個已刪除空元素的陣列副本。

- **Arguments**: 1 \(Array\)
**參數**：1（陣列）
### `is_intersect`

 Returns `true` when the two arrays share at least one element. When one of the arguments is a scalar, checks whether the value is contained in the other array.

 當兩個數組至少有一個元素相同時，回傳`true` 。當其中一個參數是標量時，檢查該值是否包含在另一個陣列中。

- **Arguments**: 2 \(Array, Array\)
**參數**：2（數組，數組）
- **Example**: `if eval "is_intersect(header.to[*], ['[[email protected]](https://stalw.art/cdn-cgi/l/email-protection)', '[[email protected]](https://stalw.art/cdn-cgi/l/email-protection)'])" { ... }`.
**範例**： `if eval "is_intersect(header.to[*], ['[[email protected]](https://stalw.art/cdn-cgi/l/email-protection)', '[[email protected]](https://stalw.art/cdn-cgi/l/email-protection)'])" { ... }` 。
## Email functions｜電子郵件功能

### `is_email`

 Returns `true` when the input string is a syntactically valid email address.

 當輸入字串是語法上有效的電子郵件地址時，回傳`true` 。

- **Arguments**: 1 \(String\)
**參數**：1（字串）
### `email_part`

 Extracts either the local part or the domain of an email address. The second argument must be the literal string `'local'` or `'domain'`; any other value returns the empty string.

 提取電子郵件地址的本地部分或網域名稱。第二個參數必須是字串字面值`'local'`或`'domain'` ；任何其他值都會傳回空字串。

- **Arguments**: 2 \(Email, Part\)
**論點**：2（電子郵件，部分）
- **Example**: `let "from_domain" "email_part(envelope.from, 'domain')"`.
**範例**： `let "from_domain" "email_part(envelope.from, 'domain')"` 。
### `domain_part` *\(trusted only\)*｜`domain_part` *\(僅限受信任使用者\)*

 Extracts a part of a domain name. The second argument selects which part to return:

 提取網域名稱的一部分。第二個參數指定要傳回的部分：

- `sld`: the second-level domain as recognised by the public suffix list. For `mail.example.co.uk`, returns `example.co.uk`.
`sld` ：公共後綴清單所識別的二級域名。對於`mail.example.co.uk` ，回傳`example.co.uk` 。
- `tld`: the top-level domain only. Returns the last dot-separated label, for example `uk`.
`tld` ：僅返回頂級網域。傳回最後一個以點分隔的標籤，例如`uk` 。
- `host`: the leftmost label. For `mail.example.org`, returns `mail`.
`host` ：最左邊的標籤。對於`mail.example.org` ，回傳`mail` 。
- **Arguments**: 2 \(Domain, Part\)
**論證**：2（域，部分）
- **Example**: `let "org_domain" "domain_part(email_part(envelope.from, 'domain'), 'sld')"`.
**範例**： `let "org_domain" "domain_part(email_part(envelope.from, 'domain'), 'sld')"` 。


## URL functions｜URL功能

### `uri_part`

 Extracts a component of a URI. The second argument selects which component:

 提取URI的一個組成部分。第二個參數選擇要擷取的組成部分：

- `scheme`, `host`, `port`, `path`, `query`, `authority`, `path_query`: the corresponding URI component.
`scheme`, `host`, `port`, `path`, `query`, `authority`, `path_query` ：對應的URI組件。
- `scheme_host`: `scheme://host`, useful for building the origin of a URL.
`scheme_host`: `scheme://host` ，用於建構URL的原點。
Returns the empty string when the argument does not parse as a URI or when the requested component is missing.
 當參數無法解析為URI或請求的元件缺失時，傳回空字串。

- **Arguments**: 2 \(URI, Part\)
**論點**：2（ URI ，部分）
- **Example**: `let "origin" "uri_part(header['list-unsubscribe'], 'scheme_host')"`.
**範例**： `let "origin" "uri_part(header['list-unsubscribe'], 'scheme_host')"` 。
### `puny_decode` *\(trusted only\)*｜`puny_decode` *\(僅限受信任使用者\)*

 Decodes Punycode-encoded \(`xn--`\) labels in a domain name. Labels that are not Punycode-encoded pass through unchanged.

 解碼網域中以 Punycode 編碼（ `xn--` ）的標籤。未以 Punycode 編碼的標籤將保持不變。

- **Arguments**: 1 \(String\)
**參數**：1（字串）
- **Example**: `let "readable" "puny_decode(env.helo_domain)"`.
**範例**： `let "readable" "puny_decode(env.helo_domain)"` 。
## Unicode-safety functions *\(trusted only\)*｜Unicode 安全函數 *（僅受信任）*

 These functions help detect abuse of Unicode to confuse recipients or evade text-matching filters.

 這些功能有助於偵測濫用 Unicode 來迷惑收件者或規避文字匹配過濾器的行為。

### `has_zwsp`

 Returns `true` when the string contains at least one zero-width or invisible separator \(U+200B, U+200C, U+200D, U+FEFF, U+00AD\).

 當字串包含至少一個零寬度或不可見分隔符號（U+200B、U+200C、U+200D、U+ FEFF 、U+00AD）時，傳回`true` 。

- **Arguments**: 1 \(String or Array\)
**參數**：1 個（字串或陣列）
### `has_obscured`

 Returns `true` when the string contains a character from one of the directional-override or formatting ranges \(U+200B–U+200F, U+2028–U+202F, U+205F–U+206F, U+FEFF\) that can be used to hide or reorder text.

 當字串包含來自方向覆蓋或格式化範圍（U+200B–U+200F、U+2028–U+202F、U+205F–U+206F、U+ FEFF ）的字元時，傳回`true`該範圍可用於隱藏或重新排列文字。

- **Arguments**: 1 \(String or Array\)
**參數**：1 個（字串或陣列）
### `is_mixed_charset`

 Returns `true` when the string mixes characters from scripts that should not normally co-occur \(for example Latin and Cyrillic letters in the same word\), a common indicator of a homograph attack.

 當字串混合了通常不應該同時出現的腳本字元（例如，同一個單字中同時出現拉丁字母和西里爾字母）時，會傳回`true` ，這是同形異義字攻擊的常見指標。

- **Arguments**: 1 \(String\)
**參數**：1（字串）
### `cure_text`

 Returns a cleaned copy of the string with confusable, invisible, and zalgo characters removed or normalised.

 傳回經過清理的字串副本，其中已刪除或規範化了易混淆字元、不可見字元和 Zalgo 字元。

- **Arguments**: 1 \(String\)
**參數**：1（字串）
### `unicode_skeleton`

### `is_ip_in_cidr` *\(trusted only\)*｜`is_ip_in_cidr` *\(僅限受信任使用者\)*

 Returns `true` when the first argument is an IP address that falls inside the network described by the second argument. The network argument accepts either a CIDR block \(`10.0.0.0/8`, `2001:db8::/32`\) or a bare IP address, in which case the function is an exact-match check.  當第一個參數是位於第二個參數所描述的網路內的IP時，會傳回`true` 。網路參數可以接受一個位址區塊（ CIDR ）或一個裸位址IP `10.0.0.0/8`, `2001:db8::/32` ，在這種情況下，該函數會進行精確匹配檢查。 IPv4 映射的 IPv6 位址（ `::ffff:1.2.3.4` ）可以與 IPv4 網路正確匹配，反之亦然。兩個參數都必須能夠正確解析；格式錯誤的值將會回傳`false` 。

- **Arguments**: 2 \(IP Address, CIDR or IP Address\)

**範例**： `if eval "is_ip_in_cidr(env.remote_ip, '10.0.0.0/8') || is_ip_in_cidr(env.remote_ip, '192.168.0.0/16')" { ... }`識別來自RFC 1918 範圍的連接，當TLS終止的反向代理位於SMTP監聽器前面時很有用，並且通常適用於連接埠 25 的特殊處理需要根據原始來源重新應用。

## DNS functions *\(trusted only\)*｜DNS 功能 *（僅限可信）*

### `dns_query`

 Performs a DNS query for the given name and record type. Supported record types are `ipv4`, `ipv6`, `ip` \(IPv4 with IPv6 fallback\), `mx`, `txt`, and `ptr`. For `ptr`, the first argument must parse as an IP address.

**參數**：2（名稱，記錄類型）
- **Example**: DNSBL lookup against Spamhaus Zen:
**範例**： DNSBL在 Spamhaus Zen 中尋找：


## SQL queries *\(trusted only\)*｜SQL 查詢 *（僅限可信）*

### `query`

 Runs a SQL statement against a data store of type SQL. If the first argument is the empty string, the default data store is used. The third argument binds parameters to the query’s placeholders, in order. The query is passed to the database driver verbatim, so the statement must use the configured database’s native placeholder syntax: `?` for SQLite and MySQL, and `$1`, `$2`, … for PostgreSQL.

 對型別為SQL的資料儲存執行SQL語句。如果第一個參數為空字串，則使用預設資料儲存。第三個參數依序將參數綁定到查詢的佔位符。查詢將原樣傳遞給資料庫驅動程序，因此語句必須使用已配置資料庫的原生佔位符語法：SQLite 和 MySQL 使用`?` ，PostgreSQL 使用`$1`, `$2`等。

 A `SELECT` returning exactly one row and one column returns the scalar value; a `SELECT` returning a single row with multiple columns returns that row as an array; multiple rows return an array of arrays. A non-`SELECT` statement returns `true` on success.

 傳回一行一列的`SELECT`傳回標量值；傳回多`true`的單行的`SELECT`傳回`SELECT`行為陣列；傳回多行的單行的單列 ...

- **Arguments**: 3 \(Store ID, Query, Parameters\)
**參數**：3（儲存ID 、查詢、參數）
- **Example**: greylisting triplet \(the `?` placeholders below are for SQLite or MySQL; on PostgreSQL use `$1`, `$2`, …\):
**範例**：灰名單三元組（以下`?`佔位符適用於 SQLite 或 MySQL；在 PostgreSQL 中使用`$1`, `$2` ，…）：

```sieve
require ["variables", "vnd.stalwart.expressions", "envelope", "reject"];

  set "triplet" "${env.remote_ip}.${envelope.from}.${envelope.to}";
  if eval "!query('sql', 'SELECT 1 FROM greylist WHERE addr=? LIMIT 1', [triplet])" {
      eval "query('sql', 'INSERT INTO greylist (addr) VALUES (?)', [triplet])";
      reject "422 4.2.2 Greylisted, please try again in a few moments.";
  }
```
