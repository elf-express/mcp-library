# ASN and GeoIP｜ASN和 GeoIP

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[server｜伺服器\\\]\\\(&lt;000 目錄.md#c-62&gt;\\\)

An Autonomous System Number \(ASN\) identifies the network operator responsible for a range of IP addresses. GeoIP data maps IP addresses to a country, region, or city. Together, these sources describe who operates an address and where it is located, allowing incoming connections to be classified by network and geography.

 自治系統編號 \( ASN \) 用於標識負責一系列IP位址的網路營運商。 GeoIP 資料將IP位址對應到國家、地區或城市。這些資訊共同描述了地址的運營商及其所在位置，從而可以按網路和地理位置對傳入連接進行分類。

 Stalwart uses ASN and GeoIP information in several places. The spam filter tracks reputation metrics by IP, sender, domain, and ASN, and the spam classifier incorporates the same data during training. When processing messages, the server includes ASN and GeoIP details in the `Received` header so that message paths can be audited after the fact.

 Stalwart 在多個地方使用ASN和 GeoIP 資訊。垃圾郵件過濾器\([https://stalw.art/docs/spamfilter/\)透過IP](https://stalw.art/docs/spamfilter/%2529%2525E9%252580%25258F%2525E9%252581%25258EIP) 、寄件者、網域名稱和ASN追蹤信譽指標，垃圾郵件分類器在訓練過程中也使用相同的資料。處理郵件時，伺服器會在`Received`標頭中包含ASN和 GeoIP 詳細信息，以便事後審核郵件路徑。

 Two data-loading strategies are supported. The preferred approach downloads CSV files from HTTP resources, which keeps ASN-to-IP and country-to-IP mappings current. A DNS-based alternative queries TXT records exposed by services such as Team Cymru; this mode is useful where outbound HTTP is restricted but carries slightly less detail.

 支援兩種資料載入策略。首選方法從HTTP資源下載CSV文件，從而保持ASN到IP以及國家/地區到IP映射關係最新。另一種基於DNS的替代方法查詢TXT由 Team Cymru 等服務公開的記錄；此模式適用於出站HTTP受限但包含略少細節的情況。

## Configuration｜配置

 ASN and GeoIP data sources are configured through the Asn singleton \(found in the WebUI under Settings › Network › ASN & GeoIP\). The object is multi-variant: each instance selects one of `Disabled`, `Resource`, or `Dns`, and the chosen variant determines which fields apply.

 ASN和 GeoIP 資料來源透過 Asn單例進行設定（可在 WebUI 的「設定」&gt;「網路」&gt; ASN和 GeoIP」中找到）。該物件是多變體的：每個實例選擇`Disabled`, `Resource`或`Dns`之一，所選變體決定應用哪些欄位。

### HTTP resources｜HTTP資源

 The `Resource` variant downloads CSV data files over HTTP. It exposes the following fields:

`Resource`變體下載CSV資料文件，覆蓋HTTP資料檔。它公開以下字段：

- asnUrls: URLs of the CSV files that contain IP-to-ASN mappings.
asnUrls : 包含IP到ASN映射的CSV檔案的 URL。
- geoUrls: URLs of the CSV files that contain IP-to-country mappings.
geoUrls : 包含IP到國家/地區映射的CSV文件的 URL。
- expires: refresh interval for downloaded data, in milliseconds. Default one day \(`86400000`\).
expires : 下載資料的刷新間隔，以毫秒為單位。預設值為一天 \( `86400000` \)。
- timeout: maximum time to wait for a fetch, in milliseconds. Default five minutes \(`300000`\).
timeout : 等待取得資料的最大時間，以毫秒為單位。預設值為五分鐘 \( `300000` \)。
- maxSize: maximum size accepted for a downloaded file, in bytes. Default 100 MiB \(`104857600`\).
maxSize : 下載檔案可接受的最大大小，以位元組為單位。預設值為 100 MiB \( `104857600` \)。
- httpAuth: HTTP authentication method \(`Unauthenticated`, `Basic`, or `Bearer`\).
httpAuth: HTTP身份驗證方法（ `Unauthenticated`, `Basic`或`Bearer` ）。
- httpHeaders: additional HTTP headers sent with each request.
httpHeaders : 隨每個請求發送的附加HTTP標頭。
For example:
 例如：

```json
{
  "@type": "Resource",
  "expires": 86400000,
  "timeout": 300000,
  "maxSize": 104857600,
  "asnUrls": {
    "https://github.com/sapics/ip-location-db/releases/download/latest/origin-asn-ipv4.csv": true,
    "https://github.com/sapics/ip-location-db/releases/download/latest/origin-asn-ipv6.csv": true
  },
  "geoUrls": {
    "https://github.com/sapics/ip-location-db/releases/download/latest/user-country-ipv4.csv": true,
    "https://github.com/sapics/ip-location-db/releases/download/latest/user-country-ipv6.csv": true
  },
  "httpAuth": {"@type": "Unauthenticated"}
}
```

### DNS queries｜DNS查詢

 The `Dns` variant queries TXT records from a zone that exposes ASN and geolocation data \(for example Team Cymru’s `origin.asn.cymru.com` and `origin6.asn.cymru.com`\). Its fields are:

`Dns`變體查詢來自公開ASN和地理位置資料（例如 Team Cymru 的`origin.asn.cymru.com`和`origin6.asn.cymru.com` ）的區域的TXT記錄。其字段包括：

- zoneIpV4: DNS zone queried for IPv4 addresses.
zoneIpV4: DNS區域已查詢 IPv4 位址。
- zoneIpV6: DNS zone queried for IPv6 addresses.
zoneIpV6: DNS區域已查詢 IPv6 位址。
- separator: character that separates fields in the TXT record. Default `"|"`.
separator : 分隔TXT記錄中欄位的字元。預設值為`"|"` 。
- indexAsn: zero-based position of the ASN field. Default `0`.
indexAsn : ASN字段的從零開始的位置。預設值為`0` 。
- indexAsnName: position of the ASN name field.
indexAsnName : ASN名稱欄位的位置。
- indexCountry: position of the country-code field.
indexCountry : 國家代碼欄位的位置。
For example:
 例如：

```json
{
  "@type": "Dns",
  "separator": "|",
  "zoneIpV4": "origin.asn.cymru.com",
  "zoneIpV6": "origin6.asn.cymru.com",
  "indexAsn": 0,
  "indexAsnName": 1,
  "indexCountry": 2
}
```

### Disabling lookups｜禁用查找

 Selecting the `Disabled` variant turns off both ASN and GeoIP resolution.

 選擇`Disabled`變體將關閉ASN和 GeoIP 解析度。
