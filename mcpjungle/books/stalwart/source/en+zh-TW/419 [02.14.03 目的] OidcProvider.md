# OidcProvider

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Configures the OAuth and OpenID Connect provider settings.

 設定 OAuth 和 OpenID Connect 提供者設定。

 This object can be configured from the WebUI under Settings › Authentication › OIDC Provider

 此物件可在 WebUI下的「設定」›「驗證」› OIDC 「提供者」中進行設定。

## Fields｜田野

##### `authCodeMaxAttempts`

> Type: \\\`UnsignedInt\\\` · default: \\\`3\\\` · min: 1 · max: 1000

類型： \`UnsignedInt\` · 預設值： \`3\` · 最小值：1 · 最大值：1000

 Number of failed login attempts before an authorization code is invalidated

 授權碼失效前允許的登入失敗次數

##### `anonymousClientRegistration`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Whether to allow OAuth clients to register without authentication

 是否允許 OAuth 用戶端在未經身份驗證的情況下註冊

##### `requireClientRegistration`

> Type: \\\`Boolean\\\` · default: \\\`false\\\`

類型： \`Boolean\` · 預設值： \`false\`

 Whether to require OAuth client\\\_ids to be registered before they can be used

 是否要求在使用 OAuth 客戶端 ID 之前必須先註冊它們

##### `authCodeExpiry`

> Type: \\\`Duration\\\` · default: \\\`600000\\\`

類型： \`Duration\` · 預設值： \`600000\`

 Expiration time of an authorization code issued by the authorization code flow

 授權碼流所頒發的授權碼的有效期限

##### `refreshTokenExpiry`

> Type: \\\`Duration\\\` · default: \\\`2592000000\\\`

類型： \`Duration\` · 預設值： \`2592000000\`

 Expiration time of an OAuth refresh token

 OAuth刷新令牌的過期時間

##### `refreshTokenRenewal`

> Type: \\\`Duration\\\` · default: \\\`345600000\\\`

類型： \`Duration\` · 預設值： \`345600000\`

 Remaining time in a refresh token before a new one is issued to the client

 刷新令牌剩餘的有效期，超過剩餘時間將向客戶端頒發新的刷新令牌。

##### `accessTokenExpiry`

> Type: \\\`Duration\\\` · default: \\\`3600000\\\`

類型： \`Duration\` · 預設值： \`3600000\`

 Expiration time of an OAuth access token

 OAuth 存取令牌的過期時間

##### `userCodeExpiry`

> Type: \\\`Duration\\\` · default: \\\`1800000\\\`

類型： \`Duration\` · 預設值： \`1800000\`

 Expiration time of a user code issued by the device authentication flow

 設備認證流程所頒發的使用者代碼的有效期限

##### `idTokenExpiry`

> Type: \\\`Duration\\\` · default: \\\`900000\\\`

類型： \`Duration\` · 預設值： \`900000\`

 Expiration time of an OpenID Connect ID token

 OpenID Connect ID令牌的過期時間

##### `encryptionKey`

> Type: \\\[\\\`SecretKey\\\`\\\]\\\(#secretkey\\\) · required

類型：\[\`SecretKey\`\]\(#secretkey\) · 必填

 Encryption key to use for OAuth

 用於 OAuth 的加密金鑰

##### `signatureAlgorithm`

> Type: \\\[\\\`JwtSignatureAlgorithm\\\`\\\]\\\(#jwtsignaturealgorithm\\\) · default: \\\`"hs256"\\\`

類型：\[\`JwtSignatureAlgorithm\`\]\(#jwtsignaturealgorithm\) · 預設值： \`"hs256"\`

 JWT signature algorithm to use for OpenID Connect.

 JWT OpenID Connect 使用的簽章演算法。

##### `signatureKey`

> Type: \\\[\\\`SecretText\\\`\\\]\\\(#secrettext\\\) · required

類型：\[\`SecretText\`\]\(#secrettext\) · 必填

 Contents of the private key PEM used to sign JWTs for OpenID Connect.

 用於簽署 OpenID Connect 的 JWT 的私鑰PEM的內容。

## JMAP API

 The OidcProvider singleton is available via the `urn:stalwart:jmap` capability.

 OidcProvider 單例可透過`urn:stalwart:jmap`功能取得。

### `x:OidcProvider/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節定義。

 For singletons, the `ids` argument should be the literal `singleton` \(or `null` to return the single instance\).

 對於單例， `ids`參數應該是字面值`singleton` （或`null`以傳回單一實例）。

 This method requires the `sysOidcProviderGet` permission.

 此方法需要`sysOidcProviderGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:OidcProvider/get",
          {
            "ids": [
              "singleton"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:OidcProvider/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節定義。

 For singletons, only the `update` argument with id `singleton` is accepted; `create` and `destroy` arguments are rejected.

 對於單例，僅接受 id 為`singleton`的`update`參數；拒絕`create`和`destroy`參數。

 This method requires the `sysOidcProviderUpdate` permission.

 此方法需要`sysOidcProviderUpdate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:OidcProvider/set",
          {
            "update": {
              "singleton": {
                "authCodeMaxAttempts": 3
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```
