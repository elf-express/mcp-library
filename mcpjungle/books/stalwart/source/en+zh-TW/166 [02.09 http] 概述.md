# Overview｜概述

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[http\\\]\\\(&lt;000 目錄.md#c-26&gt;\\\)

Stalwart includes an HTTP service that is enabled by default. It supports JMAP access, WebDAV access, API management, ACME certificate issuance, autoconfig/autodiscover protocols, well-known resources, metrics collection, and OAuth authentication.

 Stalwart 包含一個預設啟用的HTTP服務。它支援JMAP存取、WebDAV 存取、 API管理、 ACME憑證頒發、自動設定/自動發現協定、知名資源、指標收集和 OAuth 驗證。

 Multiple HTTP services can be defined, each with custom access control rules expressed on the Http singleton \(found in the WebUI under Settings › Network › HTTP › General, Settings › Network › HTTP › Security\). Rules can filter requests by IP address, resource, method name, or listener identity.

 可以定義多個服務，每個HTTP都可以自訂存取控制規則， \([https://stalw.art/docs/http/access-control\)規則透過單例\(https://stalw.art/docs/ref/object/http\)服務（可在](https://stalw.art/docs/http/access-control%2529%2525E8%2525A6%25258F%2525E5%252589%252587%2525E9%252580%25258F%2525E9%252581%25258E%2525E5%252596%2525AE%2525E4%2525BE%25258B%2528https://stalw.art/docs/ref/object/http%2529%2525E6%25259C%25258D%2525E5%25258B%252599%2525EF%2525BC%252588%2525E5%25258F%2525AF%2525E5%25259C%2525A8) WebUI 的「設定」&gt;「網路」&gt; HTTP常規」或HTTP安全性」中找到）來表達。規則可以IP位址、資源、方法名稱或監聽器標識來過濾請求。

## HTTP Endpoints｜HTTP端點

 The following endpoints are available through the HTTP service:

 以下端點可透過HTTP服務存取：

- `/jmap`: The JMAP endpoint provides access to the JMAP API, allowing clients to interact with mailboxes, messages, and other resources.
`/jmap` ： JMAP端點提供對 JMAP API的訪問，允許客戶端與郵箱、郵件和其他資源互動。
- `/dav/*`: The WebDAV endpoint provides access to WebDAV resources, allowing clients to manage calendar, contact and file resources.
`/dav/*` ：WebDAV 端點提供對 WebDAV資源的訪問，允許客戶端管理日曆、聯絡人和文件資源。
- `/calendar/rsvp`: The Calendar Scheduling RSVP page allows participants to respond to calendar invitations using a simple web interface. The page itself is static; it posts to `/api/calendar/rsvp` to read the invitation and record the response.
`/calendar/rsvp` ：日曆安排 RSVP頁允許參與者使用簡單的網頁介面回覆日曆邀請。該頁面本身是靜態的；它會將資訊發佈到`/api/calendar/rsvp`以讀取邀請並記錄回應。
- `/.well-known/*`: The [well-known endpoint](#well-known-resources) provides access to resources that are commonly used by clients to discover service information.
`/.well-known/*` ：[眾所周知的端點](#well-known-resources)提供對客戶端常用資源的訪問，以便發現服務資訊。
- `/scim/v2/*`: The SCIM provisioning endpoint accepts user and group lifecycle operations from an external identity provider. Available in the Enterprise edition.
`/scim/v2/*` ：SCIM配置端點接受來自外部身分提供者的使用者和群組生命週期操作。企業版可用。
- `/api/*`: Provides access to the HTTP API, a small set of endpoints for authentication, account introspection, configuration schema retrieval, and live telemetry. Server configuration and mailbox data are accessed through JMAP, not through this endpoint.
`/api/*` ：提供對 HTTP API的訪問，這是一組用於身份驗證、帳戶自省、配置模式檢索和即時遙測的端點。伺服器配置和郵箱資料透過JMAP訪問，而不是透過此端點存取。
- `/auth/device`: The device authorization endpoint is used for OAuth device authorization.
`/auth/device` ：設備授權端點用於OAuth 設備授權 。
- `/auth/token`: The token endpoint is used for OAuth token exchange.
`/auth/token` ：令牌端點用於OAuth令牌交換 。
- `/auth/introspect`: The token introspection endpoint is used for OAuth token introspection.
`/auth/introspect` ：令牌自省端點用於OAuth令牌自省 。
- `/auth/userinfo`: The user information endpoint is used for OpenID user information.
`/auth/userinfo` ：使用者資訊端點用於OpenID 使用者資訊 。
- `/auth/jwks.json`: The JSON Web Key Set \(JWKS\) endpoint provides public keys for JWT verification.
`/auth/jwks.json` ： JSON Web 金鑰集（ JWKS ）端點提供用於 JWT驗證的公鑰。
- `/mail/config-v1.1.xml`: The autodiscover endpoint provides email client configuration information.
`/mail/config-v1.1.xml` ：自動發現端點提供電子郵件用戶端設定資訊。
- `/autodiscover/autodiscover.xml`: The autodiscover endpoint provides email client configuration information.
`/autodiscover/autodiscover.xml` ：自動發現端點提供電子郵件用戶端設定資訊。
- `/metrics/prometheus`: The Prometheus metrics endpoint provides metrics for monitoring the server’s performance.
`/metrics/prometheus` ：Prometheus指標端點提供用於監控伺服器效能的指標。
- `/form`: The form endpoint is used for Form submissions.
`/form` ：表單端點用於表單提交 。
- `/healthz/ready`: The health check endpoint indicates whether the server is ready to accept requests.
`/healthz/ready` ：健康檢查端點指示伺服器是否準備好接受請求。
- `/healthz/live`: The health check endpoint indicates whether the server is live and operational.
`/healthz/live` ：健康檢查端點指示伺服器是否線上且運作正常。
- `/robots.txt`: The robots.txt file provides instructions to web crawlers and other user agents about the server’s content.
`/robots.txt` ：robots.txt 檔案向網路爬蟲和其他使用者代理提供有關伺服器內容的指令。
- `/*`: The default endpoint serves static files from the WebUI bundle.
`/*` ：預設端點提供來自 WebUI 套件 的靜態檔案 。
## Well-known Resources｜知名資源

 The following well-known resources are available through the HTTP service:

 以下知名資源可透過HTTP服務取得：

- `/.well-known/jmap`: The JMAP well-known resource provides information about the JMAP endpoint.
`/.well-known/jmap` ： JMAP知名資源提供有關 JMAP端點的資訊。
- `/.well-known/caldav`: The CalDAV well-known resource provides information about the CalDAV endpoint.
`/.well-known/caldav` ：CalDAV 知名資源提供有關 CalDAV端點的資訊。
- `/.well-known/carddav`: The CardDAV well-known resource provides information about the CardDAV endpoint.
`/.well-known/carddav` ：CardDAV 知名資源提供有關 CardDAV端點的資訊。
- `/.well-known/oauth-authorization-server`: The OAuth authorization server well-known resource provides information about the OAuth authorization server.
`/.well-known/oauth-authorization-server` ：OAuth 授權伺服器知名資源提供有關 OAuth授權伺服器的資訊。
- `/.well-known/openid-configuration`: The OIDC discovery well-known resource provides information about the OIDC discovery endpoint.
`/.well-known/openid-configuration` ： OIDC發現已知資源提供有關 OIDC發現端點的資訊。
- `/.well-known/acme-challenge`: The ACME challenge well-known resource provides the HTTP-01 challenge for ACME certificate issuance.
`/.well-known/acme-challenge` ： ACME挑戰眾所周知的資源為ACME證書頒發提供HTTP -01挑戰。
- `/.well-known/mta-sts.txt`: The MTA-STS well-known resource provides information about the MTA-STS policy.
`/.well-known/mta-sts.txt` ： MTA-STS知名資源提供了有關 MTA-STS政策的資訊。
- `/.well-known/mail-v1.xml`: The mail configuration well-known resource provides information about the configuration endpoint.
`/.well-known/mail-v1.xml` ：郵件配置已知資源提供有關設定端點的資訊。
- `/.well-known/autoconfig/mail/config-v1.1.xml`: The autoconfig mail configuration well-known resource provides information about the autconfig mail configuration endpoint.
`/.well-known/autoconfig/mail/config-v1.1.xml` ：自動設定郵件設定知名資源提供有關 autconfig郵件設定端點的資訊。
