# Calendar｜日曆

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Configures calendar settings including iCalendar limits and default names.

 配置日曆設置，包括 iCalendar 限制和預設名稱。

 This object can be configured from the WebUI under Settings › Calendar & Contacts › Calendar

 此物件可在 WebUI的「設定」&gt;「日曆與聯絡人」&gt;「行事曆」中進行設定。

## Fields｜田野

##### `defaultDisplayName`

> Type: \\\`String?\\\` · default: \\\`"Stalwart Calendar"\\\`

類型： \`String?\` · 預設值： \`"Stalwart Calendar"\`

 Specifies the default display name for a calendar when it is created

 指定建立日曆時的預設顯示名稱。

##### `defaultHrefName`

> Type: \\\`String?\\\` · default: \\\`"default"\\\`

類型： \`String?\` · 預設值： \`"default"\`

 Specifies the default href name for a calendar when it is created

 指定建立日曆時其預設的 href 名稱。

##### `maxAttendees`

> Type: \\\`UnsignedInt\\\` · default: \\\`20\\\` · max: 100000

類型： \`UnsignedInt\` · 預設值： \`20\` · 最大值：100000

 Specifies the maximum number of attendees that can be included in a single iCalendar instance

 指定單一 iCalendar 實例中可包含的最大與會者數量。

##### `maxRecurrenceExpansions`

> Type: \\\`UnsignedInt\\\` · default: \\\`3000\\\`

類型： \`UnsignedInt\` · 預設值： \`3000\`

 Specifies the maximum number of instances that can be generated from a recurring iCalendar event

 指定可從重複的 iCalendar 事件產生的最大實例數。

##### `maxICalendarSize`

> Type: \\\`Size\\\` · default: \\\`524288\\\`

類型： \`Size\` · 預設值： \`524288\`

 Specifies the maximum size of an iCalendar file that can be uploaded to the server

 指定可上傳到伺服器的 iCalendar 檔案的最大大小

##### `maxCalendars`

> Type: \\\`UnsignedInt?\\\` · default: \\\`250\\\` · min: 1

類型： \`UnsignedInt?\` · 預設值： \`250\` · 最小值：1

 The default maximum number of calendars a user can create

 使用者可以建立的日曆的預設最大數量

##### `maxEvents`

> Type: \\\`UnsignedInt?\\\` · min: 1

類型： \`UnsignedInt?\` · 最小：1

 The default maximum number of calendar events a user can create

 使用者可建立的日曆事件的預設最大數量

##### `maxParticipantIdentities`

> Type: \\\`UnsignedInt?\\\` · default: \\\`100\\\` · min: 1

類型： \`UnsignedInt?\` · 預設值： \`100\` · 最小值：1

 The default maximum number of participant identities a user can create

 使用者可以建立的參與者身分的預設最大數量。

##### `maxEventNotifications`

> Type: \\\`UnsignedInt?\\\` · min: 1

類型： \`UnsignedInt?\` · 最小：1

 The default maximum number of notifications a user can create for calendar events

 使用者可為日曆事件建立的預設最大通知數量

## JMAP API

 The Calendar singleton is available via the `urn:stalwart:jmap` capability.

 日曆單例可透過`urn:stalwart:jmap`功能取得。

### `x:Calendar/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是 [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)節5.1中定義。

 For singletons, the `ids` argument should be the literal `singleton` \(or `null` to return the single instance\).

 對於單例， `ids`參數應該是字面值`singleton` （或`null`以傳回單一實例）。

 This method requires the `sysCalendarGet` permission.

 此方法需要`sysCalendarGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:Calendar/get",
          {
            "ids": [
              "singleton"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:Calendar/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節中定義。

 For singletons, only the `update` argument with id `singleton` is accepted; `create` and `destroy` arguments are rejected.

 對於單例，僅接受 id 為`singleton` `update`參數；拒絕`create`和`destroy`參數。

 This method requires the `sysCalendarUpdate` permission.

 此方法需要`sysCalendarUpdate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:Calendar/set",
          {
            "update": {
              "singleton": {
                "defaultDisplayName": "updated value"
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get Calendar
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update Calendar --field defaultDisplayName='updated value'
```
