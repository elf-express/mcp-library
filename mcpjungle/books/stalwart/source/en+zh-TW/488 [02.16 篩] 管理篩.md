# ManageSieve｜管理篩

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[sieve｜篩\\\]\\\(&lt;000 目錄.md#c-67&gt;\\\)

[ManageSieve](https://datatracker.ietf.org/doc/html/rfc5804) is a protocol for remotely managing Sieve scripts on a mail server. Sieve scripts filter and sort incoming email based on rules defined by the user or the administrator. ManageSieve provides a standard way to upload, download, edit, and delete those scripts from a remote client, typically a supported email client or a web interface.

[ManageSieve](https://datatracker.ietf.org/doc/html/rfc5804)是一種用於遠端管理郵件伺服器上 Sieve 腳本的協定。 Sieve 腳本根據使用者或管理員定義的規則過濾和排序收到的電子郵件。 ManageSieve 提供了一種標準方法，可從遠端用戶端（通常是受支援的電子郵件用戶端或 Web 介面）上傳、下載、編輯和刪除這些腳本。

 Stalwart includes a ManageSieve server, so Sieve scripts can be managed over the network without direct access to the server’s file system.

 Stalwart 包含一個 ManageSieve 伺服器，因此可以透過網路管理 Sieve 腳本，而無需直接存取伺服器的檔案系統。

## Listener｜聽眾

 To enable ManageSieve access, create a network listener with its protocol set to `manageSieve`. Listeners are configured through the NetworkListener object \(found in the WebUI under Settings › Network › Listeners\). The relevant fields are bind, protocol, and tlsImplicit.

 若要啟用 ManageSieve 存取權限，請建立協定設定為`manageSieve`的網路監聽器\([https://stalw.art/docs/server/listener](https://stalw.art/docs/server/listener)\) 。監聽器透過 NetworkListener物件進行設定（可在 WebUI 的「設定」&gt;「網路」&gt;「監聽器」下找到）。相關欄位為 bind 、protocol及 tlsImplicit 。

 For example, a listener named `sieve` that binds to port 4190 on all interfaces with implicit TLS:

 例如，一個名為`sieve`的監聽器綁定到所有介面上的 4190 端口，並隱式地綁定了TLS ：

```json
{
  "name": "sieve",
  "bind": {"[::]:4190": true},
  "protocol": "manageSieve",
  "tlsImplicit": true
}
```

Once the listener is active, users can manage their Sieve scripts through any compatible ManageSieve client or through the WebUI.

 監聽器啟動後，使用者可以透過任何相容的 ManageSieve 用戶端或透過 WebUI 管理他們的 Sieve 腳本。
