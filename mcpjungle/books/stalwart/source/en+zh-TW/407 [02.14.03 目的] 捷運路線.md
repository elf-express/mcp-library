# MtaRoute｜捷運路線

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines a routing rule for outbound message delivery.

 定義出站訊息傳遞的路由規則。

 This object can be configured from the WebUI under Settings › MTA › Outbound › Routes

 此物件可在 WebUI的「設定」› MTA › 出站 › 路由 中進行設定。

## Fields｜田野

 MtaRoute is a **multi-variant** object: each instance has an `@type` discriminator selecting one of the variants below, and each variant carries its own set of fields.

 MtaRoute 是一個**多變體**物件：每個實例都有一個`@type`鑑別器，用於選擇以下變體之一，並且每個變體都帶有自己的一組欄位。

### `@type: "Mx"`

 Remote Delivery \(MX\)

 遠端交付（ MX ）

##### `ipLookupStrategy`

> Type: \\\[\\\`MtaIpStrategy\\\`\\\]\\\(#mtaipstrategy\\\) · default: \\\`"v4ThenV6"\\\`

類型：\[\`MtaIpStrategy\`\]\(#mtaipstrategy\) · 預設值： \`"v4ThenV6"\`

 IP resolution strategy for MX hosts

 IP MX解析策略

##### `maxMultihomed`

> Type: \\\`UnsignedInt\\\` · default: \\\`2\\\` · min: 1

類型： \`UnsignedInt\` · 預設值： \`2\` · 最小值：1

 For multi-homed remote servers, it is the maximum number of IP addresses to try on each delivery attempt

 對於多宿主遠端伺服器，這是每次投遞嘗試中要嘗試的最大IP位址數。

##### `maxMxHosts`

> Type: \\\`UnsignedInt\\\` · default: \\\`5\\\` · min: 1

類型： \`UnsignedInt\` · 預設值： \`5\` · 最小值：1

 Maximum number of MX hosts to try on each delivery attempt

 每次投遞嘗試中可嘗試的最大主機數量MX

##### `name`

> Type: \\\`String\\\` · read-only

類型： \`String\` · 只讀

 Short identifier for the route

 路線的簡短標識符

##### `description`

> Type: \\\`String?\\\`

類型： \`String?\`

 A short description of the route, which can be used to identify it in the list of routes

 路線的簡要描述，可用於在路線清單中識別該路線。

### `@type: "Relay"`

 Relay Host

 中繼主機

##### `address`

> Type: \\\`String\\\` · required

類型： \`String\` · 必填

 The address of the remote SMTP server, which can be an IP address or a domain name

 遠端SMTP伺服器的位址，可以是IP位址或網域名稱

##### `authSecret`

> Type: \\\[\\\`SecretKeyOptional\\\`\\\]\\\(#secretkeyoptional\\\) · required

類型：\[\`SecretKeyOptional\`\]\(#secretkeyoptional\) · 必填

 The secret to use when authenticating with the remote server

 與遠端伺服器進行身份驗證時要使用的金鑰

##### `authUsername`

> Type: \\\`String?\\\`

類型： \`String?\`

 The username to use when authenticating with the remote server

 用於向遠端伺服器進行身份驗證的使用者名

##### `port`

> Type: \\\`UnsignedInt\\\` · default: \\\`25\\\` · max: 65535 · min: 1

類型： \`UnsignedInt\` · 預設值： \`25\` · 最大值：65535 · 最小值：1

 The port number of the remote server, which is typically 25 for SMTP and 11200 for LMTP

 遠端伺服器的連接埠號碼，通常情況下， SMTP的連接埠號碼為 25， LMTP的連接埠號碼為 11200。

##### `protocol`

> Type: \\\[\\\`MtaProtocol\\\`\\\]\\\(#mtaprotocol\\\) · default: \\\`"smtp"\\\`

類型：\[\`MtaProtocol\`\]\(#mtaprotocol\) · 預設值： \`"smtp"\`

 The protocol to use when delivering messages to the remote server, which can be either SMTP or LMTP

 向遠端伺服器發送訊息時要使用的協議，可以是SMTP或LMTP

##### `allowInvalidCerts`

> Type: \\\`Boolean\\\` · default: \\\`false\\\`

類型： \`Boolean\` · 預設值： \`false\`

 Whether to allow connections to servers with invalid TLS certificates

 是否允許連接到具有無效TLS憑證的伺服器

##### `implicitTls`

> Type: \\\`Boolean\\\` · default: \\\`false\\\`

類型： \`Boolean\` · 預設值： \`false\`

 Whether to use TLS encryption for all connections to the remote server

 是否對所有與遠端伺服器的連線使用TLS加密

##### `name`

> Type: \\\`String\\\` · read-only

類型： \`String\` · 只讀

 Short identifier for the route

 路線的簡短標識符

##### `description`

> Type: \\\`String?\\\`

類型： \`String?\`

 A short description of the route, which can be used to identify it in the list of routes

 路線的簡要描述，可用於在路線清單中識別該路線。

## JMAP API

 The MtaRoute object is available via the `urn:stalwart:jmap` capability.

 MtaRoute 物件可透過`urn:stalwart:jmap`功能取得。

### `x:MtaRoute/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節中定義。

 This method requires the `sysMtaRouteGet` permission.

 此方法需要`sysMtaRouteGet` 權限 。


## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get MtaRoute id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create MtaRoute/Mx
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query MtaRoute
stalwart-cli query MtaRoute --where name=example
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update MtaRoute id1 --field description='updated value'
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete MtaRoute --ids id1
```

## Nested types｜巢狀類型

### SecretKeyOptional｜可選密鑰

 An optional secret value, or none.

 可選的秘密值，或不含秘密值。

- **`None`**: No secret. No additional fields.
**`None`**：無秘密訊息。無其他字段。
- **`Value`**: Secret value. Carries the fields of [SecretKeyValue](#secretkeyvalue).
**`Value`**: 秘密值。包含 [SecretKeyValue](#secretkeyvalue)的欄位。
- **`EnvironmentVariable`**: Secret read from environment variable. Carries the fields of [SecretKeyEnvironmentVariable](#secretkeyenvironmentvariable).
**`EnvironmentVariable`**: 從環境變數中讀取秘密值。包含 [SecretKeyEnvironmentVariable](#secretkeyenvironmentvariable)的欄位。
- **`File`**: Secret read from file. Carries the fields of [SecretKeyFile](#secretkeyfile).
**`File`**: 從文件中讀取秘密訊息。攜帶 [SecretKeyFile](#secretkeyfile)的場。
#### SecretKeyValue｜密鑰值

 A secret value provided directly.

 直接提供一個秘密值。

##### `secret`

> Type: \\\`String\\\` · required · secret

類型： \`String\` · 必填 · 機密

 Password or secret value

 密碼或秘密值

#### SecretKeyEnvironmentVariable｜密鑰環境變數

 A secret value read from an environment variable.

 從環境變數中讀取的秘密值。

##### `variableName`

> Type: \\\`String\\\` · required

類型： \`String\` · 必填

 Environment variable name to read the secret from

 要從中讀取密鑰的環境變數名稱

#### SecretKeyFile｜密鑰檔案

 A secret value read from a file.

 從文件中讀取的秘密值。

##### `filePath`

> Type: \\\`String\\\` · required

類型： \`String\` · 必填

 File path to read the secret from

 讀取密鑰的檔案路徑
