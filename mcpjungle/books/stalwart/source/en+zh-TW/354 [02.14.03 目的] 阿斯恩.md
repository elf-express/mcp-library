# Asn｜阿斯恩

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Configures ASN and geolocation data sources for IP address lookups.

 配置ASN和地理位置資料來源，用於IP位址查找。

 This object can be configured from the WebUI under Settings › Network › ASN & GeoIP

 此物件可在 WebUI的「設定」&gt;「網路」&gt; ASN和 GeoIP 中進行設定。

## Fields｜田野

 Asn is a **multi-variant** object: each instance has an `@type` discriminator selecting one of the variants below, and each variant carries its own set of fields.

 Asn 是一個**多變體**物件：每個實例都有一個`@type`鑑別器，用於選擇以下變體之一，並且每個變體都帶有自己的一組欄位。

### `@type: "Disabled"`

 Disabled

 已停用

### `@type: "Resource"`

 URL Resource

 URL資源

##### `expires`

> Type: \\\`Duration\\\` · default: \\\`86400000\\\`

類型： \`Duration\` · 預設值： \`86400000\`

 How often to refresh the ASN/Geo data.

 ASN /Geo 資料多久刷新一次。

##### `maxSize`

> Type: \\\`Size\\\` · default: \\\`104857600\\\`

類型： \`Size\` · 預設值： \`104857600\`

 Maximum size of the ASN/Geo data file.

 ASN /Geo 資料檔的最大大小。

##### `timeout`

> Type: \\\`Duration\\\` · default: \\\`300000\\\`

類型： \`Duration\` · 預設值： \`300000\`

 Time after which the ASN/Geo resource fetch is considered failed.

 ASN /Geo 資源取得失敗的時間。

##### `asnUrls`

> Type: \\\`Set<string>\\\`

類型： \`Set<string>\`

 URLs to fetch CSV file containing the IP to ASN mappings.

 取得包含IP到ASN映射的CSV檔案的 URL。

##### `geoUrls`

> Type: \\\`Set<string>\\\`

類型： \`Set<string>\`

 URLs to fetch CSV file containing the IP to country code mappings.

 取得包含IP到國家代碼映射的CSV檔案的 URL。

##### `httpAuth`

> Type: \\\[\\\`HttpAuth\\\`\\\]\\\(#httpauth\\\) · required

類型：\[\`HttpAuth\`\]\(#httpauth\) · 必填

 The type of HTTP authentication to use

 要使用的HTTP身份驗證類型

##### `httpHeaders`

> Type: \\\`Map<string, string="">\\\`

類型： \`Map&amp;lt;string, string=""&amp;gt;\`

 Additional headers to include in HTTP requests

 HTTP請求中要包含的其他標頭

### `@type: "Dns"`

 DNS Lookup

 DNS查找

##### `indexAsn`

> Type: \\\`UnsignedInt\\\` · default: \\\`0\\\`

類型： \`UnsignedInt\` · 預設值： \`0\`

 The position of the ASN in the DNS TXT record.

 ASN在DNS TXT記錄中的位置。

##### `indexAsnName`

> Type: \\\`UnsignedInt?\\\`

類型： \`UnsignedInt?\`

 The position of the ASN Name in the DNS TXT record.

 ASN名稱在DNS TXT記錄中的位置。

##### `indexCountry`

> Type: \\\`UnsignedInt?\\\`

類型： \`UnsignedInt?\`

 The position of the country code in the DNS TXT record.

 國家代碼在DNS TXT記錄中的位置。

##### `separator`

> Type: \\\`String\\\` · default: \\\`"|"\\\`

類型： \`String\` · 預設值： \`"|"\`

 The separator character used in the DNS TXT record.

 DNS TXT記錄中使用的分隔符號。

##### `zoneIpV4`

> Type: \\\`String\\\` · required

類型： \`String\` · 必填

 The DNS zone to query for IPv4 ASN and geolocation data.

 DNS區域用於查詢 IPv4 ASN和地理位置資料。

## JMAP API

 The Asn singleton is available via the `urn:stalwart:jmap` capability.

 Asn 單例可透過`urn:stalwart:jmap`功能取得。

### `x:Asn/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節中定義。

 For singletons, the `ids` argument should be the literal `singleton` \(or `null` to return the single instance\).

 對於單例， `ids`參數應該是字面值`singleton` （或`null`以傳回單一實例）。

 This method requires the `sysAsnGet` permission.

 此方法需要`sysAsnGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:Asn/get",
          {
            "ids": [
              "singleton"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:Asn/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節定義。

 For singletons, only the `update` argument with id `singleton` is accepted; `create` and `destroy` arguments are rejected.

 對於單例，僅接受 id 為`singleton`的`update`參數；拒絕`create`和`destroy`參數。

 This method requires the `sysAsnUpdate` permission.

 此方法需要`sysAsnUpdate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:Asn/set",
          {
            "update": {
              "singleton": {
                "description": "updated value"
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get Asn
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update Asn --field description='updated value'
```

## Nested types｜巢狀類型

### HttpAuth

 Defines the HTTP authentication method to use for HTTP requests.

 定義用於HTTP請求的HTTP身份驗證方法。

- **`Unauthenticated`**: Anonymous. No additional fields.
**`Unauthenticated`**：匿名。無其他字段。
- **`Basic`**: Basic Authentication. Carries the fields of [HttpAuthBasic](#httpauthbasic).
**`Basic`**：基本驗證。包含 [HttpAuthBasic](#httpauthbasic)字段。
- **`Bearer`**: Bearer Token. Carries the fields of [HttpAuthBearer](#httpauthbearer).
**`Bearer`**: 持有者令牌。攜帶 [HttpAuthBearer](#httpauthbearer)的場。
#### HttpAuthBasic

 HTTP Basic authentication credentials.

 HTTP基本驗證憑證。

##### `username`

類型： \`String\` · 必填

 HTTP基本驗證的使用者名稱

##### `secret`

> Type: \\\[\\\`SecretKey\\\`\\\]\\\(#secretkey\\\) · required

類型：\[\`SecretKey\`\]\(#secretkey\) · 必填

 Password for HTTP Basic Authentication

 HTTP基本驗證密碼

##### SecretKey｜金鑰

 A secret value provided directly, from an environment variable, or from a file.

 直接提供的秘密值、來自環境變數或來自文件的值。

- **`Value`**: Secret value. Carries the fields of [SecretKeyValue](#secretkeyvalue).
**`Value`**: 秘密值。包含 [SecretKeyValue](#secretkeyvalue)的欄位。
- **`EnvironmentVariable`**: Secret read from environment variable. Carries the fields of [SecretKeyEnvironmentVariable](#secretkeyenvironmentvariable).
**`EnvironmentVariable`**: 從環境變數中讀取秘密值。包含 [SecretKeyEnvironmentVariable](#secretkeyenvironmentvariable)的欄位。
- **`File`**: Secret read from file. Carries the fields of [SecretKeyFile](#secretkeyfile).
**`File`**: 從文件中讀取秘密訊息。攜帶 [SecretKeyFile](#secretkeyfile)的場。

 直接提供一個秘密值。

 Password or secret value

 密碼或秘密值

 Environment variable name to read the secret from
