# Envelope｜信封

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[mta｜捷運\\\]\\\(&lt;000 目錄.md#c-47&gt;\\\) › \\\[rewrite｜改寫\\\]\\\(&lt;000 目錄.md#c-54&gt;\\\)

Address rewriting alters the email addresses in the envelope of a message as it passes through the mail server. The envelope, distinct from the message content, carries the routing information \(sender or return path, and recipients\).

 位址重寫功能會在郵件通過郵件伺服器時變更郵件信封中的電子郵件地址。信封（與郵件內容不同）承載路由資訊（寄件者或退迴路徑以及收件者）。

 Address rewriting can be used to change outgoing mail addresses to match a specific domain for branding, or to adjust incoming addresses to redirect specific messages to a different inbox. Rewriting rules use regular expressions for pattern-based matching and transformation, and Sieve scripts for cases requiring finer control.

 地址重寫功能可用於變更外寄郵件地址，使其與特定網域名稱配對以進行品牌推廣，或調整收件地址，將特定郵件重新導向至不同的收件匣。重寫規則使用正規表示式進行基於模式的匹配和轉換，並使用 Sieve 腳本來處理需要更精細控制的情況。

 Stalwart supports address rewriting on both the sender and recipient parts of the envelope.

 Stalwart 支援對信封的寄件者和收件人地址進行重寫。

## Expressions｜表達式

 Address rewriting uses expressions and regular expressions. When a regex matches the email address, the captured components can be rearranged or modified to form a new address.

 位址重寫使用 表達式和正規表示式。當正規表示式與電子郵件地址相符時，捕獲到的元件可以被重新排列或修改，從而形成一個新的位址。

 Capture groups are numbered sequentially from 0 \(the whole match\). The `${pos}` syntax refers to a capture group by its position number. For example, the expression `matches('^([^.]+)\.([^.]+)@(.+)$', rcpt)` matches addresses of the form `alias.name@domain`, and a rewrite expression such as `$1 + '+' + $2 + '@' + $3` transforms them into `alias+name@domain`. When the expression does not match, the `else` branch returns `false` and no rewriting takes place.

 捕獲組從 0（整場比賽）開始依序編號。 `${pos}` 語法透過位置編號引用捕獲組。例如，表達式 `matches('^([^.]+)\.([^.]+)@(.+)$', rcpt)` 匹配`alias.name@domain` 形式的位址，而諸如 `$1 + '+' + $2 + '@' + $3` 之類的重寫表達式會將它們轉換為 `alias+name@domain`。當表達式不匹配時，`else`分支回傳`false`並且不進行重寫。

 Sender addresses are rewritten by the rewrite field on the MtaStageMail singleton \(found in the WebUI under Settings › MTA › Session › MAIL FROM Stage\). Recipient addresses are rewritten by the rewrite field on the MtaStageRcpt singleton \(found in the WebUI under Settings › MTA › Session › RCPT TO Stage\).

 寄件者地址由 MtaStageMail單例中的 rewrite欄位重寫（可在 WebUI 的「設定」&gt; MTA會話」&gt; MAIL FROM階段」中找到）。收件者地址由 MtaStageRcpt單例中的 rewrite欄位重寫（可在 WebUI 的「設定」&gt; MTA會話」&gt; RCPT TO階段」中找到）。

## Sieve｜篩

 When address rewriting cannot be expressed with regular expressions alone, a Sieve script can be used. Sieve is a scripting language designed for mail filtering. Stalwart supports the `envelope` Sieve extension, which provides access to details of the message envelope such as sender and recipient addresses, as well as other envelope information such as Delivery Status Notifications \(DSN\).

 當僅使用正規表示式無法實作位址重寫時，可以使用 Sieve 腳本是一種專為郵件過濾而設計的腳本語言。 Stalwart 支援`envelope` Sieve 擴展，該擴展提供對郵件信封詳細信息的訪問，例如發件人和收件人地址，以及其他信封信息，例如投遞狀態通知 \( DSN \)。

 To modify parts of the envelope within a Sieve script, the `set` command defines and modifies variables. Assigning a new value to `envelope.to` or `envelope.from` replaces the corresponding envelope address.

 要在 Sieve 腳本中修改信封的某些部分，可以使用`set`指令定義和修改變數。為`envelope.to`或`envelope.from`賦新值會取代對應的信封位址。

 System-level Sieve scripts are defined as SieveSystemScript objects. The script name is referenced from the script field on MtaStageMail or the script field on MtaStageRcpt. See the Sieve scripts, MAIL FROM stage, and RCPT TO stage sections for details.

 系統級 Sieve 腳本定義為 SieveSystemScript物件。腳本名稱引用自 MtaStageMail 的 script字段或 MtaStageRcpt 的 script字段。有關詳細信息，請參閱 Sieve scripts 、MAIL FROM階段和 RCPT TO階段部分。

## Examples｜範例

### Ignore dots｜忽略點

 Gmail disregards periods in the local part of an email address, so `[[email protected]](https://stalw.art/cdn-cgi/l/email-protection)` receives mail also sent to `[[email protected]](https://stalw.art/cdn-cgi/l/email-protection)` or `[[email protected]](https://stalw.art/cdn-cgi/l/email-protection)`. The same behaviour can be implemented in Stalwart with a Sieve script:

 Gmail 會忽略電子郵件地址本地部分中的句點，因此`[[email protected]](https://stalw.art/cdn-cgi/l/email-protection)`會收到發送到`[[email protected]](https://stalw.art/cdn-cgi/l/email-protection)`或`[[email protected]](https://stalw.art/cdn-cgi/l/email-protection)`郵件。在 Stalwart 中，可以使用 Sieve 腳本實現相同的行為：

```sieve
require ["variables", "envelope", "regex"];

if allof( envelope :localpart :contains "to" ".",
          envelope :regex "to" "(.+)@(.+)$") {
    set :replace "." "" "to" "${1}";
    set "envelope.to" "${to}@${2}";
}
```

 How the script works:

 腳本工作原理：

- The `require` clause declares the Sieve extensions used: `variables` for variable handling, `envelope` for envelope access, and `regex` for pattern matching.
`require`子句聲明了使用的 Sieve 擴展： `variables`用於變數處理， `envelope`用於信封訪問， `regex`用於模式匹配。
- The `if allof(...)` conditional checks that the local part of the recipient contains a period and that the address splits into local and domain parts.
`if allof(...)`條件檢查收件人的本地部分是否包含句點，以及地址是否分為本地部分和域部分。
- `set :replace "." "" "to" "${1}"` strips the periods from the local part and stores the result in the variable `to`.
`set :replace "." "" "to" "${1}"`從局部部分移除句點，並將結果儲存在變數`to`中。
- `set "envelope.to" "${to}@${2}"` reconstructs the recipient address and updates the envelope.
`set "envelope.to" "${to}@${2}"`重建收件人地址並更新信封。
The script is referenced from the script field on MtaStageRcpt.
 腳本引用自 MtaStageRcpt 上的 script字段。

### Silent bounces｜無聲彈跳

 Certain SMTP parameters control delivery-time behaviour:

 某些SMTP參數控制著交付時間行為：

- `NOTIFY`: when the sender should be notified about delivery status. Values include `NEVER`, `SUCCESS`, `FAILURE`, and `DELAY`.
`NOTIFY` ：何時應通知寄件者有關投遞狀態的資訊。值包括`NEVER`, `SUCCESS`, `FAILURE`和`DELAY` 。
- `ENVID`: unique identifier associated with the message, useful for tracking.
`ENVID` ：與訊息關聯的唯一標識符，可用於追蹤。
- `ORCPT`: original recipient address when different from the envelope recipient, useful after forwarding or rewriting.
`ORCPT` ：當收件者地址與信封收件者地址不同時，用於轉寄或重寫郵件。
To disable DSNs for messages sent to any mailer-daemon address:
 若要停用傳送到任何郵件守護程式位址的郵件的 DSN：

```sieve
require ["variables", "envelope"];

if envelope :matches "to" "mailer-daemon@*" {
    set "envelope.notify" "NEVER";
}
```
