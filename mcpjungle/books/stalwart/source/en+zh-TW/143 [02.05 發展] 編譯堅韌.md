# Compiling Stalwart｜編譯堅韌

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[development｜發展\\\]\\\(&lt;000 目錄.md#c-20&gt;\\\)

Compiling Stalwart from the source has the main advantage that binaries are built with optimizations specific to your hardware which may result in better performance. Another advantage is that you may enable or disable features to suit your needs, thus reducing the size of the binary and the memory footprint.

 從原始碼編譯 Stalwart 的主要優勢在於，生成的二進位檔案會針對您的硬體進行最佳化，這可能會帶來更好的效能。另一個優點是，您可以根據需要啟用或停用某些功能，從而減少二進位檔案的大小和記憶體佔用。

## Install Rust｜安裝 Rust

 To compile Stalwart you need the latest version of [Rust](https://www.rust-lang.org/). The fastest way to install rust is with `rustup`. On Unix systems run the following in your terminal, then follow the onscreen instructions

 要編譯 Stalwart，您需要最新版本的 [Rust](https://www.rust-lang.org/) 。安裝 Rust 最快的方法是使用`rustup` 。在 Unix 系統上，請在終端機中執行以下命令，然後按照螢幕上的指示進行操作。

```bash title=&amp;quot;Terminal window&amp;quot;
$ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

If you are running Windows 64-bit, download and run [rustup‑init.exe](https://rustup.rs/), then follow the onscreen instructions.

 如果您執行的是 64 位元 Windows 系統，請下載並執行 [rustup‑init.exe](https://rustup.rs/) ，然後按照螢幕上的指示進行操作。

## Clone the repository｜克隆儲存庫

 Clone the Stalwart repository:

 克隆 Stalwart 程式碼庫：

```bash title=&amp;quot;Terminal window&amp;quot;
$ git clone https://github.com/stalwartlabs/stalwart.git
$ cd stalwart
```

Find and then check out the latest tagged release, for example:

 找到並查看最新發布的標籤版本，例如：

```bash title=&amp;quot;Terminal window&amp;quot;
$ git tag --sort=-version:refname | head -1
v0.16.0
$ git checkout tags/v0.16.0
```

Never compile Stalwart from the `main` branch, as it may contain unstable code. Always use a tagged release.

 切勿從`main`分支編譯 Stalwart，因為它可能包含不穩定的程式碼。請始終使用已標記的版本。

## Install any required dependencies｜安裝所有必要的依賴項

 If you are compiling the Foundation DB backend, download and install the [Foundation DB client library](https://github.com/apple/foundationdb/releases).

 如果您正在編譯 Foundation DB後端，請下載並安裝 [Foundation DB客戶端程式庫](https://github.com/apple/foundationdb/releases) 。

## Compile｜編譯

 For example, to compile Stalwart with the RocksDB, ElasticSearch support and Enterprise [features](#available-features):

 例如，要編譯包含 RocksDB、ElasticSearch 支援和企業級 [功能](#available-features) Stalwart：

```bash title=&amp;quot;Terminal window&amp;quot;
$ cargo build --release -p stalwart --no-default-features --features "rocks elastic redis enterprise"
```

Or, to compile the FoundationDB backend:

 或者，編譯 FoundationDB 後端：

```bash title=&amp;quot;Terminal window&amp;quot;
$ cargo build --release -p stalwart  --no-default-features --features "foundationdb enterprise"
```

Rust compile times for large projects like Stalwart can be long, especially with multiple features enabled. Be patient\!

 對於像 Stalwart 這樣的大型項目，Rust 編譯時間可能會很長，尤其是在啟用多個功能的情況下。請耐心等待！

 Once the compilation process is completed, the Stalwart binary will be available under `target/release/stalwart`.

 編譯過程完成後，Stalwart 二進位檔案將在`target/release/stalwart`下可用。

## Available Features｜可用功能

 You can enable the following features when compiling Stalwart by using the `--features` flag:

 編譯 Stalwart 時，可以使用`--features`標誌啟用以下功能：

### Data store backends｜資料儲存後端

- `rocks`: RocksDB backend
`rocks` ：RocksDB 後端
- `sqlite`: SQLite backend
`sqlite` ：SQLite 後端
- `foundationdb`: FoundationDB backend
`foundationdb` ：FoundationDB 後端
- `postgres`: PostgreSQL backend
`postgres` ：PostgreSQL 後端
- `mysql`: MySQL backend
`mysql` ：MySQL 後端
### Blob store backends｜Blob 儲存後端

- `s3`: S3 backend
`s3` ：S3 後端
- `azure`: Azure backend
`azure` ：Azure 後端
### FTS backends｜FTS後端

- `elastic`: ElasticSearch backend
`elastic` ：ElasticSearch 後端
### In-memory backends｜記憶體後端

- `redis`: Redis backend
`redis` ：Redis 後端
### Message queue backends｜訊息隊列後端

- `nats`: NATS backend
`nats`: NATS後端
- `zenoh`: Eclipse Zenoh backend
`zenoh` ：Eclipse Zenoh 後端
- `kafka`: Kafka backend
`kafka` ：Kafka 後端
### Other features｜其他功能

- `enterprise`: Enterprise features
`enterprise` ：企業功能
