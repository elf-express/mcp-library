# MtaMilter

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines a Milter filter endpoint for message processing.

 定義用於訊息處理的 Milter 過濾器端點。

 This object can be configured from the WebUI under Settings › MTA › Filters › Milters

 此物件可在 WebUI下的「設定」› MTA › “過濾器” › “研磨器”中進行設定。

## Fields｜田野

##### `allowInvalidCerts`

> Type: \\\`Boolean\\\` · default: \\\`false\\\`

類型： \`Boolean\` · 預設值： \`false\`

 Whether Stalwart should connect to a Milter filter server that has an invalid TLS certificate

 Stalwart 是否應該連接到具有無效TLS憑證的 Milter 過濾器伺服器

##### `enable`

> Type: \\\[\\\`Expression\\\`\\\]\\\(#expression\\\) · default: \\\`{"else":"true"}\\\`

類型：\[\`Expression\`\]\(#expression\) · 預設值： \`{"else":"true"}\`

 Expression that determines whether to enable this milter

 決定是否啟用此銑刀的表達式

 Available variables: \[\`MtaRcptToVariable\`\]\(&lt;331 \[02.14.02.02 多變的\] MtaRcptToVariable.md&gt;\).

 可用變數：\[\`MtaRcptToVariable\`\]\(&lt;331 \[02.14.02.02 多變的\] MtaRcptToVariable.md&gt;\) 。

##### `hostname`

> Type: \\\`String\\\` · required

類型： \`String\` · 必填

 Hostname or IP address of the server where the Milter filter is running

 Milter過濾器運作所在伺服器的主機名稱或IP位址

##### `maxResponseSize`

> Type: \\\`Size\\\` · default: \\\`52428800\\\`

類型： \`Size\` · 預設值： \`52428800\`

 Maximum size, in bytes, of a response that Stalwart will accept from this Milter server

 Stalwart 可接受的來自 Milter 伺服器的回應的最大大小（以位元組為單位）

##### `tempFailOnError`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Whether to respond with a temporary failure \(typically a 4xx SMTP status code\) when Stalwart encounters an error while communicating with this Milter server

 當 Stalwart 與此 Milter 伺服器通訊時遇到錯誤，是否回應臨時故障（通常為 4xx SMTP狀態碼）

##### `protocolVersion`

> Type: \\\[\\\`MilterVersion\\\`\\\]\\\(#milterversion\\\) · default: \\\`"v6"\\\`

類型：\[\`MilterVersion\`\]\(#milterversion\) · 預設值： \`"v6"\`

 Version of the Milter protocol that Stalwart should use when communicating with the Milter server

 Stalwart 與 Milter 伺服器通訊時應使用的 Milter 協定版本

##### `port`

> Type: \\\`UnsignedInt\\\` · default: \\\`11332\\\` · max: 65535 · min: 1

類型： \`UnsignedInt\` · 預設值： \`11332\` · 最大值：65535 · 最小值：1

 Network port on the Milter filter host server

 Milter過濾器主機伺服器上的網路連接埠

##### `stages`

> Type: \\\`Set&amp;lt;\\\`\\\[\\\`MtaStage\\\`\\\]\\\(#mtastage\\\)\\\`&amp;gt;\\\` · default: \\\`{"data":true}\\\` · min items: 1

類型： \`Set&amp;lt;\` \[ \`MtaStage\` \]\(#mtastage\)\`&amp;gt;\` · 預設值： \`{"data":true}\` · 最少項目數：1

 Which SMTP stages to run the milter on

 SMTP階段用於運行銑刀

##### `timeoutCommand`

> Type: \\\`Duration\\\` · default: \\\`30000\\\`

類型： \`Duration\` · 預設值： \`30000\`

 How long Stalwart will wait to send a command to the Milter server

 Stalwart 會等待多久才傳送指令到 Milter 伺服器？

##### `timeoutConnect`

> Type: \\\`Duration\\\` · default: \\\`30000\\\`

類型： \`Duration\` · 預設值： \`30000\`

 Maximum amount of time that Stalwart will wait to establish a connection with this Milter server

 Stalwart 等待與此 Milter 伺服器建立連線的最長時間

##### `timeoutData`

> Type: \\\`Duration\\\` · default: \\\`60000\\\`

類型： \`Duration\` · 預設值： \`60000\`

 Maximum amount of time Stalwart will wait for a response from the Milter server

 Stalwart 等待 Milter 伺服器回應的最長時間

##### `useTls`

> Type: \\\`Boolean\\\` · default: \\\`false\\\`

類型： \`Boolean\` · 預設值： \`false\`

 Whether to use Transport Layer Security \(TLS\) for the connection between Stalwart and the Milter filter

 是否對 Stalwart 和 Milter 濾波器之間的連接使用傳輸層安全協定 \( TLS \)

##### `flagsAction`

> Type: \\\`UnsignedInt?\\\`

類型： \`UnsignedInt?\`

 Optional flags to set on the Milter connection. See the Milter protocol documentation for details on available flags.

 Milter 連接中可設定的選用標誌。有關可用標誌的詳細信息，請參閱 Milter 協議文檔。

##### `flagsProtocol`

> Type: \\\`UnsignedInt?\\\`

類型： \`UnsignedInt?\`

 Milter 連線中可選的協定標誌。有關可用協議標誌的詳細信息，請參閱 Milter 協議文檔。

## JMAP API

 The MtaMilter object is available via the `urn:stalwart:jmap` capability.

 MtaMilter 物件可透過`urn:stalwart:jmap`功能取得。

### `x:MtaMilter/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是 [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)節5.1中定義。

 This method requires the `sysMtaMilterGet` permission.

 此方法需要`sysMtaMilterGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:MtaMilter/get",
          {
            "ids": [
              "id1"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get MtaMilter id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create MtaMilter \
  --field hostname=Example
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query MtaMilter
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update MtaMilter id1 --field hostname='updated value'
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete MtaMilter --ids id1
```
