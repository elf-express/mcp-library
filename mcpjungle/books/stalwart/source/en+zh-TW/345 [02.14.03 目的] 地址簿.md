# AddressBook｜地址簿

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Configures address book and contact storage settings.

 配置地址簿和聯絡人儲存設定。

 This object can be configured from the WebUI under Settings › Calendar & Contacts › Address Book

 此物件可在 WebUI 「設定」&gt;「行事曆與聯絡人」&gt;「通訊錄」中進行設定。

## Fields｜田野

##### `defaultDisplayName`

> Type: \\\`String?\\\` · default: \\\`"Stalwart Address Book"\\\`

類型： \`String?\` · 預設值： \`"Stalwart Address Book"\`

 Specifies the default display name for a contact when it is created

 指定建立聯絡人時的預設顯示名稱。

##### `defaultHrefName`

> Type: \\\`String?\\\` · default: \\\`"default"\\\`

類型： \`String?\` · 預設值： \`"default"\`

 Specifies the default href name for a contact when it is created

 指定建立聯絡人時其預設的 href 名稱。

##### `maxVCardSize`

> Type: \\\`Size\\\` · default: \\\`524288\\\`

類型： \`Size\` · 預設值： \`524288\`

 Specifies the maximum size of a vCard file that can be uploaded to the server

 指定可以上傳到伺服器的 vCard 檔案的最大大小

##### `maxAddressBooks`

> Type: \\\`UnsignedInt?\\\` · default: \\\`250\\\` · min: 1

類型： \`UnsignedInt?\` · 預設值： \`250\` · 最小值：1

 The default maximum number of address books a user can create

 使用者可以建立的地址簿的預設最大數量

##### `maxContacts`

> Type: \\\`UnsignedInt?\\\` · min: 1

類型： \`UnsignedInt?\` · 最小：1

 The default maximum number of contact cards a user can create

 用戶可建立的聯絡人卡片的預設最大數量

##### `vCardVersion`

> Type: \\\[\\\`VCardVersion\\\`\\\]\\\(#vcardversion\\\) · default: \\\`"v4"\\\`

類型：\[\`VCardVersion\`\]\(#vcardversion\) · 預設值： \`"v4"\`

 vCard version used when serializing contact cards for clients that do not request a specific version

 在為未指定版本要求的客戶序列化聯絡人卡片時，使用 vCard 版本。

## JMAP API

 The AddressBook singleton is available via the `urn:stalwart:jmap` capability.

 地址簿單例可透過`urn:stalwart:jmap`功能取得。

### `x:AddressBook/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是 [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)節5.1中定義。

 For singletons, the `ids` argument should be the literal `singleton` \(or `null` to return the single instance\).

 對於單例， `ids`參數應該是字面值`singleton` （或`null`以傳回單一實例）。

 This method requires the `sysAddressBookGet` permission.

 此方法需要`sysAddressBookGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:AddressBook/get",
          {
            "ids": [
              "singleton"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:AddressBook/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是 [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)節5.3中定義。

 For singletons, only the `update` argument with id `singleton` is accepted; `create` and `destroy` arguments are rejected.

 對於單例，僅接受 id 為`singleton` `update`參數；拒絕`create`和`destroy`參數。

 This method requires the `sysAddressBookUpdate` permission.

 此方法需要`sysAddressBookUpdate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:AddressBook/set",
          {
            "update": {
              "singleton": {
                "defaultDisplayName": "updated value"
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get AddressBook
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update AddressBook --field defaultDisplayName='updated value'
```
