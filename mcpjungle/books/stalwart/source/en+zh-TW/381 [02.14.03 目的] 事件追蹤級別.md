# EventTracingLevel｜事件追蹤級別

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines a custom logging level override for a specific event type.

 為特定事件類型定義自訂日誌等級覆蓋。

 This object can be configured from the WebUI under Settings › Telemetry › Event Levels

 此物件可在 WebUI的「設定」›「遙測」›「事件層級」中進行設定。

## Enums｜列舉

### TracingLevelOpt｜追蹤等級選項

| Value 值 | Label 標籤 |
| --- | --- |
| `disable` | Disabled 已禁用 |
| `error` | Error - Only errors are logged 錯誤 - 僅記錄錯誤訊息 |
| `warn` | Warning - Errors and warnings are logged 警告 - 錯誤和警告訊息已被記錄 |
| `info` | Info - Errors, warnings and info are logged 訊息 - 錯誤、警告和訊息將被記錄 |
| `debug` | Debug - Errors, warnings, info and debug are logged 偵錯 - 錯誤、警告、資訊和偵錯日誌將被記錄 |
| `trace` | Trace - Errors, warnings, info, debug and trace are logged 追蹤 - 錯誤、警告、資訊、偵錯與追蹤資訊將被記錄 |
