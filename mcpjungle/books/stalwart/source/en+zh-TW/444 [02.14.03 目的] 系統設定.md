# SystemSettings｜系統設定

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Configures core server settings including hostname, thread pool, and network services.

 配置核心伺服器設置，包括主機名稱、執行緒池和網路服務。

 This object can be configured from the WebUI under Settings › Network › Services Settings › Network › General

 此物件可透過 WebUI在「設定」&gt;「網路」&gt;「服務設定」&gt;「網路」&gt;「一般」中進行設定。

## Fields｜田野

##### `defaultHostname`

> Type: \\\`HostName\\\` · required

類型： \`HostName\` · 必填

 The default hostname to use in SMTP greetings, MTA reports and other places where a hostname is needed but not specified.

 在SMTP問候語、 MTA報告以及其他需要主機名稱但未指定的地方使用的預設主機名稱。

##### `defaultDomainId`

> Type: \\\`Id&amp;lt;\\\`\\\[\\\`Domain\\\`\\\]\\\(&lt;377 \\\[02.14.03 目的\\\] 領域.md&gt;\\\)\\\`&amp;gt;\\\` · required

類型： \`Id&amp;lt;\` \[ \`Domain\` \]\(&lt;377 \[02.14.03 目的\] 領域.md&gt;\)\`&amp;gt;\` · 必填

 Default domain to use for authentication and reports.

 用於身份驗證和報告的預設網域。

##### `defaultCertificateId`

> Type: \\\`Id&amp;lt;\\\`\\\[\\\`Certificate\\\`\\\]\\\(&lt;363 \\\[02.14.03 目的\\\] 證書.md&gt;\\\)\\\`&amp;gt;?\\\`

模式標本： \`Id&amp;lt;\` \[ \`Certificate\` \]\(&lt;363 \[02.14.03 目的\] 證書.md&gt;\)\`&amp;gt;?\`

 Default TLS certificate to use when no SNI is provided by the client

 當客戶端未提供SNI證書時，要使用的預設TLS證書

##### `threadPoolSize`

> Type: \\\`UnsignedInt?\\\` · min: 1

類型： \`UnsignedInt?\` · 最少：1

 The number of threads in the global thread pool for CPU intensive tasks. Defaults to the number of CPU cores

 用於處理CPU密集型任務的全域執行緒池中的執行緒數。預設值為CPU核心數。

##### `maxConnections`

> Type: \\\`UnsignedInt\\\` · default: \\\`8192\\\` · min: 1

類型： \`UnsignedInt\` · 預設值： \`8192\` · 最小值：1

 The maximum number of concurrent connections the server will accept

 伺服器可接受的最大並發連線數

##### `proxyTrustedNetworks`

> Type: \\\`Set<ipmask>\\\`

類型： \`Set<ipmask>\`

 Enable proxy protocol for connections from these networks

 為來自這些網路的連線啟用代理協議

##### `mailExchangers`

> Type: \\\`List&amp;lt;\\\`\\\[\\\`MailExchanger\\\`\\\]\\\(#mailexchanger\\\)\\\`&amp;gt;\\\` · default: \\\`{"0":{"priority":10}}\\\`

類型： \`List&amp;lt;\` \[ \`MailExchanger\` \]\(#mailexchanger\)\`&amp;gt;\` · 預設值： \`{"0":{"priority":10}}\`

 List of mail exchangers to publish in DNS MX records.

 要在DNS MX記錄中發布的郵件交換器清單。

##### `services`

> Type: \\\`Map&amp;lt;\\\`\\\[\\\`ServiceProtocol\\\`\\\]\\\(#serviceprotocol\\\)\\\`,\\\` \\\[\\\`Service\\\`\\\]\\\(#service\\\)\\\`&amp;gt;\\\` · default: \\\`{"caldav":{"cleartext":false},"carddav":{"cleartext":false},"imap":{"cleartext":false},"jmap":{"cleartext":false},"managesieve":{"cleartext":false},"pop3":{"cleartext":false},"smtp":{"cleartext":false},"webdav":{"cleartext":false}}\\\`

類型： \`Map&amp;lt;\` \[ \`ServiceProtocol\` \]\(#serviceprotocol\)\`,\` \[ \`Service\` \]\(#service\)\`&amp;gt;\` · 預設值： \`{"caldav":{"cleartext":false},"carddav":{"cleartext":false},"imap":{"cleartext":false},"jmap":{"cleartext":false},"managesieve":{"cleartext":false},"pop3":{"cleartext":false},"smtp":{"cleartext":false},"webdav":{"cleartext":false}}\`

 List of services to advertise in DNS and auto configuration services

 在DNS中投放廣告的服務清單及自動設定服務

##### `providerInfo`

> Type: \\\`Map&amp;lt;\\\`\\\[\\\`ProviderInfo\\\`\\\]\\\(#providerinfo\\\)\\\`, String&amp;gt;\\\`

模式標本： \`Map&amp;lt;\` \[ \`ProviderInfo\` \]\(#providerinfo\)\`, String&amp;gt;\`

 Information about the provider to advertise in auto configuration services.

 關於在自動配置服務中投放廣告的提供者的資訊。

## JMAP API

 The SystemSettings singleton is available via the `urn:stalwart:jmap` capability.

 SystemSettings 單例可透過`urn:stalwart:jmap`功能取得。

### `x:SystemSettings/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節定義。

 For singletons, the `ids` argument should be the literal `singleton` \(or `null` to return the single instance\).

 對於單例， `ids`參數應該是字面值`singleton` （或`null`以傳回單一實例）。

 This method requires the `sysSystemSettingsGet` permission.

 此方法需要`sysSystemSettingsGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:SystemSettings/get",
          {
            "ids": [
              "singleton"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:SystemSettings/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節定義。

 For singletons, only the `update` argument with id `singleton` is accepted; `create` and `destroy` arguments are rejected.

 對於單例，僅接受 id 為`singleton`的`update`參數；拒絕`create`和`destroy`參數。

 This method requires the `sysSystemSettingsUpdate` permission.

 此方法需要`sysSystemSettingsUpdate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:SystemSettings/set",
          {
            "update": {
              "singleton": {
                "defaultHostname": "mail.example.com"
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get SystemSettings
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update SystemSettings --field defaultHostname=mail.example.com
```

## Nested types｜巢狀類型

### MailExchanger｜郵件交換器

 Defines a mail exchanger for DNS MX records.

 定義DNS MX所記錄的郵件交換器。

##### `hostname`

> Type: \\\`HostName?\\\`

類型： \`HostName?\`

 The hostname of the mail exchanger, or null to use the default hostname

 郵件交換器的主機名，如果為 null 則使用預設主機名。

##### `priority`

> Type: \\\`UnsignedInt\\\` · default: \\\`10\\\` · min: 1 · max: 65535

類型： \`UnsignedInt\` · 預設值： \`10\` · 最小值：1 · 最大值：65535

 The priority of the mail exchanger, lower values are preferred. Mail exchangers with the same priority will be selected randomly.

 郵件交換器的優先級，數值越低越好。優先順序相同的郵件交換器將隨機選擇。

### Service｜服務

 Defines a service endpoint advertised in auto-configuration.

 定義在自動設定中通告的服務端點。

##### `hostname`

> Type: \\\`HostName?\\\`

類型： \`HostName?\`

 The hostname of the service, or null to use the server’s default hostname

 服務的主機名，如果為 null 則使用伺服器的預設主機名。

##### `cleartext`

> Type: \\\`Boolean\\\` · default: \\\`false\\\`

類型： \`Boolean\` · 預設值： \`false\`

 Whether to advertise the service as available without TLS encryption. This does not affect whether the service actually accepts cleartext connections, which is configured separately for each network listener.

 是否將該服務宣傳為不使用TLS加密。這並不影響該服務是否實際接受明文連接，該設定針對每個網路監聽器單獨配置。
