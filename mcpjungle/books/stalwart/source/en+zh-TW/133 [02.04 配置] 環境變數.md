# Environment variables｜環境變數

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[configuration｜配置\\\]\\\(&lt;000 目錄.md#c-18&gt;\\\)

A small number of environment variables influence how Stalwart starts. None of them are required for a normal installation; they exist for recovery, diagnostics, public URL composition, and clustering.

 少量環境變數會影響 Stalwart 的啟動方式。正常安裝不需要這些變數；它們用於恢復、診斷、公共URL組合和叢集。

## Recovery and bootstrap｜恢復和引導

 The following variables control the recovery and bootstrap modes:

 以下變數控制 恢復和 引導模式：

- **`STALWART_RECOVERY_MODE`**: enables recovery mode when set to `1` or `true`. Defaults to off, so Stalwart starts normally when the variable is unset or set to any other value.
**`STALWART_RECOVERY_MODE`**：設定為`1`或`true`時啟用恢復模式。預設為關閉，因此當該變數未設定或設定為任何其他值時，Stalwart 會正常啟動。
- **`STALWART_RECOVERY_MODE_PORT`**: HTTP port the recovery or bootstrap listener binds to. Defaults to `8080`.
**`STALWART_RECOVERY_MODE_PORT`**: HTTP恢復或引導監聽器綁定的連接埠。預設為`8080` 。
- **`STALWART_RECOVERY_MODE_LOG_LEVEL`**: verbosity of the log output while the server is in recovery or bootstrap mode. Defaults to `info`.
**`STALWART_RECOVERY_MODE_LOG_LEVEL`**：伺服器處於復原或開機模式時日誌輸出的詳細程度。預設為`info` 。
- **`STALWART_RECOVERY_ADMIN`**: configures the recovery administrator in the form `username:password`. The same variable is also used during bootstrap to pin an administrator credential instead of relying on the randomly generated one.
**`STALWART_RECOVERY_ADMIN`**：設定 恢復管理員格式為`username:password` 。在引導過程中，也使用相同的變數來固定管理員憑證，而不是依賴隨機產生的憑證。
## Public URLs｜公共網址

 The URLs published in Stalwart’s OAuth, OIDC, and JMAP discovery documents are built from a single base URL. By default that base is `https://<defaultHostname>` on port `443`, where defaultHostname is the hostname defined in the SystemSettings object. When the public-facing URL differs \(a reverse proxy on a non-standard port, a path-prefixed mount, or a different scheme during local testing\), the variable below overrides the base in full:

 Stalwart 的 OAuth、 OIDC和JMAP發現文件中發布的 URL 均基於同一個基礎 URL URL 。預設情況下，該基礎 URL 為連接埠`443`上的`https://<defaultHostname>` ，其中 defaultHostname是在 SystemSettings物件中定義的主機名稱。當面向公眾的URL不同時（例如，使用非標準連接埠上的反向代理、路徑前綴掛載或在本地測試期間使用不同的方案），以下變數將完全覆蓋基礎 URL：

- **`STALWART_PUBLIC_URL`**: the full base URL clients reach the server on, for example `https://mail.example.com`, `https://mail.example.com:8443`, or `https://example.com/mail`. When set, this value replaces the scheme, host, port, and optional path prefix in every published discovery URL. Trailing slashes are stripped. The variable does not change Stalwart’s internal listener bindings; those are configured through the NetworkListener objects.
**`STALWART_PUBLIC_URL`**：完整的基礎客戶URL透過例如`https://mail.example.com`, `https://mail.example.com:8443`或`https://example.com/mail`等連接埠連接到伺服器。設定此值後，它會取代每個已發布發現URL中的協定、主機、連接埠和可選路徑前綴。末端的斜槓將被移除。此變數不會更改 Stalwart 的內部監聽器綁定；這些綁定透過 NetworkListener物件進行配置。
`defaultHostname` is still used independently of `STALWART_PUBLIC_URL`: it appears in SMTP greetings, outgoing message headers, and TLS certificate SANs, and serves as the URL fallback when `STALWART_PUBLIC_URL` is unset. Update it through the WebUI under Settings › Network › Services or with the CLI.
`defaultHostname`仍然獨立於`STALWART_PUBLIC_URL`使用：它出現在SMTP問候語、外發郵件頭和TLS證書 SAN 中，並在`STALWART_PUBLIC_URL`未設定時用作URL回退。可透過 WebUI 下的「設定」›「網路」›「服務」或使用 CLI進行更新。

## Clustering｜聚類

 When Stalwart runs as part of a cluster, additional variables influence how a given node participates. All are covered in detail in the clustering documentation and are listed here for completeness, so operators know which values the binary reads from the environment:

 當 Stalwart 作為叢集的一部分運行時，一些額外的變數會影響特定節點參與叢集的方式。所有這些變數在叢集文件中都有詳細說明，為了完整起見，這裡列出這些變量，以便運維人員了解二進位檔案從環境中讀取哪些值：

- **`STALWART_HOSTNAME`: overrides the hostname obtained from the operating system. The override is used in two places: at runtime to acquire and renew the cluster node id lease, so that each node in a cluster has a distinct identity even when the underlying system hostnames are not unique or cannot be changed; and at setup time to pre-fill the server hostname field in Step 1 of the wizard. The variable does**not affect the URLs published in OAuth, OIDC, or JMAP discovery documents; those come from [STALWART\_PUBLIC\_URL](#public-urls) when set, or from defaultHostname otherwise.
**`STALWART_HOSTNAME`：覆蓋從作業系統取得的主機名稱。此覆蓋用於兩個方面：運行時用於獲取和續訂集群 節點 ID租約，以便即使底層系統主機名不唯一或無法更改，集群中的每個節點也具有唯一的標識；以及在設定時用於預填充嚮導步驟 1 中的伺服器主機名字段。此變量**不影響 OAuth、 OIDC或JMAP發現文檔中發布的 URL；這些 URL 在設置時來自 [STALWART\_PUBLIC\_URL](#public-urls) ，否則來自 defaultHostname 。

- **`STALWART_ROLE`**: selects which cluster role the node takes on, determining which tasks and listeners are active on that machine.
**`STALWART_ROLE`**: 選擇節點承擔的 群集角色 ，決定該機器上哪些任務和監聽器處於作用中狀態。
- **`STALWART_PUSH_SHARD`**: assigns the node to a specific push notification shard.
**`STALWART_PUSH_SHARD`**：將節點指派給特定的推播通知分片。
