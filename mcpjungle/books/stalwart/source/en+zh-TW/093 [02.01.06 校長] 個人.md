# Individual｜個人

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[auth｜認證\\\]\\\(&lt;000 目錄.md#c-3&gt;\\\) › \\\[principals｜校長\\\]\\\(&lt;000 目錄.md#c-9&gt;\\\)

The **Individual** principal type in Stalwart represents a single person or user account. It is the fundamental unit for user management, as each email user within the system is stored as an individual principal. Individual principals contain all the information necessary to manage and authenticate a user’s account, such as login credentials, email addresses, group memberships, and permissions.

 Stalwart 中的 **個人** 主體類型代表單一人或使用者帳戶。它是用戶管理的基本單元，因為系統中的每個電子郵件用戶都作為單獨的主體儲存。各個主體包含管理和驗證使用者帳戶所需的所有資訊，例如登入憑證、電子郵件地址、群組成員資格和權限。

 An individual principal holds several fields that define its properties and how it interacts with the Stalwart. Below are the key fields that an individual principal stores:

 單一主體包含多個字段，用於定義其屬性以及與 Stalwart 的互動方式。以下是單一主體儲存的關鍵字段：

- **name**: This field represents the login name or username of the account. It is the identifier used by the user to access the mail server and authenticate their session.
**名稱**：此欄位表示帳戶的登入名稱或使用者名稱。它是用戶訪問郵件伺服器並驗證其會話的標識符。
- **type**: Specifies the principal type. For user accounts, this field will always be set to `"individual"`, identifying the principal as a single user.
**類型**：指定主體類型。對於使用者帳戶，此欄位始終設定為`"individual"` ，表示主體為單一使用者。
- **quota**: Defines the storage quota allocated to the user account, measured in bytes. This value sets a limit on how much data the account can store on the mail server, including emails and attachments.
**配額**：定義分配給使用者帳戶的儲存配額，以位元組為單位。此值限制帳戶可以在郵件伺服器上儲存的資料量，包括電子郵件和附件。
- **description**: A human-readable name or description for the account. This is often the user’s full name and is typically used for display purposes within the system.
**描述**：帳戶的易於理解的名稱或描述。這通常是使用者的全名，一般用於系統內的顯示。
- **secrets: This field holds one or more**secrets, such as hashed passwords or other authentication tokens. These are used to securely authenticate the user when they attempt to log in.
**金鑰：此欄位包含一個或多個**金鑰，例如雜湊密碼或其他驗證令牌。這些金鑰用於在使用者嘗試登入時安全地驗證其身份。

- **emails**: A list of one or more email addresses associated with the account. Each user can have multiple email aliases or addresses that point to their individual account.
**電子郵件**：與帳戶關聯的一個或多個電子郵件地址的清單。每個使用者可以擁有多個指向其個人帳戶的電子郵件別名或地址。
- **memberOf**: Lists the groups that the account is a member of. Group memberships are used to organize users and manage permissions or mailing lists at a group level.
**memberOf**：列出帳號所屬的群組 。群組成員關係用於組織用戶，並在群組層級管理權限或郵件清單。
- **tenant**: Indicates the tenant to which the account belongs. This is important in multi-tenant setups where different organizations or divisions share the same mail server infrastructure but need to keep their data isolated.
**租用戶**：指示帳戶所屬的 租戶 。這在多租戶環境中非常重要，因為不同的組織或部門共享相同的郵件伺服器基礎架構，但需要保持資料隔離。
- **roles**: A list of roles assigned to the account. Roles can define a set of permissions or responsibilities for the user within the mail system, such as administrative privileges.
**角色**：指派給帳號的角色清單。角色可以定義使用者在郵件系統中的一組權限或職責，例如管理權限。
- **lists**: Lists the mailing lists that the account is subscribed to or a member of. This allows the account to receive messages sent to specific mailing lists.
**清單**：列出帳號訂閱或加入的郵件清單 。這樣，帳戶就可以接收傳送到特定郵件清單的訊息。
- **enabledPermissions**: Specifies the permissions that are enabled for the account. These permissions control what actions the user can perform, such as sending emails, accessing certain resources, or managing system settings.
**啟用權限**：指定為帳戶啟用的權限 。這些權限控制使用者可以執行哪些操作，例如傳送電子郵件、存取某些資源或管理系統設定。
- **disabledPermissions**: Specifies the permissions that are explicitly disabled for the account. These are permissions that the account does not have, which restrict certain actions or access to resources.
**disabledPermissions**：指定已明確停用帳戶的權限 。這些權限是帳戶所不具備的，會限制某些操作或對資源的存取。
- **picture**: Stores the account’s profile picture. This is an image associated with the account, often used in email clients to display alongside the user’s name or email address.
**圖片**：儲存帳戶的個人資料圖片。這是與帳戶關聯的圖像，通常用於電子郵件用戶端，與使用者的姓名或電子郵件地址一起顯示。
These fields allow the Stalwart to manage the individual user’s account, ensuring secure authentication, handling email delivery, and managing their access to groups, roles, and resources within the system.
 這些欄位可讓 Stalwart 管理單一使用者的帳戶，確保安全性驗證、處理電子郵件傳送以及管理系統內使用者對群組、角色和資源的存取權。
