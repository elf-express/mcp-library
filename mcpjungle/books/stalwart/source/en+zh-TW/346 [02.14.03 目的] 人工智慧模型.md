# AiModel｜人工智慧模型

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines an AI model endpoint for LLM-based features.

 為基於LLM的特徵定義AI模型端點。

 This object is only available with an Enterprise license.

 此物件僅適用於企業許可證 。

 This object can be configured from the WebUI under Settings › AI

 此物件可在 WebUI下的「設定」› AI中進行設定。

## Fields｜田野

##### `name`

> Type: \\\`String\\\` · required

類型： \`String\` · 必填

 Short name for the AI Model

 AI型號的簡稱

##### `allowInvalidCerts`

> Type: \\\`Boolean\\\` · default: \\\`false\\\`

類型： \`Boolean\` · 預設值： \`false\`

 Whether Stalwart should connect to an endpoint that has an invalid TLS certificate

 Stalwart 是否應該連接到具有無效TLS憑證的端點

##### `temperature`

> Type: \\\`Float\\\` · default: \\\`0.7\\\` · max: 1 · min: 0

類型： \`Float\` · 預設值： \`0.7\` · 最大值：1 · 最小值：0

 The temperature of the AI model, which controls the randomness of the output. A higher temperature will produce more random output.

 AI模型的溫度控制輸出的隨機性。溫度越高，輸出的隨機性就越大。

##### `model`

> Type: \\\`String\\\` · required

 The name of the AI model to use.

 要使用的AI型號的名稱。

##### `timeout`

> Type: \\\`Duration\\\` · default: \\\`120000\\\`

類型： \`Duration\` · 預設值： \`120000\`

 Maximum amount of time that Stalwart will wait for a response from this endpoint

 Stalwart 等待此端點回應的最長時間

##### `modelType`

> Type: \\\[\\\`AiModelType\\\`\\\]\\\(#aimodeltype\\\) · default: \\\`"Chat"\\\`

類型：\[\`AiModelType\`\]\(#aimodeltype\) · 預設值： \`"Chat"\`

 API type

 API型

##### `url`

 URL of the OpenAI compatible endpoint

 OpenAI 相容端點的URL

##### `httpAuth`

> Type: \\\[\\\`HttpAuth\\\`\\\]\\\(#httpauth\\\) · required

類型：\[\`HttpAuth\`\]\(#httpauth\) · 必填

 The type of HTTP authentication to use

 要使用的HTTP身份驗證類型

##### `httpHeaders`

> Type: \\\`Map<string, string="">\\\`

類型： \`Map&amp;lt;string, string=""&amp;gt;\`

 Additional headers to include in HTTP requests

 HTTP請求中要包含的其他標頭

## JMAP API

 The AiModel object is available via the `urn:stalwart:jmap` capability.

 AiModel 物件可透過`urn:stalwart:jmap`功能取得。

### `x:AiModel/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節定義。

 This method requires the `sysAiModelGet` permission.

 此方法需要`sysAiModelGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:AiModel/get",
          {
            "ids": [
              "id1"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:AiModel/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是 [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)節5.3中定義。

 Supports create, update, and destroy operations in a single call.

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get AiModel id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create AiModel \
  --field name=Example \
  --field model=Example \
  --field url=https://example.com \
  --field 'httpAuth={"@type":"Unauthenticated"}' \
  --field 'httpHeaders={}'
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query AiModel
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update AiModel id1 --field name='updated value'
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete AiModel --ids id1
```

## Nested types｜巢狀類型

### HttpAuth

 Defines the HTTP authentication method to use for HTTP requests.

 定義用於HTTP請求的HTTP身份驗證方法。

- **`Unauthenticated`**: Anonymous. No additional fields.
**`Unauthenticated`**：匿名。無其他字段。
- **`Basic`**: Basic Authentication. Carries the fields of [HttpAuthBasic](#httpauthbasic).
**`Basic`**：基本驗證。包含 [HttpAuthBasic](#httpauthbasic)字段。
- **`Bearer`**: Bearer Token. Carries the fields of [HttpAuthBearer](#httpauthbearer).
**`Bearer`**: 持有者令牌。攜帶 [HttpAuthBearer](#httpauthbearer)字段。
#### HttpAuthBasic

 HTTP Basic authentication credentials.

 HTTP基本驗證憑證。

##### SecretKey｜金鑰

 A secret value provided directly, from an environment variable, or from a file.

 直接提供的秘密值、來自環境變數或來自文件的值。

- **`Value`**: Secret value. Carries the fields of [SecretKeyValue](#secretkeyvalue).
**`Value`**: 秘密值。包含 [SecretKeyValue](#secretkeyvalue)的欄位。
- **`EnvironmentVariable`**: Secret read from environment variable. Carries the fields of [SecretKeyEnvironmentVariable](#secretkeyenvironmentvariable).
**`EnvironmentVariable`**: 從環境變數中讀取秘密值。包含 [SecretKeyEnvironmentVariable](#secretkeyenvironmentvariable)的欄位。
- **`File`**: Secret read from file. Carries the fields of [SecretKeyFile](#secretkeyfile).
**`File`**: 從文件中讀取秘密訊息。攜帶 [SecretKeyFile](#secretkeyfile)的場。

 直接提供一個秘密值。
