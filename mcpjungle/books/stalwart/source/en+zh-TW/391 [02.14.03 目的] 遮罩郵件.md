# MaskedEmail｜遮罩郵件

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines a masked email address for privacy protection.

 用於保護隱私的遮罩電子郵件地址。

 This object is only available with an Enterprise license.

 此物件僅在擁有企業許可證的情況下可用。

 This object can be configured from the WebUI under Account › Masked Addresses

 此物件可在 WebUI下的「帳號 › 遮罩位址」中進行設定。

## Fields｜田野

##### `enabled`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Whether this masked email address is enabled

 此遮罩電子郵件地址是否已啟用

##### `accountId`

> Type: \\\`Id&amp;lt;\\\`\\\[\\\`Account\\\`\\\]\\\(&lt;342 \\\[02.14.03 目的\\\] 帳戶.md&gt;\\\)\\\`&amp;gt;\\\` · read-only

模式標本： \`Id&amp;lt;\` \[ \`Account\` \]\(&lt;342 \[02.14.03 目的\] 帳戶.md&gt;\)\`&amp;gt;\` · 只讀

 Identifier for the account this masked email address belongs to

 此已封鎖電子郵件地址所屬帳戶的識別符

##### `email`

> Type: \\\`String\\\` · server-set

類型： \`String\` · 伺服器集

 The masked email address

 已封鎖的電子郵件地址

##### `description`

> Type: \\\`String?\\\`

類型： \`String?\`

 Description of the masked email address

 已封鎖電子郵件地址的描述

##### `forDomain`

> Type: \\\`String?\\\`

類型： \`String?\`

 The domain name of the site this address was created for, e.g. “\[[https://example.com\\\\]\\\(https://example.com/\\\)”](https://example.com%255C%255D%255C%28https://example.com/%255C%29%25E2%2580%259D). This is intended to be added automatically by password managers.

 此地址所指向的網站域名，例如「\[[https://example.com\\\\]\\\(https://example.com/\\\)](https://example.com%255C%255D%255C%28https://example.com/%255C%29) 」。此資訊將由密碼管理器自動新增。

##### `createdAt`

> Type: \\\`UTCDateTime\\\` · server-set

類型： \`UTCDateTime\` · 伺服器集

 The date-time the email address was created.

 電子郵件地址的建立日期和時間。

##### `createdBy`

> Type: \\\`String?\\\`

類型： \`String?\`

 The name of the client that created this email address. This will be set by the server automatically based on the credentials used to authenticate the request, e.g. “ACME Password Manager”（ACME密碼管理器）.

 建立此電子郵件地址的用戶端名稱。伺服器將根據用於驗證請求的憑證自動設定此名稱，例如“ACME Password Manager”（ACME密碼管理器） 。

##### `expiresAt`

> Type: \\\`UTCDateTime?\\\` · read-only

類型： \`UTCDateTime?\` · 只讀

 Expiration date of the email address

 電子郵件地址的到期日期

##### `url`

> Type: \\\`String?\\\`

類型： \`String?\`

 A URL pointing back to the integrator’s use of this email address, e.g. a custom-uri to open “ACME Password Manager”（ACME密碼管理器） at the appropriate entry.

 URL指向整合者使用此電子郵件地址，例如，自訂 URI 以在適當的條目處開啟“ACME Password Manager”（ACME密碼管理器） 。

##### `emailPrefix`

> Type: \\\`EmailLocalPart?\\\` · read-only

類型： \`EmailLocalPart?\` · 只讀

 This is only used on create and otherwise ignored; if supplied, the server-assigned email will start with the given prefix. The string MUST be &lt;= 64 characters in length and MUST only contain characters a-z, 0-9 and \\\_ \(underscore\).

 此參數僅在建立時使用，其他情況下會被忽略；如果提供此參數，伺服器指派的電子郵件將以指定的前綴開頭。字串MUST長度必須小於等於 64 個字符，且MUST只能包含字符 az、0-9 和 \\\_（底線）。

##### `emailDomain`

> Type: \\\`DomainName?\\\` · read-only

類型： \`DomainName?\` · 只讀

 This is only used on create and otherwise ignored; if supplied, the server-assigned email will end with the given domain.

 此參數僅在建立時使用，其他情況下會被忽略；如果提供此參數，伺服器指派的電子郵件將以指定的網域名稱結尾。

## JMAP API

 The MaskedEmail object is available via the `urn:stalwart:jmap` capability.

 MaskedEmail 物件可透過`urn:stalwart:jmap`功能取得。

### `x:MaskedEmail/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節定義。

 This method requires the `sysMaskedEmailGet` permission.

 此方法需要`sysMaskedEmailGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:MaskedEmail/get",
          {
            "ids": [
              "id1"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:MaskedEmail/query`

 This is a standard [Foo/query](https://www.rfc-editor.org/rfc/rfc8620#section-5.5) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.5), Section 5.5.

 這是[Foo/query](https://www.rfc-editor.org/rfc/rfc8620#section-5.5)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.5) ，第5.5節定義。

 This method requires the `sysMaskedEmailQuery` permission.

 此方法需要`sysMaskedEmailQuery` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:MaskedEmail/query",
          {
            "filter": {
              "accountId": "id1"
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

The `x:MaskedEmail/query` `filter` argument accepts the following conditions \(combinable with `AnyOf` / `AllOf` / `Not` per RFC 8620\):

| Condition 條件 | Kind 種類 |
| --- | --- |
| `accountId` | id of Account 帳戶 ID |

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get MaskedEmail id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create MaskedEmail
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query MaskedEmail
stalwart-cli query MaskedEmail --where accountId=id1
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update MaskedEmail id1 --field description='updated value'
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete MaskedEmail --ids id1
```
