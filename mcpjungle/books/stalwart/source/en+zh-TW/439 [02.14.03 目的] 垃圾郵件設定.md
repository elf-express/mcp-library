# SpamSettings｜垃圾郵件設定

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Configures global spam filter thresholds, greylisting, and trust settings.

 設定全域垃圾郵件過濾閾值、灰名單和信任設定。

 This object can be configured from the WebUI under Settings › Spam Filter › General

 此物件可在 WebUI 「設定」&gt;「垃圾郵件過濾器」&gt;「常規」中進行設定。

## Fields｜田野

##### `trustContacts`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Never classify messages as spam if they are sent from addresses present in the user’s address book.

 如果郵件是從使用者通訊錄中的地址發送的，則永遠不要將其歸類為垃圾郵件。

##### `enable`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Whether to enable the spam filter

 是否啟用垃圾郵件過濾器

##### `greylistFor`

> Type: \\\`Duration?\\\`

類型： \`Duration?\`

 Time to keep an IP address in the grey list. The grey list is used to delay messages from unknown senders.

 是時候將IP地址加入灰名單了。灰名單用於延遲來自未知寄件者的消息。

##### `scoreDiscard`

> Type: \\\`Float\\\` · default: \\\`0\\\` · max: 100 · min: -100

類型： \`Float\` · 預設值： \`0\` · 最大值：100 · 最小值：-100

 Discard messages with a score above this threshold

 丟棄得分高於此閾值的消息

##### `scoreReject`

> Type: \\\`Float\\\` · default: \\\`0\\\` · max: 100 · min: -100

類型： \`Float\` · 預設值： \`0\` · 最大值：100 · 最小值：-100

 Reject messages with a score above this threshold

 拒絕得分高於此閾值的消息

##### `scoreSpam`

> Type: \\\`Float\\\` · default: \\\`5\\\` · max: 100 · min: -100

類型： \`Float\` · 預設值： \`5\` · 最大值：100 · 最小值：-100

 Mark as Spam messages with a score above this threshold

 將得分高於此閾值的郵件標記為垃圾郵件

##### `trustReplies`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Never classify messages as spam if they are replies to messages sent by the recipient.

 如果回覆的是收件者發送的訊息，則絕不能將其歸類為垃圾郵件。

##### `spamFilterRulesUrl`

> Type: \\\`Uri?\\\` · default: \\\`"https://github.com/stalwartlabs/spam-filter/releases/latest/download/spam-filter-rules.json.gz"\\\`

類型： \`Uri?\` · 預設值： \`"[https://github.com/stalwartlabs/spam-filter/releases/latest/download/spam-filter-rules.json.gz"\\\`](https://github.com/stalwartlabs/spam-filter/releases/latest/download/spam-filter-rules.json.gz%2522%255C%2560)

 URL to download spam filter rules from

 URL從此處下載垃圾郵件過濾規則

## JMAP API

 The SpamSettings singleton is available via the `urn:stalwart:jmap` capability.

 SpamSettings 單例可透過`urn:stalwart:jmap`功能取得。

### `x:SpamSettings/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是 [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)節5.1中定義。

 For singletons, the `ids` argument should be the literal `singleton` \(or `null` to return the single instance\).

 對於單例， `ids`參數應該是字面值`singleton` （或`null`以傳回單一實例）。

 This method requires the `sysSpamSettingsGet` permission.

 此方法需要`sysSpamSettingsGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:SpamSettings/get",
          {
            "ids": [
              "singleton"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:SpamSettings/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節中定義。

 For singletons, only the `update` argument with id `singleton` is accepted; `create` and `destroy` arguments are rejected.

 對於單例，僅接受 id 為`singleton` `update`參數；拒絕`create`和`destroy`參數。

 This method requires the `sysSpamSettingsUpdate` permission.

 此方法需要`sysSpamSettingsUpdate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:SpamSettings/set",
          {
            "update": {
              "singleton": {
                "trustContacts": true
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get SpamSettings
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update SpamSettings --field trustContacts=true
```
