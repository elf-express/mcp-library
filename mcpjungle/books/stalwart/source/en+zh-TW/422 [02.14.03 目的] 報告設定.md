# ReportSettings｜報告設定

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Configures inbound report analysis and outbound report settings.

 配置入站報表分析和出站報表設定。

 This object can be configured from the WebUI under Settings › MTA › Reports › General

 此物件可在 WebUI下的「設定」› MTA › “報表” › “常規”中進行設定。

## Fields｜田野

##### `inboundReportAddresses`

> Type: \\\`Set<string>\\\` · default: \\\`{"postmaster@\\\*":true}\\\`

類型： \`Set<string>\` · 預設值： \`{"postmaster@\*":true}\`

 List of addresses \(which may include wildcards\) from which reports will be intercepted and analyzed

 將被攔截和分析的報告的位址清單（可能包含通配符）。

##### `inboundReportForwarding`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Whether reports should be forwarded to their final recipient after analysis

 分析完成後，報告是否應轉發給最終接收者？

##### `outboundReportDomain`

> Type: \\\`DomainName?\\\`

類型： \`DomainName?\`

 The default domain name used for DSNs and other reports. If left empty, the default domain will be used.

 用於 DSN 和其他報告的預設域名。如果留空，則使用預設網域名稱。

##### `outboundReportSubmitter`

> Type: \\\[\\\`Expression\\\`\\\]\\\(#expression\\\) · default: \\\`{"else":"system\\\('hostname'\\\)"}\\\`

類型：\[\`Expression\`\]\(#expression\) · 預設值： \`{"else":"system\('hostname'\)"}\`

 Report submitter address or leave empty to use the default hostname

 報告提交者地址，或留空以使用預設主機名

 Available variables: \[\`MtaRcptDomainVariable\`\]\(&lt;330 \[02.14.02.02 多變的\] MtaRcptDomainVariable.md&gt;\).

 可用變數：\[\`MtaRcptDomainVariable\`\]\(&lt;330 \[02.14.02.02 多變的\] MtaRcptDomainVariable.md&gt;\) 。

##### `inboundReportMaxSize`

> Type: \\\`Integer\\\` · default: \\\`26214400\\\` · min: 1024

類型： \`Integer\` · 預設值： \`26214400\` · 最小值：1024

 Maximum size of inbound reports to be intercepted and analyzed, in bytes. Reports larger than this size will be ignored

 待攔截和分析的入站報告的最大大小（以位元組為單位）。大於此大小的報告將被忽略。

## JMAP API

 The ReportSettings singleton is available via the `urn:stalwart:jmap` capability.

 ReportSettings 單例可透過`urn:stalwart:jmap`功能取得。

### `x:ReportSettings/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是 [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)節5.1中定義。

 For singletons, the `ids` argument should be the literal `singleton` \(or `null` to return the single instance\).

 對於單例， `ids`參數應該是字面值`singleton` （或`null`以傳回單一實例）。

 This method requires the `sysReportSettingsGet` permission.

 此方法需要`sysReportSettingsGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:ReportSettings/get",
          {
            "ids": [
              "singleton"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:ReportSettings/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節定義。

 For singletons, only the `update` argument with id `singleton` is accepted; `create` and `destroy` arguments are rejected.

 對於單例，僅接受 id 為`singleton` `update`參數；拒絕`create`和`destroy`參數。

 This method requires the `sysReportSettingsUpdate` permission.

 此方法需要`sysReportSettingsUpdate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:ReportSettings/set",
          {
            "update": {
              "singleton": {
                "inboundReportAddresses": {
                  "postmaster@*": true
                }
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get ReportSettings
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update ReportSettings --field inboundReportAddresses='{"postmaster@*":true}'
```
