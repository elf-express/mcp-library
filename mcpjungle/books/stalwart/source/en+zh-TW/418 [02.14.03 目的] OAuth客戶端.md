# OAuthClient｜OAuth客戶端

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines a registered OAuth client application.

 定義已註冊的 OAuth 用戶端應用程式。

 This object can be configured from the WebUI under Management › Directory › OAuth Clients

 可以透過 WebUI在「管理 › 目錄 › OAuth 用戶端」下設定此物件。

## JMAP API

 The OAuthClient object is available via the `urn:stalwart:jmap` capability.

 OAuthClient 物件可透過`urn:stalwart:jmap`功能取得。

### `x:OAuthClient/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是 [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)節5.1中定義。

 This method requires the `sysOAuthClientGet` permission.

 此方法需要`sysOAuthClientGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:OAuthClient/get",
          {
            "ids": [
              "id1"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:OAuthClient/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節中定義。

 Supports create, update, and destroy operations in a single call.

 支援在一次呼叫中執行建立、更新和銷毀操作。

#### Create｜創造

 This operation requires the `sysOAuthClientCreate` permission.

 此操作需要`sysOAuthClientCreate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:OAuthClient/set",
          {
            "create": {
              "new1": {
                "clientId": "Example",
                "contacts": {},
                "redirectUris": {}
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:OAuthClient/query`

 This is a standard [Foo/query](https://www.rfc-editor.org/rfc/rfc8620#section-5.5) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.5), Section 5.5.

 這是[Foo/query](https://www.rfc-editor.org/rfc/rfc8620#section-5.5)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.5) ，第5.5節定義。

 This method requires the `sysOAuthClientQuery` permission.

 此方法需要`sysOAuthClientQuery` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:OAuthClient/query",
          {
            "filter": {
              "text": "example"
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

The `x:OAuthClient/query` `filter` argument accepts the following conditions \(combinable with `AnyOf` / `AllOf` / `Not` per RFC 8620\):

`x:OAuthClient/query` `filter`參數接受以下條件（可與`AnyOf` / `AllOf` / `Not`結合使用，請參閱RFC 8620）：

| Condition 條件 | Kind 種類 |
| --- | --- |
| `text` | text 文本 |
| `clientId` | text 文本 |
| `memberTenantId` | id of Tenant 租用戶 ID |

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get OAuthClient id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create OAuthClient \
  --field clientId=Example \
  --field 'contacts={}' \
  --field 'redirectUris={}'
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query OAuthClient
stalwart-cli query OAuthClient --where text=example
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update OAuthClient id1 --field clientId='updated value'
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete OAuthClient --ids id1
```
