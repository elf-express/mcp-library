# Trace｜痕跡

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Stores a message delivery trace with associated events.

 儲存訊息傳遞追蹤訊息及相關事件。

 This object is only available with an Enterprise license.

 此物件僅在擁有企業許可證的情況下可用。

 This object can be configured from the WebUI under Management › Emails › History › Inbound Delivery Management › Emails › History › Outbound Delivery

 此物件可在 WebUI下的「管理」›「電子郵件」›「歷史記錄」›「入站交付管理」›「電子郵件」›「歷史記錄」›「出站交付」中進行設定。

## JMAP API

 The Trace object is available via the `urn:stalwart:jmap` capability.

 Trace 物件可透過`urn:stalwart:jmap`功能取得。

### `x:Trace/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是 [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節中定義。

 This method requires the `sysTraceGet` permission.

 此方法需要`sysTraceGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:Trace/get",
          {
            "ids": [
              "id1"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:Trace/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是 [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)節5.3中定義。

 Supports create, update, and destroy operations in a single call.

 支援在一次呼叫中執行建立、更新和銷毀操作。

### `x:Trace/query`

 This is a standard [Foo/query](https://www.rfc-editor.org/rfc/rfc8620#section-5.5) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.5), Section 5.5.

 這是 [Foo/query](https://www.rfc-editor.org/rfc/rfc8620#section-5.5)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.5)節5.5中定義。

 This method requires the `sysTraceQuery` permission.

 此方法需要`sysTraceQuery` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:Trace/query",
          {
            "filter": {}
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

The `x:Trace/query` `filter` argument accepts the following conditions \(combinable with `AnyOf` / `AllOf` / `Not` per RFC 8620\):

| Condition 條件 | Kind 種類 |
| --- | --- |
| `text` | text 文本 |
| `timestamp` | date 日期 |
| `queueId` | text 文本 |

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get Trace id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create Trace \
  --field 'events={}'
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query Trace
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update Trace id1 --field events='{}'
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete Trace --ids id1
```

##### TraceValue｜追蹤值

 A typed value in a trace key-value pair.

 追蹤鍵值對中的類型化值。

- **`String`**: String value. Carries the fields of [TraceValueString](#tracevaluestring).
**`String`**: 字串值。包含 [TraceValueString](#tracevaluestring)的欄位。
- **`UnsignedInt`**: Unsigned integer value. Carries the fields of [TraceValueUnsignedInt](#tracevalueunsignedint).
**`UnsignedInt`**: 無符號整數值。攜帶 [TraceValueUnsignedInt](#tracevalueunsignedint)的場。
- **`Integer`**: Integer value. Carries the fields of [TraceValueInteger](#tracevalueinteger).
**`Integer`**: 整數值。攜帶 [TraceValueInteger](#tracevalueinteger)的場。
- **`Boolean`**: Boolean value. Carries the fields of [TraceValueBoolean](#tracevalueboolean).
**`Boolean`**: 布林值。包含 [TraceValueBoolean](#tracevalueboolean)的欄位。
- **`Float`**: Float value. Carries the fields of [TraceValueFloat](#tracevaluefloat).
**`Float`**: 浮點數值。攜帶 [TraceValueFloat](#tracevaluefloat)的場。
- **`UTCDateTime`**: UTC date and time value. Carries the fields of [TraceValueUTCDateTime](#tracevalueutcdatetime).
**`UTCDateTime`**: UTC日期和時間值。包含 [TraceValueUTCDateTime](#tracevalueutcdatetime)字段。
- **`Duration`**: Duration value in seconds. Carries the fields of [TraceValueDuration](#tracevalueduration).
**`Duration`**: 持續時間值，以秒為單位。包含 [TraceValueDuration](#tracevalueduration)字段。
- **`IpAddr`**: IP address value. Carries the fields of [TraceValueIpAddr](#tracevalueipaddr).
**`IpAddr`**: IP位址值。攜帶 [TraceValueIpAddr](#tracevalueipaddr)的場。
- **`List`**: Value list. Carries the fields of [TraceValueList](#tracevaluelist).
**`List`**: 值列表。包含 [TraceValueList](#tracevaluelist)的欄位。
- **`Event`**: Nested event value. Carries the fields of [TraceValueEvent](#tracevalueevent).
**`Event`**: 嵌套事件值。包含 [TraceValueEvent](#tracevalueevent)的欄位。
- **`Null`**: Null value. No additional fields.
**`Null`**：空值。無其他字段。
