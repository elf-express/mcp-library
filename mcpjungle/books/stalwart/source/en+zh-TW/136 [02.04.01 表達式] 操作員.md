# Operators｜操作員

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[configuration｜配置\\\]\\\(&lt;000 目錄.md#c-18&gt;\\\) › \\\[expressions｜表達式\\\]\\\(&lt;000 目錄.md#c-19&gt;\\\)

Expressions may combine values using arithmetic, logical, and comparison operators.

 表達式可以使用算術運算子、邏輯運算子和比較運算子組合值。

## Arithmetic｜算術

| Operator 運算子 | Meaning 意義 |
| --- | --- |
| `+` | Addition; also string and array concatenation when either operand is non-numeric. 加法；當任一操作數為非數字時，也支援字串和陣列的連接。 |
| `-` | Subtraction, or unary negation at the start of a subexpression. 減法，或子表達式開頭的一元否定。 |
| `*` | Multiplication. 乘法。 |
| `/` | Division. 部門。 |

The `+` operator composes strings as well as numbers. Expressions such as `'sql_' + listener` or `sender + '@' + system('domain')` are the common way to build identifiers and addresses from context variables.

`+`運算子可以組合字串和數字。諸如`'sql_' + listener`或`sender + '@' + system('domain')`之類的表達式是利用上下文變數建立標識符和位址的常用方法。

## Logical｜邏輯

| Operator 運算子 | Meaning 意義 |
| --- | --- |
| `&&` | Logical AND; `&` is accepted as a synonym. 邏輯AND; `&`被認為是同義詞。 |
| `\|\|` | Logical OR; `\|` is accepted as a synonym. 邏輯OR; `\|`被認為是同義詞。 |
| `^` | Logical XOR. 邏輯XOR . |
| `!` | Logical NOT; prefix unary. 邏輯NOT ; 前綴一元。 |

Non-boolean values are coerced when used in a logical context: the empty string and the integer `0` are treated as false, every other value as true.

 在邏輯上下文中使用非布林值時，會進行強制轉換：空字串和整數`0`被視為假，所有其他值被視為真。

## Comparison｜比較

| Operator 運算子 | Meaning 意義 |
| --- | --- |
| `==` | Equal; `=` is accepted as a synonym. 相等； `=`被視為同義詞。 |
| `!=` | Not equal. 不相等。 |
| `>` | Greater than. 大於。 |
| `<` | Less than. 少於。 |
| `>=` | Greater than or equal; `=>` is accepted as a synonym. 大於或等於； `=>`被視為同義詞。 |
| `<=` | Less than or equal; `=<` is accepted as a synonym. 小於或等於； `=<`可視為同義詞。 |

Operands must be of compatible types. Comparing a string against a number with `>` or `<` does not produce a runtime error, but the ordering reflects the string representation of the number rather than its numeric value. Keeping the operands of a comparison consistent \(both numeric, or both strings\) avoids surprising behaviour.

 操作數必須類型相容。使用`>`或`<`將字串與數字進行比較不會產生運行時錯誤，但順序反映的是數字的字串表示形式，而不是其數值。保持比較運算元的一致性（均為數值或均為字串）可以避免意外行為。

## Precedence｜優先權

 From highest to lowest:

 從最高到最低：

1. Unary `!` and unary `-`.
一元`!`和一元`-` 。
2. `*`, `/`.
3. `+`, `-`.
4. `>`, `<`, `>=`, `<=`.
5. `==`, `!=`.
6. `^`.
7. `&&`.
8. `||`.
Parentheses override precedence:
 括號優先於其他字元：

```
(retry_num > 3 || notify_num > 1) && is_local_domain(rcpt_domain)
```

Without the parentheses, `&&` would bind tighter than `||` and change the meaning.

 如果沒有括號， `&&`結合力會比`||`更強，進而改變其意義。
