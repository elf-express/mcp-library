# Domain｜領域

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines an email domain and its DNS, DKIM, and TLS certificate settings.

 定義電子郵件網域及其DNS, DKIM和TLS證書設定。

 This object can be configured from the WebUI under Management › Domains › Domains

 此物件可在 WebUI下的「管理 › 網域 › 網域」中進行設定。

## JMAP API

 The Domain object is available via the `urn:stalwart:jmap` capability.

 域物件可透過`urn:stalwart:jmap`功能取得。

### `x:Domain/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節中定義。

 This method requires the `sysDomainGet` permission.

 此方法需要`sysDomainGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:Domain/get",
          {
            "ids": [
              "id1"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:Domain/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節中定義。

 Supports create, update, and destroy operations in a single call.

 支援在一次呼叫中執行建立、更新和銷毀操作。

### `x:Domain/query`

 This is a standard [Foo/query](https://www.rfc-editor.org/rfc/rfc8620#section-5.5) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.5), Section 5.5.

 這是 [Foo/query](https://www.rfc-editor.org/rfc/rfc8620#section-5.5)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.5)節5.5中定義。

 This method requires the `sysDomainQuery` permission.

 此方法需要`sysDomainQuery` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:Domain/query",
          {
            "filter": {
              "text": "example"
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

The `x:Domain/query` `filter` argument accepts the following conditions \(combinable with `AnyOf` / `AllOf` / `Not` per RFC 8620\):

| Condition 條件 | Kind 種類 |
| --- | --- |
| `text` | text 文本 |
| `name` | text 文本 |
| `memberTenantId` | id of Tenant 租用戶 ID |

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get Domain id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create Domain \
  --field name=example.com \
  --field 'aliases={}' \
  --field 'certificateManagement={"@type":"Manual"}' \
  --field 'dkimManagement={"@type":"Automatic"}' \
  --field 'dnsManagement={"@type":"Manual"}' \
  --field 'subAddressing={"@type":"Enabled"}'
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query Domain
stalwart-cli query Domain --where text=example
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update Domain id1 --field description='updated value'
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete Domain --ids id1
```

## Nested types｜巢狀類型

### CertificateManagement｜證書管理

 Defines how TLS certificates for the domain are managed.

 定義如何管理網域的TLS憑證。

- **`Manual`**: Manual TLS certificate management. No additional fields.
**`Manual`**：手動管理TLS證書。無其他字段。
- **`Automatic`**: ACME TLS certificate management. Carries the fields of [CertificateManagementProperties](#certificatemanagementproperties).
**`Automatic`**: ACME TLS證書管理。包含 [CertificateManagementProperties](#certificatemanagementproperties)的欄位。
#### CertificateManagementProperties｜憑證管理屬性

 Automatic TLS certificate management settings using an ACME provider.

 使用ACME提供者自動TLS證書管理設定。

##### `acmeProviderId`

> Type: \\\`Id&amp;lt;\\\`\\\[\\\`AcmeProvider\\\`\\\]\\\(&lt;343 \\\[02.14.03 目的\\\] AcmeProvider.md&gt;\\\)\\\`&amp;gt;\\\` · required

類型： \`Id&amp;lt;\` \[ \`AcmeProvider\` \]\(&lt;343 \[02.14.03 目的\] AcmeProvider.md&gt;\)\`&amp;gt;\` · 必填

 Identifier for the ACME provider managing certificates for this domain

 管理此網域憑證的ACME提供者的識別符

##### `subjectAlternativeNames`

> Type: \\\`Set<string>\\\`

類型： \`Set<string>\`

 Additional hostnames to include in the certificate as Subject Alternative Names \(SANs\). Enter hostnames only \(e.g. \`mta-sts\`, \`autoconfig\`\), the domain is appended automatically. To include the apex domain, enter it in full \(e.g. \`example.org\`\). Leave empty to request a wildcard certificate when possible, or to use the default SANs.

 若要包含在憑證中的其他主機名稱（作為主題備用名稱 \(SAN\)）。僅輸入主機名稱（例如\`mta-sts\`, \`autoconfig\` ），網域名稱會自動新增。若要包含根域名，請輸入完整域名（例如\`example.org\` ）。留空則盡可能申請通配符證書，或使用預設 SAN。

### DkimManagement｜Dkim管理

 Defines how DKIM keys for the domain are managed.

 定義如何管理域的DKIM金鑰。

- **`Automatic`**: Automatic DKIM management. Carries the fields of [DkimManagementProperties](#dkimmanagementproperties).
**`Automatic`**: 自動DKIM管理。承載 [DkimManagementProperties](#dkimmanagementproperties)的字段。
- **`Manual`**: Manual DKIM management. No additional fields.
**`Manual`**：手動管理DKIM 。無其他字段。
#### DkimManagementProperties

 Automatic DKIM key generation and rotation settings.

 自動DKIM金鑰產生和旋轉設定。

##### `algorithms`

> Type: \\\`Set&amp;lt;\\\`\\\[\\\`DkimSignatureType\\\`\\\]\\\(#dkimsignaturetype\\\)\\\`&amp;gt;\\\` · default: \\\`{"Dkim1Ed25519Sha256":true,"Dkim1RsaSha256":true}\\\`

類型： \`Set&amp;lt;\` \[ \`DkimSignatureType\` \]\(#dkimsignaturetype\)\`&amp;gt;\` · 預設值： \`{"Dkim1Ed25519Sha256":true,"Dkim1RsaSha256":true}\`

 List of signing algorithms to use when generating new DKIM keys

 產生新的DKIM金鑰時要使用的簽章演算法列表

##### `selectorTemplate`

> Type: \\\`String\\\` · default: \\\`"v{version}-{algorithm}-{date-%Y%m%d}"\\\`

類型： \`String\` · 預設值： \`"v{version}-{algorithm}-{date-%Y%m%d}"\`

 Template for generating DKIM selectors during key rotation. Supported variables:

 用於在按鍵輪換期間產生DKIM選擇器的模板。支援的變數：

 \-   \`{algorithm}\`: signing algorithm in lowercase \(\`rsa\`, \`ed25519\`\)
      \`{algorithm}\` ：小寫簽章演算法（ \`rsa\`, \`ed25519\` ）
\-   \`{hash}\`: hash algorithm \(\`sha256\`\)
      \`{hash}\` ：哈希演算法（ \`sha256\` ）
\-   \`{version}\`: DKIM version number \(\`1\`\)
      \`{version}\`: DKIM版本號 \( \`1\` \)
\-   \`{date-<fmt>}\`: current UTC date formatted with strftime specifiers \(e.g. \`{date-%Y%m%d}\`\)
      \`{date-<fmt>}\` : 目前UTC日期，使用 strftime 說明符格式化（例如\`{date-%Y%m%d}\` ）
\-   \`{epoch}\`: current UTC unix timestamp
      \`{epoch}\` ：當前UTC Unix 時間戳
\-   \`{random}\`: random 8-character alphanumeric string
      \`{random}\` ：隨機的 8 位元字母數字字串

##### `rotateAfter`

> Type: \\\`Duration\\\` · default: \\\`7776000000\\\`

類型： \`Duration\` · 預設值： \`7776000000\`

 How often to rotate DKIM keys. Requires automatic DNS management to be enabled for the domain.

 DKIM密鑰的輪換頻率是多少？需要為網域啟用自動DNS管理。

##### `retireAfter`

> Type: \\\`Duration\\\` · default: \\\`604800000\\\`

類型： \`Duration\` · 預設值： \`604800000\`

 How long to keep the old key’s DNS record published after rotation before removing it. Requires automatic DNS management.

 舊鑰匙輪換後，其DNS記錄需要保留多久才能移除？需要自動管理DNS記錄。

##### `deleteAfter`

> Type: \\\`Duration\\\` · default: \\\`2592000000\\\`

類型： \`Duration\` · 預設值： \`2592000000\`

 How long to retain old DKIM keys on the server after rotation before deleting them permanently. Requires automatic DNS management.

 輪換後，舊的DKIM金鑰在伺服器上保留多久後才會永久刪除？需自動DNS管理。

##### `publishRecords`

類型： \`Set&amp;lt;\` \[ \`DnsRecordType\` \]\(#dnsrecordtype\)\`&amp;gt;\` · 預設值： \`{"autoConfig":true,"autoConfigLegacy":true,"autoDiscover":true,"caa":true,"dkim":true,"dmarc":true,"mtaSts":true,"mx":true,"spf":true,"srv":true,"tlsRpt":true}\` · 最少項目數：1

**`Disabled`**：禁用子位址。無其他字段。
