# ArfExternalReport｜Arf外部報告

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Stores an ARF feedback report received from an external source.

 儲存從外部來源收到的ARF回饋報告。

 This object can be configured from the WebUI under Management › Reports › Inbox › ARF

 此物件可在 WebUI下的「管理 › 報表 › 收件匣 › ARF中進行設定。

## JMAP API

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get ArfExternalReport id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create ArfExternalReport \
  --field 'report={"authFailure":"adsp","authenticationResults":{},"deliveryResult":"delivered","feedbackType":"abuse","identityAlignment":"none","reportedDomains":{},"reportedUris":{}}' \
  --field [email protected] \
  --field subject=Example \
  --field 'to={}' \
  --field receivedAt=2026-01-01T00:00:00Z \
  --field expiresAt=2026-01-01T00:00:00Z
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query ArfExternalReport
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update ArfExternalReport id1 --field subject='updated value'
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete ArfExternalReport --ids id1
```

## Enums｜列舉

### ArfFeedbackType｜Arf回饋類型

| Value 值 | Label 標籤 |
| --- | --- |
| `abuse` | Message was reported as abusive or unwanted 此訊息被檢舉為辱罵或垃圾訊息 |
| `authFailure` | Message failed authentication checks 訊息驗證檢查失敗 |
| `fraud` | Message was reported as fraudulent 此訊息已被檢舉為詐騙訊息 |
| `notSpam` | Message was incorrectly classified as spam 此郵件被錯誤地歸類為垃圾郵件 |
| `virus` | Message contained a virus 郵件包含病毒 |
| `other` | Other feedback type 其他回饋類型 |

### ArfAuthFailureType

| Value 值 | Label 標籤 |
| --- | --- |
| `adsp` | DKIM ADSP policy failure DKIM ADSP政策失敗 |
| `bodyHash` | DKIM body hash verification failed DKIM正文哈希驗證失敗 |
| `revoked` | DKIM key has been revoked DKIM金鑰已撤銷 |
| `signature` | DKIM signature verification failed DKIM簽章驗證失敗 |
| `spf` | SPF authentication failed SPF身份驗證失敗 |
| `dmarc` | DMARC authentication failed DMARC身份驗證失敗 |
| `unspecified` | Authentication failure type not specified 未指定驗證失敗類型 |

### ArfDeliveryResult｜Arf交付結果

| Value 值 | Label 標籤 |
| --- | --- |

| `reject` | Message was rejected 郵件被拒絕 |
| `other` | Other delivery result 其他配送結果 |
