# OpenTelemetry｜開放遙測

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[telemetry｜遙測\\\]\\\(&lt;000 目錄.md#c-76&gt;\\\) › \\\[metrics｜指標\\\]\\\(&lt;000 目錄.md#c-77&gt;\\\)

OpenTelemetry is an open-source observability framework that standardises how metrics, logs, and traces are collected, processed, and exported. It defines a common wire format for telemetry data and provides SDKs and collector services for a wide range of programming languages and platforms.

 OpenTelemetry 是一個開源的可觀測性框架，它規範了指標、日誌和追蹤資料的收集、處理和匯出方式。它定義了一種通用的遙測資料傳輸格式，並為各種程式語言和平台提供 SDK 和收集器服務。

 Stalwart pushes metrics to an OpenTelemetry collector, from which they can be fanned out to backends such as Prometheus, Jaeger, or Zipkin. Pushing metrics through OpenTelemetry lets Stalwart fit into an existing observability stack with a single collector configuration.

 Stalwart 將指標推送至 OpenTelemetry 收集器，然後這些指標可以分發到 Prometheus、Jaeger 或 Zipkin 等後端。透過 OpenTelemetry 推送指標，Stalwart 只需配置一個收集器即可整合到現有的可觀測性堆疊中。

## Configuration｜配置

 The OpenTelemetry metrics exporter is configured through openTelemetry on the Metrics singleton \(found in the WebUI under Settings › Telemetry › Metrics › General, Settings › Telemetry › Metrics › OpenTelemetry, Settings › Telemetry › Metrics › Prometheus\). The field is a multi-variant nested type:

 OpenTelemetry 指標導出器透過 openTelemetry在 Metrics單例上進行設定（可在 WebUI的「設定」&gt;「遙測」&gt;「指標」&gt;「常規」、「設定」&gt;「遙測」&gt;「指標」&gt;「OpenTelemetry」或「設定」&gt;「遙測」&gt;「指標」&gt;「Prometheus」中找到）。此欄位為多變量嵌套類型：

- `Disabled` turns the exporter off.
`Disabled`關閉導出器。
- `Http` exports metrics over HTTP.
`Http`導出指標超過HTTP 。
- `Grpc` exports metrics over gRPC.
`Grpc`透過 gRPC 導出指標。
Both active variants share the following fields:
 兩種活躍變體都共用以下欄位：

- endpoint: collector endpoint URL. Required for `Http`; optional for `Grpc` \(when omitted, the SDK default endpoint is used\).
endpoint : 收集器端點URL 。 `Http`必需； `Grpc`可選（省略時，將使用SDK預設端點）。
- interval: minimum interval between push requests, in milliseconds. Default `60000` \(one minute\).
interval : 推送請求之間的最小間隔，以毫秒為單位。預設值為`60000` （一分鐘）。
- timeout: maximum time to wait for a response, in milliseconds. Default `10000` \(ten seconds\).
timeout : 等待回應的最長時間，以毫秒為單位。預設值為`10000` （十秒）。
The `Http` variant additionally carries:
`Http`變體還包含：

- httpAuth: HTTP authentication used by the exporter. A nested type with variants `Unauthenticated`, `Basic`, and `Bearer`.
httpAuth: HTTP導出器所使用的驗證。嵌套類型，具有變體`Unauthenticated`, `Basic`和`Bearer` 。
- httpHeaders: additional HTTP headers sent on each request.
httpHeaders : 在每個請求中發送的附加HTTP標頭。
## Example｜例子

 The equivalent of pushing over gRPC every thirty seconds to a collector at `https://otel-collector.example.com/v1/metrics`:

 相當於每隔三十秒將一個 gRPC 推送到`https://otel-collector.example.com/v1/metrics`處的收集器：

```json
{
  "openTelemetry": {
    "@type": "Grpc",
    "endpoint": "https://otel-collector.example.com/v1/metrics",
    "interval": 30000
  }
}
```
