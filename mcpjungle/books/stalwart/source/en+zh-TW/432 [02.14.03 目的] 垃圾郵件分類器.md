# SpamClassifier｜垃圾郵件分類器

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Configures the spam classifier model, training parameters, and auto-learning settings.

 配置垃圾郵件分類器模型、訓練參數和自動學習設定。

 This object can be configured from the WebUI under Settings › Spam Filter › Classifier

 此物件可在 WebUI的「設定」&gt;「垃圾郵件過濾器」&gt;「分類器」中進行設定。

## Fields｜田野

##### `model`

> Type: \\\[\\\`SpamClassifierModel\\\`\\\]\\\(#spamclassifiermodel\\\) · required

類型：\[\`SpamClassifierModel\`\]\(#spamclassifiermodel\) · 必填

 The spam classifier model to use.

 要使用的垃圾郵件分類模型。

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

 將寄件者自動學習為垃圾郵件的DNSBL伺服器數量

 訓練所需的最低火腿樣本數量

##### `minSpamSamples`

> Type: \\\`UnsignedInt\\\` · default: \\\`100\\\` · max: 10000 · min: 1

 訓練所需的最少垃圾郵件樣本數量

## JMAP API

 The SpamClassifier singleton is available via the `urn:stalwart:jmap` capability.

 SpamClassifier 單例可透過`urn:stalwart:jmap`功能取得。

### `x:SpamClassifier/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節中定義。

 For singletons, the `ids` argument should be the literal `singleton` \(or `null` to return the single instance\).

 對於單例， `ids`參數應該是字面值`singleton` （或`null`以傳回單一實例）。

 This method requires the `sysSpamClassifierGet` permission.

 此方法需要`sysSpamClassifierGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:SpamClassifier/get",
          {
            "ids": [
              "singleton"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:SpamClassifier/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節中定義。

 For singletons, only the `update` argument with id `singleton` is accepted; `create` and `destroy` arguments are rejected.

 對於單例，僅接受 id 為`singleton`的`update`參數；拒絕`create`和`destroy`參數。

 This method requires the `sysSpamClassifierUpdate` permission.

 此方法需要`sysSpamClassifierUpdate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:SpamClassifier/set",
          {
            "update": {
              "singleton": {
                "model": {
                  "@type": "FtrlFh"
                }
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

## Nested types｜巢狀類型

### SpamClassifierModel｜垃圾郵件分類器模型

 Defines the model used for spam classification.

 定義用於垃圾郵件分類的模型。

- **`FtrlFh`**: FTRL-Proximal + Feature Hashing. Carries the fields of [SpamClassifierFtrlFh](#spamclassifierftrlfh).
**`FtrlFh`**: FTRL -近端 + 特徵哈希。攜帶 [SpamClassifierFtrlFh](#spamclassifierftrlfh)的場。
- **`FtrlCcfh`**: FTRL-Proximal + Cuckoo Feature Hashing. Carries the fields of [SpamClassifierFtrlCcfh](#spamclassifierftrlccfh).
**`FtrlCcfh`**: FTRL -近端 + 布穀鳥特徵哈希。攜帶 [SpamClassifierFtrlCcfh](#spamclassifierftrlccfh)的場。
- **`Disabled`**: Disabled. No additional fields.
**`Disabled`**：已停用。無其他字段。
