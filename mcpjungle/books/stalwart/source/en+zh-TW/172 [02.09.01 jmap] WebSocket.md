# WebSockets｜WebSocket

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[http\\\]\\\(&lt;000 目錄.md#c-26&gt;\\\) › \\\[jmap\\\]\\\(&lt;000 目錄.md#c-27&gt;\\\)

WebSockets, described in [RFC 6455](https://www.rfc-editor.org/rfc/rfc6455), allow clients to open a two-way communication channel with a web server. Unlike HTTP, which is unidirectional and requires a new connection for each request, a WebSocket maintains a full-duplex persistent connection in which data can flow in both directions.

 WebSocket（詳見[RFC 6455](https://www.rfc-editor.org/rfc/rfc6455) ）允許客戶端與 Web 伺服器建立雙向通訊通道。與單向通訊且每次請求都需要建立新連接的HTTP不同，WebSocket 維護的是全雙工持久連接，資料可以在其中雙向流動。

## JMAP over WebSocket｜JMAP透過 WebSocket

 JMAP over WebSocket is a subprotocol described in [RFC 8887](https://www.rfc-editor.org/rfc/rfc8887.html) that runs the JMAP protocol over a WebSocket transport layer. It delivers higher throughput than JMAP over HTTP by keeping a single persistent connection open between the client and the server, removing the per-request overhead of setting up and authenticating a new HTTP request. Clients authenticate once when the connection is established; credentials remain in effect for the lifetime of the connection.

 JMAP over WebSocket 是 [RFC 8887](https://www.rfc-editor.org/rfc/rfc8887.html)中描述的子協議，它在 WebSocket 傳輸層上運行JMAP協議。它透過在客戶端和伺服器之間保持單一持久連線打開，從而提供比JMAP over HTTP更高的吞吐量，消除了每次請求建立和驗證新HTTP請求的開銷。客戶端在連線建立時進行一次身份驗證；憑證在連線的整個生命週期內有效。

 JMAP over WebSocket is enabled by default in Stalwart and is available to JMAP clients at `wss://mail.example.com`.

 Stalwart 預設啟用 WebSocket 連接， JMAP客戶端可透過JMAP存取`wss://mail.example.com` 。

## Configuration｜配置

 WebSocket behaviour is controlled by the following fields on the Jmap singleton \(found in the WebUI under Settings › Network › JMAP › Limits, Settings › Network › JMAP › Push, Settings › Network › JMAP › WebSocket\):

 WebSocket 行為由 Jmap單例中的以下欄位控制（可在 WebUI 的「設定 › 網路 › JMAP › 限制」、「設定 › 網路 › JMAP › 推」與「設定 ›Sock 或「」設定 30 30333333533335333333333333之前）： JMAP › 3：

- websocketTimeout: time after which an inactive WebSocket connection is closed. Default `"10m"`.
websocketTimeout : 關閉不活動的 WebSocket 連線的時間。預設值為`"10m"` 。
- websocketHeartbeat: interval between heartbeat packets sent to WebSocket clients. Default `"1m"`.
websocketHeartbeat : 向 WebSocket 用戶端發送心跳包的間隔。預設值為`"1m"` 。
- websocketThrottle: time to wait before sending a batch of notifications to a WebSocket client. Default `"1s"`.
websocketThrottle : 向 WebSocket 用戶端發送一批通知之前等待的時間。預設值為`"1s"` 。
