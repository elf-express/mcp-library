# Access Control｜存取控制

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[http\\\]\\\(&lt;000 目錄.md#c-26&gt;\\\)

Stalwart provides a flexible access control mechanism for the HTTP server. Rules can restrict access by IP address, resource path, method name, listener identity, and other request attributes, so that sensitive services can be exposed only to the clients and listeners that require them.

 Stalwart 為HTTP伺服器提供靈活的存取控制機制。規則可以按IP位址、資源路徑、方法名稱、監聽器標識和其他請求屬性限制訪問，以便敏感服務僅對需要它們的客戶端和監聽器公開。

## Configuration｜配置

 Access rules are carried by the allowedEndpoints expression on the Http singleton \(found in the WebUI under Settings › Network › HTTP › General, Settings › Network › HTTP › Security\). The expression is evaluated for each incoming request; it must return an HTTP status code. A result of `200` permits the request, while any other value denies it and the server responds with the returned status. By default the expression evaluates to `200`, allowing every endpoint.

`200`規則由 allowedEndpoints \([https://stalw.art/docs/ref/object/http](https://stalw.art/docs/ref/object/http)\) `200` HTTP HTTP HTTP

## Examples｜範例

### Restriction by IP address｜IP地址限制

 The following rule restricts access to `/api/*` to requests originating from `127.0.0.1`:

 以下規則限制對`/api/*`訪問，僅允許來自`127.0.0.1`的請求：

```json
{
  "allowedEndpoints": {
    "match": {
      "0": {"if": "starts_with(url_path, '/api') && remote_ip != '127.0.0.1'", "then": "404"}
    },
    "else": "200"
  }
}
```

### Restriction by IP range｜IP範圍限制

 The following rule allows public access to `/robots.txt` and `/.well-known/*`; all other requests are denied unless they originate from the `192.168.1.*` network.

 以下規則允許公眾訪問`/robots.txt`和`/.well-known/*` ；所有其他請求均被拒絕，除非它們源自`192.168.1.*`網絡。

```json
{
  "allowedEndpoints": {
    "match": {
      "0": {"if": "starts_with(remote_ip, '192.168.1.') || contains(['robots.txt', '.well-known'], split(url_path, '/')[1])", "then": "200"}
    },
    "else": "400"
  }
}
```

### Restriction by listener｜監聽器限制

 Two HTTP listeners can be defined on the NetworkListener object \(found in the WebUI under Settings › Network › Listeners\): a `private-http` listener bound to localhost, and a `public-http` listener bound to all interfaces. HTTP requests arriving through `private-http` are unrestricted, while requests coming from `public-http` are only allowed for the `/jmap`, `/robots.txt`, and `/.well-known/*` endpoints.

 可以在 \[ \([https://stalw.art/docs/ref/object/network-listener](https://stalw.art/docs/ref/object/network-listener)\) \] 物件（位於 WebUI 的「設定」&gt;「網路」&gt;「監聽器」下）上定義兩個HTTP器：一個綁定到 localhost 的`private-http`器，以及一個綁定到所有介面的`public-http`器。透過HTTP到達的請求不受限制，而來自`private-http` `public-http`請求僅允許發送到`/jmap`, `/robots.txt`和`/.well-known/*`端點。

 The rule on the Http singleton:

 關於 HTTP 單例的規則：

```json
{
  "allowedEndpoints": {
    "match": {
      "0": {"if": "listener == 'private-http' || contains(['jmap', 'robots.txt', '.well-known'], split(url_path, '/')[1])", "then": "200"}
    },
    "else": "404"
  }
}
```

### Restriction of the SCIM endpoint｜限制SCIM端點

 The SCIM provisioning endpoint is reached by an external identity provider rather than by users, so it is usually served to a small, known set of addresses. The following rule confines `/scim` to one network and leaves every other endpoint unchanged:

 SCIM配置端點由外部身分提供者而非使用者訪問，因此通常只服務於一小部分已知的位址。以下規則將`/scim`限制在一個網路中，並保持其他所有端點不變：

```json
{
  "allowedEndpoints": {
    "match": {
      "0": {"if": "starts_with(url_path, '/scim') && !starts_with(remote_ip, '203.0.113.')", "then": "404"}
    },
    "else": "200"
  }
}
```

Responding with `404` rather than `403` keeps the presence of the endpoint from being advertised to callers that are not expected to use it.

 使用`404`而不是`403`進行回應，可以防止將端點的存在通告給不希望使用該端點的呼叫者。

### Restriction by endpoint and method｜按端點和方法進行限制

 The following rule disables JMAP access unless the request is an `OPTIONS` request:

 以下規則禁用JMAP訪問，除非請求是`OPTIONS`請求：

```json
{
  "allowedEndpoints": {
    "match": {
      "0": {"if": "!starts_with(url, '/jmap') || method == 'OPTIONS'", "then": "200"}
    },
    "else": "400"
  }
}
```
