# Values｜價值觀

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[configuration｜配置\\\]\\\(&lt;000 目錄.md#c-18&gt;\\\) › \\\[expressions｜表達式\\\]\\\(&lt;000 目錄.md#c-19&gt;\\\)

Values produced by an expression can be assembled from literal strings and numbers, from context variables, and from the capture groups of a preceding regular-expression match. Three substitution mechanisms are available: context variable references, positional capture groups, and string concatenation with the `+` operator.

 表達式產生的值可以由字面字串和數字、上下文變數以及先前正規表示式匹配的捕獲組組成。有三種替換機制可用：上下文變數引用、位置捕獲組以及使用`+`運算符的字串連接。

## Literals｜字面意義

 String literals are delimited by single or double quotes: `'local'`, `"fallback"`. The two forms are equivalent; single quotes avoid the need to escape the surrounding JSON double quotes when the expression is stored in a JSON document, as is the case in every reference object that accepts an expression.

 字串文字以單引號或雙引號分隔：`'local'`, `"fallback"`。兩種形式是等價的；當表達式儲存在 JSON 文件中時，單引號避免需要轉義周圍的 JSON 雙引號，就像每個接受表達式的引用對像中的情況一樣。

 Integer literals are written as decimal digits \(`25`, `0`, `-1`\). Floating-point literals use a decimal point \(`1.26`, `-3.14`\). Boolean literals are the bare words `true` and `false`.

 整數位面量以十進位數字表示（ `25`, `0`, `-1` ）。浮點字面量使用小數點（ `1.26`, `-3.14` ）。布爾字面量是純文本，例如`true`和`false` 。

 Array literals use square brackets and comma-separated elements: `[plain, login]`, `['[[email protected]](https://stalw.art/cdn-cgi/l/email-protection)', '[[email protected]](https://stalw.art/cdn-cgi/l/email-protection)']`. Array elements may themselves be expressions.

 數組字面量使用方括號和逗號分隔的元素： `[plain, login]`, `['[[email protected]](https://stalw.art/cdn-cgi/l/email-protection)', '[[email protected]](https://stalw.art/cdn-cgi/l/email-protection)']` 。數組元素本身可以是表達式。

## Context variables｜情境變數

 Context variables are referenced by name, without any sigil. The set of available variables depends on the component evaluating the expression; Variables lists them per context. A variable reference may appear anywhere a value is expected, including inside function arguments and concatenations:

 上下文變數透過名稱引用，不帶任何符號。可用變數集取決於執行表達式的元件；變數列出了每個上下文的變數。變數引用可以出現在任何需要值的地方，包括函數參數和字串連接中：

```json
{"else": "'sql_' + listener"}
```

At runtime, `listener` is replaced with the identifier of the listener accepting the current connection \(for example `smtp` or `submission`\), producing values such as `'sql_smtp'` or `'sql_submission'`.

 在運行時， `listener`被替換為接受當前連接的監聽器的標識符（例如`smtp`或`submission` ），從而產生諸如`'sql_smtp'`或`'sql_submission'`之類的值。

## Positional variables｜位置變數

 Positional variables refer to data matched by a regular expression. They are written as `$n`, where `n` is the index of the capture group. `$0` holds the entire matched string; `$1`, `$2`, and so on hold the individual groups. The capture groups populated by the most recent `matches(...)` call in the `if` branch are available in the corresponding `then` branch.

 位置變數是指透過正規表示式來匹配的資料。它們被寫為`$n`，其中`n`是捕獲組的索引。 `$0` 保存整個符合的字串； `$1`, `$2`，依此類推，各組保持不變。由 `if` 分支中最近的 `matches(...)` 呼叫填滿的捕獲組可在對應的 `then` 分支中使用。

 For example, rewriting a recipient address by extracting the local part and the top-level domain:

 例如，透過提取本地部分和頂級網域來重寫收件者地址：

```json
{
  "rewrite": {
    "match": {
      "0": {"if": "listener != 'smtp' && matches('^([^.]+)@([^.]+)\\.(.+)$', rcpt)", "then": "$1 + '@' + $3"}
    },
    "else": "false"
  }
}
```

At runtime, `$1` and `$3` are replaced by the first and third capture groups of the regex match.

 在運行時， `$1`和`$3`被正規表示式匹配的第一個和第三個捕獲組取代。

 The backslash in the regex is doubled because the expression is shown inside a JSON document; in an expression field in the WebUI it is written once, as `\.`. See escaping backslashes.

 正規表示式中的反斜線被重複出現，因為該表達式顯示在JSON文件中；在 WebUI 的表達式欄位中，它只寫一次，即`\.` 。參見 轉義反斜線 。

## Composition｜作品

 The `+` operator concatenates strings and joins them with numeric values by converting the number to its string form. The following expression returns a tag such as `'tls-submission-10'` built from three context variables:

`+`運算子用於連接字串，並將數字轉換為字串形式，從而將字串與數值連接起來。以下表達式傳回一個由三個上下文變數構成的標籤，例如`'tls-submission-10'` ：

```json
{"else": "if_then(is_tls, 'tls', 'plain') + '-' + listener + '-' + retry_num"}
```

Arrays can be composed with the same operator, producing the concatenation of their elements: `['[[email protected]](https://stalw.art/cdn-cgi/l/email-protection)'] + recipients` prepends a fixed address to the recipient list.

 陣列可以用同一個運算子組合，產生其元素的連接： `['[[email protected]](https://stalw.art/cdn-cgi/l/email-protection)'] + recipients`將固定位址加入到收件者清單的前面。
