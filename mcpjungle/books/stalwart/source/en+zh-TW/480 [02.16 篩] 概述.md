# Overview｜概述

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[sieve｜篩\\\]\\\(&lt;000 目錄.md#c-67&gt;\\\)

Sieve is a scripting language for filtering and modifying email messages. Rather than inventing a proprietary DSL, Stalwart uses Sieve because it is an established [internet standard](https://www.rfc-editor.org/rfc/rfc5228.html) well suited to the range of filtering and transformation tasks encountered in email delivery.

 Sieve 是一種用於過濾和修改電子郵件的腳本語言。 Stalwart 沒有自行開發專有的DSL ，而是使用 Sieve，因為它是一種成熟的 [互聯網標準](https://www.rfc-editor.org/rfc/rfc5228.html)非常適合電子郵件傳遞過程中遇到的各種過濾和轉換任務。

 A Sieve script consists of one or more rules, each combining a test and an action. The test inspects an attribute of the message, such as the sender’s address or the subject line; the action specifies what to do when the test matches. This documentation focuses on how Sieve is integrated into Stalwart \(interpreters, variables, expressions, function reference, examples\) rather than on Sieve syntax itself; tutorials covering the language are collected at [sieve.info](http://sieve.info/).

 一個 Sieve 腳本由一個或多個規則組成，每個規則包含一個測試和一個操作。測試檢查郵件的某個屬性，例如寄件者地址或郵件主旨；操作指定當測試符合時要執行的操作。本文檔重點介紹 Sieve 如何整合到 Stalwart 中（解釋器、變數、表達式 、函數參考 、範例），而不是 Sieve 語法本身；有關該語言的教程收集在 [sieve.info](http://sieve.info/) 。

 Stalwart extends the standard Sieve language with its own expression syntax and a rich set of built-in functions for DNS queries, directory lookups, SQL queries, hashing, image and MIME inspection, and more, all accessible from the `eval`, `let`, and `while` instructions.

 Stalwart 擴展了標準的 Sieve 語言，它有自己的 表達式語法和 豐富的內建函數集用於DNS查詢、目錄查找、 SQL查詢、哈希、圖像和MIME檢查等等，所有這些都可以透過`eval`, `let`和`while`指令存取。

## Testing scripts｜測試腳本

 Sieve has no statement for printing a value or writing to a log, and a script installed on the server runs unseen at delivery time, so checking a filter has traditionally meant sending test messages and looking at where they land. [Sievepad](https://sievepad.com/) removes that round trip. It is a playground that runs the Stalwart Sieve interpreter in the browser, compiled to WebAssembly, so a script is compiled and executed by the same code the server uses, with no Stalwart installation involved. Scripts, test messages and settings are stored in the browser and are never uploaded.

 Sieve 沒有用於列印值或寫入日誌的語句，而且伺服器上安裝的腳本在發送訊息時是隱藏運行的，因此傳統上檢查過濾器意味著發送測試訊息並查看它們的落點。 [Sievepad](https://sievepad.com/)消除了這種往返操作。它是一個在瀏覽器中運行 Stalwart Sieve 解釋器的測試環境，編譯為 WebAssembly，因此腳本由與伺服器相同的程式碼編譯和執行，無需安裝 Stalwart。腳本、測試訊息和設定都儲存在瀏覽器中，永遠不會上傳。

 The editor compiles the script as it is typed and underlines each error at the position reported by the compiler. Running the script against a test message lists the actions it takes, such as `fileinto`, `reject` or a vacation reply, and shows every message it modifies or generates. Envelope addresses, mailboxes, spam and virus scores, the current time and the other values a script can test are set per workspace, and a workspace can be shared as a link that carries its scripts inside the URL.

 編輯器會在您輸入腳本的同時進行編譯，並在編譯器報告的每個錯誤位置新增底線。執行腳本測試郵件時，會列出腳本執行的操作，例如`fileinto`, `reject`或假期回复，並顯示腳本修改或產生的每條郵件。每個工作區都可以設定信封地址、郵箱、垃圾郵件和病毒評分、當前時間以及腳本可以測試的其他值，並且可以將工作區共享為包含腳本的鏈接，該腳本位於URL中。

 Sievepad supports the `vnd.stalwart.expressions` and `vnd.stalwart.while` extensions with the functions available to the untrusted interpreter. Functions restricted to the trusted interpreter, which reach external systems such as DNS, HTTP, SQL, key-value stores and LLM providers, are not available, and a script that calls them fails to compile. A system script that omits `require`, which the trusted interpreter accepts while noCapabilityCheck is enabled, needs the same setting in Sievepad.

 Sievepad 支援`vnd.stalwart.expressions`和`vnd.stalwart.while`擴展，並支援 非信任解釋器可用的函數。僅限 信任解釋器使用的函數（例如存取外部系統，如DNS, HTTP, SQL 、鍵值儲存和 LLM提供者 ）不可用，呼叫這些函數的腳本將無法編譯。如果系統腳本省略了`require` （在啟用 noCapabilityCheck時，信任解釋器會接受此擴充），則需要在 Sievepad 中進行相同的設定。

 Examples in this documentation that run in Sievepad are followed by a “Try this script in Sievepad” link, which opens the example in Sievepad together with the test message and settings needed to exercise it.

 本文檔中在 Sievepad 中運行的示例後面都附有“在 Sievepad 中嘗試此腳本”鏈接，點擊該鏈接即可在 Sievepad 中打開示例，並顯示測試消息和運行該示例所需的設置。
