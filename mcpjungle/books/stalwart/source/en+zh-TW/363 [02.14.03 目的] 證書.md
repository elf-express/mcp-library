# Certificate｜證書

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines a TLS certificate and its associated private key.

 定義TLS憑證及其關聯的私鑰。

 This object can be configured from the WebUI under Settings › TLS › Certificates

 此物件可在 WebUI下的「設定」› TLS ›「憑證」中進行設定。

## Fields｜田野

##### `certificate`

> Type: \\\[\\\`PublicText\\\`\\\]\\\(#publictext\\\) · required

類型：\[\`PublicText\`\]\(#publictext\) · 必填

 TLS certificate in PEM format

 TLS證書採用PEM格式

##### `privateKey`

> Type: \\\[\\\`SecretText\\\`\\\]\\\(#secrettext\\\) · required

類型：\[\`SecretText\`\]\(#secrettext\) · 必填

 證書的學科別名（ SAN ）

##### `notValidAfter`

> Type: \\\`UTCDateTime\\\` · server-set

類型： \`UTCDateTime\` · 伺服器集

 Expiration date of the certificate

 證書的有效期限

##### `notValidBefore`

> Type: \\\`UTCDateTime\\\` · server-set

 Issuance date of the certificate

 證書簽發日期

##### `issuer`

> Type: \\\`String\\\` · server-set

類型： \`String\` · 伺服器集

 Certificate issuer

 證書頒發機構

## JMAP API

 The Certificate object is available via the `urn:stalwart:jmap` capability.

 證書物件可透過`urn:stalwart:jmap`功能取得。

### `x:Certificate/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是 [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)節5.1中定義。

 This method requires the `sysCertificateGet` permission.

 此方法需要`sysCertificateGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:Certificate/get",
          {
            "ids": [
              "id1"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:Certificate/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是 [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)節5.3中定義。

 Supports create, update, and destroy operations in a single call.

 支援在一次呼叫中執行建立、更新和銷毀操作。

 This operation requires the `sysCertificateCreate` permission.

 此操作需要`sysCertificateCreate` 權限 。

### `x:Certificate/query`

 This is a standard [Foo/query](https://www.rfc-editor.org/rfc/rfc8620#section-5.5) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.5), Section 5.5.

 這是 [Foo/query](https://www.rfc-editor.org/rfc/rfc8620#section-5.5)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.5)節5.5中定義。

 This method requires the `sysCertificateQuery` permission.

 此方法需要`sysCertificateQuery` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:Certificate/query",
          {
            "filter": {
              "subjectAlternativeNames": "example"
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

The `x:Certificate/query` `filter` argument accepts the following conditions \(combinable with `AnyOf` / `AllOf` / `Not` per RFC 8620\):

`x:Certificate/query` `filter`參數接受以下條件（可與`AnyOf` / `AllOf` / `Not`結合使用，請參閱RFC 8620）：

| Condition 條件 | Kind 種類 |
| --- | --- |
| `subjectAlternativeNames` | text 文本 |

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get Certificate id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create Certificate \
  --field 'certificate={"@type":"Text","value":"Example"}' \
  --field 'privateKey={"@type":"Text","secret":"Example"}'
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query Certificate
stalwart-cli query Certificate --where subjectAlternativeNames=example
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update Certificate id1 --field certificate='{"@type":"Text","value":"Example"}'
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete Certificate --ids id1
```

## Nested types｜巢狀類型

### PublicText｜公文

 A text value provided directly, from an environment variable, or from a file.

 直接提供的文字值、來自環境變數的值或來自文件的文字值。

- **`Text`**: Text value. Carries the fields of [PublicTextValue](#publictextvalue).
**`Text`**: 文字值。包含 [PublicTextValue](#publictextvalue)字段。
- **`EnvironmentVariable`**: Text value read from environment variable. Carries the fields of [SecretKeyEnvironmentVariable](#secretkeyenvironmentvariable).
**`EnvironmentVariable`**: 從環境變數讀取的文字值。包含 [SecretKeyEnvironmentVariable](#secretkeyenvironmentvariable)的欄位。
- **`File`**: Text value read from file. Carries the fields of [SecretKeyFile](#secretkeyfile).
**`File`**: 從文件中讀取的文字值。包含 [SecretKeyFile](#secretkeyfile)的欄位。
#### PublicTextValue｜公共文字值

 A text value provided directly.

 直接提供的文字值。

### SecretText｜秘密文本

 A secret text value provided directly, from an environment variable, or from a file.

 直接提供的秘密文字值，來自環境變數或文件。

- **`Text`**: Secret value. Carries the fields of [SecretTextValue](#secrettextvalue).
**`Text`**: 秘密值。包含 [SecretTextValue](#secrettextvalue)的欄位。
- **`EnvironmentVariable`**: Secret read from environment variable. Carries the fields of [SecretKeyEnvironmentVariable](#secretkeyenvironmentvariable).
**`EnvironmentVariable`**: 從環境變數中讀取秘密值。包含 [SecretKeyEnvironmentVariable](#secretkeyenvironmentvariable)的欄位。
- **`File`**: Secret read from file. Carries the fields of [SecretKeyFile](#secretkeyfile).
**`File`**: 從文件中讀取秘密訊息。攜帶 [SecretKeyFile](#secretkeyfile)的場。
#### SecretTextValue

 A secret text value provided directly.

 直接提供秘密文字值。
