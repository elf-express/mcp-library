### Enhanced Tracing｜增強追蹤

 In previous versions of Stalwart, tracing and logging provided valuable insights but lacked the detail and comprehensiveness needed for thorough monitoring. With version 0.9.1, we have completely rewritten the tracing and logging layer, resulting in a faster and more detailed system. The new implementation leverages a lock-free data structure, enabling Stalwart to record thousands of events per second without impacting server performance. This major upgrade ensures that every significant event is captured, providing a comprehensive view of the server’s operations.

 在先前的 Stalwart 版本中，追蹤和日誌記錄雖然提供了有價值的信息，但缺乏全面監控所需的細節和完整性。在0.9.1版本中，我們完全重寫了追蹤與日誌記錄\([https://stalw.art/docs/telemetry/tracing/\)層，從而打造出一個速度更快、細節更豐富的系統。新的實作方式採用了無鎖定資料結構，使](https://stalw.art/docs/telemetry/tracing/%2529%2525E5%2525B1%2525A4%2525EF%2525BC%25258C%2525E5%2525BE%25259E%2525E8%252580%25258C%2525E6%252589%252593%2525E9%252580%2525A0%2525E5%252587%2525BA%2525E4%2525B8%252580%2525E5%252580%25258B%2525E9%252580%25259F%2525E5%2525BA%2525A6%2525E6%25259B%2525B4%2525E5%2525BF%2525AB%2525E3%252580%252581%2525E7%2525B4%2525B0%2525E7%2525AF%252580%2525E6%25259B%2525B4%2525E8%2525B1%252590%2525E5%2525AF%25258C%2525E7%25259A%252584%2525E7%2525B3%2525BB%2525E7%2525B5%2525B1%2525E3%252580%252582%2525E6%252596%2525B0%2525E7%25259A%252584%2525E5%2525AF%2525A6%2525E4%2525BD%25259C%2525E6%252596%2525B9%2525E5%2525BC%25258F%2525E6%25258E%2525A1%2525E7%252594%2525A8%2525E4%2525BA%252586%2525E7%252584%2525A1%2525E9%25258E%252596%2525E5%2525AE%25259A%2525E8%2525B3%252587%2525E6%252596%252599%2525E7%2525B5%252590%2525E6%2525A7%25258B%2525EF%2525BC%25258C%2525E4%2525BD%2525BF) Stalwart 能夠在不影響伺服器效能的情況下，每秒記錄數千個事件。此次重大升級確保了每個重要事件都能被捕獲，從而提供伺服器運作的全面視圖。

 Stalwart now generates over 600 different types of events, significantly expanding the granularity and depth of our telemetry data. These events can be sent to OpenTelemetry or Webhooks, offering flexibility in how they are processed and analyzed. Additionally, events can be recorded in log files, sent to journald, or written directly to the console, providing multiple avenues for accessing and utilizing this detailed information.

 Stalwart 現在可產生超過 600 種不同類型的事件\([https://stalw.art/docs/telemetry/events#event-types](https://stalw.art/docs/telemetry/events#event-types)\) ，顯著擴展了遙測資料的粒度和深度。這些事件可以發送到 OpenTelemetry \([https://stalw.art/docs/telemetry/tracing/opentelemetry\)或](https://stalw.art/docs/telemetry/tracing/opentelemetry%2529%2525E6%252588%252596) Webhooks \([https://stalw.art/docs/telemetry/webhooks](https://stalw.art/docs/telemetry/webhooks)\) ，從而為處理和分析事件提供了靈活性。此外，事件還可以記錄在日誌檔案中\([https://stalw.art/docs/telemetry/tracing/log](https://stalw.art/docs/telemetry/tracing/log)\) ，發送到日誌\([https://stalw.art/docs/telemetry/tracing/journal](https://stalw.art/docs/telemetry/tracing/journal)\) ，或直接寫入控制台\([https://stalw.art/docs/telemetry/tracing/console](https://stalw.art/docs/telemetry/tracing/console)\) ，從而為存取和利用這些詳細資訊提供了多種途徑。

### Comprehensive Metrics｜綜合指標

 The highlight of Stalwart Mail Server version 0.9.1 is the introduction of support for hundreds of different metrics. This enhancement enables administrators to gain deeper insights into the server’s performance and health. Metrics can be exported to OpenTelemetry using a push mechanism, allowing for real-time monitoring and analysis. Alternatively, they can be collected using Prometheus via a pull method, integrating seamlessly with existing monitoring infrastructures.

 Stalwart Mail Server 版本0.9.1的亮點在於引入了對數百種不同指標\([https://stalw.art/docs/telemetry/metrics/\)的支援。這項增強功能使管理員能夠更深入地了解伺服器的效能和運作狀況。指標可以透過推送機制匯出到](https://stalw.art/docs/telemetry/metrics/%2529%2525E7%25259A%252584%2525E6%252594%2525AF%2525E6%25258F%2525B4%2525E3%252580%252582%2525E9%252580%252599%2525E9%2525A0%252585%2525E5%2525A2%25259E%2525E5%2525BC%2525B7%2525E5%25258A%25259F%2525E8%252583%2525BD%2525E4%2525BD%2525BF%2525E7%2525AE%2525A1%2525E7%252590%252586%2525E5%252593%2525A1%2525E8%252583%2525BD%2525E5%2525A4%2525A0%2525E6%25259B%2525B4%2525E6%2525B7%2525B1%2525E5%252585%2525A5%2525E5%25259C%2525B0%2525E4%2525BA%252586%2525E8%2525A7%2525A3%2525E4%2525BC%2525BA%2525E6%25259C%25258D%2525E5%252599%2525A8%2525E7%25259A%252584%2525E6%252595%252588%2525E8%252583%2525BD%2525E5%252592%25258C%2525E9%252581%25258B%2525E4%2525BD%25259C%2525E7%25258B%252580%2525E6%2525B3%252581%2525E3%252580%252582%2525E6%25258C%252587%2525E6%2525A8%252599%2525E5%25258F%2525AF%2525E4%2525BB%2525A5%2525E9%252580%25258F%2525E9%252581%25258E%2525E6%25258E%2525A8%2525E9%252580%252581%2525E6%2525A9%25259F%2525E5%252588%2525B6%2525E5%25258C%2525AF%2525E5%252587%2525BA%2525E5%252588%2525B0) OpenTelemetry ，從而實現即時監控和分析。此外，還可以透過拉取方式使用 Prometheus收集指標，並與現有的監控基礎架構無縫整合。

 This robust metrics support ensures that users can monitor a wide range of server parameters, from resource usage to request handling, enabling proactive maintenance and troubleshooting. By providing comprehensive metrics, Stalwart Mail Server empowers administrators to make informed decisions, optimize performance, and maintain high levels of reliability.

 強大的指標支援確保使用者可以監控各種伺服器參數，從資源使用到請求處理，從而實現主動維護和故障排除。透過提供全面的指標，Stalwart Mail Server 使管理員能夠做出明智的決策、最佳化效能並保持高可靠性。

### HTTP Access Controls｜HTTP存取控制

 In addition to these telemetry improvements, Stalwart Mail Server version 0.9.1 introduces a highly requested feature: HTTP endpoint access controls. This new capability allows administrators to limit access to HTTP endpoints based on various criteria, such as remote IP or IP range, HTTP method, listener ID, and more. This fine-grained control enhances security and ensures that only authorized users can access specific server functionalities.

 除了這些遙測改進之外，Stalwart Mail Server 版本0.9.1 還引進了一項備受期待的功能：HTTP 端點存取控制。這項新功能允許管理員根據各種標準限制對HTTP端點的訪問，例如遠端IP或IP範圍、HTTP方法、偵聽器ID等。這種細粒度的控制增強了安全性，並確保只有授權使用者才能存取特定的伺服器功能。

 The introduction of HTTP endpoint access controls responds directly to user feedback, demonstrating our commitment to continually enhancing the server based on real-world needs and experiences. This feature provides an additional layer of security and customization, making Stalwart Mail Server more versatile and robust.

 HTTP端點存取控制的引入直接回應了使用者回饋，體現了我們致力於根據實際需求和體驗不斷改進伺服器的承諾。此功能提供了額外的安全性和自訂選項，使 Stalwart Mail Server 更加靈活和強大。

### Conclusion｜結論

 Stalwart Mail Server version 0.9.1 represents a significant leap forward in our telemetry capabilities, offering faster, more detailed tracing and logging, comprehensive metrics support, and new HTTP endpoint access controls. These improvements underscore our dedication to providing a powerful, efficient, and secure mail server solution.

 Stalwart 郵件伺服器版本0.9.1代表我們在遙測功能方面的重大飛躍，它提供更快、更詳細的追蹤和日誌記錄，更全面的指標支持，以及全新的HTTP端點存取控制。這些改進彰顯了我們致力於提供強大、高效且安全的郵件伺服器解決方案的決心。

 Upgrade to version 0.9.1 today and experience the next level of telemetry with Stalwart Mail Server\!

 立即升級到0.9.1版本，體驗Stalwart郵件伺服器的下一代遙測功能！
