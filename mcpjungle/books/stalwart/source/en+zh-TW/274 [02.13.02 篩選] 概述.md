# Overview｜概述

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[mta｜捷運\\\]\\\(&lt;000 目錄.md#c-47&gt;\\\) › \\\[filter｜篩選\\\]\\\(&lt;000 目錄.md#c-50&gt;\\\)

Email filtering is an essential part of any modern mail server. Filtering covers the management of incoming and outgoing messages, blocking or flagging spam, removing viruses from attachments, automating the organisation of messages, and implementing user-defined rules for message handling. Effective filtering protects the security of the mail system and supports user productivity.

 電子郵件過濾是任何現代郵件伺服器的重要組成部分。過濾涵蓋傳入和傳出郵件的管理、封鎖或標記垃圾郵件、刪除附件中的病毒、自動化郵件組織以及實施使用者定義的郵件處理規則。有效的過濾可以保護郵件系統的安全並支援使用者的工作效率。

 Stalwart supports several filtering mechanisms, which can be combined:

 Stalwart 支援多種過濾機制，可以組合使用：

- Spam filter: a built-in spam and phishing filter.
垃圾郵件過濾器：內建垃圾郵件和網路釣魚過濾器。
- Sieve scripts: scripts written in the Sieve language, a standard scripting language for mail filtering. Sieve scripts let administrators and users specify rules for handling incoming mail.
Sieve 腳本：用 Sieve 語言編寫的腳本，Sieve 語言是郵件過濾的標準腳本語言。 Sieve 腳本允許管理員和使用者指定處理傳入郵件的規則。
- Milter: a dynamic extension for mail servers that allows external software to inspect or modify messages as they are being processed. Milters support spam filtering, virus scanning, and similar workflows.
Milter：郵件伺服器的動態擴展，允許外部軟體在處理訊息時檢查或修改訊息。 Milters 支援垃圾郵件過濾、病毒掃描和類似的工作流程。
- MTA Hooks: an HTTP-based alternative to milter for managing and processing email transactions.
MTA Hooks：基於 HTTP 的 milter 替代方案，用於管理和處理電子郵件事務。
