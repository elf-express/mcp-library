# JMAP for Mail｜JMAP郵件

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[email｜電子郵件\\\]\\\(&lt;000 目錄.md#c-22&gt;\\\) › \\\[settings｜設定\\\]\\\(&lt;000 目錄.md#c-24&gt;\\\)

JMAP for Mail \([RFC8621](https://www.rfc-editor.org/rfc/rfc8621.html)\) is an extension to the [JMAP Core protocol](https://www.rfc-editor.org/rfc/rfc8620.html) that allows users to manage their email accounts using the JMAP API. The extension covers uploading, deleting, and listing emails, as well as managing mailboxes and related settings. Message-level limits and mailbox-shape constraints are carried on the Email singleton \(found in the WebUI under Settings › Email › Defaults, Settings › Email › Encryption, Settings › Email › Limits, Settings › Email › Storage\); JMAP request-parsing limits are carried on the Jmap singleton \(found in the WebUI under Settings › Network › JMAP › Limits, Settings › Network › JMAP › Push, Settings › Network › JMAP › WebSocket\).

 JMAP郵件（[RFC8621](https://www.rfc-editor.org/rfc/rfc8621.html) ）是 [JMAP核心協議](https://www.rfc-editor.org/rfc/rfc8620.html)的擴展，允許用戶使用JMAP API管理其電子郵件帳戶。此擴充涵蓋電子郵件的上傳、刪除和列表，以及郵箱和相關設定的管理。郵件層級的限制和郵件匣形狀約束由 Email單例（可在 WebUI 的「設定」&gt;「電子郵件」&gt;「預設值」、「設定」&gt;「電子郵件」&gt;「加密」、「設定」&gt;「電子郵件」&gt;「限制」和「設定」&gt;「找到資料」&gt;「儲存」中找到JMAP個請求來分析）。 \([https://stalw.art/docs/ref/object/jmap\)單例承載（可在](https://stalw.art/docs/ref/object/jmap%2529%2525E5%252596%2525AE%2525E4%2525BE%25258B%2525E6%252589%2525BF%2525E8%2525BC%252589%2525EF%2525BC%252588%2525E5%25258F%2525AF%2525E5%25259C%2525A8) WebUI 的「設定 › 網路 › JMAP › 限制」、「設定 › 網路 › JMAP › 推送」、「設定 › 網路 › JMAP 」中找到）。

## Mailbox settings｜信箱設定

 Mailbox shape is controlled through two fields on the Email singleton:

 郵箱形狀由電子郵件單例中的兩個欄位控制：

- maxMailboxDepth: maximum depth of nested mailboxes a user can create. Default `10`.
maxMailboxDepth : 使用者可以建立的最大嵌套郵箱深度。預設值為`10` 。
- maxMailboxNameLength: maximum length of a mailbox name. Default `255`.
maxMailboxNameLength : 郵箱名稱的最大長度。預設值為`255` 。
Example:
 例子：

```json
{
  "maxMailboxDepth": 10,
  "maxMailboxNameLength": 255
}
```

## Email settings｜電子郵件設定

 Message-size limits are set on the Email singleton:

 郵件大小限制是在郵件單例中設定的：

- maxAttachmentSize: maximum size, in bytes, for an email attachment. Default `50000000`.
maxAttachmentSize : 電子郵件附件的最大大小（以位元組為單位）。預設值為`50000000` 。
- maxMessageSize: maximum size, in bytes, for an email message. Default `75000000`.
maxMessageSize : 電子郵件訊息的最大大小（以位元組為單位）。預設值為`75000000` 。
The upper bound on the number of email messages that can be parsed in a single JMAP request is set on the Jmap singleton through parseLimitEmail, which defaults to `10`.
 在 Jmap 單例中，單一JMAP請求可以解析的電子郵件訊息數量的上限是透過 parseLimitEmail設定的，預設值為`10` 。

 Example:

 例子：

```json
{
  "maxAttachmentSize": 50000000,
  "maxMessageSize": 75000000
}
```

And on the Jmap singleton:

 關於 Jmap 單例：

```json
{
  "parseLimitEmail": 10
}
```
