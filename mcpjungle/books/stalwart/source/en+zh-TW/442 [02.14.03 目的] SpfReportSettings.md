# SpfReportSettings

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Configures SPF authentication failure report generation.

 配置SPF身份驗證失敗報告產生。

 This object can be configured from the WebUI under Settings › MTA › Reports › SPF

 此物件可在 WebUI下的「設定」› MTA › “報表”› SPF中進行設定。

## Fields｜田野

##### `fromAddress`

> Type: \\\[\\\`Expression\\\`\\\]\\\(#expression\\\) · default: \\\`{"else":"'noreply-spf@' + system\\\('domain'\\\)"}\\\`

類型：\[\`Expression\`\]\(#expression\) · 預設值： \`{"else":"'noreply-spf@' + system\('domain'\)"}\`

 Email address that will be used in the From header of the SPF authentication failure report email

 SPF身份驗證失敗報告電子郵件的「寄件者」標頭中將使用的電子郵件地址

 Available variables: \[\`MtaMailFromVariable\`\]\(&lt;326 \[02.14.02.02 多變的\] MtaMailFromVariable.md&gt;\).

 可用變數：\[\`MtaMailFromVariable\`\]\(&lt;326 \[02.14.02.02 多變的\] MtaMailFromVariable.md&gt;\) 。

##### `fromName`

> Type: \\\[\\\`Expression\\\`\\\]\\\(#expression\\\) · default: \\\`{"else":"'Report Subsystem'"}\\\`

類型：\[\`Expression\`\]\(#expression\) · 預設值： \`{"else":"'Report Subsystem'"}\`

 Name that will be used in the From header of the SPF authentication failure report email

 SPF身份驗證失敗報告電子郵件的「寄件者」標頭中將使用的名稱

 Available variables: \[\`MtaMailFromVariable\`\]\(&lt;326 \[02.14.02.02 多變的\] MtaMailFromVariable.md&gt;\).

 可用變數：\[\`MtaMailFromVariable\`\]\(&lt;326 \[02.14.02.02 多變的\] MtaMailFromVariable.md&gt;\) 。

##### `sendFrequency`

> Type: \\\[\\\`Expression\\\`\\\]\\\(#expression\\\) · default: \\\`{"else":"\\\[1, 1d\\\]"}\\\`

類型：\[\`Expression\`\]\(#expression\) · 預設值： \`{"else":"\[1, 1d\]"}\`

 Rate at which SPF reports will be sent to a given email address. When this rate is exceeded, no further SPF failure reports will be sent to that address

 SPF報告發送到指定電子郵件地址的頻率。當超過此頻率時，將不再向該位址發送SPF故障報告。

 Available variables: \[\`MtaMailFromVariable\`\]\(&lt;326 \[02.14.02.02 多變的\] MtaMailFromVariable.md&gt;\).

 可用變數：\[\`MtaMailFromVariable\`\]\(&lt;326 \[02.14.02.02 多變的\] MtaMailFromVariable.md&gt;\) 。

##### `dkimSignDomain`

> Type: \\\[\\\`Expression\\\`\\\]\\\(#expression\\\) · default: \\\`{"else":"system\\\('domain'\\\)"}\\\`

類型：\[\`Expression\`\]\(#expression\) · 預設值： \`{"else":"system\('domain'\)"}\`

 Which domain’s DKIM signatures to use when signing the SPF authentication failure report

 在簽署SPF身份驗證失敗報告時，應使用哪個域的DKIM簽名

 Available variables: \[\`MtaMailFromVariable\`\]\(&lt;326 \[02.14.02.02 多變的\] MtaMailFromVariable.md&gt;\).

 可用變數：\[\`MtaMailFromVariable\`\]\(&lt;326 \[02.14.02.02 多變的\] MtaMailFromVariable.md&gt;\) 。

 Subject name that will be used in the SPF authentication failure report email

 SPF身份驗證失敗報告郵件中將使用的主題名稱

## JMAP API

 The SpfReportSettings singleton is available via the `urn:stalwart:jmap` capability.

 SpfReportSettings 單例可透過`urn:stalwart:jmap`功能取得。

### `x:SpfReportSettings/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節定義。

 For singletons, the `ids` argument should be the literal `singleton` \(or `null` to return the single instance\).

 對於單例， `ids`參數應該是字面值`singleton` （或`null`以傳回單一實例）。

 This method requires the `sysSpfReportSettingsGet` permission.

 此方法需要`sysSpfReportSettingsGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:SpfReportSettings/get",
          {
            "ids": [
              "singleton"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:SpfReportSettings/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是 [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)節5.3中定義。

 For singletons, only the `update` argument with id `singleton` is accepted; `create` and `destroy` arguments are rejected.

 對於單例，僅接受 id 為`singleton` `update`參數；拒絕`create`和`destroy`參數。

 This method requires the `sysSpfReportSettingsUpdate` permission.

 此方法需要`sysSpfReportSettingsUpdate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:SpfReportSettings/set",
          {
            "update": {
              "singleton": {
                "fromAddress": {
                  "else": "'noreply-spf@' + system('domain')"
                }
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```
