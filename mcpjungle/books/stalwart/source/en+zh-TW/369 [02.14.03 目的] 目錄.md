# Directory｜目錄

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines an external directory for account authentication and lookups.

 定義用於帳戶驗證和尋找的外部目錄。

 This object can be configured from the WebUI under Settings › Authentication › Directories

 此物件可在 WebUI的「設定」&gt;「驗證」&gt;「目錄」中進行設定。

## Fields｜田野

 Directory is a **multi-variant** object: each instance has an `@type` discriminator selecting one of the variants below, and each variant carries its own set of fields.

 目錄是一個**多變體**物件：每個實例都有一個`@type`鑑別器，用於選擇以下變體之一，並且每個變體都帶有自己的一組欄位。

### `@type: "Oidc"`

 OpenID Connect

##### `description`

> Type: \\\`String\\\` · required

類型： \`String\` · 必填

 Short description of this directory

 本目錄的簡要說明

##### `issuerUrl`

> Type: \\\`Uri\\\` · required

類型： \`Uri\` · 必填

 The base URL of the OpenID Connect provider \(e.g. \[[https://sso.example.com/realms/myrealm\\\\]\\\(https://sso.example.com/realms/myrealm\\\)\\](https://sso.example.com/realms/myrealm%255C%255D%255C%28https://sso.example.com/realms/myrealm%255C%29%255C)\). Stalwart will use this URL to automatically discover the provider’s endpoints, including the token validation and user info endpoints.

 OpenID Connect 提供者的基本URL （例如 \[[https://sso.example.com/realms/myrealm\\\\]\\\(https://sso.example.com/realms/myrealm\\\)](https://sso.example.com/realms/myrealm%255C%255D%255C%28https://sso.example.com/realms/myrealm%255C%29) ）。 Stalwart 將使用此URL自動發現提供者的端點，包括令牌驗證和使用者資訊端點。

##### `requireAudience`

> Type: \\\`String?\\\`

類型： \`String?\`

 If set, Stalwart will reject any token whose aud \(audience\) claim does not include this value. Set this to the client ID or resource identifier registered for Stalwart in your identity provider to ensure tokens issued for other applications are not accepted.

 如果設定此項，Stalwart 將拒絕任何 aud（受眾）聲明不包含此值的令牌。請將其設定為客戶端ID或在您的身分提供者中為 Stalwart 註冊的資源標識符，以確保不接受為其他應用程式頒發的令牌。

##### `requireScopes`

> Type: \\\`Set<string>\\\` · default: \\\`{"email":true,"openid":true}\\\`

類型： \`Set<string>\` · 預設值： \`{"email":true,"openid":true}\`

 If set, Stalwart will reject any token that does not include all of the specified scopes. Useful for ensuring that only tokens explicitly granted access to the mail server are accepted.

 如果啟用此選項，Stalwart 將拒絕任何不包含所有指定權限範圍的令牌。這有助於確保只有明確授予郵件伺服器存取權限的令牌才會被接受。

##### `claimUsername`

> Type: \\\`String\\\` · default: \\\`"preferred\\\_username"\\\`

類型： \`String\` · 預設值： \`"preferred\_username"\`

 The claim name used to retrieve the user’s login name from the token or user info response. Common values are preferred\\\_username, email, or sub depending on your provider’s configuration. If the claim value is not an email address and usernameDomain is set, the domain will be appended automatically \(e.g. john becomes \[\\\[email protected\\\]\]\([https://stalw.art/cdn-cgi/l/email-protection#442e2b2c2a04213c25293428216a272b29\\\)\\](https://stalw.art/cdn-cgi/l/email-protection#442e2b2c2a04213c25293428216a272b29%255C%29%255C)\). If the claim value already contains an @, it is used as-is. If the claim value is not an email address and no usernameDomain is configured, Stalwart will fall back to the email claim. If neither yields a valid email address, authentication will be rejected.

 用於從令牌或使用者資訊回應中檢索使用者登入名稱的聲明名稱。常見值為 preferred\\\_username、email 或 sub，取決於您的提供者配置。如果宣告值不是電子郵件地址且設定了 usernameDomain，則會自動附加網域（例如，john 變成 \[\\\[email protected\\\]\]\( [https://stalw.art/cdn-cgi/l/email-protection#442e2b2c2a04213c25293428216a272b29](https://stalw.art/cdn-cgi/l/email-protection#442e2b2c2a04213c25293428216a272b29) \)）。如果聲明值已包含 @ 符號，則直接使用。如果聲明值不是電子郵件地址且未設定 usernameDomain，Stalwart 將回退到使用 email 聲明。如果兩者都無法提供有效的電子郵件地址，則身份驗證將被拒絕。

## JMAP API

 The Directory object is available via the `urn:stalwart:jmap` capability.

 目錄物件可透過`urn:stalwart:jmap`功能取得。

### `x:Directory/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節中定義。

 This method requires the `sysDirectoryGet` permission.

 此方法需要`sysDirectoryGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:Directory/get",
          {
            "ids": [
              "id1"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```
