# MtaSts

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Configures the MTA-STS policy for the server.

 配置伺服器的MTA-STS策略。

 This object can be configured from the WebUI under Settings › MTA › Inbound › MTA-STS

 此物件可在 WebUI下的「設定」› MTA › 「入站」› MTA-STS中進行設定。

## Fields｜田野

##### `maxAge`

> Type: \\\`Duration\\\` · default: \\\`604800000\\\`

類型： \`Duration\` · 預設值： \`604800000\`

 Maximum time to cache the MTA-STS policy

 MTA-STS策略快取的最大時間

##### `mode`

> Type: \\\[\\\`PolicyEnforcement\\\`\\\]\\\(#policyenforcement\\\) · default: \\\`"testing"\\\`

類型：\[\`PolicyEnforcement\`\]\(#policyenforcement\) · 預設值： \`"testing"\`

 Whether to enforce, test, or disable the MTA-STS policy

 是否強制執行、測試或停用MTA-STS策略

##### `mxHosts`

> Type: \\\`Set<string>\\\`

類型： \`Set<string>\`

 Override the allowed MX hosts for the MTA-STS policy domain. If empty, the MX hosts are determined from the system settings

 覆蓋策略域MTA-STS允許的MX主機。如果為空，則MX主機將從系統設定中決定。

## JMAP API

 The MtaSts singleton is available via the `urn:stalwart:jmap` capability.

 MtaSts 單例可透過`urn:stalwart:jmap`功能取得。

### `x:MtaSts/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節定義。

 For singletons, the `ids` argument should be the literal `singleton` \(or `null` to return the single instance\).

 對於單例， `ids`參數應該是字面值`singleton` （或`null`以傳回單一實例）。

 This method requires the `sysMtaStsGet` permission.

 此方法需要`sysMtaStsGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:MtaSts/get",
          {
            "ids": [
              "singleton"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:MtaSts/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是 [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)節5.3中定義。

 For singletons, only the `update` argument with id `singleton` is accepted; `create` and `destroy` arguments are rejected.

 對於單例，僅接受 id 為`singleton` `update`參數；拒絕`create`和`destroy`參數。

 This method requires the `sysMtaStsUpdate` permission.

 此方法需要`sysMtaStsUpdate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:MtaSts/set",
          {
            "update": {
              "singleton": {
                "maxAge": 604800000
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```
