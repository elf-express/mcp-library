# Untrusted Interpreter｜不受信任的翻譯

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[sieve｜篩\\\]\\\(&lt;000 目錄.md#c-67&gt;\\\) › \\\[interpreter｜翻譯\\\]\\\(&lt;000 目錄.md#c-68&gt;\\\)

The untrusted interpreter runs Sieve scripts created by end-users. Stalwart supports [JMAP for Sieve Scripts](https://www.rfc-editor.org/rfc/rfc9661.html) and [ManageSieve](https://datatracker.ietf.org/doc/html/rfc5804) for uploading and managing user scripts.

 不受信任的解釋器會執行最終使用者建立的 Sieve 腳本。 Stalwart 支援 [JMAP用於 Sieve 腳本](https://www.rfc-editor.org/rfc/rfc9661.html)和 [ManageSieve](https://datatracker.ietf.org/doc/html/rfc5804)用於上傳和管理使用者腳本。

 Interpreter settings, resource limits, and the list of globally available scripts are configured through the SieveUserInterpreter singleton \(found in the WebUI under Settings › Sieve › User Interpreter\) and the SieveUserScript object \(found in the WebUI under Settings › Sieve › User Scripts\).

 解譯器設定、資源限制和全域可用腳本清單是透過 SieveUserInterpreter單例（在 WebUI 的「設定」› Sieve › 使用者解釋器」下找到）和 SieveUserScript物件（在 Web›UI 的「設定」腳本設定。

## Limits｜限制

 User scripts execute in a sandbox that bounds their use of server resources. The limits are expressed as fields on the SieveUserInterpreter singleton:

 使用者腳本在沙箱中執行，沙箱限制了它們對伺服器資源的使用。這些限制以 SieveUserInterpreter 單例物件的欄位形式表示：

- maxScriptSize: maximum size of a Sieve script, in bytes. Default `102400` \(100 KiB\).
maxScriptSize : Sieve 腳本的最大大小，以位元組為單位。預設值為`102400` \(100 KiB\)。
- maxStringLength: maximum size of a constant string. Default `4096`.
maxStringLength : 常數字串的最大長度。預設值為`4096` 。
- maxNestedBlocks: maximum depth of nested `if` / `elsif` / `else` blocks. Default `15`.
maxNestedBlocks : 嵌套塊的最大深度`if` / `elsif` / `else` 。預設值為`15` 。
- maxNestedTests: maximum depth of nested tests. Default `15`.
maxNestedTests : 嵌套測試的最大深度。預設值為`15` 。
- maxNestedForEvery: maximum depth of nested `foreverypart` loops. Default `3`.
maxNestedForEvery : 嵌套`foreverypart`循環的最大深度。預設值為`3` 。
- maxMatchVars: maximum number of match and regex variables that can be captured. Default `30`.
maxMatchVars : 可捕獲的匹配和正規表示式變數的最大數量。預設值為`30` 。
- maxLocalVars: maximum number of local variables in scope at any point. Default `128`.
maxLocalVars : 任意時刻作用域內局部變數的最大數量。預設值為`128` 。
- maxHeaderSize: maximum length of an RFC 822 header value. Default `1024`.
maxHeaderSize : RFC 822 標頭值的最大長度。預設值為`1024` 。
- maxIncludes: maximum number of `include` instructions per script. Default `3`.
maxIncludes : 每個腳本的最大指令數`include` 。預設值`3` 。
- maxNestedIncludes: maximum depth of nested `include` instructions. Default `3`.
maxNestedIncludes : `include`指令的最大深度。預設值為`3` 。
- maxCpuCycles: maximum number of instructions a script can execute, counted across any included scripts. Default `5000`.
maxCpuCycles : 腳本可以執行的最大指令數，包括所有包含的腳本。預設值為`5000` 。
- maxVarNameLength: maximum length of a variable name. Default `32`.
maxVarNameLength : 變數名稱的最大長度。預設值為`32` 。
- maxVarSize: maximum size of a variable; contents beyond this point are truncated. Default `4096`.
maxVarSize : 變數的最大長度；超出此長度的內容將會被截斷。預設值為`4096` 。
- maxRedirects: maximum number of message redirections per execution. Default `1`.
maxRedirects : 每次執行的最大訊息重定向次數。預設值為`1` 。
- maxReceivedHeaders: maximum number of `Received` headers before a message is treated as looping. Default `10`.
maxReceivedHeaders : 訊息被視為循環之前的最大`Received`標頭數。預設值為`10` 。
- maxOutMessages: maximum number of outgoing messages \(including vacation responses, notifications, and redirects\) a script can send. Default `3`.
maxOutMessages : 腳本可以發送的最大外發訊息數（包括休假回覆、通知和重定向）。預設值為`3` 。
- maxScriptNameLength: maximum length of a script name. Default `512`.
maxScriptNameLength : 腳本名稱的最大長度。預設值為`512` 。
- maxScripts: default maximum number of Sieve scripts a single account may create. Default `100`.
maxScripts : 單一帳戶可建立的 Sieve 腳本的預設最大數量。預設值為`100` 。
Example limits:
 範例限制：

```json
{
  "maxScriptNameLength": 512,
  "maxScriptSize": 102400,
  "maxStringLength": 4096,
  "maxVarNameLength": 32,
  "maxVarSize": 4096,
  "maxNestedBlocks": 15,
  "maxNestedTests": 15,
  "maxNestedForEvery": 3,
  "maxMatchVars": 30,
  "maxLocalVars": 128,
  "maxHeaderSize": 1024,
  "maxIncludes": 3,
  "maxNestedIncludes": 3,
  "maxCpuCycles": 5000,
  "maxRedirects": 1,
  "maxReceivedHeaders": 10,
  "maxOutMessages": 3
}
```

## Extensions｜擴充

 Stalwart supports [all registered Sieve extensions](https://www.iana.org/assignments/sieve-extensions/sieve-extensions.xhtml) and enables them by default. Administrators often want to disable extensions that let a user send outgoing email from a script \(for example `enotify`\) or modify message content \(for example `editheader`, `replace`, `enclose`\).

 Stalwart 支援所有已註冊的 Sieve 擴充功能\([https://www.iana.org/assignments/sieve-extensions/sieve-extensions.xhtml](https://www.iana.org/assignments/sieve-extensions/sieve-extensions.xhtml)\) ，並預設啟用它們。管理員通常希望停用允許使用者透過腳本發送外寄郵件（例如`enotify` ）或修改郵件內容（例如`editheader`, `replace`, `enclose` ）的擴充程式。

 Disabled extensions are named as keys of disableCapabilities on SieveUserInterpreter, each with the value `true`. The accepted keys are documented on the SieveCapability enum.

 已停用的擴充功能被命名為 SieveUserInterpreter 的 disableCapabilities的鍵，每個鍵的值均為`true` 。可接受的鍵在 SieveCapability枚舉中進行了記錄。

```json
{
  "disableCapabilities": {"editheader": true, "replace": true, "enclose": true, "enotify": true}
}
```

## Notification URIs｜通知 URI

 The allowed URI schemes for the `notify` extension are named as keys of allowedNotifyUris, each with the value `true`. The default is `{"mailto": true}`.

`notify`擴充允許的URI方案被命名為 allowedNotifyUris的鍵，每個鍵的值為`true` 。預設值為`{"mailto": true}` 。

```json
{
  "allowedNotifyUris": {"mailto": true}
}
```

## Protected Headers｜受保護的標頭

 Headers that cannot be added or removed by the `editheader` extension are named as keys of protectedHeaders, each with the value `true`. The default is `{"Original-Subject": true, "Original-From": true, "Received": true, "Auto-Submitted": true}`.

 無法透過`editheader`擴充新增或刪除的標頭被命名為 protectedHeaders的鍵，每個鍵的值為`true` 。預設值為`{"Original-Subject": true, "Original-From": true, "Received": true, "Auto-Submitted": true}` 。

```json
{
  "protectedHeaders": {"Original-Subject": true, "Original-From": true, "Received": true, "Auto-Submitted": true}
}
```

## Vacation defaults｜假期預設設定

 Defaults for the `vacation` extension are exposed on SieveUserInterpreter through:

`vacation`擴充的預設值透過 SieveUserInterpreter 公開：

- defaultSubject: default subject of vacation responses. Default `"Automated reply"`.
defaultSubject : 假期回覆的預設主題。預設值為`"Automated reply"` 。
- defaultSubjectPrefix: prefix prepended to vacation response subjects. Default `"Auto: "`.
defaultSubjectPrefix : 加到假期回覆主題的前綴。預設值為`"Auto: "` 。

```json
{
  "defaultSubject": "Automated reply",
  "defaultSubjectPrefix": "Auto: "
}
```

## Expiration defaults｜到期預設值

 The default lifetimes for identifiers stored by the `vacation` and `duplicate` extensions are controlled by:

 由`vacation`和`duplicate`擴充儲存的標識符的預設生命週期由下列因素控制：

- defaultExpiryVacation: default expiration for vacation response tracking, in milliseconds. Default `2592000000` \(30 days\).
defaultExpiryVacation : 假期回應追蹤的預設過期時間，以毫秒為單位。預設值為`2592000000` \(30 天\)。
- defaultExpiryDuplicate: default expiration for identifiers stored by the `duplicate` extension, in milliseconds. Default `604800000` \(7 days\).
defaultExpiryDuplicate : 由`duplicate`擴充儲存的標識符的預設過期時間，以毫秒為單位。預設值為`604800000` \(7 天\)。

```json
{
  "defaultExpiryVacation": 2592000000,
  "defaultExpiryDuplicate": 604800000
}
```

## Global Scripts｜全域腳本

 Global user scripts are published as SieveUserScript records. Each record carries a name, an optional description, an isActive flag, and the script body in contents. Users reference these scripts from their own scripts with `include :global`.

 全域使用者腳本以 SieveUserScript記錄的形式發布。每筆記錄包含一個 name 、一個可選的 description 、一個 isActive 、一個 contents使用者可以透過`include :global`在自己的腳本中引用這些腳本。

 For example, a global script that rejects messages larger than 100 KB:

 例如，一個全域腳本會拒絕大於 100 的訊息KB :

```json
{
  "name": "global_one",
  "description": "Reject oversized messages",
  "isActive": true,
  "contents": "# Declare the extensions used by this script.\n#\nrequire [\"reject\"];\n\n# Messages bigger than 100K will be rejected with an error message\n#\nif size :over 100K {\n    reject \"I'm sorry, I do not accept mail over 100kb in size. Please upload larger files to a server and send me a link. Thanks.\";\n}\n"
}
```

The contents field holds the full script text; loading the script body from an external file is not supported.

 contents欄位包含完整的腳本文字；不支援從外部檔案載入腳本主體。
