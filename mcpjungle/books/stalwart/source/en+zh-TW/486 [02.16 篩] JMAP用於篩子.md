# JMAP for Sieve｜JMAP用於篩子

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[sieve｜篩\\\]\\\(&lt;000 目錄.md#c-67&gt;\\\)

JMAP for Sieve \([RFC9661](https://www.rfc-editor.org/rfc/rfc9661.html)\) is an extension to the JMAP protocol that allows users to manage their Sieve scripts using the JMAP API. This extension provides a way for users to upload, delete, and list their Sieve scripts, as well as to set a default script for their account. Support for JMAP for Sieve is enabled by default in Stalwart, and no additional configuration is required. However, it is possible to disable on a per-user basis by disabling the JMAP for Sieve permissions for the user.

 JMAP for Sieve \([RFC9661](https://www.rfc-editor.org/rfc/rfc9661.html) \) 是 JMAP協定的擴展，允許使用者使用JMAP API管理其 Sieve 腳本。此擴充功能為使用者提供了一種上傳、刪除和列出其 Sieve 腳本的方法，以及為其帳戶設定預設腳本的方法。 Stalwart 預設啟用對JMAP for Sieve 的支持，無需額外配置。但是，可以透過停用使用者的JMAP for Sieve 權限來單獨停用此功能。
