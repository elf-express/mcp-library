# SpamLlm

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Configures the LLM-based spam classifier.

 配置基於LLM的垃圾郵件分類器。

 This object is only available with an Enterprise license.

 此物件僅在擁有企業許可證的情況下可用。

 This object can be configured from the WebUI under Settings › Spam Filter › LLM Classifier

 此物件可在 WebUI 「設定」&gt;「垃圾郵件過濾器」&gt; LLM 「分類器」中進行設定。

## Fields｜田野

 SpamLlm is a **multi-variant** object: each instance has an `@type` discriminator selecting one of the variants below, and each variant carries its own set of fields.

 SpamLlm 是一個**多變體**物件：每個實例都有一個`@type`鑑別器，用於選擇以下變體之一，並且每個變體都帶有自己的一組欄位。

### `@type: "Disable"`

 Disabled

 已停用

### `@type: "Enable"`

 Enabled

 已啟用

##### `categories`

類型： \`Set<string>\` · 預設值： \`{"Commercial":true,"Harmful":true,"Legitimate":true,"Unsolicited":true}\` · 最少項目數：2

 The expected categories in the LLM response

 LLM響應的預期置信水平

## JMAP API

 The SpamLlm singleton is available via the `urn:stalwart:jmap` capability.

 SpamLlm 單例可透過`urn:stalwart:jmap`功能取得。

### `x:SpamLlm/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節定義。

 For singletons, the `ids` argument should be the literal `singleton` \(or `null` to return the single instance\).

 對於單例， `ids`參數應該是字面值`singleton` （或`null`以傳回單一實例）。

 This method requires the `sysSpamLlmGet` permission.

 此方法需要`sysSpamLlmGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:SpamLlm/get",
          {
            "ids": [
              "singleton"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:SpamLlm/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節定義。

 For singletons, only the `update` argument with id `singleton` is accepted; `create` and `destroy` arguments are rejected.

 對於單例，僅接受 id 為`singleton` `update`參數；拒絕`create`和`destroy`參數。

 This method requires the `sysSpamLlmUpdate` permission.

 此方法需要`sysSpamLlmUpdate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:SpamLlm/set",
          {
            "update": {
              "singleton": {
                "description": "updated value"
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```
