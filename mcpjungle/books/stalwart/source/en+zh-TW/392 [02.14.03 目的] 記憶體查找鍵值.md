# MemoryLookupKeyValue｜記憶體查找鍵值

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines an in-memory lookup key-value pair.

 定義記憶體中的查找鍵值對。

 This object can be configured from the WebUI under Settings › Lookups › In-Memory Key-Values

 可以透過 WebUI下的「設定」›「尋找」›「記憶體鍵值」來設定此物件。

## Fields｜田野

##### `namespace`

> Type: \\\`String\\\` · required

類型： \`String\` · 必填

 The namespace of the key

 鍵的命名空間

##### `key`

> Type: \\\`String\\\` · required · max length: 255

類型： \`String\` · 必需 · 最大長度：255

 The key name

 密鑰名稱

##### `value`

> Type: \\\`String\\\` · required

類型： \`String\` · 必填

 The key value

 關鍵值

##### `isGlobPattern`

> Type: \\\`Boolean\\\` · default: \\\`false\\\`

類型： \`Boolean\` · 預設值： \`false\`

 Whether the key is a glob pattern

 密鑰是否為全域模式

## JMAP API

 The MemoryLookupKeyValue object is available via the `urn:stalwart:jmap` capability.

 MemoryLookupKeyValue 物件可透過`urn:stalwart:jmap`功能取得。

### `x:MemoryLookupKeyValue/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是 [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)節5.1中定義。

 This method requires the `sysMemoryLookupKeyValueGet` permission.

 此方法需要`sysMemoryLookupKeyValueGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;

  -H 'Authorization: Bearer $TOKEN' \

      "methodCalls": [
        [
          "x:MemoryLookupKeyValue/get",

            "ids": [

          },
```

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get MemoryLookupKeyValue id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create MemoryLookupKeyValue \
  --field namespace=Example \
  --field key=Example \
  --field value=Example
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query MemoryLookupKeyValue
stalwart-cli query MemoryLookupKeyValue --where namespace=example
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update MemoryLookupKeyValue id1 --field namespace='updated value'
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete MemoryLookupKeyValue --ids id1
```
