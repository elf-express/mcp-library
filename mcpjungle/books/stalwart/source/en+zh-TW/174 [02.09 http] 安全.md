# Security｜安全

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[http\\\]\\\(&lt;000 目錄.md#c-26&gt;\\\)

The HTTP server exposes two transport-security controls on the Http singleton \(found in the WebUI under Settings › Network › HTTP › General, Settings › Network › HTTP › Security\): HTTP Strict Transport Security \(HSTS\) and a permissive CORS policy. These controls enforce secure communication practices and determine how cross-origin requests are handled.

 HTTP 伺服器在 Http單例（可在 WebUI 的「設定」&gt;「網路」&gt;「HTTP」&gt;「常規」或「設定」&gt;「網路」&gt;「HTTP」&gt;「安全性」中找到）上公開了兩個傳輸安全控制：HTTP 嚴格傳輸安全 \(HSTS\) 和寬鬆的 CORS 原則。這些控制用於強制執行安全的通訊實踐，並決定如何處理跨域請求。

## Strict Transport Security｜嚴格的運輸安全

 HTTP Strict Transport Security \(HSTS\) is a web security policy mechanism that instructs compliant user agents to interact with the server only over HTTPS, protecting against protocol-downgrade attacks and cookie hijacking. Enabling HSTS guarantees that every subsequent request is encrypted and reduces the risk of active eavesdropping or session hijacking.

 HTTP嚴格傳輸安全 \( HSTS \) 是一種 Web 安全策略機制，它指示符合規範的用戶代理僅透過HTTPS與伺服器交互，從而防止協議降級攻擊和 Cookie 劫持。啟用HSTS可確保每個後續請求都經過加密，並降低主動竊聽或會話劫持的風險。

 HSTS is enabled by setting enableHsts to `true`. The default is `false`.

 將 enableHsts設定為`true`來啟用HSTS 。預設值為`false` 。

## Permissive CORS Policy｜寬鬆的CORS政策

 Cross-Origin Resource Sharing \(CORS\) is a browser security feature that controls how a web page loaded from one origin can request resources from another origin. By default, browsers block these cross-origin requests; the server must opt in by returning the appropriate CORS headers.

 跨網域資源共享 \( CORS \) 是一項瀏覽器安全功能，用於控制從一個來源載入的網頁如何從另一個來源要求資源。預設情況下，瀏覽器會阻止這些跨域請求；伺服器必須透過傳回對應的CORS標頭來啟用此功能。

 A permissive CORS policy can be useful when the Stalwart server is managed through a WebUI hosted on a different domain. Setting usePermissiveCors to `true` instructs the server to accept requests from any origin. The default is `false`.

 當 Stalwart 伺服器透過託管在不同網域上的 WebUI 進行管理時，寬鬆的CORS策略非常有用。將 usePermissiveCors設定為`true`會指示伺服器接受來自任何來源的請求。預設值為`false` 。

 This is the broadest possible CORS setting. When enabling it, ensure that every sensitive endpoint is protected by appropriate authentication and authorization checks, because browsers will no longer restrict cross-origin access to the server’s resources.

 這是最廣泛的CORS設定。啟用此設定後，請確保每個敏感端點都受到適當的身份驗證和授權檢查的保護，因為瀏覽器將不再限制對伺服器資源的跨網域存取。
