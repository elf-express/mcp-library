# StoreLookup｜商店查找

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines an external store used for lookups.

 定義用於尋找的外部儲存。

 This object can be configured from the WebUI under Settings › Lookups › Store Lookups

 可以透過 WebUI下的「設定」›「尋找」›「儲存尋找」來設定此物件。

##### `store`

> Type: \\\[\\\`LookupStore\\\`\\\]\\\(#lookupstore\\\) · required

類型：\[\`LookupStore\`\]\(#lookupstore\) · 必填
