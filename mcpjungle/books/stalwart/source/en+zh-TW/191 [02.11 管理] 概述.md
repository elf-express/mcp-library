# Overview｜概述

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[management｜管理\\\]\\\(&lt;000 目錄.md#c-31&gt;\\\)

Every management and configuration operation in Stalwart goes through the same JMAP API. Three tools expose that API in different forms, and operators typically choose one per task:

 Stalwart 中的所有管理和配置操作都經過相同的JMAP API 。有三種工具以不同的形式公開該API ，操作員通常為每個任務選擇其中一種：

 The WebUI is the browser-based administration console and the recommended entry point for interactive management. It covers every configurable object and offers forms, dashboards, and a self-service account manager for end users.

 WebUI是基於瀏覽器的管理控制台，也是互動式管理的建議入口點。它涵蓋了所有可配置對象，並為最終用戶提供表單、儀表板和自助式帳戶管理器。

 The CLI \(`stalwart-cli`\) calls the same JMAP API from a terminal. It is the right tool for scripting, automation, and declarative deployments on platforms such as NixOS, Ansible, or Terraform.

 CLI \( `stalwart-cli` \) 從終端呼叫相同的JMAP API 。它是用於在 NixOS、Ansible 或 Terraform 等平台上進行腳本編寫、自動化和聲明式部署的理想工具。

 For programmatic access from a host application, the JMAP API can be called directly over HTTP. Each JMAP method is documented on the schema reference pages alongside the object it operates on.

 對於從主機應用程式進行編程訪問，可以直接透過JMAP API呼叫HTTP 。每個JMAP方法都與它所操作的物件一起記錄在 模式參考頁面上。
