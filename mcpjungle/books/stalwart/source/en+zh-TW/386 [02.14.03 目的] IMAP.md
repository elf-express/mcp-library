# Imap｜IMAP

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Configures IMAP protocol settings including authentication, timeouts, and rate limits.

 配置IMAP協定設置，包括身份驗證、逾時和速率限制。

 This object can be configured from the WebUI under Settings › Network › IMAP

 此物件可在 WebUI下的「設定」›「網路」› IMAP中進行設定。

## Fields｜田野

##### `allowPlainTextAuth`

> Type: \\\`Boolean\\\` · default: \\\`false\\\`

類型： \`Boolean\` · 預設值： \`false\`

 Whether to allow plain text authentication on unencrypted connections

 是否允許在未加密的連線上進行明文身份驗證

##### `maxAuthFailures`

> Type: \\\`UnsignedInt\\\` · default: \\\`3\\\` · min: 1

類型： \`UnsignedInt\` · 預設值： \`3\` · 最小值：1

 Number of authentication attempts a user can make before being disconnected by the server

 使用者在被伺服器中斷連線之前可以進行的身份驗證嘗試次數

##### `maxConcurrent`

> Type: \\\`UnsignedInt?\\\` · default: \\\`16\\\` · min: 1

類型： \`UnsignedInt?\` · 預設值： \`16\` · 最小值：1

 The maximum number of concurrent connections

 最大並發連線數

##### `maxRequestRate`

> Type: \\\[\\\`Rate\\\`\\\]\\\(#rate\\\)\\\`?\\\` · default: \\\`{"count":2000,"period":60000}\\\`

類型：\[ \`Rate\` \]\(#rate\)\`?\` · 預設值： \`{"count":2000,"period":60000}\`

 The maximum number of requests per minute

 每分鐘最大請求數

##### `maxRequestSize`

> Type: \\\`Size\\\` · default: \\\`52428800\\\`

類型： \`Size\` · 預設值： \`52428800\`

 Maximum size of an IMAP request that the server will accept

 伺服器可接受的IMAP請求的最大大小

##### `timeoutAnonymous`

> Type: \\\`Duration\\\` · default: \\\`60000\\\`

類型： \`Duration\` · 預設值： \`60000\`

 Time an unauthenticated session can stay inactive before being ended by the server

 未經身份驗證的會話在被伺服器終止之前可以保持不活動狀態的時間。

##### `timeoutAuthenticated`

> Type: \\\`Duration\\\` · default: \\\`1800000\\\`

類型： \`Duration\` · 預設值： \`1800000\`

 Time an authenticated session can remain idle before the server terminates it

 在伺服器終止已認證會話之前，該會話可以保持空閒的時間。

##### `timeoutIdle`

> Type: \\\`Duration\\\` · default: \\\`1800000\\\`

類型： \`Duration\` · 預設值： \`1800000\`

 Time a connection can stay idle in the IMAP IDLE state before the server breaks the connection

 伺服器斷開連線之前，連線在IMAP IDLE狀態下可以保持空閒的時間。

##### `maxMessagesPerCommand`

> Type: \\\`UnsignedInt\\\` · default: \\\`1000000\\\` · min: 1000

類型： \`UnsignedInt\` · 預設值： \`1000000\` · 最小值：1000

 Maximum number of messages processed by a single FETCH, SEARCH, STORE, MOVE or UID EXPUNGE command, announced to clients through the MESSAGELIMIT capability. Lowering this truncates results for clients that do not implement RFC 9738

 單一FETCH, SEARCH, STORE, MOVE或UID EXPUNGE指令處理的最大訊息數，透過 MESSAGELIMIT 功能通知客戶端。降低此值會截斷未實現RFC 9738 的客戶端的結果。

##### `minUidBatchSize`

> Type: \\\`UnsignedInt\\\` · default: \\\`500\\\` · min: 1 · max: 500

類型： \`UnsignedInt\` · 預設值： \`500\` · 最小值：1 · 最大值：500

 Smallest batch size a client may ask for in a UIDBATCHES command; smaller requests are rejected with a TOOFEW response code. Cannot exceed 500, which is the batch size every server is required to support

 UIDBATCHES 指令中用戶端可以要求的最小批次大小；小於此值的請求將被拒絕，並傳回TOOFEW回應碼。不能超過 500，這是每個伺服器必須支援的批次大小。

##### `maxUidBatches`

> Type: \\\`UnsignedInt\\\` · default: \\\`10000\\\` · min: 1

類型： \`UnsignedInt\` · 預設值： \`10000\` · 最小值：1

 Maximum number of UID ranges returned by a single UIDBATCHES command; wider requests are rejected with a TOOMANY response code

 單一 UIDBATCHES 指令傳回的UID範圍的最大數量；超出範圍的請求將被拒絕，並傳回TOOMANY回應碼

##### `maxMessagesPerSave`

> Type: \\\`UnsignedInt\\\` · default: \\\`1000000\\\` · min: 1000

類型： \`UnsignedInt\` · 預設值： \`1000000\` · 最小值：1000

 Maximum number of messages accepted by a single COPY or APPEND command, announced to clients through the SAVELIMIT capability. These commands are atomic, so exceeding the limit stores nothing; keep it at or above the MESSAGELIMIT value

 單一COPY或APPEND指令可接受的最大訊息數，透過 SAVELIMIT 功能通知客戶端。這些命令是原子性的，因此超過此限制不會儲存任何內容；請將其保持在 MESSAGELIMIT 值或以上。

## JMAP API

 The Imap singleton is available via the `urn:stalwart:jmap` capability.

 Imap 單例可透過`urn:stalwart:jmap`功能取得。

### `x:Imap/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是 [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)節5.1中定義。

 For singletons, the `ids` argument should be the literal `singleton` \(or `null` to return the single instance\).

 對於單例， `ids`參數應該是字面值`singleton` （或`null`以傳回單一實例）。

 This method requires the `sysImapGet` permission.

 此方法需要`sysImapGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:Imap/get",
          {
            "ids": [
              "singleton"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:Imap/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節定義。

 For singletons, only the `update` argument with id `singleton` is accepted; `create` and `destroy` arguments are rejected.

 對於單例，僅接受 id 為`singleton` `update`參數；拒絕`create`和`destroy`參數。

 This method requires the `sysImapUpdate` permission.

 此方法需要`sysImapUpdate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:Imap/set",
          {
            "update": {
              "singleton": {
                "allowPlainTextAuth": false
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get Imap
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update Imap --field allowPlainTextAuth=false
```
