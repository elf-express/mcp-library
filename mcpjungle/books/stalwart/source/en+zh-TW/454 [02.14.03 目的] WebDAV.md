# WebDav｜WebDAV

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Configures WebDAV protocol settings including property limits and locking.

 配置 WebDAV 協定設置，包括屬性限制和鎖定。

 This object can be configured from the WebUI under Settings › Network › WebDAV

 此物件可在 WebUI 「設定」&gt;「網路」&gt;「WebDAV」中進行設定。

## Fields｜田野

##### `enableAssistedDiscovery`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Enables assisted discovery of WebDAV shared collections by modifying PROPFIND requests to the root collection. Requests with depth 1 are automatically changed to depth 2, which may cause compatibility issues with some clients that expect the original behavior.

 透過修改根集合的PROPFIND請求，實現WebDAV共享集合的輔助發現。深度為1的請求會自動變更為深度為2，這可能會導致與某些期望原始行為的用戶端出現相容性問題。

##### `maxLockTimeout`

> Type: \\\`Duration\\\` · default: \\\`3600000\\\`

類型： \`Duration\` · 預設值： \`3600000\`

 Specifies the maximum duration for which a lock can be held on a resource

 指定對資源保持鎖定的最大持續時間

##### `maxLocks`

> Type: \\\`UnsignedInt\\\` · default: \\\`10\\\`

類型： \`UnsignedInt\` · 預設值： \`10\`

 Specifies the maximum number of locks that a user can create on a resource

 指定使用者可以在資源上建立的最大鎖數。

##### `deadPropertyMaxSize`

> Type: \\\`Size?\\\` · default: \\\`1024\\\`

類型： \`Size?\` · 預設值： \`1024\`

 Specifies the maximum size of a WebDAV dead property value that the server will accept

 指定伺服器將接受的 WebDAV 死屬性值的最大大小

##### `livePropertyMaxSize`

> Type: \\\`Size\\\` · default: \\\`250\\\`

類型： \`Size\` · 預設值： \`250\`

 Specifies the maximum size of a WebDAV live property value that the server will accept

 指定伺服器將接受的 WebDAV 即時屬性值的最大大小。

##### `requestMaxSize`

> Type: \\\`Size\\\` · default: \\\`26214400\\\`

類型： \`Size\` · 預設值： \`26214400\`

 Determines the maximum XML size of a WebDAV request that the server will accept

 確定伺服器將接受的 WebDAV 請求的最大大小XML 。

##### `maxResults`

> Type: \\\`UnsignedInt\\\` · default: \\\`2000\\\`

類型： \`UnsignedInt\` · 預設值： \`2000\`

 Specifies the maximum number of results that a WebDAV query can return

 指定 WebDAV 查詢可以傳回的最大結果數

## JMAP API

 The WebDav singleton is available via the `urn:stalwart:jmap` capability.

 WebDav 單例可透過`urn:stalwart:jmap`功能取得。

### `x:WebDav/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是 [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)節5.1中定義。

 For singletons, the `ids` argument should be the literal `singleton` \(or `null` to return the single instance\).

 對於單例， `ids`參數應該是字面值`singleton` （或`null`以傳回單一實例）。

 This method requires the `sysWebDavGet` permission.

 此方法需要`sysWebDavGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:WebDav/get",
          {
            "ids": [
              "singleton"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:WebDav/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是 [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)節5.3中定義。

 For singletons, only the `update` argument with id `singleton` is accepted; `create` and `destroy` arguments are rejected.

 對於單例，僅接受 id 為`singleton` `update`參數；拒絕`create`和`destroy`參數。

 This method requires the `sysWebDavUpdate` permission.

 此方法需要`sysWebDavUpdate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:WebDav/set",
          {
            "update": {
              "singleton": {
                "enableAssistedDiscovery": true
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get WebDav
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update WebDav --field enableAssistedDiscovery=true
```
