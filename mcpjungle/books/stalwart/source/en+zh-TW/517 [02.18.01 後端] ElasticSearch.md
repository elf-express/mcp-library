# ElasticSearch

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[storage｜貯存\\\]\\\(&lt;000 目錄.md#c-72&gt;\\\) › \\\[backends｜後端\\\]\\\(&lt;000 目錄.md#c-73&gt;\\\)

Elasticsearch is an open-source, distributed search and analytics engine built on Apache Lucene. It handles textual, numerical, geospatial, structured, and unstructured data, providing high scalability and near real-time search. When full-text search volumes grow beyond what the internal engine handles comfortably, Elasticsearch is a common choice as an external search backend.

 Elasticsearch 是一個基於 Apache Lucene 的開源分散式搜尋和分析引擎。它能夠處理文字、數值、地理空間、結構化和非結構化數據，提供高可擴展性和近乎即時的搜尋能力。當全文搜尋量超出內部引擎的處理能力時，Elasticsearch 通常是外部搜尋後端的首選。

## Configuration｜配置

 The Elasticsearch backend is selected by choosing the `ElasticSearch` variant on the SearchStore object \(found in the WebUI under Settings › Storage › Search Store\). The variant exposes the following fields:

 若要選擇 Elasticsearch 後端，請在 SearchStore物件上選擇`ElasticSearch`變體（可在 WebUI 的「設定」&gt;「儲存」&gt;「搜尋儲存」中找到）。該變體公開以下欄位：

- url: URL of the Elasticsearch server or cluster endpoint \(required\).
Elasticsearch 伺服器或叢集端點的 url: URL （必需）。
- timeout: maximum time to wait for an HTTP response. Default: `"30s"`.
timeout : 等待HTTP回應的最長時間。預設值： `"30s"` 。
- allowInvalidCerts: when `true`, accepts connections with invalid TLS certificates. Default: `false`.
allowInvalidCerts : 當`true`時，接受具有無效TLS證書的連接。預設值： `false` 。
- httpAuth: authentication method used for HTTP requests \(required\). The `Unauthenticated`, `Basic`, and `Bearer` variants are supported.
httpAuth : 用於HTTP請求的驗證方法（必需）。支持`Unauthenticated`, `Basic`和`Bearer`變體。
- httpHeaders: additional headers attached to every HTTP request.
httpHeaders : 附加到每個HTTP請求的附加標頭。
### Authentication｜驗證

 For HTTP Basic authentication, select the `Basic` variant of httpAuth and supply `username` and `secret`. For bearer-token authentication, select the `Bearer` variant and supply `bearerToken`. Secrets may be provided inline, read from an environment variable, or loaded from a file.

 對於基本驗證HTTP ，請選擇 httpAuth的`Basic`變體，並提供`username`和`secret` 。對於持有者令牌身份驗證，請選擇`Bearer`變體，並提供`bearerToken` 。密鑰可以內聯提供、從環境變數讀取或從檔案載入。

### Index settings｜索引設定

 Stalwart maps its search data to an Elasticsearch index whose shape is controlled by the following fields:

 Stalwart 將其搜尋資料對應到 Elasticsearch 索引，該索引的形狀由下列欄位控制：

- numShards: number of primary shards for the index. Default: `3`.
numShards : 索引的主分片數。預設值： `3` 。
- numReplicas: number of replica shards per primary. Default: `0`.
numReplicas : 每個主節點的複本分片數。預設值： `0` 。
- includeSource: when `true`, indexes the full source document alongside the inverted index. Default: `false`.
includeSource : 當`true`時，將整個來源文件與倒排索引一起建立索引。預設值： `false` 。
