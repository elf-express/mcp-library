# Redis

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[storage｜貯存\\\]\\\(&lt;000 目錄.md#c-72&gt;\\\) › \\\[backends｜後端\\\]\\\(&lt;000 目錄.md#c-73&gt;\\\)

Redis \(Remote Dictionary Server\) is an in-memory data-structure store used as a database, cache, and message broker. It supports a range of data structures \(strings, hashes, lists, sets, sorted sets, bitmaps, hyperloglogs, geospatial indexes, streams\), replication, Lua scripting, LRU eviction, transactions, and several levels of on-disk persistence. Valkey, the open-source Redis-compatible fork, is also supported through the same variant.

 Redis（遠端字典伺服器）是一個記憶體資料結構儲存系統，可用作資料庫、快取和訊息代理。它支援多種資料結構（字串、雜湊表、列表、集合、有序集合、位圖、HyperLogLog、地理空間索引、流），支援資料複製、Lua腳本、 LRU驅逐機制、事務以及多種層級的磁碟持久化。開源的Redis相容分支Valkey也透過相同的變體得到支援。

 Redis is supported only as an in-memory store. It cannot be used as the primary data store or as a blob store.

 Redis 僅支援作為 內存存儲使用。它不能用作主資料儲存或 blob 儲存。

## Standalone configuration｜獨立配置

 The standalone Redis backend is selected by choosing the `Redis` variant on the InMemoryStore object \(found in the WebUI under Settings › Storage › In-Memory Store\). The variant exposes the following fields:

 若要選擇獨立的 Redis 後端，請在 InMemoryStore物件上選擇`Redis`變體（可在 WebUI 的「設定」&gt;「儲存」&gt;「記憶體儲存」中找到）。該變體公開以下欄位：

- url: connection URL for the Redis server. Default: `"redis://127.0.0.1"`. The URL may embed a username, password, port, and database index: `redis[s]://[<username>][:@]<hostname>[:port][/<db>]#insecure`. The `#insecure` fragment disables TLS verification when using the `rediss` scheme, which is useful with self-signed certificates.
url : Redis 伺服器的連接URL 。 URL值： `"redis://127.0.0.1"`可以嵌入使用者名稱、密碼、連接埠和資料庫索引： `redis[s]://[<username>][:@]<hostname>[:port][/<db>]#insecure`片段在使用`#insecure` `rediss`時停用TLS驗證，這對於自簽名憑證很有用。
- timeout: maximum time to wait for a response from the Redis server. Default: `"10s"`.
timeout : 等待 Redis 伺服器回應的最長時間。預設值： `"10s"` 。
- poolMaxConnections: maximum number of pooled connections. Default: `10`.
poolMaxConnections : 最大連接池連接數。預設值： `10` 。
- poolTimeoutCreate, poolTimeoutWait, poolTimeoutRecycle: connection-pool lifecycle timeouts. Default: `"30s"` each.
poolTimeoutCreate , poolTimeoutWait , poolTimeoutRecycle : 連接池生命週期逾時。預設值： `"30s"`每個。
## Cluster configuration｜叢集配置

 The Redis Cluster backend is selected by choosing the `RedisCluster` variant on the InMemoryStore object. The variant exposes the following fields:

 透過選擇 InMemoryStore物件上的`RedisCluster`變體來選擇 Redis 集群後端。該變體公開以下欄位：

- urls: list of connection URLs for the cluster nodes.
urls : 叢集節點的連接 URL 清單。
- authUsername: username used to authenticate. Default: `"stalwart"`.
authUsername : 用於驗證的使用者名稱。預設值： `"stalwart"` 。
- authSecret: password or other secret reference used to authenticate \(required\).
authSecret : 用於身份驗證的密碼或其他秘密參考資訊（必填）。
- timeout: maximum time to wait for a response from the Redis server. Default: `"10s"`.
timeout : 等待 Redis 伺服器回應的最長時間。預設值： `"10s"` 。
- maxRetries, minRetryWait, maxRetryWait: command retry policy controlling the total number of retries and the backoff between attempts.
maxRetries , minRetryWait , maxRetryWait : 指令重試策略，控制重試總數與嘗試之間的退避。
- readFromReplicas: when `true`, allows reads to be served by replica nodes; when `false`, reads are restricted to the primary. Default: `true`.
readFromReplicas : 當`true`時，允許副本節點提供讀取服務；當`false`時，讀取僅限於主節點。預設值： `true` 。
- protocolVersion: Redis protocol version. Supported values are `resp2` and `resp3`. Default: `resp2`.
protocolVersion : Redis 協定版本。支援的值為`resp2`和`resp3` 。預設值： `resp2` 。
- The pool lifecycle fields \(poolMaxConnections, poolTimeoutCreate, poolTimeoutWait, poolTimeoutRecycle\) mirror those of the standalone variant.
池生命週期欄位（poolMaxConnections , poolTimeoutCreate , poolTimeoutWait , `poolTimeoutRecycle` \([https://stalw.art/docs/ref/object/in-memory-store#pooltimeoutrecycle](https://stalw.art/docs/ref/object/in-memory-store#pooltimeoutrecycle)\) 5
To distribute load across several independent Redis deployments, combine multiple Redis or Redis Cluster backends through the Sharded in-memory store.
 為了將負載分配到多個獨立的 Redis 部署中，可以透過 分片記憶體儲存將多個 Redis 或 Redis 叢集後端組合起來。
