# Quotas｜配額

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[mta｜捷運\\\]\\\(&lt;000 目錄.md#c-47&gt;\\\) › \\\[outbound｜出站\\\]\\\(&lt;000 目錄.md#c-52&gt;\\\)

Quotas set limits on the message queue to control its size and total number of messages. Stalwart supports dynamic quotas, which can limit the total size and number of messages waiting to be delivered based on multiple variables. When a queue quota is exceeded, messages are temporarily rejected with a 4xx SMTP code, protecting the server from becoming overwhelmed while ensuring important messages continue to be delivered.

 配額用於限制訊息佇列的大小和訊息總數。 Stalwart 支援動態配額，可根據多個變數限制待處理訊息的總大小和數量。當佇列配額超出時，訊息將被暫時拒絕，並傳回 4xx SMTP錯誤代碼，從而防止伺服器過載，同時確保重要訊息能夠繼續送達。

## Settings｜設定

 Each queue quota is defined as an MtaQueueQuota object \(found in the WebUI under Settings › MTA › Rates & Quotas › Queue Quotas\). The relevant fields are:

 每個佇列配額都定義為一個 MtaQueueQuota物件（可在 WebUI 的「設定」&gt; MTA 」&gt;「費率和配額」&gt;「佇列配額」中找到）。相關欄位如下：

- enable: whether the quota is active. Default `true`.
enable : 配額是否有效。預設值為`true` 。
- messages: optional maximum number of messages that the queue will accept.
messages : 可選參數，佇列將接受的最大訊息數。
- size: optional maximum total size of messages in the queue.
size : 可選參數，佇列中訊息的最大總大小。
- key: set of context variables that determine the grouping of this quota \(see [Groups](#groups) below\).
key : 決定此配額分組的上下文變數集（見下文 [Groups](#groups) ）。
- match: expression evaluated to decide whether the quota applies to a given message.
match : 用於確定配額是否適用於給定訊息的表達式。
A quota may define only a message limit, only a size limit, or both. An MtaQueueQuota with an empty `key` and a `match` expression that always returns true imposes a global limit.
 配額可以僅定義訊息限制、僅定義大小限制，或兩者都定義。如果 MtaQueueQuota 的`key`為空，且`match`表達式總是傳回 true，則該配額會施加全域限制。

 A global quota of 100,000 messages / 10 GB:

 全球配額為 100,000 則訊息 / 10 GB :

```json
{
  "enable": true,
  "key": {},
  "match": {"else": "true"},
  "messages": 100000,
  "size": 10737418240
}
```

## Groups｜團體

 The key field creates quota groups based on a combination of context variables. Available values are:

 key欄位基於上下文變數的組合建立配額組。可用值包括：

- `sender`: the return path specified in the `MAIL FROM` command.
`sender` ： `MAIL FROM`指令中指定的返迴路徑。
- `senderDomain`: the domain component of the return path.
`senderDomain` ：返迴路徑的域分量。
- `rcpt`: the recipient address specified in the `RCPT TO` command.
`rcpt` ： `RCPT TO`命令中指定的收件人地址。
- `rcptDomain`: the domain component of the recipient address.
`rcptDomain` ：收件人地址的網域部分。
For example, to limit to 10 the total number of queued messages for any single recipient:
 例如，要將單一收件者的佇列訊息總數限制為 10 個：

```json
{
  "enable": true,
  "key": {"rcpt": true},
  "match": {"else": "true"},
  "messages": 10
}
```

And, to limit the queue size to 5 MB per combination of sender domain and recipient domain:

 而且，為了將每個寄件者域和收件者域組合的佇列大小限制為 5 個MB ：

```json
{
  "enable": true,
  "key": {"senderDomain": true, "rcptDomain": true},
  "match": {"else": "true"},
  "size": 5242880
}
```

## Conditional quotas｜有條件配額

 The match expression can restrict a quota to specific conditions. For example, applying a 900-message / 7 MB quota by recipient only to messages sent from `example.org`:

 match表達式可以將配額限制在特定條件下。例如，僅對從`example.org`發送的訊息套用 900 則訊息 / 7 MB依收件人分配的配額：

```json
{
  "enable": true,
  "key": {"rcpt": true},
  "match": {"else": "sender_domain == 'example.org'"},
  "messages": 900,
  "size": 7340032
}
```
