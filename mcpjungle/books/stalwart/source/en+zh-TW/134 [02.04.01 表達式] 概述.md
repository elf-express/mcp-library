# Overview｜概述

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[configuration｜配置\\\]\\\(&lt;000 目錄.md#c-18&gt;\\\) › \\\[expressions｜表達式\\\]\\\(&lt;000 目錄.md#c-19&gt;\\\)

Expressions are small conditional programs evaluated at runtime, controlling aspects such as whether a connection is accepted, which authentication mechanisms are offered, or how a message is routed. Several JMAP objects expose fields whose value is an expression; examples include saslMechanisms on MtaStageAuth, route on MtaRoute, and allowedEndpoints on Http. The reference page for each object marks which of its fields are expression-typed.

 表達式是在運行時求值的小型條件程序，用於控制諸如是否接受連接、提供哪些身份驗證機製或訊息路由方式等方面。 JMAP 物件公開的欄位的值為表達式；例如 saslMechanisms MtaStageAuth, route 在 MtaRoute， 和 allowedEndpoints 在 Http每個物件的參考頁面都會標記其哪些欄位是表達式類型的。

 Expressions evaluate context variables, call functions, and combine values using operators. A result can be a boolean, a string, a number, or an array. Stalwart compiles expressions into bytecode at configuration time and evaluates them at runtime.

 表達式用於評估上下文變數、呼叫函數以及使用運算子組合值。結果可以是布林值、字串、數字或陣列。 Stalwart 在配置時將表達式編譯成字節碼，並在執行時進行評估。

## Shape of an expression｜表情的形狀

 An expression is stored as a JSON object with two fields. The `match` field lists zero or more `{if, then}` pairs that are evaluated in order; the first matching condition determines the result. The `else` string is the fallback when no condition matches:

 表達式儲存為具有兩個欄位的 JSON 物件。 `match`欄位列出了依序評估的零個或多個`{if, then}`對；第一個符合條件決定結果。當沒有條件匹配時，`else`字串是後備：

```json
{
  "match": {
    "0": {"if": "<condition>", "then": "<value>"},
    "1": {"if": "<condition>", "then": "<value>"}
  },
  "else": "<default value>"
}
```

`match` is a list, so it follows the object encoding rules: its conditions are keyed `"0"`, `"1"`, `"2"` and so on, and are evaluated in that order.

`match`是一個列表，因此它遵循 物件編碼規則：它的條件以`"0"`, `"1"`, `"2"`為鍵，依此類推，並按此順序進行評估。

 All three fields \(`if`, `then`, `else`\) hold string values. Numbers, booleans, and arrays are written as their string representations: `"true"`, `"false"`, `"3"`, `"[plain, login]"`. When an expression always evaluates to the same result, the `match` field is omitted and only `else` is set:

 所有三個欄位（ `if`, `then`, `else` ）都儲存字串值。數字、布林值和陣列都以字串形式表示： `"true"`, `"false"`, `"3"`, `"[plain, login]"` 。當表達式的計算結果始終相同時， `match`字段將被省略，僅設定`else`字段：

```json
{"else": "value"}
```

## Core concepts｜核心概念

 An expression is composed of the following elements:

 表達式由以下要素組成：

- Variables carry contextual data supplied by the component evaluating the expression. For instance, `remote_ip`, `url_path`, `rcpt`, or `retry_num` may be available depending on the context.
變數攜帶由計算表達式的元件提供的上下文資料。例如，根據上下文， `remote_ip`, `url_path`, `rcpt`或`retry_num`可能可用。
- Functions manipulate variables and values: string operations \(`starts_with`, `contains`\), regular-expression matching \(`matches`\), DNS lookups \(`dns_query`\), directory queries \(`is_local_domain`\), and more.
功能操作變數與值：字串操作（`starts_with`, `contains`）、正規表示式比對（`matches`）、DNS查找（`dns_query`）、目錄查詢（`is_local_domain`）等。
- Values can be booleans \(`true`, `false`\), strings \(for example `'local'`, `'fallback'`\), numbers \(for example `25`, `1.26`\), or arrays that combine the above.
值可以是布林值（ `true`, `false` ）、字串（例如`'local'`, `'fallback'` ）、數字（例如`25`, `1.26` ）或上述類型的陣列。
- Operators combine values using arithmetic, logical, and comparison operations.
運算子使用算術、邏輯和比較運算組合值。
- **Conditional logic** chains `if`/`then`/`else` clauses to select a result.
**條件邏輯** 鍊式`if`/`then`/`else`子句以選擇結果。
## Examples｜範例

 Each example below shows a partial JSON view of the parent object; only the expression-typed field is included.

 下面的每個範例都顯示了父物件的JSON視圖；僅包含表達式類型的欄位。

 A conditional expression offering `PLAIN` and `LOGIN` mechanisms only on TLS-protected submission ports, and disabling authentication elsewhere:

 僅在受TLS保護的提交連接埠上提供`PLAIN`和`LOGIN`機制的條件表達式，並在其他位置停用身份驗證：

```json
{
  "saslMechanisms": {
    "match": {"0": {"if": "local_port != 25 && is_tls", "then": "[plain, login]"}},
    "else": "false"
  }
}
```

An expression that rewrites non-SMTP recipients by extracting the local part and the top-level domain using regex capture groups:

 使用正規表示式擷取群組提取本地部分和頂級域，從而重寫非SMTP收件人的表達式：

```json
{
  "rewrite": {
    "match": {
      "0": {"if": "listener != 'smtp' && matches('^([^.]+)@([^.]+)\\.(.+)$', rcpt)", "then": "$1 + '@' + $3"}
    },
    "else": "false"
  }
}
```

The backslash in the regex is doubled because the expression is shown inside a JSON document; in an expression field in the WebUI it is written once, as `\.`. See escaping backslashes.

 正規表示式中的反斜線被重複出現，因為該表達式顯示在JSON文件中；在 WebUI 的表達式欄位中，它只寫一次，即`\.` 。參見 轉義反斜線 。

 A multi-condition routing expression that returns different queue targets depending on whether the recipient is local and how many retries have elapsed:

 一個多條件路由表達式，根據接收者是否在本地以及重試次數，傳回不同的佇列目標：

```json
{
  "route": {
    "match": {
      "0": {"if": "is_local_domain(rcpt_domain)", "then": "'local'"},
      "1": {"if": "retry_num > 1", "then": "'fallback'"}
    },
    "else": "'mx'"
  }
}
```

A DNSBL check that consults Spamhaus Zen for the remote address and returns the matched list category, combining `ip_reverse_name`, string concatenation, and `dns_query`:

 DNSBL檢查會查詢 Spamhaus Zen 以取得遠端位址，並傳回符合的清單類別，結合`ip_reverse_name` 、字串連線和`dns_query` ：

```json
{
  "tag": {
    "match": {
      "0": {"if": "contains(dns_query(ip_reverse_name(remote_ip) + '.zen.spamhaus.org', 'ipv4'), '127.0.0.2')", "then": "'SBL'"},
      "1": {"if": "contains(dns_query(ip_reverse_name(remote_ip) + '.zen.spamhaus.org', 'ipv4'), '127.0.0.3')", "then": "'CSS'"},
      "2": {"if": "contains(dns_query(ip_reverse_name(remote_ip) + '.zen.spamhaus.org', 'ipv4'), '127.0.0.4')", "then": "'XBL'"}
    },
    "else": "false"
  }
}
```

A per-sender rate limit that increments an in-memory counter and returns `false` \(reject\) once the threshold is exceeded. The counter key incorporates the authenticated account, so accounts do not share a budget:

 每個發送方的速率限制會遞增一個記憶體計數器，一旦超過閾值，則傳回`false` （拒絕）。計數器密鑰包含已認證的帳戶信息，因此帳戶之間不會共享預算：

```json
{
  "accept": {"else": "counter_incr('', 'rcpt-' + authenticated_as, count(recipients)) <= 500"}
}
```

A longer ladder that classifies MailSpike DNSBL responses by the fourth octet of the returned IP address:

 較長的階梯式分類，根據傳回的IP位址的第四個位元組對 MailSpike DNSBL回應進行分類：

```json
{
  "tag": {
    "match": {
      "0": {"if": "octets[0] != 127", "then": "false"},
      "1": {"if": "octets[3] == 10", "then": "'RBL_MAILSPIKE_WORST'"},
      "2": {"if": "octets[3] == 11", "then": "'RBL_MAILSPIKE_VERYBAD'"},
      "3": {"if": "octets[3] == 12", "then": "'RBL_MAILSPIKE_BAD'"},
      "4": {"if": "octets[3] >= 13 && octets[3] <= 16", "then": "'RWL_MAILSPIKE_NEUTRAL'"},
      "5": {"if": "octets[3] == 17", "then": "'RWL_MAILSPIKE_POSSIBLE'"},
      "6": {"if": "octets[3] == 18", "then": "'RWL_MAILSPIKE_GOOD'"},
      "7": {"if": "octets[3] == 19", "then": "'RWL_MAILSPIKE_VERYGOOD'"},
      "8": {"if": "octets[3] == 20", "then": "'RWL_MAILSPIKE_EXCELLENT'"}
    },
    "else": "false"
  }
}
```

A simple fallback-only expression, with no `match` field:

 一個簡單的僅用於備用的表達式，不包含`match`字段：

```json
{
  "chunking": {"else": "remote_ip == '192.0.2.1'"}
}
```
