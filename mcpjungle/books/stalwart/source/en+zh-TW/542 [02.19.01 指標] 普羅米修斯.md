# Prometheus｜普羅米修斯

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[telemetry｜遙測\\\]\\\(&lt;000 目錄.md#c-76&gt;\\\) › \\\[metrics｜指標\\\]\\\(&lt;000 目錄.md#c-77&gt;\\\)

Prometheus is an open-source monitoring and alerting toolkit developed originally at SoundCloud and now part of the Cloud Native Computing Foundation. It uses a time-series data model, a dedicated query language \(PromQL\), and a pull-based scraping model where the server collects metrics from each monitored target at regular intervals.

 Prometheus 是一款開源的監控和警告工具包，最初由 SoundCloud 開發，現在是雲端原生運算基金會的一部分。它使用時間序列資料模型、專用查詢語言 \(PromQL\) 和基於拉取的爬蟲模型，其中伺服器定期從每個受監控的目標收集指標。

 Stalwart exposes a Prometheus-compatible scraping endpoint so that a Prometheus instance \(or any Prometheus-format scraper\) can collect metrics directly. From there, metrics can be queried with PromQL, visualised in Grafana, or used to drive alerting rules.

 Stalwart 提供了一個與 Prometheus 相容的抓取端點，以便 Prometheus 實例（或任何 Prometheus 格式的抓取工具）可以直接收集指標。之後，可以使用 PromQL 查詢指標，在 Grafana 中視覺化指標，或使用指標來驅動警告規則。

## Scraping endpoint｜抓取端點

 When the Prometheus exporter is enabled, metrics are exposed under `/metrics/prometheus`. A Prometheus job definition should point at this path on the Stalwart host and set the scrape interval required by the monitoring setup.

 啟用 Prometheus 導出器後，指標將暴露在`/metrics/prometheus`下。 Prometheus 作業定義應指向 Stalwart 主機上的此路徑，並設定監控設定所需的抓取間隔。

## Configuration｜配置

 The Prometheus exporter is configured through prometheus on the Metrics singleton \(found in the WebUI under Settings › Telemetry › Metrics › General, Settings › Telemetry › Metrics › OpenTelemetry, Settings › Telemetry › Metrics › Prometheus\). The field is a multi-variant nested type with two variants:

 Prometheus 匯出器透過 prometheus在 Metrics單例上進行配置（可在 WebUI 的「設定」&gt;「遙測」&gt;「指標」&gt;「常規」、「設定」&gt;「遙測」&gt;「遙測」&gt;「Open」&gt;「指標」&gt;「常規」、「設定」&gt;「遙測」&gt;「遙測」&gt;「數位」）。此欄位是一個多變數巢狀類型，包含兩個變數：

- `Disabled` turns the endpoint off.
`Disabled`關閉端點。
- `Enabled` exposes `/metrics/prometheus` and accepts optional Basic authentication credentials.
`Enabled`公開`/metrics/prometheus`並接受可選的基本驗證憑證。
The `Enabled` variant carries:
`Enabled`變體攜帶：

- authUsername: optional username for Basic authentication.
authUsername : 基本驗證的選用使用者名稱。
- authSecret: optional secret for Basic authentication. A `SecretKeyOptional` with variants `None`, `Value`, `EnvironmentVariable`, and `File`.
authSecret：基本驗證的可選秘密。 `SecretKeyOptional` 及其變體 `None`, `Value`, `EnvironmentVariable` 和 `File`。
Leaving both credentials unset exposes the endpoint without authentication.
 如果兩個憑證都未設置，則該端點將未經身份驗證而暴露。

## Example｜例子

 The equivalent of enabling the endpoint with Basic authentication credentials `prometheus` / `password123`:

 相當於使用基本驗證憑證啟用端點`prometheus` / `password123` :

```json
{
  "prometheus": {
    "@type": "Enabled",
    "authUsername": "prometheus",
    "authSecret": {"@type": "Value", "secret": "password123"}
  }
}
```
