# Caching｜快取

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[server｜伺服器\\\]\\\(&lt;000 目錄.md#c-62&gt;\\\)

Stalwart keeps a set of in-memory caches in front of slower backends \(the data store, the DNS resolver, the authentication subsystem\). Caching frequently accessed records reduces latency and takes load off the underlying backends without changing their consistency guarantees.

 Stalwart 在速度較慢的後端（資料儲存、 DNS解析器、驗證子系統）前端維護一組記憶體快取。快取頻繁存取的記錄可以降低延遲，減輕底層後端的負載，同時又不影響其一致性保證。

 The eviction policy is a modified Clock-PRO algorithm, close in spirit to the later S3-FIFO scheme. It is scan-resistant, so a transient burst of unrelated lookups does not evict hot entries, and it reaches hit rates comparable to LRU and W-TinyLFU on realistic workloads.

 此驅逐策略是對 Clock PRO演算法的改進，其理念與後來的 S3- FIFO方案相近。它具有抗掃描性，因此短暫的無關查找不會驅逐熱點條目，並且在實際工作負載下，其命中率可與LRU和 W-TinyLFU 相媲美。

## Memory usage｜記憶體使用情況

 Cache sizes should be matched to the workload. On hosts with ample memory and many users, larger caches reduce evictions and improve hit rates. On hosts with limited memory, smaller caches conserve RAM at the cost of some hit rate; monitoring resident set size and the cache-hit metrics published by the server is the normal way to pick an appropriate balance.

 快取大小應與工作負載相符。在記憶體充足且用戶眾多的主機上，較大的快取可以減少快取驅逐並提高命中率。在記憶體有限的主機上，較小的快取可以節省RAM但會降低一些命中率；監控駐留記憶體集大小和伺服器發布的快取命中指標是選擇合適平衡點的常用方法。

## Configuration｜配置

 Every cache is configured through the Cache singleton \(found in the WebUI under Settings › Storage › Cache\). Each field is a byte-size value with a suffix \(for example `"50mb"`\); minimum size is `2048` bytes.

 每個快取都透過 Cache單例進行設定（可在 WebUI 的「設定」›「儲存」›「快取」中找到）。每個欄位都是一個位元組大小的值，帶有後綴（例如`"50mb"` ）；最小大小為`2048`位元組。

### Data caches｜資料快取

- messages: email account data including message UIDs, flags, and mailbox metadata. Default `"50mb"`.
messages : 電子郵件帳戶數據，包括郵件 UID、標誌和郵箱元數據。預設值為`"50mb"` 。
- events: calendar events, including start / end times and timezone data. Default `"10mb"`.
events : 日曆事件，包括開始/結束時間和時區資料。預設`"10mb"` 。
- scheduling: calendar scheduling state. Default `"1mb"`.
scheduling : 日曆調度狀態。預設值為`"1mb"` 。
- contacts: address-book and contact data. Default `"10mb"`.
contacts : 通訊錄與聯絡人資料。預設`"10mb"` 。
- files: file-storage metadata such as paths and permissions. Default `"10mb"`.
files : 檔案儲存元數據，例如路徑和權限。預設值`"10mb"` 。
- mailingLists: mailing-list metadata. Default `"2mb"`.
mailingLists : 郵件列表元資料。預設`"2mb"` 。
- dkimSignatures: parsed DKIM signing configurations. Default `"10mb"`.
dkimSignatures : 已解析DKIM簽章配置。預設`"10mb"` 。
### Directory caches｜目錄快取

- accounts: resolved account records. Default `"20mb"`.
accounts : 已解析的帳號記錄。預設`"20mb"` 。
- domains: domain records. Default `"5mb"`.
domains : 域記錄。預設`"5mb"` 。
- domainNames: positive domain-name lookup results. Default `"10mb"`.
domainNames : 網域查找結果為真。預設值為`"10mb"` 。
- domainNamesNegative: negative \(not-found\) domain-name lookup results. Default `"1mb"`.
domainNamesNegative : 網域查找結果為否定（未找到）。預設值為`"1mb"` 。
- emailAddresses: positive email-address lookup results. Default `"10mb"`.
emailAddresses : 電子郵件地址查找結果為真。預設值為`"10mb"` 。
- emailAddressesNegative: negative email-address lookup results. Default `"2mb"`.
emailAddressesNegative : 否定電子郵件地址找出結果。預設值`"2mb"` 。
- tenants: tenant records. Default `"5mb"`.
tenants : 租用戶記錄。預設`"5mb"` 。
- negativeTtl: how long to keep negative domain and account lookup entries. Default `"1h"`.
negativeTtl : 保留否定網域名稱和帳號查詢條目的時間。預設值`"1h"` 。
### Security caches｜安全快取

- accessTokens: resolved access tokens, reducing revalidation during authentication. Default `"10mb"`.
accessTokens : 已解析的存取令牌，減少身分驗證期間的重新驗證。預設值為`"10mb"` 。
- httpAuth: short-lived state for HTTP authentication. Default `"1mb"`.
httpAuth : 用於HTTP驗證的短期狀態。預設值為`"1mb"` 。
### DNS caches｜DNS緩存

- dnsTxt: TXT records used for SPF, DKIM, and DMARC. Default `"5mb"`.
dnsTxt: TXT記錄用於SPF, DKIM和DMARC 。預設`"5mb"` 。
- dnsMx: MX records used for outbound routing. Default `"5mb"`.
dnsMx: MX用於出站路由的記錄。預設`"5mb"` 。
- dnsPtr: reverse \(PTR\) lookup results. Default `"1mb"`.
dnsPtr : 反向 \( PTR \) 找出結果。預設值為`"1mb"` 。
- dnsIpv4: forward IPv4 \(A\) lookup results. Default `"5mb"`.
dnsIpv4 : 轉送 IPv4 \(A\) 找出結果。預設值為`"5mb"` 。
- dnsIpv6: forward IPv6 \(AAAA\) lookup results. Default `"5mb"`.
dnsIpv6 : 轉送 IPv6 \( AAAA \) 找出結果。預設值為`"5mb"` 。
- dnsTlsa: TLSA records used for DANE validation. Default `"1mb"`.
dnsTlsa: TLSA用於DANE驗證的記錄。預設值為`"1mb"` 。
- dnsMtaSts: MTA-STS policy records. Default `"1mb"`.
dnsMtaSts: MTA-STS策略記錄。預設`"1mb"` 。
- dnsRbl: DNSBL / RBL lookup results. Default `"5mb"`.
dnsRbl: DNSBL / RBL找出結果。預設值`"5mb"` 。
