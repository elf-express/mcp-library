# Application｜應用

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines a web application served by the server.

 定義由伺服器提供的 Web 應用程式。

 This object can be configured from the WebUI under Settings › Web Applications

 此物件可在 WebUI 「設定」›「Web 應用程式」中進行設定。

## Fields｜田野

##### `enabled`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Whether the application is enabled and should be served by the server

 應用程式是否已啟用以及是否應由伺服器提供服務

##### `description`

> Type: \\\`String\\\` · required

類型： \`String\` · 必填

 A short description of the web application

 Web應用程式的簡要描述

##### `resourceUrl`

> Type: \\\`String\\\` · required

類型： \`String\` · 必填

 Override the URL to download application updates from.

 覆蓋URL以從中下載應用程式更新。

##### `urlPrefix`

> Type: \\\`Set<string>\\\` · min items: 1

類型： \`Set<string>\` · 最少商品數量：1

 The URL prefixes to serve the application on. For example, if set to “/admin”, the application will be accessible at \[[http://server/admin\\\\]\\\(http://server/admin\\\)](http://server/admin%255C%255D%255C%28http://server/admin%255C%29).

 用於提供應用程式服務的URL前綴。例如，如果設定為“/admin”，則可透過 \[[http://server/admin\\\\]\\\(http://server/admin\\\)存取該應用程式。](http://server/admin%255C%255D%255C%28http://server/admin%255C%29%25E5%25AD%2598%25E5%258F%2596%25E8%25A9%25B2%25E6%2587%2589%25E7%2594%25A8%25E7%25A8%258B%25E5%25BC%258F%25E3%2580%2582)

##### `autoUpdateFrequency`

> Type: \\\`Duration\\\` · default: \\\`7776000000\\\`

類型： \`Duration\` · 預設值： \`7776000000\`

 Frequency to check for application updates

 檢查應用程式更新的頻率

##### `unpackDirectory`

> Type: \\\`String?\\\`

類型： \`String?\`

 The local path to unpack the application bundle to. If left empty, the application will be unpacked to /tmp.

 應用程式包解壓縮到的本機路徑。如果留空，應用程式將解壓縮到 /tmp 目錄。

##### `oauthClientId`

> Type: \\\`String?\\\`

類型： \`String?\`

 The OAuth client identifier that this application uses to start the authorization flow. Only required when the domain is served by an external identity provider, in which case it must match a client registered with that provider.

 此應用程式用於啟動授權流程的 OAuth 用戶端識別碼。只有在網域由外部身分提供者提供服務時才需要，在這種情況下，它必須與在該提供者註冊的用戶端相符。

## JMAP API

 The Application object is available via the `urn:stalwart:jmap` capability.

 應用程式物件可透過`urn:stalwart:jmap`功能取得。

### `x:Application/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是 [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)節5.1中定義。

 This method requires the `sysApplicationGet` permission.

 此方法需要`sysApplicationGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:Application/get",
          {
            "ids": [
              "id1"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:Application/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是 [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)節5.3中定義。

 Supports create, update, and destroy operations in a single call.

 支援在一次呼叫中執行建立、更新和銷毀操作。

#### Create｜創造

 This operation requires the `sysApplicationCreate` permission.

 此操作需要`sysApplicationCreate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:Application/set",
          {
            "create": {
              "new1": {
                "description": "Example",
                "resourceUrl": "Example",
                "urlPrefix": {}
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

 此操作需要`sysApplicationUpdate` 權限 。

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get Application id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create Application \
  --field description=Example \
  --field resourceUrl=Example \
  --field 'urlPrefix={}'
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query Application
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update Application id1 --field description='updated value'
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete Application --ids id1
```
