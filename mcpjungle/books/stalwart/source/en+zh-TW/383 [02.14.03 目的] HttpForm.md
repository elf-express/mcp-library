# HttpForm

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Configures the contact form submission endpoint.

 設定聯絡表單提交端點。

 This object can be configured from the WebUI under Settings › Network › HTTP › Contact Form

 此物件可在 WebUI的「設定」&gt;「網路」&gt; HTTP 「聯絡表單」中進行設定。

## Fields｜田野

##### `deliverTo`

> Type: \\\`Set<emailaddress>\\\`

類型： \`Set<emailaddress>\`

 List of local e-mail addresses to deliver the contact form to.

 若要將聯絡表單傳送到的本機電子郵件地址清單。

##### `defaultFromAddress`

> Type: \\\`String\\\` · default: \\\`"postmaster@localhost"\\\`

類型： \`String\` · 預設值： \`"postmaster@localhost"\`

 The default e-mail address to use when the sender does not provide one.

 當寄件者未提供電子郵件地址時，將使用此預設電子郵件地址。

##### `fieldEmail`

> Type: \\\`String?\\\`

類型： \`String?\`

 The name of the field in the contact form that contains the e-mail address of the sender.

 聯絡表單中包含寄件者電子郵件地址的欄位名稱。

##### `enable`

> Type: \\\`Boolean\\\` · default: \\\`false\\\`

類型： \`Boolean\` · 預設值： \`false\`

 Whether to enable contact form submissions.

 是否啟用聯絡表單提交功能。

##### `fieldHoneyPot`

> Type: \\\`String?\\\`

類型： \`String?\`

 The name of the field in the contact form that is used as a honey pot to catch spam bots.

 在聯絡表單中用作蜜罐以捕獲垃圾郵件機器人的欄位名稱。

##### `maxSize`

> Type: \\\`Size\\\` · default: \\\`102400\\\`

類型： \`Size\` · 預設值： \`102400\`

 Maximum size of the contact form submission in bytes.

 聯絡表單提交的最大大小（以位元組為單位）。

##### `defaultName`

> Type: \\\`String\\\` · default: \\\`"Anonymous"\\\`

類型： \`String\` · 預設值： \`"Anonymous"\`

 The default name to use when the sender does not provide one.

 當寄件者未提供名稱時所使用的預設名稱。

##### `fieldName`

> Type: \\\`String?\\\`

類型： \`String?\`

 The name of the field in the contact form that contains the name of the sender.

 聯絡表單中包含寄件者姓名的欄位名稱。

##### `rateLimit`

> Type: \\\[\\\`Rate\\\`\\\]\\\(#rate\\\)\\\`?\\\` · default: \\\`{"count":5,"period":3600000}\\\`

類型：\[ \`Rate\` \]\(#rate\)\`?\` · 預設值： \`{"count":5,"period":3600000}\`

 Maximum number of contact form submissions that can be made in a timeframe by a given IP address.

 在給定的IP地址下，可在一定時間內提交聯絡表單的最大次數。

##### `defaultSubject`

> Type: \\\`String\\\` · default: \\\`"Contact form submission"\\\`

類型： \`String\` · 預設值： \`"Contact form submission"\`

 The default subject to use when the sender does not provide one.

 當寄件者未提供主題時，將使用預設主題。

##### `fieldSubject`

> Type: \\\`String?\\\`

類型： \`String?\`

 The name of the field in the contact form that contains the subject of the message.

 聯絡表單中包含訊息主題的欄位名稱。

##### `validateDomain`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Whether to validate the domain of the sender’s email address.

 是否驗證寄件者電子郵件地址的網域名稱。

## JMAP API

 The HttpForm singleton is available via the `urn:stalwart:jmap` capability.

 HttpForm 單例可透過`urn:stalwart:jmap`功能取得。

### `x:HttpForm/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節定義。

 For singletons, the `ids` argument should be the literal `singleton` \(or `null` to return the single instance\).

 對於單例， `ids`參數應該是字面值`singleton` （或`null`以傳回單一實例）。

 This method requires the `sysHttpFormGet` permission.

 此方法需要`sysHttpFormGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:HttpForm/get",
          {
            "ids": [
              "singleton"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:HttpForm/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是 [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)節5.3中定義。

 For singletons, only the `update` argument with id `singleton` is accepted; `create` and `destroy` arguments are rejected.

 對於單例，僅接受 id 為`singleton` `update`參數；拒絕`create`和`destroy`參數。

 This method requires the `sysHttpFormUpdate` permission.

 此方法需要`sysHttpFormUpdate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:HttpForm/set",
          {
            "update": {
              "singleton": {
                "defaultFromAddress": "updated value"
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get HttpForm
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update HttpForm --field defaultFromAddress='updated value'
```
