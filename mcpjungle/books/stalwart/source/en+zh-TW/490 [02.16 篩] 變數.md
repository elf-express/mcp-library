# Variables｜變數

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[sieve｜篩\\\]\\\(&lt;000 目錄.md#c-67&gt;\\\)

Sieve scripts have access to a number of variables that can be used to obtain information about the current SMTP session, the message being processed and the environment in which the script is executed.

 Sieve 腳本可以存取許多變量，這些變量可用於獲取有關當前SMTP會話、正在處理的訊息以及腳本執行環境的資訊。

## Environment｜環境

 The following environment variables can be accessed from within a Sieve script executed in the trusted interpreter:

 以下環境變數可從在 受信任的解釋器中執行的 Sieve 腳本中存取：

- `env.remote_ip`: The email client’s IP address.
`env.remote_ip` : 電子郵件客戶端的IP位址。
- `env.remote_ip.reverse`: The reversed IP address label to be used in DNS lookups.
`env.remote_ip.reverse` ：用於DNS查找的反向IP地址標籤。
- `env.helo_domain`: The domain name used in the EHLO/LHLO command.
`env.helo_domain` ： EHLO/LHLO指令中使用的網域名稱。
- `env.authenticated_as`: The account name used for authentication.
`env.authenticated_as` ：用於身份驗證的帳戶名稱。
- `env.from`: The sender’s email address specified in the `From` header.
`env.from` ：寄件者電子郵件地址在`From`標頭中指定。
- `env.spf.result`: The result of the SPF MAIL FROM check.
`env.spf.result` ：SPF MAIL FROM檢查的結果。
- `env.spf_ehlo.result`: The result of the SPF EHLO check.
`env.spf_ehlo.result` ：SPF EHLO檢查的結果。
- `env.dkim`: The result of the DKIM check.
`env.dkim` ：DKIM檢查的結果。
- `env.dkim.domains`: The domains names that have passed DKIM validation.
`env.dkim.domains` ：已通過DKIM驗證的網域。
- `env.arc.result`: The result of the ARC check.
`env.arc.result` ：ARC檢查的結果。
- `env.dmarc.result`: The result of the DMARC check.
`env.dmarc.result` ：DMARC檢查的結果。
- `env.dmarc.policy`: The DMARC policy that was applied.
`env.dmarc.policy` ：所應用的DMARC政策。
- `env.spam.score`: The score calculated by the spam filter, only available at the `DATA` stage when the spam filter is enabled.
`env.spam.score` ：由垃圾郵件過濾器計算的分數，僅在啟用垃圾郵件過濾器時， `DATA`階段可用。
- `env.spam.is_spam`: Whether the spam filter score reached the configured spam threshold.
`env.spam.is_spam` ：垃圾郵件過濾器得分是否達到配置的垃圾郵件閾值。
- `env.iprev.result`: The result of the reverse IP check.
`env.iprev.result` ：反向IP檢查的結果。
- `env.iprev.ptr`: The host name returned by the reverse IP check.
`env.iprev.ptr` ：反向IP檢查回傳的主機名稱。
- `env.tls.version`: The TLS version used for the current session.
`env.tls.version` ：目前會話使用的TLS版本。
- `env.tls.cipher`: The TLS cipher used for the current session.
`env.tls.cipher` ：目前會話使用的TLS密碼。
- `env.stage`: The current stage of the SMTP transaction.
`env.stage` ： SMTP交易的當前階段。
- `env.now`: The current date and time in seconds since the Unix epoch.
`env.now` ：自 Unix 紀元以來的當前日期和時間（以秒為單位）。
- `env.param.body`: The body flag specified in the `MAIL FROM` command. Possible values are `7bit`, `8bitmime` and `binarymime`.
`env.param.body` ： `MAIL FROM`指令中指定的主體標誌。可能的值為`7bit`, `8bitmime`和`binarymime` 。
- `env.param.smtputf8`: Set to `true` if the SMTPUTF8 flag was specified in the `MAIL FROM` command.
`env.param.smtputf8` ：如果在`MAIL FROM`指令中指定了SMTPUTF8標誌，則設定為`true` 。
- `env.param.requiretls`: Set to `true` if the REQUIRETLS flag was specified in the `MAIL FROM` command.
`env.param.requiretls` ：如果在`MAIL FROM`指令中指定了 REQUIRETLS 標誌，則設定為`true` 。
## Envelope｜信封

 The envelope contents can be accessed using the [envelope test](https://www.rfc-editor.org/rfc/rfc5228.html#page-27) or through variables:

 可以使用 [envelope test](https://www.rfc-editor.org/rfc/rfc5228.html#page-27)或透過變數存取信封內容：

- `envelope.from`: The return path specified in the `MAIL FROM` command.
`envelope.from` ： `MAIL FROM`指令中指定的返迴路徑。
- `envelope.to`: The recipient address specified in the last `RCPT TO` command.
`envelope.to` : 最後一個`RCPT TO`命令中指定的收件人地址。
- `envelope.notify`: The `NOTIFY` extension parameters.
`envelope.notify` ： `NOTIFY`擴展參數。
- `envelope.orcpt`: The `ORCPT` value specified with the DSN extension.
`envelope.orcpt` ：使用DSN擴展指定的`ORCPT`值。
- `envelope.ret`: The `RET` value specified with the DSN extension.
`envelope.ret` ：使用DSN擴展指定的`RET`值。
- `envelope.envid`: The `ENVID` value specified with the DSN extension.
`envelope.envid` ：使用DSN擴展指定的`ENVID`值。
- `envelope.by_time_absolute`: The specified absolute time in the `DELIVERBY` extension.
`envelope.by_time_absolute` ： `DELIVERBY`擴充中指定的絕對時間。
- `envelope.by_time_relative`: The specified relative time in the `DELIVERBY` extension.
`envelope.by_time_relative` ： `DELIVERBY`擴展中指定的相對時間。
- `envelope.by_mode`: The mode specified with the `DELIVERBY` extension.
`envelope.by_mode` ：使用`DELIVERBY`擴展指定的模式。
- `envelope.by_trace`: The trace settings specified with the `DELIVERBY` extension.
`envelope.by_trace` ：使用`DELIVERBY`擴展指定的追蹤設定。
Please note that user scripts executed within the untrusted interpreter only have access to the `From` and `To` parts of the envelope.
 請注意，在 不受信任的解釋器中執行的使用者腳本只能存取信封的`From`和`To`部分。
