# Overview｜概述

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[auth｜認證\\\]\\\(&lt;000 目錄.md#c-3&gt;\\\) › \\\[authentication｜驗證\\\]\\\(&lt;000 目錄.md#c-4&gt;\\\)

Stalwart authenticates users against several backends, allowing integration with existing identity systems. Supported backends include LDAP directories, SQL databases such as PostgreSQL, MySQL, and SQLite, and an internal directory managed directly by the server.

 Stalwart 透過多個\([https://stalw.art/docs/auth/backend/\)對使用者進行身份驗證，從而可以與現有的身份系統整合。支援的後端包括LDAP](https://stalw.art/docs/auth/backend/%2529%2525E5%2525B0%25258D%2525E4%2525BD%2525BF%2525E7%252594%2525A8%2525E8%252580%252585%2525E9%252580%2525B2%2525E8%2525A1%25258C%2525E8%2525BA%2525AB%2525E4%2525BB%2525BD%2525E9%2525A9%252597%2525E8%2525AD%252589%2525EF%2525BC%25258C%2525E5%2525BE%25259E%2525E8%252580%25258C%2525E5%25258F%2525AF%2525E4%2525BB%2525A5%2525E8%252588%252587%2525E7%25258F%2525BE%2525E6%25259C%252589%2525E7%25259A%252584%2525E8%2525BA%2525AB%2525E4%2525BB%2525BD%2525E7%2525B3%2525BB%2525E7%2525B5%2525B1%2525E6%252595%2525B4%2525E5%252590%252588%2525E3%252580%252582%2525E6%252594%2525AF%2525E6%25258F%2525B4%2525E7%25259A%252584%2525E5%2525BE%25258C%2525E7%2525AB%2525AF%2525E5%25258C%252585%2525E6%25258B%2525ACLDAP) 、PostgreSQL、 SQL和 SQLite 等資料庫，以及由伺服器直接管理的內部目錄。

 Stalwart also supports OpenID Connect and OAuth, which allow authentication against the built-in OpenID server or integration with external identity providers. Security controls include authentication rate limiting to reduce the risk of password guessing, and built-in Fail2Ban support, which applies temporary IP bans to sources that repeatedly trigger suspicious activity.

 Stalwart 也支援 OpenID Connect和 OAuth ，允許使用內建的 OpenID 伺服器進行身份驗證或與外部身分提供者整合。安全控制措施包括身分驗證速率限制，以降低密碼猜測的風險，以及內建的 Fail2Ban支持，該功能會對反覆觸發可疑活動的來源應用臨時IP封禁。
