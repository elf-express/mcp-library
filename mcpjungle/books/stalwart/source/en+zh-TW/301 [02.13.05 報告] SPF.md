# SPF

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[mta｜捷運\\\]\\\(&lt;000 目錄.md#c-47&gt;\\\) › \\\[reports｜報告\\\]\\\(&lt;000 目錄.md#c-53&gt;\\\)

SPF authentication-failure reporting generates reports for sending mail servers when SPF checks fail at the receiver. The receiver verifies that an incoming message is authorised by the domain specified in the envelope \(the `MAIL FROM` identity\). When the check fails, a failure report is sent back to the sender, including the SPF record, the IP address of the sending server, and relevant header details. These reports help sending operators identify and correct issues with their SPF records.

 當接收方的SPF檢查失敗時， SPF身份驗證失敗報告會為發送郵件伺服器產生報告。接收者會驗證收到的郵件是否已取得信封中指定的網域（ `MAIL FROM`標識）的授權。如果檢查失敗，則會向發送方發送失敗報告，其中包含SPF記錄、 IP發送伺服器位址以及相關的郵件頭詳細資訊。這些報告有助於發送方運營商識別並糾正其SPF記錄中的問題。

 Stalwart automatically analyses received SPF failure reports from external hosts and can also generate its own SPF reports for other hosts. Outgoing SPF failure reports are configured on the SpfReportSettings singleton \(found in the WebUI under Settings › MTA › Reports › SPF\):

 Stalwart 自動分析接收來自外部主機的SPF故障報告，並且還可以為其他主機產生自己的SPF報告。外發SPF故障報告在 SpfReportSettings單例中配置（可在 WebUI 的「設定」› MTA › “報告”› SPF下找到）：

- fromName: expression returning the name used in the `From` header of the report. Default `'Report Subsystem'`.
fromName : 傳回報表標題`From`中所使用的名稱的表達式。預設值為`'Report Subsystem'` 。
- fromAddress: expression returning the email address used in the `From` header. Default `'noreply-spf@' + system('domain')`.
fromAddress : 傳回`From`標頭中所使用的電子郵件地址的表達式。預設值為`'noreply-spf@' + system('domain')` 。
- subject: expression returning the report subject. Default `'SPF Authentication Failure Report'`.
subject : 傳回報告主題的表達式。預設值為`'SPF Authentication Failure Report'` 。
- sendFrequency: expression returning the rate at which reports are sent to a given address. Default `[1, 1d]`. Returning `false` disables SPF failure reporting.
sendFrequency : 傳迴向給定位址發送報告的速率的表達式。預設值為`[1, 1d]` 。返回`false`將禁用SPF故障報告。
- dkimSignDomain: expression returning the domain whose DKIM signatures sign the outgoing report. Default `system('domain')`.
dkimSignDomain : 傳回域的表達式，該域的 DKIM簽章用於簽署傳出的報告。預設值為`system('domain')` 。
Example configuration using explicit values:
 使用顯式值的範例配置：

```json
{
  "fromName": {"else": "'Report Subsystem'"},
  "fromAddress": {"else": "'[email protected]'"},
  "subject": {"else": "'SPF Authentication Failure Report'"},
  "sendFrequency": {"else": "[1, 1d]"},
  "dkimSignDomain": {"else": "'example.org'"}
}
```
