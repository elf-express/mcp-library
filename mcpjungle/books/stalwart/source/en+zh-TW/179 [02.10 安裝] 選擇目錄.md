# Choosing a directory｜選擇目錄

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[install｜安裝\\\]\\\(&lt;000 目錄.md#c-29&gt;\\\)

In Stalwart, a *directory* refers to the authentication backend responsible for managing user identities and access credentials. Directories are essential for validating login attempts, retrieving account-related information, and, in some cases, managing user configuration. Stalwart supports both **internal**and**external** directory configurations, giving administrators flexibility in how authentication is handled.

 在 Stalwart 中，「目錄」指的是負責管理使用者身分和存取憑證的驗證後端。目錄對於驗證登入嘗試、檢索帳戶相關資訊以及在某些情況下管理使用者配置至關重要。 Stalwart 同時支援**內部**和**外部**目錄配置，使管理員能夠靈活地處理身份驗證。

 When using the internal directory, all user account data \(including usernames, passwords, and quotas\) is stored within Stalwart’s own data store. In this setup, Stalwart fully manages user-related data, and administrators can perform all account management tasks directly within the system. This includes creating new accounts, updating credentials, configuring mail quotas, and managing account-level settings. The internal directory is ideal for standalone or small-scale deployments where centralized control and simplicity are important.

 使用內部目錄時，所有使用者帳戶資料（包括使用者名稱、密碼和配額）都儲存在Stalwart本身的資料儲存中。在此設定下，Stalwart完全管理使用者相關數據，管理員可以直接在系統內執行所有帳戶管理任務，包括建立新帳戶、更新憑證、設定郵件配額以及管理帳戶層級設定。內部目錄非常適合需要集中控制和簡易性的獨立部署或小規模部署。

 Alternatively, Stalwart can be configured to use an external directory, which delegates authentication and user information to a third-party system. Supported external directories include **LDAP,**OpenID Connect**, and**SQL-based authentication backends. In this configuration, Stalwart relies on the external system for user authentication and account data. However, it does not have the ability to modify user details \(such as resetting passwords or creating accounts\) within the external directory. All user management must be performed directly in the external system by its respective tools or APIs.

 或者，Stalwart 可以設定為使用 外部目錄 ，將身份驗證和使用者資訊委託給第三方系統。支援的外部目錄包括 **LDAP、**OpenID Connect**和**SQL 認證後端。在此配置中，Stalwart 依賴外部系統進行使用者身份驗證和帳戶資料管理。但是，它無法修改外部目錄中的使用者詳細資訊（例如重設密碼或建立帳戶）。所有使用者管理操作都必須透過外部系統各自的工具或 API 直接執行。

 Choosing between an internal or external directory depends on your operational model. The internal directory offers simplicity and full integration for deployments where Stalwart operates as a self-contained platform. On the other hand, using an external directory is recommended for organizations that already maintain a centralized identity infrastructure and require integration with existing systems.

 選擇內部目錄還是外部目錄取決於您的營運模式。對於 Stalwart 作為獨立平台運行的部署，內部目錄提供簡潔性和完全整合。另一方面，對於已經維護集中式身分基礎架構並需要與現有系統整合的組織，建議使用外部目錄。

 Stalwart’s directory system is flexible and designed to fit a wide range of use cases, from independent setups to enterprise environments with federated authentication. Available authentication backend are:

 Stalwart 的目錄系統靈活，旨在滿足從獨立部署到採用聯合身份驗證的企業環境等各種使用情境。可用的身份驗證後端包括：

- Internal: An internal directory that is automatically created and managed by Stalwart. It uses the same database backend as the data store.
內部 ：由 Stalwart 自動建立和管理的內部目錄。它使用與資料儲存相同的資料庫後端。
- LDAP: LDAP servers, including OpenLDAP and Active Directory.
LDAP: LDAP伺服器，包含 OpenLDAP 和 Active Directory。
- SQL: SQL databases, including PostgreSQL, MySQL and SQLite.
SQL: SQL資料庫，包括 PostgreSQL、MySQL 和 SQLite。
- OpenID Connect: OpenID Connect servers, including Authentik, Keycloak, etc.
OpenID Connect : OpenID Connect 伺服器，包括 Authentik、Keycloak 等。
- When the internal directory is used, Stalwart manages all user-related data within its own system. In this setup, all account management tasks, such as creating new user accounts, updating passwords, and setting quotas, are performed directly within Stalwart.
使用內部目錄時，Stalwart 會在其自身系統內管理所有使用者相關資料。在這種設定下，所有帳戶管理任務，例如建立新使用者帳戶、更新密碼和設定配額，都直接在 Stalwart 內部執行。
- When an external LDAP or SQL directory is utilized, all user account management must be performed within that external system. Stalwart will rely on this external directory for authentication and user information but will not have the ability to directly modify user details from the web-based admin.
當使用外部LDAP或SQL目錄時，所有使用者帳號管理都必須在該外部系統中執行。 Stalwart 將依賴此外部目錄進行身份驗證和使用者信息，但無法直接從 基於 Web 的管理修改使用者詳細資訊。
