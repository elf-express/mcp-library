# Branding｜品牌推廣

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[management｜管理\\\]\\\(&lt;000 目錄.md#c-31&gt;\\\) › \\\[webui｜網站\\\]\\\(&lt;000 目錄.md#c-36&gt;\\\)

Branding allows administrators to customise the appearance of the WebUI by changing the logo displayed to users. Custom branding can be applied to the entire system or scoped to specific tenants and domains, which is useful for multi-tenant deployments.

 品牌化功能允許管理員透過更改向使用者顯示的徽標來自訂 Web 使用者介面的外觀。自訂品牌化可以應用於整個系統，也可以限定於特定的租戶和網域，這對於多租戶部署非常有用。

 This feature is available exclusively in the Enterprise Edition of Stalwart and is not included in the Community Edition.

 此功能僅在 Stalwart 的 企業版中提供，社群版不包含此功能。

## Logo selection order｜標誌選擇順序

 The logo displayed by the WebUI is chosen based on the hostname of the incoming HTTP request. Stalwart consults the following sources in order and uses the first one that yields a valid logo URL:

 WebUI 顯示的標誌是根據傳入的HTTP請求的主機名稱選擇的。 Stalwart 會依序查詢以下來源，並使用第一個產生有效標誌的來源URL ：

- **Domain logo.** Stalwart looks up the hostname against the configured Domain objects. If a matching Domain has the logo field set, that logo is used.
**網域徽標。** Stalwart 會根據已設定的 Domain物件尋找主機名稱。如果匹配的網域設定了 logo字段，則使用該徽標。
- **Tenant logo.** If the matching Domain has no logo but is linked to a Tenant through memberTenantId, and the Tenant has its own logo set, that logo is displayed instead. This provides tenant-wide branding for domains that do not set their own logo.
**租戶標誌。** 如果符合的網域沒有徽標，但連結到 租戶至 memberTenantId ，並且該租戶擁有自己的 logo集，則會顯示該徽標。這為未設定自身徽標的網域提供了租戶範圍內的品牌標識。
- **System-wide default.** If neither the Domain nor the Tenant sets a logo, Stalwart falls back to the system-wide default carried by the Enterprise singleton \(found in the WebUI under Settings › Enterprise\) through its logoUrl field.
**系統範圍預設值。** 如果網域和租用戶都沒有設定徽標，則 Stalwart 將回退到 Enterprise單例（在 WebUI 的「設定 › 企業」下找到）透過其 logoUrl欄位承載的系統範圍預設值。
- **Built-in logo.** If no custom logo is set anywhere, the WebUI displays Stalwart’s built-in default.
**內建徽標。** 如果未在任何地方設定自訂徽標，則 WebUI 將顯示 Stalwart 的內建預設徽標。
