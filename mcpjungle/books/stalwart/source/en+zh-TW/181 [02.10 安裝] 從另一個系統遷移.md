# Migrating from another system｜從另一個系統遷移

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[install｜安裝\\\]\\\(&lt;000 目錄.md#c-29&gt;\\\)

Moving to Stalwart from an existing mail server does not require choosing between a disruptive all-at-once cutover and weeks of manual exporting and importing. Stalwart includes a migration proxy and a one-shot migration tool that work together to move accounts onto Stalwart gradually and with **zero downtime**, so that users keep sending and receiving mail throughout the transition.

 從現有郵件伺服器遷移到 Stalwart 無需在一次性全面切換和耗時數週的手動匯出匯入之間做出選擇。 Stalwart 包含一個遷移代理\([https://stalw.art/docs/migration/proxy\)和一個一次性遷移工具\(https://stalw.art/docs/migration/import-export\)](https://stalw.art/docs/migration/proxy%2529%2525E5%252592%25258C%2525E4%2525B8%252580%2525E5%252580%25258B%2525E4%2525B8%252580%2525E6%2525AC%2525A1%2525E6%252580%2525A7%2525E9%252581%2525B7%2525E7%2525A7%2525BB%2525E5%2525B7%2525A5%2525E5%252585%2525B7%2528https://stalw.art/docs/migration/import-export%2529) ，它們協同工作，可將帳戶逐步遷移到 Stalwart，實現**零停機時間**，確保用戶在整個遷移過程中都能正常收發郵件。

 The migration proxy sits in front of both the existing server and the new Stalwart deployment and routes each connection to whichever one currently holds that account, based on the credentials the client already presents. Because the routing decision is made from the login itself, users keep the same hostname, ports and passwords, and nothing on their devices needs to be reconfigured. The migration tool copies an account’s data, its mail, calendars, contacts, filters and stored files, from the existing server into Stalwart, one account at a time. Each account is moved by copying its data and then switching it over, and the switch remains reversible until the migration is finalized and the old server is retired.

 遷移代理程式位於現有伺服器和新的 Stalwart 部署的前端，並根據用戶端已提供的憑證，將每個連線路由到目前持有該帳戶的伺服器。由於路由決策是在登入時自動完成的，因此使用者可以保留相同的主機名稱、連接埠和密碼，無需重新配置裝置上的任何內容。遷移工具會將帳戶的資料（包括郵件、日曆、聯絡人、過濾器和儲存的檔案）從現有伺服器逐一複製到 Stalwart。每個帳戶的遷移過程都是先複製其數據，然後再進行切換，並且在遷移完成且舊伺服器停用之前，切換過程是可逆的。

 This approach works whether the migration is from a legacy or self-hosted mail server or from an older version of Stalwart. The migration overview explains how the proxy and the migration tool fit together, and leads into a complete step-by-step procedure.

 無論遷移物件是傳統郵件伺服器、自架郵件伺服器或舊版的 Stalwart，此方法都適用。 遷移概述解釋了代理和遷移工具如何協同工作，並提供了完整的逐步操作流程。
