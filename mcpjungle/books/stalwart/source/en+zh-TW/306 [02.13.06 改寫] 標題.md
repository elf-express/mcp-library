# Headers｜標題

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[mta｜捷運\\\]\\\(&lt;000 目錄.md#c-47&gt;\\\) › \\\[rewrite｜改寫\\\]\\\(&lt;000 目錄.md#c-54&gt;\\\)

Message header rewriting involves the process of adding, removing, or modifying the headers of an email message. Headers are crucial parts of an email, as they contain meta-information about the email, such as the sender, recipient, subject, and other technical details, including those required for proper routing and delivery.

 郵件頭重寫是指新增、刪除或修改電子郵件郵件頭的過程。郵件頭是電子郵件的重要組成部分，因為它們包含有關電子郵件的元信息，例如發件人、收件人、主題和其他技術細節，包括正確路由和投遞所需的信息。

 There are various reasons why header rewriting might be useful:

 重寫頭部資訊有多種用途：

- **Obfuscating internal details:** Internal server names, IP addresses, or other specifics could be present in the headers. Removing or modifying these helps keep internal infrastructure private and improves the security posture.
**混淆內部細節：** 請求頭中可能包含內部伺服器名稱、 IP位址或其他特定資訊。移除或修改這些資訊有助於保護內部基礎設施的私密性，並提升安全性。
- **Compliance and regulatory reasons:** Certain industries or legal environments require specific information to be present in email headers. By adding or modifying headers, an organization can ensure it meets these requirements.
**合規性與監管要求：**某些行業或法律環境要求電子郵件標頭中包含特定資訊。透過新增或修改標頭，組織可以確保滿足這些要求。

- **Message enhancement and organization:** Headers can be added to include additional information about the email, such as categorization information, which can be used by email clients to sort or filter messages.
**郵件增強和組織：** 可以添加郵件頭，以包含有關電子郵件的其他信息，例如分類信息，電子郵件用戶端可以使用這些信息對郵件進行排序或篩選。
- **Troubleshooting and Monitoring:** By adding custom headers, it’s possible to track the path an email took through the system, which can be invaluable for troubleshooting delivery issues or monitoring system performance.
**故障排除和監控：**透過新增自訂標頭，可以追蹤電子郵件在系統中的路徑，這對於排查投遞問題或監控系統效能非常有價值。
Headers can be modified using Sieve scripts, which is a language designed for filtering email messages. A Sieve script containing the specific add, delete, or alter commands is defined as a SieveSystemScript object and referenced from the script field on the MtaStageData singleton \(found in the WebUI under Settings › MTA › Session › DATA Stage\); see the DATA stage documentation.

 可以使用 Sieve 腳本修改郵件頭，Sieve 腳本是一種專為過濾電子郵件而設計的語言。包含特定新增、刪除或修改指令的 Sieve 腳本定義為 SieveSystemScript對象，並透過 MtaStageData單例的 script欄位引用（可在 Web › MTA ” DATA “階段” 下找到）；請參閱 DATA “階段”文檔。

 The Sieve language has a rich set of commands for precise header manipulation. The `addheader` action adds a new header, `deleteheader` removes a header, and combining the two effectively replaces a header’s value. Modifications can be applied conditionally based on attributes such as sender, recipient, subject line, or any other header.

 Sieve 語言具有豐富的命令集，可用於精確的標頭操作。 `addheader` 操作新增一個標頭，`deleteheader` 刪除標頭，並將兩者組合起來有效地取代標頭的值。可以根據寄件者、收件者、主題行或任何其他標頭等屬性有條件地套用修改。

## Examples｜範例

### Adding Headers｜新增標題

 The `addheader` command is used to add a new header to the email. Below is an example Sieve script that adds a “X-Custom-Header”（X-自訂標頭） with a value “Custom Value”（自訂值）:

`addheader`指令用於為電子郵件新增新的標頭。以下是一個 Sieve 腳本範例，它新增了一個值為“Custom Value”（自訂值）的“X-Custom-Header”（X-自訂標頭）標頭：

```sieve
require ["editheader"];
addheader "X-Custom-Header" "Custom Value";
```

### Deleting Headers｜刪除標頭

 The `deleteheader` command is used to remove a header from the email. In the following example, any existing “X-Custom-Header”（X-自訂標頭） is removed:

`deleteheader`指令用於從電子郵件中刪除郵件頭。在以下範例中，所有現有的“X-Custom-Header”（X-自訂標頭）都將被刪除：

```sieve
require ["editheader"];
deleteheader "X-Custom-Header";
```

### Replacing headers｜替換標題

 Sieve does not have a built-in replace command to modify a header. The `deleteheader` command removes the old header and the `addheader` command adds a new header with the updated value. The following example replaces the value of “X-Custom-Header”（X-自訂標頭）:

 Sieve 沒有內建的替換指令來修改標頭。 `deleteheader` 指令刪除舊標頭，`addheader` 指令新增具有更新值的新標頭。以下範例取代 “X-Custom-Header”（X-自訂標頭） 的值：

```sieve
require ["editheader", "variables"];
if header :matches "X-Custom-Header" "*" {
    set "oldValue" "${1}";
    deleteheader "X-Custom-Header";
    addheader "X-Custom-Header" "New Value";
}
```
