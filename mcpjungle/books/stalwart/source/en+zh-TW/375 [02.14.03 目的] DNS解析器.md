# DnsResolver｜DNS解析器

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Configures the DNS resolver used for domain lookups.

 配置用於域查找的DNS解析器。

 This object can be configured from the WebUI under Settings › Network › DNS › DNS Resolver

 可以透過 WebUI下的「設定」›「網路」› DNS › DNS 「解析器」來設定此物件。

## Fields｜田野

 DnsResolver is a **multi-variant** object: each instance has an `@type` discriminator selecting one of the variants below, and each variant carries its own set of fields.

 DnsResolver 是一個**多變體**物件：每個實例都有一個`@type`鑑別器，用於選擇以下變體之一，並且每個變體都帶有自己的一組欄位。

### `@type: "System"`

 System Resolver

 系統解析器

##### `attempts`

> Type: \\\`UnsignedInt\\\` · default: \\\`2\\\`

類型： \`UnsignedInt\` · 預設值： \`2\`

 Number of times a resolution request will be retried before it is considered failed

 在被視為失敗之前，解析請求將被重試的次數。

##### `concurrency`

> Type: \\\`UnsignedInt\\\` · default: \\\`2\\\`

類型： \`UnsignedInt\` · 預設值： \`2\`

 Number of concurrent resolution requests that can be made at the same time

 可以同時發出的並發解析請求數量

##### `enableEdns`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Whether to enable EDNS \(Extension Mechanisms for DNS\) support

 是否啟用EDNS （ DNS的擴充機制）支持

##### `preserveIntermediates`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Whether to preserve the intermediate name servers in the DNS resolution results

 是否在DNS解析結果中保留中間名稱伺服器

##### `timeout`

> Type: \\\`Duration\\\` · default: \\\`5000\\\`

類型： \`Duration\` · 預設值： \`5000\`

 Time after which a resolution request will be timed out if no response is received

 如果在此時間後仍未收到回复，則解決請求將逾時。

##### `tcpOnError`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Whether to try using TCP for resolution requests if an error occurs during a UDP resolution request

 如果在UDP解析請求期間發生錯誤，是否嘗試使用TCP進行解析請求

## JMAP API

 The DnsResolver singleton is available via the `urn:stalwart:jmap` capability.

 DnsResolver 單例可透過`urn:stalwart:jmap`功能取得。

### `x:DnsResolver/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節中定義。

 For singletons, the `ids` argument should be the literal `singleton` \(or `null` to return the single instance\).

 對於單例， `ids`參數應該是字面值`singleton` （或`null`以傳回單一實例）。

 This method requires the `sysDnsResolverGet` permission.

 此方法需要`sysDnsResolverGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:DnsResolver/get",
          {
            "ids": [
              "singleton"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:DnsResolver/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節中定義。

 For singletons, only the `update` argument with id `singleton` is accepted; `create` and `destroy` arguments are rejected.

 對於單例，僅接受 id 為`singleton`的`update`參數；拒絕`create`和`destroy`參數。

 This method requires the `sysDnsResolverUpdate` permission.

 此方法需要`sysDnsResolverUpdate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:DnsResolver/set",
          {
            "update": {
              "singleton": {
                "attempts": 2
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。
