# Overview｜概述

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[auth｜認證\\\]\\\(&lt;000 目錄.md#c-3&gt;\\\)

The Access Control section covers the mechanisms that regulate how users and applications interact with the server. It includes authentication, authorization, and directory management.

 存取控制部分涵蓋了規範使用者和應用程式與伺服器互動方式的機制，包括身份驗證、授權和目錄管理。

 Authentication verifies the identity of users or applications attempting to access the server. The server supports a variety of authentication methods, including the internal directory and integration with external systems such as OIDC, LDAP, and SQL for more complex environments.

 身份驗證用於驗證嘗試存取伺服器的使用者或應用程式的身份。伺服器支援多種身份驗證方法，包括內部目錄以及與外部系統（例如OIDC, LDAP和SQL的集成，以適應更複雜的環境。

 Authorization determines which actions an authenticated user may perform. The permissions model allows administrators to assign and manage permissions for individuals, groups, tenants, and roles, ensuring that each principal has access only to the resources and functionality required for its role.

 授權決定了已認證使用者可以執行哪些操作。權限模型允許管理員為個人、群組、租用戶和角色分配和管理權限，確保每個主體只能存取其角色所需的資源和功能。

 The information used for both authentication and authorization is stored in directories. A directory holds accounts, passwords, groups, mailing lists, and other metadata needed to manage and authenticate users and resources.

 用於身份驗證和授權的資訊儲存在 directories中。目錄包含帳戶、密碼、群組、郵件清單以及管理和驗證使用者和資源所需的其他元資料。

 Directories contain principals, a term that refers to individuals, groups, resources, and other entities represented within the server. Principals form the basis on which the server models different roles and resources.

 目錄包含 主體 ，該術語指的是伺服器中表示的個人、群組、資源和其他實體。主體構成了伺服器對不同角色和資源進行建模的基礎。

 By default, Stalwart stores directory information internally, in the built-in directory. It also supports external directory services such as LDAP and SQL databases, which allow integration with existing identity infrastructure.

 預設情況下，Stalwart 將目錄資訊儲存在內部的 內建目錄中。它還支援外部目錄服務，例如 LDAP和 SQL資料庫，從而可以與現有的身份基礎架構整合。

 Where the identity provider is the system of record, it can also push the account lifecycle into the server through SCIM provisioning, so that mailboxes are created when an identity is created and suspended or removed when it is withdrawn.

 如果身分識別提供者是記錄系統，它也可以透過 SCIM設定將帳戶生命週期推送到伺服器，以便在建立身分時建立郵箱，並在撤回身分時暫停或刪除信箱。
