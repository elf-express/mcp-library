# ArchivedItem｜已存檔項目

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Represents an archived item that can be restored.

 表示可以恢復的已存檔項目。

 This object is only available with an Enterprise license.

 此物件僅在擁有企業許可證的情況下可用。

 This object can be configured from the WebUI under Account › Archived Items

 此物件可在 WebUI下的「帳號 › 已存檔項目」中進行設定。

## Fields｜田野

 ArchivedItem is a **multi-variant** object: each instance has an `@type` discriminator selecting one of the variants below, and each variant carries its own set of fields.

## JMAP API

 The ArchivedItem object is available via the `urn:stalwart:jmap` capability.

 ArchivedItem 物件可透過`urn:stalwart:jmap`功能取得。

### `x:ArchivedItem/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節中定義。

 This method requires the `sysArchivedItemGet` permission.

 此方法需要`sysArchivedItemGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:ArchivedItem/get",
          {
            "ids": [
              "id1"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:ArchivedItem/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節中定義。

 Supports create, update, and destroy operations in a single call.

 支援在一次呼叫中執行建立、更新和銷毀操作。

#### Create｜創造

 This operation requires the `sysArchivedItemCreate` permission.

 此操作需要`sysArchivedItemCreate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;

  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:ArchivedItem/set",
          {
            "create": {
              "new1": {
                "@type": "Email",
                "accountId": "<Account id>",
                "archivedAt": "2026-01-01T00:00:00Z",
                "archivedUntil": "2026-01-01T00:00:00Z",
                "blobId": "abc123",
                "from": "Example",
                "receivedAt": "2026-01-01T00:00:00Z",
                "subject": "Example"
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get ArchivedItem id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create ArchivedItem/Email \
  --field from=Example \
  --field subject=Example \
  --field receivedAt=2026-01-01T00:00:00Z \
  --field 'accountId=<Account id>' \
  --field archivedAt=2026-01-01T00:00:00Z \
  --field archivedUntil=2026-01-01T00:00:00Z \
  --field blobId=abc123
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query ArchivedItem
stalwart-cli query ArchivedItem --where accountId=id1
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update ArchivedItem id1 --field from='updated value'
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete ArchivedItem --ids id1
```
