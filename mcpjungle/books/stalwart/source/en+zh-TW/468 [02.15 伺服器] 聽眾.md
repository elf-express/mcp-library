# Listeners｜聽眾

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[server｜伺服器\\\]\\\(&lt;000 目錄.md#c-62&gt;\\\)

Stalwart accepts incoming TCP connections through one or more listeners. Each listener is represented by a NetworkListener object \(found in the WebUI under Settings › Network › Listeners\), and any number of listeners can coexist on the server.

 Stalwart 透過一個或多個監聽器接受傳入的TCP連接。每個監聽器都由一個 NetworkListener物件表示（可在 WebUI 的「設定」&gt;「網路」&gt;「監聽器」下找到），伺服器上可以同時存在任意數量的監聽器。

## Bind settings｜綁定設定

 The addresses and ports a listener accepts connections on are set through bind, which takes a set of `host:port` entries. A single listener can bind to multiple IPv4 and IPv6 endpoints:

 監聽器接受連接的位址和連接埠透過 bind設置，該設定接受一組`host:port`條目。單一監聽器可以綁定到多個 IPv4 和 IPv6 端點：

```json
{
  "name": "smtp",
  "protocol": "smtp",
  "bind": {
    "192.0.2.1:25": true,
    "203.0.113.9:25": true,
    "[2001:db8::2]:25": true
  }
}
```

To bind on every interface, use an unspecified address such as `[::]:25`.

 要綁定到每個接口，請使用未指定的地址，例如`[::]:25` 。

## Protocol｜協定

 Each listener selects its application protocol through protocol. The supported values are `smtp`, `lmtp`, `http`, `imap`, `pop3`, and `manageSieve`. For example, an SMTP listener on port 25 alongside an IMAP listener on port 143:

 每個監聽器透過 protocol選擇其應用協定。支援的值為`smtp`, `lmtp`, `http`, `imap`, `pop3`和`manageSieve` 。例如，連接埠 25 上的SMTP監聽器與連接埠 143 上的IMAP監聽器：

```json
[
  {"name": "smtp", "protocol": "smtp", "bind": {"[::]:25": true}},
  {"name": "imap", "protocol": "imap", "bind": {"[::]:143": true}}
]
```

## Maximum connections｜最大連線數

 The server-wide cap on concurrent connections is set through maxConnections on the SystemSettings singleton, and defaults to `8192`. Each NetworkListener also exposes its own maxConnections field so that a specific listener \(for example an implicit-TLS submissions endpoint\) can be capped independently of the server default:

 伺服器級並發連線數上限透過 maxConnections在 SystemSettings單例中設定，預設值為`8192` 。每個 NetworkListener 也公開了自己的 maxConnections字段，以便可以獨立於伺服器預設值限制特定監聽器（例如隱式TLS端點）的連接數上限：

```json
{
  "name": "submissions",
  "protocol": "smtp",
  "bind": {"[::]:465": true},
  "tlsImplicit": true,
  "maxConnections": 1024
}
```

## TCP socket options｜TCP插槽選項

 Socket-level behaviour is configured per listener through the following fields on NetworkListener:

 每個監聽器的套接字級行為是透過 NetworkListener上的以下欄位進行設定的：

- socketReuseAddress: whether the socket can be bound to an address that is already in use. Default `true`.
socketReuseAddress : 套接字是否可以綁定到已被使用的位址。預設值為`true` 。
- socketReusePort: whether multiple sockets can be bound to the same address and port, useful for certain load-balancing scenarios. Default `true`.
socketReusePort : 多個套接字是否可以綁定到同一位址和端口，這在某些負載平衡場景中很有用。預設值為`true` 。
- socketBacklog: maximum number of pending incoming connections. Default `1024`.
socketBacklog : 待處理的傳入連接的最大數量。預設值為`1024` 。
- socketTtl: time-to-live value for outgoing packets.
socketTtl : 出站資料包的生存時間值。
- socketSendBufferSize: size of the send buffer in bytes.
socketSendBufferSize : 發送緩衝區的大小（以位元組為單位）。
- socketReceiveBufferSize: size of the receive buffer in bytes.
socketReceiveBufferSize : 接收緩衝區的大小（以位元組為單位）。
- socketTosV4: type-of-service \(TOS\) value for IPv4 traffic, used to signal traffic priority.
socketTosV4 : IPv4 流量的服務類型 \( TOS \) 值，用於指示流量優先權。
- socketNoDelay: whether the Nagle algorithm should be disabled. Default `true`.
socketNoDelay : 是否禁用 Nagle 演算法。預設值為`true` 。
## TLS on a listener｜TLS在監聽器上

 Listener-level TLS is controlled by useTls, tlsImplicit, tlsTimeout, tlsDisableProtocols, tlsDisableCipherSuites, and tlsIgnoreClientOrder. Each NetworkListener carries its own TLS fields and is configured independently: implicit TLS on a submissions endpoint is set by flipping tlsImplicit on that listener alone, without touching other listeners. See TLS overview for the list of supported protocols and cipher suites.

 監聽器等級TLS由 useTls 、 tlsImplicit 、 tlsDisableProtocols \([https://stalw.art/docs/ref/object/network-listener#tlsimplicit](https://stalw.art/docs/ref/object/network-listener#tlsimplicit)\) `tlsTimeout` `tlsDisableCipherSuites` \]\([https://stalw.art/docs/ref/object/network-listener#tlsdisableciphersuites\)和](https://stalw.art/docs/ref/object/network-listener#tlsdisableciphersuites%2529%2525E5%252592%25258C) tlsIgnoreClientOrder控制。每個 NetworkListener 都擁有自己的TLS字段，並且獨立配置：提交端點上的隱式TLS僅通過翻轉該監聽器上的 tlsImplicit來設置，無需修改其他監聽器。有關支援的協定和密碼套件列表，請參閱 TLS概述 。

## Example｜例子

 The following listeners define an SMTP server on port 25, an explicit-TLS submission endpoint on port 587, an implicit-TLS submissions endpoint on port 465, and an HTTP management endpoint on port 8080:

 以下監聽器定義了連接埠 25 上的SMTP伺服器、連接埠 587 上的明確TLS提交端點、連接埠 465 上的隱式TLS提交端點以及連接埠 8080 上的HTTP端管理：

```json
[
  {"name": "smtp", "protocol": "smtp", "bind": {"[::]:25": true}},
  {"name": "submission", "protocol": "smtp", "bind": {"[::]:587": true}},
  {"name": "submissions", "protocol": "smtp", "bind": {"[::]:465": true}, "tlsImplicit": true},
  {"name": "management", "protocol": "http", "bind": {"127.0.0.1:8080": true}}
]
```
