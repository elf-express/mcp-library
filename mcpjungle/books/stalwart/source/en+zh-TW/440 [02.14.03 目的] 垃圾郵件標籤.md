# SpamTag｜垃圾郵件標籤

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines a score or action assigned to a spam classification tag.

 定義分配給垃圾郵件分類標籤的分數或操作。

 This object can be configured from the WebUI under Settings › Spam Filter › Scores

 此物件可在 WebUI的「設定」&gt;「垃圾郵件過濾器」&gt;「分數」中進行設定。

## Fields｜田野

 SpamTag is a **multi-variant** object: each instance has an `@type` discriminator selecting one of the variants below, and each variant carries its own set of fields.

 SpamTag 是一個**多變體**物件：每個實例都有一個`@type`鑑別器，用於選擇以下變體之一，並且每個變體都帶有自己的一組欄位。

## JMAP API

 The SpamTag object is available via the `urn:stalwart:jmap` capability.

 SpamTag 物件可透過`urn:stalwart:jmap`功能取得。

### `x:SpamTag/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是 [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)節5.1中定義。

 This method requires the `sysSpamTagGet` permission.

 此方法需要`sysSpamTagGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:SpamTag/get",
          {
            "ids": [
              "id1"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:SpamTag/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是 [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)節5.3中定義。

 Supports create, update, and destroy operations in a single call.

 支援在一次呼叫中執行建立、更新和銷毀操作。

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get SpamTag id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create SpamTag/Score \
  --field tag=Example
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query SpamTag
stalwart-cli query SpamTag --where tag=example
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update SpamTag id1 --field tag='updated value'
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete SpamTag --ids id1
```
