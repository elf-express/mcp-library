# NetworkListener｜網路監聽器

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines a network listener for accepting incoming connections.

 定義一個網路監聽器，用於接受傳入的連線。

 This object can be configured from the WebUI under Settings › Network › Listeners

 可以透過 WebUI下的「設定」›「網路」›「監聽器」來設定此物件。

## Fields｜田野

##### `name`

> Type: \\\`String\\\` · read-only

類型： \`String\` · 只讀

 Unique identifier for the listener

 監聽器的唯一識別符

##### `bind`

> Type: \\\`Set<socketaddr>\\\` · min items: 1

類型： \`Set<socketaddr>\` · 最少數量：1

 The addresses the listener will bind to

 監聽器將綁定的位址

##### `protocol`

> Type: \\\[\\\`NetworkListenerProtocol\\\`\\\]\\\(#networklistenerprotocol\\\) · default: \\\`"smtp"\\\`

類型：\[\`NetworkListenerProtocol\`\]\(#networklistenerprotocol\) · 預設值： \`"smtp"\`

 The protocol used by the listener

 監聽器使用的協議

##### `overrideProxyTrustedNetworks`

> Type: \\\`Set<ipmask>\\\`

類型： \`Set<ipmask>\`

 Enable proxy protocol for connections from these networks

 為來自這些網路的連線啟用代理協議

##### `socketBacklog`

> Type: \\\`UnsignedInt?\\\` · default: \\\`1024\\\` · min: 1

類型： \`UnsignedInt?\` · 預設值： \`1024\` · 最小值：1

 The maximum number of incoming connections that can be pending in the backlog queue

 積壓隊列中可以等待的最大傳入連線數

##### `socketNoDelay`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Whether the Nagle algorithm should be disabled for the socket

 是否應該對套接字禁用 Nagle 演算法

##### `socketReceiveBufferSize`

> Type: \\\`UnsignedInt?\\\` · min: 1

類型： \`UnsignedInt?\` · 最小：1

 The size of the buffer used for receiving data

 用於接收資料的緩衝區大小

##### `socketReuseAddress`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Whether the socket can be bound to an address that is already in use by another socket

 套接字是否可以綁定到已被另一個套接字使用的位址

##### `socketReusePort`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Whether multiple sockets can be bound to the same address and port

 多個套接字是否可以綁定到同一個位址和端口

##### `socketSendBufferSize`

> Type: \\\`UnsignedInt?\\\` · min: 1

類型： \`UnsignedInt?\` · 最小：1

 The size of the buffer used for sending data

 用於傳送資料的緩衝區大小

##### `socketTosV4`

> Type: \\\`UnsignedInt?\\\` · min: 1

類型： \`UnsignedInt?\` · 最小：1

 The type of service \(TOS\) value for the socket, which determines the priority of the traffic sent through the socket

 套接字的服務類型 \( TOS \) 值決定了透過此套接字發送的流量的優先順序。

##### `socketTtl`

> Type: \\\`UnsignedInt?\\\` · min: 1

類型： \`UnsignedInt?\` · 最小：1

 Time-to-live \(TTL\) value for the socket, which determines how many hops a packet can make before it is discarded

 套接字的生存時間 \( TTL \) 值，決定了封包在被丟棄之前可以經過多少跳躍。

##### `useTls`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Whether to enable TLS for this listener

 是否為此監聽器啟用TLS

##### `tlsDisableCipherSuites`

> Type: \\\`Set&amp;lt;\\\`\\\[\\\`TlsCipherSuite\\\`\\\]\\\(#tlsciphersuite\\\)\\\`&amp;gt;\\\`

模式標本： \`Set&amp;lt;\` \[ \`TlsCipherSuite\` \]\(#tlsciphersuite\)\`&amp;gt;\`

 Which cipher suites to disable

 要停用哪些密碼套件

##### `tlsDisableProtocols`

> Type: \\\`Set&amp;lt;\\\`\\\[\\\`TlsVersion\\\`\\\]\\\(#tlsversion\\\)\\\`&amp;gt;\\\`

類型： \`Set&amp;lt;\` \[ \`TlsVersion\` \]\(#tlsversion\)\`&amp;gt;\`

 Which TLS protocols to disable

 要禁用哪些TLS協議

##### `tlsIgnoreClientOrder`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Whether to ignore the client’s cipher order

 是否忽略客戶端的密碼順序

##### `tlsImplicit`

> Type: \\\`Boolean\\\` · default: \\\`false\\\`

類型： \`Boolean\` · 預設值： \`false\`

 Whether to use implicit TLS

 是否使用隱式TLS

##### `tlsTimeout`

> Type: \\\`Duration?\\\` · default: \\\`60000\\\`

類型： \`Duration?\` · 預設值： \`60000\`

 TLS handshake timeout

 TLS握手超時

##### `maxConnections`

> Type: \\\`UnsignedInt?\\\` · default: \\\`8192\\\` · min: 1

類型： \`UnsignedInt?\` · 預設值： \`8192\` · 最小值：1

 The maximum number of concurrent connections the listener will accept

 監聽器可接受的最大同時連線數

## JMAP API

 The NetworkListener object is available via the `urn:stalwart:jmap` capability.

 NetworkListener 物件可透過`urn:stalwart:jmap`功能取得。

### `x:NetworkListener/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節中定義。

 This method requires the `sysNetworkListenerGet` permission.

 此方法需要`sysNetworkListenerGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:NetworkListener/get",
          {
            "ids": [
              "id1"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:NetworkListener/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節中定義。

 Supports create, update, and destroy operations in a single call.

 支援在一次呼叫中執行建立、更新和銷毀操作。

### `x:NetworkListener/query`

 This is a standard [Foo/query](https://www.rfc-editor.org/rfc/rfc8620#section-5.5) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.5), Section 5.5.

 這是 [Foo/query](https://www.rfc-editor.org/rfc/rfc8620#section-5.5)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.5)節5.5中定義。

 This method requires the `sysNetworkListenerQuery` permission.

 此方法需要`sysNetworkListenerQuery` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;

  -H 'Authorization: Bearer $TOKEN' \
```

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get NetworkListener id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create NetworkListener \
  --field 'bind={}' \
  --field 'overrideProxyTrustedNetworks={}' \
  --field 'tlsDisableCipherSuites={}' \
  --field 'tlsDisableProtocols={}'
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query NetworkListener
stalwart-cli query NetworkListener --where name=example
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update NetworkListener id1 --field bind='{}'
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete NetworkListener --ids id1
```
