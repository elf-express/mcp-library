# MtaQueueQuota

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines a quota rule for message queues.

 為訊息佇列定義配額規則。

 This object can be configured from the WebUI under Settings › MTA › Rates & Quotas › Queue Quotas

 此物件可在 WebUI下的「設定」› MTA › “費率和配額”› “佇列配額”中進行設定。

## Fields｜田野

##### `enable`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Whether to enable this quota

 是否啟用此配額

##### `description`

> Type: \\\`String?\\\` · read-only

類型： \`String?\` · 只讀

 Short description for the quota

 配額的簡要說明

##### `key`

> Type: \\\`Set&amp;lt;\\\`\\\[\\\`MtaQueueQuotaKey\\\`\\\]\\\(#mtaqueuequotakey\\\)\\\`&amp;gt;\\\`

模式標本： \`Set&amp;lt;\` \[ \`MtaQueueQuotaKey\` \]\(#mtaqueuequotakey\)\`&amp;gt;\`

 Optional list of context variables that determine where this quota should be applied

 可選的上下文變數列表，用於確定此配額的應用範圍。

##### `match`

> Type: \\\[\\\`Expression\\\`\\\]\\\(#expression\\\)

類型：\[\`Expression\`\]\(#expression\)

 Enable the imposition of concurrency and rate limits only when a specific condition is met

 僅當滿足特定條件時才啟用並發和速率限制。

 Available variables: \[\`MtaQueueHostVariable\`\]\(&lt;327 \[02.14.02.02 多變的\] MtaQueueHostVariable.md&gt;\).

 可用變數：\[\`MtaQueueHostVariable\`\]\(&lt;327 \[02.14.02.02 多變的\] MtaQueueHostVariable.md&gt;\) 。

##### `messages`

> Type: \\\`UnsignedInt?\\\` · min: 1

類型： \`UnsignedInt?\` · 最小：1

 Maximum number of messages in the queue that this quota will allow

 此配額允許佇列中的最大訊息數

##### `size`

> Type: \\\`Size?\\\`

類型： \`Size?\`

 Maximum total size of messages in the queue that this quota will allow

 此配額允許佇列中訊息的最大總大小。
