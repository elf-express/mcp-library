# MailingList｜郵件清單

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines a mailing list that distributes messages to a group of recipients.

 定義一個郵件列表，用於向一組收件者分發訊息。

 This object can be configured from the WebUI under Management › Directory › Mailing Lists

 此物件可在 WebUI下的「管理 › 目錄 › 郵件清單」中進行設定。

## Fields｜田野

##### `name`

> Type: \\\`EmailLocalPart\\\` · required

類型： \`EmailLocalPart\` · 必填

 Name of the mailing list, typically an email address local part.

 郵件清單的名稱，通常是電子郵件地址的本機部分。

##### `domainId`

> Type: \\\`Id&amp;lt;\\\`\\\[\\\`Domain\\\`\\\]\\\(&lt;377 \\\[02.14.03 目的\\\] 領域.md&gt;\\\)\\\`&amp;gt;\\\` · required

類型： \`Id&amp;lt;\` \[ \`Domain\` \]\(&lt;377 \[02.14.03 目的\] 領域.md&gt;\)\`&amp;gt;\` · 必填

 Identifier for the domain this mailing list belongs to. This is used to determine the email address of the mailing list, which is formed as name@domain.

 此郵件清單所屬域的識別碼。它用於確定郵件清單的電子郵件地址，格式為 name@domain。

##### `emailAddress`

> Type: \\\`EmailAddress\\\` · server-set

類型： \`EmailAddress\` · 伺服器集

 The email address of the mailing list, formed as name@domain.

 郵件清單的電子郵件地址，格式為 name@domain。

##### `description`

> Type: \\\`String?\\\`

類型： \`String?\`

 Description of the mailing list

 郵件清單描述

##### `aliases`

> Type: \\\`List&amp;lt;\\\`\\\[\\\`EmailAlias\\\`\\\]\\\(#emailalias\\\)\\\`&amp;gt;\\\`

模式標本： \`List&amp;lt;\` \[ \`EmailAlias\` \]\(#emailalias\)\`&amp;gt;\`

 List of email aliases for the mailing list

 郵件列表的電子郵件別名列表

##### `memberTenantId`

> Type: \\\`Id&amp;lt;\\\`\\\[\\\`Tenant\\\`\\\]\\\(&lt;447 \\\[02.14.03 目的\\\] 租戶.md&gt;\\\)\\\`&amp;gt;?\\\`

模式標本： \`Id&amp;lt;\` \[ \`Tenant\` \]\(&lt;447 \[02.14.03 目的\] 租戶.md&gt;\)\`&amp;gt;?\`

 Identifier for the tenant this mailing list belongs to

 此郵件清單所屬租戶的識別符

##### `recipients`

> Type: \\\`Set<emailaddress>\\\`

類型： \`Set<emailaddress>\`

 List of email addresses that are members of the mailing list

 郵件列表成員的電子郵件地址列表

## JMAP API

 The MailingList object is available via the `urn:stalwart:jmap` capability.

 MailingList 物件可透過`urn:stalwart:jmap`功能取得。

### `x:MailingList/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是 [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)節5.1中定義。

 This method requires the `sysMailingListGet` permission.

 此方法需要`sysMailingListGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \

        [
          "x:MailingList/get",
          {
            "ids": [

          "c1"
```

 This is a standard [Foo/query](https://www.rfc-editor.org/rfc/rfc8620#section-5.5) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.5), Section 5.5.

 此方法需要`sysMailingListQuery` 權限 。


## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get MailingList id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create MailingList \
  --field name=alice \
  --field 'domainId=<Domain id>' \
  --field 'aliases={}' \
  --field 'recipients={}'
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query MailingList
stalwart-cli query MailingList --where text=example
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update MailingList id1 --field description='updated value'
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete MailingList --ids id1
```
