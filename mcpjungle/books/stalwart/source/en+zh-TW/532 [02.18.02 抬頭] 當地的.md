# Local｜當地的

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[storage｜貯存\\\]\\\(&lt;000 目錄.md#c-72&gt;\\\) › \\\[lookup｜抬頭\\\]\\\(&lt;000 目錄.md#c-75&gt;\\\)

Local lookup lists hold key-only membership sets and key-value pairs entirely in memory. They are well suited to small, slow-changing sets of static data, consulted from expressions or Sieve filters.

 本地查找清單將僅包含鍵的成員集和鍵值對完全保存在記憶體中。它們非常適合用於儲存小型、變化緩慢的靜態資料集，這些資料集可透過表達式或 Sieve 篩選器進行查詢。

## Key-only lists｜僅包含密鑰的列表

 Key-only lists, useful for membership tests such as allow-lists and deny-lists, are defined through the MemoryLookupKey object \(found in the WebUI under Settings › Lookups › In-Memory Keys, Settings › Spam Filter › Lists › Blocked Domains, Settings › Spam Filter › Lists › Spam Traps, Settings › Spam Filter › Lists › Trusted Domains, Settings › Spam Filter › Lists › URL Redirectors\). Each record has:

 僅包含鍵的清單（例如允許清單和拒絕清單）透過 MemoryLookupKey物件定義（可在 WebUI的「設定」&gt;「尋找」&gt;「記憶體鍵」、「設定」&gt;「垃圾郵件過濾器」&gt;「清單」&gt;「已封鎖的網域名稱」、「設定」&gt;「垃圾郵件過濾器」&gt;「清單」&gt;「垃圾郵件陷阱」、「設定」&gt;「垃圾郵件過濾器」&gt;「清單」&gt;「受信任的網域名稱」和「設定值」&gt; URL傳送器」中「每筆記錄包含：

- namespace: the lookup namespace the key belongs to \(required\). All records sharing a namespace form a single lookup list.
namespace : 鍵所屬的尋找命名空間（必填）。共用相同命名空間的所有記錄構成一個查找清單。
- key: the key name \(required, up to 255 characters\).
key : 金鑰名稱（必填，最多 255 個字元）。
- isGlobPattern: when `true`, the key is interpreted as a glob pattern, matching multiple concrete keys \(for example `*.example.com` or `mx?.example.org`\). Default: `false`.
isGlobPattern : 當`true`時，鍵被解釋為 glob 模式，匹配多個具體鍵（例如`*.example.com`或`mx?.example.org` ）。預設值： `false` 。
To build a list of allowed domains, for instance, create one MemoryLookupKey record per entry, all sharing the namespace `allow-list-domain`, with the domain as the key.
 例如，要建立允許的域列表，可以為每個條目建立一個 MemoryLookupKey 記錄，所有記錄共用命名空間`allow-list-domain` ，並將域作為鍵。

## Key-value lists｜鍵值列表

 Lists that associate a value with each key are defined through the MemoryLookupKeyValue object \(found in the WebUI under Settings › Lookups › In-Memory Key-Values\). Each record has the same namespace, key, and isGlobPattern fields as MemoryLookupKey, plus:

 將值與每個鍵關聯的清單透過 MemoryLookupKeyValue物件定義（可在 WebUI 的「設定」&gt;「尋找」&gt;「記憶體鍵值對」中找到）。每筆記錄都包含與 MemoryLookupKey 相同的 namespace 、key和 isGlobPattern字段，此外還包括：

- value: the value associated with the key \(required\).
value : 與鍵關聯的值（必填）。
