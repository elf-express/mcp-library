# PublicKey｜公鑰

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines a public key for email encryption \(OpenPGP or S/MIME\).

 定義電子郵件加密的公鑰（OpenPGP 或 S/ MIME ）。

 This object can be configured from the WebUI under Account › Public Keys

 此物件可在 WebUI下的「帳號 › 公鑰」中進行設定。

## Fields｜田野

##### `accountId`

> Type: \\\`Id&amp;lt;\\\`\\\[\\\`Account\\\`\\\]\\\(&lt;342 \\\[02.14.03 目的\\\] 帳戶.md&gt;\\\)\\\`&amp;gt;\\\` · read-only

模式標本： \`Id&amp;lt;\` \[ \`Account\` \]\(&lt;342 \[02.14.03 目的\] 帳戶.md&gt;\)\`&amp;gt;\` · 只讀

 Identifier for the account this public key belongs to

 此公鑰所屬帳戶的識別符

 OpenPGP 或 S/ MIME公鑰數據

 公鑰描述

> Type: \\\`UTCDateTime\\\` · server-set

 Creation date of the public key

 公鑰創建日期

 公鑰的到期日期

 與公鑰關聯的電子郵件地址

## JMAP API

 The PublicKey object is available via the `urn:stalwart:jmap` capability.

 PublicKey 物件可透過`urn:stalwart:jmap`功能取得。

### `x:PublicKey/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節定義。

 This method requires the `sysPublicKeyGet` permission.

 此方法需要`sysPublicKeyGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:PublicKey/get",
          {
            "ids": [
              "id1"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:PublicKey/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是 [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)節5.3中定義。

 Supports create, update, and destroy operations in a single call.

 支援在一次呼叫中執行建立、更新和銷毀操作。

#### Create｜創造

 This operation requires the `sysPublicKeyCreate` permission.

 此操作需要`sysPublicKeyCreate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:PublicKey/set",
          {
            "create": {
              "new1": {
                "description": "Example",
                "emailAddresses": {},
                "key": "Example"
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:PublicKey/query`

 This is a standard [Foo/query](https://www.rfc-editor.org/rfc/rfc8620#section-5.5) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.5), Section 5.5.

 這是[Foo/query](https://www.rfc-editor.org/rfc/rfc8620#section-5.5)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.5) ，第5.5節定義。

 This method requires the `sysPublicKeyQuery` permission.

 此方法需要`sysPublicKeyQuery` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:PublicKey/query",
          {
            "filter": {
              "accountId": "id1"
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

The `x:PublicKey/query` `filter` argument accepts the following conditions \(combinable with `AnyOf` / `AllOf` / `Not` per RFC 8620\):

`x:PublicKey/query` `filter`參數接受以下條件（可與`AnyOf` / `AllOf` / `Not`結合使用，請參閱RFC 8620）：

| Condition 條件 | Kind 種類 |
| --- | --- |
| `accountId` | id of Account 帳戶 ID |

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get PublicKey id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create PublicKey \
  --field key=Example \
  --field description=Example \
  --field 'emailAddresses={}'
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query PublicKey
stalwart-cli query PublicKey --where accountId=id1
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update PublicKey id1 --field key='updated value'
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete PublicKey --ids id1
```
