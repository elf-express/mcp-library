# Tenant｜租戶

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines a tenant for multi-tenant environments with isolated resources and quotas.

 為具有隔離資源和配額的多租戶環境定義租戶。

 This object is only available with an Enterprise license.

 此物件僅在擁有企業許可證的情況下可用。

 This object can be configured from the WebUI under Management › Directory › Tenants

 可以透過 WebUI在「管理」›「目錄」›「租用戶」下設定此物件。

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get Tenant id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create Tenant \
  --field name=Example \
  --field 'roles={"@type":"Default"}' \
  --field 'permissions={"@type":"Inherit"}' \
  --field 'quotas={}'
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query Tenant
stalwart-cli query Tenant --where text=example
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update Tenant id1 --field name='updated value'
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete Tenant --ids id1
```

## Nested types｜巢狀類型

### Roles｜角色

 Role assignment for groups and tenants.

 為群組和租戶分配角色。

- **`Default`**: Default role. No additional fields.
**`Default`**：預設角色。無其他字段。
- **`Custom`**: Custom role. Carries the fields of [CustomRoles](#customroles).
**`Custom`**: 自訂角色。包含 [CustomRoles](#customroles)的欄位。
#### CustomRoles｜自訂角色

 Custom role assignment with specific role references.

 自訂角色分配，並指定角色參考。

##### `roleIds`

> Type: \\\`Set<id<`[`role`](\)\`&amp;gt;&amp;gt;\`模式標本： \`Set&amp;lt;id&amp;lt;`[=""`role`="" ](\)\`&amp;gt;&amp;gt;\` List of roles assigned to this principal. 該校長所承擔的角色列表。 ### Permissions｜權限

 Permission assignment mode for accounts, groups, and tenants. 帳戶、群組和租用戶的權限分配模式。 
- **`Inherit`**: Inherited permissions. No additional fields.
**`Inherit`**：繼承的權限。無其他字段。
- **`Merge`**: Permissions are combined with inherited permissions. Carries the fields of [PermissionsList](#permissionslist).
**`Merge`**：權限與繼承的權限結合。包含 [PermissionsList](#permissionslist)的欄位。
- **`Replace`**: Permissions replace all inherited permissions. Carries the fields of [PermissionsList](#permissionslist).
**`Replace`**: 權限替換所有繼承的權限。包含 [PermissionsList](#permissionslist)的欄位。
