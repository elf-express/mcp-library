# BlockedIp｜BlockedIP

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines a blocked IP address or network range.

 定義被封鎖的IP位址或網路範圍。

 This object can be configured from the WebUI under Settings › Security › Blocked IPs

 此物件可在 WebUI的「設定」›「安全性」›「已封鎖的 IP」下進行設定。

## Fields｜田野

##### `address`

> Type: \\\`IpMask\\\` · read-only

類型： \`IpMask\` · 只讀

 The IP address or mask to block

 要阻止的IP位址或掩碼

##### `reason`

> Type: \\\[\\\`BlockReason\\\`\\\]\\\(#blockreason\\\) · default: \\\`"manual"\\\`

類型：\[\`BlockReason\`\]\(#blockreason\) · 預設值： \`"manual"\`

 The reason for blocking this IP address

 封鎖此IP地址的原因

##### `createdAt`

> Type: \\\`UTCDateTime\\\` · server-set

類型： \`UTCDateTime\` · 伺服器集

 The date and time when this IP address was blocked

 此IP地址被屏蔽的日期和時間

##### `expiresAt`

> Type: \\\`UTCDateTime?\\\`

類型： \`UTCDateTime?\`

 The date and time when this IP address block will expire

 此IP地址塊的失效日期和時間

## JMAP API

 The BlockedIp object is available via the `urn:stalwart:jmap` capability.

 BlockedIp 物件可透過`urn:stalwart:jmap`功能取得。

### `x:BlockedIp/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是 [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)節5.1中定義。

 This method requires the `sysBlockedIpGet` permission.

 此方法需要`sysBlockedIpGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:BlockedIp/get",
          {
            "ids": [
              "id1"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:BlockedIp/query`

 This is a standard [Foo/query](https://www.rfc-editor.org/rfc/rfc8620#section-5.5) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.5), Section 5.5.

 這是 [Foo/query](https://www.rfc-editor.org/rfc/rfc8620#section-5.5)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.5)節5.5中定義。

 This method requires the `sysBlockedIpQuery` permission.

 此方法需要`sysBlockedIpQuery` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
```

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get BlockedIp id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create BlockedIp
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query BlockedIp
stalwart-cli query BlockedIp --where address=example
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update BlockedIp id1 --field reason=manual
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete BlockedIp --ids id1
```

### BlockReason｜阻塞原因

| Value 值 | Label 標籤 |
| --- | --- |
| `rcptToFailure` | Excessive failed RCPT TO commands 過多的失敗RCPT TO指令 |
| `authFailure` | Excessive failed authentication attempts 驗證失敗次數過多 |
| `loitering` | Excessive loitering connections 過度徘徊聯繫 |
| `portScanning` | Excessive port scanning attempts 埠掃描嘗試次數過多 |
| `manual` | Manually blocked IP address 手動屏蔽IP位址 |
| `other` | Other reason 其他原因 |
