# DkimSignature｜DKIM簽名

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines a DKIM signature used to sign outgoing email messages.

 定義用於簽署外寄電子郵件的DKIM簽名。

 This object can be configured from the WebUI under Management › Domains › DKIM Signatures

 此物件可在 WebUI下的「管理 › 網域 › DKIM簽章」中進行設定。

## Fields｜田野

 DkimSignature is a **multi-variant** object: each instance has an `@type` discriminator selecting one of the variants below, and each variant carries its own set of fields.

 DkimSignature 是一個**多變體**物件：每個實例都有一個`@type`鑑別器，用於選擇以下變體之一，並且每個變體都包含自己的一組欄位。

### `@type: "Dkim1Ed25519Sha256"`

 DKIM1 \(Ed25519 SHA-256\)

 DKIM1 （Ed25519 SHA -256）

##### `auid`

> Type: \\\`String?\\\`

類型： \`String?\`

 Agent or user identifier included in the DKIM signature header

 DKIM簽章標頭中包含的代理程式或使用者標識符

##### `canonicalization`

> Type: \\\[\\\`DkimCanonicalization\\\`\\\]\\\(#dkimcanonicalization\\\) · default: \\\`"relaxed/relaxed"\\\`

類型：\[\`DkimCanonicalization\`\]\(#dkimcanonicalization\) · 預設值： \`"relaxed/relaxed"\`

 在簽名之前，對標頭和正文應用規範化演算法。

##### `expire`

類型： \`Duration?\`

 此DKIM簽名失效的時間過後將不再有效

##### `headers`

 要包含在DKIM簽章中的消息頭列表

 PEM編碼的公鑰，用於驗證簽名，由私鑰衍生而來。

 此DKIM簽章所關聯的域的標識符

> Type: \\\`Id&amp;lt;\\\`\\\[\\\`Tenant\\\`\\\]\\\(&lt;447 \\\[02.14.03 目的\\\] 租戶.md&gt;\\\)\\\`&amp;gt;?\\\` · \\\[enterprise\\\]\\\(&lt;466 \\\[02.15 伺服器\\\] 企業許可證.md&gt;\\\)

模式標本： \`Id&amp;lt;\` \[ \`Tenant\` \]\(&lt;447 \[02.14.03 目的\] 租戶.md&gt;\)\`&amp;gt;?\` · \[企業\]\(&lt;466 \[02.15 伺服器\] 企業許可證.md&gt;\)

 Identifier for the tenant this DKIM signature belongs to

類型： \`String\` · 必填

 用於在DNS中定位DKIM公鑰的選擇器

## JMAP API

 The DkimSignature object is available via the `urn:stalwart:jmap` capability.

 DkimSignature 物件可透過`urn:stalwart:jmap`功能取得。

### `x:DkimSignature/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節中定義。

 This method requires the `sysDkimSignatureGet` permission.

 此方法需要`sysDkimSignatureGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:DkimSignature/get",
          {
            "ids": [
              "id1"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:DkimSignature/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節中定義。

 Supports create, update, and destroy operations in a single call.

 支援在一次呼叫中執行建立、更新和銷毀操作。

#### Create｜創造

 This operation requires the `sysDkimSignatureCreate` permission.

 此操作需要`sysDkimSignatureCreate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:DkimSignature/set",
          {
            "create": {
              "new1": {
                "@type": "Dkim1Ed25519Sha256",
                "domainId": "<Domain id>",
                "privateKey": {
                  "@type": "Text",
                  "secret": "Example"
                },
                "selector": "Example"
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

 此操作需要`sysDkimSignatureUpdate` 權限 。


 This is a standard [Foo/query](https://www.rfc-editor.org/rfc/rfc8620#section-5.5) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.5), Section 5.5.

 This method requires the `sysDkimSignatureQuery` permission.

 此方法需要`sysDkimSignatureQuery` 權限 。

