# SpamPyzor

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Configures the Pyzor collaborative spam detection service.

 設定 Pyzor 協同垃圾郵件偵測服務。

 This object can be configured from the WebUI under Settings › Spam Filter › Pyzor

 此物件可在 WebUI 「設定」&gt;「垃圾郵件過濾器」&gt;「Pyzor」中進行設定。

## Fields｜田野

##### `blockCount`

> Type: \\\`UnsignedInt\\\` · default: \\\`5\\\` · max: 1000 · min: 1

類型： \`UnsignedInt\` · 預設值： \`5\` · 最大值：1000 · 最小值：1

 The number of times the hash appears in the Pyzor blocklist

 雜湊值在 Pyzor 封鎖清單中出現的次數

##### `enable`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Whether to enable the Pyzor classifier. Pyzor is a collaborative, networked system to detect and report spam.

 是否啟用 Pyzor 分類器。 Pyzor 是一個協作式網路系統，用於偵測和舉報垃圾郵件。

##### `host`

> Type: \\\`String\\\` · default: \\\`"public.pyzor.org"\\\`

類型： \`String\` · 預設值： \`"public.pyzor.org"\`

 The hostname of the Pyzor server

 Pyzor伺服器的主機名

##### `port`

> Type: \\\`UnsignedInt\\\` · default: \\\`24441\\\` · max: 65535 · min: 100

類型： \`UnsignedInt\` · 預設值： \`24441\` · 最大值：65535 · 最小值：100

 The port to connect to the Pyzor server

 連接到 Pyzor 伺服器的端口

##### `ratio`

> Type: \\\`Float\\\` · default: \\\`0.2\\\` · max: 1 · min: 0

類型： \`Float\` · 預設值： \`0.2\` · 最大值：1 · 最小值：0

 The ratio of the number of times the hash appears in the Pyzor allowlist to the blocklist

 哈希值在 Pyzor 允許列表和黑名單中出現的次數之比

##### `timeout`

> Type: \\\`Duration\\\` · default: \\\`5000\\\`

類型： \`Duration\` · 預設值： \`5000\`

 The timeout for the Pyzor server. If the server does not respond within this time, the check is considered failed.

 Pyzor 伺服器的逾時時間。如果伺服器在此時間內沒有回應，則檢查被視為失敗。

##### `allowCount`

> Type: \\\`UnsignedInt\\\` · default: \\\`10\\\` · max: 1000 · min: 1

類型： \`UnsignedInt\` · 預設值： \`10\` · 最大值：1000 · 最小值：1

 The number of times the hash appears in the Pyzor allowlist

 哈希值在 Pyzor 允許清單中出現的次數

## JMAP API

 The SpamPyzor singleton is available via the `urn:stalwart:jmap` capability.

 SpamPyzor 單例可透過`urn:stalwart:jmap`功能取得。

### `x:SpamPyzor/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是 [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)節5.1中定義。

 For singletons, the `ids` argument should be the literal `singleton` \(or `null` to return the single instance\).

 對於單例， `ids`參數應該是字面值`singleton` （或`null`以傳回單一實例）。

 This method requires the `sysSpamPyzorGet` permission.

 此方法需要`sysSpamPyzorGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:SpamPyzor/get",
          {
            "ids": [
              "singleton"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:SpamPyzor/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是 [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)節5.3中定義。

 For singletons, only the `update` argument with id `singleton` is accepted; `create` and `destroy` arguments are rejected.

 對於單例，僅接受 id 為`singleton` `update`參數；拒絕`create`和`destroy`參數。

 This method requires the `sysSpamPyzorUpdate` permission.

 此方法需要`sysSpamPyzorUpdate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:SpamPyzor/set",
          {
            "update": {
              "singleton": {
                "host": "updated value"
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```
