# CalendarAlarm｜行事曆鬧鐘

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Configures calendar alarm email notifications.

 配置行事曆鬧鐘郵件通知。

 This object can be configured from the WebUI under Settings › Calendar & Contacts › Alarms

 此物件可在 WebUI 「設定」&gt;「行事曆與聯絡人」&gt;「鬧鐘」中進行設定。

## Fields｜田野

##### `allowExternalRcpts`

> Type: \\\`Boolean\\\` · default: \\\`false\\\`

類型： \`Boolean\` · 預設值： \`false\`

 Allows calendar alarms to be sent to external recipients, enabling notifications to users outside the server

 允許將日曆提醒傳送給外部收件人，從而向伺服器外部的使用者發送通知。

##### `enable`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Enables the calendar alarms feature, allowing users to set alarms for events and receive notifications via e-mail

 啟用日曆提醒功能，允許使用者為事件設定提醒並透過電子郵件接收通知。

##### `fromEmail`

> Type: \\\`EmailAddress?\\\`

類型： \`EmailAddress?\`

 Specifies the e-mail address that will appear in the ‘From’ field of calendar alarm e-mails, ensuring that users can reply to or contact the sender

 指定日曆提醒電子郵件「寄件者」欄位中顯示的電子郵件地址，確保使用者可以回覆或聯絡寄件者。

##### `fromName`

> Type: \\\`String\\\` · default: \\\`"Stalwart Calendar"\\\`

類型： \`String\` · 預設值： \`"Stalwart Calendar"\`

 Specifies the name that will appear in the ‘From’ field of calendar alarm e-mails, providing a recognizable sender name for users

 指定日曆提醒電子郵件「寄件者」欄位中顯示的名稱，以便使用者識別寄件者。

##### `minTriggerInterval`

> Type: \\\`Duration\\\` · default: \\\`3600000\\\`

類型： \`Duration\` · 預設值： \`3600000\`

 Specifies the minimum interval for calendar alarms, ensuring that alarms are not triggered too frequently

 指定日曆提醒的最小間隔，確保提醒不會觸發過於頻繁。

##### `template`

> Type: \\\`Html?\\\` · \\\[enterprise\\\]\\\(&lt;466 \\\[02.15 伺服器\\\] 企業許可證.md&gt;\\\)

類型： \`Html?\` · \[企業\]\(&lt;466 \[02.15 伺服器\] 企業許可證.md&gt;\)

 Specifies the HTML template used for rendering calendar alarm e-mails, allowing customization of the alarm notification format

 指定用於渲染日曆提醒電子郵件的HTML模板，允許自訂提醒通知格式。

## JMAP API

 The CalendarAlarm singleton is available via the `urn:stalwart:jmap` capability.

 CalendarAlarm 單例可透過`urn:stalwart:jmap`功能取得。

### `x:CalendarAlarm/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節定義。

 For singletons, the `ids` argument should be the literal `singleton` \(or `null` to return the single instance\).

 對於單例， `ids`參數應該是字面值`singleton` （或`null`以傳回單一實例）。

 This method requires the `sysCalendarAlarmGet` permission.

 此方法需要`sysCalendarAlarmGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:CalendarAlarm/get",
          {
            "ids": [
              "singleton"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:CalendarAlarm/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是 [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)節5.3中定義。

 For singletons, only the `update` argument with id `singleton` is accepted; `create` and `destroy` arguments are rejected.

 對於單例，僅接受 id 為`singleton` `update`參數；拒絕`create`和`destroy`參數。

 This method requires the `sysCalendarAlarmUpdate` permission.

 此方法需要`sysCalendarAlarmUpdate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:CalendarAlarm/set",
          {
            "update": {
              "singleton": {
                "fromName": "updated value"
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get CalendarAlarm
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update CalendarAlarm --field fromName='updated value'
```
