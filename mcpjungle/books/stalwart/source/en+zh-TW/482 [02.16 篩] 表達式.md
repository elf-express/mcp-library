# Expressions｜表達式

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[sieve｜篩\\\]\\\(&lt;000 目錄.md#c-67&gt;\\\)

The expression extension introduces the ability to evaluate arithmetic, logical, and comparison operations within Sieve scripts. This is useful for computing values from the current message and environment, and for controlling the flow of a script based on conditions that the base Sieve language cannot express.

 表達式擴充引入了在 Sieve 腳本中執行算術、邏輯和比較運算的功能。這對於根據當前訊息和環境計算值，以及根據 Sieve 基礎語言無法表達的條件控制腳本流程非常有用。

 Expressions can be evaluated using the `eval` test and the `let` and `while` instructions. In order to use these features, the `vnd.stalwart.expressions` extension must be declared in the script’s `require` statement.

 可以使用`eval`測試以及`let`和`while`指令來評估表達式。要使用這些功能，必須在腳本的`require`語句中宣告`vnd.stalwart.expressions`擴充。

## Operators｜操作員

 The expression extension supports the following operators:

 表達式擴充支援以下運算子：

**Arithmetic:** `+` \(addition\), `-` \(subtraction\), `*` \(multiplication\), `/` \(division\).

**算術：** `+` （加法）， `-` （減法）， `*` （乘法）， `/` （除法）。

**Logical:** `&&` \(AND\), `||` \(OR\), `^` \(XOR\), `!` \(NOT\).

**邏輯：** `&&` \( AND \), `||` \( OR \), `^` \( XOR \), `!` \( NOT .

**Comparison:** `==` \(equal\), `!=` \(not equal\), `>`, `<`, `>=`, `<=`.

**比較：** `==` （相等）， `!=` （不相等）， `>`, `<`, `>=`, `<=` 。

 When working with logical and comparison operators, the operands must have compatible types. Comparing a string to a number with `>` or `<` does not raise a runtime error, but the ordering reflects the string representation of the number rather than its numeric value. Keeping the operands of a comparison consistent \(both numeric, or both strings\) avoids surprising behaviour.

 在使用邏輯運算子和比較運算子時，操作數必須具有相容的類型。例如，使用`>`或`<`將字串與數字進行比較不會引發運行時錯誤，但順序反映的是數字的字串表示形式，而不是其數值。保持比較運算子的運算元一致（要麼都是數值，要麼都是字串）可以避免意外行為。

 The `+` operator is overloaded: when either operand is a string it performs concatenation, when both are numbers it performs addition, and when either operand is an array it concatenates arrays or appends the scalar. For example, `'user-' + env.remote_ip` builds a key from a literal and a variable, and `['Sender', envelope.from]` can be joined into a flat list with `['Sender'] + [envelope.from]`.

`+`運算子是重載的：當任一操作數為字串時，執行字串連接；當兩個操作數均為數字時，執行加法；當任一操作數為陣列時，執行陣列連接或附加標量。例如， `'user-' + env.remote_ip`可以根據字面量和變數建立鍵，而`['Sender', envelope.from]`可以與`['Sender'] + [envelope.from]`連接成一個扁平列表。

## Literals and indexing｜字面值和索引

 String literals are delimited by single or double quotes. Integer and floating-point literals follow the usual decimal form. Array literals use square brackets: `[1, 2, 3]`, `['[[email protected]](https://stalw.art/cdn-cgi/l/email-protection)', '[[email protected]](https://stalw.art/cdn-cgi/l/email-protection)']`.

 字串字面量以單引號或雙引號分隔。整數和浮點數位面量遵循通常的十進位形式。數組字面量使用方括號： `[1, 2, 3]`, `['[[email protected]](https://stalw.art/cdn-cgi/l/email-protection)', '[[email protected]](https://stalw.art/cdn-cgi/l/email-protection)']` 。

 Array elements are accessed with square-bracket indexing, starting at zero. The result of a function call that returns an array can be indexed directly:

 數組元素使用方括號索引訪問，索引從零開始。傳回數組的函數呼叫結果可以直接使用索引存取：

```sieve
let "parts" "split_once(envelope.from, '@')";
let "local" "parts[0]";
let "domain" "parts[1]";
```

## Literal text in `let` and `eval`｜`let`和`eval`中的文字

 The value assigned by `let`, and the argument of the `eval` test, is a Sieve string whose contents are parsed as an expression. A bare word inside that string is therefore read as a variable or function name rather than as text, and a script such as `let "prompt" "You are an assistant";` fails to compile with `Invalid variable or function name "You"`. Literal text has to carry its own quotes inside the Sieve string:

`let`賦值的值，以及`eval`測試的參數，是一個 Sieve 字串，其內容會被解析為表達式。因此，該字串中的單字會被讀取為變數名或函數名，而不是文字。類似`let "prompt" "You are an assistant";`的腳本無法與`Invalid variable or function name "You"`一起編譯。字面文字必須在 Sieve 字串中自帶引號。

```sieve
let "prompt" "'You are an assistant'";
```

 Text spanning several lines uses the Sieve multi-line form, which opens with `text:` and closes with a line containing a single period. The quoted expression string spans the whole block. There is no triple-quote form:

 跨多行的文字使用 Sieve 多行格式，以`text:`開頭，以包含單一句點的行結尾。帶引號的表達式字串跨越整個區塊。沒有三引號格式：

```sieve
let "prompt" text:
"First line of the prompt.
Second line of the prompt."
.
;
```

 Two quoting layers are involved, so the delimiters are worth choosing with care:

 由於涉及兩層引用，因此分隔符號的選擇需要格外謹慎：

- A `text:` block is taken verbatim, with no backslash processing, so the quote character that delimits the expression string cannot appear inside it. Use `"..."` when the text contains apostrophes and `'...'` when it contains double quotes. A backslash does keep the string from ending early, but it remains part of the value: `'the email\'s subject'` evaluates to `the email\'s subject`.
`text:`程式碼區塊會照原樣執行，不進行反斜線處理，因此用於分隔表達式字串的引號字元不能出現在其中。當文字包含單引號時，請使用`"..."` ；當文字包含雙引號時，請使用`'...'` 。反斜線可以防止字串提前結束，但它仍然是值的一部分： `'the email\'s subject'`計算結果為`the email\'s subject` 。
- A Sieve quoted string translates `\n`, `\r`, and `\t` before the expression is parsed, so a short multi-line value fits on one line: `let "prompt" "'First line.\nSecond line.'";` assigns two lines. A quote of the other kind is written directly, and `\\` produces a single backslash.
Sieve 引用字串會在解析表達式之前先轉換`\n`, `\r`和`\t` ，因此較短的多行值可以放在一行中： `let "prompt" "'First line.\nSecond line.'";`會賦值兩行。另一種類型的引用會直接寫入， `\\`會產生一個反斜線。
- A line consisting of a single period closes a `text:` block. To carry such a line inside the text, double the period; the interpreter removes the added one.
一個由單一句點組成的行表示一個`text:`程式碼區塊的結束。要將這樣的行放在文字內部，需要將句點重複兩次；解釋器會自動移除多出的那個句點。
## Functions｜函數

 A large set of functions is available from expressions. These range from pure string and array manipulation to DNS, SQL, and HTTP operations that the trusted interpreter can call during message processing. The reference documents each function, its signature, and whether it is restricted to the trusted interpreter.

 表達式提供了一系列函數。這些函數涵蓋了從純粹的字串和陣列操作到受信任解釋器在訊息處理期間可以呼叫的DNS, SQL和HTTP操作。 參考文件記錄了每個函數、其簽名以及它是否僅限於受信任解釋器 。

 The `system()` and `metric()` forms available in the configuration expression language are **not** available from Sieve expressions; those forms are specific to the configuration layer. Similarly, the Sieve regex extension provides the `:regex` and `:matches` match-type modifiers on tests, rather than a `matches()` function.

 配置表達式語言\([https://stalw.art/docs/configuration/expressions/](https://stalw.art/docs/configuration/expressions/)\) \) 中提供的`system()`和`metric()`形式在 Sieve 表達式中**不可用**；這些形式是配置層特有的。同樣，Sieve 正規表示式擴充在測試中提供的是`:regex`和`:matches`匹配類型修飾符，而不是`matches()`函數。

## Using the `eval` test｜使用`eval`測試

 The `eval` test evaluates the expression within the quotes and returns a boolean value.

`eval`測試評估引號內的表達式並傳回布林值。

```sieve
if eval "expression_here" {
# Actions performed when the expression evaluates to true
}
```

Every name in the expression has to resolve to a variable, to a variable assigned earlier in the script, or to a function; an unknown name is a compile-time error. For example, rejecting a message whose body is mostly links:

 表達式中的每個名稱都必須解析為一個變數 、腳本中先前已賦值的變數或一個函數 ；未知名稱會導致編譯時錯誤。例如，拒絕一則正文主要由連結組成的訊息：

```sieve
require ["variables", "vnd.stalwart.expressions", "reject"];

let "words" "count(tokenize(body.to_text, 'words'))";
let "urls"  "count(tokenize(body.to_text, 'url_strict'))";

if eval "words > 0 && (urls * 100) / words > 25" {
    reject "Your message is mostly links.";
    stop;
}
```

 常見的模式是使用`let`計算幾個中間值，然後使用`if eval`對這些中間值進行分支：

## Using the `while` instruction｜使用`while`指令

 The `while` instruction, available only from the trusted interpreter, executes a block of code repeatedly while a given condition is true. The `vnd.stalwart.while` extension must be declared in the script’s `require` statement. The expression must eventually evaluate to false to avoid infinite loops; the `maxCpuCycles` limit on the interpreter provides a final safety net.

`while` 指令僅可從可信任解釋器 取得，在給定條件為真時重複執行程式碼區塊。 `vnd.stalwart.while` 擴充功能必須在腳本的 `require` 語句中宣告。此表達式最終必須計算為 false 以避免無限循環；對口譯員的`maxCpuCycles`限制提供了最終的安全網。

```sieve
let "i" "10";
while "i > 0" {
    addheader :last "X-Header-${i}" "Counter is ${i}";
    let "i" "i - 1";
}
```

 A `while` loop can be terminated by the `break` instruction, which exits the loop and resumes execution after it:

`while`迴圈可以透過`break`指令終止，指令會退出迴圈並恢復執行：

```sieve

    let "i" "i - 1";
    if eval "i == 0" {
        break;
    }
    addheader :last "X-Header-${i}" "Counter is ${i}";
}
```
