# Log file｜記錄檔

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[telemetry｜遙測\\\]\\\(&lt;000 目錄.md#c-76&gt;\\\) › \\\[tracing｜追蹤\\\]\\\(&lt;000 目錄.md#c-78&gt;\\\)

Log-file output writes entries to a text file on disk. The file can be rotated at a fixed frequency so that long-running installations do not accumulate a single unbounded log.

 日誌檔案輸出會將日誌條目寫入磁碟上的一個文字檔案。此檔案可以以固定頻率輪換，以避免長時間運行的程式累積單一無限大的日誌檔案。

 Log-file output is represented by the `Log` variant of the Tracer object \(found in the WebUI under Settings › Telemetry › Tracers\). Alongside the common tracer fields \(enable, level, lossy, events, eventsPolicy\), the variant carries:

 日誌檔案輸出由 Tracer物件的`Log`變體表示（可在 WebUI 的「設定」&gt;「遙測」&gt;「追蹤器」中找到）。除了常見的追蹤器欄位`events` enable , \[ `level` \([https://stalw.art/docs/ref/object/tracer#lossy](https://stalw.art/docs/ref/object/tracer#lossy)\) \([https://stalw.art/docs/ref/object/tracer#level](https://stalw.art/docs/ref/object/tracer#level)\) lossy , \[ `eventsPolicy` \([https://stalw.art/docs/ref/object/tracer#eventspolicy](https://stalw.art/docs/ref/object/tracer#eventspolicy)\) ）之外，該變體還包含：

- path: directory in which the log files are written. Required.
path : 日誌檔案的寫入目錄。必填。
- prefix: filename prefix for each log file. Default `"stalwart"`.
prefix : 每個日誌檔案的檔案名稱前綴。預設值為`"stalwart"` 。
- rotate: rotation frequency. One of `daily`, `hourly`, `minutely`, or `never`. Default `daily`.
rotate : 旋轉頻率。取值為`daily`, `hourly`, `minutely`或`never`之一。預設值為`daily` 。
- ansi: whether ANSI escape sequences are used to colour the output. Default `true`.
ansi : 是否使用ANSI轉義序列為輸出著色。預設值為`true` 。
- multiline: whether each entry spans multiple lines. Default `false`.
multiline : 每個條目是否跨越多行。預設值為`false` 。
For example:
 例如：

```json
{
  "@type": "Log",
  "path": "/opt/stalwart/logs",
  "prefix": "stalwart.log",
  "rotate": "daily",
  "ansi": true,
  "multiline": false,
  "enable": true,
  "level": "info"
}
```
