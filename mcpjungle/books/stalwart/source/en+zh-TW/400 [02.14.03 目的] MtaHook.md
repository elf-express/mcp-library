# MtaHook

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines an MTA hook endpoint for message processing.

 定義用於訊息處理的MTA鉤子端點。

 This object can be configured from the WebUI under Settings › MTA › Filters › MTA Hooks

 可以透過 WebUI下的「設定」› MTA › “過濾器”› MTA鉤子”來設定此物件。

## Fields｜田野

##### `allowInvalidCerts`

> Type: \\\`Boolean\\\` · default: \\\`false\\\`

類型： \`Boolean\` · 預設值： \`false\`

 Whether Stalwart should connect to a hook server that has an invalid TLS certificate

 Stalwart 是否應該連接到具有無效TLS憑證的鉤子伺服器

##### `enable`

> Type: \\\[\\\`Expression\\\`\\\]\\\(#expression\\\) · default: \\\`{"else":"true"}\\\`

類型：\[\`Expression\`\]\(#expression\) · 預設值： \`{"else":"true"}\`

 Expression that determines whether to enable this hook

 決定是否啟用此鉤子的表達式

 Available variables: \[\`MtaRcptToVariable\`\]\(&lt;331 \[02.14.02.02 多變的\] MtaRcptToVariable.md&gt;\).

 可用變數：\[\`MtaRcptToVariable\`\]\(&lt;331 \[02.14.02.02 多變的\] MtaRcptToVariable.md&gt;\) 。

##### `maxResponseSize`

> Type: \\\`Size\\\` · default: \\\`52428800\\\`

類型： \`Size\` · 預設值： \`52428800\`

 Maximum size, in bytes, of a response that Stalwart will accept from this MTA Hook server

 Stalwart 可接受的來自此MTA Hook 伺服器的回應的最大大小（以位元組為單位）

##### `tempFailOnError`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Whether to respond with a temporary failure \(typically a 4xx SMTP status code\) when Stalwart encounters an error while communicating with this MTA Hook server

 當 Stalwart 與此MTA Hook 伺服器通訊時遇到錯誤，是否回應臨時故障（通常為 4xx SMTP狀態碼）

##### `stages`

> Type: \\\`Set&amp;lt;\\\`\\\[\\\`MtaStage\\\`\\\]\\\(#mtastage\\\)\\\`&amp;gt;\\\` · default: \\\`{"data":true}\\\`

類型： \`Set&amp;lt;\` \[ \`MtaStage\` \]\(#mtastage\)\`&amp;gt;\` · 預設值： \`{"data":true}\`

 Which SMTP stages to run this hook on

 要在哪些SMTP階段運行此鉤子

##### `timeout`

> Type: \\\`Duration\\\` · default: \\\`30000\\\`

類型： \`Duration\` · 預設值： \`30000\`

 Maximum amount of time that Stalwart will wait for a response from this hook server

 Stalwart 等待此鉤子伺服器回應的最長時間

##### `url`

> Type: \\\`Uri\\\` · required

類型： \`Uri\` · 必填

 URL of the hook endpoint

 鉤端的URL

##### `httpAuth`

> Type: \\\[\\\`HttpAuth\\\`\\\]\\\(#httpauth\\\) · required

類型：\[\`HttpAuth\`\]\(#httpauth\) · 必填

 The type of HTTP authentication to use

 要使用的HTTP身份驗證類型

##### `httpHeaders`

> Type: \\\`Map<string, string="">\\\`

類型： \`Map&amp;lt;string, string=""&amp;gt;\`

 Additional headers to include in HTTP requests

 HTTP請求中要包含的其他標頭

## JMAP API

 The MtaHook object is available via the `urn:stalwart:jmap` capability.

 MtaHook 物件可透過`urn:stalwart:jmap`功能取得。

### `x:MtaHook/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節定義。

 This method requires the `sysMtaHookGet` permission.

 此方法需要`sysMtaHookGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:MtaHook/get",
          {
            "ids": [
              "id1"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:MtaHook/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節定義。

 Supports create, update, and destroy operations in a single call.

 支援在一次呼叫中執行建立、更新和銷毀操作。

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get MtaHook id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create MtaHook \
  --field url=https://example.com \
  --field 'httpAuth={"@type":"Unauthenticated"}' \
  --field 'httpHeaders={}'
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query MtaHook
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update MtaHook id1 --field allowInvalidCerts=false
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete MtaHook --ids id1
```

### HttpAuth

 Defines the HTTP authentication method to use for HTTP requests.

 定義用於HTTP請求的HTTP身份驗證方法。

- **`Unauthenticated`**: Anonymous. No additional fields.
**`Unauthenticated`**：匿名。無其他字段。
- **`Basic`**: Basic Authentication. Carries the fields of [HttpAuthBasic](#httpauthbasic).
**`Basic`**：基本驗證。包含 [HttpAuthBasic](#httpauthbasic)字段。
- **`Bearer`**: Bearer Token. Carries the fields of [HttpAuthBearer](#httpauthbearer).
**`Bearer`**: 持有者令牌。攜帶 [HttpAuthBearer](#httpauthbearer)的場。
#### HttpAuthBasic
