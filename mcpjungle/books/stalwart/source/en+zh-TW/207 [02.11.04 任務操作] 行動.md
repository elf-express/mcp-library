# Actions｜行動

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[management｜管理\\\]\\\(&lt;000 目錄.md#c-31&gt;\\\) › \\\[tasks actions｜任務操作\\\]\\\(&lt;000 目錄.md#c-35&gt;\\\)

An Action is a server management operation triggered on demand. Unlike a scheduled Task, an Action runs immediately in response to an administrator request: reloading configuration, flushing caches, pausing the outbound queue, running a troubleshooting probe, or classifying a message through the spam filter. Each invocation is represented as an Action object \(found in the WebUI under Management › Actions\) of one of the variants described below.

 操作是按需觸發的伺服器管理操作。與排程任務不同\([https://stalw.art/docs/management/tasks-actions/tasks\)操作會回應管理員要求立即執行，例如重新載入設定、清除快取、暫停出站佇列、執行故障排除偵測或透過垃圾郵件過濾器對郵件進行分類。每次呼叫都以一個\(https://stalw.art/docs/ref/object/action\)物件（可在](https://stalw.art/docs/management/tasks-actions/tasks%2529%2525E6%252593%25258D%2525E4%2525BD%25259C%2525E6%25259C%252583%2525E5%25259B%25259E%2525E6%252587%252589%2525E7%2525AE%2525A1%2525E7%252590%252586%2525E5%252593%2525A1%2525E8%2525A6%252581%2525E6%2525B1%252582%2525E7%2525AB%25258B%2525E5%25258D%2525B3%2525E5%25259F%2525B7%2525E8%2525A1%25258C%2525EF%2525BC%25258C%2525E4%2525BE%25258B%2525E5%2525A6%252582%2525E9%252587%25258D%2525E6%252596%2525B0%2525E8%2525BC%252589%2525E5%252585%2525A5%2525E8%2525A8%2525AD%2525E5%2525AE%25259A%2525E3%252580%252581%2525E6%2525B8%252585%2525E9%252599%2525A4%2525E5%2525BF%2525AB%2525E5%25258F%252596%2525E3%252580%252581%2525E6%25259A%2525AB%2525E5%252581%25259C%2525E5%252587%2525BA%2525E7%2525AB%252599%2525E4%2525BD%252587%2525E5%252588%252597%2525E3%252580%252581%2525E5%25259F%2525B7%2525E8%2525A1%25258C%2525E6%252595%252585%2525E9%25259A%25259C%2525E6%25258E%252592%2525E9%252599%2525A4%2525E5%252581%2525B5%2525E6%2525B8%2525AC%2525E6%252588%252596%2525E9%252580%25258F%2525E9%252581%25258E%2525E5%25259E%252583%2525E5%25259C%2525BE%2525E9%252583%2525B5%2525E4%2525BB%2525B6%2525E9%252581%25258E%2525E6%2525BF%2525BE%2525E5%252599%2525A8%2525E5%2525B0%25258D%2525E9%252583%2525B5%2525E4%2525BB%2525B6%2525E9%252580%2525B2%2525E8%2525A1%25258C%2525E5%252588%252586%2525E9%2525A1%25259E%2525E3%252580%252582%2525E6%2525AF%25258F%2525E6%2525AC%2525A1%2525E5%252591%2525BC%2525E5%25258F%2525AB%2525E9%252583%2525BD%2525E4%2525BB%2525A5%2525E4%2525B8%252580%2525E5%252580%25258B%2528https://stalw.art/docs/ref/object/action%2529%2525E7%252589%2525A9%2525E4%2525BB%2525B6%2525EF%2525BC%252588%2525E5%25258F%2525AF%2525E5%25259C%2525A8) WebUI 的「管理」&gt;「操作」下找到）的形式表示，該物件具有以下描述的幾種變體之一。

 Actions can be created from the WebUI, through the CLI using `stalwart-cli create action/<variant-name>`, or over the JMAP API through the `x:Action/set` method on the Action object. The server records each Action so that results, such as the spam classification score or a DMARC troubleshooting report, can be retrieved afterwards with `x:Action/get` or `stalwart-cli get action <id>`.

 可以透過 WebUI建立操作，也可以透過 CLI使用`stalwart-cli create action/<variant-name>`建立操作，或透過 Action對像上的`x:Action/set`方法，經由JMAP API 。伺服器會記錄每個操作，以便之後可以使用`x:Action/get`或`stalwart-cli get action <id>`檢索結果，例如垃圾郵件分類分數或DMARC故障排除報告。

## Variants｜變體

 Variants that require input fields, such as a message body or a remote IP, carry those fields alongside the variant identifier; the full schema for each is on the reference page.

 需要輸入欄位的變體（例如訊息正文或遠端IP ）會將這些欄位與變體標識符一起攜帶；每個變體的完整架構都在參考頁上。

### Reload settings｜重新加載設定

 The `ReloadSettings` variant rereads the server settings from the data store without restarting the process. No input fields are required.

`ReloadSettings`變體無需重新啟動進程即可從資料儲存重新讀取伺服器設定。無需輸入任何欄位。

### Reload TLS certificates｜重新加載TLS證書

 The `ReloadTlsCertificates` variant reloads TLS certificates from disk or from the configured ACME store so that renewals take effect without a restart. No input fields are required.

`ReloadTlsCertificates`變體從磁碟或已配置的ACME儲存重新載入TLS證書，以便續訂無需重新啟動即可生效。無需輸入任何欄位。

### Reload lookup stores｜重新載入查找庫

 The `ReloadLookupStores` variant refreshes the lookup stores backing access lists, blocklists, and similar in-memory datasets. No input fields are required.

`ReloadLookupStores`變體刷新用於儲存存取清單、阻止清單和類似記憶體資料集的查找表。無需輸入任何欄位。

### Reload blocked IPs｜重新載入被屏蔽的IP位址

 The `ReloadBlockedIps` variant reloads the blocked IP list applied by the inbound filters. No input fields are required.

`ReloadBlockedIps`變體重新載入入站過濾器應用的已阻止的IP清單。無需輸入任何欄位。

### Update applications｜更新應用程式

 The `UpdateApps` variant installs pending updates for the hosted web Applications, such as the WebUI bundle. No input fields are required. Spam-filter rule updates are handled separately through the asynchronous `SpamFilterMaintenance` variant of Task.

`UpdateApps`變體安裝託管的 Web 應用程式的待處理更新，例如 WebUI 套件。無需輸入欄位。垃圾郵件過濾器規則更新透過 任務的非同步`SpamFilterMaintenance`變體單獨處理。

### Troubleshoot DMARC｜故障排除DMARC

 The `TroubleshootDmarc` variant runs the same SPF, DKIM, ARC, and DMARC checks that the server applies to an incoming message. The caller supplies the remoteIp, the ehloDomain, the mailFrom address, the spfEhloDomain and spfMailFromDomain used for the SPF checks, and an optional message body. The server populates the per-check results \(SPF, reverse DNS, DKIM, ARC, DMARC\), the overall DKIM and DMARC pass flags, the applied dmarcPolicy, and the elapsed time.

`TroubleshootDmarc`變體運行與伺服器對傳入訊息應用的相同的SPF, DKIM, ARC和DMARC檢查。呼叫者提供 remoteIp 、ehloDomain 、 `mailFrom` SPF \([https://stalw.art/docs/ref/object/action#mailfrom](https://stalw.art/docs/ref/object/action#mailfrom)\) `spfEhloDomain`地址、用於\([https://stalw.art/docs/ref/object/action#spfehlodomain](https://stalw.art/docs/ref/object/action#spfehlodomain)\) `spfMailFromDomain` \]\([https://stalw.art/docs/ref/object/action#spfmailfromdomain](https://stalw.art/docs/ref/object/action#spfmailfromdomain)\) ，以及可選的 message正文。伺服器填入每次檢查的結果（ SPF ，反向DNS, DKIM, ARC, DMARC ），整體DKIM和DMARC通過標誌，應用的dmarcPolicy ，以及\[ `elapsed` \([https://stalw.art/docs/ref/object/action#elapsed](https://stalw.art/docs/ref/object/action#elapsed)\) 5

### Classify spam｜將垃圾郵件分類

 The `ClassifySpam` variant submits a raw message to the spam filter and returns the resulting score, tags, and overall classification. The caller supplies the raw message together with the envelope context: remoteIp, ehloDomain, optional authenticatedAs identity, isTls flag, envFrom address with optional envFromParameters, and the list of envRcptTo recipients. The server populates the numeric score, the map of contributing tags, and the final result: spam, ham, reject, or discard.

`ClassifySpam`變體將原始訊息提交給垃圾郵件過濾器，並傳回結果分數、標籤和總體分類。呼叫者提供原始 message以及信封上下文：remoteIp , ehloDomain , 可選的 authenticatedAs , 可選的 isTls標誌，envFrom地址（可選）envFromParameters , 以及 envRcptTo收件人清單。伺服器填入數字 score 、貢獻映射 tags與最終 result ：垃圾郵件、正常郵件、拒絕郵件或丟棄郵件。

### Invalidate caches｜使緩存失效

 The `InvalidateCaches` variant clears all in-memory caches. No input fields are required.

`InvalidateCaches`變體清除所有記憶體快取。無需輸入任何欄位。

### Invalidate negative caches｜使否定緩存失效

 The `InvalidateNegativeCaches` variant clears only negative cache entries, such as failed DNS lookups or missing-record results, leaving positive cache entries in place. No input fields are required.

`InvalidateNegativeCaches`變體僅清除否定快取條目，例如失敗的DNS查找或缺少記錄的結果，而保留肯定快取條目。無需輸入任何欄位。

### Pause the outbound queue｜暫停出站隊列

 The `PauseMtaQueue` variant pauses outbound MTA queue processing. Messages continue to accumulate but delivery attempts stop until resumed. No input fields are required.

`PauseMtaQueue`變體暫停出站MTA隊列的處理。訊息會繼續累積，但投遞嘗試會停止，直到恢復為止。無需輸入任何欄位。

### Resume the outbound queue｜恢復出站隊列

 The `ResumeMtaQueue` variant resumes outbound MTA queue processing after a pause. No input fields are required.

`ResumeMtaQueue`變體在暫停後恢復出站MTA隊列的處理。無需輸入任何欄位。

## Permissions｜權限

 Creating, reading, querying, and destroying Actions are gated by the `sysActionCreate`, `sysActionGet`, `sysActionQuery`, and `sysActionDestroy` permissions respectively. Administrators granted these permissions can invoke any variant; finer-grained restrictions are expressed through the standard permission model.

 建立、讀取、查詢和銷毀操作分別受`sysActionCreate`, `sysActionGet`, `sysActionQuery`和`sysActionDestroy`權限的限制。擁有這些權限的管理員可以呼叫任何變體；更細粒度的限制則透過標準權限模型來實現。
