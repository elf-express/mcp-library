# Roles｜角色

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[auth｜認證\\\]\\\(&lt;000 目錄.md#c-3&gt;\\\) › \\\[authorization｜授權\\\]\\\(&lt;000 目錄.md#c-5&gt;\\\)

Roles group permissions so that access can be managed across individuals, groups, and tenants without assigning every permission individually. Each role is represented by a Role object \(found in the WebUI under Management › Directory › Roles\) and can reference other roles, producing a hierarchical model in which a parent role inherits the permissions of its subroles.

 角色群組 權限以便跨個人、群組和租用戶管理存取權限，而無需單獨分配每個權限。每個角色都由一個 角色物件表示（可在 WebUI 的「管理」&gt;「目錄」&gt;「角色」下找到），並且可以引用其他角色，從而形成一個層級模型，其中父角色繼承其子角色的權限。

 A Role object carries the following fields:

 Role 物件包含以下欄位：

- description: a human-readable description of the role’s purpose. This also serves as the role’s display label in the WebUI.
description : 角色用途的易讀描述。同時，它也作為角色在 WebUI 中的顯示標籤。
- memberTenantId: the tenant that owns the role, used in multi-tenant deployments to scope roles to a specific tenant.
memberTenantId : 擁有該角色的租戶，用於多租戶部署中，將角色限定於特定租戶。
- roleIds: a list of roles this role extends. Permissions from the listed roles are inherited by this role.
roleIds : 此角色繼承的角色清單。此角色將繼承所列角色的權限。
- enabledPermissions: permissions explicitly granted by the role.
enabledPermissions : 角色明確授予的權限。
- disabledPermissions: permissions explicitly denied by the role. Disabled permissions take precedence over inherited permissions.
disabledPermissions ：角色明確拒絕的權限。已停用的權限優先於繼承的權限。
The role’s display label in listings is drawn from description; there is no separate `name` field. Membership is not stored on the Role object itself, it is tracked on the principals that reference the role, through the `roles` field on Account \(including its `Group` variant\) and on Tenant.
 角色在清單中的顯示標籤取自 description ；沒有單獨的`name`欄位。成員資格不會儲存在角色物件本身，而是透過 \[Account\]`roles` （包括其`Group`變體）和 Tenant上的\([https://stalw.art/docs/ref/object/account\)字段追蹤引用該角色的主體。](https://stalw.art/docs/ref/object/account%2529%2525E5%2525AD%252597%2525E6%2525AE%2525B5%2525E8%2525BF%2525BD%2525E8%2525B9%2525A4%2525E5%2525BC%252595%2525E7%252594%2525A8%2525E8%2525A9%2525B2%2525E8%2525A7%252592%2525E8%252589%2525B2%2525E7%25259A%252584%2525E4%2525B8%2525BB%2525E9%2525AB%252594%2525E3%252580%252582)

 Assigning a role to an account is done from the target principal. On an Account object \(found in the WebUI under Management › Directory › Groups, Management › Directory › Accounts\), the roles field selects either a built-in role or a `Custom` role set that references one or more Role ids. Groups and tenants expose their own `roles` field of the same shape.

 為帳戶指派角色是在目標主體上完成的。在帳戶物件（位於 WebUI 的「管理」&gt;「目錄」&gt;「群組」或「管理」&gt;「目錄」&gt;「帳戶」下）中，roles欄位用於選擇內建角色或引用一個或多個角色 ID 的`Custom`角色集。群組和租戶也公開了它們自己相同格式的`roles`字段。

## Built-in Roles｜內建角色

 Stalwart provides three built-in roles for common scenarios. The Account object references them through the `UserRoles` variants `User` and `Admin`, and tenant-level administration is covered by a dedicated role set.

 Stalwart 為常見場景提供了三個內建角色。 Account 物件透過`UserRoles`變體`User`和`Admin`引用這些角色，而租戶級管理則由專門的角色集負責。

- **user**: grants access to the regular services offered by the server, such as sending and receiving email and accessing mailboxes. It is intended for standard end-user accounts.
**使用者**：授予對伺服器提供的常規服務的存取權限，例如發送和接收電子郵件以及存取郵箱。它適用於標準最終用戶帳戶。
- **admin**: grants every permission defined by the server, including configuration and principal management. Intended for system administrators.
**admin**：授予伺服器定義的所有權限，包括設定和主體管理。專為系統管理員設計。
- **tenant-admin**: grants the administrative permissions required to manage users, groups, and settings within a single tenant or domain, without exposing global configuration changes.
**租用戶管理員**：授予管理單一租用戶或網域​​內的使用者、群組和設定所需的管理權限，而不會公開全域設定變更。
Default roles automatically assigned to new accounts, groups, tenants, and administrators are configured on the Authentication singleton \(found in the WebUI under Settings › Authentication › General\) through defaultUserRoleIds, defaultGroupRoleIds, defaultTenantRoleIds, and defaultAdminRoleIds.
 預設角色會自動指派給新帳戶、群組、租用戶和管理員，這些角色在 驗證單例（在 WebUI 的「設定 › 驗證 › 常規」下找到）到 defaultUserRoleIds 、 defaultGroupRoleIds \([https://stalw.art/docs/ref/object/authentication#defaulttenantroleids\\](https://stalw.art/docs/ref/object/authentication#defaulttenantroleids%255C)\) \([https://stalw.art/docs/ref/object/authentication#defaultgrouproleids\\](https://stalw.art/docs/ref/object/authentication#defaultgrouproleids%255C)\) defaultTenantRoleIds defaultAdminRoleIds進行配置。
