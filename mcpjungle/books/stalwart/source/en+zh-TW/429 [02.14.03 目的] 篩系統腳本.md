# SieveSystemScript｜篩系統腳本

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines a system Sieve script executed by the server.

 定義伺服器執行的系統 Sieve 腳本。

 This object can be configured from the WebUI under Settings › Sieve › System Scripts

 可以透過 WebUI下的「設定」›「Sieve」›「系統腳本」來設定此物件。

## Fields｜田野

##### `name`

> Type: \\\`String\\\` · required

類型： \`String\` · 必填

 Name of the script

 腳本名稱

##### `description`

> Type: \\\`String?\\\`

類型： \`String?\`

 Description of the script

 腳本描述

##### `isActive`

> Type: \\\`Boolean\\\` · default: \\\`false\\\`

類型： \`Boolean\` · 預設值： \`false\`

 Whether the script is active

 腳本是否處於活動狀態

##### `contents`

> Type: \\\`Text\\\` · required

類型： \`Text\` · 必填

 Content of the script

 腳本內容

## JMAP API

 The SieveSystemScript object is available via the `urn:stalwart:jmap` capability.

 可以透過`urn:stalwart:jmap`功能存取 SieveSystemScript 物件。

### `x:SieveSystemScript/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是 [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)節5.1中定義。

 This method requires the `sysSieveSystemScriptGet` permission.

 此方法需要`sysSieveSystemScriptGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:SieveSystemScript/get",
          {
            "ids": [
              "id1"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:SieveSystemScript/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節定義。

 Supports create, update, and destroy operations in a single call.

 支援在一次呼叫中執行建立、更新和銷毀操作。

#### Create｜創造

 This operation requires the `sysSieveSystemScriptCreate` permission.

 此操作需要`sysSieveSystemScriptCreate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:SieveSystemScript/set",
          {
            "create": {
              "new1": {
                "contents": "Example",
                "name": "Example"
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:SieveSystemScript/query`

 This is a standard [Foo/query](https://www.rfc-editor.org/rfc/rfc8620#section-5.5) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.5), Section 5.5.

 這是 [Foo/query](https://www.rfc-editor.org/rfc/rfc8620#section-5.5)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.5)節5.5中定義。

 This method requires the `sysSieveSystemScriptQuery` permission.

 此方法需要`sysSieveSystemScriptQuery` 權限 。


## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get SieveSystemScript id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create SieveSystemScript \
  --field name=Example \
  --field contents=Example
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query SieveSystemScript
stalwart-cli query SieveSystemScript --where name=example
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update SieveSystemScript id1 --field name='updated value'
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete SieveSystemScript --ids id1
```
