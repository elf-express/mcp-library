# MtaConnectionStrategy｜Mta連接策略

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines a connection strategy for outbound message delivery.

 定義出站訊息傳遞的連線策略。

 This object can be configured from the WebUI under Settings › MTA › Outbound › Connection Strategies

 此物件可在 WebUI的「設定」› MTA › 出站 › 連線策略 中進行設定。

## Fields｜田野

##### `name`

> Type: \\\`String\\\` · read-only

類型： \`String\` · 只讀

 Short identifier for the strategy

 策略的簡短標識符

##### `description`

> Type: \\\`String?\\\`

類型： \`String?\`

 Short description of the connection strategy

 連結策略簡述

##### `ehloHostname`

> Type: \\\`HostName?\\\`

類型： \`HostName?\`

 Overrides the EHLO hostname that will be used when connecting using this strategy

 覆寫使用此政策連線時將使用的EHLO主機名

##### `sourceIps`

> Type: \\\`List&amp;lt;\\\`\\\[\\\`MtaConnectionIpHost\\\`\\\]\\\(#mtaconnectioniphost\\\)\\\`&amp;gt;\\\`

模式標本： \`List&amp;lt;\` \[ \`MtaConnectionIpHost\` \]\(#mtaconnectioniphost\)\`&amp;gt;\`

 List of local IPv4 and IPv6 addresses to use when delivering emails to remote SMTP servers

 向遠端SMTP伺服器發送電子郵件時要使用的本機 IPv4 和 IPv6 位址列表

##### `connectTimeout`

> Type: \\\`Duration\\\` · default: \\\`300000\\\`

類型： \`Duration\` · 預設值： \`300000\`

 Maximum time to wait for the connection to be established

 連線建立的最長等待時間

##### `dataTimeout`

> Type: \\\`Duration\\\` · default: \\\`600000\\\`

類型： \`Duration\` · 預設值： \`600000\`

 Maximum time to wait for the DATA command response

 等待DATA指令回應的最長時間

##### `ehloTimeout`

> Type: \\\`Duration\\\` · default: \\\`300000\\\`

類型： \`Duration\` · 預設值： \`300000\`

 Maximum time to wait for the EHLO command response

 等待EHLO指令回應的最長時間

##### `greetingTimeout`

> Type: \\\`Duration\\\` · default: \\\`300000\\\`

類型： \`Duration\` · 預設值： \`300000\`

 Maximum time to wait for the SMTP greeting message

 等待SMTP問候訊息的最長時間

##### `mailFromTimeout`

> Type: \\\`Duration\\\` · default: \\\`300000\\\`

類型： \`Duration\` · 預設值： \`300000\`

 Maximum time to wait for the MAIL-FROM command response

 等待MAIL-FROM指令回應的最長時間

##### `rcptToTimeout`

> Type: \\\`Duration\\\` · default: \\\`300000\\\`

類型： \`Duration\` · 預設值： \`300000\`

 Maximum time to wait for the RCPT-TO command response

 等待RCPT-TO指令回應的最長時間
