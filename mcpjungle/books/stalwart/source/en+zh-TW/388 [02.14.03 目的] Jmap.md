# Jmap

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Configures JMAP protocol limits for requests, uploads, and push notifications.

 配置JMAP協定對請求、上傳和推播通知的限制。

 This object can be configured from the WebUI under Settings › Network › JMAP › Limits Settings › Network › JMAP › Push Settings › Network › JMAP › WebSocket

 此物件可在 WebUI的「設定」&gt;「網路」&gt; JMAP &gt;「限制設定」&gt;「網路」&gt; JMAP &gt;「推送設定」&gt;「網路」&gt; JMAP &gt;「WebSocket」中進行設定。

## JMAP API

 The Jmap singleton is available via the `urn:stalwart:jmap` capability.

 Jmap 單例可透過`urn:stalwart:jmap`功能取得。

### `x:Jmap/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節中定義。

 For singletons, the `ids` argument should be the literal `singleton` \(or `null` to return the single instance\).

 對於單例， `ids`參數應該是字面值`singleton` （或`null`以傳回單一實例）。

 This method requires the `sysJmapGet` permission.

 此方法需要`sysJmapGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:Jmap/get",
          {
            "ids": [
              "singleton"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:Jmap/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節中定義。

 For singletons, only the `update` argument with id `singleton` is accepted; `create` and `destroy` arguments are rejected.

 對於單例，僅接受 id 為`singleton`的`update`參數；拒絕`create`和`destroy`參數。

 This method requires the `sysJmapUpdate` permission.

 此方法需要`sysJmapUpdate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:Jmap/set",
          {
            "update": {
              "singleton": {
                "webPushContact": "updated value"
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get Jmap
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update Jmap --field webPushContact='updated value'
```

### SecretTextOptional｜可選秘密文本

 An optional secret text value, or none.

 可選的秘密文字值，或不設定。

- **`None`**: No secret. No additional fields.
**`None`**：無秘密訊息。無其他字段。
- **`Text`**: Secret value. Carries the fields of [SecretTextValue](#secrettextvalue).
**`Text`**: 秘密值。包含 [SecretTextValue](#secrettextvalue)的欄位。
- **`EnvironmentVariable`**: Secret read from environment variable. Carries the fields of [SecretKeyEnvironmentVariable](#secretkeyenvironmentvariable).
**`EnvironmentVariable`**: 從環境變數讀取秘密值。包含 [SecretKeyEnvironmentVariable](#secretkeyenvironmentvariable)的欄位。
- **`File`**: Secret read from file. Carries the fields of [SecretKeyFile](#secretkeyfile).
**`File`**: 從文件中讀取秘密訊息。攜帶 [SecretKeyFile](#secretkeyfile)的字段。
