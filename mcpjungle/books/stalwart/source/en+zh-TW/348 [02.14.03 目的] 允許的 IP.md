# AllowedIp｜允許的 IP

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines an allowed IP address or network range.

 定義允許的IP位址或網路範圍。

 This object can be configured from the WebUI under Settings › Security › Allowed IPs

 此物件可在 WebUI的「設定」›「安全性」›「允許的 IP 位址」中進行設定。

## Fields｜田野

##### `address`

> Type: \\\`IpMask\\\` · read-only

類型： \`IpMask\` · 只讀

 The IP address or mask to allow

 IP位址或遮罩允許

##### `reason`

> Type: \\\`String?\\\`

類型： \`String?\`

 The reason for allowing this IP address

 允許此IP地址的原因

##### `createdAt`

> Type: \\\`UTCDateTime\\\` · read-only

類型： \`UTCDateTime\` · 只讀

 The date and time when this IP address was allowed

 此IP地址被允許的日期和時間

##### `expiresAt`

> Type: \\\`UTCDateTime?\\\`

類型： \`UTCDateTime?\`

 The date and time when this IP address allowance will expire

 此IP地址授權的失效日期和時間

## JMAP API

 The AllowedIp object is available via the `urn:stalwart:jmap` capability.

 AllowedIp 物件可透過`urn:stalwart:jmap`功能取得。

### `x:AllowedIp/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是 [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)節5.1中定義。

 This method requires the `sysAllowedIpGet` permission.

 此方法需要`sysAllowedIpGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \

      "methodCalls": [
        [
          "x:AllowedIp/get",
          {
            "ids": [

            ]

          "c1"
        ]
      ],
```

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get AllowedIp id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create AllowedIp
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query AllowedIp
stalwart-cli query AllowedIp --where address=example
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update AllowedIp id1 --field reason='updated value'
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete AllowedIp --ids id1
```
