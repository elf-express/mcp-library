# CalendarScheduling｜日曆安排

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Configures calendar scheduling, iTIP messaging, and HTTP RSVP settings.

 配置日曆安排、iTIP 訊息傳遞和HTTP RSVP設定。

 This object can be configured from the WebUI under Settings › Calendar & Contacts › Scheduling

 此物件可在 WebUI的「設定」&gt;「行事曆與聯絡人」&gt;「行程安排」中進行設定。

## Fields｜田野

##### `enable`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Enables the scheduling features for calendar events, allowing users to send and receive invitations

 啟用日曆事件的日程安排功能，允許使用者發送和接收邀請。

##### `httpRsvpEnable`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Enables the HTTP RSVP feature for calendar invitations, allowing users to respond via a web interface.

 啟用日曆邀請的HTTP RSVP功能，讓使用者透過網頁介面回覆。

##### `httpRsvpLinkExpiry`

> Type: \\\`Duration\\\` · default: \\\`7776000000\\\`

類型： \`Duration\` · 預設值： \`7776000000\`

 Sets the expiration duration for HTTP RSVP links, after which they will no longer be valid.

 設定HTTP RSVP連結的過期時間，過期後連結將不再有效。

##### `httpRsvpUrl`

> Type: \\\`Uri?\\\`

類型： \`Uri?\`

 Specifies a custom URL for the HTTP RSVP endpoint, where users can respond to calendar invitations.

 為HTTP RSVP端點指定自訂URL ，使用者可在該端點回覆日曆邀請。

##### `autoAddInvitations`

> Type: \\\`Boolean\\\` · default: \\\`false\\\`

類型： \`Boolean\` · 預設值： \`false\`

 Automatically adds incoming invitations to the user’s calendar.

 自動將收到的邀請加入到使用者的日曆中。

##### `itipMaxSize`

> Type: \\\`Size\\\` · default: \\\`524288\\\` · min: 100

類型： \`Size\` · 預設值： \`524288\` · 最小值：100

 Sets the maximum iCalendar object size for incoming iTIP messages.

 設定傳入的 iTIP 訊息的最大 iCalendar 物件大小。

##### `maxRecipients`

> Type: \\\`UnsignedInt\\\` · default: \\\`100\\\` · min: 1

類型： \`UnsignedInt\` · 預設值： \`100\` · 最小值：1

 Sets the maximum number of recipients for outbound iTIP messages.

 設定傳出 iTIP 訊息的最大收件人數量。

##### `emailTemplate`

> Type: \\\`Html?\\\` · \\\[enterprise\\\]\\\(&lt;466 \\\[02.15 伺服器\\\] 企業許可證.md&gt;\\\)

型號： \`Html?\` · \[企業版\]\(&lt;466 \[02.15 伺服器\] 企業許可證.md&gt;\)

 Specifies the HTML template used for rendering iMIP invitations.

 指定用於渲染 iMIP 邀請的HTML模板。

##### `httpRsvpTemplate`

> Type: \\\`Html?\\\` · \\\[enterprise\\\]\\\(&lt;466 \\\[02.15 伺服器\\\] 企業許可證.md&gt;\\\)

類型： \`Html?\` · \[企業\]\(&lt;466 \[02.15 伺服器\] 企業許可證.md&gt;\)

 Replaces the built-in HTTP RSVP page. The document is served verbatim and is responsible for calling the /api/calendar/rsvp endpoint itself.

 替換內建的HTTP RSVP頁面。該文檔將原樣提供，並負責呼叫/api/calendar/rsvp端點本身。

## JMAP API

 The CalendarScheduling singleton is available via the `urn:stalwart:jmap` capability.

 CalendarScheduling 單例可透過`urn:stalwart:jmap`功能取得。

### `x:CalendarScheduling/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是[Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) ，第5.1節中定義。

 For singletons, the `ids` argument should be the literal `singleton` \(or `null` to return the single instance\).

 對於單例， `ids`參數應該是字面值`singleton` （或`null`以傳回單一實例）。

 This method requires the `sysCalendarSchedulingGet` permission.

 此方法需要`sysCalendarSchedulingGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:CalendarScheduling/get",
          {
            "ids": [
              "singleton"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:CalendarScheduling/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是 [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)節5.3中定義。

 For singletons, only the `update` argument with id `singleton` is accepted; `create` and `destroy` arguments are rejected.

 對於單例，僅接受 id 為`singleton` `update`參數；拒絕`create`和`destroy`參數。

 This method requires the `sysCalendarSchedulingUpdate` permission.

 此方法需要`sysCalendarSchedulingUpdate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:CalendarScheduling/set",
          {
            "update": {
              "singleton": {
                "enable": true
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get CalendarScheduling
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update CalendarScheduling --field enable=true
```
