# Account｜帳戶

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines a user or group account for authentication and email access.

 定義用於身份驗證和電子郵件存取的使用者或群組帳戶。

 This object can be configured from the WebUI under Management › Directory › Groups Management › Directory › Accounts

 可以透過 WebUI在「管理」›「目錄」›「群組管理」›「目錄」›「帳號」下設定此物件。

## Fields｜田野

 Account is a **multi-variant** object: each instance has an `@type` discriminator selecting one of the variants below, and each variant carries its own set of fields.

 Account 是一個**多變數**物件：每個實例都有一個`@type`鑑別器，用於選擇以下變數之一，並且每個變數都包含自己的一組欄位。

### `@type: "User"`

 User account

 使用者帳戶

##### `name`

> Type: \\\`EmailLocalPart\\\` · required

類型： \`EmailLocalPart\` · 必填

 Name of the account, typically an email address local part.

 帳戶名稱，通常是電子郵件地址的本地部分。

##### `domainId`

 此帳戶所屬網域的識別碼。它用於確定帳戶的電子郵件地址，格式為 name@domain。

 使用者帳號的電子郵件地址，格式為 name@domain。

##### CredentialPermissions｜憑證權限

 Permission assignment mode for a credential.

 憑證的權限分配模式。

- **`Inherit`**: Same permissions as account. No additional fields.
**`Inherit`**：權限與帳戶相同。無其他字段。
- **`Disable`**: Disable some permissions. Carries the fields of [CredentialPermissionsList](#credentialpermissionslist).
**`Disable`**: 停用某些權限。包含 [CredentialPermissionsList](#credentialpermissionslist)的欄位。
- **`Replace`**: Replace all permissions. Carries the fields of [CredentialPermissionsList](#credentialpermissionslist).
**`Replace`**: 替換所有權限。包含 [CredentialPermissionsList](#credentialpermissionslist)的欄位。
##### CredentialPermissionsList｜憑證權限列表

 要指派給憑證的權限清單。

### UserRoles｜使用者角色

 Role assignment for user accounts.

 使用者帳戶的角色分配。

- **`User`**: User role. No additional fields.
**`User`**：使用者角色。無其他字段。
- **`Admin`**: Administrator role. No additional fields.
**`Admin`**：管理員角色。無其他字段。
- **`Custom`**: Custom role. Carries the fields of [CustomRoles](#customroles).
**`Custom`**: 自訂角色。包含 [CustomRoles](#customroles)的欄位。
