# Protocol｜協定

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[http\\\]\\\(&lt;000 目錄.md#c-26&gt;\\\) › \\\[webdav｜WebDAV\\\]\\\(&lt;000 目錄.md#c-28&gt;\\\)

WebDAV behaviour is tuned through the WebDav singleton \(found in the WebUI under Settings › Network › WebDAV\). Two fields in particular control resource usage under heavy client activity: the maximum incoming request size and the maximum number of results returned in a single response.

 WebDAV 的行為可透過 WebDav單例進行調整（可在 WebUI 的「設定」&gt;「網路」&gt;「WebDAV」中找到）。其中有兩個欄位特別控制客戶端高負載活動下的資源使用：最大傳入請求大小和單一回應中傳回的最大結果數。

- requestMaxSize: the maximum XML size of a WebDAV request that the server will accept, in bytes. Default `26214400` \(25 MB\). This limit matters most for file uploads, calendar imports, and contact synchronisation, which tend to carry large payloads. Administrators can raise it to support larger transfers or lower it to reduce resource consumption.
requestMaxSize ：伺服器可接受的XML請求的最大大小（以位元組為單位）。 `26214400`值為 25 MB 。此限制對於文件上傳、日曆匯入和聯絡人同步尤其重要，因為這些操作通常會傳輸較大的有效負載。管理員可以提高此限制以支援更大的傳輸，或降低此限制以減少資源消耗。
- maxResults: the maximum number of items \(calendar events, contact entries, and similar\) that the server will include in a single WebDAV response. Default `2000`. Adjust this value to balance response size against network and memory efficiency during bulk sync operations.
maxResults ：伺服器在單一 WebDAV 回應中包含的最大項目數（日曆事件、聯絡人條目等）。預設值為`2000` 。調整此值可在批次同步操作期間平衡回應大小與網路和記憶體效率。
Example:
 例子：

```json
{
  "requestMaxSize": 26214400,
  "maxResults": 2000
}
```
