# Overview｜概述

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[spamfilter｜垃圾郵件過濾器\\\]\\\(&lt;000 目錄.md#c-69&gt;\\\)

Spam filtering identifies and segregates unsolicited or potentially harmful messages before they reach an inbox. Stalwart includes a built-in spam and phishing filter whose behaviour is defined by a set of customizable rules, tags, scores, and statistical classifiers. The bulk of the spam and phishing rules shipped with Stalwart are ported directly from RSpamd, with a small number derived from SpamAssassin. Combined with expressions, this provides comparable filtering depth to those systems while keeping the configuration inside the JMAP object model.

 垃圾郵件過濾功能可在垃圾郵件到達收件匣之前識別並隔離未經請求或潛在有害的郵件。 Stalwart 內建垃圾郵件和釣魚郵件過濾器，其行為由一組可自訂的規則、標籤、評分和統計分類器定義。 Stalwart 附帶的大部分垃圾郵件和釣魚郵件規則直接移植自 RSpamd，少量規則源自 SpamAssassin。結合 表達式 ，這在保持配置在JMAP物件模型內的同時，提供了與這些系統相當的過濾深度。

 Global behaviour is configured on the SpamSettings singleton \(found in the WebUI under Settings › Spam Filter › General\), which carries the master enable flag and the score thresholds described below.

 全域行為在 SpamSettings單例中配置（在 WebUI 的「設定 › 垃圾郵件過濾器 › 常規」下找到），它帶有主 enable標誌和下面描述的分數閾值。

## Tags and scores｜標籤和評分

 When a message arrives the filter analyses its content, headers, and sender attributes. Each facet of the analysis produces a tag that describes a specific characteristic or outcome. For example, a message composed entirely of HTML without a text part is tagged `MIME_HTML_ONLY`, while a message that passes DMARC is tagged `DMARC_POLICY_ALLOW`.

 當郵件到達時，過濾器會分析其內容、郵件頭和寄件者屬性。分析的每個方面都會產生一個標籤，用於描述特定的特徵或結果。例如，完全由HTML組成而沒有文字部分的訊息會被標記為`MIME_HTML_ONLY` ，而透過DMARC篩選的訊息會被標記為`DMARC_POLICY_ALLOW` 。

 Each tag contributes a score, which may be positive or negative. Positive scores indicate spam-like characteristics; negative scores indicate ham-like \(legitimate\) characteristics. The cumulative score across all tags is compared against the thresholds on SpamSettings to determine the final classification. The default spam threshold is 5.0; administrators can adjust it via scoreSpam.

 每個標籤都會貢獻一個分數，分數可以是正數也可以是負數。正數表示垃圾郵件的特徵；負數表示正常郵件的特徵。所有標籤的累積分數會與 SpamSettings 中的閾值進行比較，以確定最終分類。預設的垃圾郵件閾值是5.0 ；管理員可以透過 scoreSpam進行調整。

 Tag-to-score mappings, as well as special “discard” or “reject” actions per tag, are configured through the SpamTag object \(found in the WebUI under Settings › Spam Filter › Scores\). See Scores for details.

 標籤到分數的映射，以及每個標籤的特殊「丟棄」或「拒絕」操作，均透過 SpamTag物件進行配置（可在 WebUI 的「設定」&gt;「垃圾郵件過濾器」&gt;「分數」中找到）。有關詳細信息，請參閱 Scores 。

## Analysis outcomes｜分析結果

 By default the filter is conservative: no incoming message is rejected solely on the basis of its spam score. This can be changed by setting the scoreDiscard or scoreReject thresholds on SpamSettings, or by attaching a `Discard` or `Reject` variant of SpamTag to a specific tag.

 預設情況下，過濾器較為保守：不會僅根據垃圾郵件評分拒絕任何傳入郵件。可以透過設定 scoreDiscard 或 scoreReject 在垃圾郵件設定中設定閾值，或透過附加一個 `Discard` 或者 `Reject` SpamTag 的變體 到特定標籤。

 For messages that are neither discarded nor rejected, Stalwart adds the `X-Spam-Status` and `X-Spam-Result` headers so that end users can build their own filters on top of the filter’s output, for example using Sieve via ManageSieve or JMAP Sieve. The `X-Spam-Status` header reports `Yes` or `No` along with the final score. The `X-Spam-Result` header lists each tag that fired and its contribution.

 對於既不丟棄也不拒絕的訊息，Stalwart 增加 `X-Spam-Status` 和 `X-Spam-Result` 標頭，以便最終用戶可以在過濾器的輸出之上構建自己的過濾器，例如透過 ManageSieve 或 JMAP Sieve 使用 Sieve。 `X-Spam-Status` 標頭報告 `Yes` 或 `No` 以及最終得分。 `X-Spam-Result` 標頭列出了觸發的每個標籤及其貢獻。

 Example headers on a message classified as spam:

 垃圾郵件郵件的範例郵件頭：

```yaml
X-Spam-Result: DMARC_POLICY_ALLOW (-0.50),
  DKIM_ALLOW (-0.20),
  SPF_ALLOW (-0.20),
  ONCE_RECEIVED (0.10),
  RCVD_NO_TLS_LAST (0.10),
  MV_CASE (0.50),
  R_MISSING_CHARSET (0.50),
  URI_COUNT_ODD (0.50),
  CT_EXTRA_SEMI (1.00),
  MID_RHS_MATCH_FROM (1.00),
  RDNS_NONE (1.00),
  R_PARTS_DIFFER (1.00),
  RBL_SPAMHAUS_CSS (2.00),
  RBL_VIRUSFREE_BOTNET (2.00),
  RBL_BARRACUDA (4.00),
  ABUSE_SURBL (5.00),
  DBL_SPAM (6.50)
X-Spam-Status: Yes, score=13.45
```

Both `X-Spam-Status` and `X-Spam-Result` are added unconditionally under their fixed names.

`X-Spam-Status`和`X-Spam-Result`均依其固定名稱無條件添加。
