## JMAP API

 The Enterprise singleton is available via the `urn:stalwart:jmap` capability.

 企業單例可透過`urn:stalwart:jmap`功能取得。

### `x:Enterprise/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是 [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)節5.1中定義。

 For singletons, the `ids` argument should be the literal `singleton` \(or `null` to return the single instance\).

 對於單例， `ids`參數應該是字面值`singleton` （或`null`以傳回單一實例）。

 This method requires the `sysEnterpriseGet` permission.

 此方法需要`sysEnterpriseGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:Enterprise/get",
          {
            "ids": [
              "singleton"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:Enterprise/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節定義。

 For singletons, only the `update` argument with id `singleton` is accepted; `create` and `destroy` arguments are rejected.

 對於單例，僅接受 id 為`singleton` `update`參數；拒絕`create`和`destroy`參數。

 This method requires the `sysEnterpriseUpdate` permission.

 此方法需要`sysEnterpriseUpdate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:Enterprise/set",
          {
            "update": {
              "singleton": {
                "apiKey": {
                  "@type": "None"
                }
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get Enterprise
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update Enterprise --field apiKey='{"@type":"None"}'
```

## Nested types｜巢狀類型

### SecretKeyOptional｜可選密鑰

 An optional secret value, or none.

 可選的秘密值，或不含秘密值。

- **`None`**: No secret. No additional fields.
**`None`**：無秘密訊息。無其他字段。
- **`Value`**: Secret value. Carries the fields of [SecretKeyValue](#secretkeyvalue).
**`Value`**: 秘密值。包含 [SecretKeyValue](#secretkeyvalue)的欄位。
- **`EnvironmentVariable`**: Secret read from environment variable. Carries the fields of [SecretKeyEnvironmentVariable](#secretkeyenvironmentvariable).
**`EnvironmentVariable`**: 從環境變數中讀取秘密值。包含 [SecretKeyEnvironmentVariable](#secretkeyenvironmentvariable)的欄位。
- **`File`**: Secret read from file. Carries the fields of [SecretKeyFile](#secretkeyfile).
**`File`**: 從文件中讀取秘密訊息。攜帶 [SecretKeyFile](#secretkeyfile)的場。
#### SecretKeyValue｜密鑰值

 A secret value provided directly.

 直接提供一個秘密值。

 密碼或秘密值

 從環境變數中讀取的秘密值。

##### `variableName`

 Environment variable name to read the secret from

 要從中讀取密鑰的環境變數名稱

#### SecretKeyFile｜密鑰檔案

 A secret value read from a file.

 從文件中讀取的秘密值。

##### `filePath`

類型： \`String\` · 必填

 File path to read the secret from

 讀取密鑰的檔案路徑
