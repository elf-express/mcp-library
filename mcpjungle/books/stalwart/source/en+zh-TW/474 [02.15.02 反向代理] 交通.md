# Traefik｜交通

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[server｜伺服器\\\]\\\(&lt;000 目錄.md#c-62&gt;\\\) › \\\[reverse proxy｜反向代理\\\]\\\(&lt;000 目錄.md#c-64&gt;\\\)

[Traefik](https://traefik.io/) is a reverse proxy and load balancer designed for containerised deployments. It integrates with Docker and Kubernetes, discovers services automatically, and reloads its routing at runtime when services come or go.

[Traefik](https://traefik.io/)是一款專為容器化部署設計的反向代理與負載平衡器。它與 Docker 和 Kubernetes 集成，能夠自動發現服務，並在服務啟動或停止時重新載入其路由。

 Stalwart can sit behind Traefik for both HTTP and raw-TCP traffic. Traefik speaks the Proxy Protocol, so the original client IP and TLS status are carried through to Stalwart. Stalwart accepts the Proxy Protocol header when the source address is listed in proxyTrustedNetworks on the SystemSettings singleton \(found in the WebUI under Settings › Network › Services, Settings › Network › General\) or in overrideProxyTrustedNetworks on the matching NetworkListener.

 Stalwart 可以位於 Traefik 之後，處理HTTP和原始TCP流量。 Traefik 使用 代理協定 ，因此原始客戶端IP和TLS狀態會傳遞給 Stalwart。當來源位址列在 系統設定單例（可在 WebUI 的「設定」&gt;「網路」&gt;「服務」或「設定」&gt;「網路」&gt;「常規」中找到）的 proxyTrustedNetworks中，或列在符合\([https://stalw.art/docs/ref/object/network-listener#overrideproxytrustednetworks](https://stalw.art/docs/ref/object/network-listener#overrideproxytrustednetworks)\) \[ `overrideProxyTrustedNetworks` \([https://stalw.art/docs/ref/object/network-listener\)中時，Stalwart](https://stalw.art/docs/ref/object/network-listener%2529%2525E4%2525B8%2525AD%2525E6%252599%252582%2525EF%2525BC%25258CStalwart) 會接受代理協議標頭。

## Configuration｜配置

 The following example runs Traefik and Stalwart in Docker Compose, with Traefik terminating TLS for HTTP traffic and forwarding the mail ports with Proxy Protocol v2.

 以下範例在 Docker Compose 中執行 Traefik 和 Stalwart，其中 Traefik 終止TLS以處理HTTP流量，並使用代理協議 v2 轉送郵件連接埠。

### Traefik Compose

```yaml
services:
  traefik:
    image: traefik:v3.0
    container_name: traefik
    restart: always
    networks:
      proxy:
        ipv4_address: 172.19.0.2
    ports:
      - 80:80
      - 443:443
      - 25:25
      - 465:465
      - 993:993
    volumes:
      - /etc/localtime:/etc/localtime:ro
      - /etc/traefik:/etc/traefik
      - acme:/etc/certs
      - /var/run/docker.sock:/var/run/docker.sock:ro

  traefik-certs-dumper:
    image: ghcr.io/kereis/traefik-certs-dumper:latest
    container_name: traefik-certs-dumper
    restart: unless-stopped
    depends_on:
      - traefik
    volumes:
      - /etc/localtime:/etc/localtime:ro
      - acme:/traefik:ro
      - certs:/output

volumes:
  acme:
  certs:

networks:
  proxy:
```

### Stalwart Compose｜堅韌的構成

```yaml
services:
  mailserver:
    image: stalwartlabs/stalwart:latest
    container_name: mailserver
    restart: unless-stopped
    hostname: mail.example.com
    networks:
      proxy:
        ipv4_address: 172.19.0.5
    volumes:
      - /etc/localtime:/etc/localtime:ro
      - etc:/etc/stalwart
      - data:/var/lib/stalwart
      - certs:/data/certs:ro
    labels:
      - traefik.enable=true

      - traefik.http.routers.mailserver.rule=Host(`mail.example.com`) || Host(`autodiscover.example.com`) || Host(`autoconfig.example.com`) || Host(`mta-sts.example.com`)
      - traefik.http.routers.mailserver.entrypoints=https
      - traefik.http.routers.mailserver.service=mailserver
      - traefik.http.services.mailserver.loadbalancer.server.port=8080

      - traefik.tcp.routers.smtp.rule=HostSNI(`*`)
      - traefik.tcp.routers.smtp.entrypoints=smtp
      - traefik.tcp.routers.smtp.service=smtp
      - traefik.tcp.services.smtp.loadbalancer.server.port=25
      - traefik.tcp.services.smtp.loadbalancer.proxyProtocol.version=2

      - traefik.tcp.routers.jmap.rule=HostSNI(`*`)
      - traefik.tcp.routers.jmap.tls.passthrough=true
      - traefik.tcp.routers.jmap.entrypoints=https
      - traefik.tcp.routers.jmap.service=jmap
      - traefik.tcp.services.jmap.loadbalancer.server.port=443
      - traefik.tcp.services.jmap.loadbalancer.proxyProtocol.version=2

      - traefik.tcp.routers.smtps.rule=HostSNI(`*`)
      - traefik.tcp.routers.smtps.tls.passthrough=true
      - traefik.tcp.routers.smtps.entrypoints=smtps
      - traefik.tcp.routers.smtps.service=smtps
      - traefik.tcp.services.smtps.loadbalancer.server.port=465
      - traefik.tcp.services.smtps.loadbalancer.proxyProtocol.version=2

      - traefik.tcp.routers.imaps.rule=HostSNI(`*`)
      - traefik.tcp.routers.imaps.tls.passthrough=true
      - traefik.tcp.routers.imaps.entrypoints=imaps
      - traefik.tcp.routers.imaps.service=imaps
      - traefik.tcp.services.imaps.loadbalancer.server.port=993
      - traefik.tcp.services.imaps.loadbalancer.proxyProtocol.version=2

volumes:
  etc:
  data:
  certs:
    name: traefik_certs
    external: true

networks:
  proxy:
    name: traefik_proxy
    external: true
```

### Traefik Configuration｜Traefik 配置

 The configuration example below obtains Let’s Encrypt certificates using the DNS challenge on Cloudflare and enables the Proxy Protocol for the SMTP, SMTPS, and IMAPS entry points:

 以下設定範例使用 Cloudflare 上的DNS挑戰取得 Let's Encrypt 證書，並為SMTP, SMTPS和IMAPS入口點啟用代理協定：

```yaml
global:
  checkNewVersion: true
  sendAnonymousUsage: false

certificatesResolvers:
  letsencrypt:
    acme:
      keyType: EC256
      dnsChallenge:
        provider: cloudflare
      email: REDACTED
      storage: /etc/certs/acme.json

entryPoints:
  http:
    address: :80
    http3: {}
    http:
      redirections:
        entryPoint:
          to: https
          scheme: https

  https:
    address: :443
    http3: {}
    http:
      tls:
        certResolver: letsencrypt

  smtp:
    address: :25
    proxyProtocol:
      trustedIPs:
        - 172.19.0.2
        - 172.19.0.5

  smtps:
    address: :465
    proxyProtocol:
      trustedIPs:
        - 172.19.0.2
        - 172.19.0.5

  imaps:
    address: :993
    proxyProtocol:
      trustedIPs:
        - 172.19.0.2
        - 172.19.0.5

tls:
  options:
    default:
      minVersion: VersionTLS12

providers:
  docker:
    exposedByDefault: false
```

### Stalwart configuration｜堅固的配置

 The following objects configure Stalwart so that every mail listener accepts Proxy Protocol headers from the Traefik network, while the plain-HTTP listener does not. The default certificate is loaded from the files Traefik writes into the shared certificate volume.

 以下物件配置 Stalwart，使所有郵件監聽器都接受來自 Traefik 網路的代理協定 \(Proxy Protocol\) 標頭，而純文字HTTP監聽器則不接受。預設憑證從 Traefik 寫入共用憑證磁碟區的檔案中載入。

 A Certificate object \(found in the WebUI under Settings › TLS › Certificates\) loading the Traefik-issued certificate and private key from disk:

 一個 憑證物件（可在 WebUI 的「設定」› TLS › 憑證」中找到）正在從磁碟載入 Traefik 頒發的憑證和私鑰：

```json
{
  "certificate": {
    "@type": "File",
    "filePath": "/data/certs/mail.example.com/cert.pem"
  },
  "privateKey": {
    "@type": "File",
    "filePath": "/data/certs/mail.example.com/key.pem"
  }
}
```

The SystemSettings singleton points defaultHostname at `mail.example.com` and defaultCertificateId at the Certificate record created above:

 SystemSettings單例指向 defaultHostname位於`mail.example.com`和 defaultCertificateId位於上面建立的憑證記錄中：

```json
{
  "defaultHostname": "mail.example.com",
  "defaultCertificateId": "<certificate-id>"
}
```

HTTP-level security headers are configured on the Http singleton \(found in the WebUI under Settings › Network › HTTP › General, Settings › Network › HTTP › Security\): enableHsts, usePermissiveCors, and useXForwarded.

 HTTP 級安全標頭在 Http 單例上設定（可在 WebUI 中的設定 › 網路 › HTTP › 常規、設定 › 網路 › HTTP ›安全下找到）：enableHsts、usePermissiveCors、和useXForwarded。

```json
{
  "enableHsts": true,
  "usePermissiveCors": false,
  "useXForwarded": true
}
```

Public callback URLs \(and every other absolute URL published in the OAuth, OIDC, and JMAP discovery documents\) default to `https://<defaultHostname>` on port `443`. When Traefik serves clients on a different URL \(non-`443` port, a path-prefixed mount, or a hostname that differs from `defaultHostname`\), set the STALWART\_PUBLIC\_URL environment variable on the Stalwart container to that URL so that the published URLs match. See How discovery URLs are composed for the full model.

 公共回呼 URL（以及 OAuth、 JMAP OIDC和發現文件中發布的所有其他絕對URL ）預設指向連接埠`443`上的`https://<defaultHostname>` 。當 Traefik 在不同的URL上為客戶端提供服務時（非`443` URL埠、路徑前綴掛載或與`defaultHostname`不同的主機名稱），請將 Stalwart 容器上的 STALWART\_PUBLIC\_URL將環境變數相符。有關完整模型，請參閱 發現 URL 的組成方式 。

 The mail and HTTP listeners are defined as NetworkListener objects \(found in the WebUI under Settings › Network › Listeners\). Each mail listener carries an overrideProxyTrustedNetworks value that trusts the Traefik network:

 郵件監聽器和HTTP監聽器定義為 NetworkListener物件（可在 WebUI 的「設定」&gt;「網路」&gt;「監聽器」中找到）。每個郵件監聽器都附有一個 overrideProxyTrustedNetworks值，該值表示信任 Traefik 網路：

```json
[
  {
    "name": "http",
    "protocol": "http",
    "bind": {"[::]:8080": true}
  },
  {
    "name": "https",
    "protocol": "http",
    "bind": {"[::]:443": true},
    "tlsImplicit": true
  },
  {
    "name": "smtp",
    "protocol": "smtp",
    "bind": {"[::]:25": true},
    "overrideProxyTrustedNetworks": {"172.19.0.2": true, "172.19.0.0/16": true}
  },
  {
    "name": "submissions",
    "protocol": "smtp",
    "bind": {"[::]:465": true},
    "tlsImplicit": true,
    "overrideProxyTrustedNetworks": {"172.19.0.2": true, "172.19.0.0/16": true}
  },
  {
    "name": "imaptls",
    "protocol": "imap",
    "bind": {"[::]:993": true},
    "tlsImplicit": true,
    "overrideProxyTrustedNetworks": {"172.19.0.2": true, "172.19.0.0/16": true}
  }
]
```
