# Authentication｜驗證

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Configures authentication settings including password policies and default roles.

 配置身份驗證設置，包括密碼策略和預設角色。

 This object can be configured from the WebUI under Settings › Authentication › General

 此物件可在 WebUI的「設定」&gt;「驗證」&gt;「常規」中進行設定。

## JMAP API

 The Authentication singleton is available via the `urn:stalwart:jmap` capability.

 身份驗證單例可透過`urn:stalwart:jmap`功能取得。

### `x:Authentication/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是 [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)節5.1中定義。

 For singletons, the `ids` argument should be the literal `singleton` \(or `null` to return the single instance\).

 對於單例， `ids`參數應該是字面值`singleton` （或`null`以傳回單一實例）。

 This method requires the `sysAuthenticationGet` permission.

 此方法需要`sysAuthenticationGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:Authentication/get",
          {
            "ids": [
              "singleton"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:Authentication/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節定義。

 For singletons, only the `update` argument with id `singleton` is accepted; `create` and `destroy` arguments are rejected.

 對於單例，僅接受 id 為`singleton` `update`參數；拒絕`create`和`destroy`參數。

 This method requires the `sysAuthenticationUpdate` permission.

 此方法需要`sysAuthenticationUpdate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:Authentication/set",
          {
            "update": {
              "singleton": {
                "directoryId": "<Directory id>"
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get Authentication
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update Authentication --field directoryId='<Directory id>'
```

### PasswordStrength｜密碼強度

| Value 值 | Label 標籤 |
| --- | --- |
| `zero` | Too guessable: risky password. \(guesses &amp;lt; 10^3\) 密碼過於容易被猜到：風險密碼。 （猜測次數 &amp;lt; 10^3） |
| `one` | Very guessable: protection from throttled online attacks. \(guesses &amp;lt; 10^6\) 非常容易猜測：防止網路限速攻擊。 （猜測次數 &amp;lt; 10^6） |
| `two` | Somewhat guessable: protection from unthrottled online attacks. \(guesses &amp;lt; 10^8\) 大致可以猜到：防止不受限制的網路攻擊。 （猜測次數 &amp;lt; 10^8） |
| `three` | Safely unguessable: moderate protection from offline slow-hash scenario. \(guesses &amp;lt; 10^10\) 安全不可猜測：對離線慢速哈希場景提供適度保護。 （猜測次數 &amp;lt; 10^10） |
| `four` | Very unguessable: strong protection from offline slow-hash scenario. \(guesses &amp;gt;= 10^10\) 極難猜測：有效防止離線慢速哈希場景。 （猜測次數 &amp;gt;= 10^10） |
