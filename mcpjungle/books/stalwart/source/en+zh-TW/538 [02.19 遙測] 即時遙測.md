# Live Telemetry｜即時遙測

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[telemetry｜遙測\\\]\\\(&lt;000 目錄.md#c-76&gt;\\\)

Live telemetry exposes an HTTP endpoint that streams structured logs, traces, and metrics to the client in real time. The stream is delivered using Server-Sent Events \(SSE\), so any HTTP client capable of consuming an event stream can subscribe. The feature is suited to live diagnostics, short-lived performance investigations, and dashboards that need a continuous update path.

 即時遙測功能提供了一個HTTP端點，可將結構化日誌、追蹤資訊和指標即時串流傳輸到客戶端。此流透過伺服器發送事件 \( SSE \) 進行傳輸，因此任何能夠接收事件流的HTTP客戶端都可以訂閱。此功能適用於即時診斷、短期效能調查以及需要持續更新的儀表板。

 Filters can be applied on the URL to narrow the stream to specific spans, metrics, or event keys. This is important on busy servers, where the unfiltered stream can be too large to process interactively.

 可以對URL套用篩選器，將資料流縮小到特定的跨度、指標或事件鍵。這在繁忙的伺服器上尤其重要，因為未經過濾的資料流可能過大，無法進行互動式處理。

 The WebUI is the recommended consumer: its Dashboard formats the live stream and provides controls for filtering and visualising activity.

 建議使用 WebUI ：其儀錶板可格式化即時串流，並提供篩選和視覺化活動的控制項。

 This feature is available exclusively in the Enterprise Edition of Stalwart and is not included in the Community Edition.

 此功能僅在 Stalwart 的 企業版中提供，社群版不包含此功能。

## Tracing endpoint｜追蹤端點

 Real-time tracing and log data is available at `/api/telemetry/traces/live`. The endpoint returns a continuous SSE stream; each event is a JSON object describing a server event, carrying structured keys that identify the affected accounts, connections, protocols, and other context.

 即時追蹤和日誌資料可在`/api/telemetry/traces/live`取得。此端點傳回連續的SSE流；每個事件都是一個JSON對象，描述伺服器 事件 ，攜帶結構化鍵，用於標識受影響的帳戶、連線、協定和其他上下文。

### Parameters｜參數

 Filters narrow the stream by matching on event keys. They can be applied broadly or per key:

 過濾器透過匹配事件鍵來縮小資料流範圍。它們可以全域應用，也可以按鍵應用：

- `filter`: matches the given value across every structured key. Useful for a quick search. For example, `/api/telemetry/traces/live?filter=error`.
`filter` ：符合每個結構化鍵的給定值。可用於快速搜尋。例如， `/api/telemetry/traces/live?filter=error` 。
- Per-key parameters: any structured key can be used as a query parameter to match on that key only. Multiple constraints combine. For example, `/api/telemetry/traces/live?remote-ip=192.168.1.1&domain=example.org`.
每個鍵的參數：任何結構化的 key都可以用作查詢參數，僅匹配該鍵。多個約束可以組合使用。例如， `/api/telemetry/traces/live?remote-ip=192.168.1.1&domain=example.org` 。
### Response format｜回覆格式

 Each line is a JSON object. The available keys depend on the event type; the full key catalogue is documented on the Events page.

 每一行都是一個JSON物件。可用鍵取決於事件類型；完整的鍵目錄記錄在 事件頁面上。

## Metrics endpoint｜指標端點

 Real-time metrics are available at `/api/telemetry/metrics/live`. The endpoint returns a continuous SSE stream of metric samples, each encoded as a JSON object that describes a single data point.

 實時指標可在`/api/telemetry/metrics/live`處取得。此端點傳回連續的SSE指標樣本流，每個樣本都編碼為一個JSON對象，該物件描述一個資料點。

### Parameters｜參數

- `metrics`: comma-separated list of metric names to include in the stream. For example, `/api/telemetry/metrics/live?metrics=server.memory,queue.count`.
`metrics` ：以逗號分隔的指標名稱列表，用於指定要包含在流中的指標。例如， `/api/telemetry/metrics/live?metrics=server.memory,queue.count` 。
- `interval`: sampling interval in seconds. For example, `/api/telemetry/metrics/live?interval=30` samples every thirty seconds.
`interval` ：取樣間隔，單位為秒。例如， `/api/telemetry/metrics/live?interval=30`每三十秒採樣一次。
### Response format｜回覆格式

 Each line is a JSON object with structured keys describing the metric and its current value.

 每一行都是一個JSON對象，其中包含描述指標及其當前值的結構化鍵。
