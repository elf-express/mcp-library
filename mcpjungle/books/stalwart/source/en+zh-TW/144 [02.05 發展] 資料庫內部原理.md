# Database Internals｜資料庫內部原理

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[development｜發展\\\]\\\(&lt;000 目錄.md#c-20&gt;\\\)

Stalwart uses a modular storage architecture based on *subspaces*. Subspaces are logical partitions of the database, each responsible for storing a specific category of data. This approach allows the system to efficiently organize, access, and maintain information across a wide variety of backend databases.

 Stalwart 使用基於*子空間*的模組化儲存架構。子空間是資料庫的邏輯分區，每個子空間負責儲存特定類別的資料。這種方法允許系統有效地組織、存取和維護各種後端資料庫中的資訊。

 Each subspace in Stalwart is represented by a single ASCII alphabetic character. These subspaces are integral to the internal design of the system and define how different types of information are separated within the underlying database.

 在 Stalwart 中，每個子空間都以一個字母ASCII表示。這些子空間是系統內部設計不可或缺的一部分，它們定義了底層資料庫中不同類型的信息是如何分離的。

## Backend Mapping｜後端映射

 The way subspaces are represented and stored depends on the type of data store backend used:

 子空間的表示和儲存方式取決於所使用的資料儲存後端的類型：

- When Stalwart is configured to use an SQL database such as PostgreSQL, MySQL, or SQLite, each subspace is mapped to a separate SQL table. This ensures that different categories of data are logically and physically isolated, improving performance and maintainability.
當 Stalwart 配置為使用 PostgreSQL、MySQL 或 SQLite 等SQL時，每個子空間都會對應到一個單獨SQL表。這確保了不同類別的資料在邏輯和物理上相互隔離，從而提高了效能和可維護性。
- For setups using FoundationDB, subspaces are represented by the first byte of the key. This allows for efficient key-space partitioning and lookup operations.
對於使用 FoundationDB 的設置，子空間由鍵的第一個位元組表示。這使得鍵空間分區和查找操作更加有效率。
- In RocksDB, subspaces are implemented as distinct column families, allowing different data types to be stored with optimized compaction and caching strategies.
在 RocksDB 中，子空間被實作為不同的列族，從而允許使用最佳化的壓縮和快取策略來儲存不同的資料類型。
## Subspace Structure｜子空間結構

 The following table provides a detailed description of each subspace used in Stalwart. Each entry includes the subspace letter and the type of data it is intended to store:

 下表詳細描述了 Stalwart 中使用的每個子空間。每個條目都包含子空間字母及其用於儲存的資料類型：

| Subspace 子空間 | Description 說明 |
| --- | --- |
| `a` | Access Control Lists \(ACL\): Stores permissions and access rules governing resource access. 存取控制清單 \( ACL \): 儲存管理資源存取的權限與存取規則。 |
| `d` | Directory: Stores the internal directory using for authentication. 目錄：儲存用於驗證的內部目錄。 |
| `f` | Task Queue: Keeps a list of scheduled or pending tasks awaiting background processing. 任務隊列：維護一個已安排或待處理的任務列表，這些任務將在後台進行處理。 |
| `i` | Indexes: Contains general-purpose indexes used throughout various modules in the system. 索引：包含系統中各模組所使用的通用索引。 |
| `j` | Blob Reserve: Reserved blobs that haven’t been committed yet Blob 保留：尚未提交的已保留 Blob |
| `k` | Blob Links: Links blob ids to document ids. Blob 連結：將 Blob ID 連結到文件 ID。 |
| `t` | Blobs: Used to store binary large objects, such as attachments and file content. Blob：用於儲存二進位大型對象，例如附件和文件內容。 |
| `l` | Logs: Contains the system’t changelog used for incremental caching and the IMAP CONDSTORE extension. 日誌：包含用於增量快取和IMAP CONDSTORE 擴充的系統變更日誌。 |
| `n` | Counters: Persistent numerical counters used to track metrics or system state. 計數器：用於追蹤指標或系統狀態的持久性數值計數器。 |
| `m` | In-Memory Values: Temporarily stores volatile key-value pairs kept in memory. 記憶體值：暫時儲存儲存在記憶體中的揮發性鍵值對。 |
| `y` | In-Memory Counters: In-memory numeric counters with ephemeral lifespan. 記憶體計數器：具有短暫生命週期的記憶體數字計數器。 |
| `p` | Properties: Used to store properties or metadata for different entities. 屬性：用於儲存不同實體的屬性或元資料。 |
| `s` | Settings: Stores system configuration and operational settings. 設定：儲存系統配置與操作設定。 |
| `e` | Queue Messages: Holds individual messages that are part of mail or event queues. 佇列訊息：保存屬於郵件佇列或事件佇列的單一訊息。 |
| `q` | Queue Events: Captures events and changes occurring within queues. 佇列事件：捕捉佇列中發生的事件與變化。 |
| `u` | Quota: Tracks usage limits and enforces resource quotas. 配額：追蹤使用限制並強制執行資源配額。 |
| `h` | Outgoing Reports: Stores generated reports such as pending outgoing DMARC or TLS reports 外發報告：儲存產生的報告，例如待處理的外發DMARC或TLS報告 |
| `r` | Incoming Reports: Contains data received from external reports or analytics. 接收報告：包含從外部報告或分析接收的資料。 |
| `o` | Telemetry Span: Records spans used for distributed tracing and observability. 遙測跨度：用於分散式追蹤和可觀測性的記錄跨度。 |
| `x` | Telemetry Metrics: Captures raw metric data collected for system performance monitoring. 遙測指標：擷取用於系統效能監控的原始指標資料。 |
| `z` | Search Index: Maintains indexes used for efficient text-based search capabilities. 搜尋索引：維護用於高效文字搜尋功能的索引。 |
