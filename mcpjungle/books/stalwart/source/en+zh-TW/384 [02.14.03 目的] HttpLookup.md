# HttpLookup

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines an HTTP-based lookup list.

 定義一個基於HTTP的查找清單。

 This object can be configured from the WebUI under Settings › Lookups › HTTP Lists

 可以透過 WebUI下的「設定」›「尋找」› HTTP 「清單」來設定此物件。

## Fields｜田野

##### `namespace`

> Type: \\\`String\\\` · read-only

類型： \`String\` · 只讀

 Unique identifier for this store when used in lookups

 用於查找時此商店的唯一標識符

##### `enable`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Whether to enable this HTTP list

 是否啟用此HTTP列表

##### `format`

> Type: \\\[\\\`HttpLookupFormat\\\`\\\]\\\(#httplookupformat\\\) · required

類型：\[\`HttpLookupFormat\`\]\(#httplookupformat\) · 必填

 Format of the list

 列表格式

##### `isGzipped`

> Type: \\\`Boolean\\\` · default: \\\`false\\\`

類型： \`Boolean\` · 預設值： \`false\`

 Whether to use gzip compression when downloading the list

 下載清單時是否使用 gzip 壓縮

##### `maxEntries`

> Type: \\\`UnsignedInt\\\` · default: \\\`100000\\\` · max: 1048576 · min: 1

類型： \`UnsignedInt\` · 預設值： \`100000\` · 最大值：1048576 · 最小值：1

 Maximum number of entries allowed in the list. The list is truncated if it exceeds this limit.

 清單中允許的最大條目數。如果超過此限制，清單將被截斷。

##### `maxEntrySize`

> Type: \\\`Size\\\` · default: \\\`512\\\` · max: 1048576 · min: 1

類型： \`Size\` · 預設值： \`512\` · 最大值：1048576 · 最小值：1

 Maximum length of an entry in the list.

 清單中條目的最大長度。

##### `maxSize`

> Type: \\\`Size\\\` · default: \\\`104857600\\\` · max: 1073741824 · min: 10

類型： \`Size\` · 預設值： \`104857600\` · 最大值：1073741824 · 最小值：10

 Maximum size of the list. The list is truncated if it exceeds this size.

 列表的最大長度。如果清單長度超過此限制，則會被截斷。

##### `refresh`

> Type: \\\`Duration\\\` · default: \\\`43200000\\\`

類型： \`Duration\` · 預設值： \`43200000\`

 How often to refresh the list

 清單多久刷新一次

##### `retry`

> Type: \\\`Duration\\\` · default: \\\`3600000\\\`

類型： \`Duration\` · 預設值： \`3600000\`

 How long to wait before retrying to download the list in case of failure.

 下載清單失敗後，需要等待多久才能重試？

##### `timeout`

> Type: \\\`Duration\\\` · default: \\\`30000\\\`

類型： \`Duration\` · 預設值： \`30000\`

 How long to wait for the list to download before timing out

 清單下載需要等待多久才會超時

##### `url`

> Type: \\\`Uri\\\` · required

類型： \`Uri\` · 必填

 URL of the list

 URL列表

## JMAP API

 The HttpLookup object is available via the `urn:stalwart:jmap` capability.

 HttpLookup 物件可透過`urn:stalwart:jmap`功能取得。

### `x:HttpLookup/get`

 This is a standard [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1), Section 5.1.

 這是 [Foo/get](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)方法，如 [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.1)節5.1中定義。

 This method requires the `sysHttpLookupGet` permission.

 此方法需要`sysHttpLookupGet` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:HttpLookup/get",
          {
            "ids": [
              "id1"
            ]
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

### `x:HttpLookup/set`

 This is a standard [Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) method as defined in [RFC 8620](https://www.rfc-editor.org/rfc/rfc8620#section-5.3), Section 5.3.

 這是[Foo/set](https://www.rfc-editor.org/rfc/rfc8620#section-5.3)方法，如[RFC](https://www.rfc-editor.org/rfc/rfc8620#section-5.3) ，第5.3節定義。

 Supports create, update, and destroy operations in a single call.

 支援在一次呼叫中執行建立、更新和銷毀操作。

#### Create｜創造

 This operation requires the `sysHttpLookupCreate` permission.

 此操作需要`sysHttpLookupCreate` 權限 。

```bash title=&amp;quot;Terminal window&amp;quot;
curl -X POST https://mail.example.com/api \
  -H 'Authorization: Bearer $TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
      "methodCalls": [
        [
          "x:HttpLookup/set",
          {
            "create": {
              "new1": {
                "format": {
                  "@type": "Csv"
                },
                "url": "https://example.com"
              }
            }
          },
          "c1"
        ]
      ],
      "using": [
        "urn:ietf:params:jmap:core",
        "urn:stalwart:jmap"
      ]
    }'
```

## CLI

`stalwart-cli` wraps the same JMAP calls. See the CLI reference for installation, authentication, and general usage.

`stalwart-cli`封裝了相同的JMAP呼叫。有關安裝、驗證和一般用法，請參閱 CLI參考 。

### Fetch｜拿來

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli get HttpLookup id1
```

### Create｜創造

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli create HttpLookup \
  --field 'format={"@type":"Csv"}' \
  --field url=https://example.com
```

### Query｜詢問

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli query HttpLookup
```

### Update｜更新

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli update HttpLookup id1 --field enable=true
```

### Delete｜刪除

```bash title=&amp;quot;Terminal window&amp;quot;
stalwart-cli delete HttpLookup --ids id1
```

## Nested types｜巢狀類型

### HttpLookupFormat

 Format of HTTP lookup lists.

 HTTP查找清單的格式。

- **`Csv`**: CSV. Carries the fields of [HttpLookupCsv](#httplookupcsv).
**`Csv`**: CSV . 攜帶 [HttpLookupCsv](#httplookupcsv)的字段。
- **`List`**: List. No additional fields.
**`List`**：列表。無其他字段。

 HTTP列表中關鍵字段的位置。

 The separator character used to parse the HTTP list.

 用於解析HTTP列表的分隔符號。
