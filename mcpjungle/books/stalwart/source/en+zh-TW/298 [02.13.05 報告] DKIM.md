# DKIM

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[mta｜捷運\\\]\\\(&lt;000 目錄.md#c-47&gt;\\\) › \\\[reports｜報告\\\]\\\(&lt;000 目錄.md#c-53&gt;\\\)

DKIM authentication-failure reporting lets domain owners receive notifications when messages sent from their domain fail DKIM authentication at recipient mail servers. Reports use an email-based format sent to a designated address within the domain and typically include the sender, recipient, and specific DKIM verification result. Analysing these reports helps domain owners detect issues with their DKIM implementation and protect their domain reputation.

 DKIM身份驗證失敗報告功能允許網域擁有者在從其網域發送的郵件未能通過收件者郵件伺服器的身份驗證時收到通知DKIM報告採用電子郵件格式，發送到網域內的指定位址，通常包含寄件者、收件者和特定的DKIM驗證結果。分析這些報告有助於網域所有者發現其DKIM實施中的問題，並保護其網域信譽。

 Stalwart automatically analyses received DKIM failure reports from external hosts and can also generate its own DKIM reports to inform other hosts about the authentication outcomes of the signatures it has processed. Outgoing DKIM failure reports are configured on the DkimReportSettings singleton \(found in the WebUI under Settings › MTA › Reports › DKIM\):

 Stalwart 自動分析接收來自外部主機的DKIM失敗報告，並且還可以產生自己的DKIM報告，以告知其他主機其已處理簽名的身份驗證結果。外發DKIM失敗報告在 DkimReportSettings單例中配置（可在 WebUI 的「設定」› MTA › “報告”› DKIM下找到）：

- fromName: expression returning the name used in the `From` header of the DKIM report email. Default `'Report Subsystem'`.
fromName : 傳回DKIM電子郵件的`From`標頭中所使用的名稱的表達式。預設值為`'Report Subsystem'` 。
- fromAddress: expression returning the email address used in the `From` header. Default `'noreply-dkim@' + system('domain')`.
fromAddress : 傳回`From`標頭中所使用的電子郵件地址的表達式。預設值為`'noreply-dkim@' + system('domain')` 。
- subject: expression returning the subject of the report email. Default `'DKIM Authentication Failure Report'`.
subject : 傳回報告電子郵件主題的表達式。預設值為`'DKIM Authentication Failure Report'` 。
- sendFrequency: expression returning the rate at which reports are sent to a given address. When the rate is exceeded, no further failure reports are sent to that address. Default `[1, 1d]`. Returning `false` disables DKIM failure reporting.
sendFrequency ：傳迴向給定位址發送報告的速率的表達式。當超過此速率時，將不再向該位址發送故障報告。預設值為`[1, 1d]` 。返回`false`將禁用DKIM故障報告。
- dkimSignDomain: expression returning the domain whose DKIM signatures should sign the outgoing report. Default `system('domain')`.
dkimSignDomain : 返回域的表達式，該域的DKIM簽章應簽署傳出的報告。預設值為`system('domain')` 。
Example configuration using explicit values:
 使用顯式值的範例配置：

```json
{
  "fromName": {"else": "'Report Subsystem'"},
  "fromAddress": {"else": "'[email protected]'"},
  "subject": {"else": "'DKIM Authentication Failure Report'"},
  "sendFrequency": {"else": "[1, 1d]"},
  "dkimSignDomain": {"else": "'example.org'"}
}
```
