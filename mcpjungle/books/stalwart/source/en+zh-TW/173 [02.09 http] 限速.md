# Rate limiting｜限速

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[http\\\]\\\(&lt;000 目錄.md#c-26&gt;\\\)

Rate limiting restricts how often a client can repeat an action within a given time period. Applied to the HTTP server, it mitigates brute-force attacks and reduces overall load by capping the number of requests that any single source can issue in a short window.

 速率限制會限制客戶端在給定時間內重複執行操作的次數。應用於HTTP伺服器時，它透過限制單一來源在短時間內可以發出的請求數量，來緩解暴力破解攻擊並降低整體負載。

 Stalwart tracks the IP address of each incoming HTTP request and measures the number of requests received over the configured window. Once a client exceeds the configured rate, further requests from that source are rejected until the window elapses.

 Stalwart 會追蹤每個傳入的HTTP請求的IP位址，並統計在配置的時間視窗內接收到的請求數量。一旦某個客戶端的請求速率超過配置值，來自該客戶端的後續請求將被拒絕，直到時間視窗結束。

 HTTP rate limits are configured on the Http singleton \(found in the WebUI under Settings › Network › HTTP › General, Settings › Network › HTTP › Security\) through two separate fields, one for anonymous traffic and one for authenticated users. Each field is a `Rate` value: a `count` over a `period`, where the period is a duration in milliseconds.

 HTTP速率限制在 Http單例上配置（可在 WebUI 的「設定」&gt;「網路」&gt; HTTP常規」或「設定」&gt;「網路」&gt; HTTP安全性」中找到），透過兩個獨立的欄位進行配置，一個用於匿名流量，一個用於已認證使用者。每個欄位都是一個`Rate`值：一個`count`值加上一個`period` ，其中周期以毫秒為單位表示持續時間。

## Anonymous limits｜匿名限制

 The rateLimitAnonymous field sets the request rate allowed to an anonymous IP address. The default is 100 requests per minute.

 rateLimitAnonymous欄位設定允許傳送到匿名IP位址的請求速率。預設值為每分鐘 100 個請求。

```json
{
  "rateLimitAnonymous": {"count": 100, "period": 60000}
}
```

## Authenticated limits｜已驗證限制

 The rateLimitAuthenticated field sets the request rate allowed to an authenticated user. The default is 1000 requests per minute.

 rateLimitAuthenticated欄位設定已認證使用者允許的請求速率。預設值為每分鐘 1000 個請求。

```json
{
  "rateLimitAuthenticated": {"count": 1000, "period": 60000}
}
```
