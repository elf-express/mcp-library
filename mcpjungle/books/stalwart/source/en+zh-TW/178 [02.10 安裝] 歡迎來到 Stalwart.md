# Welcome to Stalwart｜歡迎來到 Stalwart

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[install｜安裝\\\]\\\(&lt;000 目錄.md#c-29&gt;\\\)

Welcome to **Stalwart, an open-source mail and collaboration server designed for the modern internet. Stalwart supports a wide range of protocols including**JMAP**,**IMAP4**,**POP3**,**SMTP**,**CalDAV**,**CardDAV**, and**WebDAV**, covering email, calendars, contacts, and file storage. Built in**Rust**, Stalwart is designed to be**secure**,**fast**,**reliable**, and**scalable, and is capable of running everything from small personal mail servers to large, distributed enterprise deployments.

 歡迎來到 **Stalwart，這是一個專為現代互聯網設計的開源郵件和協作伺服器。 Stalwart 支援多種協議，包括**JMAP**、**IMAP4**、**POP3**、**SMTP**、**CalDAV**、**CardDAV**和**WebDAV**，涵蓋電子郵件、日曆、聯絡人和檔案儲存。 Stalwart 採用**Rust**構建，旨在**安全**、**快速**、**可靠**和**可擴展，並且能夠運行從小型個人郵件伺服器到大型分散式企業部署的所有內容。

 This **Getting Started** guide is intended to help new users install, configure, and optimize Stalwart for their specific needs. It walks through the essential steps and considerations for a successful deployment.

 本**入門指南**旨在協助新使用者安裝、配置和最佳化 Stalwart，以滿足其特定需求。它將逐步介紹成功部署的關鍵步驟和注意事項。

 We begin with an overview of System Requirements, where you’ll learn how memory and CPU usage scale with server load and how to size your system accordingly. The [Installation Guide](https://stalw.art/docs/install/) provides instructions for setting up Stalwart on your platform of choice, including details on configuration.

 首先，我們將概述系統需求 ，您將了解記憶體和CPU的使用量如何隨伺服器負載變化，以及如何相應地調整系統配置。 [安裝指南](https://stalw.art/docs/install/)提供了在您選擇的平台上安裝Stalwart的說明，包括設定詳情。

 Next, we explore how to choose the right database for your deployment, explaining Stalwart’s modular storage architecture and how to match different storage backends to the data they manage. You’ll also learn how to choose a directory, whether internal or external, for handling user authentication and account management.

 接下來，我們將探討如何為您的部署選擇合適的資料庫（ \([https://stalw.art/docs/install/store](https://stalw.art/docs/install/store)\) ），解釋 Stalwart 的模組化儲存架構，以及如何將不同的儲存後端與其管理的資料相符。您還將學習如何選擇目錄（ \([https://stalw.art/docs/install/directory](https://stalw.art/docs/install/directory)\) ），無論是內部目錄還是外部目錄，用於處理使用者身份驗證和帳戶管理。

 Once the server is configured, proper DNS setup is crucial for ensuring secure and reliable mail delivery and client connectivity. This section explains all the DNS records required for services like SPF, DKIM, DMARC, MTA-STS, and more.

 伺服器設定完成後，正確的 DNS設定對於確保郵件安全可靠地送達以及客戶端連線至關重要。本節將解釋所有DNS記錄，這些記錄對於SPF, DKIM, DMARC, MTA-STS等服務以及其他服務都至關重要。

 To ensure your deployment remains secure, we cover several best practices in the Securing Your Server section. This includes disabling unused ports, configuring HTTP access controls, and enforcing clear administrative roles to minimize risk and maintain operational integrity.

 為確保您的部署安全，我們在保護您的伺服器部分介紹了幾項最佳實踐。這包括停用未使用的連接埠、配置HTTP存取控制以及強制執行明確的管理角色，以最大限度地降低風險並維護運作完整性。

 Finally, for large or high-traffic environments, the Performance Tuning section offers guidance on caching and concurrency settings, helping you get the best performance out of your server under demanding conditions.

 最後，對於大型或高流量環境，效能調優部分提供了快取和並發設定的指導，幫助您在嚴苛條件下獲得伺服器的最佳效能。

 Whether you’re running a single-node setup or planning a distributed deployment, this guide will help you get Stalwart up and running efficiently and securely. Let’s get started.

 無論您是運行單節點設定還是計劃部署分散式系統，本指南都將幫助您有效且安全地啟動並運行 Stalwart。讓我們開始吧。
