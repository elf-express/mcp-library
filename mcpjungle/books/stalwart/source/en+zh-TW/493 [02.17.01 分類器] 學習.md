# Learning｜學習

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[spamfilter｜垃圾郵件過濾器\\\]\\\(&lt;000 目錄.md#c-69&gt;\\\) › \\\[classifier｜分類器\\\]\\\(&lt;000 目錄.md#c-70&gt;\\\)

In addition to explicitly labelled training samples provided by users or administrators, Stalwart supports automatic learning. Automatic learning allows the classifier to incorporate new samples without direct user intervention, but only under conditions where the system has high confidence in the correctness of the label. The aim is to accelerate adaptation to new patterns while minimising the risk of reinforcing incorrect classifications.

 除了使用者或管理員提供的明確標註訓練樣本外，Stalwart 還支援自動學習。自動學習允許分類器在無需使用者直接幹預的情況下整合新樣本，但前提是系統對標籤的正確性具有高度信心。其目的是在最大限度降低強化錯誤分類風險的同時，加快對新模式的適應速度。

 Automatic learning is deliberately conservative. It does not rely on the classifier’s own probabilistic output alone; it uses strong external signals and contextual information to decide whether a message should be treated as spam or ham. Those signals include user-specific trust relationships, conversational context, and infrastructure-level indicators such as spam traps and DNS block lists. Only when one of these conditions is met is a message promoted to a training sample and incorporated into the model.

 自動學習刻意保持保守。它並非僅僅依賴分類器本身的機率輸出，而是利用強有力的外部訊號和上下文資訊來判斷郵件是否應被視為垃圾郵件。這些訊號包括使用者特定的信任關係、對話情境以及基礎設施層面的指標，例如垃圾郵件陷阱和DNS黑名單。只有當滿足上述條件之一時，郵件才會被提升為訓練樣本並納入模型。

## Address books｜地址簿

 Stalwart uses the recipient’s address book as a source of corrective feedback. If a message is classified as spam but the sender is present in the recipient’s address book, the system treats this as strong evidence that the message is legitimate and automatically adds it as a ham training sample.

 Stalwart 會利用收件人的通訊錄作為糾錯回饋來源。如果郵件被判定為垃圾郵件，但寄件者存在於收件人的通訊錄中，系統會將此視為郵件合法性的有力證據，並自動將其添加為正常郵件訓練樣本。

 This mechanism allows the classifier to adjust quickly to trusted correspondents and to reduce repeated false positives for known senders. Because address book entries are curated by users, they provide a high-confidence signal that complements statistical inference.

 這種機制使分類器能夠快速調整以識別可信任的聯絡人，並減少對已知寄件者的重複誤報。由於地址簿條目由使用者維護，因此它們提供了高置信度的訊號，可以補充統計推論。

## Sent message threads｜已發送訊息線程

 A similar rule applies to message threads. If a message is classified as spam but belongs to a conversation thread that contains messages in the recipient’s Sent Items folder, Stalwart interprets this as a reply to a message the recipient previously sent. Such messages are highly likely to be legitimate, even when their content is short or atypical.

 類似的規則也適用於郵件線程。如果一封郵件被歸類為垃圾郵件，但它屬於一個包含收件者「已傳送郵件」資料夾中郵件的對話線程，Stalwart 會將其解讀為對收件者先前發送的郵件的回覆。即使內容簡短或不尋常，此類郵件也極有可能是合法的。

 When this condition is met, the message is automatically added as a ham training sample. This helps the classifier learn conversational patterns and prevents false positives in ongoing exchanges.

 當滿足此條件時，該訊息將自動新增為非目標使用者訓練樣本。這有助於分類器學習對話模式，並防止在正在進行的對話中出現誤報。

## Spam traps｜垃圾郵件陷阱

 Stalwart can automatically learn spam from messages delivered to administrator-defined spam traps, also known as honey pots. A spam trap is an address that is not used for legitimate communication and is intended solely to attract unsolicited messages; any message received at such an address is assumed to be spam with a high degree of confidence.

 Stalwart 可以自動識別發送到管理員定義的 垃圾郵件陷阱 （也稱為蜜罐）的垃圾郵件。垃圾郵件陷阱是指不用於合法通信，其唯一目的是吸引未經請求的郵件的地址；任何發送到此類地址的郵件都會被高度認定為垃圾郵件。

 Messages sent to spam traps are automatically added as spam training samples. This provides a reliable source of high-quality spam data and allows the classifier to learn about new spam campaigns early, often before they reach regular recipients.

 發送到垃圾郵件陷阱的郵件會自動加入垃圾郵件訓練範本。這提供了可靠的高品質垃圾郵件資料來源，並使分類器能夠及早了解新的垃圾郵件活動，通常在垃圾郵件到達普通收件者之前就能識別出來。

## DNS block lists｜DNS阻止列表

 Another source of automatic spam learning is DNS-based block lists. When a message originates from a sender domain or IP address that is listed in multiple DNS block lists, this is treated as strong evidence of spam activity. By default, Stalwart requires the sender to be listed in at least two block lists before this condition is satisfied.

 另一個自動垃圾郵件學習來源是 DNS基於黑名單 。當郵件來自多個DNS中列出的寄件者網域或IP時，這被視為垃圾郵件活動的有力證據。預設情況下，Stalwart 要求寄件者至少被列入兩個黑名單才能滿足此條件。

 When the requirement is met, the message is automatically added as a spam training sample. Using multiple block list confirmations reduces the risk of false positives and ensures that only well-established spam sources contribute to automatic learning.

 當滿足要求時，該郵件將自動新增為垃圾郵件訓練樣本。使用多重黑名單確認可以降低誤報風險，並確保只有信譽良好的垃圾郵件來源才會參與自動學習。

## Configuration｜配置

 Automatic learning is configured on the SpamClassifier singleton \(found in the WebUI under Settings › Spam Filter › Classifier\) and on the SpamSettings singleton \(found in the WebUI under Settings › Spam Filter › General\). The relevant fields are:

 自動學習功能已在 SpamClassifier單例（位於 WebUI 的「設定」&gt;「垃圾郵件過濾器」&gt;「分類器」下）和 SpamSettings單例（位於 WebUI 的「設定」&gt;「垃圾郵件過濾器」&gt;「常規」上）上設定。相關欄位如下：

- learnSpamFromRblHits on SpamClassifier: the minimum number of DNS block lists that must list the sender’s domain or IP address before a message is automatically treated as spam for training purposes. Default `2`.
learnSpamFromRblHits用於 SpamClassifier：在訓練目的將郵件自動視為垃圾郵件之前，必須列出寄件人域或IP的最小DNS數量。預設值為`2` 。
- learnSpamFromTraps on SpamClassifier: when `true`, messages delivered to administrator-defined spam trap addresses are added as spam training samples. Default `true`.
learnSpamFromTraps在 SpamClassifier 上：當`true`時，發送到管理員定義的垃圾郵件陷阱地址的郵件將被添加為垃圾郵件訓練樣本。預設值為`true` 。
- learnHamFromCard on SpamClassifier: when `true`, messages from senders in the recipient’s address book that would otherwise be classified as spam are added as ham training samples. Default `true`.
learnHamFromCard在 SpamClassifier 上：當`true`時，收件者通訊錄中原本會被分類為垃圾郵件的寄件者發送的郵件將被加入正常郵件訓練樣本。預設值為`true` 。
- learnHamFromReply on SpamClassifier: when `true`, messages classified as spam that belong to threads containing messages in the recipient’s Sent Items folder are added as ham training samples. Default `true`.
learnHamFromReply在 SpamClassifier 上：當`true`時，被分類為垃圾郵件且屬於收件人「已發送郵件」資料夾中包含郵件的執行緒的郵件將被加入為正常郵件訓練樣本。預設值為`true` 。
The trusted-sender overrides that feed these automatic-learning rules are themselves controlled by trustContacts and trustReplies on SpamSettings.
 為這些自動學習規則提供資訊的受信任寄件者覆蓋本身由 SpamSettings 上的 trustContacts和 trustReplies控制。
