# MtaOutboundThrottle｜Mta出站油門

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[ref｜參考\\\]\\\(&lt;000 目錄.md#c-56&gt;\\\) › \\\[object｜目的\\\]\\\(&lt;000 目錄.md#c-61&gt;\\\)

Defines an outbound rate limit rule for message delivery.

 定義訊息傳遞的出站速率限制規則。

 This object can be configured from the WebUI under Settings › MTA › Rates & Quotas › Outbound Rate Limits

 此物件可在 WebUI下的「設定」› MTA › “費率與配額”› “出站速率限制”中進行設定。

## Fields｜田野

##### `enable`

> Type: \\\`Boolean\\\` · default: \\\`true\\\`

類型： \`Boolean\` · 預設值： \`true\`

 Whether to enable this throttle

 是否啟用此節流閥

##### `description`

> Type: \\\`String\\\` · required

類型： \`String\` · 必填

 Short description for the throttle

 油門簡述

##### `key`

> Type: \\\`Set&amp;lt;\\\`\\\[\\\`MtaOutboundThrottleKey\\\`\\\]\\\(#mtaoutboundthrottlekey\\\)\\\`&amp;gt;\\\`

模式標本： \`Set&amp;lt;\` \[ \`MtaOutboundThrottleKey\` \]\(#mtaoutboundthrottlekey\)\`&amp;gt;\`

 Optional list of context variables that determine where this throttle should be applied

 可選的上下文變數列表，用於確定此節流閥應應用於何處。

##### `match`

> Type: \\\[\\\`Expression\\\`\\\]\\\(#expression\\\) · default: \\\`{"else":"true"}\\\`

類型：\[\`Expression\`\]\(#expression\) · 預設值： \`{"else":"true"}\`

 Enable the imposition of concurrency and rate limits only when a specific condition is met

 僅當滿足特定條件時才啟用並發和速率限制。

 Available variables: \[\`MtaQueueHostVariable\`\]\(&lt;327 \[02.14.02.02 多變的\] MtaQueueHostVariable.md&gt;\).

 可用變數：\[\`MtaQueueHostVariable\`\]\(&lt;327 \[02.14.02.02 多變的\] MtaQueueHostVariable.md&gt;\) 。

##### `rate`

> Type: \\\[\\\`Rate\\\`\\\]\\\(#rate\\\) · required

類型：\[\`Rate\`\]\(#rate\) · 必填

 Number of incoming requests over a period of time that the rate limiter will allow

 限速器允許在一段時間內收到的請求數量。
