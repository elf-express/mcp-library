# Tenants｜租戶

> 章節：\\\[docs｜文件\\\]\\\(&lt;000 目錄.md#c-2&gt;\\\) › \\\[auth｜認證\\\]\\\(&lt;000 目錄.md#c-3&gt;\\\) › \\\[authorization｜授權\\\]\\\(&lt;000 目錄.md#c-5&gt;\\\)

Multi-tenancy allows several independent organisations, referred to as tenants, to share the same Stalwart deployment while keeping their data and resources isolated from one another. A tenant is a logical division within the server: it has its own accounts, groups, mailing lists, and domains, and principals that belong to one tenant cannot reach resources that belong to another.

 多租用戶架構允許多個獨立組織（稱為租用戶）共享同一個 Stalwart 部署，同時保持彼此資料和資源的隔離。租用戶是伺服器內部的邏輯單元：它擁有自己的帳戶、群組、郵件清單和網域，屬於一個租用戶的主體無法存取屬於其他租用戶的資源。

 Each tenant is represented by a Tenant object \(found in the WebUI under Management › Directory › Tenants\). Principals associated with a tenant \(accounts, groups, lists, and similar\) carry a `memberTenantId` field referencing the owning tenant and are restricted to resources of that same tenant.

 每個租用戶都由一個 Tenant物件表示（可在 WebUI 的「管理」&gt;「目錄」&gt;「租用戶」下找到）。與租用戶關聯的主體（帳戶、群組、清單等）都包含一個`memberTenantId`字段，該字段引用所屬租戶，並且只能存取該租戶的資源。

 Permissions granted within a tenant are bounded by the tenant’s own permissions. If a tenant administrator assigns a permission to a principal that is not enabled on the tenant, the grant has no effect. This ensures a tenant cannot exceed the privileges allocated to it at the server level.

 租用戶內部授予的權限受限於該租用戶本身的權限範圍。如果租用戶管理員將權限指派給租用戶中未啟用的主體，則該授予無效。這確保租用戶不會超出伺服器層級分配給它的權限。

 This feature is available exclusively in the Enterprise Edition of Stalwart and is not included in the Community Edition.

 此功能僅在 Stalwart 的 企業版中提供，社群版不包含此功能。

## Properties｜特性

 A Tenant object exposes the following fields:

 租戶對象公開以下欄位：

- name: the tenant’s name, used as its identifier in the system.
name : 租用戶名稱，用作其在系統中的識別碼。
- logo: a URL or base64-encoded image used when rendering the tenant in the WebUI.
logo : 在 WebUI 中渲染租用戶時所使用的URL或 base64 編碼影像。
- roles: the roles assigned to the tenant itself, modelled as a `Roles` variant that can be either the default role set or a custom set referencing specific roles.
roles : 指派給租用戶本身的角色，建模為`Roles`變體，可以是預設角色集，也可以是引用特定角色的自訂集。
- permissions: the permissions the tenant is allowed to grant to its principals, modelled as a `Permissions` variant \(`Inherit`, `Merge`, or `Replace`\) combined with an explicit enable/disable list.
permissions : 租用戶可以授予其主體的權限，建模為`Permissions`變體（ `Inherit`, `Merge`或`Replace` ），並結合明確啟用/停用清單。
- quotas: a map from `TenantStorageQuota` keys to numeric limits. This includes the tenant’s total disk quota and the maximum number of principals of each kind \(accounts, groups, lists, domains\) that the tenant can create.
quotas : 由`TenantStorageQuota`鍵到數值限制的對應。這包括租戶的總磁碟配額以及租戶可以建立的每種類型主體（帳戶、群組、清單、網域）的最大數量。
- usedDiskQuota: the amount of disk space currently consumed by the tenant, computed by the server.
usedDiskQuota : 租用戶目前使用的磁碟空間量，由伺服器計算。
The name field carries the tenant’s human-readable label. There is no separate description field on the Tenant object.
 name欄位包含租用戶的易讀標籤。租戶物件上沒有單獨的描述欄位。

 Isolation, quotas, and custom role sets together allow multi-tenant operation, while still giving administrators the ability to regulate how much of the server each tenant can consume.

 隔離、配額和自訂角色集共同實現了多租用戶運行，同時也讓管理員控制每個租用戶可以使用的伺服器資源量。

## Quotas｜配額

 A tenant’s disk quota is the maximum storage consumed by all of its members combined. The sum of every member’s used storage must fit within this value. For example, when a tenant has a 100GB quota, if member A has consumed 60GB and member B has consumed 40GB, no further mail can be accepted for any account in the tenant until usage is reduced.

 租戶的磁碟配額是指其所有成員佔用儲存空間的總和。每個成員已使用儲存空間的總和必須不超過此值。例如，如果租戶的配額為 100GB，成員 A 已使用 60GB，成員 B 已使用 40GB，則在成員使用量減少之前，該租戶中任何帳戶都無法接收任何郵件。

 Tenants also carry principal-count quotas, which limit the number of accounts, groups, lists, or domains the tenant can create. Both kinds of quota are expressed through the tenant’s quotas map.

 租戶還擁有主體數量配額，該配額限制了租戶可以建立的帳戶、群組、清單或網域的數量。這兩種配額都透過租戶的 quotas映射來表示。

## Branding｜品牌推廣

 Stalwart supports per-tenant branding in the WebUI through the logo field on the Tenant object. The logo is displayed when a user belonging to the tenant accesses the WebUI, letting each tenant present its own visual identity in multi-tenant deployments.

 Stalwart 支援透過租用戶物件上的 logo欄位在 WebUI 中實現租用戶專屬品牌識別。當屬於該租戶的使用者造訪 WebUI時，將顯示該租戶的徽標，從而使每個租戶在多租戶部署中都能展現其獨特的視覺形象。
