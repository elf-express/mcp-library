# Delivery Notifications

> Section: MTA settings › Reports

Delivery Status Notifications (DSNs) inform senders about the status of their messages. A DSN is generated by the MTA and delivered to the original sender, communicating whether the message was delivered successfully, delayed, or permanently failed.

## Configuration

DSNs are configured on the [DsnReportSettings](https://stalw.art/docs/ref/object/dsn-report-settings) singleton (found in the WebUI under <!-- breadcrumb:DsnReportSettings --> Settings › MTA › Reports › DSN<!-- /breadcrumb:DsnReportSettings -->):

- [`fromName`](https://stalw.art/docs/ref/object/dsn-report-settings#fromname): expression returning the name used in the `From` header of the DSN. Default `'Mail Delivery Subsystem'`.
- [`fromAddress`](https://stalw.art/docs/ref/object/dsn-report-settings#fromaddress): expression returning the email address used in the `From` header. Default `'MAILER-DAEMON@' + system('domain')`.
- [`dkimSignDomain`](https://stalw.art/docs/ref/object/dsn-report-settings#dkimsigndomain): expression returning the domain whose [DKIM](https://stalw.art/docs/mta/authentication/dkim/) signatures sign the DSN. Default `system('domain')`.

Example configuration with explicit address and domain:

```json
{
  "fromName": {"else": "'Mail Delivery Subsystem'"},
  "fromAddress": {"else": "'MAILER-DAEMON@example.org'"},
  "dkimSignDomain": {"else": "'example.org'"}
}
```
