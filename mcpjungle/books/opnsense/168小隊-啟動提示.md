# 168小隊 啟動提示

隊員定義（工具、模型、職責）在全域 `~/.claude/agents/`：
`168-terminologist.md`、`168-reviewer.md`、`168-devils-advocate.md`、`168-format-checker.md`。

在 `E:\source\mcp-library\knowledge.books\opnsense` 開一個新的 `claude` 工作階段，把下面整段貼上。
（提示裡不要寫模型，否則會蓋過定義檔中的 model 設定。）

---

建立一個名為「168小隊」的 agent team（請建立 agent team，不要只用子代理），任務是審查並修正 OPNsense 文件的繁體中文（台灣）譯文。

背景：`en/` 是英文原文，`zh-TW/` 是繁中譯文，`en+zh-TW/` 是雙語對照，共 377 篇；`000 目錄.md` 有完整章節結構。產出都放在 `../168小隊/`。

依 `~/.claude/agents/` 的定義生成隊友：
- 一位 `168-terminologist`，名為 terminologist
- 三位 `168-reviewer`，分別名為 reviewer-a、reviewer-b、reviewer-c；依 `000 目錄.md` 把章節平均切成三段，每人一段，範圍不重疊
- 一位 `168-devils-advocate`，名為 devils-advocate
- 一位 `168-format-checker`，名為 format-checker

用共享任務列表分配工作，審稿任務依賴「術語表完成」。全部完成後，由你（主管）寫 `../168小隊/總結報告.md`：改了幾個檔案、主要修正類型、挑錯員與格式檢查員抓到的問題、待人工判斷的項目。
