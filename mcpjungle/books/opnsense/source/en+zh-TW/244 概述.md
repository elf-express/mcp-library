# Overview｜概述

> 章節：[Development Manual](<000 目錄.md#c-52>) › [Backend](<000 目錄.md#c-54>)

The life of a service starts during the boot process, but with different hooks available, sometimes it is challenging to find the correct one. This paragraph aims to explain the various integration spots available, which are being explained in more detail in the rest of the chapter.

服務的生命週期始於啟動過程，但由於有多種鉤子可供使用，有時很難找到正確的鉤子。本段旨在解釋各種可用的整合點，本章其餘部分將對此進行更詳細的闡述。

## Bootup｜啟動

After the kernel is loaded and the machine starts to boot, the following integration points are being executed in sequence:

核心載入完畢，機器開始啟動後，將依序執行以下整合點：

1.  [syshook/early](<245 啟動自動運行選項.md>), simple shell scripts to run before any network services are loaded, can for example be used to load specific drivers.  
    [syshook/early](<245 啟動自動運行選項.md>) ，在載入任何網路服務之前執行的簡單 shell 腳本，例如可用於載入特定驅動程式。
    
2.  [plugins/device](<248 使用插件.md>), register and create devices, services like OpenVPN use this on our end to make sure `tun` and `tap` devices exist before doing further configuration.  
    [plugins/device](<248 使用插件.md>) ，註冊並建立設備，OpenVPN 等服務在我們這邊使用此資訊來確保`tun`和`tap`設備存在，然後再進行進一步配置。
    
3.  [plugins/configure/early](<248 使用插件.md>), configure `early` event in bootup process, before normal services are being started (things like ssh and the webconfigurator use this spot)  
    [plugins/configure/early](<248 使用插件.md>) ，在啟動過程中設定`early`事件，在正常服務啟動之前（諸如 ssh 和 webconfigurator 之類的服務會使用此位置）
    
4.  [plugins/firewall](<248 使用插件.md>) allows for automatic firewall (nat) rule registration in cases where the service is able to ship its own rules. (some do this optionally for easy setup)  
    [外掛程式/防火牆](<248 使用插件.md>)允許在服務能夠自備規則的情況下自動註冊防火牆（NAT）規則。 （有些服務為了方便設置，會選擇性地啟用此功能）
    
5.  [plugins/configure/vpn](<248 使用插件.md>), configure `vpn` event, vpn type services are being configured here (e.g. IPsec, OpenVPN)  
    [plugins/configure/vpn](<248 使用插件.md>) ，設定`vpn`事件，此處正在設定 VPN 類型服務（例如 IPsec、OpenVPN）
    
6.  [plugins/configure/bootup](<248 使用插件.md>), configure `bootup` event, normal legacy service configuration, when not using the rc(8) system (for example: unbound, ntpd)  
    [plugins/configure/bootup](<248 使用插件.md>) ，配置`bootup`事件，常規傳統服務配置，當不使用 rc(8) 系統時（例如：unbound、ntpd）
    
7.  [syshook/start](<245 啟動自動運行選項.md>), simple shell scripts to run after all networking has been setup.  
    [syshook/start](<245 啟動自動運行選項.md>) ，在所有網路設定完成後執行的簡單 shell 腳本。
    
8.  [rc(8)](<245 啟動自動運行選項.md>), regular rc(8) scripts (executed using the above `` the rc.syshook.d/start` ``)  
    [rc(8)](<245 啟動自動運行選項.md>) ，常規 rc(8) 腳本（使用上述 ` ` the rc.syshook.d/start` `` 執行）
    

Tip

提示

Use `pluginctl -c` to display available events and the plugins attached to them.

使用`pluginctl -c`顯示可用事件及其附加的插件。

## Running stage｜跑步階段

Now the system is booted and events may take place, some of the common integration points with their purpose are listed below:

系統啟動後，可能會發生一些事件，以下列出了一些常見的整合點及其用途：

-   [syshook/carp](<245 啟動自動運行選項.md>), when a high-availability node changes roles from/to master or backup, these scripts are being executed. This offers the ability to prevent client services from connecting when in the wrong mode.  
    [syshook/carp](<245 啟動自動運行選項.md>) ，當高可用節點在主節點和備份節點之間切換角色時，這些腳本將被執行。這可以防止客戶端服務在錯誤的模式下連線。
    
-   [plugins/configure/newwanip](<248 使用插件.md>) will be triggered after an interface retrieves a dynamic address.  
    [plugins/configure/newwanip](<248 使用插件.md>)在介面檢索到動態位址後將會觸發。
    
-   [plugins/configure/vpn](<248 使用插件.md>) will be triggered when the VPN subsystem requires reloading.  
    [plugins/configure/vpn] 當VPN子系統需要重新載入時，將觸發(https://docs.opnsense.org/development/backend/legacy.html) 。
    
-   [plugins/interface](<248 使用插件.md>) handles dynamic registration of new (virtual) interfaces.  
    [plugins/interface](<248 使用插件.md>)處理新（虛擬）介面的動態註冊。
    
-   [plugins/syslog](<248 使用插件.md>) registers syslog facilities  
    [plugins/syslog](<248 使用插件.md>)註冊 syslog 功能
    
-   [plugins/xmlrpc](<248 使用插件.md>) registers configuration synchronisation points.  
    [plugins/xmlrpc](<248 使用插件.md>)註冊設定同步點。
    

## Shutdown (reboot)｜關機（重啟）

When the system is shutdown or being rebooted, we can hook actions using the [syshook/stop](<245 啟動自動運行選項.md>) script directory. Services like the backup hook into this to flush contents before being terminated.

當系統關機或重新啟動時，我們可以使用 [syshook/stop](<245 啟動自動運行選項.md>)腳本目錄來執行特定操作。諸如備份之類的服務會鉤入此腳本，以便在終止前刷新內容。
