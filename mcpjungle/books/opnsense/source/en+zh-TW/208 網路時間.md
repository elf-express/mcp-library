# Network Time｜網路時間

> 章節：[Services](<000 目錄.md#c-40>)

OPNsense ships with a standard [NTPd](http://doc.ntp.org/current-stable/) server, which synchronizes time with upstream servers and provides time to connected clients.

OPNsense 隨附一個標準的 [NTPd](http://doc.ntp.org/current-stable/)伺服器，該伺服器與上游伺服器同步時間，並向連接的用戶端提供時間。

A newly installed firewall comes with NTP enabled on all interfaces (firewall blocks all non LAN access in this case), forwarding queries to one of the `X.opnsense.pool.ntp.org` upstreams (`X` is any of 0,1,2,3).

新安裝的防火牆在所有介面上啟用了NTP （在這種情況下，防火牆阻止所有非LAN存取），並將查詢轉發到`X.opnsense.pool.ntp.org`上游之一（ `X`是0、1、2、3中的任何一個）。

## General settings｜常規設定

In most cases the default setup is ready to use, below you will find some of the general options which can be configured.

大多數情況下，預設設定即可使用，以下是一些可以配置的常規選項。

---

Attention

注意

NTPd syncs the local clock to remote NTP servers and listens for incoming client queries using the selected interfaces. The interface selection must therefore include a WAN type interface so that normal routing to the internet can take place. Only selecting a LAN type interface will likely work due to Source NAT rules, however, if CARP is configured, it is possible that such NAT rules will translate to the address of the CARP VIP, causing asymmetric routing for secondary nodes.

NTPd 將本機時鐘與遠端NTP伺服器同步，並使用選定的介面監聽傳入的用戶端查詢。因此，介面選擇必須包含WAN類型的接口，以便能夠正常路由到互聯網。由於來源NAT規則的存在，僅選擇LAN類型的介面可能有效；但是，如果配置了CARP ，則此類NAT規則可能會轉換為CARP VIP的位址，從而導致輔助節點的路由不對稱。

Unless you are sure that you want to use a specific interface, it is recommended to keep the default of listening on all interfaces and use the firewall rules to constrain access to the NTP service. See [Listen interfaces](<98 設定.md#listen-interfaces>) for more information.

除非您確定要使用特定接口，否則建議保留監聽所有接口的預設設置，並使用防火牆規則限制對NTP服務的存取。有關更多信息，請參閱 [監聽介面](<98 設定.md#listen-interfaces>) 。

Note

筆記

NTPs is disabled if no Time servers are configured. There is no separate enable/disable toggle.

如果未配置任何時間伺服器，則 NTP 服務將被停用。沒有單獨的啟用/停用開關。

## GPS

If you own a gps receiver, which supports NMEA, you can use it as a reference clock and configure it in this section. For some brands settings are preconfigured, you can also use custom settings.

如果您擁有支援NMEA的GPS接收器，您可以將其用作參考時鐘，並在本部分進行設定。某些品牌的接收器已預設設置，您也可以使用自訂設定。

## PPS

If your GPS receiver supports PPS (Pulse Per Second) output or you have a separate PPS signal available, you can configure the serial port to use along with some other settings here.

如果您的GPS接收器支援PPS （每秒脈衝）輸出，或者您有單獨的PPS訊號可用，您可以在此處配置要使用的串口以及其他一些設定。
