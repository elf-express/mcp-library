# Diagnostics｜診斷

> 章節：[System](<000 目錄.md#c-11>)

## Activity｜活動

The activity module shows current active processes and their details, you can search within the list of activities, fetch general information (like load averages, number of processes, etc.) using the info button in the footer of the grid.

活動模組顯示當前活動進程及其詳細信息，您可以在活動列表中進行搜索，使用網格底部的 info 按鈕獲取一般信息（如負載平均值、進程數等）。

---

|   |   |
| --- | --- |
| PID | The process id of this process<br>此進程的進程 ID |
| USERNAME | Username executed this process<br>執行此進程的使用者名稱 |
| PRI | Current priority of the process<br>目前流程優先級 |
| NICE | NICE is the [nice](https://en.wikipedia.org/wiki/Nice_\(Unix\)) amount (in the range -20 to 20)<br>NICE是 [nice](https://en.wikipedia.org/wiki/Nice_\(Unix\) ) 數量（範圍為 -20 到 20） |
| SIZE | Total size of the process (text, data, and stack)<br>進程總大小（文字、資料與堆疊） |
| RES | Current amount of resident memory, RAM currently in use by the process<br>目前駐留內存量， RAM當前進程正在使用 |
| C | is the processor number on which the process is executing (visible only on SMP systems)<br>是進程正在執行的處理器編號（僅在SMP系統上可見） |
| TIME | The number of system and user cpu seconds that the process has used<br>進程已使用的系統與使用者 CPU 秒數 |
| WCPU | Weighted cpu percentage<br>加權 CPU 使用率 |
| COMMAND | Command string<br>指令字串 |

## Services｜服務

The services page shows the configured services and status, you can stop/start/restart all of them here.

服務頁面顯示已設定的服務及其狀態，您可以在這裡停止/啟動/重新啟動所有服務。
