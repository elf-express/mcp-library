# 23.4 Series｜23.4系列

> 章節：[Releases](<000 目錄.md#c-1>) › [Business Edition](<000 目錄.md#c-3>)

The OPNsense business edition transitions to this 23.4 release including Unbound DNS statistics, PHP 8.1, assorted FreeBSD networking updates, further MVC/API conversions, WireGuard kernel module plugin plus much more.

OPNsense 商業版過渡到此23.4版本，包括 Unbound DNS統計資訊、 PHP 8.1各種 FreeBSD 網路更新、進一步的MVC/API轉換、WireGuard 核心模組外掛程式等等。

Please make sure to read the migration notes before upgrading.

升級前請務必閱讀遷移說明。

Migration notes, known issues and limitations:

遷移說明、已知問題與限制：

-   StrongSwan IPsec configuration now uses the preferred swanctl.conf instead of the deprecated ipsec.conf which could lead to connectivity issues in ambiguous cases.  
    StrongSwan IPsec 設定現在使用首選的 swanctl.conf 而不是已棄用的 ipsec.conf，這可能會導致在不明確的情況下出現連線問題。
    
-   The new IPsec connections pages and API create an independent set of connections following the design of swanctl.conf. Legacy tunnel settings cannot be managed from the API and are not migrated.  
    新的 IPsec 連線頁面和API依照 swanctl.conf 的設計建立了一組獨立的連線。傳統的隧道設定無法透過API進行管理，也不會被遷移。
    
-   Rate limiting was removed from the captive portal which was set to 250 connections by the same IP to the captive portal itself. This can be easily replaced by a manual firewall rule with advanced options set, e.g. “Max established” set to 250 with destination “This Firewall”（此防火牆）.  
    已移除強制門戶的速率限制，此限制先前由相同規則IP設定為 250 個連線。這可以透過手動設定防火牆規則輕鬆替代，例如將「最大建立連線數」設定為 250，目標位址為“This Firewall”（此防火牆）並設定進階選項。
