# Included software｜附軟體

> 章節：[Installation and setup](<000 目錄.md#c-5>)

OPNsense® comes with a lot of features included in the base system, for some situations you may need additional software, which is either provided via a plugin or only as a binary package (without user interface).

OPNsense® 的基本系統中包含許多功能，在某些情況下，您可能需要額外的軟體，這些軟體要么透過插件提供，要么僅作為二進位套件（沒有使用者介面）提供。

This chapter aims to provide some details on the components included in the system, where to find them and how to install them when not installed by default.

本章旨在提供有關係統中包含的組件的一些詳細資訊、在哪裡可以找到它們以及默認情況下未安裝它們時如何安裝它們。

## The operating system｜作業系統

The basic ([FreeBSD](https://www.freebsd.org/)) system contains a kernel and a base package, which provide the bare essentials for the system to be able to boot and do its work.

基本（[FreeBSD](https://www.freebsd.org/)）系統包含一個核心和一個基礎包，它們為系統提供了啟動和工作的基本要素。

Both components are updated using `opnsense-update`, which is explained in more detail [here](<75 OPNsense 工具.md#opnsense-update>).

這兩個組件均使用`opnsense-update`進行更新，[此處](<75 OPNsense 工具.md#opnsense-update>)對此進行了更詳細的解釋。

## Plugins｜外掛

Plugins are packages offered by OPNsense®, which can be installed directly via the user interface and often come with setup options accessible for the end-user.

插件是 OPNsense® 提供的軟體包，可直接透過使用者介面安裝，並且通常附帶最終用戶可以存取的設定選項。

Since OPNsense® is a community-driven project, the amount of (community/commercial) support available on these plugins can be different.

由於 OPNsense® 是一個由社區驅動的項目，因此這些插件提供的（社區/商業）支援量可能有所不同。

Note

注意事項

The plugin repository is maintained by the project, when plugins are not kept up to date by its maintainer, they will be removed at some point in time. (a good example for such a plugin would be if one requires python 2 and we stop shipping it due to upstream deprecation)

插件儲存庫由專案維護，當插件未由其維護者保持最新時，它們將在某個時間點被刪除。 （此類插件的一個很好的例子是，如果需要 python 2，但我們由於上游棄用而停止交付它）

## Packages (pkg)｜包裝（包包）

Binary software is installed using pkg, which uses our software repository (available via multiple mirrors). All installed software can be found via the user interface System -> Firmware ->Packages, but in some situations people want to install additional software via the command line of the machine itself.

二進位軟體使用 pkg 安裝，它使用我們的軟體儲存庫（可透過多個鏡像取得）。所有已安裝的軟體都可以透過使用者介面「系統」->「韌體」->「軟體包」找到，但在某些情況下，人們希望透過機器本身的命令列安裝其他軟體。

To find a full list of all software available, you can use the following command:

要查找所有可用軟體的完整列表，您可以使用以下命令：

```
pkg rquery '%n (%v)'
```

For example, if you would like to install the gnu [nano](https://www.nano-editor.org/) editor, you can do so using the following command:

例如，如果您想安裝 gnu [nano](https://www.nano-editor.org/) 編輯器，可以使用下列命令來安裝：

```
pkg install nano
```

Note

注意事項

OPNsense® is a firewall distribution, we aim to keep our footprint as small as possible. This means that we don’t build all the software available in the world. If you need a specific package for your use-case, you could always ask via a support ticket on [GitHub](https://github.com/opnsense/tools/issues), but note that packages not used by our core system or a supported plugin would not be guaranteed in the future (build contents may change over time).

OPNsense® 是一個防火牆發行版，我們的目標是讓我們的足跡盡可能小。這意味著我們不會建構世界上所有可用的軟體。如果您需要適合您的用例的特定包，您可以隨時透過 [GitHub](https://github.com/opnsense/tools/issues) 上的支援票詢問，但請注意，我們的核心系統或支援的插件未使用的套件將來不會得到保證（建置內容可能會隨著時間的推移而改變）。

Warning

警告

Adding (FreeBSD, ..) repositories in `/usr/local/etc/pkg/repos/` manually is not supported and usually lead to unexpected issues. Before reporting any type of issue with such setups, we kindly ask you to revert to a standard setup first.

不支援在`/usr/local/etc/pkg/repos/`中手動新增（FreeBSD，..）儲存庫，並且通常會導致意外問題。在報告此類設定的任何類型問題之前，我們懇請您先恢復到標準設定。

## The ports tree｜連接埠樹

In case you are using software which is not supplied by us, you can always build these packages yourself. It’s best to use our build system to facilitate this, you can do so using the following commands

如果您使用的軟體不是我們提供的，您始終可以自己建立這些軟體包。最好使用我們的建置系統來促進這一點，您可以使用以下命令來完成此操作

```bash
opnsense-code ports
cd /usr/ports/your/port
make install
```

To update a package, the following command can be used instead:

若要更新軟體包，可以使用以下命令：

```bash
opnsense-code ports
cd /usr/ports/your/port
make reinstall
```

It might be necessary for some ports to also install the source tree:

某些連接埠可能還需要安裝來源樹：

```
opnsense-code src
```

Note

注意事項

There are a lot of resources available about building ports packages, such as [https://www.freebsd.org/ports/](https://www.freebsd.org/ports/) and the pointers in our documentation and tools. We consider building custom software a feature not usable for beginners, before creating support tickets, make sure you have the necessary skillsets needed to perform such tasks.

有許多關於建立 ports 套件的資源，例如 [https://www.freebsd.org/ports/](https://www.freebsd.org/ports/) 以及我們文件和工具中的指標。我們認為建立自訂軟體是初學者無法使用的功能，在創建支援票證之前，請確保您擁有執行此類任務所需的必要技能。
