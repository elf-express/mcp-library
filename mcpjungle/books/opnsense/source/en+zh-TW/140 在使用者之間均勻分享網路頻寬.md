# Share internet bandwidth amongst users evenly｜在使用者之間均勻分享網路頻寬

> 章節：[Firewall](<000 目錄.md#c-26>) › [Traffic Shaping](<000 目錄.md#c-29>) › [Configuration / How-tos](<000 目錄.md#c-30>)

For this example we presume an internet connection of 10 Mbps Download and 1 Mbps Upload that we want to share evenly between all users.

對於此範例，我們假設網路連線為 10 Mbps 下載和 1 Mbps 上傳，我們希望在所有使用者之間均勻共用。

[![](<../images/5edbe2b6-nwdiag-3a3b295df95f5f47b05bd5247ff3374f6.png>)](https://docs.opnsense.org/_images/nwdiag-3a3b295df95f5f47b05bd5247ff3374f6471bbc9.png)

Shaping bandwidth evenly sample

均勻取樣頻寬整形

To start go to Firewall ‣ Shaper ‣ Pipes.

首先前往 Firewall ‣ Shaper ‣ Pipes。

## Step 1 - Create Upload and Download Pipes｜步驟 1 - 建立上傳和下載管道

On the **Pipes** tab click the **+** button in the lower right corner. An empty **Edit Pipe** screen will popup.

在 **管道**標籤上，按一下右下角的**+**按鈕。將彈出一個空的**編輯管道**螢幕。

Create Pipe For Upload

建立上傳管道

|   |   |   |
| --- | --- | --- |
| **enabled**<br>**啟用** | Checked<br>已檢查 | *Check to enable the pipe*<br>*檢查以啟用管道* |
| **bandwidth**<br>**頻寬** | 1 | *Numeric value of the desired bandwidth*<br>*所需頻寬的數值* |
| **bandwidth Metric**<br>**頻寬指標** | Mbit/s<br>兆位元/秒 | *Metric to use with the numeric value*<br>*與數值一起使用的量測* |
| **mask**<br>**面具** | empty<br>空 | *Select destination to share the bandwidth*<br>*選擇共用頻寬的目的地* |
| **description**<br>**描述** | PipeUp-1Mbps | *Free field, enter something descriptive*<br>*自由字段，輸入描述性內容* |

Create Pipe For Download

建立下載管道

|   |   |   |
| --- | --- | --- |
| **enabled**<br>**啟用** | Checked<br>已檢查 | *Check to enable the pipe*<br>*檢查以啟用管道* |
| **bandwidth**<br>**頻寬** | 10 | *Numeric value of the desired bandwidth*<br>10 *所需頻寬的數值* |
| **bandwidth Metric**<br>**頻寬指標** | Mbit/s<br>兆位元/秒 | *Metric to use with the numeric value*<br>*與數值一起使用的量測* |
| **mask**<br>**面具** | empty<br>空 | *Select destination to share the bandwidth*<br>*選擇共用頻寬的目的地* |
| **description**<br>**描述** | PipeDown-10Mbps | *Free field, enter something descriptive*<br>*自由字段，輸入描述性內容* |

## Step 2 - Create a Queues｜第 2 步 - 建立隊列

On the **Queues** tab click the **+** button in the lower right corner. An empty **Edit queue** screen will popup.

在 **佇列**標籤上，按一下右下角的**+**按鈕。將彈出一個空的**編輯隊列**螢幕。

Create Queue for Upload

建立上傳隊列

|   |   |   |
| --- | --- | --- |
| **enabled**<br>**啟用** | Checked<br>已檢查 | *Check to enable the pipe*<br>*檢查以啟用管道* |
| **pipe**<br>**管道** | PipeUp-1Mbps | *Select our Pipe*<br>*選擇我們的管道* |
| **weight**<br>**重量** | 100 | *Weight to use with the numeric value*<br>100 *與數值一起使用的權重* |
| **mask**<br>**面具** | source<br>來源 | *Every source creates a match*<br>*每個來源都會創建一個匹配* |
| **description**<br>**描述** | QueueUp-1Mbps | *Free field, enter something descriptive*<br>*自由字段，輸入描述性內容* |

Create Queue for Download

建立下載隊列

|   |   |   |
| --- | --- | --- |
| **enabled**<br>**啟用** | Checked<br>已檢查 | *Check to enable the pipe*<br>*檢查以啟用管道* |
| **pipe**<br>**管道** | PipeDown-10Mbps | *Select our Pipe*<br>*選擇我們的管道* |
| **weight**<br>**重量** | 100 | *Weight to use with the numeric value*<br>100 *與數值一起使用的權重* |
| **mask**<br>**面具** | destination<br>目的地 | *Every source creates a match*<br>*每個來源都會創建一個匹配* |
| **description**<br>**描述** | QueueDown-10Mbps<br>佇列下降-10Mbps | *Free field, enter something descriptive*<br>*自由字段，輸入描述性內容* |

## Step 3 - Create Rules｜第 3 步 - 建立規則

On the **Rules** tab click the **+** button in the lower right corner. An empty **Edit rule** screen will popup.

在 **規則**標籤上，按一下右下角的**+**按鈕。將彈出一個空的**編輯規則**螢幕。

Create a rule for traffic directed towards the internet (Upload).

為定向到互聯網（上傳）的流量建立規則。

|   |   |   |
| --- | --- | --- |
| **sequence**<br>**序列** | 11 | *Auto generated number, overwrite only when needed*<br>11 *自動產生編號，僅在需要時覆寫* |
| **interface**<br>**介面** | WAN | *Select the interface connected to the internet*<br>*選擇連接到網際網路的介面* |
| **proto**<br>**原型** | ip | *Select the protocol, IP in our example*<br>*選擇協議，在我們的範例中為IP* |
| **source**<br>**來源** | 192.168.1.0/24 | *The source IP to shape, select the LAN network*<br>*要整形的源IP，選擇LAN網絡* |
| **src-port**<br>**來源端口** | any<br>任何 | *The source port to shape, leave on any*<br>*要塑造的來源端口，保留任何* |
| **destination**<br>**目的地** | any<br>任何 | *The destination to shape, leave on any*<br>*目的地要塑造，留下任意* |
| **dst-port**<br>**目標連接埠** | any<br>任何 | *Use any of the destination port if static*<br>*如果是靜態的，則使用任何目標連接埠* |
| **target**<br>**目標** | QueueUp-1Mbps | *Select the Upload 1Mbps Queue*<br>*選擇上傳1Mbps佇列* |
| **description**<br>**描述** | ShapeUpload<br>形狀上傳 | *Enter a descriptive name*<br>*輸入描述性名稱* |

Create a rule for traffic coming from the internet (Download).

為來自 Internet 的流量建立規則（下載）。

|   |   |   |
| --- | --- | --- |
| **sequence**<br>**序列** | 21 | *Auto generated number, overwrite only when needed*<br>21 *自動產生編號，僅在需要時覆寫* |
| **interface**<br>**介面** | WAN | *Select the interface connected to the internet*<br>*選擇連接到網際網路的介面* |
| **proto**<br>**原型** | ip | *Select the protocol, IP in our example*<br>*選擇協議，在我們的範例中為IP* |
| **source**<br>**來源** | any<br>任何 | *The source address, leave on any*<br>*來源位址，任意留* |
| **src-port**<br>**來源端口** | any<br>任何 | *The source port to shape, leave on any*<br>*要塑造的來源端口，保留任何* |
| **destination**<br>**目的地** | 192.168.1.0/24 | *The destination IP to shape, select LAN network*<br>*要塑造的目的地IP，選擇LAN網絡* |
| **dst-port**<br>**目標端口** | any<br>任何 | *The destination port to shape, leave on any*<br>*目的港自行塑造，任意留任* |
| **target**<br>**目標** | QueueDown-10Mbps<br>佇列下降-10Mbps | *Select the Download 10 Mbps Queue*<br>*選擇下載 10 Mbps 佇列* |
| **description**<br>**描述** | ShapeDownload<br>形狀下載 | *Enter a descriptive name*<br>*輸入描述性名稱* |

Now press ![apply](<../images/ca819e9a-applybtn.png>) to activate the traffic shaping rules.

現在按![apply](<../images/ca819e9a-applybtn.png>)啟動流量整形規則。
