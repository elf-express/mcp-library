# WireGuard ProtonVPN Road Warrior Setup｜WireGuard ProtonVPN Road Warrior 設定

> 章節：[Virtual Private Networking](<000 目錄.md#c-32>) › [Wireguard](<000 目錄.md#c-33>) › [Examples](<000 目錄.md#c-34>)

## Introduction｜介紹

ProtonVPN is a cloud-based VPN provider, offering secure tunneling with respect to privacy. To set up a WireGuard VPN to ProtonVPN we assume you are familiar with the concepts of WireGuard that you have read the basic howto [WireGuard Road Warrior Setup](<156 WireGuard Road Warrior 設置.md>).

ProtonVPN 是一家基於雲端的 VPN 供應商，提供尊重隱私的安全隧道。要設定 WireGuard VPN 到 ProtonVPN，我們假設您熟悉 WireGuard 的概念，並且您已閱讀基本操作方法 [WireGuard Road Warrior 設定](<156 WireGuard Road Warrior 設置.md>)。

## Step 1 - Download ProtonVPN configuration｜步驟 1 - 下載 ProtonVPN 配置

The configuration is available in the ProtonVPN website. The [landing page](https://account.protonvpn.com/dashboard) appears after signing in. Click on Downloads from the left hand panel or go to the [downloads page](https://account.protonvpn.com/downloads) and scroll down to the [WireGuard configuration](https://account.protonvpn.com/downloads#wireguard-configuration)

此配置可在 ProtonVPN 網站上找到。登入後會出現[登陸頁面](https://account.protonvpn.com/dashboard)。點擊左側面板中的「下載」或前往[下載頁面](https://account.protonvpn.com/downloads)並向下捲動至[WireGuard設定](https://account.protonvpn.com/downloads#wireguard-configuration)

The existing WireGuard configurations appear first with their expiration dates and following are the options to generate new ones.

現有的 WireGuard 配置首先顯示其到期日期，然後是產生新配置的選項。

[![../../_images/proton_wireguard_configuration.png](<../images/08c4019a-proton_wireguard_configuration.png>)](https://docs.opnsense.org/_images/proton_wireguard_configuration.png)

-   Select a name for the generated configuration  
    為產生的配置選擇一個名稱
    

Note

筆記

If a name is not provided a unique ID will be generated by ProtonVPN

如果未提供名稱，ProtonVPN 將產生唯一的ID

-   Select Router as a platform  
    選擇路由器作為平台
    
-   Select VPN options  
    選擇VPN選項
    
    -   There are 3 options for NetShield blocker filtering  
        NetShield 攔截器過濾有 3 個選項
        
        -   No filtering  
            無濾鏡
            
        -   Block malware  
            封鎖惡意軟體
            
        -   Block malware, ads and trackers  
            封鎖惡意軟體、廣告和追蹤器
            
    -   There are also options to enable Moderate NAT, NAT-PMP (Port Forwarding) and VPN accelerator as well. The features are documented in the ProtonVPN website.  
        還有一些選項可以啟用中等NAT, NAT-PMP（連接埠轉送）和VPN加速器。這些功能記錄在 ProtonVPN 網站中。
        
    -   Pick the options that satisfy your requirements and move on to the next section.  
        選擇滿足您要求的選項，然後繼續下一部分。
        
-   Select a server to connect to  
    選擇要連接的伺服器
    
    -   ProtonVPN proposes the best server or allows the user to select manually.  
        ProtonVPN 會建議最佳伺服器或允許使用者手動選擇。
        
    -   When selecting manually there are 2 main choices:  
        手動選擇時有2個主要選擇：
        
        -   Standard vs Secure Core configuration  
            標準與安全核心配置
            
        -   Exit country  
            出境國家
            
    -   Pick the one that satisfies your requirements and click on Create to generate the configuration.  
        選擇滿足您要求的一個，然後按一下「建立」以產生配置。
        
    -   Upon successful completion a window like the following will appear on the screen.  
        成功完成後，螢幕上將出現如下所示的視窗。

創建配置後私鑰就會消失，因此必須儲存它。它將在以下部分中用於生成公鑰。成功配置需要兩者。

**不要重複使用這些範例中的私鑰**

## Step 2 - Generate public key from private key｜步驟 2 - 從私鑰產生公鑰

ProtonVPN, unlike Mullvad or other WG implementations, only provides a private key. The private key appears briefly when generating the configuration in the web UI. The public key will be derived from the private key with the “wg pubkey” command.

ProtonVPN 與 Mulvad 或其他WG 實作不同，僅提供私鑰。在 Web UI 中產生配置時，私鑰會短暫出現。公鑰將透過“wg pubkey”指令從私鑰派生。

Windows

窗戶

```
echo wgPrivateKey | wg pubkey
```

Linux

```
wg pubkey < wgPrivateKey
```

## Step 3 - Setup WireGuard Instance｜第 3 步 - 設定 WireGuard 實例

-   Go to VPN ‣ WireGuard ‣ Settings ‣ Instances  
    前往VPN‣WireGuard‣設定‣實例
    
-   Click **+** to add a new Instance configuration  
    點選 ****** 新增新的實例配置
    
-   Turn on “advanced mode”  
    開啟“進階模式”
    
-   Configure the Instance from the downloaded ProtonVPN configuration as follows (if an option is not mentioned below, leave it as the default):  
    從下載的 ProtonVPN 設定中設定實例，如下所示（如果下面未提及選項，請將其保留為預設值）：
    
    > |   |   |
    > | --- | --- |
    > | **Enabled**<br>**啟用** | *Checked*<br>*已檢查* |
    > | **Name**<br>**姓名** | *Call it whatever you want (eg* `ProtonVPN-ExitCountry` *)*<br>*隨心所欲地稱呼它（例如* `ProtonVPN-ExitCountry` *）* |
    > | **Public Key**<br>**公鑰** | *Insert the derived public key from the previous step*<br>*插入上一個步驟所衍生的公鑰* |
    > | **Private Key**<br>**私鑰** | *Insert the* `PrivateKey` *field from the* `[Interface]` *section*<br>*從* `[Interface]` *部分*插入* `PrivateKey` *字段 |
    > | **Listen Port**<br>**監聽埠** | *51820 or a higher numbered unique port*<br>*51820 或更高編號的唯一連接埠* |
    > | **MTU** | *Needs to be 80 bytes shorter than normal MTU. Default 1420*<br>*需要比正常的MTU短80個位元組。預設 1420* |
    > | **DNS Server**<br>**DNS伺服器** | *Insert the* `DNS` *field from the* `[Interface]` *section as is (without subnet mask)*<br>*按原樣插入* `DNS` *來自* `[Interface]` *部分的欄位（無子網路遮罩）* |
    > | **Tunnel Address**<br>**隧道位址** | *Insert the* `Address` *field from the* `[Interface]` *section\` in CIDR format, eg 10.2.0.2/32*<br>*以 CIDR 格式插入* `[Interface]` *部分\`中的* `Address` *字段，例如10.2.0.2/32* |
    > | **Peers**<br>**同行** | *Leave blank for now*<br>*暫時留空* |
    > | **Disable Routes**<br>**停用路線** | *Checked*<br>*已檢查* |
    > | **Gateway**<br>**網關** | *Insert the same address as in the DNS Server field above*<br>*插入與上面DNS伺服器欄位中相同的位址* |
    
-   **Save** the Instance configuration, and then click **Apply**  
    **儲存**實例配置，然後按一下**套用**
    

## Step 4 - Configure the peer｜第 4 步 - 配置對等點

-   Go to VPN ‣ WireGuard ‣ Settings ‣ Peers  
    前往 VPN ‣ WireGuard ‣ 設定 ‣ 對等點
    
-   Click **+** to add a new Peer  
    點選 ****** 新增對等點
    
-   Configure the Peer from the downloaded ProtonVPN configuration as follows (if an option is not mentioned below, leave it as the default):  
    從下載的 ProtonVPN 設定中設定對等點，如下所示（如果下方未提及選項，請將其保留為預設值）：
    
    > |   |   |
    > | --- | --- |
    > | **Enabled**<br>**啟用** | *Checked*<br>*已檢查* |
    > | **Name**<br>**姓名** | *Call it whatever you want (eg* `ProtonVPN_Location` *)*<br>*隨心所欲地稱呼它（例如* `ProtonVPN_Location` *）* |
    > | **Public Key**<br>**公鑰** | *Insert the* `PublicKey` *field from the* `[Peer]` *section*<br>*插入* `PublicKey` *來自* `[Peer]` *部分*的欄位 |
    > | **Allowed IPs**<br>**允許的 IP** | *0.0.0.0/0* |
    > | **Endpoint Address**<br>**端點位址** | *Insert the IP address from the* `Endpoint` *field in the* `[Peer]` *section*<br>*將* `Endpoint` *欄位中的IP位址插入* `[Peer]` *部分* |
    > | **Endpoint Port**<br>**端點連接埠** | *Insert the port number from the* `Endpoint` *field in the* `[Peer]` *section*<br>*將連接埠號碼從* `Endpoint` *欄位插入* `[Peer]` *部分* |
    > | **Instances**<br>**實例** | *Select the instance configured in the previous step*<br>*選擇上一個步驟中配置的實例* |
    > | **Keepalive**<br>**保持活力** | *25* |
    
-   **Save** the Peer configuration, and then click **Apply**  
    **儲存**對等配置，然後按一下**套用**
    

Note

筆記

The UI for configuring the Instances and Peers changed with OPNsense version 23.7.9 so some of the fields may be in different places.

用於配置實例和對等點的UI隨 OPNsense 版本23.7.9更改，因此某些欄位可能位於不同的位置。

如果尚未打開，請在 VPN ‣ WireGuard ‣ 設定 ‣ 常規下開啟 WireGuard

## ProtonVPN DNS leaks｜ProtonVPN DNS 洩露

Since ProtonVPN provides a DNS server an extra firewall rule may be required to route the DNS traffic to the WireGuard gateway.

由於 ProtonVPN 提供 DNS 伺服器，可能需要額外的防火牆規則才能將 DNS 流量路由到 WireGuard 閘道。

-   Go to Firewall ‣ Rules ‣ \[Name of interface for network in which hosts/network resides, eg LAN for LAN hosts\]  
    前往防火牆 ‣ 規則 ‣ \[主機/網路所在網路的介面名稱，例如 LAN 表示 LAN 主機\]
    
-   Click **Add** to add a new rule  
    按一下 **新增** 新增規則
    
-   Configure the rule as follows (if an option is not mentioned below, leave it as the default):  
    配置規則如下（如果下面未提及選項，請將其保留為預設值）：
    
    > |   |   |
    > | --- | --- |
    > | **Action**<br>**行動** | *Pass*<br>*透過* |
    > | **Quick**<br>**快** | *Checked*<br>*已檢查* |
    > | **Interface**<br>**介面** | *Whatever interface you are configuring the rule on*<br>*無論您在哪個介面上設定規則* |
    > | **Direction**<br>**方向** | *in*<br>*在* |
    > | **TCP/IP Version**<br>**TCP/IP版本** | *IPv4* |
    > | **Protocol**<br>**協議** | *TCP/UDP* |
    > | **Source / Invert**<br>**來源/反相** | *Unchecked*<br>*未選取* |
    > | **Source**<br>**來源** | *IP of your DNS server*<br>*您的DNS伺服器的IP* |
    > | **Destination / Invert**<br>**目的地/反轉** | *Checked*<br>*已檢查* |
    > | **Destination**<br>**目的地** | *Select the* `RFC1918_Networks` *Alias you created above in the dropdown*<br>*選擇* `RFC1918_Networks` *您在上面的下拉清單中建立的別名* |
    > | **Destination port range**<br>**目標埠範圍** | *DNS - DNS* |
    > | **Description**<br>**描述** | *Add one if you wish to*<br>*如果您願意，請新增一個* |
    > | **Gateway**<br>**網關** | *Select the WireGuard gateway created according to the selective routing how-to page (eg* `WAN_ProtonVPN` *)*<br>*選擇根據選擇性路由操作指南頁面建立的WireGuard網關（例如* `WAN_ProtonVPN` *）* |
    
-   **Save** the rule, and then click **Apply Changes**  
    **儲存**規則，然後按一下**套用變更**
    
-   Then make sure that the new rule is **above** any other rule on the interface that would otherwise interfere with its operation. For example, you want your new rule to be above the “Default allow LAN to any rule”  
    然後確保新規則**高於**介面上任何其他規則，否則會幹擾其操作。例如，您希望新規則高於“預設允許 LAN 任何規則”
    

In layman terms if the DNS server makes any requests to a non-local address it will go through the VPN gateway.

通俗地說，如果DNS伺服器向非本地位址發出任何請求，它將通過VPN網關。
