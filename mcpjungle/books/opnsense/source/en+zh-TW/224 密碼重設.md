# Password reset｜密碼重設

> 章節：[Troubleshooting](<000 目錄.md#c-50>) › [Topics](<000 目錄.md#c-51>)

Sometimes people lose their passwords, in which case it can be practical to reset the root password without performing a reinstall.

有時人們會忘記密碼，在這種情況下，無需重新安裝系統即可重設 root 密碼可能是一種可行的方法。

This guide describes step by step how to reset the root password.

本指南將一步步介紹如何重置root密碼。

Note

筆記

You can also use the installer to reset the password, use the `Password Reset - Recover Installation` option in the installer after the keymap selection.

您也可以使用安裝程式重設密碼，在選擇鍵盤映射後，使用安裝程式中的`Password Reset - Recover Installation`選項。

## Step 1 : power｜步驟 1：電源

Since you need to influence the boot process to reset the password, you should start with powering off the (virtual) device.

由於你需要影響啟動過程來重置密碼，你應該先關閉（虛擬）設備的電源。

## Step 2 : console｜步驟 2：控制台

Make sure you are able to access the (virtual) console, in case it’s a physical machine you might want to connect a monitor and keyboard, when it’s an appliance with serial access, make sure to connect to the serial/usb port using an application like putty.

確保能夠存取（虛擬）控制台；如果是實體機，您可能需要連接顯示器和鍵盤；如果是具有序列存取功能的設備，請確保使用 PuTTY 等應用程式連接到串行/USB 連接埠。

Tip

提示

When using devices from the OPNsense shop ([https://shop.opnsense.com](https://shop.opnsense.com/)), usually there’s a mini-usb to serial cable included in the box, the [Serial Console connectivity](<67 串行控制台連接.md>) guide will help you with the setup.

使用 OPNsense 商店的設備（[https://shop.opnsense.com](https://shop.opnsense.com/) ）時，包裝盒內通常會附帶一條 mini-USB 轉串口線，[串口控制台連接](<67 串行控制台連接.md>)指南將幫助您進行設定。

## Step 3 : boot single｜步驟 3：啟動單一

Switch the power and wait for the OPNsense splash screen to appear, the choose “Boot \[S\]single User” which should be option 2 in the list. (press 2)

開啟電源，等待 OPNsense 啟動畫面出現，然後選擇「啟動單一使用者」（Boot \[S\]single User），該選項應位於清單中的第二個位置。 （按 2）

## Step 4: password reset｜步驟 4：重設密碼

This stage depends on the type of installation, the root filesystem could either be UFS or ZFS, both requiring different commands to enable modifications in single user mode.

此階段取決於安裝類型，根檔案系統可以是UFS或ZFS ，兩者都需要不同的指令才能在單一使用者模式下進行修改。

For UFS file systems, execute the following command in the shell to enable disk modifications:

對於UFS檔案系統，請在shell中執行以下命令以啟用磁碟修改：

```
/sbin/mount -o rw /
```

When using ZFS, the following commands are required

使用ZFS時，需要以下指令。

```
/sbin/mount -u /
/sbin/zfs mount -a
```

Now the disk can be written to, use the following commands to reset the password and reboot the machine:

現在可以向磁碟寫入資料了，請使用以下命令重設密碼並重新啟動電腦：

```
opnsense-shell password
reboot
```

The opnsense-shell will ask for a confirmation, respond with Y

opnsense-shell 會要求確認，請回覆 Y。
