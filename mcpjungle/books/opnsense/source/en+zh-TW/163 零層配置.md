# Zerotier Configuration｜零層配置

> 章節：[Virtual Private Networking](<000 目錄.md#c-32>) › [Plugin VPN options](<000 目錄.md#c-35>)

Note

筆記

It is strongly recommended that the reader familiarise themselves with the [Zerotier Manual](https://www.zerotier.com/manual.shtml), in order to further understand the concepts behind this plugin.

強烈建議讀者熟悉[Zerotier手冊](https://www.zerotier.com/manual.shtml)，以便進一步理解該插件背後的概念。

## Prerequisites｜先決條件

Firstly, it is important that you have signed up to Zerotier at the [Zerotier Portal](https://my.zerotier.com/). Second, you will need to create at least one network on the portal in order to obtain a Network Id that this plugin uses to **join** this node to the created Zerotier network. This network will become your private network that by default is visible only to your nodes - in other words, other nodes that are on that network can talk to each other, but nothing else can talk to them - they are completely transparent to the internet in general. In effect you are layering a private network over the public internet and all intra-node communication is encrypted and private between them. This is further hinted at by the fact that the assigned IP addresses are normally RFC1918 addresses, i.e., non-routable across the internet.

首先，您必須在[Zerotier Portal](https://my.zerotier.com/)註冊Zerotier。其次，您需要在入口網站上建立至少一個網絡，以獲得該外掛程式用於**加入**該節點到創建的 Zerotier 網路的網路 ID。該網絡將成為您的私有網絡，默認情況下僅對您的節點可見 - 換句話說，該網絡上的其他節點可以相互通信，但沒有其他節點可以與它們通信 - 通常它們對互聯網是完全透明的。實際上，您正在公共互聯網上分層私有網絡，並且它們之間的所有節點內通信都是加密且私有的。分配的 IP 位址通常是 RFC1918 位址，即不可透過網路路由，這一事實進一步暗示了這一點。

Finally, in order to have a fully functioning private VPN between Zerotier nodes, a combination of this plugin plus some configuration on the [portal](https://my.zerotier.com/) **will** be required.

最後，為了在 Zerotier 節點之間建立完全功能的私人 VPN，**需要**結合使用此外掛程式以及在 [portal](https://my.zerotier.com/)上進行一些設定。

## Installation｜安裝

From the Plugins view under `System...Firmware`, install the os-zerotier package. Once the new plugin has been installed, perform a page reload and a new menu item should appear under VPN called Zerotier.

從 `System...Firmware` 下的外掛視圖中，安裝 os-zerotier 軟體包。安裝新插件後，執行頁面重新加載，VPN下應出現一個名為 Zerotier 的新選單項目。

![../../_images/zerotier-0.png](<../images/5e6e296d-zerotier-0.png>)

Clicking on the Zerotier menu item will reveal two further sub-menu items - namely Settings and Overview. Clicking on “Settings”（設定） will present a new view with two named tabs. The first tab is called Settings and the second tab is called Networks. These are further described below.

點擊 Zerotier 選單項目將顯示另外兩個子選單項目 - 即「設定」和「概述」。點選 “Settings”（設定） 將顯示一個帶有兩個命名標籤的新視圖。第一個選項卡稱為“設定”，第二個選項卡稱為“網路”。這些將在下面進一步描述。

![../../_images/zerotier-1.png](<../images/feac51ba-zerotier-1.png>)

## Settings｜設定

This tab controls the overall operation of Zerotier. Anything changed here is applied globally to all defined networks and to the Zerotier service itself.

此標籤控制 Zerotier 的整體操作。此處所做的任何變更都會全域套用至所有定義的網路和 Zerotier 服務本身。

Enabled

啟用

Controls if the service should be running. If it is disabled, then access to the Networks tab will be disabled. If it is enabled, access to the Networks tab will be enabled and the service will also start at boot time.

控制服務是否應該運作。如果停用，則將停用對「網路」標籤的存取。如果啟用，將啟用對「網路」標籤的訪問，並且該服務也將在啟動時啟動。

API Access Token (optional)

API 存取令牌（可選）

This optional entry is for future use and further development of the Zerotier plugin. The API access token can be generated by logging into your [portal](https://my.zerotier.com/) and creating a new API Access Token. When the token has been generated, copy the value into this input box.

此可選條目供 Zerotier 插件的未來使用和進一步開發。可以透過登入您的[入口網站](https://my.zerotier.com/)並建立新的API訪問令牌來產生API存取令牌。產生令牌後，將值複製到此輸入框中。

local.conf settings (optional)

local.conf 設定（可選）

As described in the Zerotier Manual, a local.conf can be created to enable or disable custom node-specific configuration overrides. Further details of permitted options can be found on the [ZeroTier Manual](https://www.zerotier.com/manual.shtml). Please note that the local.conf **must** be a valid JSON document otherwise the service will fail to start.

如 Zerotier 手冊中所述，可以建立 local.conf 來啟用或停用自訂節點特定配置覆蓋。有關允許選項的更多詳細信息，請參閱 [ZeroTier 手冊](https://www.zerotier.com/manual.shtml)。請注意，local.conf **必須**是有效的JSON文檔，否則服務將無法啟動。

## Networks｜網路

This table allows for the creation, modification and deletion of Zerotier networks. Adding a Network here will join your OPNsense installation to the specified Zerotier network.

該表允許建立、修改和刪除 Zerotier 網路。在此處新增網路會將您的 OPNsense 安裝加入指定的 Zerotier 網路。

Note

筆記

Remember, you **will** have to log into the Zerotier [portal](https://my.zerotier.com/), select the network and authorise the node before it can be assigned an IP address (or indeed, talk to other nodes on that network).

請記住，您**必須**必須登入 Zerotier [入口網站](https://my.zerotier.com/)，選擇網路並授權節點，然後才能為其指派 IP 位址（或實際上，與該網路上的其他節點通訊）。

![../../_images/zerotier-2.png](<../images/a3900927-zerotier-2.png>)

Adding a network is quite straight-forward. Simply click on the + symbol key in the following:

新增網路非常簡單。只需點擊以下中的 + 符號鍵：

Network Id

網路編號

This is the 64-bit (16 character hex) address that is generated on the portal when creating a Zerotier network.

這是在建立 Zerotier 網路時在入口網站上產生的 64 位元（16 個字元的十六進位）位址。

Local Description (optional)

本地描述（可選）

You may key in a description here that will help you remember what the network is for. Please note that this field is **not** the same as the name/description of the Zerotier network - it’s simply an aide-mémoire to help you remember what the network is for.

您可以在此輸入描述，幫助您記住網路的用途。請注意，此欄位與 Zerotier 網路的名稱/描述**並非**相同——它只是一個輔助記憶的工具，可幫助您記住該網路的用途。

Adding a network does **not** automatically cause your OPNsense installation to join that network. In order to join that network it **must** be `Enabled` first. Likewise, to remove your OPNsense node from the configured network simply deselect `Enabled`, thus disabling the network.

新增網路**不會**自動導致您的 OPNsense 安裝加入該網路。為了加入該網絡，它**必須**首先是`Enabled`。同樣，要從配置的網路中刪除 OPNsense 節點，只需取消選擇 `Enabled`，從而停用網路。

Once a network has been added and enabled the node **must** be authorised to join the network on the portal. Simply enabling the network on your OPNsense installation marks that node as a member of that network. It now has to request permission to talk to the other nodes on that network. To achieve this, you log into the portal, select the network, find the node address (this can found on the OPNsense Zerotier Overview menu item, under the Information tab) and authorise it by clicking on the “Auth?” check box beside the node. It should go from “red” to “green” to indicate that it has been authorised.

新增並啟用網路後，節點**必須**被授權在入口網站上加入網路。只需在 OPNsense 安裝上啟用網路即可將該節點標記為該網路的成員。現在它必須請求與該網路上的其他節點通訊的權限。為此，您登入門戶，選擇網絡，找到節點地址（可以在「資訊」標籤下的 OPNsense Zerotier 概述選單項目中找到）並透過點擊「Auth?」對其進行授權。節點旁的複選框。它應該從“紅色”變為“綠色”，表明它已獲得授權。

Some final “Network”（網路） operations:

一些最終的“Network”（網路）操作：

If you wish to completely remove the network, simply select the network and click on the `Bin` icon.

如果您想完全刪除網絡，只需選擇網絡並點擊`Bin`圖示即可。

If you wish to edit the network, click on the `Pencil` icon.

如果您想編輯網絡，請按一下 `Pencil` 圖示。

To “clone” the network entry, click on the `Copy` icon. Please ensure you change the Network Id, as having two networks with the same id is an invalid configuration.

若要「複製」網路條目，請按一下 `Copy` 圖示。請確保更改網路 ID，因為兩個網路具有相同的 ID 是無效配置。

For a very quick overview of the Zerotier network information, click on the `Information` icon. A more detailed view of the network can be found under the `Overview...Networks` menu item.

若要快速概覽 Zerotier 網路訊息，請按一下 `Information` 圖示。可以在`Overview...Networks`選單項目下找到更詳細的網路視圖。

## ZeroTier Overview｜ZeroTier 概述

The following 3 tabs reveal Global, Network and Peer information. They can only be viewed if the Zerotier plugin is enabled, so please ensure that the service is enabled first. For information on the terminology used, please refer to the [Zerotier Manual](https://www.zerotier.com/manual.shtml).

以下 3 個標籤顯示全域、網路和對等資訊。只有啟用 Zerotier 外掛程式才能查看它們，因此請確保先啟用該服務。有關所用術語的信息，請參閱[Zerotier 手冊](https://www.zerotier.com/manual.shtml)。

![../../_images/zerotier-3.png](<../images/aaaf5b94-zerotier-3.png>)

## Information Overview｜資訊概覽

This tab shows “Global”（全球的） information concerning the overall health of the Zerotier service.

此標籤顯示 Zerotier 服務整體運作狀況的 “Global”（全球的） 資訊。

## Networks Overview｜網路概覽

This tab shows each configured **and** enabled network that this OPNsense installation has joined. If no networks are enabled, no information is shown.

此標籤顯示此 OPNsense 安裝已加入的每個配置的**和**啟用的網路。如果未啟用網絡，則不會顯示任何資訊。

## Peers Overview｜同行概覽

This tab shows the peers (leaf, planets and moons - Zerotier terminology) known by this node.

此標籤顯示此節點已知的對等點（葉、行星和衛星 - Zerotier 術語）。

## Interface Assignment｜介面分配

Warning

警告

It is **highly** recommended that the interface have auto-assignment of IP addresses turned off **for this particular node only**. You want to give the interface a statically assigned, stable IP address (from the Zerotier network IP range) and not have the Zerotier service auto-assign an IP address. Auto-assignment of IP addresses for nodes is controlled on the [Zerotier Portal](https://my.zerotier.com/)

強烈建議介面具備自動分配功能。 IP 位址已關閉**僅針對此特定節點**。您需要為介面指派一個靜態的、穩定的位址。 IP 位址（來自 Zerotier 網路） IP 範圍）並且不要讓 Zerotier 服務自動分配一個 IP 地址。自動分配 IP 節點位址由[Zerotier Portal]控制。(https://my.zerotier.com/)

After joining a Zerotier network (and authorising it on the portal) you may now wish to assign the Zerotier virtual interface on OPNsense in order to avail of OPNsense functionality such as firewalling and routing (using OSPF for example).

加入 Zerotier 網路（並在入口網站上授權）後，您現在可能想要在 OPNsense 上分配 Zerotier 虛擬接口，以便利用 OPNsense 功能，例如防火牆和路由（例如使用OSPF）。

![../../_images/zerotier-4.png](<../images/ed12f4c1-zerotier-4.png>)

To achieve this:

為了實現這一點：

Click on the `Interfaces` menu item, then click on `Assignments`. There you should discover a new interface currently unassigned that begins with the letters `zt`. Next, click on the `+` symbol to assign it. In this example it creates a new interface called `OPT1`. Clicking on `OPT1` shows the `Enable` and `Lock` options. Check both options.

點選`Interfaces`選單項，然後點選`Assignments`。在那裡您應該會發現一個當前未分配的新接口，該接口以字母 `zt` 開頭。接下來，點選`+`符號進行分配。在此範例中，它建立了一個名為 `OPT1` 的新介面。點選`OPT1` 顯示`Enable` 和`Lock` 選項。檢查兩個選項。

Warning

警告

It is **very** important that `Lock` (i.e., Prevent interface removal) is enabled. This is because Zerotier is a software interface and not guaranteed to be brought “up” whilst the system is booting. It could happen shortly afterwards, hence locking the interface tells OPNsense not to remove it, thinking it’s gone bad.

啟用`Lock`（即防止介面刪除）**非常**重要。這是因為 Zerotier 是一個軟體接口，不能保證在系統啟動時「啟動」。它可能會在不久之後發生，因此鎖定介面告訴 OPNsense 不要刪除它，認為它已經壞了。

Once the new interface has been enabled, it is recommended to change the Description away from `OPT1` to something more descriptive for your needs.

啟用新介面後，建議將描述從`OPT1`更改為更符合您需求的描述性內容。

For `IPv4 Configuration Type`, choose `Static IPv4` then in the appropriate input boxes, key in the IPv4 address that you have assigned to this node via the `Zerotier` portal. Keep the `IPv4 Upstream Gateway` set to `None.`

對於`IPv4 Configuration Type`，選擇`Static IPv4`，然後在對應的輸入框中鍵入您透過`Zerotier`入口網站指派給該節點的IPv4位址。將`IPv4 Upstream Gateway`設定為`None.`

![../../_images/zerotier-5.png](<../images/ecba948e-zerotier-5.png>)

You may choose to do the same for `IPv6 Configuration Type`.

您可以選擇對`IPv6 Configuration Type`執行相同的操作。

Once the interface has been assigned with an IP, it show now also show up on `Firewall` Rules etc…plus any other operations that be done on a interfaces can also be applied to your assigned interface.

一旦為介面分配了IP，它現在也會顯示在`Firewall`規則等上......加上在介面上完成的任何其他操作也可以應用於您指派的介面。
