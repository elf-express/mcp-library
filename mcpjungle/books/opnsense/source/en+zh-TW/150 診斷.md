# Diagnostics｜診斷

> 章節：[Firewall](<000 目錄.md#c-26>)

## Aliases｜別名

Detailed insight into loaded aliases and their content. When an alias has **Statistics** enabled, it will show these too.

詳細了解載入的別名及其內容。當別名啟用**統計**時，它也會顯示這些。

It’s also possible to manually adjust the contents, using **Quick add address** or the delete button.

也可以使用**快速新增地址**或刪除按鈕手動調整內容。

Note

注意事項

When deleting items, keep in mind that the regular update process might put the address (or network) back in, since deletion isn’t persistent.

刪除項目時，請記住，常規更新過程可能會將位址（或網路）放回原處，因為刪除不是持久的。

Tip

提示

Use “Find references” to check if an address would match any configured aliases, which is very practical for debugging purposes, since it will also check if an address fits a network (such as 10.0.0.2 fits in 10.0.0.0/24).

使用「查找引用」來檢查位址是否與任何配置的別名匹配，這對於偵錯目的非常實用，因為它也會檢查位址是否適合網路（例如10.0.0.2適合10.0.0.0/24）。

## Sessions｜會議

Utilises [pftop](https://www.freebsd.org/cgi/man.cgi?query=pftop) to offer a detailed view on the active sessions and their traffic counters.

利用 [pftop](https://www.freebsd.org/cgi/man.cgi?query=pftop) 提供活動會話及其流量計數器的詳細視圖。

The following fields are available in the grid:

網格中提供以下欄位：

---

|   |   |
| --- | --- |
| Dir<br>目錄 | Direction (in `->` or out `<-`)<br>方向（入`->`或出`<-`） |
| Proto<br>原型 | Protocol in question<br>有問題的協定 |
| Source<br>來源 | Source address and port<br>來源位址與連接埠 |
| Gateway<br>網關 | Address and port this session is being translated too using NAT<br>此會話的位址和連接埠也正在使用 NAT 進行轉換 |
| Destination<br>目的地 | Destination address and port<br>目的位址和連接埠 |
| State<br>狀態 | State at source:destination, see tables in States section<br>來源處的狀態：目的地，請參閱「狀態」區段中的表格 |
| Age (sec)<br>年齡（秒） | The number of seconds since the state is created<br>自狀態創建以來的秒數 |
| Expires (sec)<br>過期（秒） | The number of seconds left before the state expires.<br>狀態到期前剩餘的秒數。 |
| Pkts<br>包裹 | Number of packets processed by the state<br>狀態處理的資料包數量 |
| Bytes<br>位元組 | Number of bytes processed by the state<br>狀態處理的位元組數 |
| Rule<br>規則 | Rule this state (most likely) belongs to<br>規則此狀態（最有可能）屬於 |

## States｜州

Insight into the state table (pf), offers the ability to search for specific states and removal. It is also possible to reset all states and/or the source tracking tables from here, especially the state table reset should be used with care as it drops all active connections.

深入了解狀態表 (pf)，提供搜尋特定狀態和刪除的能力。也可以從這裡重置所有狀態和/或來源追蹤表，尤其是狀態表重置應小心使用，因為它會刪除所有活動連線。

If you use the grid search input to look for states, or you used the **Inspect** button on the firewall rules page and opened the state view, you will see a button that allows you to kill all states that matched the criteria.

如果您使用網格搜尋輸入來尋找狀態，或使用防火牆規則頁面上的 **檢查** 按鈕並開啟狀態視圖，您將看到一個按鈕，讓您終止與條件相符的所有狀態。

Note

注意事項

The state table tries to connect states to rules, but since these are referred to by rule number (sequence) in `pf(4)` these aren’t always accurate after changes to the rules.

狀態表嘗試將狀態連接到規則，但由於這些是透過 `pf(4)` 中的規則編號（序列）引用的，因此在規則變更後，這些規則並不總是準確的。

The following fields are available in the grid:

網格中提供以下欄位：

---

|   |   |
| --- | --- |
| State id<br>州 ID | Unique internal identifier describing the state and the origin (creator)<br>描述狀態和起源（創建者）的唯一內部識別碼 |
| Int<br>國際 | Bound to which interface, by default this is all unless ” Bind states to interface” is set in Firewall->Settings->Advanced<br>綁定到哪個接口，預設情況下都是這樣，除非在防火牆->設定->高級中設定了「將狀態綁定到接口」 |
| Dir<br>目錄 | Direction (in `->` or out `<-`)<br>方向（入`->`或出`<-`） |
| Proto<br>原型 | Protocol in question<br>有問題的協定 |
| Source<br>來源 | Source address and port<br>來源位址與連接埠 |
| Nat<br>納特 | Address and port this session is being translated too using NAT<br>此會話的位址和連接埠也正在使用 NAT 進行轉換 |
| Destination<br>目的地 | Destination address and port<br>目的位址和連接埠 |
| State<br>狀態 | State at source:destination, see next tables for lists of states and their explanations available<br>來源處的狀態：目的地，請參閱下表以取得狀態清單及其可用說明 |
| Rule<br>規則 | Rule this state (most likely) belongs to<br>規則此狀態（最有可能）屬於 |
| Command<br>指令 | Button to drop a specific state (State id)<br>用於刪除特定狀態（狀態 ID）的按鈕 |

## Statistics｜統計數據

Various detailed statistics gathered from [pfctl](https://www.freebsd.org/cgi/man.cgi?query=pfctl), such as packet counters per interface, memory limits, configured timeouts and detailed active rules.

從 [pfctl](https://www.freebsd.org/cgi/man.cgi?query=pfctl) 收集的各種詳細統計數據，例如每個介面的資料包計數器、記憶體限制、配置的逾時和詳細的活動規則。
