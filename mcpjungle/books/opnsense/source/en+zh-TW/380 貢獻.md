# Contribute｜貢獻

OPNsense is an open source community project that depends on your contributions for its continuing development & success.

OPNsense 是一個開源社群項目，其持續發展和成功取決於您的貢獻。

There are plenty of opportunities to contribute and help OPNsense reach its goal of becoming the most widely used open source security & firewall platform. Financial contributions are always welcome and will allow us to develop parts of the system that may otherwise stay untouched.

有許多機會做出貢獻並幫助 OPNsense 實現成為最廣泛使用的開源安全和防火牆平台的目標。財政捐助總是受歡迎的，這將使我們能夠開發系統中原本可能保持不變的部分。

The OPNsense core team wants to thank everyone who contributed already.

OPNsense 核心團隊要感謝所有做出貢獻的人。

---

## Financially｜財務上

“*An open source project can only thrive by the community around it.*” We are grateful of all the kind words and support the users of OPNsense are giving us.

「*開源專案只有在其周圍的社區的支持下才能蓬勃發展。*」我們感謝 OPNsense 用戶給予我們的所有善意的話語和支持。

Frequently users ask us how they can contribute to the project. To make the software better we need your involvement in testing and providing feedback and if you can spare a few bucks that would be great.

用戶經常詢問我們他們如何為該專案做出貢獻。為了使軟體變得更好，我們需要您參與測試並提供回饋，如果您能花一些錢那就太好了。

---

### Donations｜捐款

To enable us to continue development and keep on improving the project you can contribute by donating to the project, this a simple non recurring - no strings attached - way of supporting the project. Any amount will be gratefully accepted!

為了使我們能夠繼續開發並不斷改進該項目，您可以透過向該項目捐款來做出貢獻，這是一種簡單的非經常性（無附加條件）支持該項目的方式。任何金額都將感激地接受！

  

---

### Partner program｜合作夥伴計劃

The OPNsense project offers a partner program where businesses receive project benefits while supporting the project financially.

OPNsense 專案提供了一個合作夥伴計劃，企業可以在為專案提供財務支援的同時獲得專案效益。

Main benefits include:

主要好處包括：

-   Listing on our [OPNsense partner page](https://opnsense.org/partners/)  
    列在我們的 [OPNsense 合作夥伴頁面](https://opnsense.org/partners/)
    
-   Access to the core team  
    接觸核心團隊
    

To get enlisted as partner of the OPNsense project means a minimum annual investment of € 2500.Partners that made an exceptional contribution to the project are assigned the Platinum Partner status.

要成為 OPNsense 計畫的合作夥伴，每年至少投資 2500 歐元。為此專案做出傑出貢獻的合作夥伴將授予白金合作夥伴身分。

## Development｜發展

Contributing to the ongoing development of OPNsense can be done by:

可以透過以下方式為 OPNsense 的持續開發做出貢獻：

-   Testing a development version and  
    測試開發版本並
    
-   Report issues and/or  
    報告問題和/或
    
-   Help fixing issues as well as by  
    幫助解決問題以及透過
    
-   Contributing new functionality  
    貢獻新功能
    
-   Share your code with the project by manner of a pull request.  
    透過拉取請求的方式與專案分享您的程式碼。
    

Note

筆記

Before you send in your pull request, please read our [Coding Guidelines](<236 編碼指南.md>) and see the community support levels in the [Support Options](<379 支援選項.md>). It is important for plugin developers to maintain their plugin and interact with users for QA.

在發送拉取請求之前，請閱讀我們的[編碼指南](<236 編碼指南.md>)，並在[支援選項](<379 支援選項.md>)中查看社區支援等級。對於插件開發者來說，維護他們的插件並與使用者互動QA非常重要。

### Testing｜測試

Contribute by testing the latest development version to make the next release even better than the last. If you like to test a development version then the easiest way is to login to the console and type:

透過測試最新的開發版本做出貢獻，使下一個版本比上一個版本更好。如果您想測試開發版本，那麼最簡單的方法是登入控制台並輸入：

```
pkg install -y opnsense-devel
```

And to revert back to the production version:

並恢復到生產版本：

```
pkg install -y opnsense
```

That is all there is to it to test the latest development release. Development releases are usually built at the same day the latest production release comes available.

這就是測試最新開發版本的全部內容。開發版本通常是在最新生產版本發布的同一天建立的。

### Reporting an issue｜報告問題

Issues can be easily reported on github, please consider carefully if the issue could be a configuration or user error before reporting it. If you are unsure, report your issue on the [forum](https://forum.opnsense.org/) or on [IRC](https://web.libera.chat/#opnsense).

問題可以輕鬆地在 github 上報告，請在報告之前仔細考慮問題是否可能是配置或使用者錯誤。如果您不確定，請在[論壇](https://forum.opnsense.org/)或[IRC](https://web.libera.chat/#opnsense)上回報您的問題。

---

### Fixing issues｜解決問題

If you are a programmer or just know how to fix a certain issue then you can help by either sharing your ideas on or send in a pull request on github.

如果您是程式設計師或只是知道如何解決某個問題，那麼您可以透過在 github 上分享您的想法或發送拉取請求來提供協助。

---

### Designing new features｜設計新功能

If you like to help designing new features then start with reading the [Development manual](<234 開發手冊.md>) and checkout our [roadmap](https://opnsense.org/about/road-map/) as well as our [issue tracker](https://github.com/opnsense/core/issues). Before starting it is always a good to share your idea first with a core developer, to do so you can use either:

如果您想幫助設計新功能，請開始閱讀[開發手冊](<234 開發手冊.md>)，並查看我們的[路線圖](https://opnsense.org/about/road-map/)以及我們的[問題追蹤器](https://github.com/opnsense/core/issues)。在開始之前，最好先與核心開發人員分享您的想法，為此您可以使用：

-   [github](https://github.com/opnsense/core/) and [create a issue](https://github.com/opnsense/core/issues/new) and mention you volunteer for taking on the development task (we will correctly label it as enhancement or feature)  
    [github](https://github.com/opnsense/core/) 和 [創建問題](https://github.com/opnsense/core/issues/new) 並提及您自願承擔開發任務（我們將正確地將其標記為增強或功能）
    
-   find one of us on IRC/Libera Chat (#opnsense) and see if we are available to discuss your idea.  
    在 IRC/Libera Chat (#opnsense) 上找到我們之一，看看我們是否可以討論您的想法。

## Documentation & wiki articles｜文檔和 wiki 文章

The easiest way to help with documentation is to write how-to type articles. As the wiki & documentation project itself is written in **reStructuredText** you can offer your content in this format (preferably as a [pull request](https://github.com/opnsense/docs)). Other formats are also possible, such as:

幫助編寫文件的最簡單方法是編寫如何輸入文章。由於 wiki 和文件專案本身是用 **reStructuredText** 編寫的，因此您可以以此格式提供內容（最好是作為 [拉取請求](https://github.com/opnsense/docs)）。其他格式也是可能的，例如：

-   markup with ./images/directory including the used images (if any)  
    帶有 ./images/directory 的標記，包括使用的圖像（如果有）
    
-   word document with embedded images (if any)  
    帶有嵌入圖像的Word文件（如果有）
    

To include you documentation send it to contact @ opnsense.org. Make sure that:

要包含您的文檔，請將其發送至聯絡人@opnsense.org。確保：

-   Your content does not include copyrighted material if you do not own the copyright yourself  
    如果您自己不擁有版權，您的內容不包含受版權保護的資料
    
-   State that we may use the content under our Documentation Copyright as listed in the [Legal notices](<378 法律聲明.md>) section.  
    聲明我們可以使用[法律聲明](<378 法律聲明.md>)部分中列出的文檔版權下的內容。

## Forum & IRC｜論壇&IRC

If you are an experienced network engineer, know a lot about firewall technology or if you are excited about OPNsense, then you can contribute to the project by helping others on the [forum](https://forum.opnsense.org/) or on [IRC](https://web.libera.chat/#opnsense).

如果您是一位經驗豐富的網路工程師，對防火牆技術了解很多，或者您對 OPNsense 感到興奮，那麼您可以透過在 [論壇](https://forum.opnsense.org/) 或 [IRC](https://web.libera.chat/#opnsense) 上幫助其他人來為該專案做出貢獻。

## Social media｜社群媒體

Contribute to the success of the project by letting others know how OPNsense helped solving your network or security challenges. Let others know about OPNsense and/or follow us & retweet our messages on [Twitter](https://twitter.com/opnsense).

讓其他人了解 OPNsense 如何幫助您解決網路或安全挑戰，為專案的成功做出貢獻。讓其他人了解 OPNsense 和/或在 [Twitter](https://twitter.com/opnsense) 上關注我們並轉發我們的訊息。

Anything you can do to spread the word about OPNsense will help to reach our goal to become the most widely used open source security & firewall platform.

您為宣傳 OPNsense 所做的一切都將有助於實現我們成為使用最廣泛的開源安全和防火牆平台的目標。
