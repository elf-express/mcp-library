# Firmware｜韌體

> 章節：[System](<000 目錄.md#c-11>)

In the firmware section you can keep your OPNsense up to date and have the ability to install additional software.

在韌體部分，您可以保持 OPNsense 的韌體更新，並能夠安裝其他軟體。

## Updates｜更新

How to install updates and information about our versioning can be found in the Installation and setup section, which can be found in the [Updates](<57 更新.md>) document.

有關如何安裝更新和版本控制的信息，請參閱「安裝和設定」部分，該部分位於 [更新](<57 更新.md>)文件中。

## Plugins｜外掛

Plugins are additional software packages that are available for OPNsense, usually they come with their own frontend components to setup the software underneath. Shown by default are support tier 1 and 2 plugins.

插件是 OPNsense 的附加軟體包，通常帶有各自的前端組件，用於配置底層軟體。預設顯示的是一級和二級支援插件。

Here you can also find community plugins from lower tiers, such as **bind**, **c-icap**, **freeradius** and others. These are not listed by default. To view them use the **Show community plugins** checkbox.

在這裡您還可以找到較低層的社群插件，例如 **bind**、**c-icap**、**freeradius**等。預設不會列出這些。若要查看它們，請使用**顯示社群外掛程式** 複選框。

When on the development version, a **\-devel** version is also available available, which may contain features still under development or ready for wider testing before their eventual release (master branch on GitHub versus release).

使用開發版本時，也可以使用 **\-devel** 版本，其中可能包含仍在開發中的功能，或在最終發布之前準備進行更廣泛的測試（GitHub 上的 master 分支與發布版本）。

Our plugin support tiers are explained in detail in the [Support Options](<379 支援選項.md>) document.

我們的插件支援等級在[支援選項](<379 支援選項.md>)文件中有詳細說明。

Note

注意事項

You can use the symbol to install the package.

你可以使用該符號來安裝軟體包。

Tip

提示

Use the info button to display information about the package and to find the active maintainer of this piece of software.

使用資訊按鈕顯示有關軟體包的信息，並查找此軟體的活躍維護者。

## Packages｜包裹

The packages tab contains the installed ports packages, here you can check licenses, force reinstalls or lock versions.

「軟體包」標籤包含已安裝的連接埠軟體包，您可以在這裡檢查許可證、強制重新安裝或鎖定版本。

## Changelog｜更新日誌

If you would like to read about the changes in (past) releases, you can do so in the **Changelog** tab.

如果您想了解（過去）版本中的更改，可以在**變更日誌**標籤中查看。

## Status (firmware audits)｜狀態（韌體審核）

Audits provided are troubleshooting tools for a variety of purposes explained below. The forum is a good place to post your update and upgrade issues if you get stuck despite the best effort.

提供的審計工具是故障排除工具，可用於以下各種用途。如果您盡力嘗試後仍然遇到更新和升級問題，論壇是一個很好的發文平台。

The cleanup audit triggers an immediate removal of all tempporary update files. Sometimes these files are not cleaned up correctly and can cause issues with the next round of package updates.

清理審核會立即刪除所有臨時更新檔案。有時這些文件無法正確清理，可能會導致下一輪軟體包更新出現問題。

The connectivity audit offers a direction where to look for issues during updates and the following causes are in our experience most common:

連結性審核可以幫助我們找到更新過程中出現問題的方向，根據我們的經驗，以下是最常見的原因：

-   Misconfigured DNS settings, check System ‣ Settings ‣ General for configured servers the firewall is allowed to use  
    DNS設定設定錯誤，請檢查“系統”‣“設定”‣“常規”，查看防火牆允許使用的已設定伺服器。
    
-   Misconfigured IPv6, in which case “Prefer IPv4 over IPv6” in System ‣ Settings ‣ General might help to prevent the system from using IPv6 in these cases  
    IPv6 設定錯誤，在這種情況下，在「系統」‣「設定」‣「常規」中啟用「優先使用 IPv4 而非 IPv6」可能有助於阻止系統在這些情況下使用 IPv6。
    
-   In HA (CARP) setups, using the wrong external IP address, usually caused by a misconfigured Source NAT rule, is easy to check by disabling manual Source NAT rules in Firewall ‣ NAT ‣ Source NAT (Outbound).  
    在HA ( CARP ) 設定中，使用錯誤的外部IP位址（通常是由於配置錯誤的來源NAT規則引起的）很容易透過停用防火牆 ‣ NAT ‣ 來源NAT )中的手動源NAT規則來檢查。
    

The heath audit can also help with uncovering installation and disk / file system issues. Additionally, major ugpgrades may not pass certain sanity checks that need to be corrected first which may include the command line:

健康審計還可以幫助發現安裝和磁碟/檔案系統問題。此外，主要的 ugpgrade 可能無法通過某些健全性檢查，需要先進行修正，其中可能包括命令列：

-   “Could not determine core package name.” can indicate that the local package manager database was lost. See opnsense-bootstrap command to fix.  
    「無法確定核心軟體包名稱」可能表示本機軟體套件管理器資料庫已遺失。請參閱 opnsense-bootstrap 指令進行修復。
    
-   “No package manager is installed to perform upgrades.” can indicate a broken installation. Try to reinstall the “pkg” package via System –> Firmware –> Packages.  
    「未安裝任何軟體套件管理器以執行升級。」可能表示安裝已損壞。請嘗試透過「系統」->「韌體」->「軟體包」重新安裝「pkg」軟體包。
    
-   “The Package manager is incompatible and needs a reinstall.” can indicate misuse of the FreeBSD repository. Try to reinstall the “pkg” package via System –> Firmware –> Packages.  
    「軟體套件管理器不相容，需要重新安裝。」 這可能表示 FreeBSD 軟體倉庫使用不當。請嘗試透過「系統」->「韌體」->「軟體包」重新安裝「pkg」軟體包。
    
-   “Core package not known to package database.” can mean that the mirror settings are wrong, the main mirror no longer holds any packages or that the mirror is unreachable for other reasons.  
    「軟體包資料庫中找不到核心軟體包。」可能表示鏡像設定錯誤、主鏡像不再包含任何軟體包，或由於其他原因而鏡像無法存取。
    

The security audit checks each installed package’s version against a database of known vulnerabilities. Vulnerabilities are reported for triage and inspection, not for reporting them to OPNsense. The appearance of vulnerabilities in an install indicate that the next update will likely address them.

安全性審計會將每個已安裝軟體包的版本與已知漏洞資料庫進行比對。漏洞報告僅用於分類和檢查，而非向 OPNsense 報告。安裝中出現漏洞表示下一次更新很可能會修復這些漏洞。

After having performed a major upgrade, the upgrade audit shows the package upgrade log for further inspection. This can be helpful to identify package conflicts that led to partial or full upgrade failures.

完成重大升級後，升級審核會顯示軟體包升級日誌，以便進一步檢查。這有助於識別導致部分或全部升級失敗的軟體包衝突。

## Settings｜設定

The settings menu contains all available mirrors and options which you can choose for your installation. Usually the default options are good enough here, but if you want to choose a mirror more close to home you can do so here.

設定選單包含所有可用的鏡子和選項，您可以從中選擇安裝。通常預設選項就足夠了，但如果您想選擇一面更貼近您家的鏡子，您也可以在這裡進行設定。

Tip

提示

The settings menu also provides the option to test development versions, which can be practical when testing features that are planned for release. Just change the release type to **Development**.

設定選單還提供了測試開發版本的選項，這在測試計劃發布的功能時非常實用。只需將發布類型變更為**開發**即可。

Note

注意事項

Although OPNsense does not support the configuration of a proxy server, for services like the firmware updater it is possible to add these settings manually in our `configd` service. For more information we refer to [the envronment section in our development docs](<247 使用 configd.md>).

雖然 OPNsense 不支援代理伺服器的配置，但對於韌體更新程式等服務，可以在我們的`configd`服務中手動新增這些設定。更多資訊請參閱[開發文件中的環境部分](<247 使用 configd.md>) 。

### Apply the Business Edition｜應用商業版

When you have purchased a license for the Business Edition or received it pre-installed on an appliance, you will have to enable the license first.

如果您購買了商業版許可證或收到預先安裝在設備上的許可證，則必須先啟用該許可證。

In order to do so, please choose the following settings:

為此，請選擇以下設定：

|   |   |
| --- | --- |
| Mirror:<br>鏡像： | Deciso (HTTPS,NL,Commercial)<br>已決定（ HTTPS,NL ，商業） |
| Flavour:<br>風味： | OpenSSL |
| Type:<br>類型： | Business<br>商業 |
| Subscription:<br>訂閱： | XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX (the activation key for the product)<br>XXXXXXXX-XXXX-XXXX-XXXX -XXXXXXXXXXXX（產品啟動碼） |

[![../_images/quickstart_be.png](<../images/03c11faf-quickstart_be.png>)](https://docs.opnsense.org/_images/quickstart_be.png)

After save, go back to the status tab and click **Check for updates**

儲存後，返回狀態標籤並點擊**檢查更新**

Note

注意事項

Upgrading to OPNsense BE is only possible when the installed community version number is lower than the last available business edition. E.g. you can upgrade **22.7.x** to **22.10.x**, but you can not upgrade **23.1** to **22.10**. You can always re-install using the installer found on the [business mirror](https://opnsense-update.deciso.com/)

只有當已安裝的社群版版本號低於最新可用的企業版時，才能升級到 OPNsense BE 。例如，您可以將 **22.7 .x** 升級到 **22.10 .x**，但無法將 **23.1** 升級到 **22.10**。您始終可以使用 [企業鏡像](https://opnsense-update.deciso.com/)上的安裝程式重新安裝。
