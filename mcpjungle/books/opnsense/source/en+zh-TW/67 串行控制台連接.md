# Serial Console connectivity｜串行控制台連接

> 章節：[Official hardware](<000 目錄.md#c-7>)

The following device families offer a mini-usb connection which can be used for serial communication:

以下設備系列提供可用於串列通訊的迷你 USB 介面：

| Series<br>系列 | Formfactor<br>外形尺寸 | Range<br>範圍 |
| --- | --- | --- |
| DEC6XX | Desktop<br>桌上型電腦 | Entry level<br>入門級 |
| DEC7XX | Desktop<br>桌上型電腦 | Midrange<br>中階機 |
| DEC8XX | Desktop<br>桌面 | Enterprise<br>企業 |
| DEC26XX | Rack<br>機架 | Entry level<br>入門級 |
| DEC27XX | Rack<br>機架式 | Midrange<br>中音 |
| DEC38XX | Rack<br>機架式 | Enterprise<br>企業級 |
| DEC40XX | Rack<br>機架 | Enterprise / Datacenter<br>企業/資料中心 |

Supplied with the firewall is a mini-usb to usb cable, use this to connect the to your PC (Windows, Linux, Mac) next start your terminal program (Putty, screen, etc).

防火牆附帶一條 mini-usb 轉 usb 電纜，用它將防火牆連接到您的PC （Windows、Linux、Mac），然後啟動您的終端程式（Putty、screen 等）。

The baudrate should be set to `115200,8N1`, more information about how to use the serial console is available in our [serial access guide](<60 序列存取.md>)

波特率應設定為`115200,8N1` ，有關如何使用串口控制台的更多信息，請參閱我們的[串口訪問指南](<60 序列存取.md>)

Note

注意事項

The default configured settings in OPNsense for proper serial connectivity in System->Settings->Administration are as followed:

OPNsense 中用於正確建立串行連接的預設組態設定（位於「系統」->「設定」->「管理」）如下：

| setting<br>設定 | value<br>值 |
| --- | --- |
| Primary Console<br>主控制台 | Serial Console<br>串行控制台 |
| Secondary Console<br>輔助控制台 | None<br>無 |
| Serial Speed<br>串列速度 | 115200 |
| USB-based serial<br>USB序號 | (unchecked)<br>（未檢查） |
| Console menu<br>控制台選單 | (checked)<br>（已勾選） |

Windows Tip

Windows 小技巧

On windows a COM port would be assigned after connecting the unit to usb, to find which one (COM1, COM2, .,) to use, keep the windows key pressed and hit `R` (Windows+R) and execute the following command `devmgmt.msc` to open the device manager.

在 Windows 系統中，將裝置連接到 USB 後會分配一個COM連接埠。若要尋找要使用的連接埠（ COM1, COM2 , .,），請按住 Windows 鍵並按下`R` (Windows+R)，然後執行下列指令`devmgmt.msc`開啟裝置管理員。

In the device manager all available ports are visible under the “Ports (COM & LPT)” section.

在裝置管理員中，「連接埠 ( COM & LPT )」部分下方可以看到所有可用的連接埠。

## **Legacy UART vs. UEFI serial**｜**舊款UART與UEFI序號對比**

Starting from OPNsense 22.1 (22.4 for the business edition) and the change to FreeBSD 13-STABLE, support for EFI serial has changed, which requires EFI based systems to disable legacy support to prevent confusing the operating system. Should you connect your Deciso appliance with a serial line and get limited output / no output from the point of handover to the OS, it is important your BIOS settings are updated to disable legacy UART.

從 OPNsense 22.1 （商業版為22.4 ）以及 FreeBSD 13- STABLE開始，對EFI串口的支援發生了變化，這要求基於EFI的系統禁用舊版支援，以避免作業系統出現混亂。如果您使用串口線連接 Deciso 設備，並且在切換點到OS後出現輸出受限或無輸出的情況，則務必更新您的BIOS設定以停用舊版UART 。

While in the BIOS, go to Setup Utility –> AMD CBS –> FCH Common Options –> UART Configuration Options –> UART 0 Legacy Options. and make sure this setting is set to **Disabled**.

在BIOS中，前往「設定實用程式」-> AMD CBS -> FCH常用選項 -> UART設定選項 -> UART 0 舊版選項，並確保此設定設定為 **停用**。
