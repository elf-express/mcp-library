# Firmware｜韌體

> 章節：[Development Manual](<000 目錄.md#c-52>) › [API Reference](<000 目錄.md#c-58>) › [Core API](<000 目錄.md#c-59>)

OPNsense has several API calls to get and set the firmware configuration:

OPNsense 有多個API呼叫來取得和設定韌體配置：

| Method<br>方法 | Module<br>模組 | Controller<br>控制器 | Command<br>指令 | Parameters<br>參數 |
| --- | --- | --- | --- | --- |
| `POST` | core<br>核心 | firmware<br>韌體 | audit<br>審計 |  |
| `POST` | core<br>核心 | firmware<br>韌體 | changelog<br>更新日誌 | $version |
| `POST` | core<br>核心 | firmware<br>韌體 | check<br>檢查 |  |
| `POST` | core<br>核心 | firmware<br>韌體 | connection<br>連接 |  |
| `GET` | core<br>核心 | firmware<br>韌體 | get<br>取得 |  |
| `GET` | core<br>核心 | firmware<br>韌體 | getOptions<br>取得選項 |  |
| `POST` | core<br>核心 | firmware<br>韌體 | health<br>健康 |  |
| `GET` | core<br>核心 | firmware<br>韌體 | info<br>資訊 |  |
| `POST` | core<br>核心 | firmware<br>韌體 | log<br>日誌 | $clear |
| `POST` | core<br>核心 | firmware<br>韌體 | poweroff<br>關機 |  |
| `POST` | core<br>核心 | firmware<br>韌體 | reboot<br>重新啟動 |  |
| `POST` | core<br>核心 | firmware<br>韌體 | resyncPlugins<br>重新同步插件 |  |
| `GET` | core<br>核心 | firmware<br>韌體 | running<br>運作中 |  |
| `POST` | core<br>核心 | firmware<br>韌體 | set<br>集 |  |
| `POST` | core<br>核心 | firmware<br>韌體 | status<br>狀態 |  |
| `POST` | core<br>核心 | firmware<br>韌體 | syncPlugins<br>同步插件 |  |
| `POST` | core<br>核心 | firmware<br>韌體 | update<br>更新 |  |
| `POST` | core<br>核心 | firmware<br>韌體 | upgrade<br>升級 |  |
| `GET` | core<br>核心 | firmware<br>韌體 | upgradestatus<br>升級狀態 |  |

Examples:

例如：

```bash
curl -k -u "$key":"$secret" https://opnsense.local/api/core/firmware/getfirmwareconfig -v
```

```bash
curl -k -u "$key":"$secret" https://opnsense.local/api/core/firmware/status -v
```

```bash
curl -d '' -k -u "$key":"$secret" https://opnsense.local/api/core/firmware/changelog/18.1 -v
```

## Packages｜包裹

You can manage the packages and plugins in OPNsense, using these API calls:

您可以使用以下API呼叫來管理 OPNsense 中的軟體包和插件：

| Method<br>方法 | Module<br>模組 | Controller<br>控制器 | Command<br>指令 | Parameters<br>參數 |
| --- | --- | --- | --- | --- |
| `POST` | core<br>核心 | firmware<br>韌體 | details<br>詳細資料 | $pkg\_name |
| `POST` | core<br>核心 | firmware<br>韌體 | install<br>安裝 | $pkg\_name |
| `POST` | core<br>核心 | firmware<br>韌體 | license<br>授權 | $pkg\_name |
| `POST` | core<br>核心 | firmware<br>韌體 | lock<br>鎖定 | $pkg\_name |
| `POST` | core<br>核心 | firmware<br>韌體 | remove<br>移除 | $pkg\_name |
| `POST` | core<br>核心 | firmware<br>韌體 | reinstall<br>重新安裝 | $pkg\_name |
| `POST` | core<br>核心 | firmware<br>韌體 | unlock<br>解鎖 | $pkg\_name |

Examples:

例如：

```bash
curl -d '' -k -u "$key":"$secret" https://opnsense.local/api/core/firmware/lock/os-xen -v
```

```bash
curl -d '' -k -u "$key":"$secret" https://opnsense.local/api/core/firmware/license/acme.sh -v
```
