# Reserve dedicated bandwidth｜預留專用頻寬

> 章節：[Firewall](<000 目錄.md#c-26>) › [Traffic Shaping](<000 目錄.md#c-29>) › [Configuration / How-tos](<000 目錄.md#c-30>)

**Reserve dedicated bandwidth for a realtime traffic such as (hosted) Voice Over IP (VOIP) server.**

**為即時流量預留專用頻寬，例如（託管）Voice Over IP (VOIP) 伺服器。**

In this scenario we will create a pipe dedicated for traffic going to and coming from our realtime application. For the sample we presume a SIP trunk or hosted Voice Over IP (VOIP) server.

在這種情況下，我們將建立一個專用於進出即時應用程式的流量的管道。對於範例，我們假設有一個 SIP 中繼或託管 Voice Over IP (VOIP) 伺服器。

For this example we presume a requirement of 4 uncompressed voice channels of 64 kbps, resulting in a total bandwidth of 256 kbps. The internet connection in this example has 10 Mbps Download and 1 Mbps Upload.

對於此範例，我們假設需要 4 個 64 kbps 的未壓縮語音通道，導致總頻寬為 256 kbps。本範例中的網際網路連線具有 10 Mbps 下載和 1 Mbps 上傳。

[![](<../images/d8a3726a-nwdiag-3418ebe96212e329652ed37ad74bd28dc.png>)](https://docs.opnsense.org/_images/nwdiag-3418ebe96212e329652ed37ad74bd28dc53d6d4c.png)

Shaping hosted VOIP / SIP trunk sample

塑造託管VOIP / SIP主幹樣本

To start go to Firewall ‣ Shaper ‣ Pipes.

首先前往 Firewall ‣ Shaper ‣ Pipes。

## Step 1 - Create Upload and Download Pipes｜步驟 1 - 建立上傳和下載管道

On the **Pipes** tab click the **+** button in the lower right corner. An empty **Edit Pipe** screen will popup.

在 **管道**標籤上，按一下右下角的**+**按鈕。將彈出一個空的**編輯管道**螢幕。

Create Pipe For Upload (To our VOIP Server)

建立上傳管道（到我們的VOIP伺服器）

|   |   |   |
| --- | --- | --- |
| **enabled**<br>**啟用** | Checked<br>已檢查 | *Check to enable the pipe*<br>*檢查以啟用管道* |
| **bandwidth**<br>**頻寬** | 256 | *Numeric value of the desired bandwidth*<br>256 *所需頻寬的數值* |
| **bandwidth Metric**<br>**頻寬指標** | Kbit/s<br>千位元組/秒 | *Metric to use with the numeric value*<br>*與數值一起使用的量測* |
| **mask**<br>**面具** | (Empty)<br>（空） | *Used for auto queueing, empty for our sample*<br>*用於自動排隊，我們的範例為空* |
| **description**<br>**描述** | PipeUp-256kbps | *Free field, enter something descriptive*<br>*自由字段，輸入描述性內容* |

## Step 2 - Create Rules｜第 2 步 - 建立規則

On the **Rules** tab click the **+** button in the lower right corner. An empty **Edit rule** screen will popup.

在 **規則**標籤上，按一下右下角的**+**按鈕。將彈出一個空的**編輯規則**螢幕。

Create a rule for traffic directed towards the VOIP Server (Upload).

為定向到 VOIP 伺服器（上傳）的流量建立規則。

|   |   |   |
| --- | --- | --- |
| **sequence**<br>**序列** | 11 | *Auto generated number, overwrite only when needed*<br>11 *自動產生編號，僅在需要時覆寫* |
| **interface**<br>**介面** | WAN | *Select the interface connected to the internet*<br>*選擇連接到網際網路的介面* |
| **proto**<br>**原型** | ip | *Select the protocol, IP in our example*<br>*選擇協議，在我們的範例中為IP* |

| **destination**<br>**目的地** | 172.10.2.1 | *The IP address of our VOIP server*<br>*我們的VOIP伺服器的IP位址* |

| **target**<br>**目標** | PipeUP-256kbps | *Select the Upload 256 kbps Pipe*<br>*選擇上傳 256 kbps 管道* |
