# 19.1 “Inspiring Iguana”（鼓舞人心的鬣蜥） Series｜19.1 “Inspiring Iguana”（鼓舞人心的鬣蜥）系列

> 章節：[Releases](<000 目錄.md#c-1>) › [Business Edition](<000 目錄.md#c-3>)

For more than four years now, OPNsense is driving innovation through modularising and hardening the open source firewall, with simple and reliable firmware upgrades, multi-language support, HardenedBSD security, fast adoption of upstream software updates as well as clear and stable 2-Clause BSD licensing.

四年來，OPNsense 透過模組化和強化開源防火牆，推動創新，提供簡單可靠的韌體升級、多語言支援、強化的 BSD 安全性、快速採用上游軟體更新以及清晰穩定的 2 條款BSD許可。

The 19.1 release, nicknamed “Inspiring Iguana”（鼓舞人心的鬣蜥）, consists of a total of 620 individual changes since 18.7 came out 6 months ago, spread out over 12 intermediate releases including the recent release candidates. That is the average of 2 stable releases per month, security updates and important bug fixes included! If we had to pick a few highlights it would be: The firewall alias API is finally in place. The migration to HardenedBSD 11.2 has been completed. 2FA now works with a remote LDAP / local TOTP combination. And the OpenVPN client export was rewritten for full API support as well.

19.1版本（暱稱“Inspiring Iguana”（鼓舞人心的鬣蜥） ）自 6 個月前18.7發布以來，共包含 620 項變更，這些變更分佈在 12 個中間版本中，包括最近的候選版本。這意味著平均每月發布 2 個穩定版本，其中包含安全性更新和重要的錯誤修復！如果要列舉一些亮點，那就是：防火牆別名API終於上線。向 HardenedBSD 11.2的遷移已完成。雙重認證 (2FA) 現在支援遠端LDAP / 本地TOTP組合。此外，OpenVPN 用戶端匯出也已重寫，以完全支援API 。

    入侵偵測 GeoIP 規則會自動停用，需要手動遷移到防火牆別名 GeoIP。

    監控常規設定不儲存。存在一個補丁 [\[11\]](https://github.com/opnsense/core/commit/a2899594) 來解決此問題：opnsense-patch a2899594

    IDS 遷移程式碼存在建立虛假崩潰報告的問題。最終19.1的補丁已經完成。
