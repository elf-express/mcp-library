# Log Files｜紀錄檔案

> 章節：[System](<000 目錄.md#c-11>)

When troubleshooting problems with your firewall, it is very likely you have to check the logs available on your system. In the UI of OPNsense, the log files are generally grouped with the settings of the component they belong to. The log files can be found here:

在排查防火牆問題時，您很可能需要檢查系統上的日誌。在 OPNsense 的UI目錄下，日誌檔案通常會根據其所屬組件的設定進行分組。日誌檔案位於以下位置：

|   |   |   |
| --- | --- | --- |
| **System Log**<br>**系統日誌** | System ‣ Log Files ‣ General<br>系統 ‣ 日誌檔案 ‣ 常規 | *Most of all system related events go here*<br>*大多數系統相關事件都會記錄在這裡* |
| **Backend / config daemon**<br>**後端/設定守護程式** | System ‣ Log Files ‣ Backend<br>系統 ‣ 日誌檔案 ‣ 後端 | *Here you can find logs for config generation of API usage*<br>*此處可找到API使用情況的設定產生日誌* |
| **Web GUI** | System ‣ Log Files ‣ Web GUI<br>系統 ‣ 日誌檔案 ‣ Web GUI | *Lighttpd, the webserver of OPNsense itself, logs here*<br>*OPNsense 自身的 Web 伺服器 Lighttpd 的日誌記錄在此* |
| **Firmware**<br>**韌體** | System ‣ Firmware ‣ Log File<br>系統 ‣ 韌體 ‣ 日誌檔案 | *Updates from the packaging system go here*<br>*來自打包系統的更新將放在這裡* |
| **Gateways**<br>**網關** | System ‣ Gateways ‣ Log File<br>系統 ‣ 網關 ‣ 日誌檔案 | *Lists Dpinger gateway tracking related log messages*<br>*列出 Dpinger 網關追蹤相關的日誌訊息* |
| **Routing**<br>**路由** | System ‣ Routes ‣ Log File<br>系統 ‣ 路由 ‣ 日誌檔案 | *Routing changes or interface events*<br>*路由變更或介面事件* |
