# 關於叉子

> 章節：[History](<000 目錄.md#c-65>)

歡迎來到關於本分支的頁面。本頁面旨在解釋最初建立分支的動機，但請注意，目前僅保留了不到 10% 的原始程式碼庫。如今，OPNsense 已從一個分支發展成為一個全新的安全平台，擁有許多領先創新，例如所有組件的每周安全更新、 REST API 、內聯入侵防禦以及直觀的現代化用戶界面。

讓我們一起分擔和提升這個項目吧！

![../_images/fork-lift_new.jpg](<../images/d7285c5b-fork-lift_new.jpg>)

## 那麼，我們為什麼會分叉呢？

早在 2014 年，在贊助 pfSense® 多年後，我們認為別無選擇，只能將其分支出來，並延續最初基於 m0n0wall 的分支的精神。您可以在下方了解我們最初的動機以及 OPNsense® 的誕生。

### 技術的

我們有技術上的原因選擇分叉。儘管我們很喜歡 pfSense 的功能/特性集，但我們並不喜歡它的[程式碼品質](<237 基礎與未來.md>)和分散的開發方式。我們喜歡結構化的、可實現的目標，這些目標應該在[路線圖](https://opnsense.org/roadmap/)中明確列出，並定期發布新版本，以及一個完善的[框架](<242 大樓.md>) 。

### 安全

在安全部分，主要問題是需要分離邏輯。 GUI 不應執行需要 root 存取權的任務，並且應在潛在的安全問題成為真正的問題之前將其修復。

### 品質

在品質方面，所有新功能都將基於穩健的[框架](<242 大樓.md>)和模型-視圖-控制器（MVC）架構建構。為此，我們選擇[Phalcon](https://phalcon.io/) ，因為它是目前最快的開源PHP框架。我們將逐步把從pfSense繼承的部分遷移到新框架，避免一次性大刀闊斧地進行遷移。

### 社群

只有當人們願意分享時，一個繁榮的社區才能存在。我們希望讓人們更容易加入並幫助建立社區。對於 pfSense，這相當困難，因為建造它的工具很難使用，並且在最初的幾次嘗試中通常不起作用。自 2014 年起，它們不再免費提供，您需要透過 ESF 申請訪問。我們相信一個好的開源專案沒有什麼可隱藏的，因此所有人都應該能夠存取原始碼。 ESF 為何採取這項措施仍是個謎，因為提交權和讀取權完全不同。

注意事項

ESF此後多次更改其政策，採用不同的許可模式，包括ESF 6 條款許可，以及最新的 Apache 風格許可。

### 透明度

pfSense 的一個真正問題是透明度。自從 Netgate 收購了 pfSense 的多數股權並將公司更名為ESF後，人們很難理解他們希望該專案朝著哪個方向發展。在沒有任何事先警告的情況下從 GitHub 移除工具，並利用品牌名稱來排擠競爭對手，這讓許多人感到不安。此外，許可證也無緣無故地發生了變更…

### 恢復一個穩固的開源項目

透過 OPNsense，我們恢復了一個穩定的項目，它擁有清晰的目標和非常簡​​單的許可證，適合 fork 和創建OEM版本。我們認為，社區計畫應該供所有人使用和參與。

## 首發版

在[首次正式發布](https://web.archive.org/web/20150503182123/https://opnsense.org/opnsense-version-15-1-released/)之前，已經做了很多工作：

-   建置工具已完全重寫，採用清晰易讀、可移植且體積小巧的建置腳本。
    
-   OPNsense 現在可以安裝在我們客製化的 FreeBSD 建置之上（您可以直接執行 pkg remove opnsense，這樣就得到了一個幾乎標準的 FreeBSD 基礎系統）。
    
-   韌體升級過程現已使用 pkgng 完成。
    
-   強制門戶已重寫，不再使用核心補丁。
    
-   新功能（強制門戶）已實現，並具有清晰的結構。
    
-   check\_reload\_status 功能（實際上是後端守護程式啟動和停止元件的功能）已完全以 Python (configd) 重寫。
    
-   已將GUI完全重製為基於 Bootstrap 的現代版本，如果您需要，也更容易進行自訂。
    

## 未來發展與重點

未來，我們將繼續關注程式碼品質和安全性。

注意事項

我們已投入大量精力來提升程式碼質量，並透過每週更新，證明我們能夠快速應對已知的安全威脅。有關專案目前狀態和未來發展方向，請參閱我們的[路線圖](https://opnsense.org/roadmap/) 。

### 德西索的參與

話雖如此，但需要說明的是，[Deciso](https://www.deciso.com/)一直是 pfSense 的長期贊助商，並為該項目投入了大量時間和資金。 Deciso 幫助 pfSense 在歐洲取得了成功。在 Netgate 收購該公司之前，像我們這樣的公司還有很多發展空間，但遺憾的是，這種情況已經改變了。

### 結語

歸根結底，這一切都取決於我們未來的發展方向，包括技術層面、社區參與和透明度。

誠摯邀請您體驗 OPNsense，加入社區，協助專案發展。 OPNsense 正迅速成為排名第一的開源防火牆平台！
