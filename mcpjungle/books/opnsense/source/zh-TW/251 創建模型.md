# 創建模型

> 章節：[Development Manual](<000 目錄.md#c-52>) › [Frontend](<000 目錄.md#c-55>) › [Creating Models](<000 目錄.md#c-56>)

模型表示應用程式將使用的數據並負責與該數據的交互作用。在 OPNsense 中，大多數相關資料物理儲存在 XML 結構 (config.xml) 中。 OPNsense 模型的主要目標是透過建立清晰的抽象層來結構化配置資料的使用。
