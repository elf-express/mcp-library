## [概述](#id2)

使用 OPNsense 完整架構的所有元件都會自動接收 API 功能，在這個簡單的教學中，我們使用韌體模組，但其他元件將以相同的方式運作。 API 存取是本機使用者驗證系統的一部分，但使用金鑰/秘密對將帳戶資訊與機器到機器通訊分開。秘密不會儲存在 OPNsense 上，只能下載一次，如果遺失，則必須為您的應用程式產生新金鑰。

一個使用者可以擁有多個金鑰，我們的建議是為每個使用的應用程式建立一個唯一的金鑰。

## [建立金鑰](#id3)

API金鑰在使用者管理員 (system\_usermanager.php) 中進行管理，請前往使用者管理員頁面並選擇使用者。在頁面下方，您會找到該使用者的API部分。

[![Usermanager add api key.png](<../images/fd0cdef1-Usermanager_add_api_key.png>)](https://docs.opnsense.org/_images/Usermanager_add_api_key.png)

點選“+”號新增密鑰。金鑰建立完成後，您將收到一個包含憑證的文字檔案（ini 格式），可單獨下載。該文件的內容如下所示：

```
key=w86XNZob/8Oq8aC5r0kbNarNtdpoQU781fyoeaOBQsBwkXUt
secret=XeD26XVrJ5ilAc/EmglCRC+0j2e57tRsjHwFepOseySWLM53pJASeTA3
```

## [程式碼範例（Python）](#id4)

對於 Python 程式碼範例，我們使用了優秀的「requests」函式庫（[http://docs.python-requests.org/en/latest/](http://docs.python-requests.org/en/latest/) ），這使得HTTP變得非常容易。

在開始之前，請確保您的 OPNsense 具有有效的SSL憑證（或為了測試目的而選擇忽略它，方法是將 verify=False 設定為 False），不要忘記驗證所選用戶是否可以存取韌體頁面。

Web 介面使用與 API 相同的邏輯，在本例中，我們將從韌體模組收集一些狀態資訊並將其列印出來供使用者查看。

一切都從創建請求和等待回應開始，所有資料互動都使用 json 格式，無論是回應還是請求資料（發送POST資料時）。

範例的第一步是匯入所需的庫，然後定義端點 URL 和要使用的憑證，最後發送（GET 類型）請求。收到回應後，我們將 JSON 字串解析回字典，並根據回應列印一些資料。

```js
# import libraries
import json
import requests

# define endpoint and credentials
api_key = 'w86XNZob/8Oq8aC5hxh2he+vLN00r0kbNarNtdpoQU781fyoeaOBQsBwkXUt'
api_secret = 'puOyw0Ega3xZXeD26XVrJ5WYFepOseySWLM53pJASeTA3'
url = 'https://192.168.1.1/api/core/firmware/status'

# request data
r = requests.get(url,
                 verify='OPNsense.pem',
                 auth=(api_key, api_secret))

if r.status_code == 200:
    response = json.loads(r.text)

    if response['status'] == 'ok':
        print ('OPNsense can be upgraded')
        print ('download size : %s' % response['download_size'])
        print ('number of packages : %s' % response['updates'])
        if response['upgrade_needs_reboot'] == '1':
            print ('REBOOT REQUIRED')
    elif 'status_msg' in response:
        print (response['status_msg'])
else:
    print ('Connection / Authentication issue, response received:')
    print r.text
```

## [使用 cURL](#id5)

使用 curl 進行簡單測試也是可行的，下面的範例使用相同的憑證，但忽略了SSL證書檢查 (-k) 進行測試。

```bash
curl -k -u "w86XNZob/8Oq8aC5hxh2he+vLN00r0kbNarNtdpoQU781fyoeaOBQsBwkXUt":"puOyw0Ega3xZXeD26XVrJ5WYFepOseySWLM53pJASeTA3" https://192.168.1.1/api/core/firmware/status
```

然後使用以下命令安排所有軟體包的實際更新：

```bash
curl -XPOST -k -u "w86XNZob/8Oq8aC5hxh2he+vLN00r0kbNarNtdpoQU781fyoeaOBQsBwkXUt":"puOyw0Ega3xZXeD26XVrJ5WYFepOseySWLM53pJASeTA3" https://10.211.55.100/api/core/firmware/update
```

## [使用瀏覽器控制台檢查API](#id6)

所有API端點都由WebGUI用於在視圖和控制器之間進行互動。只有極少數端點不直接在WebGUI中使用。因此，在瀏覽器控制台中檢查API請求和回應是檢查API正確使用情況的最佳方法。

可以使用 cURL 等命令列工具輕鬆重現所有API請求。

以下是使用Google瀏覽器和火狐瀏覽器的簡單指南：

### [1. 打開UI組件](#id7)

在我們的範例中，我們想要檢查如何在「系統」‣「存取」‣「群組」中建立新群組。

首先，我們瀏覽到提供新增群組的選項的UI頁面。然後，我們按下**+**按鈕開啟輸入表單對話框。我們將輸入以下數據：

| 選擇權 | 價值 |
| --- | --- |
| **群組名稱** | HelloWorld |
| **描述** | HelloWorld |
| **權限** | 大廳：控制面板 |
| **成員** | 根目錄 |

在按下**儲存**之前，我們將打開瀏覽器開發者工具來檢查按下按鈕後會發生什麼。

### [2. 開啟瀏覽器開發者工具](#id8)

Google瀏覽器或火狐瀏覽器：

按 F12 或 Ctrl+Shift+I（Windows/Linux）或 Cmd+Option+I（macOS）。

導航至**網路**標籤。

現在按下開啟的表單對話方塊中的 **儲存** 按鈕。這將透過API端點觸發資料的序列化。您將在網路標籤中看到`add/`。

### [3. 檢查API呼叫](#id9)

點選相關請求（例如，/api/auth/group/add/）。

請檢查以下細節：

-   標頭：方法（ POST, GET ）， URL ，標頭（如 content-type、accept、authorization 和 cookie）。
    
-   有效載荷：在「有效載荷」標籤中檢查請求有效載荷。
    
-   回覆：在「回覆」標籤下查看回覆資料。
    

在我們的例子中，它看起來會是這樣：

-   請求URL: `https://192.168.1.1/api/auth/group/add/`
    
-   請求方式： `POST`
    
-   請求有效載荷： `group: {name: "HelloWorld", description: "HelloWorld", priv: "page-system-login-logout", member: "0"}`
    
-   響應： `{"result":"saved","uuid":"569118e0-006b-4a2d-8eb6-332d29300a2a"}`
    

有了這些信息，您就確切地知道如何使用API組來新增組。

### [4. 使用 cURL 複製API呼叫](#id10)

在 Chrome 和 Firefox 中，您可以輕鬆地從先前的API呼叫產生 cURL 命令。

右鍵點選請求條目（例如， `add/` ），選擇「複製」→「複製為 cURL」。

這提供了一個完整的 cURL 指令，可以使用API令牌進行授權。

```bash
curl -X POST 'https://172.16.0.254:4444/api/auth/group/add/' \
-H 'accept: application/json, text/javascript, */*; q=0.01' \
-H 'content-type: application/json' \
--data-raw '{"group":{"name":"HelloWorld","description":"HelloWorld","priv":"page-system-login-logout","member":"0"}}' \
--insecure
```

這種方法允許您在GUI之外測試或自動化API交互，以便進行調試、自動化和腳本編寫。
