# 20.7《傳奇雄獅》系列

> 章節：[Releases](<000 目錄.md#c-1>) › [Business Edition](<000 目錄.md#c-3>)

五年半以來，OPNsense 透過模組化和強化開源防火牆、簡單可靠的韌體升級、多語言支援、HardenedBSD 安全性、上游軟體更新的快速採用以及清晰穩定的 2 條款BSD 許可來推動創新。

20.7，綽號“傳奇獅子”，是可持續防火牆體驗的重大操作系統飛躍。此版本新增了 DHCPv6 多WAN、Web 代理程式的自訂錯誤頁面、Suricata 5、HardenedBSD 12.1、netstat 樹視圖、基本防火牆 API 支援（透過過濾插件）以及擴充的即時日誌等。
