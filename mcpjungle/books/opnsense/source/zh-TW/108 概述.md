# 概述

> 章節：[Interfaces](<000 目錄.md#c-19>)

介面概述包含 [ifconfig](https://www.freebsd.org/cgi/man.cgi?query=ifconfig)的擴充版本，此版本在大多數系統上可用。

您可以使用此頁面查看目前指派的位址、介面狀態、連結狀態和其他詳細資訊。

使用DHCP配置介面時，您也可以在此處重新載入/釋放位址。
