# 零層配置

> 章節：[Virtual Private Networking](<000 目錄.md#c-32>) › [Plugin VPN options](<000 目錄.md#c-35>)

注意事項

強烈建議讀者熟悉 [Zerotier 手冊](https://www.zerotier.com/manual.shtml) ，以便進一步了解此插件背後的概念。

## 先決條件

首先，您必須在 [Zerotier Portal](https://my.zerotier.com/)註冊 Zerotier 帳戶。其次，您需要在入口網站上建立至少一個網絡，以便取得網絡 ID。此外掛程式會使用該網路 ID 將此節點**加入**到已建立的 Zerotier 網路。該網絡將成為您的私有網絡，預設僅對您的節點可見——換句話說，該網絡上的其他節點可以相互通信，但其他任何節點都無法與它們通信——它們對整個互聯網完全透明。實際上，您是在公共互聯網之上建立了一個私人網絡，所有節點內部通訊都經過加密，確保節點之間的私密性。這一點也體現在分配的IP位址通常是RFC1918位址，也就是無法透過網路路由的位址。

最後，為了在 Zerotier 節點之間建立完全功能的私有VPN ，**需要**結合此插件以及在 [portal](https://my.zerotier.com/)上進行一些配置。

## 安裝

在`System...Firmware`下的「外掛」視圖中，安裝os-zerotier軟體套件。新插件安裝完成後，重新載入頁面， VPN下應該會出現一個名為Zerotier的新選單項目。

![../../_images/zerotier-0.png](<../images/5e6e296d-zerotier-0.png>)

點擊 Zerotier 選單項目將顯示兩個子選單項目－「設定」和「概覽」。點擊「設定」將顯示一個新視圖，其中包含兩個已命名的標籤頁。第一個標籤頁名為“設定”，第二個標籤頁名為“網路”。以下將對它們進行更詳細的說明。

![../../_images/zerotier-1.png](<../images/feac51ba-zerotier-1.png>)

## 設定

此標籤控制 Zerotier 的整體運作。在此處所做的任何更改都將全域應用於所有已定義的網路以及 Zerotier 服務本身。

已啟用

控制該服務是否運作。如果停用，則無法存取「網路」標籤。如果啟用，則可存取“網路”選項卡，並且該服務將在啟動時自動運行。

API訪問令牌（可選）

此選用條目用於 Zerotier 外掛程式的後續開發和使用。您可以透過登入您的 [入口網站](https://my.zerotier.com/)並建立新的API訪問令牌來產生API存取令牌。令牌產生後，請將其值複製到此輸入框中。

local.conf 設定（可選）

如 ZeroTier 手冊所述，可以建立 local.conf 檔案來啟用或停用自訂節點特定的配置覆蓋。有關允許選項的更多詳細信息，請參閱 [ZeroTier 手冊](https://www.zerotier.com/manual.shtml) 。請注意，local.conf 文件**必須**是有效的JSON文檔，否則服務將無法啟動。

## 網路

此表允許建立、修改和刪除 Zerotier 網路。在此處新增網路會將您的 OPNsense 安裝加入指定的 Zerotier 網路。

注意事項

請記住，您**必須**必須登入 Zerotier [入口網站](https://my.zerotier.com/)，選擇網路並授權節點，然後才能為其指派 IP 位址（或實際上，與該網路上的其他節點通訊）。

![../../_images/zerotier-2.png](<../images/a3900927-zerotier-2.png>)

新增網路非常簡單。只需點擊以下選單中的“+”符號即可：

網路 ID

這是在入口網站上建立 Zerotier 網路時產生的 64 位元（16 個字元的十六進位）位址。

本地描述（可選）

您可以在此輸入描述，幫助您記住網路的用途。請注意，此欄位與 Zerotier 網路的名稱/描述**並非**相同——它只是一個輔助記憶的工具，可幫助您記住該網路的用途。

新增網路**不會**自動使您的 OPNsense 安裝加入該網路。要加入該網絡，**必須**先將其設為`Enabled` 。同樣，要從已設定的網路中移除您的 OPNsense 節點，只需取消選擇`Enabled` ，即可停用該網路。

網路新增並啟用後，節點**必須**在入口網站上取得加入該網路的授權。只需在 OPNsense 安裝中啟用網絡，即可將該節點標記為該網絡的成員。現在，它需要請求與該網路上的其他節點通訊的權限。為此，您需要登入入口網站，選擇網絡，找到節點位址（該位址位於 OPNsense Zerotier 概覽選單項目的「資訊」標籤下），然後點擊節點旁的「授權？」複選框進行授權。複選框應從“紅色”變為“綠色”，表示已獲得授權。

最後的一些「網路」操作：

如果您想徹底刪除網絡，只需選擇該網絡並點擊`Bin`圖示即可。

若要編輯網絡，請點選`Pencil`圖示。

若要「複製」網路條目，請點選`Copy`圖示。請務必變更網路 ID，因為兩個網路使用相同的 ID 屬於無效配置。

若要快速概覽 Zerotier 網路訊息，請點選`Information`圖示。要查看更詳細的網路信息，請點擊`Overview...Networks`菜單項目。

## 介面分配

警告

強烈建議介面具備自動分配功能。 IP 位址已關閉**僅針對此特定節點**。您需要為介面指派一個靜態的、穩定的位址。 IP 位址（來自 Zerotier 網路） IP 範圍）並且不要讓 Zerotier 服務自動分配一個 IP 地址。自動分配 IP 節點位址由[Zerotier Portal]控制。(https://my.zerotier.com/)

加入 Zerotier 網路（並在入口網站上進行授權）後，您現在可能想要在 OPNsense 上分配 Zerotier 虛擬接口，以便利用 OPNsense 的功能，例如防火牆和路由（例如使用OSPF ）。

![../../_images/zerotier-4.png](<../images/ed12f4c1-zerotier-4.png>)

為了實現這一目標：

點選選單項目`Interfaces` ，然後點選`Assignments` 。此時您應該會看到一個以字母`zt`開頭的、目前未指派的新介面。接下來，點選`+`符號進行分配。在本例中，它會建立一個名為`OPT1`的新介面。點選`OPT1`會顯示`Enable`和`Lock`選項。勾選這兩個選項。

警告

啟用`Lock`（即防止介面刪除）**非常**重要。這是因為 Zerotier 是一個軟體接口，不能保證在系統啟動時「啟動」。它可能會在不久之後發生，因此鎖定介面告訴 OPNsense 不要刪除它，認為它已經壞了。

新介面啟用後，建議將描述從`OPT1`更改為更符合您需求的描述性內容。

對於`IPv4 Configuration Type` ，選擇`Static IPv4` ，然後在對應的輸入框中輸入您透過`Zerotier`入口網站指派給此節點的 IPv4 位址。保持`IPv4 Upstream Gateway`設定為`None.`

![../../_images/zerotier-5.png](<../images/ecba948e-zerotier-5.png>)

您也可以選擇對`IPv6 Configuration Type`執行相同的操作。

一旦介面被指派了IP ，它現在也會出現在`Firewall`規則等…此外，對介面執行的任何其他操作也可以套用於您指派的介面。
