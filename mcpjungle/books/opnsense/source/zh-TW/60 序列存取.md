# 序列存取

> 章節：[Installation and setup](<000 目錄.md#c-5>) › [Setup guides](<000 目錄.md#c-6>)

![../../_images/serial_bootloader.png](<../images/3fe95326-serial_bootloader.png>)

除了網頁前端、 SSH和本地連接的顯示器（如果您的裝置支援）之外，OPNsense 還可以透過串列埠進行控制。透過串列埠存取 OPNsense 與透過SSH存取，但與SSH不同的是，即使 OPNsense 無法透過網路存取，您也可以隨時存取該系統。這使得它特別適用於安裝 OPNsense、在意外斷開網路連接時進行緊急故障排除以及進行重大系統升級。

## 要求

-   OPNsense 安裝必須提供序列介面（虛擬或硬體）。
    
-   可用於存取序列介面的軟體（screen、minicom、PuTTY 等）
    

對於裸機安裝，您還需要以下元件（除非透過管理介面以其他方式提供，請參閱您的伺服器手冊）：

-   零調製解調器電纜
    
-   如果您的電腦上沒有RS232端口，則需要一個USB轉RS232轉換器。
    

## 連接到串列埠控制台

如果您已透過非串列式安裝程式安裝了 OPNsense，則需要啟用串列存取。為此，請開啟 Web 介面，導覽至“系統”‣“設定”‣“管理”，向下捲動至“控制台”，並將主控制台或輔助控制台設定為“串列埠控制台”。注意：僅當您已安裝 OPNsense 但未使用串列埠安裝程式時才需要執行此操作。在所有其他情況下（訪問串口）， BIOS（運行串行安裝程序，連接到透過串行完成的安裝），串行存取已可用。

在類 Unix 系統中，您可以使用`screen`程式連接到串列埠控制台，波特率為 115200。設備名稱可能因係統和串列設備而異。名稱範例：

-   /dev/ttyS0（串口，Linux）
    
-   /dev/ttyUSB0（USB 轉串口，Linux）
    
-   /dev/cuau0（串口，FreeBSD）
    
-   /dev/cuaU0（USB 轉串口，FreeBSD）
    
-   /dev/tty.usbmodem1112421（USB 轉串口，macOS）
    
-   COM1, COM2 ，…（Windows）
    

注意事項

如果您有多個相同類型的設備，如下圖所示：

> `# ls /dev/ttyUSB*`
> 
> `/dev/ttyUSB0  /dev/ttyUSB1`

您可以斷開其中一個設備，看看還剩下哪一個，或者您可以讀取`dmesg`日誌來取得設備節點的供應商資訊。您可以搜尋包含「now attached to ttyUSB1」的訊息，以找出是哪個裝置。之後，您可以將先前的輸出與`lsusb`等工具的輸出進行比較。

例如，在 macOS 系統下存取 Deciso DEC630時，裝置名稱為`/dev/tty.usbmodem1112421` 。因此，進入串列埠控制台需要開啟終端機並執行下列指令：

```
screen /dev/tty.usbmodem1112421 115200
# or
minicom -b 115200 -D /dev/tty.usbmodem1112421
```

注意事項

對該設備的存取可能受到限制。您應該以 root 使用者身分執行該命令，因為以普通使用者身分執行可能會導致 Linux 系統上出現存取被拒絕的錯誤 / BSD 。

如果 OPNsense 正在運行，並且啟用了身份驗證，系統會要求您輸入使用者名稱和密碼。否則，將顯示選單（至少在按下回車鍵後會顯示）。憑證與SSH所使用的憑證相同。

需要注意的是，螢幕並非總是自動更新。如果您連接後沒有看到任何輸出，請先嘗試按 Enter 鍵，然後再嘗試其他（更複雜的）方法。另外，透過`screen`連接時，您可能無法捲動螢幕（但您仍可將輸出透過分頁器（例如`more`或`less` ）進行串流）。
