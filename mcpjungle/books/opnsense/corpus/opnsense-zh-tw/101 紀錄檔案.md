# 紀錄檔案

在排查防火牆問題時，您很可能需要檢查系統上的日誌。在 OPNsense 的UI目錄下，日誌檔案通常會根據其所屬組件的設定進行分組。日誌檔案位於以下位置：

|   |   |   |
| --- | --- | --- |
| **系統日誌** | 系統 ‣ 日誌檔案 ‣ 常規 | *大多數系統相關事件都會記錄在這裡* |
| **後端/設定守護程式** | 系統 ‣ 日誌檔案 ‣ 後端 | *此處可找到API使用情況的設定產生日誌* |
| **Web GUI** | 系統 ‣ 日誌檔案 ‣ Web GUI | *OPNsense 自身的 Web 伺服器 Lighttpd 的日誌記錄在此* |
| **韌體** | 系統 ‣ 韌體 ‣ 日誌檔案 | *來自打包系統的更新將放在這裡* |
| **網關** | 系統 ‣ 網關 ‣ 日誌檔案 | *列出 Dpinger 網關追蹤相關的日誌訊息* |
| **路由** | 系統 ‣ 路由 ‣ 日誌檔案 | *路由變更或介面事件* |
