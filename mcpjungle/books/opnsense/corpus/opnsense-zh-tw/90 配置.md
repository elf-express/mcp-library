# 配置


配置部分包含一些用於追蹤您的設定的工具。

## 備份

您可以使用「系統」‣「設定」‣「備份」部分備份和還原機器配置。執行本機備份時，您可以選擇使用密碼保護備份，並決定是否同時儲存 rrd 統計資料（如果選擇存儲，則這些資訊將儲存在同一個匯出 xml 檔案中）。

警告

一台機器配置的控制台設定可能不適用於其他（虛擬）硬體平台的情況。為了避免在這些情況下失去控制台對防火牆的訪問，配置恢復預設不會套用備份的控制台設定。若要停用此行為，請取消選取**從匯入中排除控制台設定**。

注意事項

由於配置資料的敏感性，建議在儲存備份檔案或分發給其他人時，使用強密碼保護備份檔案。

注意事項

RRD統計資料用於系統健康

恢復備份可以部分恢復，也可以恢復整個配置。由於配置通常包含多個相互依賴的元件，因此恢復整個配置最為安全。

警告

部分恢復可能會導致意外情況，請謹慎使用。出於一致性考慮，未來版本可能不再支援此功能。 （並非所有元件都支援部分導出）

注意事項

如果在不同的（虛擬）機器上恢復備份，且硬體介面名稱不匹配，則不會自動重啟，而是會提示您修復介面分配。

-   [透過安全副本 (sftp) 進行備份](<91 透過安全副本（sftp）進行備份.md>)
-   [使用 Git 進行設定變更的可追溯性](<184 使用 Git 追蹤配置更改.md>)
-   [雲端備份/Nextcloud](<185 雲端備份 Nextcloud.md>)

## 預設值

使用預設設定工具，您可以將防火牆重設為韌體預設設置，完成後即可關機。

## 歷史

歷史記錄選單可協助您追蹤修改之間的變化，並提供下載舊版本設定的機會。

當 OPNcentral 安裝在防火牆上並執行備份時，頁面頂部會有一個主機選擇器，用於選擇要檢查的主機。

此電腦上儲存的每個備份都會以以下拉選單中的一個項目顯示。選擇項目後，系統會自動選擇先前的備份（如有）作為比較目標。螢幕上的最後一個窗格以 [統一差異](https://en.wikipedia.org/wiki/Diff#Unified_format)格式顯示兩個選定版本之間的差異。

在「備份（比較）」窗格中提供以下按鈕：

|   |   |
| --- | --- |
| |還原到此備份（僅限此防火牆），請記住，執行此操作後不會重新啟動任何服務，為了獲得乾淨的狀態，可能需要重新啟動 |
| | 刪除此備份（僅此防火牆） |
| | 下載選定的備份（在左側下拉選單中） |

  

提示

您可以在備份選單（系統‣配置‣備份）中指定要保留的備份數量，這在需要更高層級的稽核時非常實用。
