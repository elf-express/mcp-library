# 開機

## 掛在“正在啟動...”

在某些序列連接裝置上，控制台設定不同，在這種情況下您將無法啟動安裝程式。

如果您可以到達載入程式提示符，則可以嘗試在啟動前更改一些核心參數。

```
set hint.uart.0.flags=0x0
set hint.uart.1.flags=0x10
set hint.uart.0.at="isa"
set comconsole_speed=115200
set comconsole_port=0x3F8
set console=comconsole
boot
```

注意事項

若要進入載入程式提示，請在 OPNsense 啟動選單可見時按 `3`

安裝後，您可以在 System ‣ Settings ‣ Tunables 中保留這些設置
