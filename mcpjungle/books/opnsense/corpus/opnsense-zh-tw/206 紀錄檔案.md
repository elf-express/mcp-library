# 紀錄檔案


在排除防火牆問題時，您很可能必須檢查系統上可用的日誌。在 OPNsense 的 UI 中，日誌檔案通常會依照其所屬組件的設定進行分組。日誌檔案可以在這裡找到：

|   |   |   |
| --- | --- | --- |
| **強制入口網站** |服務 ‣ 強制入口網站 ‣ 記錄檔 | *來自 Captive Portal 的活動請移至此處* |
| **DHCPv4** |服務 ‣ DHCPv4 ‣ 日誌檔案 | *DHCP 事件記錄在此* |
| **Dnsmasq DNS** |服務 ‣ Dnsmasq DNS ‣ 日誌檔案 | *DNSmasq 轉發器日誌* |
| **HAProxy** |服務 ‣ HAProxy ‣ 日誌檔案 | *反向代理的日誌* |
| **入侵偵測** |服務 ‣ 入侵偵測 ‣ 日誌檔案 | *Suricata 日誌在這裡* |
| **網路時間** |服務 ‣ 網路時間 ‣ 日誌檔案 | *NTP守護程式日誌* |
| **未綁定DNS** |服務‣未綁定DNS‣日誌檔案| *可以在此處找到未綁定的解析器日誌* |
| **網頁代理程式** |服務 ‣ Web 代理程式 ‣ 日誌檔案 | *Squid access.log、store.log 和cache.log* |
