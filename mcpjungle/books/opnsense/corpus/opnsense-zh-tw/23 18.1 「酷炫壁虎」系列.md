# 18.1 「酷炫壁虎」系列

3 年多來，OPNsense 透過模組化和強化開源防火牆來推動創新，提供簡單可靠的韌體升級、多語言支援、強化的 BSD 安全性、快速採用上游軟體更新以及清晰穩定的 2 條款BSD許可。

我們很榮幸地向您呈現 OPNsense 防火牆的另一個重大迭代更新。在 2017 年下半年，我們對該版本（暱稱“Groovy Gecko”）進行了超過 500 項更改。其中最值得一提的是，我們對防火牆的NAT規則進行了重新設計，使其更加靈活，並可透過插件進行擴展，這將為後續API核心防火牆功能的改進奠定基礎。更多詳情請參閱下方附件中的變更清單。

從17.7升級的路線將於今天晚些時候開放。請耐心等待。 :)

FreeBSD 目前正在開發 Meltdown 和 Spectre 的補丁 [\[1\]]( https://lists.freebsd.org/pipermail/freebsd-security/2018-January/009719.html )，但尚無可靠的時間表。一旦有更多消息，我們將透過常用管道及時通知您。請耐心等待！

以下是自版本17.7以來最顯著的變化：

-   FreeBSD 11.1, PHP 7.1和 jQuery 3 遷移
    
-   Realtek 廠商NIC驅動版1.94
    
-   便攜式NAT支援 IPsec 之前
    
-   OpenVPN 和 IPsec 中的本機群組限制功能
    
-   OpenVPN 多遠端客戶端支援
    
-   SSH和 web GUI的嚴格介面綁定
    
-   改進了MVC標籤頁和整體頁面佈局
    
-   共用轉送現在可在 IPv6 上執行，並結合「嘗試轉送」和改進的回覆多WAN行為
    
-   Web代理程式中對Linux和Windows的易於使用的更新快取支持
    
-   入侵偵測警報改進和對新規則集的插件支援（ ET Pro，Snort VRT ）
    
-   經過改良的 HAProxy 插件，新增了介紹頁面
    
-   將介面選擇移至選單，並可快速搜尋防火牆規則、 DHCP和無線狀態
    
-   為了便於未來擴展，對別名後端進行了重寫
    
-   支援插件的防火牆NAT規則
    
-   系統路由UI和後端遷移至MVC （也可透過API存取）
    
-   反向DNS支持洞察報告（也可透過API取得）
    
-   完全重寫的防火牆即時登入MVC （也可透過API取得）
    
-   新增插件：zerotier、mdns-repeater、collectd、telegraf、clamav、c-icap、tor、siproxd、web-proxy-sso、web-proxy-useracl、postfix、rspamd、redis、iperf、arp-scan、zabbix-proxy、fporter、noproxy

## 18.1.13 （2018年7月24日）

又到了一年一度的更新時間：本次更新是18.1系列的最後一次更新，而暱稱為“快樂河馬”的18.7將於下週發布！

## 18.1.5 （2018年3月21日）

今天發布的版本針對 amd64 架構提供了 Meltdown 和 Spectre V2 漏洞緩解措施，其中 Spectre V2 漏洞緩解措施僅在更新相應的微程式碼後才有效。然而，應對推測執行安全問題仍然是一項持續且難以預料的挑戰。為了避免意外情況，HardenedBSD 預設啟用了 Meltdown 漏洞緩解措施（ PTI ），即使對於尚未發現漏洞的 CPU（ AMD ）也是如此。幸運的是，效能影響微乎其微，但 Spectre V2 漏洞緩解措施（ IBRS ）在更新對應的微程式碼後可能會降低 CPU 的運作速度。

若要選擇退出其中一項或兩項功能，現在可以在「系統」>「設定」>「可調參數」下永久設定下列值：

-   將「vm.pmap.pti」的值設為「0」並重啟，即可停用PTI
    
-   透過“hw.ibrs\_disable”停用IBRS並將其設為“1”，然後簡單地“套用”。
