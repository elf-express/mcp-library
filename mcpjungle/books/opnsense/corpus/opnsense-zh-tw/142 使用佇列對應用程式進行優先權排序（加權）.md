# 使用佇列對應用程式進行優先權排序（加權）

透過利用佇列，我們可以影響管道內的頻寬，並根據加權演算法為某些應用程式提供比其他應用程式更多的頻寬。

這個想法很簡單：假設我們有一個 10 Mbps 的管道和 2 個應用程序，例如 smtp（電子郵件）和 http(s)。 http(s) 流量的權重為 1，smtp 流量的權重為 9，然後當管道的所有容量都使用時，電子郵件流量將獲得比 http(s) 流量多 9 倍的頻寬，從而導致 http(s) 流量為 1 Mbps，smtp 流量為 9 Mbps。

對於我們的範例，我們僅查看下載流量，但可以對上傳流量執行完全相同的操作。

<table>
<tr><th>應用</th><th>重量</th><th>最小頻寬</th></tr>
<tr><td>SMTP（埠 25）</td><td>9</td><td>9 Mbps</td></tr>
<tr><td>HTTP (80)</td><td rowspan="2">1</td><td rowspan="2">1 Mbps</td></tr>
<tr><td>HTTPS (443)</td></tr>
</table>

首先前往 Firewall ‣ Shaper ‣ Pipes。

## 步驟 1 - 建立下載管道

在 **管道**標籤上，按一下右下角的**+**按鈕。將彈出一個空的**編輯管道**螢幕。

建立下載管道 (10 Mbps)

|   |   |   |
| --- | --- | --- |
| **啟用** |已檢查 | *檢查以啟用管道* |
| **頻寬** | 10 | 10 *所需頻寬的數值* |
| **頻寬指標** |兆位元/秒 | *與數值一起使用的量測* |
| **面具** | （空）| *留空* |
| **描述** | PipeDown-10Mbps | *自由字段，輸入描述性內容* |

## 第 2 步 - 建立隊列

在 **佇列**標籤上，按一下右下角的**+**按鈕。將彈出一個空的**編輯隊列**螢幕。

為SMTP建立隊列

|   |   |   |
| --- | --- | --- |
| **啟用** |已檢查 | *檢查以啟用管道* |
| **管道** | PipeDown-10Mbps | *選擇我們的管道* |
| **重量** | 9 | *與數值一起使用的權重* |
| **面具** | （空）| *留空* |
| **描述** |隊列-SMTP | *自由字段，輸入描述性內容* |

為HTTP建立隊列

|   |   |   |
| --- | --- | --- |
| **啟用** |已檢查 | *檢查以啟用管道* |
| **管道** | PipeDown-10Mbps | *選擇我們的管道* |
| **重量** | 1 | *與數值一起使用的權重* |
| **面具** | （空）| *留空* |
| **描述** |隊列-HTTP | *自由字段，輸入描述性內容* |

## 第 3 步 - 建立規則

在 **規則**標籤上，按一下右下角的**+**按鈕。將彈出一個空的**編輯規則**螢幕。

為 smtp 下載流量（電子郵件）建立規則

|   |   |   |
| --- | --- | --- |
| **序列** | 11 | 11 *自動產生編號，僅在需要時覆寫* |
| **介面** | WAN | *選擇連接到網際網路的介面* |
| **原型** | ip | *選擇協議，在我們的範例中為IP* |
| **來源** |任何| *來源位址，任意留*|
| **來源端口** |郵件傳輸協定 | *形狀的來源端口，smtp 或 25* |
| **目的地** |任何| *目的地IP塑造，留下任意*|
| **目標端口** |任何| *目的港自行塑造，任意留任*|
| **目標** |隊列-SMTP | *選擇SMTP隊列* |
| **描述** | ShapeSMTP下載 | *輸入描述性名稱* |

為HTTP下載流量建立規則

|   |   |   |
| --- | --- | --- |
| **序列** | 21 | 21 *自動產生編號，僅在需要時覆寫* |
| **介面** | WAN | *選擇連接到網際網路的介面* |
| **原型** | ip | *選擇協議，在我們的範例中為IP* |
| **來源** |任何| *來源位址，任意留*|
| **來源端口** | http | *要整形的來源端口，http 或 80* |
| **目的地** |任何| *目的地IP塑造，留下任意*|
| **目標端口** |任何| *目的港自行塑造，任意留任*|
| **目標** |隊列-HTTP | *選擇HTTP隊列* |
| **描述** | ShapeHTTP下載 | *輸入描述性名稱* |

為 HTTPS 流量新增額外規則很簡單，因為如果我們願意，我們可以使用相同的 HTTP 佇列：

|   |   |   |
| --- | --- | --- |
| **序列** | 31 | *自動產生編號，僅在需要時覆寫* |
| **介面** | WAN | *選擇連接到網際網路的介面* |
| **原型** | ip | *選擇協議，在我們的範例中為IP* |
| **來源** |任何| *來源位址，任意留*|
| **來源端口** | https | *要塑造的來源端口，https 或 443* |
| **目的地** |任何| *目的地IP塑造，留下任意*|
| **目標端口** |任何| *目的港自行塑造，任意留任*|
| **目標** |隊列-HTTP | *選擇HTTP隊列* |
| **描述** | ShapeHTTPS下載 | *輸入描述性名稱* |

這樣，HTTP 和 HTTPS 流量將被同等對待（總計最大 1 Mbps）。

現在按apply啟動流量整形規則。
