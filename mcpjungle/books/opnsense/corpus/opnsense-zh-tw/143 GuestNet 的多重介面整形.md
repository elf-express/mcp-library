# GuestNet 的多重介面整形

OPNsense 流量整形器的選項之一是能夠基於兩個介面新增整形規則。此選項可讓您根據流量在介面之間移動的方向以不同方式調整流量。

在此範例中，我們將使用此功能在主 LAN 網路和訪客網路之間共用對稱 10 Mbps 網路連線。

LAN 網路不會受到限制，訪客網路上的使用者流量將限制為總共 2 Mbps 下載和 1 Mbps 上傳。

## 步驟 1 - 建立上傳和下載管道

在 **管道**標籤上，按一下右下角的**+**按鈕。將彈出一個空的**編輯管道**螢幕。

建立上傳管道（GuestNet - em2）

|   |   |   |
| --- | --- | --- |
| **啟用** |已檢查 | *檢查以啟用管道* |
| **頻寬** | 1 | *所需頻寬的數值* |
| **頻寬指標** |兆位元/秒 | *與數值一起使用的量測* |
| **面具** | （空）| *留空* |
| **描述** | PipeUp-1Mbps | *自由字段，輸入描述性內容* |

建立下載管道（GuestNet - em2）

|   |   |   |
| --- | --- | --- |
| **啟用** |已檢查 | *檢查以啟用管道* |
| **頻寬** | 2 | *所需頻寬的數值* |
| **頻寬指標** |兆位元/秒 | *與數值一起使用的量測* |
| **面具** | （空）| *留空* |
| **描述** | PipeDown-2Mbps | *自由字段，輸入描述性內容* |

## 第 2 步 - 建立規則

在 **規則**標籤上，按一下右下角的**+**按鈕。將彈出一個空的**編輯規則**螢幕。

重要 - 在繼續之前！

首先將模式變更為高級，請參閱彈出對話方塊左上角的切換按鈕。單擊即可將其從紅色（禁用）更改為綠色（啟用）。

建立下載流量規則

|   |   |   |
| --- | --- | --- |
| **序列** | 11 | 11 *自動產生編號，僅在需要時覆寫* |
| **介面** | WAN | *選擇連接到網際網路的介面* |
| **介面2** |訪客網| *選擇與您的 GuestNet 相符的介面* |
| **原型** | ip | *選擇協議，在我們的範例中為IP* |
| **來源** |任何| *來源位址，任意留*|
| **來源端口** |任何| *要塑造的來源端口，保留任何* |
| **目的地** |任何| *目的地IP塑造，留下任意*|
| **目標端口** |任何| *目的港自行塑造，任意留任*|
| **方向** |在 | *符合傳入的套件（下載）* |
| **目標** | PipeDown-2Mbps | *選擇下載管道* |
| **描述** |訪客網路下載 | *輸入描述性名稱* |

建立上傳流量規則

|   |   |   |
| --- | --- | --- |
| **序列** | 21 | 21 *自動產生編號，僅在需要時覆寫* |
| **介面** | WAN | *選擇連接到網際網路的介面* |
| **介面2** |訪客網| *選擇與您的 GuestNet 相符的介面* |
| **原型** | ip | *選擇協議，在我們的範例中為IP* |
| **來源** |任何| *來源位址，任意留*|
| **來源端口** |任何| *要塑造的來源端口，保留任何* |
| **目的地** |任何| *目的地IP塑造，留下任意*|
| **目標端口** |任何| *目的港自行塑造，任意留任*|
| **方向** |出 | *符合傳出包（上傳）* |
| **目標** | PipeUp-1Mbps | *選擇上傳管道* |
| **描述** |訪客網路上傳 | *輸入描述性名稱* |

現在按apply啟動流量整形規則。
