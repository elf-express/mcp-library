# 恩托彭

## 安裝

首先，您必須從可透過 System ‣ Firmware ‣ Plugins 存取的插件視圖安裝 ntopng 插件 (os-ntopng)。

頁面重新載入後，您將在 ntopng 的 **服務** 下取得一個新選單項目。如果您沒有安裝 Redis 插件，您將在 ntopng 主選單中收到警告。請返回 System ‣ Firmware ‣ Plugins，安裝 os-redis，切換到 Services ‣ Redis 並啟用該服務。這足以運行 ntopng。

## 常規設定

啟用ntopng

啟用並啟動 ntopng。

介面

您可以在此處設定 ntopng 應偵聽的介面。如果您不選擇任何接口，它將偵聽系統中的第一個接口，例如em0，但您可以根據需要更改ntopng的UI內的接口；當設置顯式接口時，您將不會獲得其自己的 UI 中呈現的任何其他接口。

HTTP 端口

端口 ntopng 的 UI 應該監聽。當您將其保留為預設值時，只需打開瀏覽器並使用連接埠 3000 和 HTTP 進入防火牆IP。如果您想確保連線安全，請隨意設定 HAProxy 或 Nginx 作為反向代理（SSL 卸載）。

DNS模式

您可以在此選擇 ntopng 是否應嘗試將 IP 解析為主機名稱。
