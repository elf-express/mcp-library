# 23.10系列


OPNsense 商業版過渡到此23.10版本，包括許多MVC/API轉換、新的 OpenVPN「實例」設定選項、OpenVPN 群組別名支援、OpenVPN 的延遲驗證、FreeBSD 13.2, PHP 8.2 、重寫的 WireGuard 核心外掛等等。

升級前請務必閱讀遷移說明。

下載連結如下。安裝指南 [\[1\]](<55 初始安裝和配置.md>) 和映像的校驗和也可以在下面找到。

[https://downloads.opnsense.com/](https://downloads.opnsense.com/)

遷移說明、已知問題與限制：

-   Unbound ACL現在預設接受所有流量，不再自動產生條目。這樣做是為了避免動態位址配置（尤其是VPN介面）出現連線問題。如果您不希望這樣，可以將其預設為阻止，並手動新增允許的條目。
    
-   Dpinger 不再自行觸發警報，因為它的機制太簡單，無法像 Apinger 那樣偵測丟包和延遲。延遲和丟包觸發機制已修復，日誌記錄也得到了改進。 rc.syshook 中的「monitor」功能仍然存在，但僅出於與現有使用者腳本的兼容性考慮而提供。
    
-   IPsec「隧道設定」 GUI現已棄用，可手動遷移至「連線」 GUI 。目前沒有計劃移除已棄用的舊組件，因此可以不受限制地使用。
    
-   新的 OpenVPN 實例頁面和API創建了一組獨立的實例，這些實例更嚴格地遵循 OpenVPN 的上游文件。舊版客戶端/伺服器設定無法透過API進行管理，也不會被遷移，但將繼續獨立運作。
    
-   舊的 DynDNS 插件已被移除，取而代之的是適用於 ddclient 的更新的MVC/API插件。 ddclient 今年曾一度停止維護數月，但目前正在準備發布新版本。我們一直維護著該軟體的副本，並在開發版本中修復了錯誤，並在補丁可用時將其提交到上游。此外，該插件還提供了一個原生 Python 後端，支援 Dyndns2 協定、 AWS Route 53、Azure、Cloudflare 和 DuckDNS。
