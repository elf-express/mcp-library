## [建築](#id2)

OPNsense® 的 **軟體設定** 和安裝僅適用於 [x86-64](https://en.wikipedia.org/wiki/X86-64) 微處理器架構。

## [嵌入式與完整](#id3)

OPNsense 為所有主要版本提供兩種影像類型：嵌入式影像和完整影像。嵌入式映像適用於由於防火牆上缺乏儲存和/或控制台存取（VGA/序列）等本機資源而需要預先安裝儲存媒體的環境。該映像也經過定制，可以減少寫入週期，但該映像可以在任何地方使用。使用嵌入式映像的另一個原因是無需本地控制台存取即可安裝 OPNsense。透過將映像預先寫入儲存裝置、安裝儲存裝置並引導系統來管理安裝。

完整映像檔提供 OPNsense Importer、Live Environment 和 Installer 等安裝工具。發布完整映像以支援不同的控制台/硬體安裝要求。

兩種映像類型都可以從虛擬磁碟 (VM)、[SD 記憶卡](https://en.wikipedia.org/wiki/Secure_Digital), USB 磁碟、[固態磁碟 (SSD)](https://en.wikipedia.org/wiki/Solid-state_drive) 或 [硬碟 (HDD)](https://en.wikipedia.org/wiki/Hard_disk_drive) 安裝和運行。

嵌入圖像和完整圖像之間的主要區別是：

|嵌入式|完整|
| --- | --- |
|寫入RAM磁碟 |寫入本機磁碟 |
|重啟後無日誌資料保留 |重啟後日誌資料保留|
|不適用於本機磁碟寫入 |適合磁碟寫入。 |
|僅限嵌入式使用，SWAP 檔案可選 |可以啟用RAM磁碟為嵌入式模式。 |

嵌入式映像僅將日誌記錄和快取資料儲存在記憶體中，而完整版本會將資料儲存在本機磁碟機上。完整版本可以透過啟用RAM磁碟來模仿嵌入式版本的行為，這對於SD記憶卡安裝特別有用。

警告

有關安裝前硬體要求的更多信息，請參閱[硬體調整和設定](<54 硬體尺寸和設置.md>)一章。

根據您的硬體和使用案例，可以使用不同的安裝選項：

|類型 |描述 |圖像類型|
| --- | --- | --- |
| DVD | ISO 映像在VGA-only 模式下啟動到即時環境，並支援 UEFI |完整|

|奈米|用於預先安裝到 >=4 GB USB 驅動器、SD 或 CF 卡上的映像，用於在串行控制台 (115200) 模式下運行並具有輔助 VGA 支援的嵌入式設備（儘管沒有內核訊息）|嵌入式|

注意事項

所有完整映像類型都可以在啟動到 Live 環境之前運行 [OPNsense Importer](#opnsense-importer)，並且在啟動到 Live 環境後也可以運行 [Installer](#install-to-target-system)。

警告

閃存卡只能承受有限次數的寫入和重新寫入。對於Nano鏡像，**/var/log**和**/tmp**預設為內存盤，以延長特殊情況下CF/SD卡和SSD的使用壽命。

若要啟用非嵌入式版本：前往 System ‣ Settings ‣ Miscellaneous ‣ Disk / Memory Settings，變更設置，然後重新啟動。也可以考慮啟用外部系統日誌伺服器。

## [下載並驗證](#id6)

OPNsense 發行版可以從我們的 [鏡像](https://opnsense.org/download) 之一[下載](https://opnsense.org/download)。

OpenSSL 用於映像檔驗證。驗證過程需要4個文件：

-   SHA-256 校驗與文件 (<filename>.sha256)
    
-   bzip 壓縮的圖片檔案 (<filename>.<image>.bz2)
    
-   未壓縮圖片檔案的簽名檔（<filename>.<image>.sig）
    
-   OpenSSL 公鑰 (<filename>.pub)
    

使用 OPNsense 鏡像之一下載這些檔案：

1.  前往 OPNsense [下載](https://opnsense.org/download) 頁面底部。
    
2.  點擊距離您所在位置最近的可用鏡子之一。
    
3.  根據您的圖像類型下載上述每個檔案之一。
    

需要 OpenSSL 公鑰 (.pub) 進行驗證。儘管該文件在鏡像存儲庫中可用，但您不應信任那裡的副本。下載它，打開它，並驗證公鑰與其他來源的公鑰是否匹配。如果沒有，鏡像可能已被駭客入侵，或者您可能是中間人攻擊的受害者。獲取公鑰的其他一些來源包括：

-   [https://pkg.opnsense.org/releases/mirror/README](https://pkg.opnsense.org/releases/mirror/README)
    
-   [https://forum.opnsense.org/index.php?board=11.0](https://forum.opnsense.org/index.php?board=11.0)
    
-   [https://opnsense.org/blog/](https://opnsense.org/blog/)
    
-   [https://github.com/opnsense/changelog/tree/master/community](https://github.com/opnsense/changelog/tree/master/community)
    
-   [https://pkg.opnsense.org](https://pkg.opnsense.org/) (/<FreeBSD:<version>:<architecture>/<release version>/sets/changelog.txz)
    

注意事項

只有鏡像的主要發佈公告包含公鑰，更新發佈公告則不會。即22.1將在發佈公告中擁有公鑰副本，但22.1.9不會。

下載所有必需的文件並驗證公鑰是否與上面列出的備用來源之一中找到的公鑰匹配後，您可以相對確信該密鑰沒有被篡改。若要驗證下載的映像，請執行以下命令（用括號中的檔案名稱取代您下載的檔案）：

```
openssl sha256 OPNsense-<filename>.bz2
```

將 checksum 指令輸出與檔案 `OPNsense-<version>-OpenSSL-checksums-amd64.sha256` 中的校驗和值進行比對。如果校驗和不匹配，請重新下載映像檔。

如果校驗和匹配，則繼續執行驗證命令。

```
openssl base64 -d -in OPNsense-<filename>.<image>.sig -out /tmp/image.sig
openssl dgst -sha256 -verify OPNsense-<filename>.pub -signature /tmp/image.sig OPNsense-<filename>.<image>
```

警告

確保在驗證之前使用`bunzip2`解壓鏡像。我們的簽名是在壓縮之前產生的（從 OPNsense 版本 24.1 開始）

如果第二個指令的輸出是“**Verified OK**”，則您的映像檔已成功驗證，可以安全地從中進行安裝。任何其他輸出，您可能需要檢查命令是否有錯誤，或者圖像檔案可能已洩露。

## [安裝媒體](#id7)

現在您已經從上面下載並驗證了安裝映像，您必須先解壓縮映像文件，然後才能將映像寫入磁碟。對於類別 Unix 作業系統，請使用下列命令：

```
bzip2 -d OPNsense-<filename>.bz2
```

對於 Windows，請使用 [7zip](https://www.7-zip.org/download.html) 等應用程式。命令/應用程式完成後，`.bz2`將從檔案名稱末尾刪除。

解壓縮映像後，您可以建立安裝媒體。安裝 OPNsense 最簡單的方法是使用 USB “[vga](#installation-media)” 映像。如果您的目標平台有序列控制台接口，請選擇「[serial](#installation-media)」映像。如果您需要了解有關使用串行控制台介面的更多信息，請參閱[串行存取操作方法](<60 序列存取.md>)。

將映像寫入 USB 隨身碟 (>=1 GB) 或硬碟，對於類 Unix 作業系統使用 dd，對於 Windows，使用 physdiskwrite、[Etcher](https://www.balena.io/etcher#download-etcher) 或 [Rufus](https://rufus.ie/)。

**免費BSD**

```
dd if=OPNsense-##.#.##-[Type]-[Architecture].img of=/dev/daX bs=16k
```

其中 X = USB 快閃磁碟機的裝置編號（檢查`dmesg`）

**開放BSD**

```
dd if=OPNsense-##.#.##-[Type]-[Architecture].img of=/dev/rsd6c bs=16k
```

該裝置必須是 ENTIRE 裝置（在 Windows/DOS 語言中：「C」分割區）和原始 I/O 裝置（裝置「sd6」前方的「r」），而不是區塊模式裝置。

**Linux**

```bash
sudo dd if=OPNsense-##.#.##-[Type]-[Architecture].img of=/dev/sdX bs=16k
```

其中 X = USB 快閃磁碟機的 IDE 裝置名稱（使用 hdparm -i /dev/sdX 檢查）（忽略有關尾隨垃圾的警告 - 這是因為數位簽章）

**macOS**

```bash
sudo dd if=OPNsense-##.#.##-[Type]-[Architecture].img of=/dev/rdiskX bs=64k
```

其中 r = 原始設備，X = CF 卡的磁碟設備號碼（檢查「磁碟工具」）（忽略有關尾隨垃圾的警告 - 這是因為數位簽章）

**Windows**

```
physdiskwrite -u OPNsense-##.#.##-[Type]-[Architecture].img
```

（使用v0.3或更高版本！）

## [安裝說明](#id9)

安裝說明

OPNsense 安裝引導程序可讓我們執行幾個可選的設定步驟。啟動過程被設計為始終啟動到實時環境，允許我們直接訪問GUI甚至SSH。如果逾時，請重新啟動啟動程序。

### [OPNsense 導入器](#id10)

所有完整映像都具有 OPNsense 導入器功能，可靈活恢復失敗的防火牆、透過在記憶體中使用現有配置運行新版本或將配置遷移到新硬體安裝來測試新版本，而無需覆蓋當前安裝。使用導入器在磁碟上現有配置的先前安裝與新安裝/遷移之間略有不同。

對於已安裝 OPNsense 且配置完好的系統，流程如下：

1.  使用安裝媒體引導系統
    
2.  當您看到 **「按任意鍵啟動配置導入程式」** 時，請按任意鍵。
    
    1.  如果您看到登入提示，則表示您已通過匯入程序，需要重新啟動。
        
3.  輸入包含配置的現有磁碟機的裝置名稱，然後按 Enter 鍵。
    
4.  如果導入程式成功，引導程序將使用磁碟上儲存的配置繼續進入即時環境。
    
5.  如果導入程式不成功，我們將返回到設備選擇提示。確認設備名稱正確並重試。否則，可能會出現磁碟損壞並從備份還原的情況。
    

此時，系統將使用現有配置在即時環境中啟動功能齊全的防火牆，但不會覆蓋先前的安裝。使用此功能可以安全地預覽或測試升級。

對於新安裝或遷移，請遵循以下流程：

1.  我們必須有一個使用 FAT 或 FAT32 檔案系統格式化的第二個 USB 驅動器。
    
    1.  首選不可啟動的USB驅動器。
        
2.  在 USB 磁碟機的根目錄下建立 **conf** 目錄
    
3.  將 *未加密的* <downloaded backup>.xml 放入 /conf 並將檔案重新命名為 **config.xml** (`/conf/config.xml`)
    
4.  將安裝媒體和第二個USB驅動器放入系統中並啟動/重新啟動。
    
5.  透過啟動選單或BIOS (UEFI) 從 OPNsense 安裝媒體啟動系統。
    
6.  當您看到：**「按任一鍵啟動配置導入程式」時，請按任一鍵**
    
7.  輸入第二個USB驅動器的裝置名稱，例如da0 或 nvd0 ，然後按 Enter。
    
    1.  如果導入程式成功，引導程序將使用儲存在USB磁碟機上的設定繼續進入即時環境。
        
    2.  如果不成功，導入器將出錯並返回到裝置選擇提示。在這種情況下，請再次重複步驟 1-3。
        

### [生活環境](#id11)



使用 OPNsense 完整映像（DVD, VGA、序列）啟動後，無論是否使用 OPNsense 導入器，防火牆都會處於即時環境中。我們可以透過本地控制台、GUI（HTTPS）或SSH與Live環境互動。

預設情況下，我們可以使用使用者`root`和密碼`opnsense`登入shell，透過本機控制台操作即時環境。

預設情況下，可以使用使用者名稱：`root`密碼：`opnsense`在[https://192.168.1.1/](https://192.168.1.1/)訪問GUI（除非匯入了先前的設定）。

使用 SSH 我們可以存取位於 IP **192.168.1.1**的防火牆。**root**和**installer** 使用者都可以使用上面指定的密碼。

注意事項

安裝媒體是唯讀的，這表示您目前的即時配置將在重新啟動後遺失。

繼續 [OPNsense 安裝程序](#opnsense-installer) 將 OPNsense 安裝到本機儲存裝置。

### [OPNsense 安裝程序](#id12)

注意事項

若要呼叫安裝程序，請使用使用者 **installer**和密碼**opnsense** 登入

使用 OPNsense 完整映像（DVD, VGA，串列）成功啟動後，防火牆將出現在即時環境的登入：提示字元處。若要開始安裝流程，請使用使用者`installer`和密碼`opnsense`登入。如果使用導入程式導入現有配置，則安裝者和 root 使用者密碼將是導入配置中的 root 密碼。

如果安裝程式使用者不起作用，請以 root 使用者身分登錄，然後從選單中選擇：`8) Shell`，然後輸入`opnsense-installer`。如果您需要重新執行匯入，也可以透過這種方式執行 `opnsense-importer`。

始終可以運行安裝程式來克隆現有系統，甚至對於 Nano 映像也是如此。這對於建立即時備份以供以後恢復非常有用。

提示

也可以使用 SSH 從內部主機啟動安裝程式。預設IP位址為`192.168.1.1`

注意

安裝具有 SD 或 MMC 快閃記憶體卡儲存的裝置時，請確保選擇 UFS 檔案系統，並在磁碟選擇中選擇 `mmcsd0`。不要選擇`da0`，因為它是USB 驅動器。例如，這適用於DEC677桌面安全設備。

安裝過程包括以下步驟：

1.  鍵映射選擇 - 預設配置應該適合大多數情況。
    
2.  安裝 (UFS|ZFS) - 選擇 UFS 或 ZFS 檔案系統。 ZFS 在大多數情況下是最好的選擇，因為它是最可靠的選擇，但它確實需要足夠的容量（至少幾千兆位元組）。
    
3.  分區 (ZFS) - 選擇設備類型。使用單一磁碟時，預設選項（條帶）通常是可以接受的。
    
4.  磁碟選擇 (ZFS) - 選擇儲存設備，例如`da0` 或 `nvd0`
    
5.  最後的機會！ - 選擇「是」繼續分割區並格式化磁碟。但是，這樣做會**破壞**磁碟的內容。
    
6.  繼續使用建議的交換 (UFS) - 此處「是」通常沒問題，除非安裝目標非常小（< 16GB）
    
7.  選擇 Root 密碼 - 更改並確認新的 root 密碼
    
8.  選擇完整安裝 - 退出安裝程式並重新啟動電腦。系統現已安裝並準備好進行初始設定。
    

警告

您將會遺失安裝盤上的所有檔案。如果要使用另一個磁碟，則選擇自訂安裝而不是快速/輕鬆安裝。

### [奈米影像](#id13)

要使用奈米圖像，請遵循以下過程：

1.  使用Nano鏡像建立系統磁碟。請參閱[安裝媒體](#installation-media)如何將nano鏡像寫入磁碟。
    
2.  將系統磁碟機安裝到系統中。
    
3.  將系統 (BIOS) 配置為從此磁碟啟動。
    
4.  系統啟動後，防火牆就可以進行設定了。
    

使用嵌入式系統的奈米映像，您的防火牆已經啟動並運行。預設情況下，停用記憶體磁碟（RAM 磁碟）的配置設置，透過將這些分割區掛載到系統記憶體中來最小化相關分割區的寫入週期，並且報告功能處於停用狀態。

## [初始配置](#id14)

安裝完成後，系統會提示您進行介面分配。如果您忽略這一點，則將套用預設設定。安裝以登入提示結束。

預設情況下，您必須登入才能進入控制台。

**歡迎留言**

提示

使用者可以使用其憑證登入控制台選單。全新安裝後的預設憑證是使用者名稱「root」和密碼「opnsense」。

VLAN 和分配介面

如果您選擇手動指派介面或找不到設定文件，系統會要求您指派介面和 VLAN。 VLAN 是選購的。如果您不需要 VLAN，則選擇**否**。您始終可以稍後配置 VLAN。

LAN, WAN及可選接口

第一個接口是LAN接口。鍵入適當的介面名稱，例如“em0”。第二個接口是WAN接口。輸入適當的介面名稱，例如“em1”。可能的附加介面可指派為OPT 介面。如果您指派了所有接口，您可以按\[ENTER\]並確認設定。 OPNsense 將設定您的系統並在完成後顯示登入提示。

最少的安裝操作

如果是最低安裝設定（即在CF卡上），OPNsense 可以使用所有標準功能運行，但需要磁碟寫入的功能除外，例如像 Squid 這樣的快取代理。不要建立交換片，而是建立 RAM 磁碟。在GUI中啟用系統‣設定‣雜項‣RAM磁碟設定並將大小設為100-128MB或更大，取決於您可用的RAM。之後重新啟動。

**手動啟用RAM磁碟**

[圖：../_images/Screenshot_Use_RAMdisks.png](https://docs.opnsense.org/_images/Screenshot_Use_RAMdisks.png)

然後透過控制台，檢查您的 /etc/fstab 並確保您的主分區有 **rw,noatime**而不是只有**rw**。

```
0)     Logout                              7)      Ping host

3)     Reset the root password             10)     Filter logs
4)     Reset to factory defaults           11)     Restart web interface
5)     Reboot system                       12)     Upgrade from console
6)     Halt system                         13)     Restore a configuration
```

表：*控制台選單*

opsense-更新

OPNsense 具有命令列介面 (CLI) 工具「opnsense-update」。透過選單選項 **8) Shell**，使用者可以存取 shell 並使用 opnsense-update。

如需協助，請輸入 *man opnsense-update* 並按 \[Enter\]。
