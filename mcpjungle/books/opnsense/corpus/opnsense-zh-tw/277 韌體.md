# 韌體

|方法|模組|控制器|指令 |參數|
| --- | --- | --- | --- | --- |
| `POST` | 核心 | 韌體 | 審計 | |
| `POST` | 核心 | 韌體 | 更新日誌 | $version |
| `POST` | 核心 | 韌體 | 檢查 | |
| `POST` | 核心 | 韌體 | 連接 | |
| `GET` | 核心 | 韌體 | 取得 | |
| `GET` | 核心 | 韌體 | 取得選項 | |
| `POST` | 核心 | 韌體 | 健康 | |
| `GET` | 核心 | 韌體 | 資訊 | |
| `POST` | 核心 | 韌體 | 日誌 | $clear |
| `POST` | 核心 | 韌體 | 關機 | |
| `POST` | 核心 | 韌體 | 重新啟動 | |
| `POST` | 核心 | 韌體 | 重新同步插件 | |
| `GET` | 核心 | 韌體 | 運作中 | |
| `POST` | 核心 | 韌體 | 集 | |
| `POST` | 核心 | 韌體 | 狀態 | |
| `POST` | 核心 | 韌體 | 同步插件 | |
| `POST` | 核心 | 韌體 | 更新 | |
| `POST` | 核心 | 韌體 | 升級 | |
| `GET` | 核心 | 韌體 | 升級狀態 | |

例如：

```bash
curl -k -u "$key":"$secret" https://opnsense.local/api/core/firmware/getfirmwareconfig -v
```

```bash
curl -k -u "$key":"$secret" https://opnsense.local/api/core/firmware/status -v
```

```bash
curl -d '' -k -u "$key":"$secret" https://opnsense.local/api/core/firmware/changelog/18.1 -v
```

|方法|模組|控制器|指令 |參數|
| --- | --- | --- | --- | --- |
| `POST` | 核心 | 韌體 | 詳細資料 | $pkg\_name |
| `POST` | 核心 | 韌體 | 安裝 | $pkg\_name |
| `POST` | 核心 | 韌體 | 授權 | $pkg\_name |
| `POST` | 核心 | 韌體 | 鎖定 | $pkg\_name |
| `POST` | 核心 | 韌體 | 移除 | $pkg\_name |
| `POST` | 核心 | 韌體 | 重新安裝 | $pkg\_name |
| `POST` | 核心 | 韌體 | 解鎖 | $pkg\_name |

```bash
curl -d '' -k -u "$key":"$secret" https://opnsense.local/api/core/firmware/lock/os-xen -v
```

```bash

```
