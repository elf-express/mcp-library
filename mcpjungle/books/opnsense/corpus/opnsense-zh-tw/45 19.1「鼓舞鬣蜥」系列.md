# 19.1「鼓舞鬣蜥」系列


四年多來，OPNsense 透過模組化和強化開源防火牆、簡單可靠的韌體升級、多語言支援、HardenedBSD 安全性、上游軟體更新的快速採用以及清晰穩定的 2 條款BSD 許可來推動創新。

19.1 版本綽號“鼓舞人心的鬣蜥”，自 6 個月前 18.7 發布以來，總共包含 620 個單獨的更改，分佈在 12 個中間版本中，包括最近的候選版本。這是平均每月 2 個穩定版本，包括安全性更新和重要錯誤修復！如果我們必須選擇幾個亮點的話，那就是： 防火牆別名 API 終於到位了。到 HardenedBSD 11.2 的遷移已完成。 2FA 現在可與遠端 LDAP / 本地 TOTP 組合搭配使用。 OpenVPN 用戶端匯出也被重寫以獲得完整的 API 支援。

## 19.1.7（2019 年 5 月 2 日）

此更新具有許多改進，例如對橋接器的連結本機支援、HA 同步整合、為大多數系統下載功能將本機 CA 新增至受信任的 SSL 憑證、針對 IPsec 和 Web 代理程式的基於插件的 PAM 驗證返工以及針對 hostapd / wpa\_supplicant 2.8 和 Suricata 4.1.4 的第三方修復。

Python 3 遷移現在也在進行中，需要引入兩個 Python 版本，這可能會對嵌入式 Nano 安裝造成很大負擔，但我們看不到另一種方法來完成這項繁瑣的任務，該任務可能會延伸到 19.7 中以在 20.1 中完全執行。

說到 20.1：這是眾多提醒中的第一個，20.1 將終止 i386（英特爾 32 位）專營權，多年來社區內多次討論過這一點。我們希望 ARM64 能夠成為可行的替代品。但那是另一次了。

您可能已經注意到，該專案並未每隔一周發布一次版本，原因有很多：

在安全性方面，我們沒有進行許多必要的第三方軟體更新。在功能方面，我們正在為即將推出的 19.7 系列進行大量改進，這些改進現在將滲透到 19.1.x 中，但同時也需要更大規模的準備和測試。在社群方面，由我們的合作夥伴 max 贊助。為此，我們開始致力於更好的預設閘道切換，這導致了整體網關整合返工，然後迅速進行了介面處理重組，這反過來又提高了核心服務的插件功能（OpenVPN、IPsec、Unbound、Dnsmasq、DHCPD、Dpinger）。現在來看，這是迄今為止對多年前建立的程式碼進行的最大規模的返工，並且只是偶爾進行修補。我們希望這表明我們對程式碼庫的奉獻精神，即使事情並不總是 100% 無錯誤。如果您覺得現在是嘗試開發版本的好時機，請讓我們了解它的效能。

-   系統：將會話檔案移到自己的目錄中（強制當前會話過期）
