# 配置蜂巢式調變解調器


OPNsense 支援各種USB和 miniPCIe 蜂窩數據機，可用作主要互聯網 ( WAN ) 連接或用作固定/乙太網路連接的故障轉移。

本指南將向您展示如何輕鬆新增新的數據機並將其配置為主要WAN連接。

## 支援的設備

一般來說，OPNsense 應該支援所有 FreeBSD 核心支援的蜂巢式調變解調器（請參閱最新的<https://cgit.freebsd.org/src/tree/sys/dev/usb/serial/u3g.c#n197> ）。但是，並非所有裝置的行為都相同，您可能需要使用特定的AT命令來調整您的網卡，例如在初始化字串中進行設定。

本指南中的螢幕截圖適用於華為 ME909u-521 miniPCIe 蜂巢式調變解調器。

## 選擇合適的硬體

根據您想要使用調變解調器的國家/地區，您可能需要不同的蜂巢式調變解調器。 mPCIe 卡價格較高，因此請確保您選擇的設備支援您要使用的國家/地區和運營商的LTE頻段。您可以使用 [FrequencyCheck](https://www.frequencycheck.com/)等網站來尋找所使用的頻段，並選擇支援這些頻段的蜂巢式調變解調器。

您還應該購買合適的尾纖天線電纜和LTE天線。請注意， LTE天線的介面通常與Wi-Fi天線不同，請據此選擇合適的設備。選擇合適的天線對訊號品質有很大影響。對於LTE, MIMO （多輸入多輸出）天線，應考慮使用其他類型的天線，例如請參閱[本指南](https://www.specialistantennas.co.uk/news/lte-antenna-choices-considerations) 。

注意事項

在 OPNsense 中設定調變解調器時，請務必將天線連接到數據機。如果沒有天線，幾乎不可能接收任何訊號。

## 第一步——與蜂窩調製解調器通信

首先，我們需要確定您的數據機上哪個裝置正在接收AT指令。在本例中使用的華為數據機，該設備是`/dev/cuaU0.0` ，其他數據機可能透過另一個設備提供AT介面。

在 FreeBSD 中， `/dev/cuauN`設備是用於調製解調器而不是終端的呼叫端口，請參閱 FreeBSD 手冊中的 [26.2.1](https://www.freebsd.org/doc/handbook/serial.html)部分。

找到正確連接埠的最佳方法是向其發送AT命令。可以使用`cu`工具進行測試：

```
cu -l /dev/cuaU0.2
Connected
AT (<-type that)
OK
```

看到`Connected`後，輸入`AT` 。如果沒有收到`OK`的回复，請輸入`~.`退出並嘗試下一個裝置。在本例中，使用的是 Sierra Wireless MC7430網卡，只有`/dev/cuaU0.2`設備會回傳`OK`回覆。

現在，檢查SIM卡是否可用且可以存取：

```
cu -l /dev/cuaU0.2
Connected
AT+CPIN?
+CPIN: READY
```

這裡可能會出現多種問題， SIM卡可能未被偵測到，或者SIM卡可能設定了 PIN 碼。

一旦SIM卡準備就緒，使用`~.`退出`cu` 。

注意事項

若要清除密碼，請先使用`AT+CPIN="1234"`檢查其是否有效，其中`1234`是您SIM卡的密碼。若要清除密碼，請輸入`AT+CLCK="SC",0,"1234"` 。密碼現在應該已清除。

注意事項

如果在嘗試`AT+CPIN?`之後始終無法獲得`READY`您可以嘗試更換系統上的不同 mPCIe 插槽。就我而言，在PC Engines APU主機板和 Sierra Wireless 網卡上，我必須更換插槽才能正確識別SIM網卡。中間的那個插槽解決了我的問題。如果您知道這是怎麼回事，或知道原因，請將您的發現新增至此文件。此外， APU主機板有多個SIM插槽，如果第一個方法無效，請嘗試兩個插槽。

## 步驟 2 - 配置點對點設備

轉到“介面”‣“點對點”‣“設備”，然後按一下表單右上角的**新增**。

請如下填寫表格（範例為荷蘭移動4G KPN套餐訂閱）：

|   |   |
| --- | --- |
| **連結類型** | PPP |
| **連結介面** | /dev/cuaU0.0 ( HUAWEI行動連線 - 數據機) |
| **描述** | 4G 蜂窩網路 |
| **服務提供者** | 選擇國家/地區、服務提供者和套餐以進行自動設定 |
| **使用者名稱** | 留空（用於NL KPN ） |
| **密碼** | 留空（用於NL KPN ） |
| **電話號碼** | *99#（用於NL KPN ） |
| **存取點名稱 ( APN )** | fastinternet (適用於NL KPN 4G) |

若您需要輸入PIN號碼，請點選**進階選項**

點擊**儲存**以套用設定。

[圖：../../_images/4g_configure_ppp.png](https://docs.opnsense.org/_images/4g_configure_ppp.png) [圖：../../_images/ppp_celular_configured.png](https://docs.opnsense.org/_images/ppp_celular_configured.png)

## 步驟 3 - 分配WAN接口

要分配接口，請轉到“接口”‣“分配”，在本例中，我們將把此接口設為主要互聯網連接，並相應地更改WAN分配。

為此，只需將 **WAN**的**網路連接埠**變更為**ppp0 (/dev/cuaU0.0) - 4G 蜂窩網路**。

現在點擊表單下方的**儲存**按鈕。

如果一切順利，那麼就一切就緒，預設網關將是您的蜂窩網路連接的網關。

[圖：../../_images/Interface_assignment_4g.png](https://docs.opnsense.org/_images/Interface_assignment_4g.png)

## 第四步 - 故障排除

如果仍然無效，請先查看手機PPP連接的日誌，具體操作為：系統‣日誌檔案‣常規。運氣好的話，可以直接在日誌中看到出錯的原因。遺憾的是， PPP日誌的資訊量有限，可能根本幫不上忙。

如果實在找不到問題所在，重啟裝置重新初始化有時會有幫助。這點在嵌入式裝置上尤其適用，重啟次數過多反而會適得其反。如果您在各種設定選項中迷失了方向，恢復原廠設定也是個好辦法。根據我們的經驗，使用不同供應商的SIM卡時，無論出於何種原因，都需要恢復出廠設定才能正常運作。

注意事項

如上所述，需要準備SIM卡。請參閱本教學第一步驟中的提示，確保一切準備就緒。

注意事項

某些 Sierra Wireless 數據機似乎仍然需要特定的初始化字串才能正常運作。一個似乎適用於多個使用者和LTE網卡的初始化字串是`&F0E1Q0 +CMEE=2` 。無論如何，您應該先嘗試不使用初始化字串，只有在不使用初始化字串的情況下無法建立連接時才嘗試使用。您可以在「介面」‣「點對點」‣「裝置」‣「您的特定裝置」‣「進階選項」‣「初始化字串」中新增此字串。

當設備看起來工作正常時，檢查介面是否分配了IP位址，轉到“介面”‣“概覽”，然後按一下WAN介面查看詳細資訊。

您應該會看到IP位址、 IP網關和ISP DNS伺服器。如果全部填寫完整，則表示您的防火牆阻止了流量，或網路連線有問題。

如果操作失敗，您可能需要手動檢查問題所在。請閱讀 FreeBSD 手冊中的 [故障排除PPP連接](https://www.freebsd.org/doc/handbook/ppp-troubleshoot.html)部分以獲取更多信息，並諮詢 OPNsense 支援論壇。
