# Python PEP


對於 Python 程式碼，Python 增強建議 (PEP) 適用。詳細資訊請參閱[Python開發者指南](https://www.python.org/dev/)。最基本的是[PEP8：Python程式碼風格指南](https://www.python.org/dev/peps/pep-0008/)。可以使用[Python風格指南檢查器](https://pypi.python.org/pypi/pycodestyle/)檢查是否符合PEP8。
