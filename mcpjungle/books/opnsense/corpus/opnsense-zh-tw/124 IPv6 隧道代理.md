# IPv6 隧道代理


**原作者：** 肖恩·韋伯

## 介紹

OPNsense 支援本機 IPv6 以及隧道 IPv6。本文說明如何使用 OPNsense 設定 TunnelBroker（Hurricane Electric 的 IPv6-in-IPv4 隧道）。如果您位於 US 並且使用 Netflix，您可能不想遵循這些說明。 Netflix 現已封鎖 TunnelBroker。

如果您使用 IRC 或需要透過 TunnelBroker 連接存取 SMTP，Hurricane Electric 要求您完成他們的免費 IPv6 認證流程。他們的“聖人”級別是最高級別，將允許您啟用IRC和SMTP。請注意，您的 OPNsense 防火牆必須直接連接到 Internet。落後於NAT是行不通的。

本文的其餘部分假設您已經有一個 TunnelBroker 帳戶。如果沒有，請註冊並完成免費的 IPv6 認證流程。本文通篇提供了螢幕截圖。

## 背景

在 OPNsense 防火牆的 WAN 端啟用 ICMP。 TunnelBroker 的 UI 會告訴您當您在其一端設定隧道時要使用的 IP。

現在新增一條隧道。確保新增路由 /48，因為我們需要它來向每個網路分發單獨的 /64 切片。配置完成後，您的隧道設定應如下所示：

[圖：../../_images/tunnelbroker_setup.png](https://docs.opnsense.org/_images/tunnelbroker_setup.png)

## 步驟 1 - 新增 GIF 隧道

若要設定 OPNsense，請從新增新的 gif 介面開始。前往 Interfaces ‣ Devices ‣ GIF 並點選表單右上角的 **Add**。

使用下列設定並從 TunnelBroker 的 UI 複製 IPv4 和 6 位址。

|   |   |
| --- | --- |
| **家長介面** | *WAN* |
| **GIF遠端位址** | *伺服器 IPv4 位址* |
| **GIF 隧道本機位址** | *用戶端 IPv6 位址* |
| **GIF隧道遠端位址** | *伺服器 IPv6 位址/64* |
| **路由快取** | *已停用* |
| **ECN 友善的行為** | *已停用* |
| **描述** | *隧道經紀人* |

[圖：../../_images/opnsense_add_gif.png](https://docs.opnsense.org/_images/opnsense_add_gif.png)

## 步驟 2 - 將GIF隧道配置為新介面

新建的GIF隧道現在必須指派為新介面。前往介面 ‣ 分配，為 **新介面**選擇 GIF 隧道，然後按一下旁邊的**+** 符號。

然後在 Interfaces ‣ \[OPTX\]（或 Interfaces ‣ \[TunnelBroker\]，取決於您選擇的內容）下，選取 **Enable Interface**並將描述變更為例如 TUNNELBROKER，然後再點擊**Save**。

現在必須在 System ‣ Gateways ‣ Configuration 下將新建立的介面設定為預設 IPv6 網關，方法是編輯新網關條目 TUNNELBROKER\_TUNNELV6 並在儲存前選取 **Upstream Gateway**。

## 第 3 步 - 基本防火牆規則

現在新增基本的防火牆規則。由於我有一個 LAN 網絡和一個 WLAN 網絡，因此我允許 WLAN 發起與 LAN 的連接，但反之則不然。我只有LAN上的伺服器，而我的大多數客戶端都在WLAN（無線LAN）上。我阻止所有傳入LAN和WLAN。當然，出站連線沒問題。

[圖：../../_images/tunnelbroker_fw_rules.png](https://docs.opnsense.org/_images/tunnelbroker_fw_rules.png)

## 步驟 4 - 設定LAN接口

現在配置您的LAN介面。我們將為它提供的靜態 IPv6 位址是您指派的 **/48**中的**/64**位址。我不會簡單地顯示WLAN設置，因為它們是一樣的。您將對其他網路重複相同的過程，但為下一個介面指派一個單獨的**/64** 位址。

[圖：../../_images/tunnelbroker_configure_lan.png](https://docs.opnsense.org/_images/tunnelbroker_configure_lan.png)

## 步驟 5 - 設定 DHCPv6 SLAAC

接下來，我們將為無狀態位址自動設定 (SLAAC) 配置 OPNsense。前往服務 ‣ 路由器通告並選擇一個介面。

將**路由器通告**設定設定為*輔助*，將**路由器優先權**設定設定為*正常*。

[圖：../../_images/tunnelbroker_dhcpv6.png](https://docs.opnsense.org/_images/tunnelbroker_dhcpv6.png)

儲存您的設定。

## 第 6 步 - 測試您的配置

您現在應該已完成 IPv6 的設定。若要測試您的配置，請將 IPv6 電腦聯機，使用您喜歡的工具來確定您是否擁有 IPv6 位址。如果您使用SLAAC，可能需要 30 秒或更長時間才能取得 IPv6 位址。如果您發現您的介面有 IPv6 位址，您可以嘗試前往僅 IPv6 的測試站點，例如 [https://www.doesnotwork.eu/](https://www.doesnotwork.eu/)

## 步驟 7 - 設定端點更新

如果您的 IPv4 位址是動態的，請務必將您的隧道端點保持最新狀態，以維持透過隧道的 IPv6 連線。我們將使用 ddclient 設定自動更新。

首先，在 System ‣ Firmware ‣ Plugins 下安裝 **os-ddclient** 外掛程式。安裝後，刷新UI並前往服務‣動態DNS‣設定。新增帳戶，填寫以下信息，根據需要從 Tunnelbroker 的隧道設定中提取資訊。

|   |   |
| --- | --- |
| **服務** | he-net-隧道 |
| **使用者名稱** | *隧道經紀帳戶使用者名稱* |
| **密碼** | *更新隧道金鑰* |
| **主機名稱** | *隧道ID* |

[圖：../../_images/tunnelbroker_configuration_ddclient.png](https://docs.opnsense.org/_images/tunnelbroker_configuration_ddclient.png) [圖：../../_images/tunnelbroker_tunneldetails_id.png](https://docs.opnsense.org/_images/tunnelbroker_tunneldetails_id.png) [圖：../../_images/tunnelbroker_tunneldetails_key.png](https://docs.opnsense.org/_images/tunnelbroker_tunneldetails_key.png)

對於 **檢查 ip 方法**，選擇將傳回 *IPv4* 位址的任何方法（例如 ipify-ipv4、介面 \[IPv4\] 或 ipv4only.me）。如果使用“介面\[IPv4\]”，也要選擇適當的WAN介面進行監控。

新增供您自己使用的**說明**，並保留所有其他選項不變。啟用並儲存此帳戶配置，然後啟用並啟動動態DNS服務。
