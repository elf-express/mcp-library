# 標準化


流量標準化可以保護內部機器免受互聯網協定和實現不一致的影響。 OPNsense 具有一些通用選項，可在每個介面的基礎上規範某些資料包，在某些情況下需要更詳細的更改，為此可以配置自訂規則。

預設情況下（當未設定 **停用介面清理**時），將對所有流量清理所有接口，並在接口上的**MSS** 中指定時啟用 `fragment reassemble` 並設定 `max-mss`。

注意事項

某些協議，例如 NFS，需要特定的片段處理選項，我需要設定特定的選項，如 **IP Do-Not-Fragment\***

## 設定

規範化規則使用與普通防火牆規則相同的匹配類型，我們不會在這裡詳細介紹。匹配時，可以設定一些不同的選項。

注意事項

當規則重疊時，第一個匹配的規則獲勝，因此每個介面選項在使用者可配置的選項之後排序。

---

|   |   |
| --- | --- |
|最大毫秒數 |強制匹配TCP封包的最大MSS。作為一般規則，也可以在介面上進行設定。 |
| TOS / DSCP |強制使用 TOS/DCP 來匹配 IP 封包。 |
|最低TTL |強制執行最小 TTL 來匹配 IP 封包。 |
|不要碎片|清除符合的 IP 封包的 `dont-fragment` 位，設定後將停用 [IP 碎片](https://en.wikipedia.org/wiki/IP_fragmentation)。 |
|隨機ID|以隨機值取代IP標識字段，以補償許多主機產生的可預測值。此選項僅適用於在可選片段重組後未分段的資料包。 |
