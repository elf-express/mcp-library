# 如何設定郵件網關

## 如何：設定郵件網關

警告

高負載下的郵件網關可能需要大量記憶體和CPU電源。請記住，這些組件有一些硬體需求，例如 ClamAV 和 Redis 插件。不建議在較弱的硬體上運行該軟體。

## 安裝

首先，您必須從插件視圖安裝所需的插件。



所需的插件是：

-   ClamAV
    
-   後綴
    
-   雷迪斯
    
-   垃圾郵件
    

頁面重新載入後，您將在所有已安裝插件的服務下獲得一些新的選單項目。

## 插件的配置

### 1\.蛤蜊病毒

對於ClamAV，您可以按照[ClamAV](<167 ClamAV.md>)中的說明進行操作。

### 2\. Redis（可選但建議）

下一步，我們需要安裝Redis資料庫。快取和 rspamd 插件的某些功能需要 Redis。

警告

如果您沒有設定 Redis 實例，rspamd 的某些元件會自動靜默停用，並且在GUI 中不可見。



對於基本的Redis實例，您只需勾選“啟用Redis”並點擊“應用”即可啟動伺服器。

### 3\.垃圾郵件

首先，您需要透過選取啟用 rspamd 複選框來啟用該外掛程式。如果您已經安裝並配置了 Redis 插件，則您也應該選取第二個複選框。



如果您準備好了，rspamd 應該已啟動並運行。

現在您應該配置您需要的 rspamd 模組。

注意事項

如果 ClamAV 元件已根據 ClamAV (clamd) 配置進行配置，則它會自動啟用或停用自身。

### 後綴

首先，您需要在「網域」功能表中設定要轉送的網域。



點選 + 後，在對話方塊中輸入郵件伺服器的值：



儲存後，通常需要點擊「應用」按鈕，但伺服器無論如何都不會運行，因為需要先配置它。如果新增網域，則必須點擊此按鈕才能套用變更。



在「常規」標籤中，必須啟用 Postfix 服務。如果您的系統設定與您的系統設定不同，您可以在此處覆蓋它們。例如，覆寫主機名稱是有意義的，因為您可能想要使用已在 DNS 中配置為 MX 主機的主機名稱。

您應該保持底部的核取方塊處於啟用狀態，因為它們會啟用限制，從而提供額外的安全層。

儲存變更並切換到反垃圾郵件標籤。



啟用複選框並點擊儲存。

## 跟進任務

在下一步中，您應該進入“防火牆”選單。建立一條新規則，將連接埠 TCP/25 流量從任何連接埠傳遞到此防火牆。
