# API啟用標準服務


OPNsense 包含一個簡單的封裝器，用於處理啟動和停止服務等標準服務作業。在本範例中，我們假設 HelloWorld 範例已建立且模型已存在。

## 先決條件

HelloWorld 範例是本範例的基礎，請務必在開始學習此範例之前先閱讀並嘗試 HelloWorld 範例。

## 配置操作

由於範例中沒有包含服務，我們將首先擴展 configd 模板。編輯`/usr/local/opnsense/service/conf/actions.d/actions_helloworld.conf`並新增以下部分：

```yaml
[start]
command:exit 0
parameters:
type:script
message:hello world service start

[stop]
command:exit 0
parameters:
type:script
message:hello world service stop

[restart]
command:exit 0
parameters:
type:script
message:hello world service restart

[reload]
command:exit 0
parameters:
type:script
message:hello world service restart

[status]
command: echo "hello world is running"
parameters:
type:script_output
message:hello world service status
```

接下來，使用`service configd restart`重啟 configd，並使用以下命令測試這些新呼叫。

```
# configctl helloworld start
OK
# configctl helloworld stop
OK
# configctl helloworld status
hello world is running
# configctl helloworld restart
OK
```

我們的模板只是模擬一項服務，它實際上什麼都不做（ `exit 0` ）。

## 更新服務控制器

接下來，我們將現有控制器更改為使用`ApiMutableServiceControllerBase` ，它將現有模型連結到已定義的服務呼叫。為了避免混淆，HelloWorld 範例中使用的`testAction`將被省略。

/usr/local/opnsense/mvc/app/controllers/OPNsense/HelloWorld/Api/ServiceController.php

```php
use OPNsense\Base\ApiMutableServiceControllerBase;

class ServiceController extends ApiMutableServiceControllerBase
{
    protected static $internalServiceClass = '\OPNsense\HelloWorld\HelloWorld';
    protected static $internalServiceTemplate = 'OPNsense/HelloWorld';
    protected static $internalServiceEnabled = 'general.enabled';
    protected static $internalServiceName = 'helloworld';

    protected function reconfigureForceRestart()
    {
        return 0;
    }
}
```

上述服務定義了以下靜態變數：

-   $internalServiceClass
    
    -   引用模型類，該模型類用於確定此服務是否已啟用（將模型連結到服務）。
        
    
-   $internalServiceTemplate
    
    -   服務啟動前會呼叫 configd 產生配置數據，在這種情況下，它會在控制台上執行相當於`configctl template reload OPNsense/HelloWorld`的命令。
        
    
-   內部服務已啟用
    
    -   模型中的哪個部分包含一個布林值，用於定義服務是否已啟用（general.enabled）？
        
    
-   $internalServiceName
    
    -   指的是操作模板，其中包含啟動/停止/重新啟動/狀態/重新載入操作（actions\_helloworld.conf）。
        
    

`reconfigureForceRestart`覆蓋告訴控制器是否應該在嘗試啟動之前始終停止服務，某些服務可以被指示在不停止的情況下進行重新配置。

提示

當一個服務可以註冊新的[介面](<248 使用插件.md>)時，可以實現受保護的方法`invokeInterfaceRegistration`並使其返回`true` ，之後插件系統將自動偵測介面註冊的變更。

## 終點

將此控制器部署到 HelloWorld 模組後，它將公開下列端點。

| 方法 | 端點 |
| --- | --- |
| `POST` | /api/helloworld/service/stop |
| `POST` | /api/helloworld/service/start |
| `POST` | /api/helloworld/service/restart |
| `POST` | /api/helloworld/service/reconfigure |
| `GET` | /api/helloworld/service/status |
