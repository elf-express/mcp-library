# 介面配置

OPNsense 中的所有流量都透過介面傳輸。預設情況下，會分配WAN和LAN ，但還可以分配更多接口，例如GUESTNET ([強制門戶](<200 強制入口網站和 GuestNET.md>) ) 和PFSYNC ([高可用性](<96 高可用性.md>) )。

注意事項

為了實現傳統相容性，WAN 介面設定為類型DHCP 或具有*網關規則* 選擇的介面直接將回覆封包傳送到對應的網關，即使傳送者位於同一介面上也是如此。在某些罕見的情況下，這會中斷連接，可以透過**防火牆->設定->進階->停用回應**來停用。

## 任務

大多數介面必須分配給一個實體連接埠。預設情況下， LAN分配給連接埠 0， WAN分配給連接埠 1。可以透過「介面」‣「分配」來變更分配情況。此處列出了現有接口，左側顯示接口名稱，下拉列表中選擇物理端口。也可以在此處建立新接口，並使用未佔用的實體連接埠。

建立新介面或變更現有介面時（可透過在概覽中按一下其名稱來完成），可以使用下列選項：

| 選項 | 說明 |
| --- | --- |
| **通用配置** | |
| 啟用接口 | 停用接口，而無需完全移除其分配。 |
| 防止介面移除 | 避免意外移除介面（必須先關閉並儲存設定才能移除介面）。 |
| **通用配置** | |
| 描述 | 如果名稱不足以說明問題，請在此處新增簡短描述。 |
|封鎖私人網路 |封鎖聲稱來自私人位址的流量。在WAN介面上，這種流量不應該合法發生。 |
| 封鎖偽造網路 | 封鎖聲稱來自無效或保留位址（火星資料包）的流量。請注意，這也包括使用OSPF和RTMP的多播流量。 |
| IPv4 設定類型 | 如何取得此連線的 IPv4 位址。 |
| IPv6 設定類型 | 如何取得此連線的 IPv6 位址。 |
| MAC地址 | 可用於偽造MAC地址。通常可以留空（在這種情況下，它將使用硬體的實際MAC位址）。 |
| MTU | [最大傳輸單元](https://en.wikipedia.org/wiki/Maximum_transmission_unit) . |
| MSS | [最大分段大小](https://en.wikipedia.org/wiki/Maximum_segment_size) . |
|速度和雙工|建議將其保留為預設值，除非您知道自己在做什麼並且您選擇的設定與實體連接埠上的設定相符。 |
|動態網關策略|如果可以透過不需要中間系統充當網關的介面直接存取目標，則可以選擇此選項，該選項允許在沒有直接目標位址的情況下建立動態網關。某些隧道類型支援此功能。 |

注意事項

設定沒有靜態隧道位址的VPN客戶端時，可以使用「動態網關策略」選項自動產生到裝置的網關（沒有位址）。

除了這些設定之外，根據「IPv4 配置類型」和「IPv6 配置類型」下的配置，還將啟用下列模組。

| 選項 | 說明 |

| IPv4 位址 | |

| **DHCP客戶端設定** | |
| 配置模式 | |

| 主機名稱 | 此值在請求DHCP租約時作為DHCP客戶端標識符和主機名稱發送。某些 ISP 可能需要此資訊（用於客戶端識別）。 |
| 覆蓋MTU | ISP可能錯誤地設定了MTU值，這可能導致間歇性網路中斷。預設情況下，此值將被忽略。取消設定此選項將允許套用ISP提供的MTU值。 |

*身分關聯*提供與*軌道介面（傳統版）*類似的功能，但不具備自動ISC -DHCPv6和Radvd設定功能。它旨在透過Dnsmasq或Kea/Radvd進行純RA和DHCPv6配置。

## 行動網路

[圖](https://docs.opnsense.org/_images/OPNsense_4G_new.png)

OPNsense 支援 3G 和 4G ( LTE ) 蜂巢式調變解調器作為備用或主WAN介面。同時支援USB和 (mini)PCIe 卡。

### 支援的設備

雖然所有 FreeBSD 支援的裝置都可能在 OPNsense 下運行，但它們的配置取決於一個AT命令字串，該字串可能因裝置而異。為了方便起見，其中一些字串包含在一個易於選擇的設定檔中。

OPNsense團隊測試的設備包括：

-   **華為M909S -120**（設備 cuaUx.0）（需要單獨的SIM卡座/適配器）[已測試：OPNsense 21.1 ]
    
-   **華為 ME909u-521**（設備 cuaUx.0）
    
-   **華為 E220**（設備 cuaUx.0）
    
-   **Sierra Wireless MC7304** (設備 cuaUx.2) \[截至 OPNsense 16.7 \]
    

注意事項

如果您測試過的蜂窩數據機不在清單中，但確實有效，請將其報告給專案組，以便我們將其列入清單並告知其他人。

### 配置蜂巢式調變解調器

設定和配置蜂窩數據機非常簡單，請參閱：[配置蜂窩數據機](<120 配置蜂巢式調變解調器.md>)

### 3G-4G蜂窩網路故障轉移

要設定蜂窩網路故障轉移，只需按照以下兩個操作步驟操作即可：

1.  [配置蜂巢式調變解調器](<120 配置蜂巢式調變解調器.md>)
    
2.  [多WAN](<95 多色WAN.md>)
    

注意事項

對待蜂窩網路連接的方式與對待普通的WAN連接的方式相同。
