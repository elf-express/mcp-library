# Zenarmor（Sensei）概述


## Zenarmor（Sensei）：概述

## 關於

Zenarmor 是 OPNsense 防火牆的一個插件，提供最先進的下一代功能。 Zenarmor 由 Sunny Valley Cyber​​ Security Inc ([https://www.zenarmor.com](https://www.zenarmor.com/) ) 開發。

如果您正在運行 L4 防火牆（所有開源防火牆都屬於此類），並且正在尋找應用程式控制、網路分析和TLS檢查等功能，那麼 Zenarmor 就是您正在尋找的產品。

## 特徵

Zenarmor 為您的防火牆增添了以下新世代功能：

1.  應用程式控制
    
2.  雲端應用控制（Web 2.0控制）
    
3.  進階網路分析
    
4.  網路過濾與安全
    
5.  雲威脅情報
    
6.  基於使用者的篩選和報告
    
7.  Active Directory 集成
    
8.  RESTful API
    
9.  基於雲端的集中式管理和報告
    
10.  基於應用程式/網站類別的流量整形和優先排序
    
11.  基於策略的過濾和服務品質
    
12.  加密威脅防護
    
13.  所有端口TLS檢測（包括所有TCP ，而不僅僅是HTTPS端口）*即將推出*
