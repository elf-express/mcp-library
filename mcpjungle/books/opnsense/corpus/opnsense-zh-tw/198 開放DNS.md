# 開放DNS


[OpenDNS](https://www.opendns.com/) 是一家公司和服務，如果使用其 DNS 伺服器，除了 DNS 查找之外，還透過添加網路釣魚防護和可選內容過濾等功能來擴展網域名稱系統 (DNS)。

當您使用靜態 IP 位址時，通常只需在 System ‣ Settings ‣ General 中輸入 OpenDNS 名稱伺服器就足夠了。

## 設定

註冊 OpenDNS 需要最少的設定。

---

|   |   |
| --- | --- |
|已啟用 |如果啟用，防火牆將向 OpenDNS 發出有關位址變更的訊號 |
|使用者名稱 |使用 OpenDNS 註冊的使用者名稱 |
|密碼 |關聯密碼 |
|網路|在 OpenDNS 的 [網頁儀表板](https://www.opendns.com/dashboard/networks/) 的「管理您的網路」下設定的網路名稱。用於每當WAN介面更改其IP位址時更新節點的IP位址。 |

注意事項

停用服務時，請在 System ‣ Settings ‣ General 中檢查您的名稱伺服器，因為此功能刪除了先前的名稱伺服器。
