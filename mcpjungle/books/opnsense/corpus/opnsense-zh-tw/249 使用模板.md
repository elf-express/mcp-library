# 使用模板


## 一般

對於設定檔生成，我們提供了一個後端服務，可以將 config.xml 資料綁定到 Jinja2 中編寫的模板（[https://jinja.palletsprojects.com/en/stable/](https://jinja.palletsprojects.com/en/stable/)）。

所有可用範本應安裝在 OPNsense 系統上的以下位置：

1.  /usr/local/opnsense/service/templates/
    

## 命名約定

所有範本都應放入包含供應商和套件/應用程式名稱的目錄結構中，我們的範例應用程式放置在該目錄中：

/usr/local/opnsense/service/templates/*OPNsense/範例*

模板包內容

每個範本目錄應至少包含 2 個檔案：

1.  內容描述符，包含實際目標，名稱為+TARGETS
    
2.  一個或多個模板
    

## 目標

+TARGETS 檔案包含範本目錄內的來源範本名稱和以冒號 (:) 分隔的（動態）目標檔名，每個檔案可以插入多行。

例如：

```
example_simple_page.txt:/tmp/template_sample/simple_page.txt
```

將使用模板 example\_simple\_page.txt 建立檔案 /tmp/template\_sample/simple\_page.txt。

注意事項

您可以選擇在呼叫「模板清理」時指定要刪除的文件，可以透過使用目標旁邊的額外標籤來指定，例如：`example_simple_page.txt:/tmp/template_sample/simple_page.txt:/tmp/template_sample/simple_page.*`

預設情況下，呼叫清理時所有目標都將被刪除。

如果您想使用 config.xml 檔案中的資訊作為輸出檔名，您可以使用標籤來定址內容，例如 \[version\] 從 xml 檔案輸入標籤版本。當從 1 個範本產生多個檔案時，您可以使用通配符 (%) 來定址設定檔的一部分，例如 \[interfaces.%.if\] 循環遍歷介面並輸出 **if** 的值。

## 目標覆蓋

每個模板包都可以指定覆蓋，供為 OPNsense 中的功能實施和維護自己的模板的供應商使用。

只需使用模板資料夾的 **+TARGETS.D**目錄中的目標定義新增文件，並使用副檔名**.TARGET**。

例如，OPNsense/Sample 的覆蓋範圍可以使用以下名稱和位置 `/usr/local/opnsense/service/templates/OPNsense/Sample/+TARGETS.D/custom.TARGET`

注意事項

使用此功能時要非常小心，您需要自行維護這些模板，並且 OPNsense 升級後功能可能會中斷。

## 範本

有關模板語言本身的更多信息，請查看 [https://jinja.palletsprojects.com/en/stable/](https://jinja.palletsprojects.com/en/stable/) 以及 /usr/local/opnsense/service/templates/OPNsense/Sample 中安裝的範例。

使用模板引擎時有一種特殊情況，用於產生輸出檔案的每個通配符也會提供給模板，因此您能夠確定哪個過濾器允許此輸出。

這些過濾器儲存在變數 TARGET\_FILTERS 中。

```
{% if TARGET_FILTERS['interfaces.wan'] %}
{% endif %}
```

## 測試使用情況

範本可以透過後端服務 (configd) 呈現，若要在執行的 OPNsense 系統上測試此功能，請使用：

```
# generate template package
configctl template reload OPNsense/Sample
# cleanup files
configctl template cleanup OPNsense/Sample
```

  

## Python 範本使用範例

模板系統本身就是一個單獨的模組，由 configd 使用，要在沒有守護程式的情況下使用（或測試）系統，請使用：

```
# import template system and config.xml handling
from modules import template
from modules import config

# construct a new template object, set root to /tmp/
tmpl = template.Template(target_root_directory='/tmp/')
# open the config.xml and bind to template object
conf = config.Config('/config.xml')
tmpl.set_config(conf.get())

# generate output for OPNsense/Sample
generated_filenames = tmpl.generate('OPNsense/Sample')

# print results
for filename in generated_filenames:
  print ('.. generated : %s'%filename)
```
