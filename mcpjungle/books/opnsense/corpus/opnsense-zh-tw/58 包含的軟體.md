# 包含的軟體

OPNsense® 基本系統包含許多功能，但在某些情況下，您可能需要額外的軟體，這些軟體可以透過外掛程式提供，也可以僅作為二進位套件提供（沒有使用者介面）。

本章旨在詳細介紹系統中包含的元件、它們的存放位置以及在預設情況下未安裝它們時如何安裝它們。

## 作業系統

基本（[FreeBSD](https://www.freebsd.org/) ）系統包含核心和基本軟體包，它們提供了系統啟動和運行所需的基本要素。

這兩個組件都使用`opnsense-update`進行更新，詳情請參閱 [此處](<75 OPNsense 工具.md#opnsense-update>) 。

## 外掛

插件是 OPNsense® 提供的軟體包，可透過使用者介面直接安裝，並且通常帶有最終用戶可存取的設定選項。

由於 OPNsense® 是一個社區驅動的項目，因此這些插件可獲得的（社區/商業）支援量可能有所不同。

注意事項

插件庫由項目方維護。如果插件未能得到維護者的及時更新，則會在某個時間點被移除。 （例如，如果某個外掛程式需要 Python 2，而我們由於上游棄用而停止提供 Python 2，則該外掛程式將被移除。）

## 包裹（pkg）

二進位軟體使用 pkg 工具安裝，該工具使用我們的軟體倉庫（可透過多個鏡像站點存取）。所有已安裝的軟體都可以透過使用者介面「系統」->「韌體」->「軟體包」找到，但在某些情況下，使用者希望透過電腦命令列安裝其他軟體。

要查找所有可用軟體的完整列表，您可以使用以下命令：

```
pkg rquery '%n (%v)'
```

例如，如果您想安裝 GNU (https://www.nano-editor.org/)編輯器，可以使用下列命令：

```
pkg install nano
```

注意事項

OPNsense® 是一個防火牆發行版，我們的目標是盡可能減少系統資源佔用。這意味著我們不會建構世界上所有可用的軟體。如果您需要特定軟體包來滿足您的使用需求，您可以隨時透過 [GitHub](https://github.com/opnsense/tools/issues)上的支援工單進行諮詢，但請注意，我們無法保證核心系統或受支援外掛程式未使用的軟體包在未來能夠持續提供（建置內容可能會隨時間而變化）。

警告

手動在`/usr/local/etc/pkg/repos/`中新增（FreeBSD等）軟體倉庫不受支援，通常會導致意外問題。在報告此類配置的任何問題之前，請先恢復到標準配置。

## 連接埠樹

如果您使用的軟體並非由我們提供，您可以自行建立這些軟體包。為了方便起見，最好使用我們的建置系統，您可以使用以下命令進行操作。

```bash
opnsense-code ports
cd /usr/ports/your/port
make install
```

若要更新軟體包，可以使用以下命令：

```bash
opnsense-code ports
cd /usr/ports/your/port
make reinstall
```

某些連接埠可能還需要安裝原始碼樹：

```
opnsense-code src
```

注意事項

關於建置連接埠包，有許多資源可供參考，例如 [https://www.freebsd.org/ports/](https://www.freebsd.org/ports/)以及我們文件和工具中的相關提示。我們認為建立自訂軟體的功能不適合初學者，因此在提交支援工單之前，請確保您具備執行此類任務所需的技能。
