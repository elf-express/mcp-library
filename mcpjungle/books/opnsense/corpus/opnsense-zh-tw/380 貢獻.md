# 貢獻

OPNsense 是一個開源社群項目，它的持續發展和成功取決於您的貢獻。

有很多機會可以貢獻力量，幫助 OPNsense 實現成為應用最廣泛的開源安全防火牆平台的目標。我們始終歡迎資金捐助，這將使我們能夠開發系統中那些原本可能被擱置的部分。

OPNsense核心團隊感謝所有已經做出貢獻的人。

---

## 財務方面

「*開源專案只有依靠社群的支持才能蓬勃發展*。」我們衷心感謝 OPNsense 使用者給予我們的所有鼓勵和支持。

用戶經常詢問我們如何為專案做出貢獻。為了改進軟體，我們需要您參與測試並提供回饋，如果您能捐贈一些資金，那就太好了。

---

### 捐款

為了幫助我們繼續開發並不斷改進項目，您可以捐贈支持我們。這是一種簡單、非定期、無任何附加條件的捐贈方式。任何金額的捐贈我們都將感激不盡！

  

---

### 聯盟計劃

OPNsense 專案提供合作夥伴計劃，企業在為專案提供資金支持的同時，也能獲得專案收益。

主要優勢包括：

-   在我們的 [OPNsense 合作夥伴頁面](https://opnsense.org/partners/)上列出
    
-   聯繫核心團隊
    

成為 OPNsense 計畫的合作夥伴意味著每年至少投資 2500 歐元。對專案做出傑出貢獻的合作夥伴將被授予白金合作夥伴稱號。

---

### 支持合約

透過支持合同，我們為您提供支持，您也為我們提供支持，因為 OPNsense 由 Deciso 提供全面支持。

如需支援選項，請參閱 [OPNsense 商業支援](https://opnsense.org/support-overview/commercial-support/)

---

## 發展

可以透過以下方式為 OPNsense 的持續開發做出貢獻：

-   測試開發版本
    
-   報告問題和/或
    
-   幫助解決問題以及其他方式
    
-   貢獻新功能
    
-   透過提交 pull request 的方式將你的程式碼分享給專案。
    

注意事項

在提交拉取請求之前，請閱讀我們的[編碼指南](<236 編碼指南.md>) ，並查看[支援選項](<379 支援選項.md>)中的社群支援等級。對於插件開發者來說，維護插件並與使用者互動至關重要QA 。

---

### 測試

參與測試最新開發版本，讓下一個版本比上一個版本更好。如果您想測試開發版本，最簡單的方法是登入控制台並輸入：

```
pkg install -y opnsense-devel
```

並恢復到生產版本：

```
pkg install -y opnsense
```

這就是測試最新開發版本所需的全部步驟。開發版本通常與最新正式版本在同一天發布。

---

### 報告問題

您可以在 GitHub 上輕鬆回報問題，請在報告前仔細考慮問題是否可能是設定錯誤或使用者錯誤。如果您不確定，請在 [論壇](https://forum.opnsense.org/)或 [IRC](https://web.libera.chat/#opnsense)上報告您的問題。

---

### 解決問題

如果您是程式設計師，或者知道如何解決某個問題，那麼您可以透過在 GitHub 上分享您的想法或提交 pull request 來提供協助。

---

### 設計新功能

如果您想參與新功能的設計，請先閱讀[開發手冊](<234 開發手冊.md>) ，並查看我們的[路線圖](https://opnsense.org/about/road-map/)以及[問題追蹤器](https://github.com/opnsense/core/issues) 。在開始之前，最好先與核心開發人員分享您的想法，您可以透過以下方式之一分享：

-   [github](https://github.com/opnsense/core/)和 [創建 issue](https://github.com/opnsense/core/issues/new)並說明您自願承擔開發任務（我們會將其正確標記為增強功能或特性）。
    
-   在IRC /Libera Chat (#opnsense) 上找到我們，看看我們是否有空討論您的想法。

## 翻譯

OPNsense 有一個活躍的[翻譯專案](https://translate.opnsense.org/projects/) ，目前支援：

-   捷克語
    
-   英語
    
-   法語
    
-   德文
    
-   日本人
    
-   葡萄牙語
    
-   俄文
    
-   簡體中文
    

翻譯工作很耗時，但如果您願意嘗試並希望協助添加另一種語言，請透過電子郵件 (contact@opnsense.org) 與我們聯繫。

---

## 文件和維基文章

幫助完善文件最簡單的方法是撰寫操作指南類文章。由於 wiki 和文件專案本身是用 **reStructuredText** 編寫的，您可以以這種格式提交內容（最好以 [pull request](https://github.com/opnsense/docs)的形式）。其他格式也是可以接受的，例如：

-   使用 ./images/directory 進行標記，並包含所使用的影像（如果有）。
    
-   包含嵌入圖片的 Word 文件（如有）
    

請將您的文件發送至 contact@opnsense.org。請確保：

-   如果您不擁有版權，則您的內容不得包含受版權保護的資料。
    
-   聲明我們可以根據[法律聲明](<378 法律聲明.md>)部分中列出的文檔版權使用該內容。

## 論壇 & IRC

如果您是一位經驗豐富的網路工程師，對防火牆技術非常了解，或者對 OPNsense 感興趣，那麼您可以透過在 [論壇](https://forum.opnsense.org/)或 [IRC](https://web.libera.chat/#opnsense)上幫助其他人來為該專案做出貢獻。

---

## 社群媒體

透過分享 OPNsense 如何幫助您解決網路或安全難題，為專案的成功做出貢獻。請向他人介紹 OPNsense，或在 [Twitter](https://twitter.com/opnsense)上關注我們並轉發我們的訊息。

任何有助於宣傳 OPNsense 的行為都將有助於我們實現成為使用最廣泛的開源安全和防火牆平台的目標。

---

## 結束語

如果您對其他人如何為 OPNsense 做出貢獻有任何建議，而該建議尚未在此頁面列出，請告知我們。您可以透過 contact@opnsense.org 聯繫我們。
