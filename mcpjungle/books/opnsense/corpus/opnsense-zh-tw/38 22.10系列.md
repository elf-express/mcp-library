# 22.10系列

OPNsense 商業版過渡到此22.10版本，包括升級到 FreeBSD 13.1, PHP 8.0 、Phalcon 5、 MVC/API IPsec、Unbound 和通知轉換、 BGP ASN牆別名、新的Sec⟦ APCUPSD日。

升級前請務必閱讀遷移說明。

下載連結如下。安裝指南 [\[1\]](<55 初始安裝和配置.md>) 和映像的校驗和也可以在下面找到。

[https://downloads.opnsense.com/](https://downloads.opnsense.com/)

## 22.10.2 （2023年2月20日）

此商業版本基於 OPNsense 22.7.11社群版，並增加了可靠性改進。

以下是完整的補丁說明：

-   介面：修復VLAN刪除時缺少配置鎖定
    
-   防火牆：啟動時不要切換網關
    
-   入侵偵測：當未發現元資料時，正確重置元資料響應。
    
-   未綁定：缺少全域變量，因此請求時快取永遠不會刷新。
    
-   mvc：使用前清理 searchRecordsetBase() 中的 $record 輸入
    
-   src：修正多個 OpenSSL 漏洞 [\[1\]]( https://www.freebsd.org/security/advisories/FreeBSD-SA-23:03.openssl.asc )
    
-   src: geli: 拆分HMAC [\[2\]]( https://www.freebsd.org/security/advisories/FreeBSD-SA-23:01.geli.asc ) 的初始化
    
-   src：修正第七代AWS實例類型 [\[3\]]( https://www.freebsd.org/security/advisories/FreeBSD-EN-23:03.ena.asc ) 重設後 ena 驅動程式崩潰的問題
    
-   src：修正 sdhci 損壞的寫入保護設定 [\[4\]]( https://www.freebsd.org/security/advisories/FreeBSD-EN-23:02.sdhci.asc )
    
-   src: import tzdata 2022g [\[5\]]( https://www.freebsd.org/security/advisories/FreeBSD-EN-23:01.tzdata.asc )
    
-   src: x86: 忽略APL30勘誤表的單步執行
    
-   ports: openssl 1.1 .1t [\[6\]]( https://github.com/openssl/openssl/blob/openssl-3.0/CHANGES.md )
    

已發布熱修復版本22.10.2 \_1:

已知問題和限制：

-   DH 參數在 OpenVPN 伺服器設定中不再可用，現在固定為 RFC 7919 4096 位元金鑰。唯一的缺點可能是舊機器上的性能較低。
    
-   臭名昭著的 /var MFS 功能已縮小到 /var/log 範圍，以避免未來需要 /var 下持久存儲的插件出現問題。實際上，使用 /var MFS 的人對於需要在 /var 下進行持久存儲才能運行的軟體沒有任何好處。在基於 SSD 的系統上，定期寫入 /var 的設定檔可以忽略不計。
    
-   os-dyndns 外掛程式仍然可用，因為自從我們啟動 os-ddclient 以來 ddclient 尚未發布非開發版本。其可用性可能稍後在 22.7.x 中更改。
    
-   控制台韌體更新現在將顯示基於文字的變更日誌，以便安裝更新（如果有）。使用箭頭鍵捲動更改日誌並輸入“q”以恢復更新過程。
    
-   手動 DHCPv6 追蹤模式現在需要提供適當的前綴範圍，就像靜態位址的對應前綴範圍一樣。如果偵測到先前的前綴 ID 類型輸入僅設定 IPv6 位址的低 64 位，則會發出警告，並且 ID 將被視為 IPv6 位址的高 64 位元。如果您的 DHCPv6 伺服器未啟動，請正確修復給定的範圍。
    
-   在此版本之前建立的空 CRL（系統：信任：吊銷）未正確儲存。當從此版本開始使用這些 CLR 時，這會導致 OpenVPN 伺服器無法運作。要在升級之前解決此問題，請從 OpenVPN 中刪除空的 CRL，或向其添加虛擬證書以正確填充 CRL，或者添加並刪除隨機現有證書以更正空的 CRL。
