# 硬體尺寸和設置


**硬體設定**需要仔細準備和選擇標準PC硬體組件，以實現 OPNsense 的預期安裝。

⚠ 預先安裝開源安全軟體 OPNsense® 的電腦硬體可以直接從各種（線上）商店購買。

提示

OPNsense 開發團隊鼓勵每個尋求交鑰匙解決方案的人從 [Deciso](https://www.deciso.com/) 或我們合作夥伴頁面上列出的其他合作夥伴之一購買。 **列出的合作夥伴為該專案做出了重大貢獻。**

## 支援的硬體架構

OPNsense® 適用於 [x86-64](https://en.wikipedia.org/wiki/X86-64) (amd64) 位元微處理器架構。 [SD 記憶卡](https://en.wikipedia.org/wiki/Secure_Digital)、[固態磁碟 (SSD)](https://en.wikipedia.org/wiki/Solid-state_drive) 或 [硬碟 (HDD)](https://en.wikipedia.org/wiki/Hard_disk_drive) 上的完整安裝適用於 OPNsense。

雖然支援的設備範圍從嵌入式系統到機架式伺服器，但硬體必須能夠運行 64 位元[作業系統](https://en.wikipedia.org/wiki/operating_system)。

## 硬體需求

對於大幅縮減的 OPNsense® 功能，有基本規範。為了實現完整的功能，有最低、合理和推薦的規格。

最低

這是運行所有不需要磁碟寫入的 OPNsense 標準功能的最低規格。這表示您可以運行所有標準功能，但需要磁碟寫入的功能除外，例如快取代理（快取）或入侵偵測和預防（警報資料庫）。

|   |   |
| --- | --- |
|處理器| 1 GHz 雙核心CPU |
| RAM | 3 GB |
|安裝方法|序列控制台或視訊 (VGA) |
|安裝目標 | SD或CF卡且至少有4個GB，使用nano鏡像進行安裝。 |

表：*最低硬體需求*

合理

這是運行所有 OPNsense 標準功能的合理規範。這意味著每個功能都是可用的，但可能不適用於大量使用者或高負載。

|   |   |
| --- | --- |
|處理器| 1 GHz 雙核心CPU |
| RAM | 4 GB |
|安裝方法|序列控制台或視訊 (VGA) |
|安裝目標 | 40 GB SSD，安裝程式運作至少需要 3 GB 記憶體。 |

表：*合理的硬體需求*

推薦

這是運行所有 OPNsense 標準功能的建議規格。這意味著每個功能都是實用的並且適合大多數用例。

|   |   |
| --- | --- |
|處理器| 1.5 GHz 多核心CPU |
| RAM | 8 GB |
|安裝方法|序列控制台或視訊 (VGA) |
|安裝目標 | 120 GB SSD |

表：*建議的硬體需求*

硬體指南

本地 OPNsense 所需的硬體將由預期的最小[吞吐量](#throughput) 和功能集決定。

## 功能集的影響

雖然大多數功能不會影響硬體尺寸，但少數功能會對硬體尺寸產生巨大影響。這些包括：

[魷魚](https://en.wikipedia.org/wiki/Squid_\(software\))

可用於 Web 內容控制的快取 Web 代理。這些包強烈依賴於CPU載入和磁碟快取寫入。

[強制門戶](https://en.wikipedia.org/wiki/Captive_portal)

在下面顯示的所有硬體規格中，具有數百個同時服務的強制門戶用戶的設定將需要更多的 CPU 功率。

[狀態轉換表](https://en.wikipedia.org/wiki/State_transition_table)

眾所周知，每個狀態表條目需要大約 1 kB（千位元組）的RAM。平均狀態表填入 1000 個條目，將佔用約 1 MB（兆位元組）的 [RAM](https://en.wikipedia.org/wiki/Random-access_memory)。具有數十萬個連接的 OPNsense 使用設定將相應地需要記憶體。

  

## 吞吐量

OPNsense 設定涉及的主要硬體因素是CPU, RAM、大容量儲存（磁碟）、網路介面的數量和品質。

網路介面卡

如 FreeBSD 硬體清單和建議所述，用於 [LAN](https://en.wikipedia.org/wiki/Local_area_network) 連接的英特爾® 網路介面卡 (NIC) 可靠、快速且不易出錯。 Intel 晶片組 NIC 以減少的 [CPU 負載](https://en.wikipedia.org/wiki/Load_\(computing\)) 提供更高的吞吐量。

支援的硬體

FreeBSD 是 OPNsense 的基礎。所有FreeBSD驅動程式都包含在OPNsense核心中，且硬體相容性是相同的。
