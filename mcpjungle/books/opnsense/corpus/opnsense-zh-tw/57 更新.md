# 更新

OPNsense 更新計劃每年包括兩個主要版本，大約每兩週收到一次小更新。主要版本號由發布年份和月份組成（例如 25.1 表示 2025 年 1 月版本），每兩週一次的次要更新添加了第三個數字（例如 25.1.3 表示 25.1 的第三次更新）。

## 更新設定

透過導覽至 System ‣ Firmware ‣ Settings，您可以影響韌體更新設定：

-   **韌體鏡像：** 這會影響 OPNsense 嘗試從中取得更新的位置。如果您在更新或搜尋更新時遇到問題，或者當前的鏡像運行緩慢，您可以在此處進行更改。
    
-   **發布類型：**這在每兩週定期的測試版本（生產）或最新的、未完全測試的程式碼（開發）之間切換。**請將此設定保留為“生產”，除非您完全理解切換的含義。 **
    

提示

設定頁面也是您可以運行審核的地方，這有助於調試常見的連接問題。如果您遇到遠端伺服器問題，只需按「執行審核」並從清單中選擇「連線」即可。

## 小更新

可以透過 Web 介面安裝更新，方法是前往 System ‣ Firmware ‣ Status。在此頁面上，您可以點擊「**檢查更新**」來搜尋更新。如果它們可用，則會出現一個按鈕，要求安裝它們。

## 主要升級

建議透過VGA顯示器或序列控制台完成主要升級，以便您可以看到正在發生的情況。

注意事項

您可以在[串行訪問](<60 序列存取.md>)下找到有關串行訪問的文檔

警告

主要更新是離線安裝的。這意味著沒有運行網路或SSH伺服器來監控升級。如果發生故障，您將需要輔助連線或直接存取來恢復快照或修復安裝。

如果您在最新版本的控制台選單上選擇選項 12，系統會詢問您是否要升級到最新版本或下一個主要版本。輸入主要版本號（例如“19.1”）並按 Enter 鍵。 OPNsense 將下載所有版本檔案以進行離線升級（核心、軟體包等），然後重新啟動。

重新啟動後，它將安裝所有更新，完成後，它將再次重新啟動。然後您應該就可以使用所需的版本了。
