# 選單系統


OPNsense 選單系統

[圖：../../_images/menusystem.png](https://docs.opnsense.org/_images/menusystem.png)

## 概述

OPNsense 框架的共用元件之一是選單系統，它包裝在單一類別中，並且是基本模型的一部分。

選單系統的唯一職責是建立一個樹狀結構來表示選單，並能夠追蹤選單系統的位置和層次結構之間的對應。為了保持簡潔和易於理解，選單系統不了解任何有關使用者或授權的資訊。

目前選單系統的主要焦點是支援舊程式碼，因此我們將能夠在舊程式碼和新程式碼中重新實作選單。

我們的基礎UI控制器（\\OPNsense\\Base\\ControllerBase）實作了選單系統以供進一步使用。

下面給出瞭如何建立選單的範例：

```
// create new menu
$menu = new Menu\MenuSystem();
// append an additional dynamic item into the system
$menu->appendItem("System.Advanced", "test123", array("url"=>"/testpage.php","order"=>1));
// test, print menu as structured named array
print_r($menu->getItems("/testpage.php"));
```

目前版本僅實作由一個XML檔案（models/OPNsense/Base/Menu/Menu.xml）定義的靜態選單，但元件中已支援使用其他XML檔案進行擴充以供日後使用。

## Menu.xml

選單xml定義如下：

```xml
<menu>
    <MainItem order="0" VisibleName="System" cssClass="glyphicon glyphicon-dashboard">
        <SubItem1 url="/ui/test.php"/>
        <SubItem2 url="/ui/test2.php"/>
    </MainItem>
</menu>
```

頂層應命名為“menu”，讓系統知道這是一個選單結構，接下來的層將用於其自身的結構。為了將屬性對應到建立的選單對象，OPNsense\\Base\\Menu\\MenuItem 中有設定器，在此版本中支援以下屬性：

-   order，在我們的選單中排序
    
-   VisibleName，要使用的名稱（如果未設置，將使用標記名/id）
    
-   cssClass，前端系統的樣式屬性。
