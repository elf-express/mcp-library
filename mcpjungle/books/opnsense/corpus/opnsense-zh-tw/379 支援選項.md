# 支援選項



## 軟體支援等級

OPNsense 可用於各種規模的基礎設施，在某些情況下，了解遇到問題時會發生什麼非常重要，尤其是在需要從第三方獲取維護基礎設施的部分知​​識時。

我們的平台易於擴展，這鼓勵人們開發我們未直接支援但對我們的用戶非常有價值的元件。

為了讓所有相關人員都清楚了解情況，我們決定在本章中解釋我們如何處理可用的元件。

我們目前區分了三個不同的支持級別，從關鍵支持到社區支持，其中關鍵支持始終由 OPNsense® 核心團隊直接支持，而社區支持您可以放心地認為核心團隊沒有（或參與非常有限）。

提示

在設計基礎架構時，如果您需要 OPNsense 社群外掛程式的創建者提供商業支持，您可以隨時與我們聯繫並討論各種方案。

如果社群外掛非常受歡迎，就可以在支援選項方面進行推廣，但要脫離社群層級發展，必須滿足一些條件。

-   軟體應該易於使用和理解。
    
-   插件的可維護性應該良好（程式碼品質高，遵循最佳實踐）。
    
-   應該提供文檔，並且至少要解釋組件的用途，包括最常用的設定。
    

以下是所涉及的層級：

### 危急（一級）

-   核心團隊負責開發與支持
    
-   編譯器錯誤或功能故障會阻止 Git 合併和發布。
    
-   該功能是標準安裝的一部分，或是官方支援的插件的一部分。
    

### 補充（第二層級）

-   核心團隊負責開發和支持，或認為該功能非常重要，值得投入時間，並從長遠來看將其提升到理想的狀態。
    
-   編譯器錯誤或功能故障會阻止 Git 合併
    
-   功能性問題，例如“已知問題”，仍然可能會包含在版本中。
    
-   某些功能需要使用者安裝插件/預設未安裝對應功能。
    

### 社區（三級）

-   第三層級由社群支持，這意味著OPNsense核心開發團隊不會為其提供支持，以避免團隊負擔過重。
    
-   將三級功能納入程式碼庫時，會存在一些限制和條件：
    
    -   提交者必須承諾維護該文件：
        
    
    > -   確保在 OPNsense 和/或外部庫（例如庫）更改後，程式碼能夠編譯並正確運行。
    >     
    > -   為遇到問題的使用者提供支援（論壇/git 問題追蹤器－所有相關問題都將分配給維護者）
    >     
    
-   程式碼以插件形式提供，不會包含在 OPNsense 的預設安裝包中。 OPNsense 核心團隊對此不承擔任何責任QA
    
-   如果該功能獲得廣泛關注，或者團隊認為它非常有用，則可能會被「提升」為官方支援功能（二級）。
    
-   如果提交者停止維護該功能且無人接手，則該功能將被移除。
    

### 開發中或未知（第四級）

-   作為第三層級的延伸，此層級專用於插件的開發版本，適用於插件未能設定層級或使用任何其他自訂第三方儲存庫的情況。
    

## 社群

如果您在使用 OPNsense 時遇到問題，可以先嘗試社群尋求協助。在尋求社區支持時，請務必理解，所有幫助您的人都是無償且利用業餘時間提供幫助的。即使您的問題或疑問可能無法完全解答，也請對幫助您的人表示感謝。

如需社區支持，您可以選擇以下方式：

-   開始搜尋此文件和維基百科
    
-   [OPNsense 論壇](https://forum.opnsense.org/)
    
-   請在 [IRC Libera Chat](https://libera.chat/) #opnsense 上向線上用戶提問。
    
-   請使用我們的範本之一，在 GitHub 上提交一個 issue（[core](https://github.com/opnsense/core/issues) ，[plugins](https://github.com/opnsense/plugins/issues) ）。
    

注意事項

當使用者在 GitHub 上建立 issue 時，通常會被標記為“支援”，但隨著更多資訊的揭露，其狀態可能會發生變化。問題分類需要時間，如果能在全新安裝的系統上輕鬆復現問題，那麼 issue 得到解決的可能性就越高。

## 商業的

由於我們建立和維護全球個人和公司使用的軟體，因此我們能夠在網頁設計選擇、解決問題以及圍繞 OPNsense 進行客製化開發方面為您提供幫助。

我們提供付費的擴展專業支援服務。您可以在[OPNsense網上商店](https://shop.opnsense.com/product-categorie/support/)中找到我們的選項，或者您可以直接[聯絡我們](https://shop.opnsense.com/contact-us/) 。
