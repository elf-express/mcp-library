# 25.1 “終極獨角獸”系列


十年來，OPNsense 透過模組化和強化開源防火牆，推動創新，提供簡單可靠的韌體升級、多語言支援、快速採用上游軟體更新以及清晰穩定的 2 條款BSD許可。

25.1 版本，綽號“終極獨角獸”，具有眾多 MVC/API 轉換、改進的安全區域支援和文件、ZFS 快照支援、帶有淺色和深色主題的全新 UI 外觀、PHP 8.3、FreeBSD 14.2 等等。

下面還可以找到下載連結、安裝指南 [\[1\]]( https://docs.opnsense.org/manual/install.html ) 和映像校驗和。

-   US西海岸: [https://mirror.sfo12.us.leaseweb.net/opnsense/releases/25.1/](https://mirror.sfo12.us.leaseweb.net/opnsense/releases/25.1/)

## 25.1.12 （2025年7月22日）

在上一個版本發布後又發布一個版本，這確實出乎意料，但並非毫無必要。 Sqlite 共享庫命名中的一個 bug 在 FreeBSD ports 中短暫出現，並被引入到25.1.11版本中，這很可能是導致重啟後出現軟體包缺失更新問題的原因之一。這個問題直到昨天在25.7的升級測試中才被發現。

為了確保正確升級，決定推出完整的穩定版本，並添加一些額外功能，例如修復 Unbound 和 LibXML 的安全問題，以及修復防火牆規則頁面在特定情況下無法保存的「現代瀏覽器」問題。

25.7版本仍計劃於明日發布，但需通過重建測試。韌體組件已完成連接，一旦鏡像伺服器顯示升級訊息，系統即可檢測到。此次版本發布可能不會再發布任何熱補丁。請在25.7版本發佈公告發佈數小時後再次檢查更新，以便鏡像伺服器同步。

以下是完整的更新說明：

-   韌體：為25.7添加指紋和升級提示
    
-   韌體：用於自動安裝 GDrive、IPsec 和 OpenVPN 舊版外掛程式的升級腳本
    
-   ui：取代自閉合選擇元素（由 Gavin Chappell 提供）
    
-   埠：libxml 2.14.5 [\[1\]]( https://gitlab.gnome.org/GNOME/libxml2/-/blob/v2.14.5/NEWS )
    
-   ports: sqlite SONAME修復及相關重建 [\[2\]]( https://github.com/freebsd/freebsd-ports/commit/25ef3857b8 )
    
-   埠：未綁定1.23.1 [\[3\]]( https://nlnetlabs.nl/projects/unbound/download/#unbound-1-23-1 )

## 25.1.7 （2025年5月19日）

Dnsmasq DHCP現已推出，並且由於我們收到了許多快速回饋，修復了多個問題，使其性能更加完善。我們了解近年來DHCP的複雜性，因此請記住，我們添加 Dnsmasq 是為了滿足小型部署的特定需求，而其他服務無法滿足這些需求。 Kea 在某些方面仍然表現出色，因此同時提供這兩種選擇是最佳方案。

以下是完整的更新說明：

-   系統：保護 local\_group\_set()，因為使用者可能由於正當理由而不存在。
    
-   interfaces：模擬 ifconfig 中 legacy\_interface\_create() 的邊緣情況的裝置名稱返回
    
-   介面：清理與VIP存取相關的冗餘函數
    
-   介面：改進私有網路和 Bogon 網路過濾器（由 Maurice Walker 提供）
    
-   介面：考慮重新載入時追蹤的介面和連結設備
    
-   防火牆：新增使用 src-ip6/dst-ipv6 指定符指定 IPv6 管道和佇列遮罩的功能（由 Daniel Tang 貢獻）
    
-   防火牆：在 shaper 中使用共用的 base\_bootgrid\_table 和 base\_apply\_button
    
-   強制門戶：恢復斷線原因的日誌記錄
    
-   強制門戶：修復 last\_accessed 被緩存自先前條目的問題（如果 N/A）。
    
-   強制門戶：將別名標記為外部類型，以便在規則中使用
    
-   dnsmasq：透過IANA規範提供所有DHCP選項

## 25.1 .b（2024年12月19日）

25.1系列將包含 FreeBSD 14.2 ，因此我們基於最新的開發狀態發布了此BETA版本。此版本不適用於生產環境，但所有插件均已提供，並且基於這些鏡像的安裝未來可以進行更新。

[https://pkg.opnsense.org/releases/25.1/](https://pkg.opnsense.org/releases/25.1/)

雖然還有一些工作要做，但大部分里程碑已經達成。如果您需要進行測試部署或想體驗一些新功能，這些鏡像檔案正適合您。讓我們攜手合作，共同打造更強大的 OPNsense。

25.1的最終發布日期為 1 月 29 日。候選版本將於 1 月初發布。

版本24.7的亮點包括：

-   系統：重構PPP以適應僅 IPv6 部署
    
-   系統：實現持久通知橫幅
    
-   系統：用於證書到期和續約的儀表板小工具
    
-   系統：高可用性狀態MVC/API轉換
    
-   系統：使用者和群組MVC/API轉換
    
-   系統：進階信任設定頁面
    
-   系統： ZFS快照GUI
    
-   報告： RRD健康圖重構
    
-   防火牆：改進了安全區域支援和文檔
    
-   IPsec：進階設定MVC/API轉換
    
-   unbound：將網域覆蓋合併到查詢轉送中
    
-   UI：主題更新，採用全新樣式並添加官方深色主題
    
-   來源：FreeBSD 14.2
