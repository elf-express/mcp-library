# 快取代理



注意事項

確保透過 System ‣ Firmware ‣ Plugins 安裝 `os-squid` 才能使用網路代理。從 OPNsense 24.1 開始，代理不再包含在預設安裝中。

OPNsense 配備了功能齊全的前向快取（透明）代理。快取代理透過快取和重複使用經常請求的網頁來減少頻寬並提高回應時間。存取控制清單可用於使用者驗證和/或作為（基於類別的）網路篩選器。

特點包括：

-   多介面支援
    
-   透明模式（包括SSL/HTTPS）
    
-   ICAP 支援防毒/惡意軟體引擎
    
-   HTTP 代理
    
-   FTP 代理
    
-   使用者認證
    
-   存取控制清單（對 http(s) 和 ftp 均有效）
    
-   （壓縮）黑名單
    
-   基於類別的網頁過濾
    
-   可與流量整形器結合使用
    

## 驗證器

使用者身份驗證可以使用 OPNsense 標準和內建身份驗證器來完成。目前這些包括：

-   LDAP（含 Microsoft Active Directory）
    
-   半徑
    
-   本地用戶管理員
    
-   沒有認證
    

這些選項可以在 Web 代理程式 -> 管理 -> 轉送代理程式 -> 驗證設定部分中找到。

## 存取控制

OPNsense 支援細粒度存取控制，可在 Web 代理程式 -> 管理 -> 轉送代理程式 -> 存取控制清單中進行配置，其中包含以下（進階）選項：

-   子網
    
-   港口
    
-   MIME型
    
-   禁止IP’s
    
-   白名單
    
-   黑名單
    
-   瀏覽器/用戶代理
    

## 交通管理

代理可以與流量整形器結合使用，並充分利用其整形功能。此外，它還包括自己的選項：

-   最大下載大小
    
-   最大上傳大小
    
-   整體頻寬限制
    
-   每個主機的頻寬限制
    

這些選項可以在 Web 代理 -> 管理 -> 常規代理設定 -> 流量管理設定部分中找到。

## 基於類別的網頁過濾器

不需要額外的插件，例如squidGuard - 因為 OPNsense 具有內建的基於類別的 Web 過濾器支援。主要特點包括：

-   從遠端取得URL
    
-   支援平面檔案列表和基於類別的壓縮列表
    
-   自動將基於類別的黑名單轉換為魷魚 ACL
    
-   使用內建調度程序保持最新狀態
    
-   相容最流行的黑名單
    

## 透明模式

透明模式意味著所有請求都將被轉送到代理，而無需在客戶端進行任何設定。透明模式非常適合不安全的 http 請求，但是使用安全的 (SSL) HTTPS 連接，代理將成為中間人，因為客戶端將與代理“對話”，而代理將使用客戶端需要信任的主密鑰來加密流量。

警告

使用透明的HTTPS代理可能是一種危險的做法，您使用的服務（例如電子銀行）可能不允許。

## WPAD 和 PAC

如果無法使用透明代理，OPNsense 仍然支援透過 WPAD / PAC 自動配置代理。

警告

透過 DNS 的 WPAD 要求 Web 介面在預設 HTTP 連接埠 (TCP/80) 上運行，這也是安全風險（MITM 攻擊）。在這種情況下，您應該代理連接或避免從不受信任的網路配置設備。

## 自訂錯誤頁面

錯誤頁面可以根據您自己的需求進行自訂。為此，請前往 Web 代理 -> 管理 -> 常規代理設置，然後在“用戶錯誤頁面”中選擇“自訂”，之後將顯示一個名為“錯誤頁面”的附加選項卡。

前往此標籤並使用頂部的下載圖示接收包含所有可用錯誤頁面和關聯的級聯樣式表的 zip 檔案。  
  
更改檔案後，再次壓縮它們並使用相同選項卡上的檔案選擇器選項上傳，然後使用上傳按鈕 。  
  
重設按鈕可用於從配置中刪除自訂模板，之後下載選項將傳回標準 OPNsense 模板。

建立自訂主題錯誤頁面時需要考慮一些規則：

-   擴充 `errorpage.css` 檔案來主題化您的頁面
    
-   確保錯誤頁面除了 css 之外不需要任何其他內容，圖像應轉換為 base64 並內聯提供。這不僅比單獨的圖像檔案處理起來更快，而且還可以防止無法存取圖像時出現渲染問題。
    
-   僅處理現有的錯誤頁面，如果檔案名稱不匹配，檔案將不會寫入磁碟。您可以使用下載按鈕檢查正在部署的內容（它將傳回一組自訂和標準檔案的組合）
    
-   最好不要包含未更改的文件，這樣可以節省配置空間並防止預設值被覆蓋。
    

提示

如果您只想更改背景圖片，通常只需上傳目錄中的 css 檔案並忽略所有 html 檔案。

提示

要將圖片轉換為內嵌 Base64 標籤，有很多可用的線上工具，可以使用 google 輕鬆找到。例如，我們的標誌可以在 css 檔案中找到，如下所示 `background: url('data:image/svg+xml;base64,PD9...) no-repeat left;`
