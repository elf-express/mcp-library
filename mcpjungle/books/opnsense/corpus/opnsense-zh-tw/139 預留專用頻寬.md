# 預留專用頻寬


**為即時流量預留專用頻寬，例如（託管）Voice Over IP (VOIP) 伺服器。**

在這種情況下，我們將建立一個專用於進出即時應用程式的流量的管道。對於範例，我們假設有一個 SIP 中繼或託管 Voice Over IP (VOIP) 伺服器。

對於此範例，我們假設需要 4 個 64 kbps 的未壓縮語音通道，導致總頻寬為 256 kbps。本範例中的網際網路連線具有 10 Mbps 下載和 1 Mbps 上傳。

[圖](https://docs.opnsense.org/_images/nwdiag-3418ebe96212e329652ed37ad74bd28dc53d6d4c.png)

塑造託管VOIP / SIP主幹樣本

首先前往 Firewall ‣ Shaper ‣ Pipes。

## 步驟 1 - 建立上傳和下載管道

在 **管道**標籤上，按一下右下角的**+**按鈕。將彈出一個空的**編輯管道**螢幕。

建立上傳管道（到我們的VOIP伺服器）

|   |   |   |
| --- | --- | --- |
| **啟用** |已檢查 | *檢查以啟用管道* |
| **頻寬** | 256 | 256 *所需頻寬的數值* |
| **頻寬指標** |千位元組/秒 | *與數值一起使用的量測* |
| **面具** | （空）| *用於自動排隊，我們的範例為空* |
| **描述** | PipeUp-256kbps | *自由字段，輸入描述性內容* |
