# 19.1 「鼓舞人心的鬣蜥」系列

四年來，OPNsense 透過模組化和強化開源防火牆，推動創新，提供簡單可靠的韌體升級、多語言支援、強化的 BSD 安全性、快速採用上游軟體更新以及清晰穩定的 2 條款BSD許可。

19.1版本，暱稱“Inspiring Iguana”，自 6 個月前18.7發布以來，共包含 620 項獨立更改，這些更改分佈在 12 個中間版本中，包括最近的候選版本。這意味著平均每月發布 2 個穩定版本，其中包含安全性更新和重要的錯誤修復！如果要列舉幾個亮點，那就是：防火牆別名API終於上線。向 HardenedBSD 11.2的遷移已完成。雙重認證 (2FA) 現在支援遠端LDAP / 本地TOTP組合。此外，OpenVPN 用戶端匯出也已重寫，以完全支援API 。

## 19.1.7 （2019年5月2日）

本次更新包含多項改進，例如橋接的鏈路本地支援、 HA同步整合、為大多數系統下載功能將本地 CA 新增至受信任的SSL憑證中、針對 IPsec 和 Web 代理程式的基於插件的PAM 2.8 4.1.4的第三方修復。

Python 3 遷移目前也在進行中，這需要引入兩個 Python 版本，這可能會對嵌入式 Nano 安裝造成很大負擔，但我們看不到其他方法可以在20.1中完全完成這項繁瑣的任務，該任務可能會持續到19.7 。

說到20.1 ：這是多次提醒， 20.1將停止i386（Intel 32位）系列產品線，這一點多年來社區內已多次討論過。我們希望ARM64能夠成為一個可行的替代方案。但這又是另一個話題了。

您可能已經注意到，該專案並沒有像之前那樣每隔一周發布一次版本，這其中有許多原因：

在安全性方面，我們並沒有太多必要的第三方軟體更新。在功能方面，我們正在為即將推出的19.7系列開發一系列改進，這些改進將逐步應用到19.1版本中，但同時，我們也需要進行更多的準備和測試。在社群方面，在合作夥伴max it的贊助下，我們開始著手改進預設閘道切換功能，這導致了網關整合的整體重構，並迅速轉向介面處理重構，進而提升了核心服務（OpenVPN、IPsec、Unbound、Dnsmasq、 DHCPD 、Dpinger）的插件功能。現在看來，這是迄今為止對多年前創建且僅偶爾打補丁的程式碼進行的最大規模重構。我們希望這能展現我們對程式碼庫的投入，即使程式碼並非總是100%無bug。如果您有興趣參與，現在正是試用開發版本並向我們回饋其效能的好時機。

## 19.1.2 （2019年2月28日）

本次更新是經過數週密集測試和調試後的結果，測試和調試領域包括：租期非常短的WAN DHCP 、Suricata IPS無法按預期工作、設備名稱過長的堆疊式 6RD 設定等等。

這次更新可能會有些不順利，因為 Web GUI會話目錄將會被移轉到更安全的位置。更新期間您將被強制登出，並且系統會因作業系統更新而重新啟動。系統重新啟動後，您就可以像往常一樣登入了。

LibreSSL 已從2.7升級到2.8 。如果您在使用 LibreSSL 時遇到任何問題，請務必告知我們，因為令人遺憾的是，OpenVPN、Squid、StrongSwan 和NTP等第三方專案似乎將 LibreSSL 的使用權留給了少數能夠自行修復原始程式碼建置問題的用戶，而我們希望盡可能避免為第三方軟體修補程式。
