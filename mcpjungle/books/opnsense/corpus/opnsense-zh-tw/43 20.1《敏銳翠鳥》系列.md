# 20.1《敏銳翠鳥》系列


五年多來，OPNsense 透過模組化和強化開源防火牆、簡單可靠的韌體升級、多語言支援、HardenedBSD 安全性、上游軟體更新的快速採用以及清晰穩定的 2 條款BSD 許可來推動創新。

20.1，綽號“敏銳的翠鳥”，是對永續防火牆體驗的微妙改進。此版本新增了 VXLAN 和其他環回裝置支援、IPsec 公鑰驗證和橢圓曲線 TLS 憑證建立等。第三方軟體已更新至最新版本。日誌記錄前端針對 MVC 進行了重寫，並提供無縫 API 支援。另一方面，文件的品質和數量都得到了提高，現在以熟悉的選單佈局呈現。

下載連結、安裝指南 [\[1\]](<55 初始安裝和配置.md>) 以及圖像的校驗和也可以在下面找到。
